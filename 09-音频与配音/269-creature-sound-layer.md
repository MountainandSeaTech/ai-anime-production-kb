# 动物声音层

## 核心要点
- **存在感一半靠声音**：呼吸、鼻息、爪步、毛皮摩擦构成"动物体音层"——没有体音只有叫声的动物＝后期配上去的
- **三个同步点**：呼吸声对胸腹起伏峰值帧、爪步声对足部落下帧、毛皮摩擦声对身体接触/转向帧——音画对不齐＝假
- **体音比叫声重要**：叫声是事件（剧情点），体音是存在（持续在场）；一场戏可以零叫声，不能零体音

## 详细内容
- **分景别给声**：近景可给鼻息/呼吸/舔舐细响；中景给爪步与身体摩擦；全景只给群体环境声（蹄声、翅膀、低鸣底噪）
- **大型动物加低频**：胸腔共鸣的低频呼吸/踏步低频震感，是"大"的听觉凭证——与 260 视觉重量互证
- **情绪进声音**：警觉＝呼吸屏住（声音消失也是信息）；恐惧＝高频呜咽断续；亲昵＝呼噜/叹鼻——声音五态与 255 体征五态配套

## 关键参数 / 模板 / 清单
```
体音清单（按镜别取用）：
  近景：鼻息喷声、呼吸起伏声、舔鼻、胡须扫过布料的细响
  中景：爪垫落地声（软）/爪甲叩地声（硬）、毛皮蹭过衣料、抖毛声
  全景：蹄声群、翅膀扑棱、远处低鸣底噪

后期备注写法（制作本段末）：
  「后期：本段加貂的呼吸与偶尔鼻息，音量压在人声下 -12dB 作底；
   S09-3 拔剑瞬间貂的呼吸声骤停——静音即警觉。」

同步检查：
  □ 呼吸声峰值对胸腹起伏帧  □ 爪步对落足帧  □ 摩擦声对接触帧
```

## 备注
- 与 247（音效分层）同法：动物体音是一层独立轨道，与人声、环境声分轨混音
- AI 视频原生音效常漏体音层——制作本里把体音写进后期备注，别指望模型自动给
- "声音消失"也是设计：警觉态的骤静比任何叫声都有效（→255 警觉态全身凝固的音画对应）
- 来源：动物 Foley 音效设计文献
