# 音效前置与延迟

## 核心要点
- **音画错位是张力的隐藏高手**——声音和画面不同步反而更揪心
- **音效前置**：声音先于画面出现（先闻刀声再见刀）=预期揪心
- **音效延迟**：画面先于声音（先见斩再见血/声）=重量感+回响
- 同步（声画同时）是最普通的选择，错位才是张力工具

## 三种音画时序

| 时序 | 效果 | 张力用途 |
|---|---|---|
| 前置（声先于画） | 预期揪心、悬念 | 威胁未现先闻声 |
| 同步（声画同时） | 写实、冲击 | 普通爆发 |
| 延迟（画先于声） | 重量感、回响、凝固 | 致命一击、剧变 |

## 音效前置（声先于画）

### 原理
- 观众先听到威胁的声音但没看见=信息差（013 心理轴）
- "什么发出的？"=悬念激活，注意力锁定画面等"看见"
- 等看见的瞬间=延迟释放=揪心峰值

### 经典用法
- 脚步声先于追兵入画（追逃）
- 刀鸣声先于出刀画面（居合）
- 低吼先于怪物现身（恐怖）
```
画面：主角近景听声（0.5s，声先入）→ 画面：转头（0.3s）→ 画面：追兵入画+脚步声同步（0.3s）
```
声先入 0.5s，主角先听→观众跟主角一起紧张→追兵入画释放。

## 音效延迟（画先于声）

### 原理
- 画面已经发生但声音没到=时间错位=凝固感
- 观众"看见但没听到"=本能不安=重量感
- 适合致命一击、剧变、死亡

### 经典用法
- 斩击画面先现，刀声延迟 0.1-0.3s 到=重量感
- 中刀画面先，痛呼/倒地声延迟=凝固
- 爆炸闪光先，爆声延迟（光速快于声速的真实感）
```
画面：出刀斩（0.3s）→ 0.2s 静默延迟 → 刀声/中刀声炸响（0.3s）
```
画先 0.2s，那 0.2s 的静默=凝固，声到=释放。

## 时序的张力配方

### 居合斩杀（前置+延迟组合）
```
蓄势静默（1.5s）→ 刀鞘微响前置0.2s（声先于出刀画）→ 出刀画面（0.2s）→ 刀声延迟0.15s（重量感）→ 中刀声+爆点（0.3s）
```
前置（鞘响）→延迟（刀声）→爆点，三段音画错位。

### 追逃威胁（前置主导）
```
主角跑画面+静默（0.8s）→ 脚步声前置入（0.5s，追兵未现）→ 主角回头（0.3s）→ 追兵入画（0.3s）
```
声先于画，悬念拉满。

### 致命一击（延迟主导）
```
斩击画面（0.3s）→ 0.2s 静默延迟 → 中刀声炸响（0.3s）→ 倒地声（0.5s）
```
画先声后，凝固重量感。

## 时序的常见坑
- **全程同步**=最普通，无张力工具
- **延迟太长**（>0.4s）=违和，观众以为 bug
- **前置太早**（>0.8s）=声画脱节，观众忘了声
- **滥用错位**=每镜都错位=无对比=混乱

## 前置/延迟的音效选择
- 前置声要"辨识度高"（脚步、刀鸣、低吼）——观众一听就知道是什么
- 延迟声要"爆发感强"（刀声、枪声、爆音）——延迟后炸响才有释放感
- 静默段（033）常作为前置和延迟的"缓冲带"

## AI/剪辑实操
- AI 视频生成不带可控音效，全部后期叠加
- 工具：剪映/达芬奇，音轨可独立移动对齐画面
- 前置：把音效轨往左拖 0.2-0.5s
- 延迟：把音效轨往右拖 0.1-0.3s，中间留静默
- 关键：错位幅度小（0.1-0.5s），大了就 bug 感

- [ ] 错位幅度在 0.1-0.5s 吗？
- [ ] 全程同步的镜有没有（同步也是必要的，别全错位）？

## 备注
- 音画错位是 011 延迟释放+013 信息差的"听觉版"
- 前置=听觉信息差（先闻），延迟=听觉凝固（后闻）
- 错位是隐藏高手，新手很少用，用好张力翻倍
