# 配乐配置会与双主题大纲

## 核心要点
- 配乐曲线的首要功能是**为电影服务**——音乐再伟大也必须服从影片需求
- **反"米老鼠式配乐"**：可预知的、与画面逐点同步的配乐是烂配乐的标志
- 好配乐的两难悖论：有的能唤起画面，有的记不住旋律却"一直能感受到"——吕美特追求后者
- 音乐可以做**叙事结构设计**：双主题数学大纲，中点对峙、结尾一方主导
- 不用配乐是合法选择；每段音乐要有足够时长讲述它要表达的内容
- 关联 154 情绪曲线、158 主题动机、151 声画关系

## 配乐的第一原则：服务，而非展示

- 唯一可脱离电影独立存在的配乐是普罗科菲耶夫《冰上之战》（据传爱森斯坦据配乐剪辑）——这是例外而非常态
- 配乐不要重复画面，要**表达画面没说出的东西**：《大审判》中保罗·纽曼的背景几乎未交代，吕美特让约翰尼·曼德尔为其"宗教环境中的童年"写深邃沉郁的音乐——功能是"营造跌落前受到恩宠的状态"，服务于"重生"主题
- **米老鼠式配乐（mickey-mousing）**：画面动作与音乐逐点同步、可预知——即便出效果也是烂标志。AI音乐工具极易生成此类配乐，需主动要求非同步、留白、反讽

## 双主题数学大纲（《典当商》范式）

配乐概念="哈莱姆的凯旋"，与昆西·琼斯设计**近乎数学般精确的音乐大纲**：

| 段落 | 欧洲主题（古典/精确/柔和） | 哈莱姆主题（打击乐/铜管/狂野爵士） |
|---|---|---|
| 开场 | 主导 | 潜伏 |
| 推进 | 此消 | 彼长 |
| 中点 | 旗鼓相当 | 旗鼓相当 |
| 结尾 | 退场 | 主导 |

- 两主题占比曲线 = 角色内心"冰墙被打破"的声音化——**音乐结构直接呼应主题**
- 短剧可直接套用：为两个阵营/两种心境各设一个动机（158），按剧情进度编排占比曲线，中点对峙、结尾一方主导——低成本高叙事效率的声音设计

## 配器改变戏剧含义

- 《伦敦间谍战》全片只用**一首爱情歌曲主题**，随配器改变，从爱情歌变成最具戏剧张力的配乐
- 同一动机换配器=统一感白送，且能随剧情变质——与154"五段同一动机不同配器"互证
- 昆西·琼斯自己配器不分包——配器即创作，不是后期加工

## 不用配乐是合法选择

| 影片 | 无配乐理由 |
|---|---|
| 《热天午后》 | 首要义务是让观众相信事件真实发生过 |
| 《山丘》 | 自然主义 |
| 《电视台风云》 | 音乐会妨碍笑话、与大段台词冲突 |

- 制片厂讨厌无配乐，因为这让他们害怕——但真实感、段子密度高的作品，无配乐反而成立
- 音效与配乐通常只用其一：《东方快车谋杀案》声音剪辑师花六周做火车真实音效，混音时吕美特选了华尔兹——"我们听过火车驶离站台，但从没听过火车以四三拍驶出站台"

## 可复用流程：音乐配置会（spotting session）

```
1. 初剪满意后开会，回到最根本的问题：
   "这部电影是讲什么的？配乐能做什么？"
2. 逐卷看片，导演与作曲家各自提出音乐进入点 → 初步草案
3. 复核：作曲家是否有足够空间表达？转场音乐是否有足够时长？
4. 确定每段配乐精确时长，逐格对应画面
   ——切入点差几格都决定成败；此修改过程持续2-3天
```

- **反对"刺激点"（stings）和二十几秒叠化转场音乐**："短暂的音乐转场只会让空气充斥多余声响，真正需要配乐时效果大打折扣。每段音乐都应有足够时间讲述它要表达的内容。"
- **选人标准**：昆西·琼斯、保罗·茅原都是首次做电影配乐——缺乏电影配乐经验是加分项（避免套路），但古典功底要扎实

## AI迁移清单

- 配乐先问"**这部短剧讲什么**"，再定音乐功能：暗示角色未言明的过去（《大审判》式）/ 做主题结构（《典当商》双主题式）
- 提示词写"**表达画面没说的东西**"，而非描述画面本身
- 双主题大纲提示词模板："为阵营A写动机X（古典/克制），为阵营B写动机Y（打击乐/狂野），前段X主导，中点两者对峙交织，结尾Y主导淹没X"
- 警惕AI逐点同步：主动要求"音乐不与画面动作对齐""留白段落""反讽性错位"
- 敢于整段不用配乐：真实系、对白密度高的短剧，无配乐>烂配乐
- 分段生成时给每段留足时长，拒绝20秒敷衍转场（154分段点单法联动）

## 备注
- 核心：音乐为电影服务；双主题大纲=用音乐结构写主题
- 配置会逐格定切入点，差几格定成败；流程耗时2-3天，不可省
- 选作曲家：电影配乐经验少=加分，古典功底=必需
