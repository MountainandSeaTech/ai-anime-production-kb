# 音画关系总论

## 核心要点
- 拿到任何一段声音，先问唯一的问题：**角色听得到吗？** 听得到=叙事内(diegetic)，听不到=叙事外(non-diegetic)
- 同步(synchronization)是声音和画面讲同一件事；对位(counterpoint)是声音故意讲另一件事
- 声音不是画面的附件——它是**第二条叙事轨**，能和画面平行、加强、或背叛画面
- AI短剧的声音90%是后期贴的，所以音画关系是**剪辑台上的决定**，不是生成时的运气

## 坐标系：声音的户籍登记

### 2×2定位表
```
            屏内(声源可见)        屏外(声源不可见)
叙事内      角色对话/画面里的收音机   画外脚步声/隔壁的枪声
叙事外      BGM/旁白(对着空气配)     画外旁白/内心独白*
```
- *内心独白=内部叙事声(internal diegetic)——角色脑内的声音，观众听得见，同场其他角色听不见
- 希区柯克套路：**audio before visual**——先出画外音，再揭示声源，悬念就是这么廉价又有效

### 四种声音身份的实战功能
| 身份 | 例子 | 功能 |
|---|---|---|
| 叙事内屏内 | 对白、拔刀声 | 锚定真实感 |
| 叙事内屏外 | 画外警笛渐近 | 扩展画框，省镜头 |
| 叙事外配乐 | BGM、主题动机 | 操控情绪（158） |
| 叙事外旁白 | 主角吐槽/上帝视角 | 压缩叙事，补信息 |

## 同步与对位：二选一的岔路

### 同步（平行音画）
```
画面：英雄冲锋 → 音乐：激昂鼓点
画面：恋人相拥 → 音乐：温柔弦乐
```
- 观众零认知负荷，情绪直给
- 风险：**太顺=太无聊**，全程同步像MV

### 对位（反差音画）
```
画面：屠杀 → 音乐：欢快圆舞曲（发条橙）
画面：婚礼 → 音效：心电监护仪的平线声
```
- 观众被迫同时处理两层信息=张力翻倍
- 风险：对位失败=观众以为音轨贴错了
- 详见 153 音画对位表意

### 选择原则
```
要爽 → 同步（动作戏踩点，160）
要深 → 对位（悲剧配乐景）
要怕 → 先同步后抽离（静默，155）
```

## 声音的四个叙事岗位
1. **交代环境**：鸟叫=白天森林，不用拍树
2. **引导注意**：嘈杂人群中一声清响=观众自动找声源
3. **补画外空间**：单镜头出租屋+楼下麻将声=整个世界（157）
4. **替代画面**：惨叫+黑屏>直给血腥画面（审查友好+想象更恐怖）

## 视觉声音：让画面先"发声"

- 声音不必先出现——**画面能先制造听觉**：水花溅开的弧度、反光的闪烁节律、撞击的形变、尘埃落地的节奏，都在暗示声音的形状与节律，观众会在大脑里自动合成音效
- 先给画面端"能被听见"的线索，音频端再落实，声画互为因果（画面端线索对接 156 拟音）

## AI短剧应用清单
```
□ 分镜表加"音轨列"：每镜标注 叙事内/外 + 同步/对位
□ 生成画面时预留"声音接入点"：角色转头/停步=贴画外音的位置
□ 无声镜头是有意设计还是忘了配——写清楚，别让剪辑师猜
□ 叙事外音乐的情绪走向要和137的J/L-cut配合：音乐先行于画面切换
```

## 常见坑
- **BGM万能胶**：什么画面都糊一层煽情音乐=声音丧失叙事权，变成噪音壁纸
- **叙事层级混乱**：角色听不到的声音配了角色的反应=穿帮（除非喜剧效果）
- **对位无动机**：随便反差=随机，对位的两层必须有主题关联（153）
- **忽视画外音**：AI单镜头信息有限，不肯用画外音补世界=每镜都在硬拍全景
- **音画同起同落**：所有声音和画面同时开始同时结束=机械感，J/L-cut错位才是人话（137）

## 进阶
- **身份滑动**：让音乐从叙事外滑进叙事内——片尾BGM拉到一半，画面切到酒吧，原来乐队就在现场。观众会下意识重估整段戏
- **声源延迟揭示**：画外音出现3次后才给声源镜头=悬念结构（137的L-cut变体）
- **层级翻转**：恐怖片惯用——观众以为是叙事外的紧张配乐，突然角色说"你听到那个声音了吗"，汗毛倒竖
- **静默也是一种身份**：见 155，无声不是没有声音，是声音的减法设计

## 备注
- 第一问永远是：角色听得到吗
- 同步给爽，对位给深，静默给怕
- 声音是第二条叙事轨——可以平行，可以背叛
- 关联：137 J/L-cut、153 对位、155 静默、157 空间感、034 节拍同步
