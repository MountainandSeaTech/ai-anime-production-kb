# BGM 节拍对齐峰值

## 核心要点
- **BGM 节拍 = 张力的心跳**——剪辑点对齐节拍=节奏感强=张力翻倍
- 蓄势段用低频/渐强堆积，峰值段重拍/爆点炸响
- 节拍错位=张力崩盘：BGM 在蓄势段就炸=峰值提前泄
- 三层结构：蓄势（低频堆积）→峰值（重拍炸响）→释放（余音/静默）

## BGM 在张力曲线的三层

### Build-up 蓄势段
- 低频持续（drone/bass）+ 渐渐加密的节奏
- 音量渐强（crescendo），但不到爆点
- 任务：把听觉预期拧到顶，等"那一拍"
```
低频渐强 2s → 节奏加密 1s → 屏息静默 0.3s → ...
```

### Peak 峰值段
- 重拍/爆点在出刀/开枪瞬间炸响
- 与硬切点（032）对齐=视听双爆发
- 任务：把累积的听觉预期一次释放
```
... 静默 0.3s → 重拍炸响+刀声 0.3s → 余响 0.5s
```

### Release 释放段
- 余音/低频回降/或静默
- 任务：给观众听觉喘息
```
余响 1s → 渐弱 → 静默收
```

## 节拍对齐的核心技法

### 1. 剪辑点踩拍
- 每个硬切（032）对齐 BGM 重拍=视听同步=节奏感
- 蓄势段慢切踩慢拍，爆发段快切踩快拍
- 错位（切点不在拍上）= 脱节=张力散

### 2. 静默接爆点
- 蓄势到顶→BGM 突然静默 0.3-0.5s（见 033）→重拍炸响
- 静默=听觉延迟，重拍=听觉释放
- 这就是"drop"技法（电音常用）

### 3. 渐强到爆
- 蓄势段音量/节奏密度持续上升
- 上升到顶→一瞬静默→爆点
- 渐强=听觉蓄势，与视觉蓄势同步

## BGM 类型选择

| 张力场景 | BGM 类型 | 特征 |
|---|---|---|
| 居合斩杀 | 太鼓/和风打击 | 单点重击，留白多 |
| 追逃 | 急促弦乐/电子 | 持续紧张，节奏密 |
| 对峙对白 | 低频drone+心跳 | 低沉渐强 |
| 倒计时 | 钟声/滴答 | 规律节拍逼近 |
| 决别悲剧 | 缓慢弦乐 | 长音余韵 |

## 节拍对齐的反例

### 蓄势段就炸
- BGM 在蓄势段已经爆点=峰值提前泄=真正峰值时没燃料
- 解法：蓄势段只用低频渐强，爆点留给峰值

### 切点不踩拍
- 硬切在两拍之间=脱节=节奏散
- 解法：剪辑时把切点拖到波形重拍上

### 全程满音量
- BGM 从头炸到尾=无渐强无静默=无对比=平
- 解法：必须有渐强+静默+爆点的层次

## 经典 BGM 张力序列（居合）
```
低频drone渐强（2s，蓄）→ 节奏加密太鼓（1s，拧）→ 全静默（0.3s，屏息）→ 重拍+刀声炸响（0.3s，峰）→ 太鼓余响（1s，释）
```
蓄→拧→静→爆→释，五段听觉曲线，与视觉曲线（014）同步。

## AI/剪辑实操
- AI 视频生成不带可控 BGM，需后期叠加
- 工具：剪映/达芬奇，用波形图把切点对齐重拍
- 选 BGM：优先有明确"build-up→drop"结构的（电子/太鼓/影视配乐）
- 静默段手动抽音轨，爆点手动叠音效

## 自检：BGM 是否服务张力
- [ ] 蓄势段有没有渐强（不是全程满音量）？
- [ ] 峰值前有没有一瞬静默？
- [ ] 爆点有没有重拍+音效炸响？
- [ ] 剪辑硬切点踩在 BGM 重拍上吗？

## 备注
- BGM 是 014 张力曲线的"听觉版"，与视觉曲线必须同步
- 节拍对齐是 032 硬切的听觉搭档，两者错位则双崩
- 动漫短剧 BGM 选曲优先"有 build-up→drop 结构"的，省后期调
