# 产品宣传片声音设计与节拍同步方法论

## 一、节拍同步方法论

> 强节奏 BGM 的片子，所有转场和关键动效必须落在拍上。目标：成片切点误差 ≤3 帧（感知阈值）。

### 0. 何时启用

- 用户已选好 BGM → 先分析节奏，再让分镜的每个切点/动效锚到拍号
- 未选 BGM → BGM 选型放后期，动效时间线按内容节奏排，不强行卡点

**铁律：音乐先行。** 网格没验收通过之前不设计分镜；时长对不上时改时间参数，不删改用户文案。

### 1. 节拍网格测定

不相信 `beat_track` 返回的 tempo 标量（可能偏差 2%+），用 beat 时刻序列做最小二乘等距网格拟合：

```
t_i = t0 + i × T
BPM = 60 / T
```

**验收**：残差 ≤ ±15ms（半帧内）说明是机器鼓点、网格可信；残差大说明有变速段，需分段拟合。

**半倍/双倍歧义必查**：beat 检测常在 2x/0.5x 之间跳。判据不是听感——正确网格下 kick 应主要落在整数拍。

**复杂曲先分离鼓 stem**：人声/贝斯厚的编曲会埋掉鼓的攻击。轻量方案用 `librosa.effects.hpss` 取打击成分；重方案用 Demucs 分离整条鼓轨。

### 2. 鼓点分类与能量结构

**三分类瞬态检测**（分频段各测一遍）：

| 类别 | 频段 | 驱动的动效 |
|---|---|---|
| kick | 40–160 Hz | 冲击/slam/骤缩——画面"被砸"的一拍 |
| snare | 150–500Hz 体 + 1–3kHz 打击面 | 替换/闪切/构图切换——"换一件事"的一拍 |
| hihat | 6–14 kHz | 微动密度——密的段落微动效可密，稀的段落必须收 |

**命中表是候选池，不是触发器**：检测到的每个 kick ≠ 都要配一次画面冲击。强鼓点曲 kick 几乎每拍都有，逐拍执行"被砸"就是画面抖动。kick→冲击映射只用于选出最强 hit（全片 2–3 处），其余 kick 只作为切点和元素级动效的**时机**参照。

**RMS 能量曲线与结构表**：
- 音乐结构表：能量从第几拍起满、breakdown 段在第几拍——分镜能量曲线贴着它排
- 最强 hit 拍号清单：全片 2–3 个最大 slam 必须钉在这些拍上

### 3. 网格验收四指标

| 指标 | 含义 | 门槛 |
|---|---|---|
| match | 网格拍命中真实瞬态的比例 | ≥98% |
| mean_abs_ms | 平均绝对对齐误差 | <10ms |
| drift | 残差对时间线性回归的斜率 | 全曲累计 <5ms |
| 首拍有效性 | 网格第 0 拍是否落在真实音乐攻击上 | 必须 |

### 4. 时间线用拍号写

所有镜头边界/动效关键帧用拍号函数 `beatF(n)` 表达，不用裸帧号。好处：换曲/换段落时改两个常量全片重排；SFX 钉帧表与画面共用同一事实源。

**锚点绑定规则**：
- 密集规则切点（每拍/每两拍一切）→ 用网格的 `beatF(n)`
- 稀疏重音、孤立定格 → **钉真实瞬态**，不用网格插值点
- 视频素材/SFX 按**内部峰值**对齐，不按文件头对齐

### 5. 渲后回测（闭环，必做）

两种误差分开报：
- **音频真值误差**：设计切点秒值 vs 真实瞬态秒值——验分析管线；门槛平均 <5ms
- **视觉量化误差**：秒值换算到最近可渲染帧的取整误差——验帧率；30fps 是 ±16.7ms

**30fps 交付不要声称 <5ms 的视觉精度**；量化误差超容忍时升帧率，不改音频分析。

**系统性同向偏移先查输出音轨偏移**：误差表若呈同向等量偏移，根因是渲染输出链路的音轨偏移（AAC encoder priming，48kHz 典型 ≈1.28f），不是节拍分析错。输出偏移单设常量，不写回源分析值。

## 二、声音设计

### 方法顺序

**画面结构基本锁定 → 先铺 BGM 定能量骨架 → 逐拍钉 SFX。**

1. **BGM 先行**：一条 BGM 全片铺底，音量压在 0.34 左右给 SFX 留 headroom。候选曲必须垫进成片试听——单听曲子无法判断气质。
2. **词汇表按"片种"选，不按"事件"选**：产品宣传片 SFX 词汇 = whoosh(运镜)/impact(落地)/riser(铺垫)/sparkle(光效)/transition(转场)，禁用游戏音包**音色**。
3. **SFX 逐拍钉帧、声明式表集中管理**：`{ from, src, volume }[]` 数组，逐条注释对应画面动作。
4. **拟音优先**：有辨识度的画面动作配专属拟音（打字配键盘声），泛用 swoosh 盖不住。

### BGM 选型判据

- 鼓点强、节奏感强，优先电子底（tech-house 类）；"好听/欢快"不是判据
- 气质基准是"典型的产品宣传视频"——闭眼只听音轨，应像产品发布会预告，不像手机游戏
- 能量曲线能托住全片结构：平稳鼓底适合叠 SFX 层次，旋律太抢会和拟音打架

### 16 类 SFX 词汇表

| 类别 | 装什么 | 什么时候用 |
|---|---|---|
| transition | whoosh/sweep/swoosh/风 | 运镜、场景切换、元素飞入飞走 |
| impact | impact/thud/stomp/bass hit | 落地钉点、重拍、slam |
| riser | 上升铺垫 | 进 finale/大镜头前的能量铺垫 |
| light | sparkle、光效 | 扫光、点亮、余韵闪光 |
| camera | 快门、镜头、变焦 | 拍照感、crash zoom、对焦 |
| ui | 点击、开关、通知、pop | UI 反馈（需逐个试听，禁合成反馈音） |
| text | 打字机、键盘、书写 | 打字揭示、描线 |
| paper | 纸、翻页、印刷 | 翻页转场、撕裂 |
| film | 放映机、胶片、磁带 | 预告片语法 |
| data | glitch、电流、数据 | HUD、流式输出、故障 |
| scifi | 科技、太空、底噪 | 太空运镜、系统底噪 |
| mech | 机械、工业、锁 | 部件组装、锁定、形变 |
| glass | 玻璃、碎裂 | 碎裂转场、硬切冲击 |
| fluid | 墨水、水、流体 | 墨开场、颗粒填充 |
| crowd | 人群、掌声、呼吸 | 合影收尾、发布会感 |
| counter | 计数器、仪表、钟 | 数字滚动、读数 |

### SFX 管理三规则

1. **钉帧方法**：声明式中央注册表，每条注释对应画面动作；长样本靠 Sequence 截断（>5s 的必须显式给 durationInFrames），不剪音频文件。
2. **连发防机枪感三招**：双样本交替 + 音量阶梯递减（如 0.40→0.25）+ 间隔加速贴动画曲线。
3. **音量按素材实测峰值给**：`volume` 是乘法系数不是目标音量——常规 0.2–0.6 的前提是素材峰值贴近 0dB。录得轻的素材（峰值 <-12dB）给到 1.0 仍被 BGM 盖住，首选换素材或预归一化。

### 结尾固定句式

riser（组装段起）→ impact（字标落地，全片音量峰值）→ sparkle（余韵）。

## 三、与主线的差异

| 维度 | 产品宣传片（本支线） | 动漫短剧（主线） |
|---|---|---|
| BGM | 强鼓点电子底，全片卡点 | 按剧情/情绪选，卡点非必须 |
| SFX 词汇 | whoosh/impact/riser/sparkle/transition | 拟音为主（拳风/脚步/武器/法术） |
| 节拍同步 | 精确到帧（误差≤3f） | 粗粒度对齐（情绪点/冲击点） |
| 音量 | BGM 0.34 打底，SFX 0.2–0.6 | 按场景动态混音 |
