# 音效层次设计

## 核心要点
- 单音效几乎不存在——**专业音效全是叠出来的**
- 单个声音的纵向三层：**瞬态(attack)→主体(body)→尾音(decay)**
- 整个声场的横向三层：**前景→中景→背景**
- 频段即领土：低频管重量，中频管实体，高频管细节——各占各的，谁也别抢
- 关联 156 拟音实操、035 预延迟、157 空间透视

## 纵向：一个声音的三层解剖

### 声音三元组(Sound Triad)
```
一记踢门的音效：
  瞬态 = 木尺敲击的脆裂声（短、尖、0.05秒内）
  主体 = 软锤砸门板的闷响（中、厚、0.3秒）
  尾音 = 合页震颤+碎屑落地（长、散、1秒+）
```
- 瞬态=清晰度：决定观众"听没听清这是什么动作"
- 主体=重量感：决定这一脚"有多重"
- 尾音=真实感：决定"这是在什么材质的世界发生的"

### 打拳的三明治（动作戏标配）
```
第一层 攻击层：皮拍/掌击的锐利"啪"   → 负责疼
第二层 质量层：击肉的闷"咚"+超低频  → 负责重
第三层 细节层：指节脆响/皮革摩擦     → 负责真
可选第四层：sub-bass低频轰(30-60Hz) → 负责银幕在震
```
- 只放单层=廉价页游打击感
- 三层时机：瞬态对齐命中帧，主体可拖后1-2帧（035预延迟），尾音自由衰减

## 横向：一个场景的三层景深

```
前景：对白+画面内动作拟音（响、干、全频段）
中景：场景内环境声（中等、轻度混响）
背景：世界底噪（轻、高频滚降、重混响）
```
- 声音景深远比镜头景深便宜——一个特写镜头也能有完整世界
- 观众对"背景声消失"极其敏感：背景底噪突然断=出戏警报

## 频段领土分配表

| 频段 | 住着谁 | 职能 |
|---|---|---|
| 20-120Hz | 爆炸/巨物/sub震感 | 生理冲击，身体感觉到而非听到 |
| 120-500Hz | 闷响/男声基频/重量 | 实体感 |
| 500-4kHz | 对白主体/多数拟音 | 可懂度核心区，最挤的频段 |
| 4k-12kHz | 金属/玻璃/空气声 | 细节与方向感 |
| 12kHz+ | 极高频泛音 | "贵"的感觉，可牺牲 |

- 混音冲突排查顺序：先救对白(500-4kHz)，再管其他
- 音效顶在一起糊了？不是音量问题，是**频段撞车**——错开频段比调音量优雅

## 实战工作流

### 单个动作音效的制作顺序
```
1. 找瞬态素材（脆的、快的）
2. 叠主体素材（闷的、厚的）——对齐瞬态后0-2帧
3. 铺尾音素材（散的、长的）——混响拉长
4. 需要重量→补sub低频
5. 总线：压缩粘合三层→调比例→试听是否"一个声音"
```

### 场景声景的搭建顺序
```
1. 背景底噪先铺（决定场景气质）
2. 中景环境声补位（风扇/远处车流/雨）
3. 前景拟音精确对帧
4. 全程检查：每层能否单独静音不崩塌？
```

## AI时代提示
- AI音效生成（159）单条输出的问题就是**只有一层**——把生成结果当素材层用，别当成品用
- 提示词分层生成："sharp slap transient" / "meaty low thud" / "debris rattle tail" 分开生成再叠
- AI生成的底噪常有循环接缝——用8秒以上素材+交叉淡化藏接缝
- 关联 089 音频工具张力

## 常见坑
- **一层走天下**：单个素材直接上=纸片打击感
- **三层同帧齐发**：没时差=糊成一团，主体层永远略晚于瞬态
- **低频上头**：什么都加sub=全程轰头，低频要留给真正的重击
- **背景断层**：切镜头时底噪跟着切=空间感死亡，底噪走J/L-cut延续（137）
- **动态全满**：每层都很响=没有层次，层次靠**对比**不靠堆量

## 进阶
- **尾音叙事**：爆炸的尾音换成耳鸣声=主角被震懵的主观视角（157主观层）
- **频段叙事**：电话声只留500-4kHz=不用看画面都知道在打电话
- **负空间设计**：高潮前把中频抽空0.5秒，随后的音效自动获得三倍冲击力（155联动）
- **一条底噪走全片**：同一个世界底噪贯穿，不同场景只改中景层=隐性统一感

## 备注
- 纵向三层：瞬态/主体/尾音；横向三层：前景/中景/背景
- 频段是领土，撞车比音量失衡更致命
- AI音效是素材层，不是成品
- 关联：156 拟音、157 空间感、035 预延迟、089 工具、137 音桥
