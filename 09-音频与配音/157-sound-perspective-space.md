# 声音透视

## 核心要点
- 声音有景深：观众靠**响度+频段+混响**三个线索判断声音远近
- 近=响、干(混响少)、高频全；远=轻、闷(高频滚降)、混响多
- 画框是有限资源，**画外空间是无限资源**——声音是画框的扩建工程
- 单镜头AI视频最大的病=世界只有镜头里那一小块；声音透视是最便宜的特效
- 关联 152 横向分层、151 画外音身份、155 缝隙静默

## 距离的三线索配方

```
近景声音（特写台词/面前的脚步）：
  响度大 + 高频完整 + 混响极少 + 瞬态锐利

中景声音（房间另一头）：
  响度中 + 高频略滚降 + 房间混响明显

远景声音（街对面/山下）：
  响度小 + 高频大幅滚降(闷) + 混响长 + 可叠加环境干扰(风/城市底噪)
```
- 高频滚降是"远"的最强信号——空气吃高频，观众的耳朵门儿清
- 混响尾巴长度≈空间大小：大教堂尾巴4秒+，壁橱尾巴几乎没有

## 声场四层模型（从近到远）

```
L1 前景事件层：对白+画面内动作拟音 → 响、干、全频段
L2 场景环境层：房间底噪/风扇/同空间物件声 → 中、轻混响
L3 画外世界层：街道车流/邻居电视/远处雷声 → 轻、闷、重混响
L4 主观抽象层：心跳/耳鸣/记忆闪回的声音 → 打破物理规则
```
- L3是"便宜的世界观"：出租屋里打斗+楼下麻将声+远处警笛=完整城市
- L4是"便宜的内心戏"：不用拍闪回，声音闪回即可（151内部叙事声）

## 画外音的战术价值

### 1. 扩展空间
```
画面：狭小的储藏室。声音：门外走廊的脚步由远及近。
效果：储藏室突然有了"外面"=空间感翻倍
```

### 2. 悬念前置（audio before visual）
```
希区柯克公式：先闻其声，后见其人
画外异响→角色反应特写→切声源揭示
= 一次悬念三次利用（137的L-cut变体）
```

### 3. 省预算叙事
```
拍不起的战争=画外炮火+角色脸上的火光+震动的尘土
拍不起的怪物=画外低吼+逐渐逼近的阴影
```
- 观众脑补的画面永远比你拍得起的大

### 4. 喜剧节奏
```
画面：主角淡定整理领子。画外：连环碰撞惨叫。
冷幽默标配：画面平静+画外灾难=面瘫式反差（疯批风格绝配）
```

## 方位感（立体声/环绕简版）
```
左右声像(pan)：画左传来的声音摆左声道=不用给镜头观众也知道方位
由远及近：响度渐大+高频渐开+混响渐收=逼近的三件套
掠过镜头：pan从左扫到右+多普勒效应(音高先升后降)=飞车/飞剑掠过
```
- AI短剧多为立体声交付——别小看两个声道，pan+距离配方足够画出空间

## 实战：给一个AI特写镜头补世界
```
画面：雨夜，主角面部特写（AI生成，就这一张脸）
L1：主角的呼吸+雨水打在脸上
L2：屋檐滴水+湿衣服摩擦
L3：远处雷声+街道积水车过+极远警笛
L4：（可选）心跳渐强
效果：单镜头变全景深，成本=四条音轨
```

## 常见坑
- **声景随镜头硬切**：特写一切，环境声全变=空间感死亡；L2/L3层走J/L-cut平滑过渡（137）
- **画外音太清楚**：画外对话和画内一样清晰=听觉上它们就在画内——画外音要闷要糊
- **混响穿帮**：山洞里的对话配了干声=观众潜意识觉得"假"，材质级混响是底线
- **世界层缺席**：全程只有对白和BGM=世界是假的，L3底噪是沉浸感的地基
- **逼近不做频段渐变**：只推响度=声音在"放大"而不是"靠近"，高频渐开才是物理正确

## 进阶
- **声像反打**：对话戏中，声音始终来自各自主人公的屏幕方位=闭眼也能跟住谁在说（131轴线的听觉版）
- **透视压缩=主观恐惧**：恐怖片中角色害怕时，远处声音突然变得又近又清楚=听觉过敏的主观化
- **静默的深度**：155的缝隙静默=抽掉L2/L3但留L1=空间塌陷成只剩眼前
- **声音的纵深引导**：动线设计（136）的听觉版——画外声从远到近横穿=引导观众期待入画
