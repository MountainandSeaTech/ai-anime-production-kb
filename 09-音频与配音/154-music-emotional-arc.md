# 配乐情绪曲线

## 核心要点
- 配乐的唯一KPI：**让观众的情绪按你的时间表到达指定位置**
- 标准五段式：铺垫→推进→riser攀升→顶点(爆或空)→释放
- 顶点的两种形态：**爆炸性顶点**(sting/drop)与**真空顶点**(骤静)——后者更贵
- 曲线可以画在单场景内，也可以画在全片——微观宏观同构
- 关联 034 BGM节拍同步、076 叙事张力曲线、153 对位

## 五段式拆解

```
情绪值
  │           ●顶点(爆/空)
  │          ╱ ╲
  │    riser╱   ╲ 释放(回落/余韵)
  │   ╱         
  │  ╱ 推进(动机重复+加密)
  │ ╱
  │─铺垫(动机首次呈示)
  └────────────────────→ 时间
```

### 各段职能
| 段 | 音乐手段 | 观众状态 |
|---|---|---|
| 铺垫 | 主题动机轻声呈示（158） | 无意识接收 |
| 推进 | 动机变奏+配器加厚+和声紧张化 | 模糊不安 |
| riser | 上行滑音/渐强/滤波打开/鼓加密 | 屏息等待 |
| 顶点 | sting重击 / drop低频砸 / 骤静 | 情绪释放/冻结 |
| 释放 | 主题回归/简化独奏/长音衰减 | 回味 |

## 工具库：每个零件叫什么

### 推进期零件
- **ostinato固定音型**：两音符循环（大白鲨E-F）=机械的逼近感，越简单越可怕
- **和声悬置**：拒绝解决的和弦=悬着的心
- **节奏加密**：鼓点从四分→八分→十六分=心跳加速模拟器

### 顶点前零件
- **riser**：上行音高/强度扫频（合成噪音上扫/弦乐滑音/铜管渐强），预告片工业的面包黄油
- **braam**：盗梦空间式铜管轰响，"大事发生"的听觉公章
- **滤波渐开**：音乐从闷到亮=黎明将至的听觉版

### 顶点零件
- **sting**：尖锐短促的齐奏重音，jump scare的官配，也对齐任何反转帧
- **drop**：预告片手法——最强画面同步砸下重低音+鼓点，视听双重锤
- **真空顶点**：riser推到极限→全部抽掉→0.5-2秒死寂→再落点。比任何sting都响（155详解）

### 释放零件
- **主题简化**：大战后用单钢琴弹主题=劫后余生
- **长尾衰减**：混响尾巴留长=让观众慢慢落地，别急着切下场

## 场景级 vs 全片级曲线

### 场景级（30-90秒短剧单场景）
```
0-20%   铺垫：环境音+单乐器动机
20-60%  推进：冲突升级，音乐加厚
60-85%  riser：推向对决
85-95%  顶点：爆或空
95-100% 释放：留尾巴给切场
```

### 全片级（短剧全集）
- 每集的顶点要**递增**：第1集顶点=第3集的推进段起点
- 大结局前需要一次**全局真空**：最深的静默留给最终顶点（076叙事曲线联动）

## AI音乐生成适配

### 提示词写法（按五段式点单）
```
铺垫段："minimal piano motif, sparse, mysterious, 60bpm"
推进段："same motif with strings, building tension, ostinato cello"
riser： "rising orchestral swell, accelerating, crescendo to climax"
顶点：  "sudden orchestral hit, massive braam, abrupt" / "sudden silence"
释放：  "solo piano reprise, gentle, fading out"
```
- 分段生成+剪辑台拼接，别指望AI一次生成完整曲线（159工具链）
- 关键：五段用**同一动机**的不同配器=统一感白送（158）

### 对齐画面
- sting/drop必须对齐剪辑点或动作帧，误差容忍±2帧（035）
- riser的长度=画面推进段的长度——先剪画面再量长度下单生成

## 常见坑
- **平线配乐**：一首BGM从头铺到尾=没有曲线=没有情绪设计
- **顶点通货膨胀**：场场有sting=观众免疫，顶点要省着用
- **riser悬空**：推上去了没有顶点=观众被吊死，要么爆要么空必须给一个
- **释放缺失**：顶点后硬切下一场=情绪坠机，留2-4秒衰减
- **曲线与叙事脱钩**：音乐的顶点必须对齐剧情的顶点（076），音乐自嗨=车祸

## 进阶
- **双顶点结构**：假顶点(小爆)→快速回落→真顶点(真空或大爆)=预期违背，爽感翻倍
- **静默当riser**：反向操作——声音越来越少也是攀升（观众的不安在累积）
- **动机的变调顶点**：顶点不是更响而是**主题动机转大调/转乐器**=升华而非爆炸（158）
- **画外曲线**：顶点时刻切黑屏只留声音=声音独立扛顶点，想象力加成

## 备注
- 五段式：铺垫→推进→riser→顶点(爆/空)→释放
- 真空顶点比爆炸顶点贵，留给最重要的一刻
- AI按段点单，同一动机变配器
