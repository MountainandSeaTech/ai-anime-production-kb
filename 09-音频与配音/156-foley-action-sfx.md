# 拟音与动作音效

## 核心要点
- 拟音(Foley)=人工"演"出来的动作音效——电影里的拳头、脚步、衣料摩擦全是后期配的
- 真相：**真实录到的动作声往往又薄又垮**——好音效是超真实的(hyper-real)，比真实更真实
- 动作音效的可信度=层次叠加(152)+帧级对齐(035)+材质正确
- AI视频生成没有音轨或音轨拉胯——**拟音是AI短剧的后期刚需**，不是可选项
- 关联 152 分层、035 预延迟、128 武器碰撞、126 打戏节奏

## 招牌音效解剖

### 拳头（动作戏的面包）
```
四层结构：
  1. 攻击层：皮拍/掴掌的锐响"啪"（对齐命中帧）
  2. 质量层：击肉闷响"咚"（晚0-2帧，负责重量）
  3. 细节层：指节脆响/皮革挤压（负责"打到真东西"）
  4. 低频层：sub-bass轰(30-60Hz)（负责银幕震感，重击才加）
```
- 轻刺拳：1+3层即可；蓄力重击：四层全上+拉开层间时差
- 打脸vs打腹：打脸瞬态更高频（皮+骨），打腹主体更厚（肉+闷）

### 脚步（被低估的叙事工具）
```
三层：触地(footfall)+拖擦(scuff)+环境尾音(reverb)
```
- 脚步泄露角色状态：犹豫=拖擦长、心虚=轻且碎、追杀=稳且重
- 材质即世界观：木地板的吱呀=老房子，金属走廊=科幻，碎石=野外
- 追逐戏的脚步音量差=距离差（157空间透视）

### 拔刀/武器
```
出鞘声=金属摩擦(长)+护手轻碰(点)+空气切割whoosh(如果挥动)
```
- whoosh制作：藤条/球杆挥录，或AI生成"fast air whoosh"
- 武器的性格在尾音：宝刀=高频泛音长鸣，锈刀=干涩短促（123武器节奏联动）

### 衣料与体音
```
打斗戏最易漏的一层：衣服摩擦+呼吸+闷哼
```
- 没有衣料声的打斗=两个全息投影在打架
- 呼吸声是动作戏的心跳线：憋气→喘息→力竭的呼吸变化=体力叙事

## 帧级对齐规范
```
命中音效对齐命中帧：±0帧（观众对打击同步极敏感）
预备动作音效可提前1-2帧（035预延迟，抬手声先到）
余波音效（碎裂/倒地）可拖后，模拟物理传播
```
- 打击感公式：**对的层次×对的帧=拳拳到肉**；层次对帧错了=棉花拳

## 材质对照表（选素材先问材质）

| 画面材质 | 音效关键词 | 频段倾向 |
|---|---|---|
| 肉体 | meaty, thud, wet | 中低频 |
| 金属 | metallic, ring, clang | 高频泛音 |
| 木头 | knock, crack, splinter | 中频脆 |
| 玻璃 | shatter, tinkle | 极高频 |
| 皮革/衣料 | rustle, creak, flap | 中频噪 |
| 混凝土 | concrete, grit, debris | 宽频粗糙 |

## AI时代的拟音工作流
```
1. 粗剪完成→列出音效清单（按镜号+帧位置）
2. 分层生成（159工具）："sharp slap" / "low body thud" / "knuckle crack" 分开生成
3. 剪辑台叠层+对帧（152流程）
4. 过一遍"裸听测试"：只听声音能否复述动作过程？能=合格
```
- AI生成音效的一次性时长有限（22-90秒）——动作戏按"击打单元"生成而非整段
- 生成不稳定就多次抽卡，和画面抽卡一个心态

## 常见坑
- **真实现场声迷信**：实拍同期声的拳头又闷又小——电影拳头声从来都是假的，别用真录音委屈自己
- **一层裸奔**：单个"punch.wav"直接上=页游打击感（152详述）
- **帧漂移**：音效晚5帧以上=打击感归零，观众说不出但感受得到
- **漏掉体音**：只有打击没有呼吸衣料=打击感再强也是打沙袋
- **音效密度均匀**：每拳都一样响=听觉疲劳，重击要稀、要对比（126节奏联动）
- **whoosh滥用**：每次挥手都呼啸=卡通化，whoosh只给"有速度叙事意义"的动作

## 进阶
- **主观化拟音**：主角被打懵后，拳头声变闷+距离变远=伤害的主观体验（157）
- **材质叙事**：同一把刀，前期声音明亮后期声音暗哑=磨损/堕落的声音弧光
- **静默处刑**：最狠的一拳不给声音（155）——观众的脑补比任何音效都疼
- **风格化夸张**：动漫式打斗可合法超现实——剑气音爆/拳风压缩炮，只要风格统一（113）
