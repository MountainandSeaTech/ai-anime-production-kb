# 音频工具叠加张力（TTS+音效+BGM）

## 核心要点
- **音频占张力 50%**——画面再强没声=干
- 三层叠加：TTS（人声语调）+ 音效（冲击）+ BGM（情绪）
- 静默也是音——突然静=张力顶配（见 033）
- 音画错位=反差张力（见 048 喜剧/049 反转）

## 三层音频的张力分工

### 1. TTS（人声）——语调张力
| 语调 | 张力效果 |
|---|---|
| 气声低语 | 压迫/诡秘/亲密恐惧 |
| 平淡冷读 | 疯批冷幽默（用户偏好） |
| 颤抖破音 | 恐惧/崩溃 |
| 突然拔高 | 爆发/惊吓 |
| 缓慢停顿 | 压迫/深思熟虑 |

- TTS 工具：豆包/魔音工坊/ElevenLabs
- 调语速/音调/停顿=控张力节奏
- 疯批冷幽默=平淡语气念离谱台词=反差张力

### 2. 音效（SFX）——冲击张力
| 音效 | 用途 |
|---|---|
| 低频轰鸣（sub-bass） | 压迫/巨物/危险逼近 |
| 金属锐响 | 冷兵器/利刃出鞘 |
| 心跳鼓点 | 倒计时/紧张 |
| 环境白噪 | 雨/风/电流=氛围 |
| 突然静音 | 冲击前/死亡=张力顶配 |
| 慆嗤/电流声 | 失真/异变/错乱 |

- 音效库：剪映自带/Epidemic Sound/自己录
- 低频轰鸣是压迫感万能钥匙

### 3. BGM——情绪张力
| BGM 类型 | 情绪 |
|---|---|
| 弦乐长音 | 肃杀/悲剧/压迫 |
| 钢琴单音 | 孤寂/余韵 |
| 鼓点加速 | 倒计时/决战 |
| 无 BGM | 静默=最强张力（033） |
| 反差 BGM | 喜剧/反转（048/049） |

- BGM 不是越大越好——静默比轰鸣更高级

## 三层叠加法（关键）

### build 段（建压）
```
BGM：弦乐长音渐强
SFX：低频轰鸣 + 心跳鼓点缓
TTS：气声低语 / 缓慢停顿
= 压迫渐增
```

### peak 段（爆点）
```
BGM：骤停或拔顶
SFX：金属锐响 + 冲击音
TTS：突然拔高 / 破音 / 猛喝
= 爆发
```

### release 段（释放）
```
BGM：钢琴单音 / 渐弱
SFX：环境白噪（风/雨）
TTS：沉默 / 气息
= 余韵
```

## 音画错位张力（进阶）
- 画面惨烈 + BGM 欢快 = 疯批冷幽默（048 喜剧）
- 画面平静 + 音效轰鸣 = 暗示危险（悬疑）
- 画面急促 + BGM 缓慢 = 错位压迫
- 音画错位=反差=张力

## 静默的张力（最强）
- 爆发前**骤停所有音**=0.5-1s 静默=张力顶配（见 033）
- 死亡/牺牲段：去 BGM 只留环境音=肃穆
- 静默比轰鸣更高级——让观众"听"自己的心跳

## 工具推荐
| 层 | 工具 |
|---|---|
| TTS | 豆包/魔音工坊/ElevenLabs |
| 音效 | 剪映自带/Epidemic Sound/自录 |
| BGM | 剪映曲库/Suno AI 生成 |
| 混音 | 剪映/达芬奇（见 090） |

## 常见坑
- **三层全满**：TTS+SFX+BGM 全开=糊=无重点
- **BGM 太响**：盖过人声=听不清=出戏
- **全程有音**：没静默=没呼吸=张力平
- **音画同步**：太同步=呆；适当错位=张力

## 进阶
- 疯批冷幽默：TTS 平淡念离谱台词 + BGM 欢快 + 画面惨烈 = 三重反差
- 用 Suno AI 生成定制 BGM（输入情绪词）
- 低频轰鸣（20-60Hz）是压迫感万能钥匙
- 剪映关键帧调音量=精准控渐强渐弱
