# AI 配音工具与口型同步流程

## 核心要点
- 流程顺序：剧本台词 → TTS 配音 → 视频生成 → 口型同步 → BGM/音效混音
- 口型同步在视频生成「之后」做，不要让视频生成模型脑补口型
- BGM 与音效最后混，配音轨道决定节奏

## TTS 工具选型

| 工具 | 优势 | 劣势 | 适用 |
|---|---|---|---|
| GPT-SoVITS | 音色克隆强，本地部署，0样本/少样本均可 | 需 GPU，部署门槛 | 主力配音 |
| Bert-VITS2 | 中文情感表现好 | 模型生态分散 | 中文角色 |
| Edge TTS | 免费，零部署 | 音色固定，无情感控制 | 早期 Demo |
| 火山 TTS | 中文自然，API 稳定 | 收费 | 商用项目 |

## 音色克隆要点
- 目标音色样本：3-10 分钟干净人声，无 BGM/噪音
- GPT-SoVITS 流程：样本切片 → 训练/微调 → 推理
- 一角色一模型，模型文件命名 `角色名_voice_v01.pth`
- 情感控制：用参考音频驱动情感，不同情绪备不同参考

## 口型同步工具

| 工具 | 模式 | 适用 |
|---|---|---|
| SadTalker | image + 音频 → 说话视频 | 单镜头角色口播 |
| Wav2Lip | 视频 + 音频 → 替换口型 | 已生成视频补口型 |
| MuseTalk | 实时唇形，质量较高 | 高质量补口型 |
| Sync Labs | 视频延长口型 | 长对白场景 |

## 流程顺序（重要）
1. 剧本台词文本定稿
2. TTS 生成配音 wav/mp3，按镜切片命名 `S01-001.wav`
3. 视频生成（不含口型，角色闭嘴或张嘴定格）
4. 口型同步：视频 + 配音 → 输出对口型视频
5. 音效：刀声/脚步/环境音，按镜对齐
6. BGM：整段铺底，关键节拍对齐剪辑点
7. 终混：配音 -3dB，BGM -12dB，音效 -6dB 起调

## 命名与切片
- 配音按镜切片：`audio/配音/S01-001.wav`，镜号对应分镜表
- BGM 整段：`audio/BGM/集号_场景.wav`
- 音效按事件：`audio/SFX/刀出鞘.wav`、`脚步_石板.wav`

## 备注
- 口型同步对侧脸/背身效果差，正面 3/4 角度最佳
- 视频生成时角色嘴部保持闭合或微张，方便后期补口型
- BGM 别让 TTS 配音盖过，混音时配音轨道独占中频

## WAN3.0 校准（2026-10-20）
WAN3 原生音画输出覆盖基础对话+BGM+音效，复杂场景仍需后期精配覆盖高精度定制配音/隐形体音层；原条目中的后期管线工具链（ElevenLabs/Suno/拟音）定位调整为 "WAN3 不满足时的补充管线"
