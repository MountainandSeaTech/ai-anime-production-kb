# ai-anime-production-kb

AI 视频动漫短剧制作知识库 —— 从提示词工程到剪辑合成的全流程实战沉淀，共 **13 大类 483 条目**。

## 简介

本库面向 AI 视频 / 动漫短剧（Wan、可灵等视频生成模型）制作场景，收录经过验证的制作知识：提示词写法、角色一致性方案、张力构建、镜头语言、动作戏编排（含冲击帧/居合等专项拆解）、分镜连贯性、音频配音、剪辑合成规范与踩坑记录。

条目以编号 + 主题命名，按目录分类组织，可直接检索调用。
