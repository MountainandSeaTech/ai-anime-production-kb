# 情感戏分镜动作库（lib_emotion_100）

## 用途说明
本库为 AI 动漫分镜/视频生成提供**可直接落到镜头的物理动作指令**，替代"他很心动""气氛暧昧"这类抽象情绪描述。每条遵循六字段格式，适配 WAN3/H3 铁律：**禁帧级微操、写物理行为不写抽象情绪**。全书共 **10 章 60 条**（E01-E60），覆盖亲密距离、重逢相遇、分别告别、克制爆发、亲密接触、家庭亲情、友情羁绊、悲伤失去、喜悦庆祝、复杂混合情绪等情感场景。

## 第1章 情感戏基础与亲密距离

### E01 情感戏的镜头克制原则
- **原句**：情感戏要用克制的镜头，不要拍得太满。
- **缺口**：只说"克制"没说怎么克，没有可执行的物理动作。
- **扩写动作**：手抬起向对方肩膀→指尖在距肩半厘米处僵住→收回；镜头保持中景不推进。
- **前→后**：手部向肩膀抬起 → 指尖悬停在肩前虚空 → 手收回身侧。
- **提示词**：手指向对方肩膀抬起，指尖悬停在距肩半厘米的虚空处微微发颤，随后手收回身侧，镜头始终保持中景不推进。
- **别写成**："他强忍着内心的激动，眼神中充满了克制的爱意。"（抽象情绪，无物理动作）

### E02 亲密距离的镜头处理
- **原句**：两个人关系越近，镜头越近。
- **缺口**：只给距离对应关系，没有具体镜头调度与物理位移。
- **扩写动作**：50cm 内用过肩近景；120cm 外中景留负空间；距离变化用镜头推拉或人物位移。
- **前→后**：两人隔桌对坐（中景，桌面留大片负空间） → 一方倾身越过桌面（切过肩近景，肩膀占画面边缘）。
- **提示词**：两人隔桌对坐中景，桌面留大片负空间；一方倾身越过桌面，切过肩近景，肩膀占画面边缘。
- **别写成**："他们之间的距离很近，气氛暧昧。"（只有结论，没有物理位移与镜头变化）

### E03 触碰的层级与节奏
- **原句**：触碰要有层次，不能一上来就抱。
- **缺口**：没说层次怎么分、每级之间停顿多久。
- **扩写动作**：指尖轻触 → 手掌覆上 → 手指扣入指缝 → 手臂环住；每级之间留一拍停顿。
- **前→后**：指尖轻点对方手背 → 停顿 → 手掌覆上 → 停顿 → 手指慢慢扣入指缝。
- **提示词**：先用指尖轻触对方手背，停一拍，再将整个手掌覆上，再停一拍，最后手指慢慢扣入对方指缝。
- **别写成**："他轻轻触碰她，心中涌起一阵暖流。"（抽象情绪+无层级节奏）

### E04 眼神的情感传递
- **原句**：眼神要能传递情感。
- **缺口**：没说眼神怎么动——停留、躲闪、直视还是偷瞄。
- **扩写动作**：看一眼 → 移开 → 偷瞄回去 → 被发现时垂下眼帘；或直视不眨、瞳孔放大。
- **前→后**：目光落在对方脸上 → 迅速移向侧方 → 停顿后悄悄转回 → 对方回望时垂下眼帘。
- **提示词**：看对方一眼后迅速移开视线看向侧方，停顿片刻又悄悄转回目光，对方回望时立刻垂下眼帘。
- **别写成**："他的眼神里充满了爱意和羞涩。"（只有情绪标签，没有目光运动轨迹）

### E05 身体朝向与心理距离
- **原句**：身体朝向反映心理距离。
- **缺口**：没说具体哪个部位的朝向、怎么变化。
- **扩写动作**：脚尖朝向对方=有兴趣；身体侧开=回避；肩膀正对=开放接纳。
- **前→后**：身体侧对、脚尖朝外 → 逐渐将脚尖转向对方 → 肩膀也转正正对。
- **提示词**：初始身体侧对对方、脚尖朝外；逐渐将脚尖转向对方，最后肩膀也转正正对。
- **别写成**："他心里其实很在意她，只是不好意思。"（抽象心理，无肢体变化）

### E06 情感张力的物理化
- **原句**：情感张力要用物理动作表现。
- **缺口**：没说哪些物理动作能制造/打破张力。
- **扩写动作**：呼吸从各自平稳到同步同频 → 一方突然屏住打破同步；手指无意识摩挲；喉结滚动。
- **前→后**：两人呼吸各自平稳 → 逐渐同步同频 → 一方突然屏住呼吸打破同步。
- **提示词**：两人呼吸从各自平稳逐渐同步同频，随后一方突然屏住呼吸，打破同步制造张力。
- **别写成**："空气中弥漫着暧昧的张力。"（只有氛围结论，无任何物理行为）

## 第2章 重逢与相遇

### E07 久别重逢的第一眼
- **原句**：久别重逢的第一眼要震撼。
- **缺口**：只说震撼，没说第一眼怎么拍、看哪里、停留多久。
- **扩写动作**：镜头从一方视角摇向人群中的对方→停住→景别从全景推到面部特写；视线锁定不动。
- **前→后**：镜头扫过人群 → 锁定对方 → 从全景慢推到面部特写，视线不动。
- **提示词**：镜头在人群中缓慢摇移，忽然锁定远处一人，从全景慢推到面部特写，视线凝住不动。
- **别写成**："他看到她的那一刻，心中百感交集。"（抽象情绪，无镜头运动与视线物理）

### E08 认出对方的瞬间
- **原句**：认出对方的瞬间要有冲击力。
- **缺口**：没说认出这个动作怎么用身体表现。
- **扩写动作**：脚步顿住→瞳孔放大→嘴唇微张→手中物品滑落或握紧。
- **前→后**：正常行走 → 脚步猛地顿住 → 瞳孔放大、嘴唇微张 → 手中杯子滑落。
- **提示词**：人物正常行走中脚步猛地顿住，瞳孔放大、嘴唇微张，手中握着的杯子从指间滑落。
- **别写成**："他一下子认出了她，震惊不已。"（只有情绪标签，无身体反应）

### E09 拥抱的节奏
- **原句**：重逢的拥抱要有力、有层次。
- **缺口**：没说拥抱的力度变化和节奏点。
- **扩写动作**：先轻搭肩膀试探→收紧双臂贴紧→一方手抚对方后颈→慢慢松开留半步。
- **前→后**：手轻搭对方肩膀 → 双臂收紧将对方贴紧胸口 → 手抚上对方后颈 → 缓缓松开留半步距离。
- **提示词**：先将手轻搭在对方肩膀上，随即双臂收紧把对方贴紧胸口，手抚上对方后颈，最后缓缓松开，两人之间留半步距离。
- **别写成**："他们紧紧相拥，心中充满重逢的喜悦。"（抽象情绪+无节奏层次）

### E10 奔向前方的镜头
- **原句**：奔向前方要有速度感和冲击力。
- **缺口**：没说镜头怎么跟、两人怎么会合。
- **扩写动作**：低角度跟拍一方奔跑→切对方迎面跑来→两人在画面正中相撞→身体因惯性晃动。
- **前→后**：低角度跟拍一方向前奔跑 → 切对方迎面跑来 → 两人在画面正中相撞 → 身体因惯性左右晃动。
- **提示词**：低角度跟拍一方向前奔跑，切对方迎面跑来的镜头，两人在画面正中相撞，身体因惯性左右晃动。
- **别写成**："他们奔向彼此，眼中只有对方。"（抽象，无镜头角度与相撞物理）

### E11 相认前的犹豫
- **原句**：相认前要有犹豫，不能太干脆。
- **缺口**：没说犹豫具体体现在哪些肢体动作上。
- **扩写动作**：脚步放慢→手抬起想叫住又放下→嘴唇开合没出声→侧身假装看别处。
- **前→后**：脚步放慢趋近 → 手抬起想叫住对方又放下 → 嘴唇开合未出声 → 侧身假装看向别处。
- **提示词**：脚步放慢向对方趋近，手抬起想叫住对方又缓缓放下，嘴唇开合却未出声，随即侧身假装看向别处。
- **别写成**："他犹豫着要不要上前相认，内心十分挣扎。"（抽象心理，无肢体犹豫动作）

### E12 重逢后的静默
- **原句**：重逢后要有一段静默，胜过千言万语。
- **缺口**：没说静默时人物做什么、镜头怎么处理。
- **扩写动作**：两人面对面站定→都不开口→呼吸可见→景别从中景渐推到近景→一方先别开眼。
- **前→后**：两人面对面站定都不开口 → 呼吸可见起伏 → 镜头从中景渐推到近景 → 一方先别开视线。
- **提示词**：两人面对面站定都不开口，呼吸的起伏清晰可见，镜头从中景缓慢推到近景，最后一方先别开视线。
- **别写成**："他们相顾无言，千言万语尽在不言中。"（只有氛围结论，无静默期的物理与镜头变化）

## 第3章 分别与告别

### E13 告别的最后一眼
- **原句**：告别的最后一眼要让人记住。
- **缺口**：没说最后一眼具体怎么看、停多久、是否回头。
- **扩写动作**：一方转身走出几步→停住不回头→只侧过半张脸→眼神扫过对方再收回。
- **前→后**：转身走出几步 → 停住不回头 → 侧过半张脸 → 眼神扫过对方再收回。
- **提示词**：一方转身走出几步后停住，没有回头，只侧过半张脸，眼神快速扫过对方后立刻收回。
- **别写成**："他最后看了她一眼，眼中满是不舍。"（抽象情绪，无转头角度与视线轨迹）

### E14 转身离开的镜头
- **原句**：转身离开要有决绝感。
- **缺口**：没说转身的速度、镜头角度、是否回头。
- **扩写动作**：快速转身背对镜头→大步沿画面纵深走远→镜头不动保持全景→背影逐渐变小。
- **前→后**：快速转身背对镜头 → 大步沿画面纵深走远 → 镜头固定不动 → 背影在全景中逐渐变小。
- **提示词**：人物快速转身背对镜头，大步沿画面纵深走远，镜头固定不动，背影在全景中逐渐变小。
- **别写成**："他决然地转身离去，再也没有回头。"（只有情绪结论，无转身速度与镜头固定方式）

### E15 想说没说出口
- **原句**：有话想说但没说出口。
- **缺口**：没说"没说出口"用什么身体动作表现。
- **扩写动作**：嘴唇张开→喉结滚动→手抬起想叫住→又放下→最终只点了一下头。
- **前→后**：嘴唇张开欲言 → 喉结滚动吞咽 → 手抬起想叫住 → 手又放下 → 最终只点了一下头。
- **提示词**：嘴唇微微张开欲言又止，喉结滚动吞咽了一下，手抬起想叫住对方又缓缓放下，最终只朝对方点了一下头。
- **别写成**："他有千言万语却无法说出口，心中十分痛苦。"（抽象心理，无欲言的肢体动作）

### E16 目送远去
- **原句**：目送对方远去。
- **缺口**：没说目送时留下的人做什么、镜头怎么处理。
- **扩写动作**：留下者站在原地不动→目光追随远去背影→身体保持送别姿势→手还半举着没放下。
- **前→后**：留下者站在原地不动 → 目光追随远去的背影 → 身体保持送别姿势 → 半举的手一直没放下。
- **提示词**：留下者站在原地一动不动，目光追随远去的背影，身体保持送别的姿势，半举的手一直没有放下。
- **别写成**："他目送着她远去，心中充满了离别的伤感。"（抽象情绪，无站立不动与手半举的物理细节）

### E17 分别后的空镜
- **原句**：分别后给一个空镜收尾。
- **缺口**：没说空镜拍什么、怎么从人物过渡到空镜。
- **扩写动作**：人物走出画面→镜头不跟随、固定不动→画面只剩空荡的街道/月台→停留数秒。
- **前→后**：人物走出画面边缘 → 镜头固定不跟随 → 画面只剩空荡的街道 → 停留数秒。
- **提示词**：人物走出画面边缘后，镜头固定不跟随，画面只剩空荡的街道或月台，静止停留数秒。
- **别写成**："他走后，只剩下空荡荡的街道，仿佛一切都不曾发生。"（文学化描述，无镜头固定与停留时长）

### E18 强颜欢笑的告别
- **原句**：告别时要强颜欢笑。
- **缺口**：没说强颜欢笑的具体面部与肢体破绽。
- **扩写动作**：嘴角上扬挤出笑→但眼角紧绷没有笑纹→笑着笑着嘴角先垮下来→迅速转身不让对方看见。
- **前→后**：嘴角上扬挤出笑容 → 眼角紧绷没有笑纹 → 笑着笑着嘴角先垮下来 → 迅速转身背对对方。
- **提示词**：嘴角上扬挤出一个笑容，但眼角紧绷没有笑纹，笑着笑着嘴角先垮下来，随即迅速转身背对对方。
- **别写成**："他强颜欢笑，其实心里在流泪。"（抽象情绪，无笑容破绽与转身动作）

## 第4章 克制与爆发

### E19 压抑情绪的身体信号
- **原句**：他在压抑自己的情绪。
- **缺口**：只说"压抑"，没说身体哪些部位在用力、怎么用力。
- **扩写动作**：嘴唇紧抿→指节攥得发白→指尖蜷曲→呼吸刻意放浅→肩膀绷起不下沉。
- **前→后**：嘴唇紧抿成一条线 → 手指攥紧指节发白 → 指尖不自觉蜷曲 → 呼吸刻意放浅 → 肩膀绷起不下沉。
- **提示词**：嘴唇紧抿成一条线，手指攥紧指节发白，指尖不自觉蜷曲，呼吸刻意放浅，肩膀绷起始终不下沉。
- **别写成**："他强忍着内心的悲痛，不让自己哭出来。"（抽象情绪，无身体紧绷的具体部位）

### E20 情绪决堤的瞬间
- **原句**：情绪一下子决堤了。
- **缺口**：没说决堤时身体哪个先失控、怎么从克制到失控。
- **扩写动作**：一直紧抿的嘴唇先抖→下巴开始颤抖→憋住的气从鼻腔漏出→眼泪夺眶而出。
- **前→后**：紧抿的嘴唇先开始抖 → 下巴跟着颤抖 → 憋住的气从鼻腔漏出 → 眼泪夺眶而出。
- **提示词**：一直紧抿的嘴唇先开始抖动，下巴跟着颤抖，憋住的气从鼻腔漏出，随即眼泪夺眶而出。
- **别写成**："他再也忍不住，眼泪决堤般涌了出来。"（只有结论，无失控的身体顺序）

### E21 无声的哭泣
- **原句**：他无声地哭了。
- **缺口**：没说无声哭泣时呼吸、肩膀、脸的具体表现。
- **扩写动作**：没有哭声只有吸气声→肩膀一抽一抽→低着头不让人看见脸→手捂住嘴但捂不住眼泪。
- **前→后**：没有哭声只有断续的吸气声 → 肩膀一抽一抽地耸动 → 低着头不让人看见脸 → 手捂住嘴但眼泪从指缝渗出。
- **提示词**：没有哭声只有断续的吸气声，肩膀一抽一抽地耸动，低着头不让人看见脸，手捂住嘴但眼泪从指缝渗出。
- **别写成**："他默默地流下了眼泪，心中无比悲伤。"（抽象情绪+无呼吸肩膀的物理细节）

### E22 从平静到崩溃
- **原句**：他从平静瞬间崩溃了。
- **缺口**：没说崩溃前的停顿、身体软下来的过程。
- **扩写动作**：听完消息呆坐几秒→身体微微摇晃下坠→双腿发软站不稳→顺着墙滑坐到地上。
- **前→后**：听完消息呆坐几秒不动 → 身体微微摇晃下坠 → 双腿发软站不稳 → 顺着墙慢慢滑坐到地上。
- **提示词**：听完消息后呆坐几秒一动不动，身体开始微微摇晃下坠，双腿发软站不稳，顺着墙慢慢滑坐到地上。
- **别写成**："听到这个消息，他瞬间崩溃了，瘫倒在地。"（只有结果，无呆坐停顿与下滑过程）

### E23 克制后的释放
- **原句**：克制了很久终于释放出来。
- **缺口**：没说释放的触发动作和身体失控的方式。
- **扩写动作**：一直攥紧的拳头突然松开→整个人垮下去→扶着墙干呕/猛捶墙→然后蹲下身埋头。
- **前→后**：一直攥紧的拳头突然松开 → 整个人垮下去 → 扶着墙猛捶一下或干呕 → 随即蹲下身埋头。
- **提示词**：一直攥紧的拳头突然松开，整个人垮下去，扶着墙猛捶一下或干呕一声，随即蹲下身埋头。
- **别写成**："压抑已久的情绪终于爆发，他彻底释放了自己。"（抽象，无拳头松开与捶墙的物理动作）
