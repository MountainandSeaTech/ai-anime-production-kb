# 喜剧反差张力（节奏破坏造笑点）

## 核心要点
- 喜剧的笑点本质是**张力的反差释放**——把严肃蓄势拧到顶，用"不对劲"的释放引爆笑
- 三大手法：节奏破坏（蓄到顶却泄气）、期待违背（该爆却没爆/爆了别的）、反差并置（严肃配荒诞）
- 喜剧张力曲线=蓄势（严肃）→峰（荒诞/泄气）→释（笑点回甘）
- 笑点的力度=蓄势的严肃程度×释放的荒诞程度

## 喜剧张力的原理
- 严肃蓄势让观众"准备好"看某种爆发（揪心建立）
- 用"不对劲"的释放打破预期=反差=笑
- 蓄势越正经、释放越离谱=反差越大=越好笑
- 这就是"面瘫冷幽默"的机制——情绪稳定地执行离谱逻辑（用户偏好）

## 三大手法

### 1. 节奏破坏（蓄到顶却泄气）
- 严肃蓄势到峰值点，该爆却……没爆/爆了弱鸡动作
```
居合蓄势（1.5s，超正经）→ 出刀瞬间……刀掉了（0.3s，泄气）→ 角色呆滞（0.5s，笑点）
```

### 2. 期待违背（爆了别的）
- 蓄势指向 A，释放却是 B
```
主角怒吼蓄力（1s，像要放大招）→ 放了个屁（0.3s）→ 众人石化（0.5s）
```

### 3. 反差并置（严肃配荒诞）
- 严肃氛围里塞荒诞元素，两者并存=笑
```
庄严神殿对峙（1s）→ Boss 是只猫（0.3s）→ 主角愣（0.5s）→ 猫喵（0.3s）
```

## 喜剧张力曲线
```
build-up（严肃蓄势 1-2s，越正经越好）→ peak（荒诞释放 0.3s，反差）→ release（角色反应 0.5-1s，笑点回甘）
```
关键：蓄势必须真正经，不能提前暗示笑——观众要认真"揪心"了，反差才成立。

## 角色反应是笑点放大器
- 释放后接角色的"反应镜"——呆滞/石化/面瘫吐槽=笑点翻倍
- 面瘫式反应最狠（情绪稳定地接受荒诞=用户偏好的疯批冷幽默）
- 反应镜时长 0.5-1s，给观众笑的时间

## 喜剧张力的常见坑
- **蓄势不正经**：提前暗示要搞笑=反差不成立=不好笑
- **释放太长**：荒诞动作拖=解释笑话=不好笑
- **无反应镜**：荒诞后直接切走=没给笑的时间
- **重复滥用**：同一手法用太多次=疲劳=失效
- **节奏太均匀**：每个笑点间隔一样=可预测=不好笑

## 节奏在喜剧里的特殊作用
- 喜剧最吃**停顿**（029）——荒诞前停一下，让观众"准备好"
- 停顿=蓄势=笑点的燃料
- 笑点之间要有"正经段"做缓冲，不能连环笑=疲劳

## 经典喜剧张力场景

### 居合泄气型
```
居合蓄势超正经（1.5s）→ 出刀瞬间刀掉了（0.3s）→ 呆滞面瘫（0.8s）→ 捡刀装没事（0.5s）
```

### 怒吼放屁型
```
怒吼蓄力（1s）→ 放屁（0.3s）→ 众人石化（0.5s）→ 主角面瘫（0.5s）
```

### 严肃猫 Boss
```
庄严神殿（1s）→ 猫Boss（0.3s）→ 主角愣（0.5s）→ 猫喵一爪子拍飞主角（0.3s）→ 主角倒地定格（0.5s）
```

## 声音的喜剧处理
- 蓄势段用正经 BGM/音效（建立严肃）
- 释放段用"不对劲"音效——泄气声/噗/荒诞音=反差
- 静默在笑点前=停顿蓄势；笑点后静默=给笑时间
- 忌笑声音效（罐头笑）=廉价

## AI 提示词
- 严肃蓄势：用正经 prompt（与悲剧/打戏同款）
- 荒诞释放：`slapstick, anticlimax, item dropping, anticlimactic moment`
- 面瘫反应：`deadpan expression, blank stare, motionless, underwhelmed reaction`
- 石化：`frozen in shock, petrified, statue-like stillness`

## 备注
- 喜剧是张力的"反向应用"——蓄势正经+释放荒诞=笑
- 用户偏好疯批冷幽默：情绪稳定地执行离谱逻辑，即"面瘫反应"+荒诞释放
- 笑点力度=蓄势正经度×释放荒诞度，蓄势必须真正经
- 节奏破坏是核心——该爆不爆/爆了别的=反差=笑
