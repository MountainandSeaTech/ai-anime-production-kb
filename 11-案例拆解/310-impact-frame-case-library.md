# 冲击帧经典案例拆解坐标

## 核心要点

学冲击帧最快的方式是**逐帧拉片**——本条目给出六个必拆名场面的坐标与"看什么"

## 详细内容

| 作品/场景 | 类型 | 拆解要点 |
|---|---|---|
| 《盖塔机器人G》#39（1970s） | 起源帧 | 史上首个黑白反色冲击帧——看它如何替代白色频闪 |
| 《EVA》真嗣精神崩溃段 | 情绪帧 | 冲击帧脱离打击场景——抽象反色帧表现精神冲击，"情绪爆点"时机的教科书 |
| 《龙珠Z》悟空vs弗利萨 | 战斗闪 | 高密度的①反色型连闪——注意连闪的节奏递减编排（303） |
| 《一拳超人》认真拳 | 收束帧 | 全季憋一次的稀缺性教科书——整季克制换来的一次爆发 |
| 《咒术回战》黑闪 | 属性帧 | 单彩色闪的极致——黑红配色绑定角色术式，"属性宣言"式冲击帧 |
| 《鬼灭之刃》游郭篇/火之神神乐 | 插画帧 | ④插画型的巅峰——画风突变但全场最贵的一帧，帧本身即是壁纸 |

### 拉片方法
1. 剪辑软件逐帧走（←→键），找到冲击帧，数帧数、记色彩方案、标帧位与接触帧的关系
2. 记录"前后帧→冲击帧→恢复帧"的三段画面内容
3. 问三个问题：这帧几帧长｜用了五型中哪一型｜拿掉它打击感损失多少

## 关键参数 / 模板 / 清单

**学习顺序建议**：盖塔（起源）→龙珠（密度）→EVA（情绪）→一拳（稀缺）→咒术（属性）→鬼灭（插画帧）
