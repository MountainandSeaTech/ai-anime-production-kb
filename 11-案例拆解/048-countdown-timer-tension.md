# 倒计时/限时张力

## 核心要点
- 倒计时是**时间轴（013）的极致运用**——不可逆时间=最强延迟释放
- 三件：不可逆时间（钟/数字/进度）、阶梯加速（频率渐快）、临界抉择（最后一刻做什么）
- 张力曲线是"阶梯型"（014）：每秒都是新峰值，越近临界越揪心
- 倒计时戏的命脉是"可视的时间"——必须有钟/数字/进度让观众读

## 三大张力来源

### 1. 不可逆时间
- 时间在走且不可停=延迟不可逆=揪心最强
- 必须让时间"可视"：倒计时数字、钟摆、进度条、沙漏
- 观众读到时间流逝=预期"临界将至"=持续加压

### 2. 阶梯加速
- 蓄势段节奏渐快（023）：每镜时长递减，配合时间递减
- 数字越小，切换越快=视觉与时间同步加速
- BGM 节拍也渐密（034）

### 3. 临界抉择
- 最后一刻"做什么"=抉择=心理轴加压
- 谁去拆弹？拆哪根线？救谁弃谁？
- 抉择的代价=揪心

## 张力曲线（阶梯型）
```
长蓄（数字大，慢切，2s）→ 中蓄（数字减，中切，1.5s）→ 短蓄（临界近，快切，1s）→ 临界（最后秒，极快切，0.5s）→ 结局（爆/解除，定格，1s）
```
节奏与数字同步递减——数字 10→5→3→1→0，切换也 2s→1.5s→1s→0.5s→定格。

## 可视时间的工具

| 工具 | 用法 | 效果 |
|---|---|---|
| 倒计时数字 | 屏幕角/装置数字递减 | 直观读秒 |
| 钟摆/秒针 | 摆动/跳动特写 | 节奏可视化 |
| 进度条/沙漏 | 渐满/渐空 | 不可逆可视 |
| 炸弹闪烁灯 | 红灯渐快闪 | 临界信号 |
| BGM 滴答 | 钟声/滴答渐密 | 听觉读秒 |

## 经典倒计时张力场景

### 拆弹临界
```
数字 10（全景装置+慢切，2s）→ 5（特写抉择哪根线，1.5s）→ 3（手部特写颤抖，1s）→ 1（屏息静默，0.5s）→ 0 剪线（0.3s）→ 静默定格（1.5s，成败揭晓）
```

### 限时逃亡
```
倒计时 30s（逃跑全景，2s）→ 15s（追兵逼近，1.5s）→ 5s（出口在望，1s）→ 1s（跃出瞬间，0.5s）→ 爆炸/安全定格（1s）
```

### 救援临界
```
坠落中（升格，1s）→ 伸手特写（0.8s）→ 快抓到（0.5s）→ 握住/脱手（0.3s，峰）→ 定格（1.5s）
```
坠落=不可逆时间，救援=抉择。

## 倒计时的常见坑
- **时间不可视**：只说"快没时间了"但没钟/数字=观众无感
- **节奏匀速**：每秒一样切=无加速=无逼近感
- **临界无抉择**：最后只是等爆=无心理轴=弱
- **数字太快**：10→0 一秒=没蓄势=不揪心
- **结局拖**：临界后拖 3s 才揭晓=泄气

## 声音处理
- 滴答/钟声渐密渐响=听觉读秒（034）
- 临界前静默 0.3s（033）=最大揪心
- 结局瞬间重音（爆音或解除音）=释放
- 数字越小音调越高=逼近感

## 备注
- 倒计时是 013 时间轴的极致——不可逆+可视+渐快
- 必须让时间"可见可读"，光说没用
- 阶梯加速=切换频率+数字+音效三者同步递减
- 临界必有抉择=心理轴，否则只是干等
