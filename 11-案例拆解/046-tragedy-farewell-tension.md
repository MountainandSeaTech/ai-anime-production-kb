# 悲剧决别张力构建

## 核心要点
- 悲剧决别与打戏相反：**峰值不"爆"而"凝固"，释放段超长**=心沉式揪心
- 张力曲线是"长尾型"（014）：蓄→凝固峰→超长释，释放占 50%+
- 三件：致命瞬间凝固（定格/极慢）、静默余韵、长拉远孤立
- 悲剧忌"煽情过猛"——BGM 灌满+慢镜滥用=廉价，留白才高级

## 悲剧的张力曲线（长尾型）
```
build-up（不可挽回的逼近 1.5s）→ peak（致命瞬间凝固 1s，不爆）→ release（超长余韵 2.5s，静默+孤立）
```
比例约 3:2:5，释放段最长——让观众消化"不可挽回"。

## 三大张力来源

### 1. 凝固峰值（不爆）
- 致命瞬间用定格/极慢（4x+），不是爆发的闪白
- 凝固=时间停止=不可挽回的视觉化
- 镜头：致命瞬间升格定格+静默

### 2. 静默余韵
- 致命后全静默 1-2s（033）=听觉留白
- 让观众在静默里消化悲伤
- 忌立即灌 BGM——静默比音乐更悲

### 3. 长拉远孤立
- 缓拉远到全景/远景，主体变小变孤=孤立感（020 负空间）
- 拉远=与世界抽离=悲剧的视觉收束
- 镜头：slow pull back 到 wide shot，主体压角

## 悲剧的常见坑
- **峰值爆了**：致命瞬间用闪白爆音=变爽片不是悲剧
- **BGM 灌满**：全程煽情音乐=廉价=观众反感
- **慢镜滥用**：每镜都慢=无对比=失效
- **释放太短**：致命后直接切走=没余韵=不悲
- **过度煽情**：角色大哭大喊=直白=不如克制

## 克制原则（悲剧的高级感）
- **少即是多**：表情克制比大哭更悲（微表情 024）
- **静默 > 音乐**：留白比 BGM 更揪心
- **凝固 > 爆发**：定格比闪白更"沉"
- **孤立 > 渲染**：拉远变小比近景大哭更悲

## 经典悲剧张力场景

### 致命一击的凝固
```
逼近对峙（1.5s）→ 致命瞬间升格4x凝固（1s，静默）→ 主体倒下极慢（1s）→ 长拉远全景孤立（2s，静默）→ 定格（1s）
```

### 决别对白
```
最后对白近景（1s）→ 一方渐弱闭眼特写（0.5s）→ 静默定格（1.5s）→ 拉远另一方独留（2s）→ 定格远景（1s）
```

### 牺牲瞬间
```
决意出手近景（0.8s）→ 自爆/挡击凝固（0.8s，升格）→ 静默（1s）→ 残存者反应特写（0.5s）→ 拉远孤立全景（2s）
```

## 声音的悲剧处理
- 致命瞬间：静默（不是爆音）
- 余韵段：极简低频/单音/或全静默
- 忌：满配煽情弦乐——留一两个长音足矣
- 环境声渐入（风/雨）=与世界继续的对比=悲剧感

## AI 提示词
- 凝固：`4x slow motion, fatal moment, freeze frame, silent, still`
- 倒下：`very slow motion, character falling, dramatic, sad`
- 孤立拉远：`slow pull back to wide shot, character alone, small in vast environment, negative space, isolation`
- 克制表情：`restrained expression, subtle sadness, eyes closing, micro emotion`

## 备注
- 悲剧是 014 长尾型曲线的典型，与打戏（尖峰型）相反
- 核心：峰值凝固不爆+释放超长+静默孤立
- 悲剧在 AI 视频里适合（慢镜+定格+拉远都稳），是高回报类型
- 忌煽情——克制即高级，留白比渲染更悲
