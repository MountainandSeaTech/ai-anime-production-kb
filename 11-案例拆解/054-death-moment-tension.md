# 死亡瞬间张力处理

## 核心要点
- 死亡瞬间是"不可逆"的视觉化——必须让观众凝视"再也回不来了"
- 处理=凝固（不爆）+静默+不可逆确认（倒下/闭眼/松手）
- 与悲剧决别（046）部分重叠，但本条聚焦"瞬间处理"本身
- 死亡忌"爆"——爆了=爽片不是悲；沉了=揪心

## 死亡瞬间的四段

### 1. 致命瞬间凝固
- 致命一击/中招瞬间升格 4x+定格=时间停=不可逆信号
- 不用闪白爆音，用凝固+静默
- 镜头：致命瞬间升格大特写

### 2. 静默确认
- 致命后全静默 0.5-1s（033）=让"死了"被消化
- 这段是死亡戏的命脉——观众在静默里接受"不可逆"

### 3. 不可逆确认
- 一个"确认死了"的细节——闭眼、松手、倒下、瞳孔散
- 确认细节让观众无悬念=悲释放
- 镜头：确认细节特写

### 4. 余韵定格
- 死后定格/拉远=与世界抽离（046 长释）
- 留白让观众悲伤回甘

## 张力曲线
```
致命逼近（1s）→ 致命瞬间升格凝固（0.5s，静默）→ 静默确认（0.8s）→ 不可逆细节特写（0.5s，闭眼/松手）→ 长拉远定格（2s，余韵）
```

## 死亡处理的常见坑
- **爆了**：闪白+爆音=爽片不是悲
- **无静默**：致命后立即音乐=没消化=不悲
- **无确认细节**：死了但没"确认"=观众不确定=悬空
- **无余韵**：死后直接切=没回甘=浪费
- **过度渲染**：慢镜+煽情音乐满=廉价

## 不同死亡的处理差异

| 死亡类型 | 处理 | 核心 |
|---|---|---|
| 战死 | 凝固+静默+倒下 | 重量感 |
| 牺牲 | 凝固+微笑+拉远 | 崇高 |
| 被背刺 | 凝固+回头反应（053） | 信任崩塌 |
| 衰老/病 | 缓慢闭眼+松手 | 平静不可逆 |
| 突然死亡 | 骤切+静默+确认 | 错愕 |

## 经典死亡张力场景

### 战死凝固
```
致命一击逼近（1s）→ 中招升格凝固（0.5s，静默）→ 静默（0.8s）→ 松手武器特写（0.5s）→ 倒下极慢（1s）→ 拉远定格（1.5s）
```

### 牺牲微笑
```
决意出手（0.8s）→ 自爆/挡击升格凝固（0.5s，静默）→ 微笑闭眼特写（0.5s）→ 静默（0.8s）→ 拉远孤立（2s）
```

### 突然死亡（错愕型）
```
正常对白（1s）→ 骤切+静默（0.3s）→ 倒地确认（0.5s）→ 残存者愣（0.8s）→ 定格（1s）
```
突然死亡用"骤切"制造错愕，比慢镜更狠。

## 声音处理
- 致命瞬间静默（不爆音）
- 静默确认段全无声
- 确认细节配极轻音（松手的轻响）
- 余韵段极简低频或全静默
- 忌：满配煽情音乐

## AI 提示词
- 凝固：`4x slow motion, fatal moment, freeze frame, silent, still, dramatic`
- 确认细节：`extreme close-up, eyes closing, hand releasing weapon, final moment`
- 倒下：`very slow motion, falling, dramatic, silent`
- 拉远余韵：`slow pull back to wide, body alone, still, vast negative space`
