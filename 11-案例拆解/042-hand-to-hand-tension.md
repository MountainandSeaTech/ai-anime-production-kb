# 徒手格斗张力构建

## 核心要点
- 徒手格斗比冷兵器更难拍张力——没有"刀鞘延迟"这个天然前摇，要靠**重量感**补
- 核心三件：接触瞬间凝固（impact frame）、近身缠斗的呼吸、一击定格余韵
- 徒手戏最大坑：打得太快太碎=看不出重量=像舞蹈不像打
- 镜头：近景缠斗+接触瞬间升格/定格+重量音效

## 徒手戏的张力来源

### 1. 重量感（最关键）
- 拳/脚接触瞬间必须有"重量"——升格凝固+冲击帧+重低音
- 没重量=像挠痒，观众无代入
- 手法：接触瞬间 0.1s 升格定格+形变夸张+爆低音

### 2. 近身缠斗的呼吸
- 缠斗（锁/抓/扭）时双方呼吸可听=持续紧张
- 缠斗是徒手戏的"蓄势段"，比挥拳更揪心
- 镜头：近景双方贴身+呼吸声渐强

### 3. 一击定格
- 重击后保持姿势定格=重量余韵（029 停顿）
- 比连击更狠——一击一停=每拳都有分量

## 徒手戏的张力骨架（5s）
```
缠斗近景贴身+呼吸（1.5s，蓄）→ 拉开一瞬蓄拳（0.5s，前摇）→ 接触瞬间升格凝固（0.2s，峰）→ 形变+重低音（0.3s）→ 定格余韵（1s）
```

## 接触瞬间的处理（核心技法）
接触那 0.1-0.3s 是徒手戏的命脉，必须强化：
- **升格**：接触瞬间 2-4x 慢镜，让"打中"可凝视
- **冲击帧**：单张高细节图替换动画瞬间（见 060 冲击帧）
- **形变**：受击部位瞬间夸张形变（脸被压扁/拳陷进肉）=重量视觉化
- **重低音+静默前置**：接触前一瞬静默→接触爆重低音（035 音效前置/延迟）
- **定格**：接触后保持姿势 0.5-1s=余韵

## 徒手戏 vs 兵器戏的差异

| 维度 | 兵器戏 | 徒手戏 |
|---|---|---|
| 天然前摇 | 刀鞘延迟 | 需靠蓄拳补 |
| 接触处理 | 干净几何线 | 形变+重量 |
| 蓄势段 | 待机站姿 | 缠斗呼吸 |
| 峰值强调 | 出刀瞬间 | 接触凝固 |
| AI 稳定性 | 较高（兵器延伸） | 较低（肉接触易崩） |

## 徒手戏的常见坑
- 全程快打：每镜 0.2s 连击=看不出重量=像舞蹈
- 接触无强化：打中瞬间没升格/形变=轻飘飘
- 无缠斗蓄势：直接挥拳=没前摇=不揪心
- 形变过度：脸打变形不恢复=滑稽=出戏

## 经典徒手张力场景

### 一拳决胜
```
缠斗近景（1.5s）→ 拉开蓄拳特写手握紧（0.5s）→ 冲拳+接触升格凝固（0.3s）→ 受击形变+重低音（0.3s）→ 定格出拳姿势（1s）
```

### 锁技窒息
```
贴身缠斗近景（1.5s，呼吸渐弱）→ 锁定姿势特写（0.8s，窒息蓄势）→ 锁紧瞬间+受锁者挣扎（0.5s）→ 定格（1s）
```
锁技=持续加压型，靠"窒息渐弱"做时间轴。

## AI 提示词
- 缠斗：`close-quarters grapple, two bodies pressed, heavy breathing, close-up, static`
- 蓄拳：`close-up, fist clenching, muscles tensed, winding up punch, slow motion`
- 接触：`2x slow motion, punch connecting, impact frame, facial distortion, freeze frame`
- 重量：`heavy impact, motion blur on fist, deformation on contact`

## 备注
- 徒手戏在 AI 视频里最易崩（肉接触/形变），建议：接触瞬间用定格帧+形变图拼接，而非完整生成
- 重量感是徒手戏命脉——没有冲击帧+形变+重低音=没有张力
- 锁技/窒息类比挥拳类更适合 AI（动作慢、接触持续），优先选
