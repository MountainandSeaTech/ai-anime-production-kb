# 对峙对白张力构建

## 核心要点
- 对峙对白的张力**不在台词，在沉默和视线**——言语是表层，停顿才是刀
- 骨架：正反打凝视（027）→停顿欲言（029）→信息差揭露（011）→决意出手
- 三轴齐拧：时间（停顿延迟）+空间（近景极近距离）+心理（信息差/代价）
- 对白戏最忌话痨——台词越少，停顿越多，张力越强

## 张力曲线映射（014）
```
Build-up（0-4.5s）：凝视→开口→停顿→识破，蓄势 4.5/7≈64%
Peak（4.5-5.5s）：视线回避→直视→决意，1s
Release（5.5-7s）：出手定格拉远，1.5s
```

## 张力的真正来源（不是台词）

### 1. 视线正反打（027）
- 001-002 双方凝视对接=对峙成立
- 005-006 A 识破/ B 回避转直视=关系裂痕=转折
- 对白戏的"交锋"是视线交锋，不是言语

### 2. 停顿欲言（029）
- 004 B 张口→闭嘴停顿 0.8s=话将说未说=心理加压
- 停顿=延迟释放（011）的对白版
- 台词越短，停顿越多，张力越强

### 3. 信息差（011/013）
- A 揭露秘密/B 隐瞒=心理轴加压
- 005 A 眼神收紧=识破=信息差反转
- 观众知不知道决定揪心程度

### 4. 静默（033）
- 004/006 静默段=听觉留白=揪心顶点
- 对白戏的静默比台词有力

## 三轴检查（013）
- 时间轴：停顿 0.8s+静默=延迟到位
- 空间轴：近景→特写→大特写逐级收紧
- 心理轴：信息差（识破）+代价（出手）双拧

## 对白戏的反例（杀张力）
- **台词太满**：两人不停说话=没停顿=没延迟=平
- **无视线戏**：只拍说话不拍凝视=失去对峙载体
- **无停顿**：每句紧接=没蓄势
- **无信息差**：全透明=无悬念

## 对白量的黄金比
- 台词时长 : 停顿+凝视时长 ≈ 3 : 7
- 7s 戏里台词≤2s，其余是凝视/停顿/静默
- 台词越精炼越狠——一句"你知道"比十句话揪心

## 可复用结论
- 对白戏=凝视戏+停顿戏，台词是配角
- 正反打 3-5 来回是对峙蓄势标准量
- 每句台词后接停顿=延迟=揪心
- 信息差揭露用"眼神收紧"特写做信号
- 静默段比台词段更揪心，别怕没声
