# 冷兵器对战张力（剑/双刀/枪）

## 核心要点
- 冷兵器对战张力来自**步法可读+交锋节奏化+一击几何线**，不是连斩乱砍
- 鬼灭式调度：长镜读站姿/呼吸→爆发瞬间快切→斩击用干净几何线，情绪收在斩后
- 三种武器各有张力节奏：单刀=居合爆发型，双刀=节奏打击型，长枪=距离控制型
- 兵器戏切忌"全程连斩"——连斩=匀速=无张力（015）

## 三种冷兵器的张力节奏

### 单刀/剑（居合爆发型）
- 张力在"鞘中→出鞘"的延迟，爆发仅 0.3s
- 详 037 居合斩杀全流程
- 镜头：static 长蓄+大特写手/眼+快切出刀

### 双刀（节奏打击型）
- 鬼灭善逸/伊之助式：把战斗变成节奏，每一斩是"打击点"
- 张力在节奏的**骤停与加速**——连斩中突然停一拍再爆
- 镜头：tracking 跟随+节奏剪辑（每斩踩一拍）
```
连斩快切（每镜0.3s，跟节奏）→ 蓄势骤停一拍（0.8s，静默）→ 重斩爆发（0.3s）→ 定格
```

### 长枪（距离控制型）
- 张力在"距离"，枪的威胁半径=安全区临界
- 刺=瞬间缩短，回枪=拉开喘息
- 镜头：全景深景深拍双方距离+特写枪尖
```
远全景对峙（1s）→ 枪尖特写逼近（0.5s）→ 刺击瞬间（0.3s）→ 拉开喘息（0.5s）→ 再逼近
```

## 鬼灭式调度的可复用要点（网上学习）
- **镜头尊重步法**：长镜停留足够久让观众读"站姿变化/呼吸节奏"，再在爆发时快切
- **干净几何线**：斩击瞬间用清晰几何（直线/对角线），不堆特效，情绪留给斩后
- **动作带诗意**：一斩的停顿、一跃的犹豫、一格挡的颤抖——动作里藏角色心理
- **动+静反差**：连斩 barrage 后接一个"屏息定格"做峰值

## 冷兵器戏的张力骨架（通用 5s）
```
步法读站姿长镜（1.5s，蓄）→ 兵器/手部特写（0.5s，前摇）→ 呼吸/眼神特写（0.3s，决意）→ 交锋快切（0.3s×2，峰）→ 定格几何线收（1s，释）
```

## 冷兵器戏的常见坑
- 全程连斩：每镜 0.3s 切到底=匀速轰炸=疲劳无张力
- 步法不可读：太快看不清站姿变化=观众读不出"将动"
- 特效堆满：斩击全是光效=几何线被吃=没重量
- 无停顿：连斩里没有骤停=无峰值点

## AI 提示词
- 单刀：`iaido sword fight, static stance then sudden draw, clean slash line, extreme close-up on hilt`
- 双刀：`dual blade rhythmic combat, tracking shot, percussive strikes, sudden pause`
- 长枪：`spear fight, distance control, deep focus wide shot, spear tip close-up`
