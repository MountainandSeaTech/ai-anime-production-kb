# 围困/包围张力

## 核心要点
- 围困张力是**空间轴（013）的极致压缩**——出路逐个被封，逼仄到无路可逃
- 三件：包围闭合（威胁从四面合拢）、出路封堵（每个逃路被掐灭）、逼仄收窄（活动空间越来越小）
- 与追逐（039 单向距离）不同：围困是**多向合围**，四面八方都有威胁
- 镜头：鸟瞰围困全景+主体被压中心+出路被封特写

## 三大张力来源

### 1. 包围闭合
- 威胁从四面合拢，包围圈渐小
- 每个方向的威胁都可见=无处可逃
- 镜头：鸟瞰/俯视全景看包围圈+主体在中心缩

### 2. 出路封堵
- 主角尝试逃某方向→该路被掐灭（追兵/墙/陷阱）
- 出路逐个被封=希望逐个破灭=揪心递增
- 镜头：尝试方向→被封的特写反应

### 3. 逼仄收窄
- 活动空间物理收窄（墙合拢/人群逼近/空间塌缩）
- 空间越小=压迫越强（020 负空间的反向：被填满的压迫）
- 镜头：空间收窄全景+主体被挤压特写

## 围困 vs 追逐

| 维度 | 追逐（039） | 围困 |
|---|---|---|
| 威胁方向 | 单向（后方追） | 多向（四面合围） |
| 距离变化 | 反复拉锯 | 持续收窄 |
| 出路 | 有逃路 | 出路被封 |
| 空间 | 纵深长廊 | 闭合圆/逼仄角 |
| 心理 | 逃的焦虑 | 无路的绝望 |

## 张力曲线（阶梯收窄型）
```
被发现/包围形成（1.5s）→ 尝试逃方向A被封（1s）→ 转向B被封（1s）→ 闭合圈收窄（0.8s）→ 临界无路（0.5s）→ 抉择/爆发定格（1s）
```
每次"出路被封"是一个小峰值，逐步累积到无路临界。

## 经典围困张力场景

### 群敌合围
```
鸟瞰主角被围中心（1.5s）→ 尝试突围方向被挡特写（0.8s）→ 转向另一方向也被挡（0.8s）→ 合围收紧全景（0.5s）→ 主角拔刀决意特写（0.3s）→ 爆发突围（0.5s）→ 定格（1s）
```

### 陷阱合拢
```
主角察觉地形（1s）→ 墙开始合拢特写（0.8s）→ 找出口被封（0.8s）→ 空间急速收窄（0.5s）→ 临界挤过/被夹（0.3s）→ 定格（1s）
```

### 被包围的对峙
```
主角居中，敌人四面（1.5s，鸟瞰）→ 敌人缓步逼近收圈（1s）→ 主角视线扫各方向（0.5s，无路）→ 决意特写（0.3s）→ 出手横扫（0.5s）→ 定格（1s）
```

## 围困的常见坑
- **只拍主角不拍包围**：观众看不到合围=无压迫
- **出路没被封**：直接突围成功=无围困感
- **空间不收窄**：一直一样大=无逼仄
- **无抉择瞬间**：干等被围=无心理峰
- **鸟瞰滥用**：每镜都鸟瞰=无主体细节=远

## 声音处理
- 多方向脚步声=合围听觉（从四面来）
- 空间收窄配环境音渐闷（墙合拢的闷响）
- 临界静默（033）=无路瞬间的凝固
- 爆发突围配重音=释放

## 备注
- 围困是 013 空间轴极致——多向合围+出路封堵+逼仄收窄
- 鸟瞰/俯视是围困戏的核心机位（看包围圈），但要穿插主体特写
- AI 视频多角色合围易崩，建议：鸟瞰用静态构图（背景人不动）+主体动
- 围困的揪心在"出路逐个被封"——每次封堵是小峰值
