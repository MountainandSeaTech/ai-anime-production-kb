# 单挑群战张力

## 核心要点
- 一对多群战的张力在**错峰进攻+逐个击破的节奏**，不是全员齐上
- 最大坑：所有人一起冲=糊一团=看不清=无张力（031 群戏同理）
- 三件：错峰进攻（敌人分批上）、分层动（主角应对有重点）、逐个击破节奏（每个倒下是小峰）
- 镜头：鸟瞰看群势+主角特写应对+击破瞬间快切

## 三大张力来源

### 1. 错峰进攻
- 敌人分批/分方向上，不是齐冲
- 错峰=不可预测下一波从哪来=持续悬念
- 每波进攻是一个小蓄势-峰-释

### 2. 分层动（031 群戏法则）
- 主角应对有重点：当前主要威胁做大动作，其他敌人待机/微动
- 全员一起动=糊；分层=焦点清晰
- 主角视线/身体朝向标示"当前主要威胁"

### 3. 逐个击破节奏
- 每个敌人倒下是一个小峰值，形成"击破节奏"
- 节奏型：蓄（敌人冲）→峰（击破）→短释→下一波蓄
- 击破数累积=主角压力可视化（还剩几个）

## 张力曲线（多峰连环型）
```
第一波冲（蓄0.8s）→ 击破1（峰0.3s）→ 短喘（释0.3s）→ 第二波（蓄0.8s）→ 击破2（峰0.3s）→ ...→ 最后强敌（长蓄1.5s）→ 终极击破（大峰0.5s）→ 定格（1s）
```
多峰连环，最后留一个强敌做大峰值。

## 经典单挑群战场景

### 错峰围攻
```
鸟瞰主角居中敌人四散（1s）→ A 方向敌人冲（蓄0.8s）→ 主角应对击破A（峰0.3s）→ B 方向冲（蓄0.8s）→ 击破B（峰0.3s）→ C/D 同时冲（蓄0.5s，升级）→ 双击破（峰0.4s）→ 定格（1s）
```
从单方向→多方向升级=压力递增。

### 逐个斩落
```
群敌逼近全景（1s）→ 第一人冲主角一斩（0.3s）→ 第二人冲一斩（0.3s）→ 节奏渐快连斩（0.2s×3）→ 留最后强敌（1.5s蓄）→ 终极一击（0.5s）→ 收刀定格（1s）
```

### 被围绝地反击
```
被围无路（1s，049）→ 决意特写（0.3s）→ 横扫击破数人（0.5s，升格）→ 残存者惊退（0.5s）→ 定格（1s）
```

## 单挑群战的常见坑
- **全员齐冲**：糊一团=看不清=无焦点
- **无错峰**：同时上同时被打=无节奏=平
- **无击破节奏**：连斩无停顿=匀速轰炸=疲劳
- **无最后强敌**：全打完没有升级=无大峰=平收
- **主角无敌**：毫无压力=代价为零=不揪心（011）

## 让主角"有压力"的技巧
- 群战里主角必须受伤/被逼/耗力=代价可见=揪心
- 给主角一个"差点失手"瞬间=不确定性（011）
- 击破节奏里穿插主角喘息/伤势特写=压力可视化
- 忌主角全程轻松碾压=无张力

## 声音处理
- 错峰进攻用多方向脚步/喊声=合围听觉
- 每次击破配重音=节奏点
- 主角喘息渐重=耗力可视化
- 最后强敌前静默=大峰蓄势（033）

## AI 提示词
- 鸟瞰群势：`top-down, one character vs many enemies surrounding, layered, others waiting`
- 错峰冲：`one enemy charging while others hold back, staggered attack,分层`
- 击破：`2x slow motion, slash connecting, enemy falling, impact frame`
- 强敌：`final stronger enemy steps forward, boss reveal, tension peak`

## 备注
- 单挑群战是 031 群戏法则的"战斗版"——错峰+分层+击破节奏
- AI 视频多角色战斗极易崩，核心策略：鸟瞰静态（敌人待机）+主角动+击破瞬间单独生成拼接
- 主角必须有压力（伤/耗/差点失手），否则代价为零无张力
- 最后留一个强敌做大峰值=多峰曲线的收束
