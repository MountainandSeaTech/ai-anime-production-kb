# 觉醒/暴走变身张力

## 核心要点
- 变身/觉醒张力来自**被压抑到极限后的能量破体**——前段越被压，爆发越揪心
- 三件：压抑到临界（前段被虐/憋）、能量破体（视觉爆发）、失控边缘（是力量还是失控？）
- 变身是 014 尖峰型曲线的极致——超长蓄势+超短峰值
- 镜头：被压近景→能量聚集大特写→破体升格闪白→变身定格

## 三大张力来源

### 1. 压抑到临界
- 前段主角被虐/被逼/被逼到绝境=能量被压到临界
- 压抑越深=爆发燃料越多
- 镜头：被打倒/濒败近景+眼神从绝望到转变

### 2. 能量破体
- 能量从体内破出的视觉化——气流/光/裂纹/发飘
- 破体=压抑释放的瞬间=峰值
- 镜头：能量破体升格+闪白+形变

### 3. 失控边缘
- 变身后是"掌控"还是"失控"？=不确定性（011）
- 失控的可能=揪心延续到变身后
- 镜头：变身后面部失智/狂态特写

## 张力曲线（超长蓄势尖峰型）
```
被压濒败（1.5s，压抑）→ 眼神转变特写（0.5s，临界）→ 能量聚集破体升格（0.5s，峰）→ 闪白变身（0.2s）→ 变身定格失智特写（0.8s）→ 反击（0.5s）→ 定格（1s）
```
蓄势超长（2s），峰值短（0.7s），释放中等。

## 变身的常见坑
- **无压抑直接变**：没燃料=爆发无力
- **能量堆特效**：全光效=看不清=信息过载
- **变身即掌控**：变身后完全冷静=无失控悬念=揪心断
- **变身太频**：每集都变=廉价=失效
- **无失智特写**：变身后不拍面部=失去"是人是兽"的悬念

## 高级变身的处理
- **能量用环境反应**间接表现（风/碎石/光晕）比直接画能量稳（043 同款）
- **变身后面部失智特写**=是力量还是失控的视觉悬念
- **闪白破体**（036）=能量极值视觉化
- **静默峰值前**（033）=破体前一瞬全静默=听觉延迟

## 经典变身张力场景

### 暴走觉醒
```
被打倒濒败（1.5s）→ 眼神从绝望转空特写（0.5s，临界）→ 能量破体升格+闪白（0.5s）→ 变身失智面部特写（0.8s，眼无神）→ 暴起反击（0.5s）→ 定格（1s）
```

### 解锁形态
```
绝境中回忆闪回（1s，压抑）→ 能量聚集大特写（0.5s）→ 破体升格（0.5s）→ 新形态定格（0.8s）→ 反击（0.5s）→ 收势定格（1s）
```

## 变身 vs 超能力对轰（043）

| 维度 | 变身 | 超能力对轰 |
|---|---|---|
| 来源 | 内在压抑破体 | 外在能量对冲 |
| 峰值 | 破体瞬间 | 对冲僵持 |
| 悬念 | 失控 vs 掌控 | 谁压过谁 |
| 前段 | 被虐濒败 | 双方蓄能 |

## 声音处理
- 压抑段：低频渐强+被打音
- 临界段：静默 0.3s（破体前）
- 破体峰：重拍+破体音+闪白
- 变身后：失智的低吼/空灵音=是人是兽
- 反击：重音释放

## 备注
- 变身是 043 超能力的"内在版"——压抑破体而非外在对轰
- 命脉：前段压抑越深+破体瞬间+失智悬念
- 能量用环境反应间接表现比直接画稳
- 变身后必须有"失智特写"=是人是兽的悬念=揪心延续
