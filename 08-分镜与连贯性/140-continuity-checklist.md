# 分镜连贯性自检清单

## 核心要点
- 连贯性不是靠感觉——是靠**逐条打勾**
- 两轮检查：**分镜表阶段**（文字可查）+ **素材生成后**（画面必查）
- 每条不通过=明确修法（本清单每条附修法）
- 关联 131-139 全部连贯性条目

## 第一轮：分镜表阶段（文字预检）

### A. 空间连续性（131）
```
□ 轴线定了吗？每场戏标出轴线方向
□ 角色屏幕方向逐镜一致？（A恒在左朝右）
□ 有越轴吗？越轴用了4种合法手段之一吗？
□ 追逐/移动戏的运动方向逐镜一致？
```

### B. 动作连续性（132/138）
```
□ 跨镜动作标注了相位？（起手/峰值/收势）
□ 接力镜头标注了首尾帧方案？
□ 每个镜头的"入口状态/出口状态"填了吗？
□ 角色状态（伤情/服装/手持物）逐镜核对？
```

### C. 视线连续性（133）
```
□ 正反打双方视线方向相反？（左视vs右视）
□ 视线高低差符合身高/权力设定？
□ 每个"看"之后有没有给"被看物"？
```

### D. 叙事因果（135）
```
□ 每场戏写了入口/出口因果？
□ 场景间连接词是"因此/但是"还是"然后"？（然后=重写）
□ 上场结尾的钩子，下场接住了吗？
□ 角色每个行动有前置动机？
```

### E. 时间连续（139）
```
□ 时间跳跃处标注了信号物？
□ 信号物写进了AI提示词？
□ 大时间跳跃有仪式感段落？
```

### F. 动线设计（136）
```
□ 每镜标注动线入/出方向？
□ 相邻镜头动线咬合或有意断裂？
□ 关键爆点镜的动线汇聚了吗？
```

### G. 声音设计（137）
```
□ 场景转换处标了J-cut/L-cut？
□ 对话戏标了"看听者"的反应镜头？
□ 静默段落是有意设计的？
```

## 第二轮：素材生成后（画面复查）

### H. 画面级检查
```
□ 相邻镜头角色服装/发型/道具一致？
□ 光线方向一致？（阳光不会从左突然变右）
□ 天气/时间状态一致？（雨的密度/天色）
□ 色调温度渐变合理？（突变需有意）
```

### I. 剪辑级检查
```
□ 静止切静止的硬切有几个？（能改动作切就改）
□ 每个切点问：这里切观众的眼睛去哪？
□ 接力处动作相位对齐？（逐帧检查）
□ 音画同起同落的镜头占比？（>80%=加J/L-cut）
```

### J. 叙事级检查（拉片自检）
```
□ 闭眼只听声音能跟上剧情吗？（听觉线独立成立）
□ 只看画面静音能跟上剧情吗？（视觉线独立成立）
□ 每30秒问一次：观众此刻知道"谁在哪要什么"吗？
□ 结尾回收了开头埋的钩子吗？（078）
```

## 问题→修法速查表

| 症状 | 病灶 | 修法 |
|---|---|---|
| 两人像对空气说话 | 133视线错位 | 重生成，写frame left/right |
| 球会拐弯 | 131方向突变 | 统一屏幕方向词 |
| 动作闪帧 | 132相位错位 | 首尾帧接力重做 |
| 伤口消失 | 138状态丢失 | 文本锚补状态词 |
| 突然换场景 | 135因果断裂 | 补承接转场/物件接力 |
| 不知过了多久 | 139信号物缺失 | 补光影/物件信号 |
| 看着累说不出为啥 | 136动线乱 | 兴趣点位置重排 |
| 切换生硬 | 137无音桥 | 音轨错位0.5-2秒 |

## 工作流嵌入

### 推荐节奏
```
分镜表完成 → 第一轮自检（10分钟）→ 改表
素材生成 → 第二轮自检（每镜30秒）→ 重抽/补拍
初剪完成 → J项拉片 → 精剪
```

### 团队/多人协作时
```
自检表作为交付物附件：
"本镜通过了A-J全部检查，除H项光线为有意设计"
= 让"我觉得挺顺"变成可核验的交付标准
```

## 常见坑
- **只在出事后查**：自检表是前置工具不是救火工具
- **逐条全过的执念**：有意破例=打勾备注"有意"即可，不是必须全绿
- **检查顺序错**：先查叙事因果（D），再查画面细节（H）——大动脉优先
- **AI甩锅**："AI生成的没办法"=错，138给了全套接力工具
- **清单用完就扔**：每次翻车把新病灶加进表=清单会进化

## 进阶
- **抽检制**：长项目不必全检——关键场景（爆点/转场/首尾）必检，过渡场景抽检
- **观众代检**：给不了解剧情的人看一遍，他皱眉的地方=断点
- **建立私有病灶库**：把自己常犯的错提到清单最前面（个人化QA）
- **反向清单**：记录"这次有意破坏了哪条规则+目的"=风格化档案

- 连贯性=逐条打勾，不靠感觉
