# 轴线与180度规则

## 核心要点
- 两个角色之间画一条**想象线（动作轴）**，摄影机全程待在线的**同一侧**
- 守轴的结果：A 永远朝画面右看，B 永远朝画面左看——观众脑中自动拼出空间地图
- 越轴=屏幕方向突然翻转=观众潜意识"咦？"=出戏
- 连贯性第一法则：**空间关系必须可预测**
- 关联 130 战斗角度选择

## 轴线详解

### 什么是动作轴
```
A 和 B 对话 → 轴线=穿过两人的直线
A 追 B → 轴线=运动方向的直线
车向画面左开 → 轴线=车的行进路线
```
- 轴随**视线和运动方向**生成，不是固定不变的
- 一场戏可以有新轴（角色移动重建轴线），但**换轴要有交代镜头**

### 屏幕方向一致性
```
Shot A: 投手朝画面右投球 → 球出画方向=右
Shot B: 击球手必须朝画面左 → 球入画方向=从左来
```
- 出画方向与入画方向必须呼应——这是观众的空间直觉
- 方向乱了=球像会拐弯=观众懵

## 越轴的 4 种合法方式

### 1. 摄影机运动越轴
```
镜头运动中连续越过轴线（如环绕运镜）
观众眼看着镜头过去=空间连续不破
```
- 关联 129 战斗运镜

### 2. 中性镜头过渡
```
插一个骑在轴线上的镜头（正对着两人拍）
中性镜头无方向性 → 之后换到哪一侧都行
```

### 3. 角色移动重建轴线
```
A 起身走到 B 的另一侧 → 新轴建立
给观众看清楚移动过程=新空间关系成立
```

### 4. 故意越轴（表意）
```
表现混乱/眩晕/立场翻转时故意跳轴
例：审讯戏压到顶点时跳轴=心理崩塌
```
- 破规则的前提：观众已经被你训练得习惯规则——否则就是单纯迷路

## AI视频中的轴线问题

### AI的常见翻车
```
Shot1 角色朝左走 → Shot2 角色朝右走（AI不知轴线）
两人对话 → 两人都朝同一侧看（像在跟第三个人说话）
```
- AI 没有空间地图概念，每个镜头是独立生成
- **必须在提示词里锁死方向**

### 提示词锁方向模板
```
"character A on the left side of frame facing right,
 character B on the right side of frame facing left,
 consistent screen direction"
```
- 每个镜头都重复写方位词——别嫌啰嗦，AI记性差
- 用参考图/首帧图传递位置关系比纯文字可靠（关联 119 参考图技法）

## 模板示例（双人对话场景）

```
分镜1: 过A肩拍B（B在画面右，面朝左）
分镜2: 过B肩拍A（A在画面左，面朝右）
分镜3: B特写（面朝左，视线略下=看A的眼睛）
分镜4: A特写（面朝右，视线略上=A比B高/或仰视B）
分镜5: 双人侧面全景（骑轴中性镜头=确认空间）
```
- 全部镜头保持摄影机在轴线同侧
- 视线高低也传递身高差/权力关系（关联 017 角度即权力）

## 常见坑
- **AI随机方向**：不写方位=50%概率翻车，5个镜头全对的概率=3%
- **运动方向突变**：追逐戏主角突然反向跑=观众以为他回头了
- **多人轴线混乱**：三人以上场景轴变复杂=用全景定场镜头锚定
- **越轴无信号**：想跳轴表意但不给提示=观众当事故看
- **景别跳跃伴随越轴**：特写→反向大远景=双重迷失

## 进阶
- **情绪轴**：角色情绪关系也可成轴（A压制B=A永远在高位构图）
- **轴的渐变**：镜头缓慢绕轴=关系缓慢变化的视觉隐喻
- **无轴场景**：单人独景无对手=自由轴，但运动方向仍需一致
- **多轴管理**：打群架时锁定主轴（主角vs主敌），其余人服从主轴

## 备注
- 轴线是空间连续性的地基——先守轴再谈风格
- 合法越轴4法：运动越轴/中性镜头/角色移动/故意表意
- AI时代轴线要在提示词里显式锁死
