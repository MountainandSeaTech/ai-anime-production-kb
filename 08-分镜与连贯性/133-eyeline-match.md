# 视线匹配与正反打

## 核心要点
- 角色看哪儿，下一个镜头就给哪儿——**视线即剪辑指令**
- 视线匹配=观众通过角色的眼睛建立空间关系
- 正反打=对话戏的标准语法：A看右→B看左→A看右…循环
- 视线错位=两人像在对着空气说话=空间崩塌
- 关联 131 轴线、164 眼神演技

## 视线匹配详解

### 基本结构（视线匹配三段式）
```
Shot 1: 角色A抬头看（视线朝画面右上）
Shot 2: 高处的敌人/钟楼/飞机（A所看之物）
Shot 3: A的反应表情
```
- 看→被看物→反应=信息完整闭环
- 缺 Shot 2=观众不知道看啥=悬念或失误（取决于是否故意）

### 视线角度的几何
```
A 在画面左侧朝右看 → 被看对象必须在空间上的右侧
A 略微仰视 → 被看对象在更高处（下个镜头俯拍回来）
A 视线下移 → 看的是地面/手部/比A矮的人
```
- 视线角度透露**相对位置与高度差**
- 正反打里A俯视线+B仰视线=身高差/权力差（关联017）

## 正反打（Shot Reverse Shot）标准语法

### 基本型
```
1. 定场镜头：两人位置关系（全景/中景）
2. 过A肩拍B（B正脸）
3. 过B肩拍A（A正脸）
4. 循环 2-3，按台词节奏交替
5. 情绪升级时：越拍越近（中景→近景→特写）
```
- 定场镜头先行=锚定空间，后面正反打观众不迷路
- 关联 016 景别

### 景别递进（情绪升温曲线）
```
开场闲聊：双人中景或宽松过肩
话题严肃：单人近景
冲突爆发：大特写（眼神/嘴角）
```
- 景别收紧=心理距离收紧
- 突然从特写跳回大远景=情绪释放/间离

### 变体
```
内反打：不过肩，纯单人镜头（更主观、更孤立）
外反打：过肩带前景（空间感强）
背对背反打：两人背对，视线朝相反方向=决裂/平行叙事
```

## 视线的 5 种表意用法

### 1. 对视（Connection）
```
两人视线在镜头间对接=关系成立
```

### 2. 回避（Avoidance）
```
A看B，B移开视线看别处=拒绝/心虚/谎言
视线不接比台词更响
```

### 3. 共视（Shared attention）
```
两人都看画面外同一方向 → 切所看之物=共同威胁/奇观登场
```

### 4. 错视（Misdirection）
```
A看似看B，下一镜揭示A实际看的是B身后的刀=反转伏笔
```

### 5. 打破第四面墙
```
角色突然直视镜头=观众被点名=喜剧/恐怖/宣告
```

## AI视频的视线问题

### 典型翻车
```
Shot A：角色看画面右
Shot B（反打）：另一角色也看画面右
→ 两人像在看不存在的第三人
```
- AI不懂视线几何，必须显式写

### 提示词模板
```
"character looking toward frame left, eye contact with off-screen partner"
"reverse angle: character looking toward frame right, matching eyeline"
```
- 写"looking toward frame left/right"比"looking at him"可靠
- 写视线的**高低**："gazing slightly downward"传递身高/权力关系
- 连续镜头保持视线方向一致（守131轴线）

## 模板示例（审问场景）

```
分镜1: 定场——小房间，A坐着B站着（全景）
分镜2: 过B肩拍A：A低头（视线朝下=回避）
分镜3: 过A肩拍B：B俯视（视线朝下=压迫）
分镜4: A特写：缓慢抬头，视线从下到上（对视建立=反抗开始）
分镜5: B特写：B视线微移（压迫松动）
分镜6: 双人侧面：两人对视僵持（骑轴中性镜=对峙顶点）
```
- 视线从"回避→对视→僵持"=无台词的心理战
- 全程守轴：A在左看右，B在右看左

## 常见坑
- **视线同向**：正反打两人都朝同侧看=第三人幻觉
- **无被看物**：视线匹配缺中间镜=观众期待落空
- **视线高度错**：A仰视B却在下镜里俯视=空间错乱
- **AI随机视线**：不写方向=视线乱飞
- **对视无目的**：视线对接但没有情绪内容=空洞

## 进阶
- **视线引导剪辑**：用角色视线把观众注意力引向下个镜头的兴趣点
- **群戏视线网**：多人场景视线交错=阵营关系可视化（关联031群像）
- **视线+景深**：焦外的人被看时缓缓合焦=注意力转移（关联019景深）
- **无对视的爱情戏**：两人始终不直视对方=含蓄美学

## 备注
- 视线即剪辑指令——看→物→反应三段闭环
- 正反打配景别递进=对话戏的情绪引擎
- AI提示词必须写 frame left/right + 视线高低
