# 承接转场与因果链

## 核心要点
- 画面连贯靠剪辑技法（131-134），**剧情连贯靠因果**
- 黄金法则：场景之间用"**因此/但是**"连接，不能用"**然后**"连接
- 每场戏必须有：**入口因果**（为什么会到这）+**出口因果**（导致下一场什么）
- 剧情跳跃感=因果链断裂=观众脑子补不上
- 关联 076 开场、078 伏笔、080 段落曲线

## 因果链详解

### 因此/但是测试（南方公园法则）
```
烂故事：A发生了，然后B发生了，然后C发生了 → 流水账
好故事：A发生了，因此B发生了，但是C发生了，因此D…
```
- "然后"=并列=观众抓不住线
- "因此"=因果，"但是"=冲突——叙事只有这两种胶水

### 场景级因果检查
```
每场戏写两句话：
  入口：因为___，所以角色来到这里/做这个
  出口：因为本场发生了___，所以下一场___
填不出来=这场戏可以删
```
- 例：因为主角败北（入口），所以去拜师；
  因为师父给了悖论课题（出口），所以下一场独自苦练

### 微观因果（镜头级）
```
镜头3成立的前提在镜头1-2埋好：
  镜头1: 角色瞥一眼墙上的剑（埋）
  镜头2: 敌人逼近（压）
  镜头3: 角色反手拔剑（收——观众觉得顺）
```
- 没埋就拔剑=天降神兵=剧情跳跃
- 关联 078 伏笔与回收

## 剧情跳跃的 5 大成因

### 1. 动机缺失
```
角色突然做某事，观众不知道为什么
→ 补：前置一场"决定戏"或一句动机台词
```

### 2. 信息跳级
```
角色知道了观众不知道的事（无伏笔）
→ 补：78 式伏笔，或让角色与观众同步发现
```

### 3. 空间瞬移
```
上一场在城东，下一场在城西，无过渡
→ 补：移动镜头/交通工具/路牌空镜=空间胶水
```

### 4. 时间黑洞
```
上一场白天重伤，下一场生龙活虎
→ 补：时间字幕/伤口愈合镜头/"三天后"的暗示物
```

### 5. 情绪断裂
```
上一场悲痛欲绝，下一场嘻嘻哈哈
→ 补：情绪过渡场（独坐/雨/静默）=情绪需要冷却时间
```

## 承接转场的 6 种技法

### 1. 承接转场（因果呼应）
```
上场结尾：A说"我必须找到那把剑"
下场开场：剑的特写/地图/铁匠铺
```
- 上场结尾抛问题，下场开场接问题=最稳的转场

### 2. 反差转场
```
上场：极静的特写系列
下场：大远景+喧嚣
```
- 大反差=明确的段落感=观众接受"换章了"
- 反差必须是"有意的换章信号"，不是随机跳

### 3. 声音先导（J-cut）
```
下一场的声音先入（雨声/钟声/台词）
画面随后才切=听觉带视觉走
```
- 关联 137 声音先导详解

### 4. 物件接力
```
上场：A把信物交给B（特写信物）
下场：信物特写拉开——已在另一个城市B的桌上
```
- 物件是时空跳跃的实体锚

### 5. 空镜缓冲
```
激烈场景后切：云/水/街道空镜 2-3秒
=给观众喘气+暗示时间流逝
```
- 动漫的"間"美学

### 6. 问答剪辑
```
A场景："他会来吗？"
切 → B场景：那人推门而入
```
- 问题即钩子，切换即回答

## AI短剧的因果链实战

### AI特有风险
```
AI每镜独立生成 → 最容易出"美图流水账"
10个漂亮镜头≠1场戏——观众看完不知道发生了什么
```

### 解法：先写因果链再写分镜
```
步骤1：一句话故事（谁+因为什么+做了什么+结果如何）
步骤2：每场戏写入口/出口因果
步骤3：分镜表每行标注"本场因果功能"（建压/反转/揭示/缓冲）
步骤4：用140清单自检
```

### 提示词层的因果延续
```
Shot N+1 提示词开头复写 Shot N 的关键状态：
  "same character, now holding the broken sword, blood on sleeve,
   walking away from the battlefield"
→ 状态延续=视觉因果
```
- AI没有记忆，**状态必须每镜重写**（关联 113 风格锁定同理）

## 模板示例（3场戏的因果链）

```
场1（败北）
  入口：因为敌人来袭
  出口：因为武器被斩断，所以必须找铸剑师
  转场钩子：断剑特写

场2（拜师）
  入口：接上——断剑特写→铸剑师拿起断剑（物件接力）
  出口：因为铸剑师说"心不静剑不成"，所以主角去瀑布打坐
  转场钩子：台词"心不静剑不成"

场3（顿悟）
  入口：接上——瀑布声先导（声音先导J-cut），画面后入
  出口：因为顿悟，所以下一场决战
  转场钩子：睁眼特写→切决战场景的同角度睁眼（匹配剪辑）
```
- 三场戏三种转场技法，因果环环相扣

## 常见坑
- **然后式流水账**：场景间无因果=短视频合集不是剧
- **因果倒置**：先给结果后补原因=可以（悬念），但不补=坑
- **转场全靠黑屏**：黑屏=放弃治疗
- **钩子无回收**：上场结尾抛问题下场不接=观众记仇
- **AI状态丢失**：上场断剑下场剑完好=AI不记得，你要记得

## 进阶
- **双线因果**：A线出口因果=B线入口因果=交叉剪辑的结构力
- **假因果**：观众以为A导致B，实际C导致B=反转的结构基础
- **因果延迟**：埋因后隔5场才结果=长尾张力（关联078）
- **因果密度**：短剧每分钟至少1个因果事件——低于此=水

## 备注
- 剧情不跳跃的本质：场景间只有"因此/但是"，没有"然后"
- 每场戏写入口/出口因果，填不出就删
- AI实战：先因果链后分镜表，状态词每镜重写
- 关联：134 匹配剪辑、137 声音先导、140 分镜自检清单
