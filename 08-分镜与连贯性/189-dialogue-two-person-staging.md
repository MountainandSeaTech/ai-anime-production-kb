# 双人对话场面调度（机位方案库）

## 核心要点
- 双人对话在调度系统里只有一种**形态**：**I 形态**（两人连成一条线），但有十个"位置"变奏
- 三个开关决定观感：**面向观众程度 / 视线离镜头远近 / 机位取向与焦距**
- 主镜头管"看懂空间"，正反拍管"看见反应与视点变化"
- 位置一~十 = 现成机位菜单，按"亲密 / 对立 / 疏离 / 张力"取用

## 一、面向观众原则（frontality）
- 西方传统：主体倾向面向观看者，电影里即**面向摄影机**；两人对话演员更常面向镜头而非彼此
- 若人人都能面向镜头，可用**一个主镜头**拍完；一旦有人从镜头方向转开，就需**多机位**才能看到两张脸
- 由此分叉两手法：①共同面对单一机位 ②多机位视点剪在一起

## 二、主镜头与长镜头
| 手法 | 定义 | 作用 |
|---|---|---|
| 主镜头 master shot | 涵盖全场、拍完整个动作长度，常属备用镜头计划 | 空间锚点 / 安全网 |
| 长镜头 sequence shot | 摄影机经移动车在场景中流畅换位 | 用运动替代剪辑 |
- 主镜头里摄影机通常**不动**（好让后面切别的角度）；若主镜头本身在动，即成段落镜头
- 长镜头比剪辑更依赖面向观众：剪辑能接 180° 对立镜头，长镜头几乎无法快速换向，故对话长镜头通常维持**一个总体观看方向**

## 三、景别和距离：美式景别
- 双人中景是主镜头的一种，30 年代好莱坞对话戏主力，法国人称 **美式景别 plan American / American shot**
- 成因：有声片 + 长篇对白 + 早期隔音摄影机笨重，双人镜头减少移动；技术改善后仍沿用
- 作者偏好：双人 / 全身镜头提供**距离与客观性**；身体是绝佳表演媒介（站位、接触、姿势远景即可辨识），整个场景可在此距离调度不必靠特写

## 四、正拍 / 反拍模式
- 演员以交替特写出现，最能代表好莱坞风格
- 相比双人镜头两优点：①看清一个人对台词的**单独反应** ②**视点会改变**；视线匹配顺便建立空间统一（见 133）

## 五、演员视线与正视观众
- 单人对话镜头里，视线**越靠近镜头**，观众与该角色**越亲密**；极端 = 直接注视镜头 = **正视观众**（对抗性、冲击）
- 正视观众最常出现在 POV；故事片很少用；多数台词戏视线稍偏镜头左 / 右；要交替特写视线一致，就让多人**与摄影机保持相同距离**

## 六、调度系统：形态 + 位置（字母模式）
- **形态 pattern**：俯视人物排列像字母 **A / I / L**，由动作轴线决定 → 决定机位
- **位置 position**：人物面对的方向 → 决定构图
- **A、L 需三人以上；双人唯一形态是 I 形态**，它是基本建构单位；有一串特写 / 单人镜头时，I 也能出现在 A、L 内部

## 七、双人对话位置一~十（机位方案库）

> 均为 I 形态下的"位置"变奏；书中以固定（锁定）摄影机拍摄，代表被剪在一起的多重角度。

### 位置一 · 面对面
- 最基本位置，双肩平行。四种拍法：
  - **侧拍**：强对立感，难见表情（除非很紧）
  - **过肩**：经典正反拍，成对拍、大小匹配；前景头遮 **1/3~1/2** 画面 = 强烈孤立
  - **远摄过肩**：**120 → 200mm**，比广角更亲密，框到肩 + 脖子
  - **低角度反拍（over-the-hip）**：**3 英尺高**、加长焦至 **100mm** 使前景失焦、强调后景
- 适用：对峙、辩论、审讯式对话

### 位置二 · 肩并肩
- 基本正面位置，选择最多（正 / 侧脸同框），对话时侧脸对镜头
- 可双人镜头作主镜头；也可斜角双人开场 → 移侧拍正反拍特写（人物望向镜头 = 把观众卷入，现场感强）
- 适用：并肩同盟、共同面对外敌、并肩谈心

### 位置三 · 90° 角
- 位置一与位置二的折中，姿态轻松
- 双人 45° 角（面向镜头者更有利，机位近似过肩）；或让第二人转向镜头获对等反拍
- 适用：半亲半敌、关系微妙

### 位置四 · 制造张力（缺目光接触）
- 张力来自**演员间缺乏目光接触**（目光转开 = 强烈疏离），观众处优势地位
- 用 **30mm** 拍出深度（前景略变形、后景遥不可及，实际只隔一张桌）；此处**不用反拍**
- 适用：疏离、冷战、心不在焉

### 位置五 · 疏离 / 张力（肢体语言）
- 靠肢体（交叉手臂、插裤兜）说明意义；对"谁强势"基本中立
- 高角度开场（造张力与孤立）→ 双人 → 斜角反拍 → 越轴（"有效就用"）
- 适用：僵局、谈判、各说各话

### 位置六 · 纵深调度
- 与肩并肩相关，但**纵深会鼓励观众认同前景演员**；过分剪辑破坏完整性
- 后景演员可移动 / 踱步 / 暂离；前景演员限制在小空间
- 适用：前景主观视角、让观众站队

### 位置七 · 目光再岔开
- 两人往镜外不同方向望 = 注意力分散、随意轻松
- 后景演员望向前景演员会引导注意力并连接镜头；"读故事板就是用眼睛做**剪辑**"
- 适用：日常闲聊、群戏外围对话

### 位置八 · 直角但视线岔开
- 前者变体：两人成直角，后景演员视线与前景岔开
- 原则：**眼睛被清楚呈现的演员主宰该镜头**；斜角镜头倾向平衡注意力
- 适用：一方主导、另一方游离

### 位置九 · 完全对立
- 两人放在**完全对立的立场**，像音乐喜剧片；想象两人知彼此存在却采敌对姿态
- 可改为跟踪 / 监视场景 → 更像惊片；转头表明听见画外声音 = **"视线剪切"的听觉版**
- 适用：宿敌、摊牌

### 位置十 · 不同高度
- 演员处在**不同高度**；紧的双人镜头多半配高 / 低角度；无反拍（可行）
- "从右向左或对角阅读画面"可产生不同组合
- 适用：高差权力（站立 vs 坐地）、台阶对峙

## 八、取舍速查
| 想要 | 优先位置 |
|---|---|
| 亲密度高 | 二（斜角）、三、远摄过肩 |
| 强对立 | 一、九 |
| 疏离 / 冷战 | 四、五、六 |
| 观众站队 / 代入 | 六、八 |

## 对 AI 分镜的落地要点
- 把"位置一~十"当**模板库**：一场戏锁定同一 I 形态，用 `侧拍 / 过肩 / 远摄过肩 / 低角度反拍 / 肩并肩 / 90°角 / 纵深 / 直角岔开 / 完全对立 / 不同高度` 作机位措辞
- 焦距数字（**30/40/50/100/120/200mm**）写进 prompt，控制亲密感与背景走向
- 视线显式写 `looking toward frame left/right`、`eyeline slightly below camera`；需正视镜头写 `looking straight into camera, breaking the fourth wall`
- **面向观众程度 = 亲密度开关**：两人都朝镜头 = 旁听感；一人转身背对 = 必须切多机位
- 用主镜头锁几何 + 位置变体补反应特写，避免 AI 每镜随机朝向

## 常见坑
- **位置乱用**：要疏离却给过肩正脸 = 情绪不准
- **视线同向**：两人都朝同侧 = 像对第三个人说话（见 133）
- **越轴无信号**：位置五式越轴须给头部转动提示，否则观众当事故
- **只拍特写**：丢掉美式景别的距离与身体表演

## 附：双人情感互动公式（非台词驱动）
> 适用：恋爱/亲情/对峙等**不靠台词**的双人关系动作（对视/触碰/拥抱/擦肩/包扎/背后环抱等）。
> 公式：**人物A动作 + 人物B反应 + 接触位置 + 距离 + 视线 + 镜头运动**

| 要素 | 落地规则 |
|---|---|
| 接触位置 | 必须具体到身体部位：手背/肩膀/腰后/发梢/手腕/额头，禁写"触碰"这种笼统词 |
| 距离 | 用拳距/肩宽/一臂/贴身量化；距离变化=关系变化的物理信号 |
| 视线 | 对视/回避/追视/垂眼四选一，须与接触位置匹配（对视+手部接触=亲密；回避+擦肩=遗憾） |
| B的反应 | 刺激-反应同镜完成：A动作落地后 B 的微表情/退避/回握/僵直必须写在同一镜头内 |
| 镜头运动 | 关系靠近用 push-in、疏远用 pull-back、对峙用 static、追逐/奔向用 tracking |

示例：`她伸手替他整理领口（A动作+接触位置：领口），他垂眼望着她的发顶、喉结微动（B反应+视线），两人相距半拳（距离），slow push-in from medium shot to close-up（镜头运动）`

## 备注
- 双人对话 = I 形态 + 十个位置；**面向观众 / 视线距离 / 机位取向**三开关
- 主镜头管空间，正反拍管反应
- 书中学例：《教父 II》维托与法努奇车内对话，用两个推轨镜头分拍两侧再剪成过肩组，后景方向切换会颠倒却**不造成干扰**，证明 180° 规则有宽容度
