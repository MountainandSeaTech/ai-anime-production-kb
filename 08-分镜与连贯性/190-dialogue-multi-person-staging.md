# 三人及多人对话调度：A/L/I 形态与字母模式

## 核心要点
- 加一个人，形态从 I 变出 **A 与 L**；判据是"第三人被框在哪"
- **A 形态**=第三人被框在另两人**之间**（一人对两人）；**L 形态**=第三人**单独占一边**（一组两人 vs 一人）
- 这种"一对二"的外观叫**对立（opposition）**
- 人越多越不能穷举：**5 人场景约 27 个镜头**，实际靠**合并与简化**，先锁 2 个主角轴线

## 一、字母模式回顾（形态 + 位置）
- **形态 pattern**：俯视人物排列像 **A / I / L**，由动作轴线决定 → 决定机位
- **位置 position**：人物面对的方向 → 决定构图 / 站法
- 前提：①I 是基本建构单位，可在 A、L 中出现 ②形态决定机位 ③位置决定站法
- 判据：第三人被框在另两人之间 → **A**；与另两人成相对关系 → **L**

## 二、A 形态 vs L 形态的几何差异
| 维度 | A 形态 | L 形态 |
|---|---|---|
| 几何 | 一人被两人从两侧**包夹**（三人像 A 的中间点） | 一人独居一边，两人成一组（L 折角两端） |
| 关系 | 一人**面对**两人 | 一人**对**一组两人 |
| 观感 | 聚焦被围者，压迫 / 审视强 | 组内关系更稳，单人一侧更孤立 |
| 机位 | 唯一看清所有人的机位 = 主镜头首选 | 常把两人当一组放 L 字**上端** |
| 片中例 | 示图 10.1 黑衣男人被两侧包夹 | 黑衣男人独放画面一边 |

## 三、I 形态
- 三人戏里最简单常见，倾向**正反拍剪辑**
- 不剪辑时可在纵深画面做复杂调度，常用**过肩 / 双人 / 特写**框取动作
- 示图 10-6：借"推镜头运动 + 重调演员位置"，获得与只用主镜头一样多的多角度镜头

## 四、三人调度的动作轴线用法
- A 形态先定**基本观看方向**：摄影机可 360° 环绕，场景仍应有主观看方向
- 示图 10.3：1 号机开始，A、C 对话建立假想线，1、2 号过肩在轴线外
- B 与 C 说话（建新轴线）时，**留在演员 A 同一侧**、用 2 号机位，别在 A、B 之外造新机位
- 原则：**尽量重复使用原位置**，而非建新轴线后不断造新机位

## 五、三人调度范例要点
- **A 形态·版本一（图 10-1）**：唯一能看清每个人的机位 = 主镜头首选；第一组几个单人镜头（中景 + 特写）易分割空间但看不到说话 + 倾听者，下一组用过肩统一空间，双人 I 形态过肩变化全适用
- **A 形态·版本二（图 10-2）**：双方**正面相向**（访谈 / 会议）；男人视线接近镜头 = 与观众直接、居权威，两女人侧面 = 似倾听者；画面5 用 **40mm** 显太宽；以女人面对镜头开场则女人处权威
- **重叠 vs 非连续空间（图 10-3）**：画面10 含前一镜男人一部分 = **重叠空间**；画面11 不含前面空间 = **非连续空间**；画面11 / 13 作**转折镜头**导向特写；全部由 **50~90mm** 拍，三人镜头用最广的 **50mm**
- **L 形态·版本一（图 10-4）**：斜角 → 低角度过肩 → 两个特写，靠景别 / 角度造节奏；只用三人过肩也可撑全场，更轻松稳定
- **L 形态·版本二（图 10-5）**：开场是双人镜头，**不到第一画面看不到全貌**（故意保留全貌的策略）
- **A 形态·纵深调度（图 10-7 / 10-8）**：10-7 在男人与两女人间建轴，接低角度双人或女人过肩（又建新轴），**可能越轴**；10-8 不用反拍，摄影机移到后景拍穿门女人，"视线剪切"但**非主观镜头**
- **动作轴线实验（图 10-9）**：演员放**不同高度**、**非正统轴线**（不以视线为据）；男孩手中的枪 = 空间记号；多次越轴 + 再交代，用转头 / 空间记号保持连贯
- **L 形态·版本三（图 10-10）**：多为"视线剪切"——三人镜头开场 → 反拍转头 → 栏杆后男孩回看 → 丢石子 → 向上看 → 全景呼叫 → 特写转头，由动作 / 视线推动

## 六、四人以上：合并与简化
- **5 人场景 ≈ 5 特写 + 9 双人 + 6 三人 + 6 四人 + 1 五人主镜头 ≈ 27 个镜头**，许多机位不实际；超过三人实际是**合并与简化**
- 群众里点对话仍以**说话者 / 倾听者二人**为基础；多人说话常用**三人和四人镜头**帮观众分辨
- 一大群人中建立**多于四条视线**=自找麻烦；限制在几个主要机位（示图 11.4 一条基本动作轴线 = 基本观看方向）
- 轴线在**两位主要人物**间建立（示图 11.2），即使切别人特写，基本调度仍据这两人轴线

### 11.1 单一机位的正面位置
- 群像主镜头以一个视点调度，银幕像剧院幕前装置；**不是横向调度，而是以画面纵深调度**
- 图 11-4 走廊一群男孩：多侧面，前景者偶尔转向后景回应

### 11.2 有纵深的正面位置 & 开放式构图
- 前景演员靠近摄影机；担心看不清 → 过度安排显得不真实；**唯一解法是放弃工整构图**
- 人物重叠 / 被框切掉 = 构图自由 = **开放式构图**；图 11-1~11-6 是现场调度过程，画面5 最接近满意

### 11.3 群众和大型团体：两种基本方法
- **从群众之中往外看**（广角 / 正常焦距，动作范围之内拍）
- **从群众之外往里看**（远摄，动作范围之外拍）——执行很大程度依赖**镜头焦距**

### 11.4 远摄镜头拍群众
- 优势：①少演员模拟大群众 ②浅景深把主角从前后景真假群众中独立 ③摄影机可离远、空间关系"无限" ④可远距离拍到真实处境
- 关键：摄影机须在动作范围之外；**十至十五个临时演员就能制造极大群众效果**；在群众中用远摄须小心布置

### 11.5 广角镜头拍群众
- 困难：摄影机在动作范围之中、接近人物；景深大 + 清晰 = 构图不容错
- 旋转一个方位就涵盖 **90° 空间**，可能需**成千上万临时演员**填补；移动车轨道 / 灯光又要求清场
- 取舍：**以较广角拍外在动作，以远摄拍对话场面**

### 11.6 群众场景镜头比较（焦距 → 主体层次）
| 焦距 | 主体所处层次 |
|---|---|
| **35mm** | 微广角，从动作范围外拍（画面1） |
| **40mm** | 穿过游行队伍，人处画面**中间地带**（画面2） |
| **50mm** | 接近中心，人物**留前景**（画面5、6） |
| **300mm** | 人物**停在后景** |
| **500mm** | 从对街拍，以两位观众作前景（画面4） |
- 画面3：用长焦拉近后景，主角因浅景深**失焦**（外貌已建立仍可辨认）

## 对 AI 分镜的落地要点
- 三人戏先选形态再选机位：一对二压迫用 **A**；组内关系用 **L**；正反拍流畅用 **I**
- 提示词显式声明几何：`A-shape: one character framed between two, facing them` / `L-shape: one character isolated at frame edge, two grouped`
- 多人戏别穷举：**先写死 2 个（≤4 个）主角轴线**，其余 group shot 带过；AI 多人易崩脸，优先"静态背景 + 少数人动"
- 用焦距数字（**35/40/50/300/500mm**）控制主体前后景层次：远摄 = 隔离 / 伪群众，广角 = 交代地理
- 群像用"前景近 + 后景松散 + 允许重叠出框"的自然感
- 越轴镜（图 10-9 式）须给"转头 / 空间记号"作信号

## 常见坑
- **形态判错**：把 L 当 A = 关系全乱；先问"第三人被框在哪边"
- **多人穷举机位**：5 人 27 镜，别硬凑
- **轴线多于四条**：群众戏视线一多就乱
- **广角塞群众**：旋转 90° 就要成千上万人
- **过度工整**：群像排列太齐 = 假

## 备注
- 三人 = A / L 二选一 + I 内嵌；多人 = 合并简化 + 锁双主角轴
