# 视觉引导线与动线一致性

## 核心要点
- 每个画面都有一条**主导向线**（对角线/曲线/垂直线）——观众眼睛沿线走
- 镜头间动线**首尾相接**：上镜视线终点≈下镜视线起点=零成本过渡
- 动线突然反向=观众眼睛要急刹车=隐性疲劳
- 漫画的格间动线、动画的镜头动线、AI短剧的分镜动线=同一套工程
- 关联 091 构图、018 构图原则

## 视觉引导线详解

### 引导线的来源
```
实体线：道路/河流/武器/手臂/队列
暗示线：视线方向/运动方向/光线方向
结构线：建筑的边/地平线/门框
```
- 每个镜头先问：这条线把眼睛引向哪里？

### 动线方向的情绪属性
```
从左到右（西方式阅读方向）= 顺畅/前进/正常
从右到左 = 阻力/逆行/不适
对角线上升 = 希望/攀升
对角线下降 = 坠落/衰败
曲线 = 优雅/流动
锯齿 = 混乱/暴力
```

### 动线接续（镜头间）
```
镜头1：角色朝画面右跑（动线→）
镜头2：跟随镜头，角色继续朝画面右（动线→ 接续）
镜头3：终点建筑在画面右（动线→ 抵达）
```
- 动线连续=空间连续+方向可预测（与131轴线一体两面）

## 动线设计 4 技法

### 1. 首尾咬合
```
镜头A的视觉落点在右下 → 镜头B的兴趣点在右下开场
= 观众眼睛零位移
```
- 剪辑前检查：前后两镜的兴趣点位置距离
- 距离近=顺；距离远=跳（跳也可以是有意的）

### 2. S型阅读流
```
漫画分镜：左上→右上→左下→右下=Z字
复杂构图：用S型曲线串多个兴趣点
```
- AI单图内也可用：前景人物→中景引导线→远景焦点

### 3. 动线反转表意
```
全片动线一直向右（前进）
关键转折镜头：动线突然向左
= 潜意识层面宣告"方向变了"
```
- 《进击的巨人》常用：调查兵团出墙向右，败退向左

### 4. 动线汇聚
```
多线汇聚于一点=高潮构图
所有引导线指向画面中心=爆点帧设计
```
- 关联 059 冲击帧、131 速度线（速度线本质=暴力动线）

## AI分镜的动线实战

### 提示词写引导线
```
"leading lines of the corridor converging toward the character"
"her gaze directs attention to the glowing door on frame right"
"diagonal composition, motion flowing from bottom-left to top-right"
```
- 显式写 leading lines / gaze direction / diagonal
- AI对构图指令响应好——比让它猜强

### 分镜表的动线检查列
```
分镜表加一列【动线入/出】：
  镜头1: 入=左上，出=右下
  镜头2: 入=右下（咬合），出=右
  镜头3: 入=右（咬合），出=中心
```
- 咬合不上就调整构图或加过渡镜

## 模板示例（追逐戏动线）

```
分镜1: 远景，主角从左入画向右跑（动线→ 建立）
分镜2: 低角度跟拍，脚部和地面速度线（动线→ 强化）
分镜3: 前方岔路在画面右（动线→ 指向目标）
分镜4: 反派从画面右逆向入画（动线← 冲突预告）
分镜5: 两者相撞于画面中心（动线对冲=爆点）
```
- 前3镜同向=积蓄动能
- 第4镜反向=对冲预警
- 第5镜对撞=动线动能释放

## 常见坑
- **动线乱炖**：一镜内3条以上引导线互斗=眼睛不知道去哪
- **方向随机**：AI生成人物朝向随机=逐镜写朝向词
- **兴趣点跳对角**：上镜左下下镜右上=眼睛跨屏=累
- **动线无功能**：引导线引向画面外无物=虚晃
- **首尾断裂**：镜头间兴趣点毫无位置关系=每个镜头都重启注意力

## 进阶
- **动线即情绪曲线**：全片动线统计图=视觉节奏图（右向多=推进，左向多=回顾）
- **静中之动**：静态构图里用暗示线（视线）保持动线活性
- **动线欺骗**：引导线指向A，爆点在B=预期违背（需先建强预期）
- **环形动线**：视线被引回起点=轮回/闭环主题

## 备注
- 观众的眼睛是被牵着的——引导线就是缰绳
- 镜头间动线首尾咬合=零成本过渡
- 分镜表加【动线入/出】列做自检
