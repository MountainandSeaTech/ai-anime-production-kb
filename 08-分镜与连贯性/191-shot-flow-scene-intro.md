# 镜流与用景别交代场景

## 核心要点
- **镜流（shot flow）**=电影镜头的连接显现出的**流畅运动效果**，像河流：可汹涌、宁静、曲折甚至中途折回
- 一段镜头段落通常含节奏与动态上复杂的剪辑关系，最终汇入单一统一的结构
- 决定镜流的两大最基础元素：**景别（shot size）与摄影角度**；本章集中讲景别
- 交代场景不必只靠一个全景——**改变景别本身**就能制造视觉运动、速度与方向

## 一、镜流是什么
- 定义：镜头连接呈现的流动感；它是有"性格"的——汹涌 / 宁静 / 曲折 / 折返
- 一个段落无论镜头关系多复杂，都汇入一个统一结构
- 无需给镜头添加不需要的装饰；**景别 + 角度**两个元素就决定镜流
- 实操：给整段镜头打一个"镜流标签"（汹涌 / 宁静 / 曲折），即段落整体的律动提示

## 二、用改变景别来交代场景
- 通过改变**镜头间空间跨度**来交代一个地点 / 场景，并同时控制：视觉运动、速度与加速度、气氛、视点、韵律、节奏、情感距离、戏剧意图
- 三种基本剪辑策略：
  1. **前端推进**：全景开场后向主体靠近
  2. **后拉揭示（pull-back）**：从局部特写向后拉出，显出地点全貌
  3. **特写群蒙太奇**：以一连串特写拼出一个整体的感觉

- **版本二**：加入真正特写（画面3、6）看见"出租告示牌"；镜头间摄影机距离变化约 **1/4 英里**；盖住画面2、5 可见空间跨度之大，却仍保持空间统一性
- **版本三**：从极高角度处理（1~3）；画面4~6 加旋转运动但景别变化不大；结合两法以**环形路径**移进主体（7~9）；画面10~12 从三个面向（向下、接近、弧形环绕）逼近房子
- **版本四**：两种**后拉运动（pull-back）**——由正面镜头拉远至斜角空中镜头；前两镜建立运动路径，第三画面在比例与角度上出现更大变化
- **版本五**：只给局部细节，让观众自行组织整体（更符号化 / 抽象）。10 个元素：①废弃生锈的脚踏车 ②打翻在地的信箱 ③门廊堆积的广告邮件 ④破了的窗户 ⑤透过破窗望见空荡房间 ⑥房屋出售告示牌 ⑦被切断的电视信号线 ⑧翻倒的空狗屋 ⑨墙上涂鸦 ⑩装满垃圾的纸盒

## 三、固定镜头的叙事迭代（风筝 / 父与子）
- 导演为童年题材在真实房前把开场**改了四版**，展示创作过程本身：
  - **版本一**：尽量用固定镜头 + 有限摇镜；全景父亲出前门走向车库 → 男孩卧室窗口（被子动、袜子掉下）→ 前景男孩 / 室外父亲。导演觉得背景应更广、第二镜太拐弯抹角
  - **版本二**：改俯拍（不必过斜）涵盖更多环境；父亲入镜 → 弯腰捡到一只运动鞋 → 中景叹气；切男孩翻身、脚露被外，父亲的手把运动鞋放床架
  - **版本三**：以填满画面的亮橘色"宇宙飞船"淡入开场，后拉才知是破烂风筝卡在背光树枝上；风吹落风筝掉出画面显露房子；多镜切换（床上男孩 / 车库门 / 男孩翻身 / 父亲倒车）；画面4 改善为拍更紧（画面5）；刹车声、车在鞋子几英尺前停下、父亲（只脚部）下车
  - **版本四（图 8-9）**：降低视点、下摇前涵盖邻居；交叉剪辑加入母亲、女儿分散鞋子焦点；母亲厨房收碗盘呼叫"彼得起床了没？"；结尾车保险杠勾到风筝线拖走风筝
- 导演分析：反复比较草稿、重组新旧想法直到得到想要的效果；风筝作为抒情元素仍有效，但开场后视点应移向男孩并停在他身上
- 方法总结：通过画面中**移动主体的重复**显现每个阶段动作（母亲在房间出现两次；男孩左脚、右脚分列画面并配文字说明）——**自己设计故事板才不会混淆**；为他人设计时务必标明每个意味深长的动作

## 四、景别交代策略速查
| 策略 | 景别走向 | 效果 |
|---|---|---|
| 前端推进 | 全 → 中 → 特 | 逼近 / 加压 / 聚焦 |
| 后拉揭示 | 特 → 中 → 全 | 揭示 / 泄压 / 交代空间 |
| 特写蒙太奇 | 特 + 特 + 特…→ 整体 | 符号化 / 抽象 / 环境叙事 |
| 环形移入 | 高角 → 环绕 → 逼近 | 动感勘探 / 立体空间 |

## 对 AI 分镜的落地要点
- 把"镜流"当整段分镜的**风格 / 律动提示词**：汹涌 / 宁静 / 曲折，用来指导切点密度与运动量
- 交代场景优先用**景别跨度**而非依赖镜头运动：AI 静态帧最稳，直接写 `wide shot → medium shot → close-up` 即可
- 局部特写蒙太奇（版本五清单法）是高复用模板：把 5~10 个细节物各生成一帧再剪成整体，AI 单帧稳定性最好
- 用 `pull back / reveal` 写关键揭示镜（如风筝 → 房子）：`reveal: pull back to show the whole house`
- 多版本迭代：先出 3~4 版故事板草稿再定稿；跨帧重复移动主体并配文字标注，防止跨镜混淆

## 常见坑
- **只用一个全景交代**：空间跨度被浪费，节奏平
- **景别不动**：一段戏景别不变 = 观众觉得没进展
- **特写蒙太奇无指向**：细节堆一起但指向不明 = 观众拼不出整体
- **装饰过剩**：镜流只靠景别 + 角度两元素，堆花活反乱
- **交代镜头只显示已预期之物**：对建立期待 / 加强叙事无大用

## 备注
- 镜流 = 镜头连接的流动观感；**景别 + 角度**是两大决定因素
- 交代场景 = 改变景别 = 改变空间跨度与节奏
- 三策略：前端推进 / 后拉揭示 / 特写蒙太奇；书中"一栋房子"五版、"风筝"四版为核心片例
