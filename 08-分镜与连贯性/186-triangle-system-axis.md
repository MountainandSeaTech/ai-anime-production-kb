# 三角机位系统与越轴六法

## 核心要点
- **动作轴线（180°假想线）**是剪辑系统里摄影机摆放的**最基本法则**：为维持一贯的银幕方向感与空间感
- 轴线方向**通常由景中两个人的视线形成**；一旦定线，就得到 **180° 工作区间（灰色半圆区）**，只允许在半圆内放机位
- **三角机位系统**：在假想线同一侧，用 **A / B / C 三个点**就能取得全部素材的基本镜头；三点连线成三角，**系统内任何镜头都能互相连接**
- 半圆之外＝**越轴（跳轴）**：把区内 A 与区外 F 剪在一起 → 男人会望着女人的**后脑勺**
- 越轴不是绝对禁忌——有**六种合法越轴方式**，每一种都配一个专用过渡手段

## 详细内容

### 一、动作轴线原则
把轴线想成「摄影机前一块被划分出来的想象空间」。主体在第一画面朝某方向通过，就应以**相同方向**出现在第二画面。

```
A 与 B 对话 → 轴线 = 过两人视线的直线
A 追 B    → 轴线 = 运动方向直线
```

- 同一侧镜头银幕方向必然一致（A 永远朝画右、B 永远朝画左）
- **附带收益**：同角度、同地位的镜头可**一齐拍摄**，避免为相同机位重复打光

### 二、三角机位系统：五种基本机位
三角机位系统包含对话场面用到的**所有基本景别和角度**。五种基本机位：
1. **斜角单人镜头**（angular singles，中景或特写）
2. **双人主镜头**（master two-shots）
3. **过肩镜头**（over-the-shoulder shots）
4. **单人主观镜头**（point-of-view singles，中景或特写）
5. **侧拍镜头**（profile shots）

**四种摆法（A / B / C 三点）**：

| 摆法 | A / C 机位 | B 机位 | 备注 |
|---|---|---|---|
| 摆法一 | 两人斜角单人 | 双人镜头 | A、C 景别可**大特写→全景**任选 |
| 摆法二 | 过肩镜头 | （省略） | 与摆法一差别只在远近距离 |
| 摆法三 | 移到动作轴线内侧（人物视线上） | — | 拍人物**视点的特写**，未拍者移开以便放机 |
| 摆法四 | 侧拍镜头 | — | 侧面呈现 |

- 只要不破坏假想线，实际角度、构图、景别可有**无穷变化**
- **限制条件**：不能有大规模场面调度或摄影机运动，否则会出现「一台摄影机跑到另一台前面」的问题（适合单一个体/动作场面/直播电视）
- **单机操作**：一台摄影机在三个角位自由移动，分别完成三种机位设定——剧情长片通常这样拍
- 注：经典教材的「1/2/3 号机位」在本章以 **A/B/C** 表达；「1号/2号/3号摄影机」编号实际出现在**第 9 章**

### 三、六种合法越轴方式

**① 根据新的视线建立新轴线**（6.7）
- 旧轴线上，另一人走近、坐着的男人**转头望向他** → 新视线建立**新动作轴线**及新半圆
- 配 **转轴镜头（pivot shot）**连接两条假想线
- 一旦建立新轴，摄影机即可越过旧轴进入新工作区；但旧角色（女人）下次出现时，机位仍按**旧轴线**决定——这叫**再交代镜头（reestablishing shot）**
- 复用经验：已建立基本剪辑模式后，**不需再经转轴镜头**即可回旧轴线

**② 在演员越轴时建立新轴线**（6.8）
- 演员站起**越过自己的动作轴线**走向新区 → **目光与对方交汇、重建两人关系** → 新轴取代失效旧轴
- **硬性要求**：必须在画面中**清楚展示演员的重新就位**
- 选边规则：新工作区可在线任一侧，但**要与前一个「转轴镜头」所处的区间保持一致**

**③ 移动摄影机越过轴线**（6.9）
- 借**摇镜、推轨或升降**把摄影机移到新空间
- **条件**：只要不中断摄影机运动即可；**不需建立视线关系**（如弧形运动越过轴线）

**④ 用切出镜头和过渡镜头**（6.10）
- 插入一个**与场景动作相关但与位置无关**的镜头（如教室戏里**学生的笔记本**细节）
- 回到主动作时即可越轴建立新轴——通常是**剪辑时碰到问题的快速解决方案**

**⑤ 在动作段落中越轴**（6.13）
- 非对话场景的越轴策略与对话相同，**只是以运动轴线取代视线**
- 建立新轴三法：**主体越轴**（车/马/人越过并取新运动方向）、**摄影机越轴**（跟拍至新地点）、**新主体进入画面**形成相对的主运动轴

**⑥ 轴线上的跳轴**（6.14）
- 规律：**摄影机越靠近动作轴线，就越难发现它越轴**
- 机位 A、B 坐在轴线上剪在一起会出现方向颠倒；因人物以**侧面**呈现，甚至比其他情形更突兀
- 当人物视线就是轴线时，可用**正面与背面拍摄**帮助观众分辨镜头差异

## 关键参数清单
- 工作区间：**180° 半圆（灰色区）**，机位只放区内
- 三角机位点数：**3 个（A/B/C）**；基本机位 **5 种**
- 机位摆法：**4 种**（斜角单人/双人、过肩、主观、侧拍）
- 越轴方式：**6 种**；专用过渡手段：**转轴镜头 / 再交代镜头 / 切出镜头 / 清空画面**
- 单人主观特写景别跨度：**大特写 → 全景**任选

## 对 AI 分镜的落地要点
- 把「A=单人（斜角）/ C=反打单人 / B=双人主镜 / 再补过肩、主观、侧拍」直接做成**对话段镜头清单模板**
- 提示词里显式声明**同轴一侧**约束（*same side of the 180° line / consistent screen direction*）
- 换轴**必须给合法动机**：角色转头看新区域（方式①）、角色起身走过对视重建关系（方式②）、连续弧形运镜（方式③）、插入道具特写/空镜（方式④⑥）
- 跨轴后旧角色再出现，用**再交代镜头**的机位，别凭空翻方向
- 动作/追车段把「车辆行进方向」当轴线；若已侧向反转，用**更紧的过肩镜头填满画面**掩盖方向错乱

## AI 提示词对照
- 守轴：`same side of the 180° line, consistent screen direction`
- 反打单人：`reverse-angle single, character A left of frame facing right`
- 过肩：`over-the-shoulder shot, foreground shoulder in frame`
- 主观：`POV shot from character's eyeline, inside the action axis`
- 侧拍：`profile shot, subject facing sideways`
- 换轴动机：`character turns head to look at the newcomer` / `character stands up, walks across, their eyes meet`
