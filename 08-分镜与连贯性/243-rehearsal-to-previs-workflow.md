# 排演九日志→AI预演工作流

## 核心要点
- **排演是导演工作的核心环节**，标准两周起，复杂角色三–四周。
- **排演的真正价值=建立信任+让本能引导调度**。导演不提前设计调度，看演员本能如何引导。
- **排演不投入真感情原则**：第一遍走位只做动作、正常音量，感情留给正式那条。
- **"准备带来即兴自由"悖论**：充分准备才能抓住幸运的意外。
- **AI迁移五阶段预演工作流**：脚本通读锁主题→情绪节拍分解→rough blocking动态分镜→精调动作流动与视线→按序连跑查弧线断层。
- **动漫短剧的"走位"=角色在场景中的动线与关键帧位置**。
- **预演期发现情绪断层成本最低**，远低于正片返工。
- **冻结剧本机制**：预演结束后冻结，避免无休止改写。

## 详细内容

### 一、吕美特排演九日志

| 天数 | 内容 | 目的 |
|---|---|---|
| 第1天 | 围桌通读剧本 | 主题对齐，本能释放 |
| 第2–3天 | 分解剧本元素+改写讨论+再通读 | 标记需改写处；第二次通读本能损耗 |
| 第4天起 | 走位快速通关 | 就地取材；胶带标实际尺寸 |
| 随后两天半 | 精调走位流动 | 停停走走；看演员本能引导 |
| 第9天 | 摄影师走戏 | 视觉化确认 |
| 最后一天 | 按剧本顺序再过1–2遍 | 建立连续感与角色弧线 |

### 二、排演的真正价值：信任与本能

排演不是"把动作练熟"，而是**建立信任的过程**。出色表演需要暴露自我，排演让演员获得信心。导演必须毫无保留，演员才能信任你。**导演不提前设计调度**——吕美特不会提前把走位图画死，而是观察演员本能如何引导行动。

AI迁移：AI没有"本能"，但有"生成倾向"。预演阶段观察AI在不同prompt约束下的生成倾向，找到符合角色气质的表演模式。

### 三、排演不投入真感情原则

吕美特："我不想浪费演员的任何感情，他们要在这里待上漫长的一天，我希望他们把感情留给正式那条。"第一遍走位只做动作、正常音量。AI短剧同构：预演低分辨率快速过。

### 四、"准备带来即兴自由"悖论

吕美特："准备不会扼杀即兴，反而让'幸运的意外'成为可能。"预演越充分，正式生成时的"幸运意外"越容易被抓住。已通过预演锁定动线、情绪节奏、视线落点，AI给出更好结果时能立刻识别并保留。

### 五、AI迁移五阶段预演工作流

| 阶段 | 对应吕美特排演 | 核心任务 | 输出物 |
|---|---|---|---|
| ①脚本通读锁主题 | 第1天围桌通读 | 一气呵成读完，一句话锁定主题 | 主题锚点 |
| ②情绪节拍分解 | 第2–3天分解+改写讨论 | 逐场标记情绪峰值、转折点 | 情绪节拍表 |
| ③rough blocking动态分镜 | 第4天起走位快速通关 | 低分辨率animatic快速过全部戏 | rough animatic |
| ④精调动作流动与视线 | 随后两天半精调走位 | 确认动作自然过渡；视线接触/回避到帧 | 精调animatic |
| ⑤按序连跑查弧线断层 | 最后一天按剧本顺序再过1–2遍 | 完整播放，检查角色弧线连续性 | 最终预演+冻结剧本 |

**关键细节**：
- 阶段③"胶带标实际尺寸"对应AI中的**场景边界与角色比例锚定**：在animatic中标出可行动空间，避免穿墙或比例失调；
- 阶段④"视线"是AI短剧最低成本高收益的情感信号：精确控制视线落点能瞬间改变情感层级；
- 阶段⑤必须完整播放，不能跳场。非顺序生成决定了"连续感"最容易在预演期丢失。

### 六、动漫短剧的"走位"=动线与关键帧

- **角色在场景中的动线**：从A点到B点的路径、速度、停顿点；
- **关键帧位置**：情绪峰值时的身体姿态、手部动作、面部朝向；
- **与场景元素的关系**：角色与门、窗、家具、光源的相对位置。

预演期用简笔画或3D占位模型标出，避免正式生成时"站错位置"。

### 七、预演期发现情绪断层成本最低

排演使导演在脑中形成完整情绪图景，以应对非顺序拍摄。AI短剧的非顺序生成特性比电影更极端，预演期发现"第三幕接不上第一幕"成本几小时，正片后数天。

### 八、冻结剧本机制

吕美特明确：**排演结束后冻结剧本**，避免临时无休止改写。AI短剧的等价问题是"无休止prompt微调"。预演结束后冻结：主题锚点、情绪节拍表、角色动线、色彩系统与滤镜参数。

## 关键参数 / 模板 / 清单

### AI预演五阶段检查清单

- [ ] ①：是否已用一句话锁定主题？是否已确认编剧意图？
- [ ] ②：每场戏是否已标记情绪峰值与转折点？是否已识别废戏？
- [ ] ③：animatic是否覆盖全部场次？动线是否用占位图标出？
- [ ] ④：动作流动是否自然？视线落点是否到帧？
- [ ] ⑤：是否已按叙事顺序完整连跑？角色弧线是否连续？
- [ ] 冻结：是否已冻结主题、节拍、动线、色彩？

### 排演-预演时长对照表

| 项目类型 | 吕美特排演 | AI预演建议 |
|---|---|---|
| 简单短片/单集 | 两周 | 3–5天 |
| 复杂角色/多线叙事 | 三周 | 7–10天 |
| 悲剧/史诗维度 | 四周 | 10–14天 |

## 备注

- **踩坑**：不要把预演当成"低质量正片"来做。预演的目的是发现问题，不是提前欣赏成品。
- **限制**：吕美特的排演依赖真人演员的本能，AI预演依赖生成倾向的观察。
- **适用范围**：最适合有明确情绪弧线、角色关系复杂的叙事性AI短剧。纯展示型AI视频可压缩阶段②和⑤。
