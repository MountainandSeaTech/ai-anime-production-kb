# 大场面人物不漂移③：高速动作中的身份稳定

## 核心要点

- **运动矢量越大，五官/服装纹理/解剖比例溶解越快**——动作戏是一致性的终极压力测试；思路要从"生成抽彩票"转为"受控工程"
- **减法提示（Subtractive Prompting）**：不要加更多动作形容词去"强调快"，而是锚定**该保持刚性的材质**——"厚重皮夹克不随风飘摆""刚性甲片"，让模型把注意力预算花在该硬的地方
- **分区分担运动**：显式写"上半身保持稳定，腿部发力"，降低模型运动扭曲层的负载，腿和环境承担动感
- **时间超频**：按0.75倍速生成（模型渲染更多中间帧、身份数据更密），剪辑软件里提速115-130%——比直接按目标速度生成更稳

## 详细内容

### 一、动作参考图的静态门槛（开打前已决胜负）

静帧里不清楚的特征，运动中会彻底融化。主动作角色的参考图需满足：
1. **高对比光**：伦勃朗光或轮廓光把人物剪影从背景切出来——快速摇镜时模型靠剪影区分人与背景
2. **≥3个高对比锚特征**：特定伤疤、织物纹理图案、独特护目镜/头饰等（对接344高频纹理：明线丹宁胜光滑化纤）
3. **焦段35-85mm**：超广角（14-24mm）边缘扭曲在运动中会被引擎错误解释，动作参考禁用超广角
4. 分辨率≥1024²，清晰、中性、正面（与正典参考标准一致，条目343）

### 二、减法提示与材质锚（动作段提示词结构）

不要写"非常快地、极速地、疯狂地"——模糊副词只会放大概率包络。用四段式：

```
主体/动作：主角在雨中全力冲刺
环境：霓虹巷道，湿沥青反光
运动控制：腿部有力蹬地，上半身保持稳定，镜头平稳跟摇
材质锚：厚重防水风衣、硬挺立领、哑光面料，衣料不飘不变形；
        硬质胸甲保持形状；头发束紧不乱飞
```

**材质锚词库**：
- 该硬的：rigid armor plates（刚性甲片）、stiff collar（硬领）、heavy leather that does not flow（厚重不飘动皮革）
- 该服帖的：hair tied tight（头发束紧）、fitted bracers（贴合护臂）
- 反向：披风/飘带等**必须飘的物件**单独声明物理方向（"披风向右后扬起"），并逐镜锚其存在（对接条目183武器持久性同理）

**上稳下动原则**：跑动写"躯干稳定、双腿发力"；挥砍写"双脚扎根、肩臂挥出"——每次只让一部分身体高速运动，脸与躯干区域尽量稳。

### 三、时间超频工作流（Temporal Overclocking）

1. 按约0.75倍速生成，提示用 "slow-motion sprint"（慢动作冲刺）/ "deliberate, powerful movements"（沉稳有力的动作）
2. 按时间线原生帧率导出（24/30fps）
3. 剪辑软件（剪映/Premiere/Resolve）提速到115-130%
4. 需要时开光流补帧平滑微卡顿

原理：慢速生成＝更多中间帧＝更密的身份数据，减少时间混叠（肢体"鬼影"——模型无法决定下一帧肢体该在哪）。
**适用**：奔跑、飞跃、近身快打。不适用：本来就慢的情绪段（提速会破坏表演）。

### 四、锚帧链（Chain of Custody）

单条原生镜头封在3-6秒；更长的动作段用**重叠锚帧**接：
- A镜的最后一帧（身份已确认稳定）→ 存为B镜的参考/首帧
- B镜末帧 → C镜参考……
- 身份像证据链一样逐镜交接，配合正典实体双保险（正典防跨链漂移，锚帧防接缝跳变）

选帧要求：交接帧选**脸正、清晰、无动态模糊、服装完整**的瞬间；不要选大回头/遮挡/发力表情帧。

### 五、多pass与合成挽救（3-5次是正常预算）

核心动作条按3-5次生成规划，每次是数据点不是失败：
- pass1 人稳背景崩、pass2 背景完人漂＝**可挽救**：取pass1干净的开头＋pass2稳定的中段，后期拼接/遮罩合成
- 判据分离：身份、背景、动作完成度分开打分，不要求一次全中
- 合成是专业常规操作，把成本计入镜头预算（参考条目249批次经济学）

### 六、动作段漂移症状速修

| 症状 | 修法 |
|---|---|
| 跑着跑着脸变了 | 降到3-5秒/条；降运动档；上稳下动；锚帧链接 |
| 衣服融化/变色/换款 | 材质锚句＋全套服装固定串逐镜复述；高纹理服装 |
| 头发糊成墨/乱飘 | "束紧"声明＋头饰锚特征；必要时改发型设计（束发胜散发） |
| 四肢鬼影/多手多脚 | 时间超频；减少同屏快速肢体数量；负向加 extra limbs, melted hands, morphing |
| 武器忽隐忽现 | 条目183全套：逐镜锚武器、避免长时间出画、武器专用负向 |
| 高速运镜里人和背景分离失败 | 参考图换轮廓光版；跟摇代替甩镜；降低人景相对速度 |

### 七、与冲击帧体系的协同

- 需要冲击帧/顿帧的爆点（条目292-311）：**把最容易漂的高能量帧与最稳的拍法配对**——接触瞬间用短镜（≤1-2秒生成段内）或转成剪影/特写（不需要脸），不要又快又远又正脸
- 战争大场面的高运动预算优先给：无脸群演、武器特写、环境破坏；主角的反应靠中近景稳镜承接

## 备注

- 非人生物（怪兽）不适用本人形优化参数，巨兽稳定靠尺度与慢速（条目339巨物战）；人类武者/士兵适用
- H3版15秒上限同样不是动作身份推荐时长，动作段实操仍取短端
- 武侠飘逸风的例外：披风/长袖/长发是设计语言，不能简单"锚死不飘"，要写清飘动的方向与幅度并接受多pass成本——飘逸与稳定靠多次抽卡平衡
