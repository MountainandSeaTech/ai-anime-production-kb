# 匹配剪辑（Match Cut）

## 核心要点
- 两个镜头通过**视觉相似性**连接：形状/运动/色彩/构图
- 相似性让观众的眼睛平滑过渡=跳时间跳空间但不跳注意力
- 最高级的转场：观众意识到"跳了"但觉得"就该这么跳"
- 2001太空漫游：骨头→飞船=影史最强匹配剪辑
- 关联 132 动作匹配、135 承接转场

## 匹配剪辑的 4 大类型

### 1. 形状匹配（Graphic Match）
```
落日圆 → 煎蛋圆
瞳孔 → 月亮
旋转的伞 → 旋转的齿轮
```
- 两个画面中心/构图/轮廓一致=视觉押韵
- 动漫OP大量用：眼球形状→圆形遮挡物过渡

### 2. 运动匹配（Movement Match）
```
A 向右挥拳 → 切 → 门向右被推开
下坠的雨滴 → 下坠的泪滴
旋转倒下的人 → 旋转倒下的塔
```
- 运动方向+速度一致=动能连续
- 与132动作匹配的区别：匹配剪辑跨场景/跨物体

### 3. 色彩匹配（Color Match）
```
血红夕阳 → 红色警示灯
蓝色深海 → 蓝色病房
```
- 色调延续=情绪延续
- 关联 064 色温、066 色块

### 4. 构图匹配（Composition Match）
```
A站在画面左1/3 → 切场景后B也在画面左1/3
中心对称构图 → 中心对称构图
```
- 视线落点不动=观看零成本
- 关联 091 构图、018 构图原则

## 匹配剪辑的叙事功能

### 1. 时间压缩
```
点燃火柴 → 切 → 篝火熊熊（一夜过去）
```
- 关联 139 时间省略

### 2. 隐喻对照
```
屠刀落下 → 切 → 菜刀切菜（暴力的日常化）
孩子奔跑 → 切 → 战马奔腾（天真与毁灭）
```
- 匹配的不只是画面，还有意义
- 库布里克/今敏的核心手法

### 3. 心理转场（今敏流）
```
《未麻的部屋》：钥匙开门 → 另一场景的钥匙开门
同一动作，不同空间=未麻分裂的心理时空
```
- 心理动机优先于物理逻辑
- 匹配剪辑是"梦的语法"——梦里场景就是这么跳的

### 4. 命运回响
```
开头：孩子放走纸飞机
结尾：老人接住纸飞机（同样的构图同样的动作）
```
- 首尾匹配=结构闭环=主题升华
- 关联 080 段落曲线、078 伏笔

## AI视频的匹配剪辑实战

### 提示词写法（形状匹配对）
```
Shot A: "extreme close-up of a full moon, centered, glowing circle on black sky"
Shot B: "extreme close-up of an eye's iris, centered, glowing circle on dark face"
```
- 两镜共享：景别（extreme close-up）+构图（centered）+形状（glowing circle）
- 把这些**共享词**写进两个提示词=AI生成可匹配的画面

### 运动匹配对
```
Shot A: "character spinning clockwise, camera locked"
Shot B: "flower petals spiraling clockwise down, camera locked"
```
- 写清旋转方向（clockwise）——AI方向随机，不写就翻车

### 参数要点
```
构图锁定：中心构图写 centered composition
景别锁定：两个镜头用同一景别词
运动锁定：方向词（leftward/clockwise/rising）
色彩锁定：主色词（golden hour / cold blue）
```

## 模板示例（三连环匹配转场）

```
场景A（战场）→ 场景B（葬礼）→ 场景C（回忆）
分镜1: 剑尖滴血特写（红色垂直下落）
  ↓ 形状+运动匹配
分镜2: 白烛垂泪特写（白色垂直下落，同构图）
  ↓ 色彩匹配（烛火橙→夕阳橙）
分镜3: 夕阳下两人年少背影（暖橙全景）
```
- 血→烛泪→夕阳=从暴力到哀悼到温柔
- 三次匹配完成时空两连跳，观众不觉得断

## 常见坑
- **为匹配而匹配**：形似但意义无关=炫技空洞
- **相似度不够**：形状差30%=观众get不到=白搭
- **匹配点偏离中心**：一个居中一个偏左=眼睛要重新找焦点=卡
- **AI方向随机**：不写clockwise/leftward=50%反向
- **连环匹配过多**：3次以上=审美疲劳+叙事失重

## 进阶
- **声音匹配**：画面匹配+声音延续=双重缝合（关门声跨场景延续）
- **三重匹配**：形状+运动+色彩同时匹配=最强缝合
- **匹配失败表意**：故意做90%匹配最后10%断裂=不安感
- **OP/ED的匹配链**：动漫OP常用5-6连匹配=信息密度+视觉爽感

## 备注
- 匹配剪辑=用相似性缝合时空跳跃
- 四类型：形状/运动/色彩/构图
