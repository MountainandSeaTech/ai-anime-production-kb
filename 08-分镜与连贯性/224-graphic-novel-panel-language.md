# 图像小说画格组合语言

## 核心要点
- **画格组合本身就是视觉语言**——不只是容器，画幅的形状、尺寸、比例、位置都在叙事
- 与电影银幕不同：图像小说可在同一页/同一故事中使用**多种画幅**，甚至打破画格边缘
- **画幅即情绪**：窄=幽闭恐惧，宽=空间感，规则方形=平静，不规则=累感与动作
- **连续两页是整体叙事单元**（漫画国际惯例），画格在跨页中的布局决定节奏
- **锯齿形分界线 = 战斗爆发**；**画中画** = 大场景内嵌次要动作

## 原理：为什么画格不只是"框"

电影银幕画幅从头到尾不变（除非有意切换），而图像小说的画格拥有**无限种可能性**。画幅对比本身就是视觉语言——在一个画格内同时使用不同画幅比例，能创造画幅之间相互对抗的游戏感。观众通过画格的尺寸与比例，在读懂剧情之前就先感受到情绪基调。

## 画幅形状=情绪词典

| 画幅形状 | 情绪 | 典型用途 |
|---|---|---|
| 狭窄垂直画幅 | 幽闭恐惧、窒息 | 迷宫、牢笼、心理压迫 |
| 开放宽画幅 | 空间感、广阔、自由 | 山脉、大海、解放 |
| 规则长方形/正方形 | 淡定、平静、秩序 | 日常对话、铺垫 |
| 不规则/歪斜画幅 | 累感、动作、不稳定 | 打斗、混乱、精神失常 |
| 跨页大画幅（全出血） | 宏伟、震撼、关键瞬间 | 高潮、场景揭示 |

## 画格尺寸与位置强化身临其境感

- 画格尺寸、画幅类型、在页面中所占比例大小，共同**强化身临其境感**
- 核心原则：不要填鸭式地给观众理性信息，而是通过视觉元素将他们**不知不觉地带入规定情境**
- **案例**：
  - 《钢铁之路：公元 1441 年》开场：画格尺寸各有不同但出入不大，所有设计处于克制之中→诡异而寂静的气氛
  - 神庙迷宫：画格变得更加垂直狭窄→强化恐怖迷宫的幽闭感
  - 逃出迷宫后：连绵雄伟的山脉突然占据整整两页→从窒息到广阔的情绪释放

## 锯齿形分界线=战斗爆发

- 当紧张气氛达到顶点、战斗全面爆发时，用**锯齿状分界线**打破之前的规整布局
- 操作逻辑：先铺垫（让垂直与水平画幅尽可能相互呼应，反差降到最低），再用醒目的锯齿形分界线彻底打破铺垫的气氛→战斗打响
- 锯齿分界线本身就是"断裂"的视觉符号=冲突的可视化

## 画中画（大画面内嵌小画格）

- 在一个大场景画面中，以**画中画**形式安置次要动作
- **案例**：山脉大画面的右下角嵌入士兵队伍穿越山脉的小画格——避免士兵动作干扰大画面的整体气氛，同时保留叙事信息
- 画中画 = 主次并置：大画面定基调，小画格推剧情

## 跨页布局的叙事功能

- **机位不变的连续画格**：五个画格中四个是同一镜头的放大/推进版，只有一个切到反应镜头→用尺寸变化而非角度变化制造节奏
- **贯穿页面的纵向画格**：讲述者以垂直画幅由上至下贯穿整页，故事内容以水平画格展开→讲述者成为页面布局的一部分，把所有故事点联系在一起
- **角色眼睛高度对比**：在垂直画幅中，通过两个角色眼睛在画格中所处高度对比，突出权力与征服关系（警长眼睛始终高于逃犯）

## 关键参数 / 模板

| 叙事需求 | 画格策略 |
|---|---|
| 诡异寂静开场 | 尺寸相近的规则画格，克制变化 |
| 幽闭恐惧 | 狭窄垂直画幅，剔除周围多余信息 |
| 广阔释放 | 跨页全出血大画幅 |
| 战斗爆发 | 锯齿形分界线+不规则画幅 |
| 权力关系 | 垂直画幅+角色眼睛高度差 |
| 主次并置 | 大画面+右下角/角落画中画 |
| 节奏推进 | 同一机位的放大/推进画格序列 |

## 对 AI 短剧的落地要点

- **画格大小变化=节奏控制**：AI 分镜时，用画幅尺寸变化替代频繁切角度——同一场景连续几个镜头，可用"中景→近景→特写"的画幅递进制造节奏，比每次换机位更连贯
- **窄画幅拍幽闭**：竖屏短剧天然适合幽闭/压迫场景；提示词用 `narrow vertical framing, claustrophobic, tight on character`，并**减少画面内的环境信息**（只留脸和必要道具）
- **宽画幅拍释放**：从窄画幅突然切到宽画幅=情绪释放；AI 生成时前一镜用 9:16 紧构图，下一镜用 16:9 或 2.39:1 大景观
- **锯齿分界=转场暴力**：用 `zigzag split, jagged dividing line, violent transition` 提示词模拟战斗爆发的断裂感
- **画中画=信息分层**：提示词用 `wide establishing shot with small inset panel of character action in corner`，让 AI 生成带画中画的分镜稿
- **眼睛高度=权力**：拍权力关系时，提示词明确 `character A's eyes positioned much higher than character B's, vertical composition, power dynamic`
- **跨页感=大特写+留白**：AI 视频无法真跨页，但可用"全画面大特写+大量留白"模拟跨页大画幅的震撼感

## 备注
- 图像小说的画格语言是**电影分镜的上游灵感库**——电影受限于固定银幕，漫画不受限，因此漫画在画幅叙事上走得更远
- 画幅变化要有**叙事理由**，不能为变而变；每次画幅切换应对应情绪或时空的硬转折
- 画格尺寸变化是最被低估的节奏工具——比剪辑节奏更先作用于观众潜意识
- 与 191（镜头流动与场景引入）配合：画格布局决定了场景引入的节奏与信息量
- 与 222（非常规构图）互补：漫画画幅的灵活变化正是"方向相悖"问题的终极解法——直接换画幅
