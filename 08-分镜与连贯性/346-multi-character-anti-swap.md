# 大场面人物不漂移④：多人同框身份互换/融合防混

## 核心要点

- **身份互换机理**：模型把同框人物理解成"一个属性袋"（红衣、蓝衣、高、矮……）；一旦像素混合（遮挡、贴身、交叉走过），人物重新出现时模型从属性袋里**重新分配**——于是红衣穿到了另一个人身上，甚至脸互换
- 互换精确发生在**遮挡后重新出现的几帧内**：柱后、拥抱、错身、硝烟/烟雾遮没
- **三级修法**：文字强区分（地板）→ 每角色独立参考实体（2026最强工具内修法）→ 分开生成后期合成（零互换保证）
- 分镜层最高级的防混是**不让危险时刻发生**：固定空间泳道、避免要求角色换位/交叉的调度

## 详细内容

### 一、五病因

1. **逐角色锚定太弱**：只靠文字，遮挡即互换
2. **文字区分度不足**："两个朋友在走"零锚点；"左边高个红衣短发女，右边矮个卷发黄发蓝衣男"才有
3. **参考图两人融合**：同一裁切区内轮廓交叠，模型视为一个实体——参考图必须能给每人画干净包围盒
4. **动作要求换位**：提示词含 switch/cross/pass/exchange（换位、穿过、交错），身份会跟着位置走
5. **时长放大**：双人镜4秒通常安全，10秒互换率大增；多一个身份要维持，漂移窗口更短

### 二、修法阶梯（按成本从低到高）

**修法1：文字强区分（地板，必须做）**
- 每人给齐：位置＋身高＋发色发型＋服装主色＋外套，差异维度≥3
- 提示词首尾各复述一次分配："女在左男在右，全片不换位；红衣始终在女、蓝衣始终在男"
- 删除一切换位动词（switch/cross/pass/exchange/交换/错身）
- 顺序提示：`[角色1：特征] 在画面左，[角色2：特征] 在画面右`

**修法2：每角色独立参考实体（主力方案）**
- Runway Gen-4 References：每人单独上传干净单主体参考，命名 `@woman_red` `@man_blue`，提示词 `@woman_red 在左行走，@man_blue 在右，不换位不换装`
- Kling Elements：每主体1-4张（正/侧/45度提升空间一致性），分别描述各自动作
- Sora 2 类角色实体：单条生成硬上限2人；3人以上必须走合成
- 参考图纪律：单人、光线均匀、主体之间无重叠

**修法3：双人同框首帧锁定**（无分角色tag时的退路）
- 首帧：两人都清晰、剪影差异大（身高/发/衣）、空间干净分离无遮挡、服装强色对比
- 图生视频＋"延续画面，红衣全程在左、蓝衣全程在右，不换位不换装，身份以参考帧为准"
- 单条≤4秒

**修法4：分开生成＋后期合成（零互换保证）**
模型一次只见一个人，物理上无法互换：
1. 分别在同一场景生成A单人、B单人（同机位锁定三脚架、同光位同色调），提示"空场景，无其他人"
2. AE/Resolve 遮罩/抠像分层（绿幕/灰底生成最好抠）
3. 对齐时间线，A下层B上层
4. **每人脚下补接触阴影**——合成穿帮第一在阴影方向，第二在光色不匹配

**修法5：分镜改写，危险时刻不共框**
- 一个双人镜拆成两个单人镜交叉剪辑
- 必须用双人镜时：只取遮挡前的3秒，遮挡后部分丢弃或用别的镜接
- 错身调度改为"先后经过同一地标"（A过柱→切→B过柱），不拍同框交错

### 三、空间泳道（Staging 防混设计）

- **屏幕方向固定**：A全程画面左、B全程画面右，越轴与换位同等危险（对接条目131轴线、186三角机位）
- **纵深分层代替横向交叉**：要换戏剧重心，用一前一后（焦段虚实切换），不要让两人物理穿过彼此
- **遮挡物管理**：大场面的柱、烟、爆炸、人群都是"互换触发器"；必须遮挡时，遮挡前给足身份锚（色+光），重新出现的第一帧立刻给确认特写
- **接触戏**（搀扶、搏斗、拥抱）：互换/融化率最高——优先单人镜对切＋局部特写（手、肩），全身同框接触段≤2秒或直接合成

### 四、群像（3人以上）的身份预算

- 单条生成的"有名有姓"角色≤2；第三人要么是D级群演（无个体特征），要么拆镜/合成
- 三人对峙常用拍法：三人各自单人镜建立＋一个**静态站位全景**（无运动、无遮挡、时间短）＋冲突开始后全部切单人镜
- 战场小队（4-6人）：靠344的色/标志物体系（头巾色、武器形状、身高梯队）＋快速点名式特写轮转，不依赖长群像镜
- 大部队人群镜头：主角按344处理（唯一色块+光/运动引导），其余一律群演，不给模型多个需要保持的身份

### 五、同框QC（遮挡点逐帧 scrub）

1. 在遮挡点（柱子/烟/错身）前后逐帧拖，互换就发生在重现的几帧内
2. 末帧查三项：每人的服装色、发型、屏幕位置是否与首帧一致
3. 同提示词连抽2-3次：身份互换是随机的，一次干净是运气，三次都稳才算修住
4. 合成件查：两层阴影方向、光位、色温、地面接触

## 关键参数 / 模板 / 清单

**多人镜生成前检查**
```
□ 每人独立参考实体已挂载（≤2个有名角色/条）
□ 文字差异维度≥3（位置/身高/发色/服装色/标志物）
□ 提示词首尾复述位置与服装分配
□ 无 switch/cross/pass/换位/错身 类词
□ 空间泳道固定（谁左谁右，全程不变）
□ 调度无遮挡/贴身/交叉（有→改分镜或≤2s或合成）
□ 时长≤4-5s
□ 遮挡点逐帧QC方案已定
```
