# 动作匹配剪辑（Match on Action）

## 核心要点
- 一个动作**从A镜头开始，在B镜头完成**——切换藏在动作中段
- 原理：观众眼睛追踪动作，忽略剪辑点=剪辑消失术
- 静止时切=观众看见切；运动时切=观众只看见动作
- AI分镜最大痛点：两个镜头动作对不上=跳帧感
- 关联 127 战斗关键帧、138 AI多镜头连续

## 原理详解

### 为什么动作切隐形
```
静止画面切换 → 视线无锚点 → 观众注意到画面突变
运动画面切换 → 视线追踪运动物体 → 切换被运动感覆盖
```
- 人眼对运动的注意力 > 对剪辑点的注意力
- 希区柯克/今敏都靠这招做无缝转场

### 切点的黄金位置
```
动作前1/3切开 → 后2/3在新镜头完成
例：挥手动作
  Shot A: 手从静止到挥出（起手）
  切 ↓（在挥动最快的瞬间）
  Shot B: 手继续挥到尽头（收势）
```
- 切在**运动峰值帧**附近最顺（见 127 关键帧）
- 切在动作起点前=迟；切在动作结束后=观众已看完=切感明显

## 动作匹配的 4 种用法

### 1. 同人同景（换角度）
```
角色起身：
  Shot A 正面：弯腰起一半
  切
  Shot B 侧面：继续起直到站直
```
- 最基础用法——一个动作两个角度=景别变化不跳戏

### 2. 同人异时（时间压缩）
```
角色开门：
  Shot A 室内：手伸向门把
  切
  Shot B 室外：门已开，人走出（已跳过开门过程）
```
- 动作匹配允许你省略中间过程=节奏紧凑
- 关联 139 时间省略

### 3. 异人同动（今敏式转场）
```
角色A挥手告别 → 切 → 角色B挥刀劈下（动作同构）
同方向同速度的运动把两场戏缝在一起
```
- 今敏招牌技法：《未麻的部屋》钥匙开门切到另一场景
- 动作即桥梁=空间时间都能跳但画面不跳

### 4. 同动异物（隐喻转场）
```
旋转的硬币倒下 → 切 → 旋转的舞者停驻
形状运动相同，物体不同=诗意转场
```
- 关联 134 匹配剪辑

## AI视频的动作衔接实战

### 痛点
```
Shot A 结尾：手挥到画面中央
Shot B 开头：手却从头顶开始挥
→ 动作跳帧=假
```
- AI每镜独立生成，没有动作记忆

### 解法1：首尾帧接力
```
Shot A 的最后一帧 → 作为 Shot B 的首帧参考图
动作位置/姿态/速度方向强制继承
```
- 关联 138 AI多镜头连续、wan3.0首尾帧功能
- 最可靠的AI动作衔接方案

### 解法2：提示词写动作阶段
```
Shot A: "arm raised halfway up, mid-swing motion, moving leftward"
Shot B: "arm completing the swing, follow-through, momentum continuing leftward"
```
- 显式写"挥到一半"vs"挥完收势"=告诉AI这是同一动作的两段
- 写清楚运动方向（leftward）保持方向一致

### 解法3：重叠生成
```
Shot A 结尾动作做满 → Shot B 从动作稍前处开始
剪辑时取重叠区内的切点=容错空间大
```

## 模板示例（战斗格挡反击）

```
分镜1（特写）：反派刀劈下（刀从顶部劈至中部）
  ↓ 切点：刀速最快的瞬间
分镜2（中景）：主角侧身，刀继续劈空砸地（动作完成）
  ↓ 反派收刀起手
分镜3（特写）：反派手腕翻转蓄力（动作起）
  ↓ 切点：拳头/刀挥出峰值
分镜4（全景）：反派攻击完成，主角已绕到背后（时间压缩）
```
- 每个切点都在动作峰值
- 景别大小交替=动作清晰+信息丰富

## 常见坑
- **静止切静止**：两个静态镜头硬切=最生硬的跳
- **动作相位错位**：A镜头手在3点方向，B镜头手在9点方向=闪帧
- **速度不匹配**：A慢速挥拳B瞬间完成=动作像加速鬼畜
- **方向不匹配**：A向右挥B向左挥=结合131轴线=双重车祸
- **AI省略中间帧**：AI图生视频容易跳相位=用首尾帧强制约束

## 进阶
- **切割即节奏**：快动作配快切（每动作2-3个角度），慢动作一镜到底
- **动作匹配+声音先导**：下一镜的声音先入耳，画面再切=双层缝合（关联137）
- **连续动作链**：3个以上镜头串一个长动作=炫技但费工期，关键场景用
- **假动作匹配**：看似同动作实则换了人/物=今敏式心理转场

## 备注
- 切在动作峰值帧=剪辑点隐形
- 4用法：换角度/时间压缩/异人同动/同动异物
- AI实战首选首尾帧接力
