# 时间省略与压缩

## 核心要点
- 叙事时间 ≠ 现实时间——10秒的镜头可以装下10年
- 省略的前提：观众能**自动补全**被省掉的部分
- 补全条件：给足"时间流逝的信号物"
- 省略失败的标志：观众问"刚才发生了什么/怎么突然这样了"
- 关联 132 动作匹配、134 匹配剪辑、135 因果链

## 时间压缩的 5 级刻度

### Lv1 微省略（秒级）
```
动作匹配压缩：伸手→（省开门过程）→人已出门
```
- 用132动作匹配遮盖=观众无感

### Lv2 场景内省略（分钟级）
```
同场景跳切：对话中段→沉默→人已散去
信号物：烟头变多/茶水变凉/光线移动
```

### Lv3 日夜压缩（小时级）
```
信号物：光影角度变化/太阳位置/钟表/窗色
经典：窗前人物不动，光线从金到蓝=一下午
```

### Lv4 蒙太奇压缩（天-月级）
```
训练蒙太奇：摔倒→再摔→站稳→出拳
配音乐节奏=《洛奇》公式
```

### Lv5 年代跳跃（年级）
```
信号物：字幕"十年后"/容貌变化/物是人非的空镜对照
用134匹配剪辑缝合（童年扔纸飞机→成年接文件）
```

## 时间信号物清单

### 光影系
```
日影移动/天色变化/灯光亮起/蜡烛烧短
```

### 物件系
```
日历翻页/植物生长/食物腐败/酒瓶装空/衣服换季
```

### 环境系
```
雨停/雪化/工地建成/树叶落尽
```

### 人体系
```
伤痕愈合/胡须变长/发型变化/体态佝偻
```
- AI生成时：信号物必须在提示词里显式指定（"bandage now healed scar"）

## 省略的安全法则

### 法则1：省略结果可推断
```
省掉"上楼过程"→观众能推断（楼梯在门口）
省掉"如何学会绝招"→观众不能推断→必须给蒙太奇或台词交代
```
- 可推断性测试：观众问不问"怎么做到的？"

### 法则2：省略前后状态对比明确
```
省略前：菜鸟被吊打（明确弱）
省略后：反杀师父（明确强）
中间可省——因为两端状态差本身就讲了成长故事
```

### 法则3：大跳跃需要仪式感
```
秒级省略：一个动作匹配就够
年级省略：需要匹配剪辑/音乐蒙太奇/空镜组=仪式感段落
```
- 跳跃越大，缝合材料越厚

## AI短剧的时间压缩实战

### AI的优势
```
AI生成"时间信号物"成本极低：
  同构图两张图：窗前人白天版/夜晚版 → 直接表现时间流逝
  角色状态卡：受伤版/痊愈版 → 省掉恢复期
```

### 提示词对（时间压缩专用）
```
Shot A: "same character by the window, morning golden light, bandaged arm"
Shot B: "same character by the window, evening blue light, scar healed, arm free"
```
- "same"+"状态差"=AI时间压缩公式
- 配137的L-cut音乐延续=无痕跳跃

## 模板示例（修炼压缩段落）

```
镜1: 瀑布下打坐，春日樱花飘落（信号：樱花）
镜2: 同构图，夏日蝉鸣光影（信号：浓绿+强顶光）
镜3: 同构图，秋日红叶（信号：红叶）
镜4: 同构图，冬雪覆肩，人不动如山（信号：雪+呼吸白雾）
镜5: 睁眼特写——眼神已完全不同
```
- 4个同构图季节镜头=一年压缩成8秒
- 人物姿态不变+环境四季轮转=以静写动

## 常见坑
- **无信号物跳跃**：时间变了但画面没线索=观众以为同一场
- **信号物矛盾**：白天出门，下个镜头白天到家（路程2小时）=时间感崩
- **省略关键变化**：性格转变无过渡=人设跳戏（成长必须有1-2个中间态）
- **AI状态倒退**：镜3的伤比镜2轻=AI状态锚没写好（关联138）
- **蒙太奇无节奏**：4个镜头时长平均=流水账，应渐快（蓄积感）

## 进阶
- **时间错位的叙事**：先给结果再补过程（关联081时间错位张力）
- **压缩中的膨胀**：大省略中突然一个实时长镜头=那个瞬间被强调
- **并行时间**：两条时间线交替压缩=对比结构（A在苦练/B在腐化）
- **信号物变奏**：同一信号物反复出现且渐变（树苗→大树）=编年史骨架
