# 大场面人物不漂移①：角色漂移六病因与锁定体系

## 核心要点

- **漂移机理**：视频模型没有"身份跟踪器"，它逐帧从前一帧去噪生成，小误差帧帧累积——**镜头越长、运动越大、脸越侧/越遮挡，漂移越狠**。到第5个镜头，人已经换了一个
- **最大杠杆（2026模型共识）**：不要指望提示词"记住"角色，用模型自带的角色参考功能绑定**唯一一张正典参考图/一个命名角色实体**；仅这一条即可消除约60-70%的跨镜漂移
- **首帧≠身份锁**：首帧图只锚第1帧，整片仍会漂；必须用全片持续生效的角色实体（Runway @tag / Kling Elements / Veo Ingredients 类机制）
- **大场面放大一切漂移因子**：远景脸小、运动快、群像遮挡多——所以大场面要在普通一致性纪律上**再加码**，见344-346

## 详细内容

### 一、漂移六病因（按命中率排序）

| # | 病因 | 典型症状 |
|---|---|---|
| 1 | 单次生成超出模型"一致性窗口" | 第2秒脸对、第5秒后开始变 |
| 2 | 纯文生视频、无任何参考 | 每次去噪现编一张脸 |
| 3 | **每镜用不同参考图**（哪怕重新生成"同一个人"） | 单片内像、跨片是两个人；90%相似的再生成会逐片复合误差 |
| 4 | 运动强度过高 | 漂移恰好发生在奔跑、快运镜、大手势时 |
| 5 | 正侧脸/局部遮挡 | 转头、走过前景物体、极端角度时脸变；偏角/模糊参考可使一致性掉约30% |
| 6 | 老模型或没用角色功能 | 开了角色功能就稳、不开就漂 |

### 二、唯一正典参考体系（Canonical Reference）

**建实体流程**
1. 先生成/选定**唯一一张**高质量正典：正面中性表情、均匀光、≥1024×1024、清晰无动态模糊无极端角度
2. 命名存档（如 `角色A_REFERENCE.png`），**全项目永不再生第二张"差不多的"**
3. 注册进工具的**角色库/实体系统**（不是一次性传图）：
   - Runway Gen-4/4.5 → References，上传打 tag（如 @yan），提示词用 @yan 调用，tag 跨会话保留，官方称单张好参考约95%一致性
   - Kling 3.0 → Elements / Subject Library（Bind Subject），可传最多4张多角度（正/3/4左/3/4右/背）或3-8秒角色视频；多角度让模型在转头时能重建脸
   - Veo 3.1 → Ingredients to Video，最多3张（角色/场景/风格）
   - Luma → Ray3（Ray3.14 砍了角色参考，只用于一次性空镜）
4. 每个镜头调用**同一个实体**，禁止"给第二镜再生成一张相似参考"

**本项目落地映射（即开资产包流程）**
- 半身定妆主图＝正典脸参考；全身定妆图＝身材/穿搭/比例第二参考（与项目既有"定妆+全身"双图口径完全一致）
- 三视图＝Kling 类多角度参考的素材；表情组只用于表情参考，不可当身份参考混用
- 视频段生成：图生视频时正典实体必须实际挂载，提示词里重复外貌描述**不能替代**参考绑定

### 三、时长纪律：一切在一致性窗口内生成

各模型单次生成的实用稳定窗（2026年中口径，随版本变，以实测为准）：
- 角色动作戏取短端：5秒级最稳（Kling 3.0 可选3-15s，动作用短端）
- 长序列＝**一镜一生成再剪辑拼接**，不靠一次长渲染
- **Wan 3.0（本项目主用）**：单段≤30s 是上限不是推荐——人物特写/动作身份段实际应切更短（5-10s级），30s 段留给风景、氛围、人物占比小的镜头
- 策略：把叙事拆成短镜，每镜拉同一角色实体，后期拼接

### 四、运动档位与取景纪律

- 运动强度降一档：剧烈→中等（高运动＝每帧更大去噪偏差）；高运动预算留给不露脸的B-roll/环境镜头
- 角色镜头取景：脸尽量朝向镜头（忌全侧）、不要快速甩头、不要走过大型前景遮挡物、半身/中近景让脸占够画面
- 剧本必须的侧脸/遮挡镜头：压到2秒以内，或用剪影/过肩等"不需要脸"的拍法（对接344）

### 五、镜头级QC（漂移防扩散）

每生成一条立刻做：
1. 截第1帧和最后1帧并排
2. 一眼读不出是同一人→重生，**绝不带着已知漂移条进下一条**
3. 跨条抽检：第1条和第5条也要对得上（防跨镜复合漂移）
4. 静态对、动起来不对＝病因4（运动）不是病因2（参考），别改错方向

### 六、大场面专项预检（本系列总纲）

进入大场面段落前确认：
- 每个会露脸/被跟随的角色都已建唯一正典实体
- 分镜表已标注每镜的"身份依赖等级"（正脸识别／轮廓即可／纯群演），见344
- 高运动镜头已排定"无脸拍法"备选（345）
- 同框角色色板/站位方案已定（346）
- 每镜首尾帧QC已排进生成流程
