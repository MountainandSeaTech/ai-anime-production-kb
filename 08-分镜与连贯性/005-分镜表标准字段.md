# 动漫短剧分镜表标准字段

## 核心要点
- 分镜表是 AI 视频生成的「任务清单」，每镜一行，字段决定生成参数
- 字段越完整，生成越可复现，团队协作/返工成本越低
- 推荐用 Markdown 表格或 CSV，便于脚本批量处理

## 标准字段

| 字段 | 说明 | 示例 |
|---|---|---|
| 镜号 | 唯一编号，集内自增 | S01E02-007 |
| 时长 | 该镜秒数 | 5s |
| 镜头 | 镜头运动词 | slow dolly in |
| 构图 | 景别 + 角度 | 中景正面，微仰 |
| 角色 | 入镜角色 | 雪菜（白发少女） |
| 动作 | 主体动作 | 居合站姿 → 出刀瞬间 |
| 场景 | 环境 | 月光中庭 |
| 光照 | 光线氛围 | 逆光，蓝月光 |
| 风格 | 视觉风格 | 赛璐璐，高对比 |
| 首帧 | 角色卡切片路径 | refs/雪菜/正面持刀.png |
| 提示词 | 完整生成 prompt | slow dolly in, white hair anime girl... |
| seed | 固定 seed | 123456 |
| 负面词 | negative prompt | no morph, no extra fingers |
| 模型 | 生成工具 | runway-gen3 / kling-pro |
| 音频 | 配音/BGM/音效 | SE刀出鞘 + BGM低音 |
| 衔接 | 前后镜衔接方式 | 硬切 / 叠化 |
| 备注 | 踩坑/特殊要求 | 注意出刀后定格0.5s |

## 模板（Markdown 表格）
```markdown
| 镜号 | 时长 | 镜头 | 角色 | 动作 | 首帧 | 提示词 | seed | 音频 |
|---|---|---|---|---|---|---|---|---|
| S01-001 | 5s | static | 雪菜 | 居合站姿 | refs/雪菜/正面持刀.png | static shot, white hair anime girl iaido stance, moonlit courtyard, cel-shaded | 123456 | BGM入 |
```

## 编写流程
1. 剧本定稿 → 拆段 → 段内拆镜
2. 每镜填字段，先填镜头/角色/动作/首帧四项必填
3. 提示词从 [镜头运动词库](003) 取词 + 角色描述 + 场景描述拼接
4. seed 留空，首跑后填入复现
5. 音频/衔接最后补，剪辑阶段对齐

## 一集典型规模
- 90秒短剧：18-25 镜，每镜 3-5s
- 60秒短剧：12-16 镜
- 打戏段：每秒 1-2 镜切碎，硬切为主

## 备注
- 分镜表本身就是 AI 视频生成的「批处理清单」，写完即可逐镜生成
- 镜号带集前缀，避免多集混淆
- 首帧字段强制要求路径，逼自己先把角色卡出好
