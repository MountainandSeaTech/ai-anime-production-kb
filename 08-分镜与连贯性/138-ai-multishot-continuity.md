# AI多镜头连续性（锚点接力工作流）

## 核心要点
- AI每镜独立生成=金鱼记忆——**上一镜的一切默认丢失**
- 连续性的本质：把上一镜的**状态**显式搬运到下一镜
- 三类锚点：**视觉锚（首尾帧/参考图）+ 文本锚（状态词）+ 结构锚（分镜表）**
- 多镜头AI视频活的不是单镜质量，是**接力质量**
- 关联 113 风格锁定、119 参考图、150 图生视频链路

## 三类锚点详解

### 1. 视觉锚（最强）
```
镜头A的最后一帧 → 导出 → 作为镜头B的首帧/参考图
```
- 位置/姿态/服装/光线全部强制继承
- 适用：图生视频模型（wan系/可灵/Vidu都支持首尾帧）
- 注意：接力处构图完全相同时，用"相近但不同构图"避免静态感

### 2. 文本锚（状态词复写）
```
镜头A关键状态 → 提取成词 → 写进镜头B提示词开头：
"same silver-haired swordsman, torn blue coat, bleeding left arm,
 holding broken katana, standing in rain-soaked shrine"
```
- 状态词清单：
  - 角色锚：发型/服装/伤情/手持物
  - 情绪锚：表情状态（grim/tearful）
  - 环境锚：天气/时间/光线（rain-soaked/sunset）
  - 位置锚：画面方位（on frame left facing right）
- 关联 113 风格锁定（风格词也是每镜复写）

### 3. 结构锚（分镜表）
```
分镜表每行必备列：
  | 镜号 | 内容 | 入口状态 | 出口状态 | 锚点类型 |
  | 03   | 拔剑 | 断剑在鞘 | 剑已出鞘 | 首尾帧接力 |
```
- 入口状态=承接上镜出口状态
- 填不出来=这镜会断

## 接力工作流（实操）

### 流程
```
1. 分镜表先行：写清每镜入口/出口状态（关联135因果链）
2. 镜头A生成 → 导出最后一帧
3. 镜头B：用A的尾帧做首帧 + 文本锚写新动作
4. 检查B的中段是否漂移（AI常在接力后3秒开始跑偏）
5. 漂移则：降低B的运动幅度/缩短时长/重抽
6. 剪辑时对齐动作相位（关联132动作匹配）
```

### 接力点构图选择
```
方案1（完全同构图）：A尾帧=B首帧
  优：无缝  缺：镜头无变化感
方案2（同位置异构图）：角色位置同，景别/角度变
  优：有镜头感  缺：需要抽卡匹配位置
方案3（动线接力）：A出画方向=B入画方向（关联136）
  优：动感最强  缺：需要两镜各自生成后拼接
```

## 连续性的 5 个层级（从易到难）

```
Lv1 风格连续：统一风格词+种子（最容易，113解决）
Lv2 角色连续：参考图/LoRA/角色锚词（03角色与表演专题）
Lv3 空间连续：方位词+轴线（131解决）
Lv4 动作连续：首尾帧接力+动作相位（本条+132）
Lv5 叙事连续：因果链+状态接力（135+本条）
```
- 观众对断裂的容忍度：风格<角色<空间<动作<叙事
- 即：叙事断了最难被原谅

## 模板示例（5镜头连续场景）

```
场景：剑士走入神社→发现敌人→拔刀

镜1: 远景，雨夜神社，剑士从右入画
  出口状态：剑士在画面中央，面朝左
镜2: 中景（镜1尾帧局部放大做参考），剑士走近，雨打肩甲
  入口锚：镜1尾帧+方位词"character center frame facing left"
  出口状态：剑士停步，头微抬
镜3: 特写，剑士眼神——瞳孔映出火把光
  入口锚：情绪词"alert, eyes sharp"+光线锚"torchlight reflection"
  出口状态：视线锁定画面左
镜4: 反打（守131轴），敌人在鸟居下（镜3视线匹配）
  入口锚：空间词"opposite side, torii gate backdrop"
  出口状态：敌人拔刀
镜5: 回到剑士，拔刀（动线接力：与敌人同动作）
  入口锚：动作匹配词"mirroring motion, drawing sword"
```
- 5镜用了4种锚点：尾帧/情绪/视线/动作匹配

## 常见坑
- **只锁风格不锁状态**：风格统一但伤口消失/武器变形=穿帮
- **接力链过长**：首尾帧接力超过3-4棒=画质逐代劣化（重抽中间帧重锚）
- **尾帧质量差**：A的尾帧崩了，B继承崩坏=先修尾帧再接力
- **文本锚不全**：只写角色不写环境=场景光线跳变
- **忽视中段漂移**：首尾帧对了但中段角色换脸=分段生成或缩短单镜时长

## 进阶
- **双锚校准**：首帧+尾帧都锁定（wan3.0首尾帧功能）=走廊式约束
- **锚点素材库**：建立"角色状态卡"图库（不同伤情/服装/表情），随取随用
- **漂移预算**：动作幅度大的镜头给短时长（2-3秒）=漂移来不及发生
- **跨镜粒子延续**：雨/雪/火星在提示词中保持同方向同密度=隐性连续

## 备注
- AI没有记忆——你当它的记忆
- 三锚点：视觉（首尾帧）/文本（状态词）/结构（分镜表）
- 连续性5层级，叙事连续最重要
- 关联：132 动作匹配、135 因果链、150 图生视频避坑、140 自检清单
