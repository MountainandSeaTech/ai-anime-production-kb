# 张力定义与构成要素

## 核心要点
- **张力 = 观众对"即将发生却尚未发生"的预期紧张感**，不是动作本身，而是动作前的悬念
- 动得越多≠张力越强；真正制造张力的是"延迟释放"和"代价悬而未决"
- 五要素：威胁源 / 不确定性 / 延迟释放 / 信息差 / 代价
- 动漫短剧里张力最浓的三个时刻：对峙前静止、爆发前摇、胜负未分时

## 五要素拆解

| 要素 | 含义 | 动漫短剧里的体现 |
|---|---|---|
| 威胁源 | 有明确的危险/对手/后果可能 | 拔刀的敌人、倒计时的爆炸、追兵逼近 |
| 不确定性 | 结果不可预测 | 谁先动？这一刀中不中？他会反击吗？ |
| 延迟释放 | 该发生的事迟迟不发生 | 刀出鞘前那 0.5 秒、举手要打却停住 |
| 信息差 | 观众/角色知道的不一样 | 观众看到暗器，主角没看到 |
| 代价 | 失败的后果严重 | 输了就死、暴露就全灭 |

> 五要素齐全 = 张力峰值；缺一两个 = 张力普通；全无 = 平淡。

## 怎么用五要素自检
写完一段分镜，逐项问：
1. 这段的威胁源是谁？观众清楚吗？
2. 结果能预测吗？（能预测＝张力减半，立刻改）
3. 该爆发的事被延迟了吗？延迟多久合理？
4. 观众和角色信息是否不对称？能否制造一个？
5. 失败代价够不够重？不够就加码。

## 常见反例（张力杀手）
- 角色一出场就打，没有对峙 → 缺威胁延迟
- 全程旁白解说意图 → 杀死不确定性
- 主角无敌 → 代价为零，观众不紧张
- 镜头切太碎太快 → 不给延迟蓄力的时间

## 备注
- 本条是后续 29 条张力课的总纲，五要素会反复出现
- 张力不是"刺激感"，是"揪心感"——刺激是炸了，揪心是还没炸
- 动漫短剧 15-60 秒体量，每段只够承载 1 个主张力点，别贪多
