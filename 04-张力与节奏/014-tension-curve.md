# 张力曲线：Build-up / Peak / Release

## 核心要点
- 一段张力戏必有**三段曲线**：蓄势（build-up）→ 峰值（peak）→ 释放（release）
- 黄金比例约 **6 : 1 : 3**——蓄势最长，峰值最短，释放留余韵
- 新手通病：蓄势太短就爆发（没燃料）、峰值拖太长（峰值一拉长就泄）、释放省略（没余韵）

## 三段详解

### Build-up 蓄势（占 60% 时长）
任务：铺垫威胁、延迟、代价，把观众预期拧到最高
- 手段：静止对峙、呼吸/手部细节、慢推进、BGM 低频堆积、信息差暗示
- 时长参考：动漫短剧 2-5 秒
- 忌：蓄势里塞动作（一动作就提前泄了）

### Peak 峰值（占 10% 时长，最短）
任务：爆发瞬间，把累积的预期一次性释放
- 手段：出刀、开枪、爆炸、表情剧变——一帧/0.3-0.5 秒
- 时长参考：0.3-1 秒，越短越狠
- 忌：峰值给 2 秒以上 → 变成动作展示而非张力释放

### Release 释放（占 30% 时长）
任务：余韵、收束、给观众喘息和回味
- 手段：定格、收刀、慢拉远、静默、BGM 余音
- 时长参考：1-3 秒
- 忌：直接切走没释放 → 像被掐断，观众不适

## 曲线形态库

| 形态 | 特征 | 适用 |
|---|---|---|
| 尖峰型 | 蓄长峰短释中 | 居合一击、惊吓点 |
| 双峰型 | 蓄-峰-小蓄-峰-释 | 两回合对战 |
| 阶梯型 | 蓄势逐级加压到末峰 | 倒计时、逼近 |
| 长尾型 | 蓄-峰-超长释 | 悲剧收场、决别 |

## 6:1:3 的实操校准
以 5 秒段落为例：
- 蓄势 3 秒（对峙/慢推/呼吸）
- 峰值 0.5 秒（出刀瞬间）
- 释放 1.5 秒（收刀/定格/拉远）

比例可调：要更狠 → 蓄加长峰缩短；要更悲 → 释放加长。

## AI 生成分镜映射
- 蓄势镜：static + slow dolly in，主体微动
- 峰值镜：升格 slow motion 或快切特写
- 释放镜：static + slow pull back，或定格帧

## 备注
- 这条是 30 条张力课的"时间骨架"，所有镜头/动作/剪辑课都挂在这三段上
- 一条动漫短剧（15-60s）通常承载 1-2 条完整张力曲线，别贪多
- 峰值一定要"短"——短就是力量，长就是泄气

## WAN3.0 校准（2026-10-20）
30 秒段落张力曲线方案：蓄 18s / 峰 3s / 释 9s
