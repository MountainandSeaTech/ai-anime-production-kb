# 冲击帧时机学——命中帧·蓄力峰值·情绪爆点

## 核心要点

冲击帧的生命在**帧位**——早一帧是预告，晚一帧是回响，只有卡在"接触成立"的那一帧才是冲击

## 详细内容

### 三大类合法时机
| 时机 | 帧位定义 | 例子 |
|---|---|---|
| 命中帧 | 武器/拳脚与目标**接触成立**的那一帧（不是挥动中，不是穿透后） | 拳头贴到脸颊变形的瞬间 |
| 蓄力峰值 | 蓄力动作张力最大的极点（收束到极限即将反弹之帧） | 拉弓满弦、居合拔刀前一瞬 |
| 情绪爆点 | 角色情绪/剧情信息"击穿"观众的瞬间 | 真相揭示、角色崩溃、反转成立 |

### 帧位校准法（剪辑实操）
1. 先找到接触帧：逐帧走，找到"两物体首次接触"帧C
2. 冲击帧放C或C+1——C+1（接触后一帧）通常更"脆"，C更"实"
3. 反例：放在挥动中段（C-3）＝打击落空感；放在飞散后（C+5）＝打的是空气

### 与顿帧的时序关系（联用公式）
```
接触帧C：冲击帧（1-2帧画面断裂）
C之后：顿帧冻结（2-10帧时间冻结，见297）
冻结结束：受力反馈（倒飞/形变/环境破坏）
```
冲击帧管"画面"，顿帧管"时间"——一个撕画面一个停时钟，叠加才是完整的"打击感"

## 关键参数 / 模板 / 清单

**时机自检**：把镜头逐帧播放，问"冲击帧是否正好落在接触成立的帧"——错位超过2帧即返工
