# 冲突·赌注·张力

## 核心要点

- **冲突 ≠ 张力**：冲突是"双方目标相撞"（客观事件），张力是"观众预知后果却无力干预"（主观感受）。怪物砸门是冲突，观众知道门后有睡着的孩子、守城兵不知道——才是张力
- **冲突要分层叠加**：人vs人最好写但最薄；人vs自我最难演但最深。最强的戏永远是"外部对手逼他做选择，内部缺陷同时发作"
- **赌注要双向抬高**：成功的奖品加码、失败的代价也加码，最好同时进行；且代价必须先让观众看见一次（小预演），后续威胁才有分量
- **希区柯克炸弹定律**：突然爆炸给观众15秒惊吓；让观众先看见桌下的炸弹、角色不知道，给15分钟煎熬

## 详细内容

### 一、冲突五型（按从外到内排）

| 类型 | 本质 | 典型 |
|---|---|---|
| 人vs人 | 两个都合理的目标相撞 | 侦探要真相，市长要体面头条——双方都不是恶人 |
| 人vs自然/环境 | 生存资源与物理规则 | 兽潮、暴雪、缺氧、坍塌的城 |
| 人vs社会/体制 | 个人对抗系统性规则 | 逃兵令、献祭传统、官僚否决增援 |
| 人vs命运/处境 | 被扔进非自选的困境 | 征召入伍、巨兽恰好在他值班时登陆 |
| 人vs自我 | 现有的我 vs 必须成为的我 | 缺陷与需要的内战（见条目335） |

**叠加公式（攻城战适用）**：
老兵岩骨同时承受：人vs巨兽（守住墙）＋人vs体制（预备队申请被否决）＋人vs自我（幽灵逼他不敢再做决策）。三线在终局拧成同一个选择，戏剧密度翻三倍。

### 二、让冲突成立的三个条件

1. **双方都想要、且都有合理理由**——反派如果只是坏，冲突就塌；让他的逻辑在他视角里完全成立
2. **目标不可调和且只能当场碰撞**——不能靠一方走开解决；用空间/时间/责任把人焊死在场
3. **冲突对接观众在乎的东西**——声誉、安全、爱、金钱、身份；抽象的"正义"要落到具体损失（墙破了死的是今早给他递水的那个孩子）

### 三、赌注（Stakes）工程

四层赌注，由实到虚，至少占两层：
1. **生存赌注**：会死（最基础，只有这层会疲劳）
2. **关系赌注**：会失去谁（战友、信任、被原谅的资格）
3. **身份赌注**：会变成什么样的人（懦夫？再一次开闸的屠夫？）
4. **世界赌注**：失败的意义外溢（全城、后人、某种活法的存废）

**抬高赌注的手法**：
- 奖赏与代价同时加码（救兵到了，但只够守一门，选哪门？）
- **先付小额代价做预演**：巨兽第一波攻城先死一个有名字的角色，后面"城破会死很多人"才不再是抽象台词
- 缩窄退路：桥断了、通讯没了、援军日期从三天变永不
- 把"公共危机"私人化：百万难民是数字，护城河里漂浮的那只童鞋是刀子

### 四、希区柯克炸弹：信息差制造悬念

- **惊讶（surprise）**：观众和角色同时发现炸弹——15秒
- **悬念（suspense）**：观众先看见炸弹，角色不知道——15分钟
- 三种信息差配置：
  1. 观众＞角色：观众知情、角色无知（经典悬念，观众想喊"快跑"）
  2. 角色＞观众：角色藏着秘密、观众被吊胃口（悬疑类型）
  3. 观众＝角色、角色之间不等：观众跟随主角，但配角在撒谎（谍战/狼人杀张力）

**AI视频特别提示**：分镜可以给观众"上帝视角插入镜头"（墙基裂缝渗水、巨兽腹下亮起的孵化红光），主角们仍在按旧情报行动——一个空镜完成希区柯克炸弹的布设。

### 五、倒计时（Ticking Clock）七种形态

不只是数字读秒，任何**随时间恶化**的东西都是钟：
1. 字面钟：炸弹、洪水水位、援军到达时间
2. 生理钟：失血、感染、氧气管读数、体力（念师每用一次能力失声加重）
3. 机会窗：巨兽静默领域两次展开的间隙、潮汐、天亮
4. 关系钟：耐心耗尽（"我最后一次帮你"）、信任流失
5. 连锁钟：A门只能再撑X次冲击，破了B门腹背受敌
6. 心理钟：记忆/理智（白泽每次共感都在被污染，倒计时是他人性）
7. 假钟与翻盘：钟被拆除的瞬间发现真钟在别处（慎用，一次为限）

**使用纪律**：钟必须被看见走动（插水位上涨/手表/能力恶化的镜头），不被看见的钟不存在；钟最好压在两难选择上——时间到必须选，而不是时间到就结束。

### 六、张力的呼吸：不能一直拉满

- 持续高强度＝没有强度。在两次升级之间必须给**泄压阀**：一句苦中作乐、一个仪式性小动作（老兵把女儿的照片塞回内袋）
- 泄压不是泄气：好的放松场景本身埋新雷（说笑的人下一波战死）
- 张弛节奏参考：紧张-稍缓-更紧-假安全-击穿（假安全段越日常，击穿越狠）

## 关键参数 / 模板 / 清单

**冲突-赌注体检表**
```
□ 本场冲突双方各自想要什么？写得出两句话吗？
□ 双方理由在各自视角里都合理吗？
□ 冲突占了几层（人/环境/体制/自我）？
□ 失败的具体后果是什么？有"小额预演"让观众信吗？
□ 赌注四层里占了几层？只有生存层？
□ 有没有观众比角色多知道的信息？用哪个镜头让观众看见？
□ 倒计时是什么形态？观众看得见它走动吗？
□ 上一次泄压在第几场？是不是连了三场高强度？
```
