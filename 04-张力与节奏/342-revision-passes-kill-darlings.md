# 改写与节奏诊断

## 核心要点

- **顺序大于努力**：第二幕还塌着就打磨第一页台词＝把废墟擦干净。修订必须分层：结构→人物→场景/对白节奏→连贯→精修
- **第一遍通读只读不改**：边读边改是在用"勤快"逃避结构决策；读完列问题清单，再按层动手
- **Kill your darlings**：考验标准从来不是"我喜不喜欢"，是"这场戏挣到它的位置了吗"。观众看不见你删了什么，只感觉得到节奏
- **删掉的戏进废料文件，不删出硬盘**——心理上更容易下手，且素材常能在下个项目复活

## 详细内容

### 一、六遍修订法（Draft 2 标准流程）

| Pass | 只问 | 产出 |
|---|---|---|
| 1 结构 | 故事成立吗？Want/障碍清楚吗？催化剂够早吗？中点真的翻盘了吗？高潮还了铺垫的债吗？有没有功能重复的场？有没有"必须发生却没发生"的缺口？ | 增删调序场景，纸面更新大纲；不管文字好坏 |
| 2 人物 | 是主角在驱动故事还是事情只在发生在他身上？选择符合他的Want和缺陷吗？反派有真实立场吗？配角有功能吗？动机写在纸上了还是只在你脑子里？ | 磨利欲望/反应/赌注 |
| 3 场景与对白 | 每句台词都在干活吗？有没有重复动作/潜台词已表达的信息？能不能更晚进、更早出？整场删掉故事还成立吗？ | 紧场景、删说明、快节奏；**杀宠儿在这一遍执行** |
| 4 连贯 | 时间线、伤口、道具、称呼、空间方向是否前后一致？（对接KB条目131-140、铁律④资产审计） | 连贯性修复 |
| 5 精修 | 感官细节、文字节奏、格式 | 终稿质感 |
| 6 冷读 | 隔至少48小时，像陌生人一样读；或请信任读者读 | 下一轮问题清单或锁定 |

**铁律**：不许跳级；不必一次坐完，但必须按顺序。

### 二、杀死宠儿：判定与操作

一场戏/一句台词满足任一条即判删：
- 删掉后后续没有任何一场不成立
- 它只重复了另一处的功能/情绪
- 留着它的唯一理由是"我喜欢这段"（聪明/美/酷）
- 它为了一句金句而存在（把金句搬走，场删掉）

操作：剪切进 `scrap废料文件.md`，标注原项目与日期，从正稿移除。
**特别警惕**：你最想给朋友看的那段，往往就是该删的那段。

### 三、节奏诊断（观众为什么走神）

症状→病灶速查：
| 症状 | 最可能的病灶 | 修法 |
|---|---|---|
| 开场10秒入不了戏 | 催化剂太晚/铺垫先行 | 开场即事件，设定后补（条目338） |
| 中段疲软 | 只有中点没有Pinch/没有倒计时 | 补施压点、挂钟（条目333/337） |
| 每场都"还行"但整体平 | 赌注没分层、没有净变化 | 四层赌注盘点；场景变化体检（条目334/337） |
| 高潮不燃 | 结局不靠人物弧光达成 | 回Pass1补铺垫，结局常常自动修好 |
| 感觉拖但说不清哪拖 | 场景头尾过长 | 晚进早出，砍入场寒暄与收场余烬 |
| 动作戏看累了 | 强度无呼吸/招式同质 | 泄压阀＋变速＋一击一结果（条目337/339） |
| 信息看不懂 | 不是观众笨，是投放错位 | 检查"好奇先于答案"顺序（条目338） |

### 四、篇幅即节奏（Page Space）

- 剧本里**时间＝空间**：密集长段读起来慢，短促留白的行读起来快
- 动作戏：短段落、短行、大量留白，纸面上就要让人喘不上气
- 情感时刻：允许句子放慢、拉长
- 视频化对应：快剪段每镜≤2-3秒信息密度高；情绪点给足停留时长。**文字排版的疏密与成片剪辑的疏密同构**

### 五、诊断记录的正确写法

- 通读时只记位置+病灶，不写方案："40页结构问题"，不要在第40页就地重写
- 收到反馈先归类：这是结构问题、人物问题还是执行问题？在哪层发现就在哪层修
- 典型误诊：读者说"不在乎主角"就加前史——真正的病往往是他Want不够具体或没做过艰难选择；**前史是支撑，不是创可贴**

### 六、什么时候停（防止改写到死）

- 笔记不再带来新信息，修的问题开始重复，自己读到烦——不是稿子要更好，是你在制造"不同"而非"更好"
- Draft 2 不是 Draft 20。锁住，开下一个项目，手艺在新项目里涨
- 锁定的客观标准：结构/人物/场景三张pass表全部能打勾，剩下的都是口味分歧而非错误

## 关键参数 / 模板 / 清单

**修订总检表（过一遍锁一稿）**
```
Pass1 □ 催化剂在前10-15% □ 中点真翻盘 □ 75%谷底≠中点坏消息
      □ 高潮由弧光提供解法 □ 无功能重复场 □ 无因果缺口
Pass2 □ 主角主动驱动 □ 每场选择可追溯到Want/缺陷
      □ 反派有自洽立场 □ 每个有名配角有功能
Pass3 □ 每场通过"删除测试" □ 晚进早出 □ 无直说病台词
      □ 金句≤配额 □ 宠儿已处置
Pass4 □ 时间/伤口/道具/称谓/方向连贯 □ 资产逐镜核对
Pass5 □ 每段有主感官 □ 无紫散文 □ 疏密节奏匹配情绪
```
