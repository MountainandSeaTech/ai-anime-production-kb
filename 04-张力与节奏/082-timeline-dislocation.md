# 时间线错位张力

## 核心要点
- 时间线错位=**闪回/闪前打乱顺序**——观众拼时间=认知峰
- 错位揭示=时间反转=051 反转的"时间版"
- 与 081 POV 切换同属"叙事结构工具"
- 核心：让观众"拼"时间顺序=参与感=揪心

## 时间线错位的张力来源

### 1. 拼时间=参与感
- 错位让观众主动拼顺序=参与=投入
- 比"按顺序讲"更揪心——观众"自己懂"

### 2. 错位揭示=反转
- 时间错位让观众以为 A 在 B 前，揭 B 在 A 前=时间反转=峰
- 是 051 反转的变体

### 3. 闪前=钩子（076）
- 开篇闪前高潮=钩子
- 闪前是错位的最常用形式

## 时间线错位的形式

### 1. 闪前（flash-forward）
- 先放高潮/结果，再回过程
- 闪前=钩子（076）
```
高潮结果（0.5s，闪前钩）→ 切正文过程（2s）→ 呼应高潮（0.5s，峰）→ 定格（1s）
```

### 2. 闪回（flashback）
- 切到过去揭示背景/伏笔
- 闪回=伏笔回收（078）
```
当下（0.5s）→ 切闪回过去（1.5s，揭示）→ 回当下（0.5s）→ 定格（1s）
```

### 3. 多线交错
- 多条时间线交错=拼真相
- 每切一次=滴漏（077）
```
线A（0.5s）→ 线B过去（0.5s）→ 线A现在（0.5s）→ 拼出真相（0.5s，峰）→ 定格（1s）
```

### 4. 时间反转揭示
- 让观众以为 A→B，揭 B→A=反转
```
以为是 A 致 B（1.5s）→ 揭 B 致 A（0.5s，时间反转峰）→ 定格（1s）
```

## 时间线错位的常见坑
- **错位太乱**：观众拼不出=看不懂=弃
- **无标记**：闪回/闪前无视觉标记=分不清当下=乱
- **错位无意义**：为错位而错位=无揭示=无用
- **错位太多**：每镜都切时间=乱=疲劳

## 时间错位的标记（让观众分清）
- 闪回：去色（069）/黑边/不同色调
- 闪前：高对比/特写
- 多线：每线一种色调/POV
- 必须有视觉标记，否则乱

## 时间错位与其他工具配合
- 错位+闪前钩子（076）=开篇抓人
- 错位+伏笔回收（078）=草蛇灰线
- 错位+反转（051）=时间反转峰
- 错位是 011 信息差的时间工具

## 经典时间错位场景

### 闪前钩
```
高潮结果（0.5s，闪前）→ 切正文（2s）→ 呼应（0.5s，峰）→ 定格（1s）
```

### 闪回揭示
```
当下（0.5s）→ 闪回（1.5s，揭示）→ 回当下（0.5s）→ 定格（1s）
```

### 时间反转
```
以为A致B（1.5s）→ 揭B致A（0.5s，反转峰）→ 定格（1s）
```

- 闪前：`flash forward, future moment, different tone, dramatic preview`
- 闪回：`flashback, past event, desaturated, black border, memory`
- 多线：`multiple timelines intercut, different color per line, fragmented`
- 时间反转：`time reversal reveal, cause and effect inverted, dramatic twist`
