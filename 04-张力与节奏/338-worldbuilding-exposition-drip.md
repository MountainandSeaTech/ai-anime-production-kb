# 世界观呈现与信息投放

## 核心要点

- **冰山理论（90/10规则）**：世界观按100%建造，正片只露10%；观众感知到水面下的体量，但几乎不被直接展示
- **最快失去观众的方式：让故事停下来解释**——info dump（信息倾倒）是作者想给，不是故事需要它浮出来
- **滴灌，不是洪水（drip, not dump）**：一个说明性细节现在给、二十场后再给一个、第三个在它突然变得要命时给；观众靠拼装保持前倾
- **信息先于好奇给＝说明书；先有好奇再给＝奖励**。顺序永远是：制造问题→延迟→让角色付出代价→答案流出

## 详细内容

### 一、四种必删的失败形态

1. **开场史前部**：第一页讲三百年前大战，观众还没在乎任何人
2. **"你懂的"对话**：两个知情人互相复述共同记忆（见条目336，修法＝信息武器化）
3. **人物登场即简历**：新角色一进门，旁白报完他的生平
4. **规则讲座**：停下剧情讲能力体系/怪物分级，而不是让规则在使用中显形

### 二、五种合法投放通道

**① 行动中的角色（character-in-action）**
不解释能力体系，拍他使用能力、支付代价、违规受罚。
- 弦音第一次发动声弦：不说"她能操控振动"，拍她拨动空气后自己捂喉咳嗽出血丝——**规则和代价一次显形，零解说**
- 习惯、恐惧、熟练度都能携带信息：老兵进防空洞先摸门框数台阶（他在这里失去过队友）

**② 埋进冲突（最高效通道）**
人在争吵时会把历史当武器扔出来：旧背叛、没兑现的承诺、"那年你也是这么说的"。观众吸收了全部前史，但因为它是**弹药不是说明**，毫无说教感。
公式：给信息一个"被迫开口的情感压力"（指控/辩护/哀求/争胜）。

**③ 内行视角的日常化**
角色对世界的奇观已经麻木，这种麻木本身就是世界观。
- 怪兽分类不口播：食堂电视播兽潮新闻，老兵打饭时只抬头看了一眼说"B级，不用动员"
- 配给制不解释：主角领营养膏时抱怨今天的口味，顺手把半块分给新兵

**④ 环境叙事（视觉投放，AI视频最该用）**
一个空镜携带三条信息：
- 城墙合金板上焊着密密麻麻的名字（阵亡者文化）
- 难民排队领水，队伍尽头的告示写着"内陆准入积分：480"（阶层制度）
- 主角家墙上的身高刻度停在12岁那道线（家庭前史）
**视觉信息不占台词、不停剧情，是分镜提示词里最该埋的层。**

**⑤ 后果倒推**
不描述规则，拍违反规则的下场：墙上一具被腐蚀的残躯、脚下被磨出深沟的地板（某种力量经常在此发动）、新兵伸手碰某样东西被老兵一棍子打开手——观众自动建立"那东西危险"的规则。

### 三、规则体系的"自洽三角"（能力/怪物设定专用）

每个超自然设定只需让观众明确三件事，越早立越好：
1. **能做什么**（边界）
2. **代价是什么**（限制——没有代价的能力会杀死所有张力，见条目291/335）
3. **违规/极限会怎样**（一次小示范即可，为终局破限埋雷）

例：声弦操控——能共振金属／代价是声带／过度使用会永久失声。三角立住后，终局"要不要为最后一击烧掉声音"才是真两难。

### 四、什么时候允许直接告诉

直接叙述并非禁用，三种情况直接说更专业：
1. 信息**不重要**，戏剧化它是浪费篇幅（"十年后"一行字幕）
2. 强叙事声音本身有魅力（旁白者的口吻即享受）
3. 观众**此刻必须**拿到定位信息，再绕弯就是装腔作势

**比例检验**：重要的东西配场景，不重要的东西配概括。什么都戏剧化会淹死，什么都概括会干瘪。

### 五、投放顺序与记账

- **好奇心管理**：每场留一个"想知道"，同时回答上一个；问题与答案错峰，观众始终前倾
- **冰山记账**：长篇/多集项目必须维护"已知信息表"——每条信息标注：谁知道、第几场露出、还剩什么没给。靠脑子记必然矛盾或重复
- 揭示（reveal）要提前**铺证据**：终局反转的所有线索必须在之前以"当时以为无关"的形态出现过，二刷可见

### 六、AI视频改编提示

- 1分钟短片世界观预算极小：**只解释与本场冲突有关的规则**（1-2条），其余全部交给视觉奇观让观众自行脑补
- 把背景信息转成**道具文字**（告示、纹身编号、臂章）和**环境细节**，提示词中直接写进画面描述
- 宁让观众第一遍有10%没看懂，也不要让任何一个角色停下来解释——二刷率是奖励，看不懂解说则是赶客

## 关键参数 / 模板 / 清单

**单条信息投放测试**
```
□ 此刻观众/角色已经有理由需要这条信息了吗？（没有→推迟）
□ 能不能让角色为得到它付出代价？
□ 能不能只给一半？
□ 能不能用画面/道具给，不用台词？
□ 这条信息是"弹药"还是"讲座"？（后者重写）
```

**世界观露出预算（短片）**：1分钟≤2条规则、≤1个历史背景点、≤1个人物前史细节；其余全部冰山以下。

## 备注

- 世界观设定按100%写在**资产圣经/设定文档**里（提示词资产表就是冰山的水下部分），正片只调取需要的碎片
- 怪兽片"分级体系"是最容易被做成讲座的设定：用公告牌、军队动员级别、老兵一句行话带过，比旁白念分级表高级
- 与条目339（类型片节奏）配合：史诗战争片允许开场一个短信息钩子（新闻播报/命令书），但必须≤10秒且立刻进入行动
