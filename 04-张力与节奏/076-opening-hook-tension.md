# 开篇钩子张力（前3秒抓人）

## 核心要点
- 开篇钩子=**前3秒用悬念/冲突/反差抓人**——短视频不抓前3秒=划走
- 三种钩子：悬念钩（抛疑问）、冲突钩（直接打/对峙）、反差钩（荒诞/异常一瞬）
- 钩子不是"正片"，是"诱饵"——抛出疑问让观众想知道答案
- 钩子后接"正文蓄势"，别钩子完了直接进平淡交代

## 三种开篇钩子

### 1. 悬念钩（抛疑问）
- 开篇抛一个让观众"想知道答案"的疑问
- 如：角色倒在血泊/倒计时在走/一句诡异台词
- 钩=信息差（011）建立=好奇驱动
```
角色倒血泊特写（0.5s，谁杀的？）→ 倒计时数字（0.5s，会发生什么？）→ 切正文蓄势（2s）
```

### 2. 冲突钩（直接冲突）
- 开篇直接打/对峙/危机=动作抓人
- 如：刀已出鞘/追兵已到/爆炸将发生
- 钩=威胁源（011）已现=揪心驱动
```
刀已挥出特写（0.5s）→ 对峙双方（0.5s）→ 切蓄势（2s）
```

### 3. 反差钩（荒诞/异常）
- 开篇一个反差/荒诞/异常一瞬=好奇+笑（喜剧）或不安（恐怖）
- 如：严肃场景里一只猫/Boss 是只猫/角色说离谱话
- 钩=反差=认知抓人
```
庄严神殿（0.5s）→ 猫 Boss（0.3s，荒诞）→ 切正文（2s）
```

## 钩子的张力曲线
```
钩子（0.5-1s，抓人）→ 切正文蓄势（2s，建立）→ 钩子的答案/呼应（后续揭晓）
```
钩子是"闪前"（flash-forward）——先把高潮/疑问抛前面，再回正文，最后呼应。

## 钩子的常见坑
- **平淡开篇**：交代环境/角色=无抓=划走
- **钩子太长**：超过3秒=变正片=失钩子功能
- **钩子无呼应**：抛了疑问不回答=悬空=观众反感
- **钩子与正文脱节**：钩子是A正文是B=欺骗

## 钩子与正文的呼应
- 钩子抛的疑问，正文必须回答
- 钩子是高潮/结果，正文是过程
- 呼应瞬间=情绪峰（观众"原来如此"）

## 钩子的进阶

### 误导钩
- 钩子让观众以为A，正文揭B=反转（051）
- 高级但需铺垫

### 双钩
- 两个钩子叠加=悬念加倍
- 如：倒血泊+倒计时=谁杀+何时揭晓

## 前3秒爆点动作库（剧情向，10选1直接用）
> 剧情动作公式：**角色 + 身体姿态 + 手部动作 + 头部方向 + 镜头 + 光影氛围**。
> 与三种钩子的关系：本库是**具体动作模板**，三钩是**分类原则**——雨夜抬头/废墟起身属悬念钩，推开铁门/天台对峙/飞身跨越属冲突钩，摘下耳机/捡起信物属反差钩（日常物件承载情绪）。

| 动作 | 用途 | 镜头 | 动作要点（提示词直接抄） |
|---|---|---|---|
| 雨夜抬头 | 情绪定格 | 仰拍特写 | 雨中缓缓抬头、眼神坚定、雨水滑落 |
| 废墟起身 | 绝境反击 | 低机位仰拍 | 从废墟中撑地起身、眼神凌厉、满身尘土 |
| 摘下耳机 | 情绪转折 | 近景特写 | 摘下耳机、转头看向远方、神情冷静 |
| 捡起信物 | 情绪被触动 | 手部特写 | 弯腰捡起地上的信物、眼神微变、往事浮现 |
| 推开铁门 | 强势登场 | 中景跟拍 | 用力推开沉重的铁门、逆光而入、气势强烈 |
| 侧耳倾听 | 紧张铺垫 | 侧面特写 | 站在门边侧耳倾听、眼神专注、留意周围动静 |
| 拉人逃离 | 紧张追逐 | 动态跟拍 | 拉住同伴的手向前奔跑、回头警戒、表情紧张 |
| 天台对峙 | 冲突顶点 | 中景低角度 | 天台上与对手对峙、侧身而立、眼神锐利 |
| 飞身跨越 | 动作高潮 | 低角度动态 | 跃过障碍、身姿飞扬、动作凌厉利落 |
| 逆光站定 | 气场定格 | 全身远景 | 逆光中站定、风吹衣摆、轮廓分明、独行气质 |

落地规则：**前3秒只给一帧核心动作**，不要塞连招；**身体姿态+头部方向是情绪载体**（抬头=不屈、垂首=沉思、侧耳=警觉），**光影氛围是风格锁**（雨夜=冷蓝、废墟=尘黄、逆光=暖橙剪影）；镜头栏是下限不是上限，可按 016-022 景别原则升级。
