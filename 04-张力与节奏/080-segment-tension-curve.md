# 段落张力曲线

## 核心要点
- 一条动漫短剧=**多段张力曲线（014）拼接**，段间有小谷，整剧有大峰
- 全程高压=疲劳；全程平=无聊——起伏才揪心
- 段落曲线=单段 build-peak-release；整剧曲线=多段起伏+大峰
- 节奏自检：把每段张力值画出来看起伏

## 整剧张力曲线的形态

### 单峰型
```
蓄—峰—释（一段曲线，适合15-30秒短剧）
```

### 双峰型
```
蓄—峰1—小谷—蓄—峰2—释（两段，30-45秒）
```

### 阶梯型
```
蓄—峰—小谷—更高蓄—更高峰—释（递增，45-60秒）
```

### 长尾型
```
蓄—峰—超长释（悲剧，046）
```

## 段间小谷的作用
- 小谷=两峰间的喘息=让观众松懈
- 松懈后再拧=下次峰更狠（与 044 假警报同理）
- 无小谷=全程高压=疲劳=无对比

## 段落曲线的常见坑
- **全程高压**：每段都峰=无对比=疲劳
- **全程平**：每段都蓄=无峰=无聊
- **段间无谷**：峰接峰=无喘息=累
- **大峰太早**：开头就大峰=后面无升级=泄
- **大峰太晚**：结尾才峰=前面无聊=划走

## 段落曲线的设计

### 大峰位置
- 短剧（15-30s）：大峰在 70-85% 处
- 中短剧（30-45s）：大峰在 75% 处
- 别在最后1秒峰=没时间释放

### 段长配比
- 蓄势段最长（占40-50%）
- 峰段最短（占10-15%）
- 释放段中等（占20-30%）
- 段间谷短（占5-10%）

## 整剧曲线自检
- 画张力值随时间曲线
- [ ] 有起伏吗（不是一条直线）？
- [ ] 大峰在 70-85% 处吗？
- [ ] 段间有小谷吗？
- [ ] 全程不是全程高压/全程平？

## 段落曲线与其他工具配合
- 段内曲线=014 build-peak-release
- 段间谷=044 假警报式的松懈
- 整剧大峰=076 钩子的最终呼应
- 段落是 015 节奏的"宏观版"

## 经典段落曲线示例

### 双峰短剧（30s）
```
蓄1（4s）—峰1（0.5s）—谷（1.5s）—蓄2（4s）—大峰（0.5s）—释（2s）—结尾余韵（083，2s）
```

### 阶梯中短剧（45s）
```
蓄1—峰1—谷—更高蓄2—更高峰2—谷—最高蓄3—最高峰—释—余韵
```

## 备注
- 段落曲线是 014 单段曲线的"宏观拼接版"
- 核心：多段起伏+段间小谷+整剧大峰
- 全程高压=疲劳，全程平=无聊——起伏才揪心
- 大峰位置在 70-85%，别太早（泄）也别太晚（划走）
- 自检：画张力值曲线看起伏
