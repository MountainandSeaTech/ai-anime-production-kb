# 视角切换张力（POV）

## 核心要点
- POV（视角）切换=**信息差的视觉化**——第一人称让观众同无知，第三人称给全知
- 切换瞬间=信息差反转=峰
- POV限制=045 视角限制的工具，也是 082 错位的前置
- 核心：让观众"知道多少"靠 POV 控制

## POV 与信息差

| POV | 观众知道 | 效果 |
|---|---|---|
| 第一人称（角色眼） | =角色=同无知 | 代入+悬念 |
| 限制第三人称（跟角色） | =角色 | 同上 |
| 全知第三人称（多视角） | >角色 | 眼看踩坑=揪心 |
| 上帝视角（鸟瞰） | 全知 | 全局+无力感 |

## POV 切换的张力来源

### 1. 切换=信息差反转
- 从第一人称切到全知=观众突然"知道更多"=信息差反转=峰
- 从全知切到第一人称=观众突然"被困在角色视角"=无力感峰

### 2. POV 限制=悬念
- 第一人称看不到背后/画外=悬念（045）
- 观众=角色=同无知=好奇驱动

### 3. 全知=揪心
- 全知让观众看到角色没看到的威胁=眼看踩坑=揪心（011）

## POV 切换的用法

### 1. 第一人称转全知（揭威胁）
```
第一人称逃（1.5s，看不到追兵）→ 切全知全景见追兵已近（0.5s，反转峰）→ 切回第一人称回头（0.3s）→ 定格（1s）
```

### 2. 全知转第一人称（被困视角）
```
全知见威胁逼近（1s）→ 切第一人称被困看不到（0.8s，无力感峰）→ 威胁现身（0.3s）→ 定格（1s）
```

### 3. 多 POV 交错
- 在多角色间切 POV=多视角拼真相
- 每切一次给一块拼图=滴漏（077）
```
A POV（0.5s）→ B POV（0.5s）→ 拼出真相（0.5s，峰）→ 定格（1s）
```

## POV 切换的常见坑
- **POV 不变**：全程一个视角=无信息差反转=平
- **切换太频**：每镜切=乱=看不懂
- **第一人称太久**：全程第一人称=看不到全局=无聊
- **切换无意义**：为切而切=无信息差=无用

## POV 与其他工具配合
- POV+视角限制（045）=信息差视听双控
- POV+rack focus（019）=视角内揭示
- POV+时间错位（082）=时空双控
- POV 是 011 信息差的视角工具

## 经典 POV 张力场景

### 第一人称转全知
```
第一人称逃（1.5s）→ 全知见追兵（0.5s，峰）→ 回第一人称（0.3s）→ 定格（1s）
```

### 多 POV 拼真相
```
A POV（0.5s）→ B POV（0.5s）→ 拼真相（0.5s，峰）→ 定格（1s）
```

## AI 提示词
- 第一人称：`first person POV, point of view shot, limited view`
- 全知：`omniscient wide shot, god's eye view, full scene visible`
- 限制第三人称：`over the shoulder shot, following character, limited third person`
