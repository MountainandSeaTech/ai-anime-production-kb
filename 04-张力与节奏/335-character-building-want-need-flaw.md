# 人物塑造：欲望-需要-幽灵-缺陷

## 核心要点

- **人物不是靠资料表立起来的，是靠一条因果链**：幽灵事件（Ghost）→ 谎言信念（Lie/Misbelief）→ 性格缺陷（Flaw）→ 外在欲望（Want）；而故事要给他真正的**需要（Need）**
- **Want 驱动剧情，Need 驱动主题**：Want 是他自己以为想要的外部目标，Need 是他看不见的内在功课
- **Want 与 Need 第一页就一致＝没有弧光**；简单对立＝说教；**最高级的是"斜对角"**——他追的东西和需要的东西看似相关实则错位，得到时才发现找错了
- 没有幽灵的缺陷是作者派发的标签；有幽灵的缺陷是角色从亲历中得出的"理性结论"——他越难放弃，转变时越满足

## 详细内容

### 一、五件套因果链（每个主要角色填一遍）

| 元件 | 定义 | 示例（守城老兵岩骨） |
|---|---|---|
| 幽灵 Ghost | 故事开始前的具体创伤事件 | 二十年前下令开闸门救平民，反放入兽群，全队覆没只活他一个 |
| 谎言 Lie | 他从事件中得出的错误信念 | "只要我不再做选择，就不会再害死任何人" |
| 缺陷 Flaw | 谎言导致的可观测行为模式 | 逃避指挥位、只执行不决策、把自己当工具 |
| 欲望 Want | 他当下主动追的外部目标 | 守住这面墙，活到换防 |
| 需要 Need | 他真正该学会的（主题） | 为了救人必须重新承担选择之重，哪怕可能再错 |

### 二、弧光的三种走法

1. **正向弧光（Positive）**：谎言被现实击碎，主角接受真相，用新信念解决终局——终局胜利必须依赖他**放下缺陷后**才可能的行动
2. **负向弧光（Negative）**：他抱紧谎言一路滑到底（悲剧）；观众看着一个本可被拯救的人自我毁灭
3. **平直弧光（Flat）**：主角信念不变，是他改变了周围的世界（侦探片、硬汉类型常用）；考验放在"世界值不值得他坚持"

**铁律：终局的解法必须由弧光提供**。如果删掉转变线结局照样成立，说明缺陷和剧情是两张皮。

### 三、缺陷的写作要求

- **缺陷要在第一场就发作并造成损失**，不能只在背景故事里——开场就让他因逃避决策付出一个小代价
- 缺陷同时是**优点的阴影面**：忠诚的阴影是盲从，谨慎的阴影是不敢开闸，强大的阴影是不信任队友
- 给缺陷配一个**招牌行为**（observable tic）：说谎前先摸手腕、思考时用手指敲拍子、紧张时讲笑话——可表演、可在分镜里反复出现、转变时可被打破

### 四、前史投放：冰山原则

- 写人物档按100%写，**正片只露出10%**，但露出的每一块都暗示水下的体量
- 幽灵事件**不要开场旁白交代**，用三种方式漏出：①他人一句带刺的提及 ②他对特定刺激的反常反应（听到"开闸"两个字手一抖）③终局两难与幽灵同构（二十年前关闸还是开闸，今天再选一次）
- **终局两难＝幽灵事件的重演**，这是检验人物戏是否咬合的硬指标：第一幕的创伤在第三幕换个形式回来，这次他做出不同选择

### 五、人物声音（Voice）：遮住名字也知道谁在说话

四个区分维度：
1. **句子长度**：老兵短句命令式；学者长句带条件从句；少女跳句、话题突然转弯
2. **词汇领域**：每个人从自己的职业/出身借词——海员用航海比喻，音乐人用节奏和音准描述一切
3. **对抗方式**：有人攻击、有人回避、有人用幽默化解、有人讲事实
4. **口头禅/语言习惯**：固定句式、提问方式、特有的脏话或敬语

快速测试：把剧本里所有对白的人名遮掉，能不能靠语气对上角色？对不上就是"提线木偶共用一张嘴"。

### 六、配角与反派的最低配置

- **配角也要有 Want**（哪怕只是"把这箱箭矢搬完"），不能只为给主角递信息存在
- **反派相信自己是主角**：给他自己的幽灵和谎言，他的目标从他的逻辑里完全合理。最高级反派不是邪恶，是"用另一套答案回应同一个创伤"
- 功能型角色（报信兵、技师）给一个**一招记忆点**：结巴、总在吃东西、怕死到反而活最久——一个标签即可，不抢戏

## 关键参数 / 模板 / 清单

**人物档案模板（写戏前填，写完不直接搬进剧本）**
```
姓名/年龄/身份：
幽灵事件（具体一幕，不是概括）：
谎言信念（一句话，他信以为真的错话）：
缺陷（可观测行为，第一场如何发作）：
Want（外部具体目标，可验证）：
Need（内在功课，他自己此刻说不出来）：
Want与Need在哪场戏正面相撞：
终局两难＝幽灵如何重演：
招牌行为（一个可反复拍的小动作）：
声音四件套（句长/词汇领域/对抗方式/口头禅）：
开场状态 vs 终局状态（一句话对照）：
```

**人物体检三问**
1. 他的缺陷在第一场造成损失了吗？
2. 终局胜利是否只有"转变后的他"才能拿到？
3. 遮住人名，台词能认出是谁说的吗？

## 备注

- 群像战争片：每个视角人物只需一个"迷你五件套"（幽灵可省，谎言+缺陷+两难必须有），主角给全套
- 短剧（1-3分钟）装不下完整弧光时，用"单一转变时刻"：全片只拍他从谎言到真相的**那一个决定**，前史靠一个道具/一句刺话锚定
- 与表演体系对接：Want≈查伯克"总目标/分场目标"（条目202），幽灵≈"既往情境"（条目211），写作层定好的元件可直接喂给表演层
