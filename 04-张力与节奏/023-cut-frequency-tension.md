# 切换频率与张力

## 核心要点
- 切换频率（每秒切几次镜）= 剪辑节奏的直接参数，编码张力强弱
- **慢切=蓄势累积**（每镜 1.5-3s），**快切=爆发过载**（每镜 0.3-0.8s）
- 关键不在频率本身，而在**频率的骤变**——从慢切突然变快切=张力峰值信号
- 匀速切（无论快慢）杀张力，见 015

## 切换频率与张力对照

| 频率 | 每镜时长 | 张力效果 | 适用阶段 |
|---|---|---|---|
| 极慢切 | 3s+ | 持续累积、宿命感 | 长对峙、决别 |
| 慢切 | 1.5-3s | 蓄势、平稳紧张 | build-up |
| 中切 | 0.8-1.5s | 平衡、过渡 | 交代、推进 |
| 快切 | 0.3-0.8s | 爆发、过载 | peak、缠斗 |
| 极快切 | <0.3s | 信息轰炸、混乱 | 高潮乱战 |

## 频率骤变 = 张力信号

### 慢→快的骤变（蓄到爆）
```
慢切对峙（每镜2s，3镜共6s）→ 快切爆发（每镜0.3s，3镜共1s）→ 慢切定格（1镜2s）
```
慢切蓄势→快切峰值→慢切释放。频率骤变就是 014 曲线的剪辑实现。

### 快→慢的骤变（爆到凝）
```
快切缠斗（每镜0.4s，4镜）→ 慢切致命一击（1镜1.5s，升格）→ 慢切定格（1镜2s）
```
快切乱战→骤慢一击=时间凝固感=峰值强调。

## 切换频率的经典节奏型

### 居合斩杀（慢-爆-慢）
```
慢切蓄势（2s×2镜=4s）→ 极快切出刀（0.3s×2镜=0.6s）→ 慢切定格（2s×1镜）
```
频率：2s → 0.3s → 2s，骤变三段式。

### 缠斗高潮（快-停-快）
```
快切缠斗（0.5s×4镜=2s）→ 慢切停顿对峙（1.5s×1镜）→ 快切决胜（0.4s×3镜=1.2s）
```
快→停→快，中间慢切做"喘息峰"。

### 追逃逼近（渐快阶梯）
```
中切（1.2s×2）→ 中快切（0.8s×3）→ 快切（0.4s×4）→ 慢切定格（2s×1）
```
频率阶梯加速=逼近感，最后慢切定格=定格结局。

## 切换频率的反例

### 匀速切（杀张力）
全程每镜 1 秒，从头切到尾——无快慢对比=平=无张力。
> 自检：数一下每镜时长，如果方差很小，这段张力弱。

### 蓄势段快切
对峙戏每镜 0.5 秒切——没给蓄势时间，揪心累积不起来。

### 峰值段慢切
爆发瞬间每镜 2 秒——峰值被拉长成展示，泄气。

## AI 生成的切换频率控制
- AI 视频每个 clip 是一个"镜"，时长由生成决定（通常 4-6s 一段）
- 实操：生成多段相似机位 clip，在剪辑软件里按目标时长裁切拼接
- 关键：剪辑时手动控每镜时长，按上面节奏型排布
- 升格段（021）可把一段拉长，等效"慢切"

## 备注
- 切换频率是 015 节奏论的参数化，也是 032 硬切节奏的前置理论
- 动漫短剧切换频率建议：蓄势 1.5-3s/镜，峰值 0.3-0.8s/镜，释放 1.5-2s/镜
- 自检工具：把分镜表每镜时长列出来看方差，方差大=有对比=有张力
