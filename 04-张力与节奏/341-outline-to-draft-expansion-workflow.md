# 从大纲到初稿：雪球式多级扩写工作流

## 核心要点

- **核心纪律：永远不在错误的抽象层写作**。写节拍时不要想台词，写场景卡时不要想运镜；每一级只解决本级的问题
- **大纲是地图，场景表是每日行军路线**——地图给全局，路线表切成"今天走到哪"的最小可执行单位
- **每一级膨胀都要先压测再往下**：一句话没过逻辑关，扩成一万字只会把错误放大一万倍
- 雪球法（Snowflake）的精髓：**先写小、逐级长大、每级回头同步**，不是一次性铺开

## 详细内容

### 一、七级膨胀流水线

| 级别 | 产出物 | 篇幅 | 本级只决策 |
|---|---|---|---|
| L0 | 一句话前提（logline） | 1句 | 谁＋想要什么＋什么挡着＋不解决会怎样 |
| L1 | 五句段落 | 5句 | 建置／灾难1／灾难2／灾难3／结局（雪球法标准结构） |
| L2 | 节拍表 | 15拍或7点 | 每个转折点的位置与性质（条目333） |
| L3 | 序列表 | 4-8个序列 | 每序列一个迷你三幕＋一个序列目标 |
| L4 | 场景卡 | 40-60张（长片）／5-12张（短片） | 每场的目标/冲突/结果/情感变化 |
| L5 | 场景初稿 | 完整散文/剧本 | 动作、对白、细节（条目334/336/340） |
| L6 | 分镜段提示词 | 可拍摄时间码 | 镜头、运镜、声音、资产锚定（项目制作本） |

### 二、每一级的操作要点

**L0 一句话前提**（不过这关什么都别写）
公式：「[身份缺陷的主角]在[催化事件]后必须[行动]，否则[具体代价]，但[对手/缺陷]逼他[两难]。」
压测：读给陌生人听，对方追问的第一个问题就是你L1要补的洞。

**L1 五句段落**
句1建置（主角与世界）；句2-4三次升级灾难（每次改变局面性质，不是加码同类）；句5结局。
压测：删掉任一句，故事是否还成立？成立＝那句是注水。

**L2 节拍表**
用333的15节拍按百分比落点。短片压成5拍。
压测：中点和"一切尽失"是两个不同的坏消息吗？开场/终场画面能对照吗？

**L3 序列表**
每序列≈10-15分钟（短片≈15秒-1分钟），有自己的目标-结果；序列之间用"结果行"咬合：上一序列的结果是下一序列的初始困境。

**L4 场景卡（扩写的关键中转站）**
每张卡五字段：
```
场次/地点/时间：
出场人物：
本场目的（角色的具体目标）：
核心冲突与两难：
情感变化（入场情绪→出场情绪）：
```
**卡片先于文字的价值**：可以摊在桌上排序、删减、互换，发现"两场情绪变化相同"（重复）或"连续三场紧张"（节奏问题）——改卡片成本是改初稿的百分之一。

**L5 场景初稿**
一次只写一场，先写最有感觉的（不按顺序写是合法的）；初稿只求"完成的烂"，精修是L7的事。

**L6 分镜段提示词（本项目落地层）**
把场景做"摄影机翻译"（见条目340映射表）：心理→动作，概括→具体名词，按平台分段（Wan≤30s自然语言），同步挂资产参考。

### 三、压测闸门（每级通过才放行）

- L1闸门：三次灾难是"质变"还是"量变"？（连续三次"又来一批怪"＝量变，枪毙）
- L2闸门：弧光与剧情咬合吗？（终局解法必须来自人物转变，条目335）
- L4闸门：每张卡填不出"两难"或"情感变化"？（这场不存在，删或合并）
- L5闸门：朗读测试（条目336）＋场景体检三问（条目334）
- L6闸门：逐镜资产核对（项目铁律④）＋冲击帧/张力预算

### 四、短片专用极速流程（1-3分钟，实战推荐）

```
L0 一句话（10分钟）
 → L2 直接做5拍表（跳过L1/L3，短片体量装不下）
 → L4 场景卡5-12张（每卡必须有情感变化）
 → L6 分镜段提示词（边写边挂资产）
 → 同步产出资产提示词（铁律②：分镜与资产同批次）
```
短片最容易犯的错是用长片的耐心铺世界观——338条的"露出预算"在这一级强制执行。

### 五、扩写时的"加法清单"与"禁令清单"

**允许加**：抉择的犹豫过程｜动作的代价与反馈｜感官锚点（每场1-2个）｜关系变化的微动作｜环境叙事细节
**禁止加**：解释性旁白｜重复信息｜不改变局面的新角色｜与本场目标无关的招式/奇观｜"我觉得很酷"但无功能的镜头

### 六、常见工程事故

1. **越级写作**：L2还没定就写台词——结果台词全废。治疗：回到当前级
2. **扩写即注水**：把"他冲进城"扩成三段跑步描写。治疗：扩写四问（条目334第五节），只放大抉择/代价/感官/关系
3. **卡片与初稿脱节**：写嗨了偏离卡片。允许，但偏离后必须**回头改卡并重排相邻卡**，保持地图同步（雪球法的"每级回头同步"）
4. **资产债**：分镜写了没有提示词的角色/道具——铁律④审计当场回填

## 关键参数 / 模板 / 清单

**开工前最小检查**
```
□ L0一句话能脱口而出
□ L2节拍表（或短片5拍）落纸
□ L4场景卡每张有：目标/冲突/结果/情感变化
□ 资产清单随分镜同步（角色/场景/道具seed）
□ 每级压测问题已回答
```
