# 信息滴漏节奏

## 核心要点
- 信息滴漏=**一点给线索，留新疑问**——每次滴漏是小峰，维持持续好奇
- 是 045 悬疑的核心节奏，也是 076 钩子的延续
- 黄金法则：每给一条线索，必抛一个新疑问=永不让观众"全懂"
- 全懂=无悬念=无张力；全不懂=无抓手=无聊——滴漏是平衡

## 信息滴漏的原理
- 观众的好奇=信息差（011）驱动
- 一次给全=信息差归零=好奇死
- 一点给+留新问=信息差持续=好奇持续
- 每次滴漏是一个小峰（揭示）+新蓄势（新疑问）

## 滴漏的节奏

### 标准滴漏节
```
新线索揭示（0.3-0.5s，小峰）→ 角色反应/思考（0.5s）→ 新疑问浮现（0.3s，新蓄势）→ 下一段
```
每节=揭示+反应+新问，循环。

### 滴漏密度
- 动漫短剧每 5-10 秒一条线索=保持好奇
- 太密（每秒一条）=信息过载=乱
- 太疏（30秒一条）=无聊

## 滴漏的常见坑
- **一次给全**：真相一次抛=好奇死=无张力
- **一直不给**：全程无线索=无聊=划走
- **线索无新问**：给了但没新疑问=无驱动=平
- **滴漏太密**：信息过载=乱=看不懂

## 滴漏的进阶

### 误导滴漏
- 给的线索指向"假真相"（051）=为反转铺垫
- 观众"以为懂了"=反差前提

### 多线滴漏
- 多条线索并行滴=多悬念=立体
- 但别超过3线=乱

### 呼应滴漏
- 前面抛的线索，后面"回收"=呼应=满足感
- 草蛇灰线=好滴漏

## 滴漏与其他工具配合
- 滴漏+视角限制（045）=信息差视听双控
- 滴漏+伏笔（078）=线索回收
- 滴漏+钩子（076）=钩子是第一滴
- 滴漏是 011 信息差的节奏化

## 经典信息滴漏场景

### 悬疑滴漏
```
线索1揭示（0.5s，小峰）→ 反应（0.5s）→ 新疑问（0.3s）→ 线索2（0.5s）→ ...→ 真相大峰（0.5s）→ 定格（1s）
```

### 误导滴漏（反转铺垫）
```
假线索滴漏（2s，让观众信假真相）→ 反转细节（0.3s）→ 真相（0.5s）→ 定格（1s）
```

- 角色思考：`character processing information, realization dawning, thinking`
- 新疑问：`new mystery emerging, questioning expression, deeper doubt`
