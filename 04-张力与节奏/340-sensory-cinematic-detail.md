# 感官细节与画面感

## 核心要点

- **画面感来自精确，不来自华丽**：不是"一辆车"，是"一扇红门的白色本田"。一个选对的细节比一堆形容词有力得多
- **紫散文（purple prose）是画面感的敌人**：形容词堆叠把感官冲击埋在废话下；手艺是选出"那唯一正确的细节"
- **好的感官细节一感双关**：烟味混着廉价空气清新剂，不止是气味，它同时说出了人物、处境和阶层
- **视觉之外，嗅觉与触觉是被遗忘的杀器**：气味与记忆直连，触觉（温度/质地/震动）让观众"身体在场"

## 详细内容

### 一、五感的分工与战力

| 感官 | 战力 | 用法要点 |
|---|---|---|
| 视觉 | 基础层，最易写也最易滥 | 只选1-2个视觉主体，其余虚化成氛围 |
| 听觉 | 战争/悬念戏的第一战力 | 远近层次、突然的寂静、声音先于画面 |
| 嗅觉 | 最被低估、直通情绪与记忆 | 一场戏给一个标志性气味即可：硝烟、铁锈、雨后沥青 |
| 触觉 | 身体在场感来源 | 温度、震动、质地：钢盔被冲击波震得发麻、墙在掌心抖 |
| 味觉 | 少而精，用一次记一辈子 | 极端时刻：血的铁锈味、跑断气时嘴里的苦味 |

**比例原则**：每场以一感为主、一感为辅，五感平均用力等于没有重点。

### 二、具体名词＋精确动词（语法层的画面感）

- 名词升级：武器→**卷了刃的工兵铲**；怪兽→**鳞甲缝隙里嵌着沉船铆钉的巨兽**
- 动词升级：走→**蹭/挪/趟/踮/拖**；打→**砸/挑/绞/崩**
- 砍掉的副词：不是"用力地关门"，是"门被摔上，墙上的灰簌簌掉"——**让结果显出力道**
- 检验句：把这句话里的形容词全删掉，画面还成立吗？成立才算过关

### 三、细节的"冰山载荷"：一感双关

每个细节问一句：除了感官，它还额外说了什么？
- 指挥官的白手套袖口磨起了毛边（军队补给已断＋他撑了很久）
- 新兵的靴带系得一丝不苟（他还没见过血／老兵的靴子全是泥）
- 巨兽鳞片上生长着发光的藤壶状生物（它来自深海＋暗示体内生态）

**最高级细节同时完成三件事**：感官画面＋人物信息＋剧情伏笔。

### 四、电影化描写：写"可被拍摄的东西"

1. **只写镜头能拍、麦克风能录的**：不写"他想起亡妻"，写"他看了一眼内袋口袋的位置，把按扣又按了一遍"
2. **用空间关系代替心理陈述**：两人对话，一人始终隔着办公桌（权力距离）；和解那场两人坐在同一张地图两侧
3. **光与天气即情绪，且要物理合理**：不写"氛围绝望"，写应急灯每七秒闪一次、警报声里灰尘下落
4. **运动描写给方向与参照物**：不说"怪兽巨大"，说"它的影子越过城墙时，城西的集市整条街暗了下来"
5. **慢镜头的文字信号**：在连续短句搏杀后放一个拉长的具象细节（见条目339节拍法）

### 五、感官细节与情绪的错位使用（进阶）

- **温柔场景给不适细节**：诀别时背景里有糊味——生活还在继续，伤感不请自来
- **恐怖场景给日常细节**：巨兽登陆前，自动售货机掉下一罐可乐滚过空荡的街道
- **极端暴力给感官抽离**：真正的重创瞬间反而声音发闷、视野收窄、耳鸣——亲历者报告式写法比鲜血喷涌更真实
- 这比"应景配乐式描写"高级：观众的情绪被反差激活，而不是被指挥

### 六、转成AI视频提示词的映射表

| 文字层 | 提示词层 |
|---|---|
| 具体名词 | 直接成为主体描述：卷刃工兵铲、嵌铆钉的金色鳞甲 |
| 听觉细节 | 进声音行：低频脚步、号角、突然抽干的环境音 |
| 嗅觉/触觉 | 转译为可见征兆：烟雾、地面尘粒震起、钢盔震颤、人物搓动发麻的手指 |
| 光/天气情绪 | 进灯光与氛围行：7秒周期频闪应急灯、暖红夕照＋冷蓝预警灯对撞 |
| 一感双关细节 | 作为画面中的次级元素写死：背景磨损的白手套、背景发光藤壶 |
| 心理活动 | 一律转动作：摸口袋、二次确认按扣、视线方向 |

**铁律**：提示词只接收"可拍摄成分"，写分镜时先把剧本里的所有心理/概括句做一次"摄影机翻译"，再组织进时间码。

## 关键参数 / 模板 / 清单

**一段描写的精简流程**
```
1. 写下初稿（随意）
2. 圈出全部形容词/副词，删掉一半
3. 把3个泛指名词换成具体名词
4. 把1个弱动词换成精确动词
5. 检查：有没有一个细节同时携带感官+人物/伏笔信息？没有→换一个
6. 心理句全部改成可拍摄动作
```

**感官盘点（每幕一次）**：这一幕主感官是什么？｜有没有用听觉/触觉补视觉的短板？｜气味给了吗？

## 备注

- 与条目232（焦点与细节经济学）一致：细节价值＝对整体的贡献，不是越细越好，是每个细节都要干活
- 真人写实风下，材质类触觉细节要具体到织物/金属/混凝土的真实质感（对接全剧画风口径）
- 动作戏感官优先级：触觉（冲击/震动）＞听觉＞视觉；文艺对话戏：微表情视觉＋环境声，慎用配乐填满
