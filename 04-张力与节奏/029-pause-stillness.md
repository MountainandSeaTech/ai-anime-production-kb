# 停顿与静止的张力

## 核心要点
- **停顿 = 动作中途的静止**——不是待机（025 那是动作前），是动作"进行中"被冻结
- 停顿制造：延迟释放（011）+ 重量感（动作被强调）+ 悬念（会不会继续）
- 停顿的位置决定张力类型：**出手前停=蓄势，出手中停=凝视峰值，出手后停=余韵**
- 停顿时长 0.3-1.5s 最佳，超 2s 变拖

## 三种停顿位置与张力

### 1. 出手前停（蓄势停顿）
- 动作到一半骤停：手已举到半空但未落下、刀已出鞘一半但未挥
- 张力：最大蓄势——该爆未爆，延迟拉满
- 时长：0.5-1.5s
```
举手蓄势（0.5s）→ 骤停半空（1s，最大揪心）→ 落下爆发（0.3s）
```

### 2. 出手中停（凝视峰值）
- 动作进行到关键瞬间定格：刀挥到一半、子弹飞到中点
- 张力：把峰值瞬间凝固成可凝视的雕塑
- 手法：升格到极慢/定格帧
- 时长：0.3-0.8s
```
出刀（0.2s）→ 刀锋中途定格（0.5s，凝视峰值）→ 落刀（0.3s）
```

### 3. 出手后停（余韵停顿）
- 动作结束后保持结果姿势静止：收刀定格、击中后保持姿势
- 张力：余韵+重量感——让观众消化"刚才发生了什么"
- 时长：0.8-2s
```
斩击（0.3s）→ 收刀定格背身（1.5s，余韵）→ 敌人倒下（0.5s）
```

## 停顿的重量感技巧
- 停顿时角色保持"用力"的姿势而非松垮=能量仍在=有重量
- 配合呼吸：停顿时屏息或长呼气=内在仍在动
- 配合镜头：停顿用固定机位+大特写=注意力钉死

## 停顿的反差定律
- 动作越快，停顿反差越大=张力越强
- 快动作（0.3s）→ 停顿（1s）→ 快动作（0.3s）= 快-停-快节奏
- 全程匀速+停顿=无反差=停顿失效

## 经典停顿序列

### 居合"半拔"停顿
```
手搭柄（0.5s）→ 拔到一半骤停（1s，刀身半露，最大蓄势）→ 猛拔出（0.3s）→ 挥斩（0.3s）→ 收刀定格（1s）
```
半拔停顿是居合戏最揪心的瞬间——刀已动但未成，临界态。

### 一击"中途凝视"
```
举刀（0.5s）→ 挥到中途升格定格（0.8s）→ 落刀爆发（0.3s）→ 保持斩姿（1s）
```
中途升格=把挥斩峰值拉长凝视。

### 对白"欲言又止"
```
张口欲言（0.5s）→ 停顿闭嘴（1s，悬念）→ 转头开口（0.3s）
```
对白戏的停顿=话将说未说=心理加压。

## 停顿的常见坑
- **停顿太久**（>2s）= 拖，观众出戏
- **停顿位置错**：在无关动作处停=没意义的静止=无聊
- **停顿无能量**：停顿时姿势松垮=能量泄了=停顿失效
- **停顿太多**：每镜都停=无对比=全停=平

## AI 生成的停顿实操
- AI 视频生成"动作中途定格"难，建议用升格模拟停顿（`slow motion freeze mid-action`）
- 定格帧可用 `freeze frame` / `still frame` 词
- 出手后定格：生成收尾姿势的静态镜（`holding final pose, motionless`）
- 避坑：AI 倾向生成完整连贯动作，停顿要靠剪辑在动作中途切到定格镜实现

## 自检：停顿是否有效
- [ ] 停顿前有没有快动作做反差？
- [ ] 停顿位置是关键瞬间（出手前/中/后）吗？
- [ ] 停顿时角色姿势有能量（不松垮）吗？
- [ ] 停顿时长在 0.3-1.5s 吗？

## 备注
- 停顿是 011 延迟释放+014 曲线 peak 的具体手段
- 与 025 待机区别：待机是动作前的姿势，停顿是动作中途的静止
- 停顿+升格+固定大特写=峰值顶配（把瞬间凝固成雕塑）
