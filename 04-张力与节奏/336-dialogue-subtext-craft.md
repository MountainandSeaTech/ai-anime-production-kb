# 对白工艺：潜台词与直说病修法

## 核心要点

- **对白的戏剧能量＝台词与意图之间的距离**："on-the-nose"（直说病）把这个距离压成零，演员没有表演空间，观众感觉被说教
- 三种最致命的直说：**主题广播**（"这都是为了家"）、**情绪贴标签**（"我好害怕"）、**信息灌输**（"你知道的，2019年我们在湖边……"）
- 潜台词不是让角色打哑谜，而是**恢复压力**——碍于权力、羞耻、时机、在场的人，他不敢直说，于是绕路追目标
- 允许直说的场景：军令/警告等高 stakes 必须清晰的时刻、观众首次需要的定位信息（延迟过头就是装腔作势）

## 详细内容

### 一、直说病的三种病灶与修法

| 病灶 | 病例 | 修法 |
|---|---|---|
| 主题广播 | "家人就该互相扶持。" | 让角色为**具体的东西**争吵：钥匙、钱、谁先挂电话；主题从行为里长出来 |
| 情绪贴标签 | "我很害怕。" | 恐惧显形为：转话题、讲笑话、攻击他人、过分精确地报数据 |
| 信息灌输（As You Know, Bob） | 两个都知情的人互相复述背景给观众听 | 把信息变成**武器或秘密**：只在被逼问、被用来占上风、或不小心说漏时流出 |

**信息武器化原则**：信息只能在两种时刻出现——角色被迫透露，或角色利用它获取优势。观众靠拼碎片理解，比被喂记得牢十倍。

### 二、潜台词重写七步法（写完一场后单跑一遍）

1. **标粉线**：把所有直接陈述主题/情绪/前史的台词标出来，先不删；一场超过2条＝这场在演讲
2. **写秘密目标**：每个出场者一句话写下他到散场前实际想拿到什么（情感或实物）
3. **绕路追求**：改写台词问——为了保住面子他会怎么说？怎样试探而不坦白？怎样赢了还不承认在乎？
4. **加矛盾行为**：微笑着威胁、递水却后退半步；与台词相反的身体动作让潜台词无需解释即可被读懂
5. **删重复拍**：台词和动作表达了同一信息时，留更好的那个
6. **大声朗读（盲读测试）**：和搭档各读各的，若每条句子像同一篇散文里出来的，按角色重分句法
7. **抽查金句配额**：全片允许1-2句可以直接剪进预告片的直白金句；多了就是演讲稿

### 三、潜台词的四种廉价生成器

1. **说反话**：嘴上说"真为你高兴"，下颌绷紧、手不停撕纸
2. **答非所问**：被问"你还信他吗"，回答变成"茶凉了"——回避本身就是答案
3. **谈A事其实在谈B事**：夫妻当着孩子的面争论"这盆花该不该扔"，吵的是去留
4. **信息差反讽（dramatic irony）**：观众已知而角色不知，角色一句普通台词在观众耳里自动变成悲剧预兆

### 四、功能性清单：一句台词最多同时干三件事

好台词可以同时完成：推进剧情＋暴露角色＋埋设信息。
**自检**：随便指一句台词，问"如果只留剧情信息，这句能不能用动作替代？"能→改成动作；台词要留给"只有这个角色用这种方式才说得出口"的部分。

### 五、动作/战争/灾难场景的对白特殊性

- 高压实战台词**必须短、必须直接**："东门破了。""预备队还有多少？"——潜台词让位给生存效率，此时绕路反而虚假
- 战地的潜台词转移到**行动间隙**：递水、换弹匣时的半句家常、喊代号而不喊名字——用克制写情感，战后一句"你头发烧焦了"比哭喊更重
- 命令与服从的裂缝就是人物戏：新兵复述命令时多问的那半句、老兵重复第二遍才被执行——权力关系靠台词回合写

### 六、台词的节奏感（句法工程）

- 长短句交替：连续短句后放一个长句，长句自动变成重点
- **打断**是最便宜的冲突标记：抢话、被噪音盖过、话没说完门开了
- 沉默和"半句"计入台词：被咽回去的那半句，观众会自己补完，参与感由此产生
- 数字、专有名词让台词落地："三箱，不是四箱"比"弹药不多了"真实十倍

## 关键参数 / 模板 / 清单

**单场对白体检表**
```
□ 有没有角色直接说出情绪名词？（改成行为）
□ 有没有角色向知情者复述双方都知道的信息？（改成武器/秘密）
□ 每个说话者的秘密目标写出来了吗？
□ 有没有一处台词与行为相反？
□ 遮掉人名，靠语气能认出谁是谁吗？
□ 连续三句都在完整陈述吗？（加打断/半句/沉默）
□ 本场超过2句"金句"了吗？
```

**信息投放三问**：这条信息不给会怎样？｜能不能让角色为此付代价才得到？｜能不能只给一半，剩下让观众猜？

## 备注

- AI视频提示词转化：潜台词在分镜层＝台词与微表情/动作相反（对接条目161-170微表情系列），写段提示词时把"矛盾行为"显式写进表演描述
- 七步法是修订 pass，不要在初稿阶段边写边压潜台词——先把意思写通，再跑重写
- 喜剧的潜台词逻辑相同但方向相反：角色一本正经说字面意思，周围所有人都听出言外之意，误会系喜剧情境由此建立
