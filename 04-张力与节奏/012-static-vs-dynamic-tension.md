# 静态张力 vs 动态张力

## 核心要点
- **静态张力**：角色不动，靠构图/视线/呼吸/距离维持紧张（居合站姿、对峙凝视）
- **动态张力**：动作进行中，靠速度差/距离变化/追逃维持（追逐、缠斗）
- **动漫短剧黄金法则：静态张力 > 动态张力**——静比动更揪心
- 高手把动态段也"静态化"：在动作中插入 0.3 秒静止制造峰值

## 两种张力的对比

| 维度 | 静态张力 | 动态张力 |
|---|---|---|
| 触发 | 不动 | 在动 |
| 紧张来源 | "什么时候动"的悬念 | "会不会中/追上"的悬念 |
| 持续时长 | 可拉到 3-8 秒 | 单镜难超 2 秒否则拖 |
| 典型场景 | 居合待机、对峙凝视、举刀未落 | 追逐、缠斗、连续斩击 |
| 镜头 | 固定机位为主 | 跟随/横移为主 |
| 失败常见原因 | 演太久变枯燥 | 切太碎看不清 |

## 为什么静>动
- 静止时，观众的注意力无处安放，只能盯住"即将爆发"的细节（手、眼、刀柄）→ 注意力被压缩到一点
- 一旦动起来，注意力被动作分散，揪心感反而下降
- 所以**爆发力 = 静止时长 × 爆发瞬间强度**，静止是爆发的燃料

## 静动转换的黄金结构
动漫短剧最揪心的 3-5 秒结构：
```
静（2-3s，固定机位，呼吸/手部细节）
  → 静止峰值（0.3s，微表情/眼神一变）
    → 动（0.5-1s，爆发，可升格可常速）
      → 静（0.5s，收刀/定格，余韵）
```
这就是居合戏、对峙戏的通用骨架。静→静峰→动→静，四段式。

## 怎么把动态段"静态化"（提升张力的技巧）
- 在连续动作中插入 1 帧/0.3 秒的定格（角色动作悬停）
- 给运动中角色一个"减速观察"瞬间（追逐中突然回头）
- 用慢镜头把动态瞬间拉长成准静态（升格到 1/8 速度）
- 在缠斗中切一个旁观者屏息的静止反应镜头

## 备注
- 纯动态段超过 3 秒观众会疲劳，必须用静态点打断
- AI 视频生成里，"固定机位 + 主体微动"成功率远高于"镜头运动 + 主体大动"
- 静态张力最考验演技/作画细节：手抖、呼吸、眼神，差一点都不对
