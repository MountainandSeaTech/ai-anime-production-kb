# 期待与违背（反套路张力）

## 核心要点
- 期待违背=**建立观众预期再打破**=认知冲击峰
- 喜剧靠它造笑（047），正剧靠它造揪心/反转（051）
- 套路=观众预期，反套路=打破=反差=张力
- 核心：让观众"以为会发生X"，发生的是Y

## 期待违背的原理
- 观众看套路多了=有预期（X 将发生）
- 违背预期=发生 Y=认知冲击=峰
- 反差力度=预期强度×违背程度

## 期待违背的两种走向

### 1. 喜剧走向（造笑）
- 蓄势指向严肃 A，释放荒诞 B=笑（047）
- 越正经蓄势+越荒诞释放=越好笑
```
居合蓄势正经（1.5s）→ 刀掉了（0.3s，违背）→ 呆滞（0.8s，笑点）→ 定格（1s）
```

### 2. 正剧走向（造揪心/反转）
- 蓄势指向 A，释放意外 B=揪心/反转
- 如：以为赢→输了；以为救到→没救到
```
以为救到（蓄势1.5s）→ 手脱开（0.3s，违背）→ 坠落（0.5s）→ 定格（1s）
```

## 期待违背的用法

### 1. 反套路动作
- 观众以为A招，出B招=不可预测=揪心
```
以为挥剑（蓄0.5s）→ 出脚（0.3s，违背）→ 中（0.3s）→ 定格（1s）
```

### 2. 反套路结局
- 以为赢，输/同归/未决=反差
```
以为赢（蓄1.5s）→ 同归（0.3s，违背）→ 定格（1s）
```

### 3. 反套路角色
- 以为弱，强；以为强，弱=反转
```
以为弱被压（1s）→ 反转强反击（0.5s，违背）→ 定格（1s）
```

## 期待违背的常见坑
- **无蓄势**：直接违背=无预期建立=无反差
- **违背太频**：每次都违背=无套路=无预期=失效
- **违背无逻辑**：为反而反=生硬=不买账
- **违背无代价**：违背了但无后果=无揪心

## 期待违背的进阶

### 双重违背
- 违背一次后，再违背第二次=双层峰
- 观众以为懂了→又打破=持续冲击

### 套路内违背
- 用套路建立预期，在套路"应该"的节点违背=最狠
- 如：居合"应该"出刀斩，却违背=最大反差

## 期待违背与其他工具配合
- 违背+反转（051）=正剧认知峰
- 违背+喜剧（047）=造笑
- 违背+钩子（076）=钩子是预期建立
- 违背是 011 不确定性的极致

## 经典期待违背场景

### 喜剧违背
```
居合正经蓄势（1.5s）→ 刀掉（0.3s，违背）→ 呆滞（0.8s）→ 定格（1s）
```

### 正剧违背
```
以为救到（1.5s）→ 手脱（0.3s，违背）→ 坠落（0.5s）→ 定格（1s）
```

### 反套路动作
```
以为挥剑（0.5s）→ 出脚（0.3s）→ 中（0.3s）→ 定格（1s）
```

## AI 提示词
- 蓄势（建立预期）：用正常套路 prompt
- 违背瞬间：`anticlimax, subverted expectation, unexpected turn`
- 反应：`shocked freeze, disbelief, anticlimactic reaction`

## 备注
- 期待违背是 011 不确定性的极致，喜剧（047）和正剧（051）共用
- 核心：建立预期→打破=认知冲击峰
- 必须有蓄势建立预期，否则无反差
- 别滥用——每次都违背=无套路=失效
- 用户偏好的疯批冷幽默=情绪稳定地执行违背=最寒
