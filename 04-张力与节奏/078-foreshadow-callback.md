# 伏笔与回调张力

## 核心要点
- 伏笔=**提前藏线索**，回调=**后面回收**=观众"原来如此"的满足感峰
- 草蛇灰线=好伏笔——回看才发现，全程都有
- 伏笔是 051 反转的铺垫手段，也是 077 滴漏的呼应版
- 回调瞬间=认知峰=揪心+满足双峰

## 伏笔的张力来源

### 1. 提前藏=信息差
- 伏笔藏线索=观众当时没注意=信息差建立
- 回调时"原来早有线索"=信息差反转=峰

### 2. 回调=满足感
- 观众"原来如此"=认知满足=情绪峰
- 比单纯反转更高级——有铺垫的揭晓

### 3. 草蛇灰线=可信
- 全程有线索=反转/揭晓可信=观众买账
- 无铺垫的反转=生硬=不买账

## 伏笔的用法

### 1. 道具伏笔（074）
- 提前给一个道具特写（暗器/印记/信物）
- 回调时该道具成为关键
```
盟友身上印记特写（伏笔0.3s，藏）→ [正文2s]→ 印记揭露身份（回调0.5s，峰）→ 定格（1s）
```

### 2. 台词伏笔
- 角色说一句"奇怪"的话
- 回调时才懂其意
```
角色说诡异台词（伏笔0.5s）→ [正文]→ 台词呼应揭露（回调0.5s）→ 定格（1s）
```

### 3. 视觉伏笔
- 背景里藏一个细节（影子/背景物）
- 回调时 rack focus 揭示
```
背景模糊处有细节（伏笔0.3s）→ [正文]→ rack focus 揭示（回调0.5s）→ 定格（1s）
```

## 伏笔的常见坑
- **无伏笔直接反转**：生硬=观众不买账
- **伏笔太明显**：一出来就猜到=无回调峰
- **伏笔不回收**：藏了不回=悬空=浪费
- **回调太快**：藏完立刻回=无"草蛇灰线"感

## 伏笔的进阶

### 多重伏笔
- 多条伏笔并行，最后一起回收=多层峰
- 但别超3条=乱

### 误导伏笔
- 伏笔指向假真相（051）=反转铺垫
- 观众以为懂了=反差前提

### 呼应结构
- 开篇钩子（076）=第一伏笔
- 结尾（083）=最终回调
- 首尾呼应=完整

## 伏笔与滴漏/反转的关系

| 工具 | 机制 | 时机 |
|---|---|---|
| 滴漏（077） | 一点给+留新问 | 持续 |
| 伏笔 | 提前藏，后回收 | 伏笔早/回调晚 |
| 反转（051） | 推翻假真相 | 峰值 |

> 三者联动：滴漏抛线索，伏笔藏深线，反转大揭晓。

## 经典伏笔回调场景

### 道具伏笔
```
印记特写（伏笔0.3s）→ [正文2s]→ 印记揭露（回调0.5s，峰）→ 定格（1s）
```

### 台词伏笔
```
诡异台词（伏笔0.5s）→ [正文]→ 台词呼应（回调0.5s）→ 定格（1s）
```

### 视觉伏笔 rack focus
```
背景模糊细节（伏笔0.3s）→ [正文]→ rack focus揭示（回调0.5s）→ 定格（1s）
```

- 视觉伏笔：`blurred background detail, rack focus potential, hidden element`
