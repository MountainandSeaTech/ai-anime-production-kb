# 大场面人物不漂移⑤：叙事层——人物不被规模淹没

## 核心要点

- **技术上脸不漂 ≠ 观众在乎他**。大场面最大的失败不是换脸，是"千军万马很好看，但我不知道该看谁、为什么紧张"——人物被规模淹没
- **三层窄化**：①战略目标一句话（破墙/守桥/拖住敌军）②战术透镜：每个乐章只跟1-3个POV ③情感赌注：这一仗让主角个人付出什么
- **宽近交替语法**：规模镜头短促（声音、烟、战报暗示大军），贴身执行镜头持续——观众靠人感受战争，不靠兵牌清单
- **叙事与技术的同一组解**：周期性回访主角的特写/反应镜头，在叙事上维持牵挂，在技术上正是343-346要求的"身份再锚定镜头"——一个镜头同时解决两件事

## 详细内容

### 一、大场面的三层窄化

1. **战略层（一句话目标）**："拖住敌军直到村民撤离"。整场戏每个镜头都服务这句话，不为展示而展示
2. **战术层（1-3个POV）**：一个小队、一个指挥官、一个被困平民——早标定、节奏性回访。工作记忆里同时存在的有名角色不超过3个（与条目339一致）
3. **情感层（个人代价）**：守到最后要炸桥，而朋友还在桥那头——规模只有压在一个具体的人身上才有重量

**规模靠暗示而非普查**：兵牌、番号、十二位具名队长是"人口普查模式"，观众第一支箭射出前就淹死了。"山脊号角响起，看尘土怕是有数千"——一行规模感胜过一段兵种罗列。

### 二、宽近交替语法（Scope Grammar）

- **远景＝呼吸与规模，短**：给一个大远景确认局势，2-3秒即走
- **近景＝体验与牵挂，长**：把镜头时间投资在POV角色的执行与反应上
- 肉搏距离原则：开枪时镜头在一英里外（远景交火），动手时镜头贴到一臂之内——危险越近，镜头越近，观众内脏式参与
- 规模信息以**战报**进入贴身线："山脊有骑兵！"——观众和主角同时得知，不用真的拍到每一支骑兵
- 剪辑形成"扩张-收缩"的呼吸：远景扩张→近景收缩→再扩张，每次收缩都回到同几张脸

### 三、地理只教一次，然后复用

- 开场一句"地图句"："河把战场劈成两半，城在北岸，攻城线在南岸"
- 之后只用已教过的地标：左翼、河、城门、山脊。不引入新地名、不用未解释的军语
- AI制作的额外红利：地理锚点（桥、门、旗帜）同时是344的**空间找人锚点**，观众定向与角色定位共用一套地标

### 四、乐章化与回访节奏（对接339乐章表）

四乐章模板，每乐章一句结局行：
1. **接近**：目标与恐惧建立
2. **首次交锋**：代价预演
3. **逆转**：局势变坏，POV选项改变
4. **代价**：伤、同伴之死、道德选择、惨胜——收在人物弧光线索上，不止收在军事地图上

**回访节律**：每次切去规模/副线后，必须在约定节拍内回到主POV的脸；副线越切越频繁、各线在高潮前汇聚（《敦刻尔克》三线check-in渐频收敛为一体的手法）。

### 五、反应镜头：规模的度量衡

- 大场面的奇观要由**人脸反应来定价**：巨兽踏地→先给角色瞳孔收缩/耳膜渗血/手中物颤抖的特写，奇观才"有多大"
- 经典手法：眼睛大特写作为士兵视角的情绪锚（《拯救大兵瑞恩》米勒）；用反应镜头替代一部分无法生成的超大规模镜头，省钱且更有力
- 反应镜头是A级身份镜头（344）：正脸、短、稳——每次大场面冲击后插一张，既刷新情绪又重置身份，阻断漂移累积

### 六、个人赌注清单（开打前必须答得出）

- 主角在这一仗里**会失去什么具体的东西**？（人/物/信念/身体代价）
- 他的选择和"胜利"是否存在冲突？（炸桥朋友还在对岸＝战术目标与情感目标对撞）
- 结局是否落在人的后果上，而不只落在输赢上？
- 答不出＝先修结构，不要加士兵（先修戏，再充场面）

### 七、AI番剧的镜头配比建议（叙事×技术双约束）

| 镜头类型 | 叙事职能 | 技术身份等级（344） | 时长/工艺 |
|---|---|---|---|
| 大远景/兽潮 | 规模、呼吸 | C/D：色块·光·地标 | 短，无脸参考 |
| POV执行中近景 | 体验、推进 | A/B：正典实体 | 3-5s，稳镜或降档运动 |
| 反应特写 | 代价定价、身份再锚 | A：正脸短镜 | 冲击后必插 |
| 战报/传令 | 规模信息注入 | B：半身 | 新信息推动选择 |
| 个人代价镜 | 乐章收尾、弧光 | A：正脸/眼神 | 全片最稳的拍法给这里 |

经验配比：每1-2条规模/远景镜，至少配1条POV近景或反应镜。**连续3条以上无主角人脸的大场面镜头，观众会丢牵挂，模型也会失去身份锚**——双红线。

### 八、清晰度测试

- 读完/剪完，用四句话复述这场戏：目标是什么？跟谁？局势怎么变坏的？谁付出了什么代价？说不清→减地名/减POV/合并角色
- 具名且有台词的角色数：不用笔记记不住就删减合并
- 台词桌读：指挥官的命令彼此可区分、有目的，不能互换

## 关键参数 / 模板 / 清单

**大场面开写前五问**
```
1. 一句话战略目标：＿＿
2. 回访的POV（≤3）：＿＿
3. 地图句（地理只教一次）：＿＿
4. 每个乐章如何改变主角的选项：接近/交锋/逆转/代价
5. 结尾的人的后果（不是战术输赢）：＿＿
```

**剪辑红线**：远景镜≤2-3s即回访人脸｜不连续3条无主角镜头｜每次冲击后插反应特写｜规模信息走战报不走普查
