# 慢镜头（升格）的张力用法

## 核心要点
- 升格（slow motion）的本质：**把"峰值瞬间"拉长成可凝视的时间**——让 0.3 秒的爆发延展到 1-2 秒
- 它放大的是 014 张力曲线里的 **peak 段**，不是 build-up
- 黄金法则：**升格越少用越有效**——每段戏最多 1-2 次升格，滥用=失效
- 升格≠慢节奏：升格是"时间被拉长"，慢节奏是"镜头切换慢"

## 升格在张力曲线的位置

```
build-up（常速蓄势 2-3s）→ peak（升格 1-2s，瞬间被放大）→ release（常速/定格收束 1s）
```
- 蓄势段用常速甚至略快，制造"等不及"感
- 一到峰值切升格，时间骤慢=反差=揪心峰值
- 释放段回常速，给观众喘息

> 蓄势快、峰值慢、释放常速——这就是升格的反差逻辑。蓄势如果也慢，峰值升格就没反差了。

## 升格速度档

| 升格倍率 | 画面速度 | 适用 |
|---|---|---|
| 1.5x | 略慢，情绪延展 | 表情转折、决意时刻 |
| 2x | 慢，细节可见 | 出刀瞬间、击中瞬间 |
| 4x | 很慢，凝视级 | 居合斩、子弹时间 |
| 8x+ | 极慢，雕塑感 | 终极一击、决别瞬间 |

- 动漫短剧常用 2x-4x；8x+ 慎用（太慢变拖）
- AI 视频生成里用 `slow motion` / `2x slow motion` 控制

## 升格的三大用法

### 1. 峰值延展（最经典）
出刀/击中瞬间升格，把爆发拉长让观众看清"致命一瞬"。
```
常速蓄势（2s）→ 升格出刀（1s，2x）→ 常速定格（1s）
```

### 2. 细节凝视
把一个微小动作（眼神变、手抖、血珠落）升格，让观众"看见"平时看不见的细节=心理加压。
```
升格特写眼神一变（0.5s，4x）→ 常速爆发（0.5s）
```

### 3. 决别/死亡延宕
致命一击或死亡瞬间升格到 4x+，把"不可挽回"拉长成悲剧凝视。
```
升格中刀瞬间（1.5s，4x）→ 升格倒下（1s，4x）→ 常速定格（1s）
```

## 升格滥用的崩盘
- **每镜都升格** = 没有常速对比 = 升格失效（全慢=匀速=无张力，见 015）
- **蓄势段升格** = 提前泄掉峰值燃料
- **非峰值处升格** = 观众不知道该凝视什么，注意力涣散
- 升格段超过 2.5 秒 = 拖沓，观众出戏

## AI 提示词
- `slow motion` / `2x slow motion` / `4x slow motion`
- `bullet time`（极端升格，子弹可见）
- `time freeze`（定格，比升格更极端，瞬间凝固）
- 注意：升格在 AI 生成里偶有帧率不稳，建议升格段时长略短于预期
- **用摄影术语撬动，别只写"慢动作"**：给具体帧率（如 `1000fps high-speed`）与快门角度、介质反应（牛奶皇冠飞溅、液滴悬浮），比抽象词更可控——AI 对帧率/摄影术语有 latent 理解

## 备注
- 升格是 014 peak 段的时间轴工具，与"固定机位+主体动"组合最强
- 升格 + 大特写 + 浅景深 = 峰值顶配三件套
- 一条动漫短剧最多用 1-2 次升格，把"贵"留给真正的峰值
