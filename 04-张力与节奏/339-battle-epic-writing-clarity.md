# 战争/史诗场面写作

## 核心要点

- **史诗不等于百科全书**：观众要感觉到千军万马，故事一次只追踪一个清晰目标。规模是暗示出来的，不是清点出来的
- **写小，演大（write small so it plays enormous）**：纸面上控制在工作记忆能装下的范围（每乐章2-3个有名有姓的行动者），其余用声音、烟尘、战报暗示
- **三层收窄结构**：战略目标（拖住兽潮到共振完成）→ 战术透镜（跟一个小队/指挥者/平民）→ 情感代价（这场仗让主角个人失去什么）
- **远景与近景是一种语法**：短暂的将军远景＋持续的士兵近景交替，剪辑的扩张与收缩由此而来

## 详细内容

### 一、写前六步（结构不对，加再多怪物也没用）

1. **一句话战役目的**："在共振器启动前，把深渊之核挡在东门外。"——之后所有内容服务这句话
2. **选POV锚点**：每个乐章最多1-3人，早早标记、有节奏地回访；名单长到不用笔记不住＝砍人或合并
3. **一句话建立地理**：左翼、护城河、东门、山脊——开战前用大白话给一次，之后反复复用同一组地标；军语只有角色在用且当场定义时才出现
4. **切成乐章（movements）**：①接近 ②首次碰撞 ③逆转 ④代价。每个乐章必须有一句"结果行"——打完这一段，局面发生了什么变化
5. **规模点到为止**：一行胜千言——"山脊线上号角连成一片，看尘土，怕是有几万。"
6. **收尾落在人的后果**：受伤、战友死、道德选择、惨胜；战役要解决一条人物弧光线，不只是地图上的推进

### 二、远景-近景语法（直接对应分镜）

| 景别层 | 内容 | 写作方式 |
|---|---|---|
| 将军远景（1-2拍） | 战线全貌、巨兽规模、部队调动 | 极简：一个画面＋一个规模细节（地平线全黑、遮天的飞行兽） |
| 战报层（穿插） | 看不见的战场动态 | 经POV转述："号角。地面在震。东面有东西进来了。" |
| 士兵近景（主体） | 锚点人物的具体任务与伤亡 | 完整场景写法（目标-冲突-两难，见条目334） |

**交替节奏**：远景给定位→立即切回近景给体验。连续远景＝纪录片，连续近景＝不知道大战在打什么。

### 三、三种身份的笔触不可混写

- **指挥官**：短句命令，命令里泄露战略——"守浅滩，不守山头。"
- **士兵**：感官碎片——"嘴里全是灰。看不见旗了。"
- **平民**：给一个具体任务——躲、跑、出卖、记录。三种身份的文字混在同一段＝可读性崩溃

### 四、可读性的免费工具：天气与能见度

- 雾：藏住大军直到号角响（悬念＋省钱）
- 雨：泥泞废掉冲锋，改变战术
- 烟：把战场切成"房间"，每个房间里是一场可读的小型战斗——**这是处理"巨物战场"的最佳武器**，深渊之核体表的蒸汽/尘柱天然提供这种分隔
- 夜战＋信号弹：光源即注意力引导，亮处打仗、暗处埋恐惧

### 五、声音是规模的第一载体

- 关键声变要标注：号角＝撤退指令、**突然的寂静＝最深的恐惧**（声音设计见条目151-160）
- 巨兽的"存在感"优先用声音建立：脚步声先于全貌、低频震动让水面/钢盔起颤
- 层次：脚步低频→兽潮嘶吼中频→人类武器高频→某个瞬间全部抽空（静默领域的声音设计直接可写）

### 六、动作的"节拍"而非"逐招笔录"

- 战斗文字写**节拍（beats）**不写流水账：一个节拍＝一个意图动作＋一个结果。短句加速，长句放慢
- 加速与减速交替：连续短节拍搏杀后，**一个慢镜头细节**（断矛缓缓旋转、他看见来袭者的眼睛）——速度差就是冲击
- 一处生动的伤胜过三处方格化砍杀；伤口要影响后续行动（手臂废了改用左手）

### 七、巨物战（kaiju）专用要点

1. **规模对比三连**：人体→建筑→巨兽，用参照物递进（人站在城墙下→城墙只到巨兽脚踝）
2. **局部即全貌**：篮球场大的鳞片、爪缝里滴落的腐蚀液、一次呼吸掀翻直升机——巨物靠特写成立，不靠全身远景
3. **攻击要改变地形**：巨兽每一击后重画一次地图（护城河被填平＝战术失效，逼迫新决策）
4. **无效攻击的展示纪律**：打不动的事实只需要完整展示一次（导弹在鳞甲上炸开白痕），之后用角色反应带过，重复展示会泄气
5. **人与巨兽不要直接"对打"**：人改变的是巨兽的**行为**（引开、误导、让它转身），不是血量——这是《海裂》"骗走而非击败"设定的写作优势

### 八、战后去动员（demobilization）

不要在全景大画面上结束。落在一个人物动作上：丢剑、背尸体、拒绝命令、烧旗。再给一个短过渡显示时间流逝与代价沉淀——观众需要情感上的"解甲归田"。

## 关键参数 / 模板 / 清单

**乐章表模板（攻城战专用）**
```
一句话目的：
POV锚点（≤3）：
地理一句话：
乐章1 接近：谁在动｜结果行：
乐章2 首撞：谁赢了第一下｜结果行：
乐章3 逆转：什么翻盘｜结果行：
乐章4 代价：人物失去了什么｜结果行：
规模暗示点（声音/烟尘/战报，3处）：
战后人物动作收尾：
```

**清晰度测试**：读完草稿，用四句话大声复述整场战役。做不到→简化地理或砍POV。
**命名测试**：列出所有有台词角色；超过不看笔记能记住的数量→合并。
**页数纪律**：连续10页（≈10分钟）不中断的战斗会耗尽观众——用决策、逆转、短暂的室内/安静拍点打断。
