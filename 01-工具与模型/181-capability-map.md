## 知识库使用流程

```
0. 先过顶部"总调用流程"十阶段，定位当前任务在哪个阶段、该阶段必过清单是什么
1. 明确任务场景 → 查本总图场景块找条目号（场景块没覆盖 → 查症状表）
2. 按编号读条目（文件：[编号]-[slug].md）
3. 按related字段横向扩展阅读
4. 实战应用 → 翻车 → 记录新问题
5. 新问题沉淀为新条目（176流程）→ 刷新索引
6. 定期回顾本总图，发现能力盲区（180体系）
```

## 常见坑
- **只存不查**：条目写完就忘，下次重新学——总图存在的意义就是防这个
- **查完不看related**：单点知识孤立应用，效果减半
- **编号错乱**：新建条目不续号=索引混乱，关联断裂
- **总图不更新**：新条目加了总图没更新=地图失效
