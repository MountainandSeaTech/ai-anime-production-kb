# 即梦/豆包 动作张力生成技巧

## 核心要点
- 即梦**中文理解最深**——可写分镜脚本式提示词
- 动作幅度中等可控——比 Gen3 强、比 Kling 温和
- 适合**国风/二次元短剧**——风格化强
- 强项：风格统一/角色定妆/场景氛围

## 即梦的张力强项

### 1. 中文叙事理解（最强）
- 可写："剑客立于雨中，缓抬头，刀出鞘，斩落，雨水分两半"
- AI 按叙事顺序生成=有节奏感
- 比 Kling 更懂"意境词"（肃杀/苍凉/凛然）

### 2. 风格化
- 国风水墨/二次元/赛博——风格锁定强
- 画面美术统一——适合系列短剧

### 3. 角色定妆
- 即梦的图生视频角色一致性较好
- 先出定妆图再动=一致性高

### 4. 场景氛围
- 雨/雪/雾/月光——氛围渲染强
- 适合 build 段（环境张力）

## 张力镜提示词模板

### 国风对峙
```
国风动画，雨夜竹林，剑客持伞缓步走来，低角度仰拍，
雨水沿伞沿滴落，面部半隐阴影，肃杀氛围，缓推特写，
眼神凛然，24fps，电影感
```

### 二次元爆发
```
二次元风格，少年握拳怒目，头发逆立，背景速度线爆发，
低角度仰拍，冲击帧定格0.5秒，色块冲击，热血张力
```

### 意境留白
```
水墨风，孤舟停于江面，蓑笠翁不动，雪花缓落，
镜头缓拉远，江天一色，留白，孤寂余韵，长镜
```

### 出刀一瞬
```
特写手握刀柄，刀身反光一闪，出鞘瞬间残影，
对手发带断开飘落，定格半秒，肃杀，侧光高对比
```

## 分镜脚本式提示词（即梦专属）
- 三段式：**场景+动作+镜头**
- 例：`[雨夜竹林] + [剑客缓步走来，刀出鞘斩落] + [低角度仰拍缓推特写]`
- 每段逗号分隔，AI 按序理解

## 风格锁定词
| 风格 | 锁定词 |
|---|---|
| 国风 | 国风动画/水墨风/工笔重彩 |
| 二次元 | 二次元/赛璐璐/日系动画 |
| 赛博 | 赛博朋克/霓虹/全息 |
| 写实 | 电影感/写实/8k |

## 常见坑
- **动作太复杂**：即梦动作幅度中等，复杂打戏→拆镜
- **风格不锁**：不写风格词→随机风格；必加风格锁定
- **意境词缺**：只写动作没意境→干；加"肃杀/苍凉/凛然"
- **超8s**：长镜→后段糊；拆短

## 进阶
- 即梦出定妆图 → 图生视频锁角色（见 088）
- 系列短剧用即梦统一风格——降低风格漂移
- "意境词+动作+镜头"三段式是即梦最佳写法
