# Kling（可灵）张力镜生成技巧

## 核心要点
- Kling 强**动作连贯**与物理感——适合打戏/转身/奔跑
- 提示词写**动作链**（A→B→C）而非单帧描述
- 物理重力/衣物摆动/惯性比 Gen3 真实
- 中文提示词友好，写"情绪+动作+镜头"三段式

## Kling 的张力强项

### 1. 动作连贯（最强）
- 出拳/踢腿/转身/冲刺——动作链不易断
- 物理惯性：衣物/头发/披风摆动跟随真实
- 重力感：跳跃落地有重量=打击感强

### 2. 表情幅度
- 大表情（怒目/咬牙/惊恐）比 Gen3 稳
- 适合情绪张力段（对峙/暴怒/绝望）

### 3. 群像（2-3人）
- 两人对打/对峙比 Gen3 不易崩
- 3 人以内小群像可控

### 4. 中文语义
- 中文提示词理解深——可直接写中文
- 写"剑客缓步逼近，刀光一闪，对手后退"这种叙事链

## 张力镜提示词模板

### 冷兵器对峙
```
镜头缓推，剑客持刀缓步逼近，眼神冰冷，低角度仰拍，
逆光剪影，披风随步摆动，对手后退半步，紧张对峙，24fps
```

### 冲刺爆发
```
角色猛然蹬地冲刺，地面碎石飞溅，衣摆向后拉直，
低角度跟拍，速度线残影，冲击瞬间定格半秒，120fps慢镜
```

### 转身拔刀
```
背影特写，角色缓缓转身，手握刀柄，刀光出鞘一瞬，
侧光半明半暗，面部表情由平静转冷酷，缓推至特写
```

### 压迫逼近
```
反派缓步走来，每步地面微震，低角度仰拍，
逆光，面部阴影笼罩，周围人后退，压迫感极强，慢速
```

## 动作链写法（关键）
- 错误：`角色在打斗` （太散→AI 自由发挥→崩）
- 正确：`角色蹬地→冲刺3步→起跳→空中转身→下劈落地`（动作链=可控）
- 每个动作节点写清，AI 按链生成=连贯

## 与 Gen3 的分工
| 场景 | 用谁 | 理由 |
|---|---|---|
| 打戏/动作 | Kling | 动作连贯物理感强 |
| 运镜/环境 | Gen3 | 运镜稳光影强 |
| 表情特写 | Kling | 大表情稳 |
| 慢镜空镜 | Gen3 | 氛围强 |
| 群像≤3人 | Kling | 不易崩 |
| 单主体氛围 | Gen3 | 更稳 |

## 常见坑
- **动作链太长**：写5个以上动作→后半段崩；拆成2-3个动作/镜
- **不写镜头**：只写动作→机位随机；必加"低角度/仰拍/特写/缓推"
- **情绪空缺**：只写动作没情绪→干；加"冰冷/暴怒/惊恐"
- **超10s**：长动作→后段漂移；拆镜拼接

## 进阶
- 先 MJ/即梦 出角色定妆图 → Kling 图生视频锁一致性（见 088）
- 多段动作拆多镜：A镜出拳→B镜对手反应→C镜落地——剪辑拼
- 用"负向提示词"：`no deformation, no extra limbs, no background distortion`

## 备注
- Kling 扬长：动作连贯/物理感/大表情/小群像/中文
- 提示词写动作链 A→B→C，不写单帧
- 与 Gen3 分工：Kling 管动作，Gen3 管氛围
- 单镜≤10s，长动作拆多镜拼接
- 物理惯性（衣物/披风/碎石）是 Kling 张力加分项
