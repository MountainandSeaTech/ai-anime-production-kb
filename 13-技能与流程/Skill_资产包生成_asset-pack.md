# 资产包生成（Asset Pack）

四件套交付的第 2、3 件（总规范见《番剧制作四件套交付规范》）。核心目标：**分镜里出现的每个具名元素都有出图依据，且跨镜、跨集形象不漂移**。沉淀自《天龙八部》S1E1/S1E2 三轮实践口径。

## 触发场景

- 要求给某剧/某集出角色提示词、定妆图、三视图、表情组
- 要求场景概念图、道具设定图
- 制作本写完后补齐资产——或与制作本同批次交付（铁律②，只交分镜不交资产＝不合格）

## 主要画风（默认口径）

**写实电影感（photoreal cinematic）为主要画风**——未特别指定时，全部资产与分镜都按此出图。

```
风格词（全片共用同一串）：photorealistic, live-action cinematic, film grain,
  natural light ratio, shallow depth of field, 35mm lens
负向词：anime, cartoon, cel shading, 3D render, CGI, illustration, 画风漂移
```

- 全片**只用 1 张风格参考图**锁死，中途不换（见 113 风格锁定）
- 戏核另有要求时（如喜剧/童话需 2D 动漫）可切换，但**必须显式声明且全片一致**，不许混用
- 写实风下的特效/冲击帧应用边界守 307，不做卡通化、不做游戏特效感

## 前置询问（三道门，按顺序过）

**门一｜能力探测——拿到剧本的第一件事**
问：**是否具备 Wonder-Image-2（出图）与 WAN3.0（出视频）的模型 API？**
- 两者都有 → 资产可按"提示词 → 自动出图"一步到位，并衔接后续视频生成
- 只有出图（Wonder-Image-2）→ 交付资产图与提示词，视频另行安排
- 都没有 → **只交付中英提示词包**（资产卡），不承诺出图，避免交付承诺落空

**门二｜是否建本地资产库——提示词输出完成后再问**
问：**是否在本地生成本地资产库？**
- 用户答**有/是** → 执行"建库动作"；**若具备出图 API（Wonder-Image-2），开始出图前还必须再问一次「是否要生成资产图？」，用户确认后才逐条出图**，不得自动开跑
- 用户答**否** → 只交付提示词文件，不再出图

**门三｜视频生成——资产确认之后才可进入**
- **硬前提**：本地资产库的资产必须**先经用户确认定稿**（形象、编号、参考图）；**资产未确认，不得生成视频**
- **必须再问一次**：进入视频生成前，问用户「**是否生成视频？**」，用户确认后才执行，不得默认开跑
- **参考挂载**：生成时必须**使用该分镜所需资产作为参考**——按逐镜清单把该镜对应的 `char_／env_／prop_` 资产编号文件挂上（沿用 WAN3 上限 10 图：正典脸 4／全身多角度 3／场景 2／风格 1），**禁止跳过资产参考裸跑提示词**
- 无出视频 API（无 WAN3.0）时，门三不触发，只交付提示词与资产

## 建库动作（门二确认后执行）

1. **建目录**：`<剧名>/02_资产/{characters,scenes,props}/`
2. **逐资产出图落盘**（出图前须先按门二征得用户确认）：文件名与分镜提交块的引用逐字一致：`char_角色名.png` ／ `env_场景名.png` ／ `prop_道具名.png`
3. **给生成的资产编号**：按下方 seed 段位登记（81xx／87xx／93xx／91xx／92xx），全库唯一；同制式道具、同角色跨集复用同一编号，绝不重开
4. **落库登记**：编号落进资产清单，形成「资产编号 ↔ 文件 ↔ 出场镜」三列映射，供逐镜核对
5. **做好分镜参考**：分镜生成前把该段所需资产按 WAN3 的 10 图参考上限配齐（正典脸 4／全身多角度 3／场景 2／风格 1），交付时**与分镜包一同提交**（角色资产图＋场景图即便角色离屏也上传，保画风一致）

## 交付形态

- **全剧批次 0**：`<剧名>_批次0_全员定妆图提示词_vN.md`——主角团＋十二要角＋群像模块＋地域概念图＋跨季伏笔角色（提前锁形象）
- **单集包**：`<剧名>_SxEx_角色提示词_vN.md` ＋ `<剧名>_SxEx_场景与道具提示词_vN.md`——主要角色"本集状态"版＋本集专属配角＋本集场景道具
- 产出后在制作本 §2 加一行导航；既有文件只做增量（新集状态层），不重复造基础条目

## 步骤

1. **盘点具名元素**：通读制作本/压缩表，列全：具名角色（含只出场一两镜的对手方，不能混进群像）、场景（含建场大远景、门口、由内转外交界镜）、道具（含对手兵器——需与主角兵器同框可辨）
2. **查 seed 段位**：先看既有资产文件最大 seed，新条目顺延，全库唯一
3. **按模板逐条写**（三种模板见下），中英双版
4. **色系对位**：对立角色与兵器做"同框可辨"色差（例：东宗深青袍＋青光剑 vs 西宗浅铁青袍＋灰白剑）
5. **血缘/神似对照**：母子、易容、"真人 vs 雕像"等相似对设为定稿门槛（例：钟灵×甘宝宝眉眼；王语嫣×玉像）
6. **锚点表收口**：文件末尾附"角色/道具 × 出场段 × 关键镜 × 连戏要点"锚点表，能对上逐镜清单（Skill《逐镜资产核对》产出件）

## 三种条目模板

> **铁律：每个资产的正向提示词与负向词必须在同一个代码块内**——正向在前、`Negative:` 行在后，一次复制即可直接粘贴。禁止把负向词拆到单独代码块或另起段落：拆开会漏贴、错贴。格式范本见 379（火焰爆炸提示词模板，正向正文＋末行 `Negative:` 同块）。

**角色**（主角表情组 6 张／配角 3 张）
```
角色名（seed 8xxx）｜三视图：正/侧/背差异点｜表情组：按人设选
[中] 定妆词：时代＋年龄＋体型五官＋服装（色系/材质）＋姿态特征＋恒定随身物；白底三视图；柔和影棚光
[EN] <full character anchor prompt: hair / eyes / face / outfit / material / pose / signature prop>
Negative: 仅此角色会翻车的（如 "no sword, no callus on palms, extra fingers, no glasses"）
```

**场景**（每场景一张概念图＝该场景生成时的首帧底图）
```
SC-x 场景名（seed 91xx）
[中] 一句话特征＋光位/色温＋与相邻场景的色彩关系（渐冷/渐暖曲线）＋必画清的结构要素（如"横梁必须画清——有人要伏"）
[EN] <full scene prompt block: place + landmarks with spatial relation + light direction + palette>
Negative: 常见崩坏（如 "no people, no distorted architecture, no extra pillars, no watermark"）
```

**道具**（必须完整 prompt block，禁止只留一行表格）
```
道具名（seed 92xx，持有者）｜三视角＋白底双光
[中] 完整中英 prompt block＋状态变体（高频道具按动作存多态，如扇＝展开/合拢两态＋轻摇/攥紧/放置三态）
[EN] <full prop prompt block>
Negative: 材质错/骨数错/该在时不在（如 "wrong material, wrong number of ribs, missing when held"）
```

## seed 段位（全库唯一）

```
81xx 主角 ｜ 87xx 要角 ｜ 93xx 单集专属配角（每集文件内连续递增）
91xx 场景 ｜ 92xx 道具
同一制式道具、同一角色跨集复用同一 seed，绝不重开
```

## 状态与随附规则

- 伤妆/破损/易容：起始镜全库统一口径；跨集延续物标注"跨集确认镜"
- 服装附件（腰囊）、场景陈设（桌椅）：随角色/场景锁定，不单立道具，避免过度拆分
- 恒定随身物在定妆词里写死（如"折扇永远在右手"）

## WAN3 多模态参考素材类型指引

Wan 3.0 支持 **10 图 + 5 视频 + 5 音频** 参考上限。资产包生成时需同步产出多模态参考素材并标注，以下为三类素材的入库规范：

### 音频参考（≤5条上限）
每条标注三项：**乐器 / 情绪 / 节拍(BPM)**。用途是引导 Wan 原生生成音画同步的 BGM/音效。
```
[A-REF-001] 古琴 + 苍凉 + 72BPM  →  段誉出场主动机（全剧复用）
[A-REF-002] 尺八 + 肃杀 + 120BPM  →  竹林决斗 BGM（单集复用）
[A-REF-003] 重击鼓点 + 紧张 + 180BPM →  招式碰撞拟音（动作段通用）
```

### 视频参考（≤5条上限）
每条标注三项：**动作 / 机位 / 时长**。用途是动作一致性锁——同一动作跨镜/跨集保持步态/手势/运镜角度。
```
[V-REF-001] 凌波微步 侧机位跟拍 3.2s  →  段誉 64 卦步法步态锁
[V-REF-002] 降龙十八掌 低角度仰拍 1.8s →  萧峰出掌收势帧速率锁
[V-REF-003] 云剑七式 正面跟 2.4s  →  慕容复剑招连贯性
```

### 10 图参考上限分配建议
Wan3 单次生成最多挂 10 张图参考，以下为番剧单段生成时的最优分配比例：

| 类型 | 数量 | 说明 |
|---|---|---|
| 正典脸参考 | 4 | 主角正脸/侧脸/表情基准图，每角色锁 1 张正典脸 |
| 全身多角度 | 3 | 同一角色正面/背面/3/4 角度全身，防换装漂移 |
| 场景参考 | 2 | 当前段场景概念图 + 相邻场景光位参考 |
| 风格参考 | 1 | 统一画风/材质/光影基调，跨集风格锁 |

**铁律**：10 张图里**正典脸必须先占满**——角色脸崩比场景崩代价大得多；风格参考永远只放 1 张，多了会干扰角色锚定。
