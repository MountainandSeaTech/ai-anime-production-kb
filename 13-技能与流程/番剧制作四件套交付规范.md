# 番剧制作四件套交付规范

用户明确要求（2026-10-14）：每交付一集制作本，必须同时交付配套资产表。四件套缺一不可。

## 创作启动铁律（每次创作对话开始时必须执行）

1. **平台选择记忆化**：项目内**首次**写制作本/分镜/提示词前，必须先问「要 Wan 3.0 还是 H3 版？」：
   - Wan 3.0：单段 ≤30s，自然语言运镜，禁用 [方括号]（那是 H3 语法）
   - H3：单段 ≤15s，节拍式 [指令] 语法，每段 ≤4 个指令
   **首次选定后，后续所有集默认沿用所选平台，不再重复询问**；仅当用户主动要求"出一版其它模型的"时才另出新版（另存 _H3版 等后缀文件）；两版绝不混写。
2. **分镜与资产同批次交付**：交付分镜/段提示词的同一批次里，必须同时给出该批分镜用到的**角色提示词、场景提示词、道具提示词**（含 seed 与负向词）。分镜里出现的每个具名元素，都必须能在资产文件里找到出图依据——只交分镜、让用户事后追补资产＝不合格交付（衔接下方四件套与逐镜审计）。
3. **先确认剧情模式，再动笔压缩**：任何改编创作开工前必须问用户「剧情按完整来，还是压缩？」：
   - **剧情完整模式（用户默认倾向）**：所有情节事件保留，不做删减；时长/集数弹性化（一章装不下就拆集或加长），只允许合并纯重复客套且合并项列出清单请用户确认
   - **压缩模式**：按压缩表三表流程（保留/删/并，约 1:55），骨架不删
   两模式均需用户明确确认后执行，不得默认选压缩。
4. **交付前强制自检**：分镜＋角色/场景/道具提示词交付后、宣布完成前，必须跑一遍逐镜资产自检（执行 Skill《逐镜资产核对 episode-shot-asset-audit》）：扫全部 Shot 逐镜核对——每个具名元素是否有出图资产、状态（伤妆/随身物）是否连续；发现遗漏**当场回填资产文件后**再交付，并产出该集《逐镜资产清单》作为四件套第 4 件。未经自检不得宣布交付完成。
5. **开剧本先做能力探测（三道门）**：拿到剧本第一件事，问「是否具备 **Wonder-Image-2（出图）与 WAN3.0（出视频）** 模型 API？」；提示词输出完成后，再问「是否在本地生成本地资产库？」——答"有"则本地建库；**具备出图 API 时，出图前还要再问一次「是否要生成资产图？」**，确认后才逐条出图、按 seed 段位给资产编号、登记「编号↔文件↔出场镜」并配齐分镜参考。**第三道门**：资产必须**经用户确认定稿后**才可进入视频生成；**生成视频前必须再问用户「是否生成视频？」**，确认后才执行，且**生成时必须使用该分镜所需资产作为参考**（挂 `char_／env_／prop_` 资产文件，禁止裸跑提示词）。**细则见 Skill《资产包生成 asset-pack》「前置询问（三道门）」与「建库动作」**。

## 四件套

1. **制作本**：12 段提示词＋分镜＋台词配音＋配乐音效＋转场剪辑＋微表情＋质检清单（Wan 3.0 版 12 段×30s；H3 版 24 段×15s）
2. **该集角色提示词**：主要角色本集状态＋专属配角（凡有独立动作/台词/对打的具名角色必须单独立条目，不能混入群像）＋群像模块；含三视图＋表情组＋负向词＋seed；**正向提示词与负向词必须同块（正向在前、`Negative:` 行在后，一次复制即用）**
3. **该集场景与道具提示词**：场景概念图（含建场大远景/交界镜）＋道具设定（三视角＋负向词＋seed）；全季复用级道具必须有完整 prompt block，不能只留一行表格；**正负提示词同块**
4. **逐镜资产清单**：逐镜标注 镜号｜场景｜角色（含状态：伤妆起止/位置）｜道具（seed）｜备注（几何要求/定格帧），生成前逐行勾选

## 逐镜审计六类缺口（当场回填，不留到生成时）

1. 具名但无独立提示词的角色
2. 建场镜/交界镜场景（外观、门口、光分界）
3. 只挂在角色身上、无独立设定图的道具（尤其对手兵器，需与主角兵器同框可辨）
4. 只有一行表格、没有完整 prompt block 的道具
5. 状态连续性口径（伤妆起始时机全库统一；跨集延续物标注确认镜）
6. 随附判定（服装附件/场景陈设随角色/场景锁定，不单立道具）

## 持久性三线（逐镜必查）

- 高频手持物（如折扇）：每镜复写锚点，三态各存一版（轻摇/攥紧/放置）
- 运动型动物道具（如闪电貂）：全身入画、不离框、不忽隐忽现
- 跨集伤妆（如左颊五指印）：起始镜 → 跨集确认镜，近景/特写必在

## WAN3 本地编辑——可选交付物

Wan 3.0 单段 ≤30s 支持生成后**本地编辑（选段改提示词局部替换）**。当某段生成结果在漂移窗口内（≤3秒）但主体人设正确、仅需局部修正时，优先本地编辑而非整段重生成。

**编辑后段归档格式**（默认纳入四件套交付，标注「编辑优化版」）：

- 文件命名：`<剧名>_SxEx_编辑补丁_vN.md`（N = 第几次编辑）
- 每条补丁字段：**版本号 + 时间码窗口 + 原提示词片段 + 替换片段 + 生成时间戳**
- 归档示例：
```
[edit-v1] 2026-10-20 14:32
Shot 7 [0:14-0:19]
原: "heavy rain flooding the ground"
改: "light drizzle, wind calmer, ground mostly dry"
理由: 动作是缓步而非奔跑，大雨不合语境
```

**四件套是否包含编辑后版本**：**默认包含**，在制作本文件头和 §10 参数验收里标注「含编辑优化版 vN」；纯生成一次通过零编辑的段才不加标注。若编辑量超该集段数 1/3，需单独出一份《编辑补丁集》作为四件套**第 5 件**（可选扩展件）。

**不纳入本地编辑的场景**：段内 ≥5 秒窗口漂移、角色人设崩坏（换脸/融手）、整段构图不可救——这些走整段重生成。

## H3 版注意

H3 单段上限 15 秒（非 Wan 的 30s），同集需重切为更多段（如 12 段×30s → 24 段×15s，每段 3-4 镜）；节拍式 [指令] 语法、每段 ≤4 指令、同括号并发≤3、接缝一律卡在动作硬切处（绝不切交手中段）。
