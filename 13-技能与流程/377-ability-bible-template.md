# 技能魔法编写二十连⑳：全剧能力圣经

## 核心要点

- **圣经第一原则：凡观众已被告知为真的，必须持续为真，除非故事明确地让它演化**——无声打破自己的规则是失去观众信任最快的方式
- 能力圣经是全剧"能力正典"的唯一事实源：规则、能力卡、术语、强度标尺、登场时间线、视觉资产、变更记录七位一体
- **AI番剧的圣经还要管生产**：每个能力的正典帧ID、提示词模块版本、元素板文件位置——编写正典与生成正典在同一文档挂钩（374）
- 规则不是不能改：任何改动走"登记→影响面评估（前置剧情/资产/台词）→演化剧情→版本号"四步，严禁为单集便利打补丁

## 详细内容

### 一、文档结构（九章模板）

**0. 封面与版本**
- 作品/季/版本号/最近更新日期/维护人
- 一句话主题句＋一句话能力总纲（如"力量来自沟通，代价是自我消融"）

**1. 世界规则层（359）**
- 能量从哪来/硬禁止清单（全剧所有能力都不能做的3-7条）
- 硬软分区：哪些规则观众可知、哪些保持神秘到哪一季
- 社会四态：能力者在社会中的位置、组织、法律、经济
- 逻辑模型锁定（若含时间/空间系，375）

**2. 能力卡总册（361，每能力一页）**
- 名称与俗称（360）｜体系归属｜五要素（触发/I-O/代价/边界/失败）
- 克制链（克谁/被谁克，368）｜与角色绑定（364）
- 代价三档与催债时间点（362）
- 形态/升级路线与触发条件（370）
- 非战斗用法三个

**3. 强度标尺（363）**
- 天花板定义＋占据者
- 标志物三档标尺（入门/高手/天花板）
- 强者名录与不出手的规则性理由

**4. 阵容与关系（373/376）**
- 职能位表＋战场问题覆盖矩阵＋团队盲区
- 契约/伙伴兽档案（生态卡＋关系模型＋契约条款）
- 反派镜像配置

**5. 术语表（372）**
- 三列：圈内术语／俗称／功能描述
- 首登场集次＋锚定画面＋复习安排
- 命名体系句法规范（360）

**6. 时间线**
- 能力登场/首秀/升级/失效/代价发作的集数排期（365/369/370）
- 规则投放进度：观众每集结束后"知道什么"的清单（第一定律审计）
- 伏笔登记（编号/埋设集/计划兑付集）——防ass pull

**7. 视觉资产索引（374）**
- 每能力：签名特效规格（意象/色板/粒子/声音/后果）
- 正典三帧文件ID、提示词模块版本、负向串、元素板路径
- 显形级L1-L4镜头规格与预算
- 形态/失能态/残效独立资产

**8. 对白与声音档**
- 各角色谈论能力的口径（学者/老油条/新人，372）
- 喊招清单与喊法表演说明
- 声音设计要点交音频（发动音/环境反应/静默节拍，304）

**9. 变更记录（治理）**
- 版本号｜改动内容｜原因｜影响面（哪些集/卡/资产要同步）｜审批
- 废弃规则不删除，标"已演化＋演化剧情集次"留痕

### 二、规则演化的合法流程

剧情需要突破旧规则时：
1. **登记**：想改哪条，为什么现有规则不能产出戏
2. **影响评估**：列出所有前置剧情中依赖该规则的镜头/台词/资产
3. **优先外推**：先尝试用359深挖法在旧规则内解；解不了才演化
4. **演化入戏**：突破本身写成一场有代价的戏（发现/实验/牺牲），不做无声重设
5. **升版同步**：圣经升版本号，受影响资产（正典帧/模块）重做登记
- 禁止：写某集时临时让能力多一个功能救场（New-Powers-as-the-Plot-Demands）

### 三、每集开机前的能力审计（过审清单）

```
□ 本集出现的所有能力均在圣经在册
□ 使用方式不违反已投放规则（对照第6章"观众已知"）
□ 新规则/新形态：首秀五拍齐＋伏笔已埋（365/370）
□ 代价记账：上次代价状态延续（138）
□ 术语：本集新词≤预算，锚定画面已排
□ 视觉：模块引用版本号正确，正典帧比对安排
□ 强度：本战胜利来源属智斗/代价/信息差，非数值碾压（363）
□ 圣经变更单：本集是否产生规则演化（是→走五步）
```

### 四、与既有制作文档的挂载

- 番剧制作四件套规范（本分类既有）：能力圣经作为世界观附件随制作本下发
- 分镜表"技能列"直接引用圣经第7章资产ID（374字段）
- 逐镜资产自检清单：能力相关镜必查正典引用
- 混音/声音档走247流程
- 文件命名建议：`能力圣经_作品名_v0.3.md`＋`/assets/fx/能力名/`

### 五、最小可用版（小项目不必九章全做）

- 短片/单集最小集：第0章两句＋第2章（主角能力卡1-3张）＋第1章硬禁止清单＋第7章签名规格
- 季播完整版：九章全建
- 判断标准：一个没参与前期的同事，只看圣经能否正确写出一场能力战且不违规——能，文档就够了
