# 《剧名》SxEx 逐镜资产调用清单 vN（Shot × Assets）

> 用途：生成每一镜前逐行勾选"该镜调哪些资产、角色什么状态、道具在不在手"。
> 覆盖 SxEx 全部 12 段共 NN 镜。资产来源：批次0、SxEx 角色提示词、SxEx 场景与道具提示词。
> 用法：先看 §0 代号 → 按段查 §1–§12 每镜一行 → 缺口见 §13。

## 0 资产代号

**场景 SC**
```
SC-x  场景名（一句话特征） 出处文件章节 / seed
```

**角色 C**
```
缩写=角色名(seed，恒定随身物；伤妆起止镜)
```

**道具 P**
```
缩写=道具名 seed（持有者/制式）
```
