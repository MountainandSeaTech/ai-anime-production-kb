# 产品宣传片制作总纲（支线入口）

> 本支线收纳**产品宣传片**领域的制作方法论，与知识库主线（AI 视频动漫短剧）并行。
> 来源：[video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) — 用 Remotion 代码逐帧绘制产品宣传片的 Skill。

## 领域定位与核心差异

| 维度 | 产品宣传片（本支线） | 动漫短剧（主线） |
|---|---|---|
| 生成方式 | Remotion 代码逐帧绘制（确定性） | WAN3/H3 AI 生成（概率性） |
| 主体 | 产品 UI 页面、字卡、数据 | 角色、场景、动作 |
| 动效 | UI 元素入场/转场/数据滚动 | 角色表演/战斗/法术 |
| 节奏 | 强鼓点 BGM 卡点为主 | 叙事节奏 + 动作节奏 |
| 声音 | 电影系 SFX 词汇表（whoosh/impact/riser/sparkle） | 拟音 + 配乐 + 音效 |
| 验收 | 逐帧静帧肉眼验收 + ffmpeg 抽帧 | 逐镜资产核对 + 连贯性检查 |

**可交叉借鉴的方法论**：节奏呼吸、机位服务可读性、特效节制、声音片种选择、字高可读性（451）。这些已并入主线条目。

**不可直接迁移的**：Remotion 工程细节（PageCam/CSS zoom/layout.json）、UI 动效配方卡的具体参数、剪映工程导出——这些是工具链，留在本支线或不入库。

## 124 镜头配方卡·10 分类索引

> 124 张卡 / 150 个镜头，分布在 10 个功能分类。每张卡 = 语义 + 参数表 + 已知坑，附 Remotion demo 源码。本索引只列分类与用途，具体卡名见原仓库 Gallery。

| 分类 | 用途 | 典型场景 |
|---|---|---|
| **opening** 开场 | 单主角完整动作弧（聚光→推近→悬浮→归位） | 开场 hero 镜头 |
| **outro** 收尾 | 发布会合影式组装 + crane 运镜 + 舞台光 | 全片能量峰值 |
| **camera** 运镜 | 2.5D 页面相机、orbit 环绕、crane 升降、push-in | 产品页面空间化展示 |
| **ui-entrance** UI 入场 | 飞入堆叠、发牌式硬加速、逐格填入 | 功能列表/网格展示 |
| **typography** 文字 | 字卡入场、描线揭示、数字滚动、下划线 | 标题/数据/卖点展示 |
| **data** 数据 | 图表绘制、计数器、流式输出、骨架屏 | 数据可视化段落 |
| **interaction** 交互 | 点击、打字、筛选、拖拽、滚动 | 功能演示段落 |
| **effects** 特效 | 扫光、粒子、光效 reveal、形变 | 高光时刻 |
| **transition** 转场 | 翻页、闪切、玻璃碎裂、swoosh | 场景切换 |
| **rhythm** 节奏 | 节拍泵、步进、收敛逼近、hold 呼吸 | 卡点段 |

**选卡原则**（来自 pipeline.md 阶段 2）：
1. 一种动画手法全片只当一次主角，同质化即返工信号
2. 按能量曲线选卡：开场低能量→功能段中能量→收尾高能量
3. 每镜只讲一个主要动效
