# 黑白与张力

## 核心要点
- 黑白=**去掉色彩=情绪抽离+明暗对比极致**——做减法到极限
- 用于：回忆（抽离现实）、死亡（断灭）、决别（悲的极致）、暴走临界（去色）
- 黑白是 065 单色的极致版——只留明暗
- 黑白的张力在"明暗差"被放大——无色干扰，光暗更狠

## 黑白的张力来源

### 1. 抽离=非现实
- 黑白=与现实不同=抽离=回忆/梦/死后
- 观众一看黑白=知道"这不是当下"=情绪预设

### 2. 明暗极致
- 无色=只剩黑白=明暗差最大=对比最狠
- 阴影更黑，光更白=064 高对比的极限

### 3. 凝练=庄重
- 黑白=去掉装饰=庄重/悲剧感
- 适合死亡/决别/神圣时刻

## 黑白的用法

### 1. 回忆/闪回
```
黑白闪回段（2s，抽离）→ 回彩色当下（0.3s，回现实）→ 定格（1s）
```

### 2. 死亡断灭
```
致命瞬间（0.5s）→ 去色转黑白+静默（0.8s，断灭）→ 黑白定格（1.5s）
```

### 3. 决别极致
```
黑白决别对峙（2s，庄重）→ 致命（0.3s）→ 黑白定格孤立（1.5s）
```

### 4. 暴走临界去色
```
被压濒败（1s）→ 去色渐转黑白（0.8s，临界）→ 爆发回色（0.3s）→ 定格（1s）
```
去色=将爆的信号，回色=爆发。

## 黑白的常见坑
- **全程黑白**：无彩色对比=无"抽离"信号=平
- **黑白无明暗**：黑白但灰平=无对比=无张力
- **黑白滥用**：每段都黑白=无特殊感
- **黑白无切换**：不回色=没"回现实"=悬空

## 黑白与彩色的切换=信号
- 彩→黑白=进入抽离/将断
- 黑白→彩=回现实/觉醒/爆发
- 切换瞬间=情绪转折信号

## 黑白与其他工具配合
- 黑白+高对比（064）=明暗极致
- 黑白+剪影（068）=极致剪影
- 黑白+静默（033）=抽离+留白顶配
- 黑白+负空间（020）=孤立极致

## 经典黑白张力场景

### 死亡断灭
```
彩色致命（0.5s）→ 去色黑白+静默（0.8s）→ 黑白定格（1.5s）
```

### 回忆闪回
```
彩色当下（0.3s）→ 切黑白闪回（2s）→ 回彩色（0.3s）→ 定格（1s）
```

### 暴走临界
```
彩色濒败（1s）→ 渐去色黑白（0.8s，临界）→ 爆发回色（0.3s）→ 定格（1s）
```

### 决别庄重
```
黑白决别对峙（2s）→ 致命（0.3s）→ 黑白孤立定格（1.5s）
```
