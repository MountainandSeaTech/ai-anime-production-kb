# 色温突变张力

## 核心要点
- 色温突变=**情绪反转的视觉信号**——暖转冷=信任崩塌/绝望，冷转暖=觉醒/希望
- 色温是情绪的"温度计"，骤变=情绪骤变=张力转折
- 与 063 色块骤变同源，但色温是渐变光谱的暖冷两端
- 色温反转=无台词的"立场/情绪反转"信号

## 色温与情绪

| 色温 | 情绪 | 张力用途 |
|---|---|---|
| 暖（橙/黄/红） | 信任、温、热血、生 | 并肩、日常、热血 |
| 冷（蓝/青/紫） | 冷、悲、死、叛 | 背叛、死亡、绝望 |
| 中性 | 平衡 | 过渡 |
| 绿 | 异常、腐 | 异变、病 |

## 色温突变的张力来源

### 1. 暖转冷=信任崩塌
- 暖色并肩→骤冷=关系破裂=背叛/绝望
- 色温反转=无台词的背叛信号（053）
```
暖色并肩（1s）→ 骤冷+背刺（0.3s，反转）→ 冷色定格（1s）
```

### 2. 冷转暖=觉醒希望
- 冷色绝望→骤暖=觉醒/反击/希望
- 冷转暖=055 变身的色温版
```
冷色濒败（1s）→ 骤暖+觉醒（0.5s，反转）→ 暖色反击（0.3s）→ 定格（1s）
```

### 3. 色温渐变=情绪渐变
- 不是骤变，渐变=情绪渐变=持续转折
- 暖渐冷=信任渐失；冷渐暖=渐觉醒

## 色温突变的用法

### 1. 背叛色温反转
```
暖色信任近景（1s）→ 骤冷+背刺（0.3s）→ 冷色受害者特写（0.8s）→ 定格冷色（1s）
```

### 2. 觉醒色温反转
```
冷色濒败（1s）→ 骤暖+觉醒特写（0.5s）→ 暖色反击（0.3s）→ 定格暖色（1s）
```

### 3. 色温渐变转折
```
暖色并肩（1s）→ 暖渐冷（1s，信任渐失）→ 全冷背叛（0.3s）→ 定格（1s）
```

## 色温突变的常见坑
- **色温无变化**：全程一温=无反转=平
- **突变无铺垫**：突然变=突兀=无情绪逻辑
- **色温与情不符**：觉醒用冷=错码
- **渐变太慢**：渐变拖=无转折感

## 色温与其他工具配合
- 色温+高对比（064）=情绪+明暗双反
- 色温+双色（065）=色温即双色
- 色温+静默（033）=情绪反转+留白
- 色温反转+机位反转（017）=双重反转信号

## 经典色温张力场景

### 背叛暖转冷
```
暖色并肩（1s）→ 骤冷+背刺（0.3s）→ 冷色受害者难以置信（0.8s）→ 冷色定格（1s）
```

### 觉醒冷转暖
```
冷色濒败（1s）→ 骤暖+觉醒（0.5s）→ 暖色反击（0.3s）→ 定格暖色（1s）
```

## AI 提示词
- 暖：`warm color temperature, orange amber tones, warm lighting`
- 冷：`cold color temperature, blue cyan tones, cold lighting`
- 骤变：`sudden color temperature shift, warm to cold, dramatic color transition`
- 渐变：`gradual color temperature change, warming up, cooling down`
