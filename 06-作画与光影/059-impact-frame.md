# 冲击帧/Impact Frame

## 核心要点
- 冲击帧（impact frame）=**接触/爆发瞬间用单张高细节静止图替换动画**，让"打中"被凝视
- 是峰值段最强作画工具——一帧的凝固=最大冲击（网上学习的核心技法）
- 冲击帧常配：速度线/集中线（058）、形变（060）、闪白（036）、重音效
- 张力来源：动画突然停止单帧=时间凝固=瞬间被放大=揪心峰值

## 冲击帧的原理（网上学习）
- 动画一直在动，到接触瞬间突然变成一张高细节静止图=视觉冲击
- "屏幕冻结一瞬，常配速度线/戏剧角度/音效"——让观者 soak in 力量、情绪、风格
- 是"视觉的重音效"——把瞬间变成可凝视的雕塑

## 冲击帧的张力来源

### 1. 时间凝固=峰值强调
- 动画→单帧=时间停=瞬间被无限放大
- 比 029 停顿更极端——不是动作中途停，是接触瞬间单图替换
- 凝固=不可逆的视觉确认

### 2. 高细节=力量视觉化
- 单帧用最高细节（肌肉/形变/光影）=力量被画出来
- 细节密度=力量感

### 3. 配件叠加=冲击翻倍
- 冲击帧常叠：集中线（058）指向、形变（060）、闪白（036）、重低音
- 多件叠加=一帧的信息量爆炸=最强峰

## 张力曲线
```
动画蓄势（1.5s，流畅）→ 接触瞬间冲击帧（0.1-0.2s，单图凝固）→ 重低音+闪白+形变（叠加0.1s）→ 动画继续/定格（0.5s）→ 定格余韵（1s）
```
冲击帧仅 0.1-0.2s（2-4帧），越短越狠。

## 冲击帧的三种用法

### 1. 击中瞬间（最经典）
- 拳/刀/能量击中瞬间的单帧
- 形变+集中线+重音
```
挥击动画（0.5s）→ 击中冲击帧+形变+线（0.15s）→ 受击飞动画（0.3s）→ 定格（1s）
```

### 2. 出招瞬间
- 大招释放瞬间的单帧
- 能量爆发+闪白
```
蓄招（1s）→ 释放冲击帧+闪白（0.15s）→ 能量束动画（0.5s）→ 定格（1s）
```

### 3. 反应瞬间
- 角色表情剧变的单帧（恍然/惊愕/决意）
- 面部高细节+集中线
```
对白（0.5s）→ 恍然冲击帧+面部线（0.15s）→ 反应动画（0.3s）→ 定格（1s）
```

## 冲击帧的常见坑
- **时长太长**：给 0.5s=变静止画=拖，不是冲击帧了
- **无配件**：单图无线无形变=干=冲击弱
- **每击都用**：每次都冲击帧=无对比=失效
- **细节不够**：单帧不拉细节=浪费峰值

## 冲击帧 vs 029 停顿 vs 021 升格

| 工具 | 机制 | 时长 | 强度 |
|---|---|---|---|
| 029 停顿 | 动作中途静止 | 0.3-1.5s | 中 |
| 021 升格 | 慢镜延展 | 0.5-2s | 中高 |
| 冲击帧 | 单图替换动画 | 0.1-0.2s | 极强 |

> 冲击帧最短最强，是峰值顶配。

## AI 生成的冲击帧实操
- AI 视频不直接产"冲击帧"，需后期：
  - 生成击中瞬间的高细节静态图（MJ/SD）
  - 在剪辑里替换动画那 0.1-0.2s
  - 叠集中线贴图+形变+闪白+重音
- 工具：剪映/AE，单帧替换+特效叠加
- 关键：冲击帧要高细节+多配件叠加+短时长

## 备注
- 冲击帧是网上学习的核心——动漫峰值最强作画工具
- 机制：动画→单图凝固=瞬间无限放大
- 必配：集中线+形变+闪白+重低音，单用则弱
- AI 视频靠后期叠加（生成静态图替换+特效），prompt 难直接控
- 时长极短（0.1-0.2s），长了变拖
