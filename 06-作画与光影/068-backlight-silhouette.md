# 逆光剪影张力

## 核心要点
- 逆光（backlight）把主体化为**剪影**=神秘+压迫+不可读
- 剪影看不到表情=不可预测=揪心（044 半隐半现）
- Boss 登场/决意瞬间/决别余韵的共同光影
- 逆光是 061 剪影化+064 高对比的交集

## 逆光剪影的张力来源

### 1. 不可读=神秘
- 剪影无表情=观众读不出意图=不可预测=揪心
- 比"看清脸"更威胁——未知即恐（044）

### 2. 轮廓=压迫
- 逆光勾出主体轮廓=形状感强=压迫
- 大剪影=体量压迫（Boss 巨影）
- 小剪影在负空间=孤立（046 决别）

### 3. 光源背后=权威
- 光从主体背后=主体背光=被光"加冕"=权威
- Boss 逆光=不可直视的威

## 逆光剪影的用法

### 1. Boss 逆光登场
```
逆光巨影剪影全景（1.5s，压迫）→ 剪影缓步逼近（1s）→ 出剪影露脸（0.5s）→ 压迫出手（0.3s）→ 定格（1s）
```

### 2. 决意剪影
```
主体逆光剪影近景（1s，决意）→ 剪影出手（0.3s）→ 出剪影露脸特写（0.5s）→ 定格（1s）
```

### 3. 决别余韵剪影
```
逆光剪影孤立全景（2s，余韵）→ 静默定格（1s）
```
剪影+负空间=决别顶配（046）。

## 逆光剪影的常见坑
- **剪影太久不露脸**：全程剪影=无揭示=拖
- **剪影无轮廓**：逆光不够强=半剪影=不纯粹
- **剪影太小无环境**：看不出压迫
- **剪影滥用**：每镜都逆光=无对比=失效

## 逆光剪影的进阶

### 部分露脸
- 剪影但一瞬露脸（眼神/嘴角）=半隐半现=最强
- 一瞬露脸=信息差释放=峰
```
剪影（1s）→ 一瞬露眼神特写（0.3s，揭示）→ 回剪影出手（0.3s）→ 定格（1s）
```

### 多剪影合围
- 多个剪影逆光=合围压迫（049 光影版）
```
多剪影逆光合围全景（1.5s）→ 主体被围（0.5s）→ 临界（0.3s）→ 定格（1s）
```

## 逆光剪影与其他工具配合
- 逆光+高对比（064）=剪影+明暗=压迫顶配
- 逆光+负空间（020）=孤立剪影=决别
- 逆光+静默（033）=神秘+留白
- 逆光+黑白（069）=极致剪影

## 经典逆光剪影张力场景

### Boss 逆光登场
```
逆光巨影剪影（1.5s）→ 逼近（1s）→ 露脸（0.5s）→ 出手（0.3s）→ 定格（1s）
```

### 决别剪影余韵
```
逆光剪影孤立全景（2s）→ 静默定格（1s）
```

### 部分露脸揭示
```
剪影（1s）→ 一瞬露眼神（0.3s）→ 回剪影出手（0.3s）→ 定格（1s）
```
