# 残影/Afterimage 张力

## 核心要点
- 残影（afterimage/smear）= 高速移动留下的拖影，制造**速度感+未消之动的悬念**
- 残影数量=速度=威胁程度——残影越多越快越险
- 残影"未消"=动作还在进行=延迟感=揪心；残影"消散"=动作完成=确认
- 残影是动态张力（012）的速度视觉化

## 残影的张力来源

### 1. 速度=威胁
- 残影越多=移动越快=威胁越大
- 观众读残影数量=读速度=读威胁
- 多残影逼近=危险加压

### 2. 未消之动=悬念
- 残影还在=动作未完成=下一步未定=悬念
- 残影定格不消=时间凝固在"动到一半"
- 这是 029 停顿的"高速版"——动作中途凝固

### 3. 残影消散=确认
- 残影消散=动作完成=结果揭晓
- 消散瞬间=峰值释放
- 消散后定格=余韵

## 张力曲线
```
残影逼近（多残影1s，速度威胁）→ 残影定格未消（0.5s，凝固悬念）→ 残影消散+结果（0.3s，峰）→ 定格（1s）
```

## 残影的三种用法

### 1. 速度逼近（残影多）
- 高速移动留多残影=逼近威胁
- 残影数量递增=速度加快
```
1残影（0.3s）→ 3残影（0.3s）→ 5残影（0.3s，最快）→ 抵达/出招（0.3s）→ 定格（1s）
```

### 2. 残影定格（凝固）
- 动作中途残影定格=高速中的静止峰
- 比 029 停顿更"动"——是动的凝固
```
高速移动残影（0.5s）→ 残影定格不消（0.8s，凝固）→ 消散+结果（0.3s）→ 定格（1s）
```

### 3. 残影消散揭晓
- 残影消散后揭晓"已经在背后/已经出招"=位置反转
- 消散瞬间=揭晓=峰
```
残影正面逼近（1s）→ 残影消散→ 人已在背后（0.3s，揭晓）→ 受击（0.3s）→ 定格（1s）
```

## 残影的常见坑
- **残影太多太频**：全程残影=无对比=晕
- **残影无定格**：一直拖=无峰值点
- **残影不消散**：不揭晓=悬空
- **残影方向乱**：拖影方向不一致=违和

## 残影 vs 速度线（058）

| 维度 | 残影 | 速度线 |
|---|---|---|
| 形态 | 主体拖影 | 背景线条 |
| 表现 | 主体速度 | 环境速度感 |
| 用法 | 高速移动 | 速度感强调 |
| 凝固 | 可定格 | 难定格 |

## AI 提示词
- 残影：`motion blur afterimage, trailing copies of character, high speed movement, smear`
- 多残影：`multiple afterimages, extreme speed, streaking echoes`
- 凝固：`freeze frame with afterimage suspended, motion frozen mid-dash`
- 消散：`afterimage fading, revealing final position, speed dissipating`

## 备注
- 残影是 012 动态张力的速度视觉化——残影数量=速度=威胁
- 残影定格不消=高速中的凝固峰（029 停顿的高速版）
- AI 视频残影靠 motion blur 关键词+后期叠加
- 残影消散揭晓位置反转是高级用法
