# 单色/双色张力

## 核心要点
- 单色/双色限制=**情绪纯粹+对比锐利**——去掉杂色让情绪/冲突被强化
- 单色压满=情绪凝固（063 色块的持续版）；双色对立=冲突可视
- 色彩限制是"做减法"=减法让剩下的色更狠
- 与 020 负空间同理——少即是多，色少=张力强

## 单色的张力

### 单色=情绪纯粹
- 全画面一色=情绪被强制纯粹
- 全红=纯暴怒，全蓝=纯悲，全灰=纯虚无
- 杂色去掉=情绪不被稀释

### 单色持续=氛围压满
- 与 063 色块瞬间不同，本条是**持续单色氛围**
- 全段单色=情绪贯穿=持续揪心
- 适合：悲剧整段、暴走整段、回忆段

## 双色的张力

### 双色对立=冲突可视
- 两色对立=双方冲突被画出来
- 红vs蓝=热血vs冷、主角红vs反派蓝
- 双色对峙=视觉上的"势不两立"

### 双色分配=权力编码
- 强者色占多，弱者色占少=权力可视
- 色比例反转=权力反转

## 单/双色的用法

### 1. 单色悲剧氛围
```
全蓝冷色决别整段（3s，悲持续）→ 致命（0.5s）→ 全蓝定格（1.5s）
```

### 2. 双色对峙
```
主角红 vs 反派蓝对峙（1.5s，双色对立）→ 出手双色交错（0.3s）→ 定格（1s）
```

### 3. 双色权力反转
```
反派蓝占多/主角红占少（1s，弱）→ 觉醒红色扩张（0.5s，反转）→ 红占多蓝退（0.5s）→ 定格（1s）
```

## 色彩的情绪编码（与 063 同表）

| 色 | 情绪 | 单色用途 | 双色对立 |
|---|---|---|---|
| 红 | 暴怒/血/热 | 暴走段 | vs蓝(冷) |
| 蓝 | 悲/冷/死 | 悲剧段 | vs红(热) |
| 黑 | 断灭/死 | 死亡段 | vs白(生) |
| 白 | 纯/超/爆 | 超能力段 | vs黑(灭) |
| 灰 | 虚无/旧 | 回忆段 | — |
| 紫 | 异/腐 | 异变段 | vs金(正) |

## 单/双色的常见坑
- **单色太久**：全段一色无变化=拖=无聊
- **双色太杂**：超过两色=失对立=乱
- **色与情不符**：悲用红=错码
- **无明暗变化**：单色但全亮=无层次=平

## 单/双色与其他工具配合
- 单色+负空间（020）=情绪+孤立
- 单色+静默（033）=情绪+留白顶配
- 双色+高对比（064）=冲突+明暗双对
- 单色+黑白（069）=极致色彩限制

## 经典单/双色张力场景

### 双色对峙决战
```
主角红 vs 反派蓝对峙全景（1.5s，双色）→ 出手双色交错冲击帧（0.3s）→ 一色压过（0.5s）→ 定格（1s）
```

### 单色暴走段
```
全红暴走整段（2s，红持续）→ 爆发（0.3s）→ 红消散恢复（0.5s）→ 定格（1s）
```

- 双色：`dual color contrast, red vs blue, two-tone palette, color opposition`

- 双色权力：`color ratio shift, one color expanding, dominance reversal`

## 备注
- 单/双色是 063 色块的持续版——色块是瞬间，单/双色是氛围
- 核心：做减法——色少=情绪纯=冲突锐
- 单色+静默=情绪顶配，双色对立=冲突可视
- AI 视频靠 prompt（monochrome/dual tone）+后期调色
