# 布料物理实片拆解方法论——六步从参考到提示词

## 核心要点

- 布料物理拆解 = 把"好看但说不出"的动态变成"参数化可复制"的知识——六步流程（公认）
- 六步：①取元数据 → ②抽帧（关键帧+中间帧）→ ③材质/风向/动作标注 → ④分类归档 → ⑤对照参数表提炼 → ⑥提示词产出（呼应眼神戏 426 的六步流程）
- 拆解对象优先级：动画 > 真人实拍 > 3D 渲染（动画最稳定提炼原理，经验）
- 推荐拆解对象：鬼灭披风（厚棉+内衬）、进巨斗篷（厚重帆布）、死神队长袍（多层混合）、武侠披风（丝绸）
- 拆解的核心产出是**参数**（滞后帧数、摆幅角度、自然频率）而非截图——截图是证据，参数是知识（公认）
- 每个拆解条目必须注明**确定性等级**：公认/经验/争议

## 详细内容

### 六步拆解流程

#### Step 1：取元数据

从视频中提取基础信息，填进拆解表头部：

| 元数据字段 | 内容 | 示例 |
|---|---|---|
| 来源 | 作品名+具体集数/时间点 | 《鬼灭之刃》立志篇 EP3 12:35 |
| 帧速率 | 24fps / 30fps / 60fps | 24fps |
| 分辨率 | 1920×1080 | 1920×1080 |
| 时长 | 动作段的精确时长 | 4 秒 |
| 动作类型 | 走路/奔跑/转身/跳跃/静止 | 快速转身+冲刺 |
| 镜头语言 | 景别+机位+运动 | 中景，正面跟拍 |
| 布料材质（视觉判断） | 厚棉/丝绸/帆布/皮革/纱 | 厚棉披风，内衬红色 |

#### Step 2：抽帧

**关键帧 + 中间帧**两手抓：

| 抽帧类型 | 定义 | 抽帧密度 |
|---|---|---|
| 关键帧（Key Frames） | 姿势变化的起止点（起始/极端/结束） | 每个关键动作抽 3-5 帧 |
| 中间帧（In-betweens） | 关键帧之间的动态过渡帧 | 每 2 帧抽 1 帧（24fps 下即每 80ms 一帧） |

```
抽帧工具推荐：
- 免费：FFmpeg (命令行), VLC 逐帧播放
- 专业：After Effects, Adobe Animate, TVPaint
- 在线：frame-by-frame.org (直接上传视频)

# FFmpeg 抽帧命令示例（每 2 帧抽 1 张）
ffmpeg -i input.mp4 -vf "fps=12" frame_%04d.png
```

#### Step 3：标注——材质/风向/动作三要素

每帧都标注三个维度，填进拆解记录表：

| 标注维度 | 观察点 | 标注值 |
|---|---|---|
| **布料材质** | 从褶皱密度、反光、厚度反推 | 厚棉（硬挺波浪，褶皱深）/丝绸（S 曲线软，反光亮）/帆布（直角多，波浪宽） |
| **风向** | 从头发/环境草叶/披风主方向 | 方向（上/下/左/右/斜 45°）+ 风速（微风/轻风/强风/无风） |
| **动作** | 角色动作类型 + 身体部位角度 | 跑步（3.5 m/s）/ 转身（180°/2 秒）/ 跳跃（最大高度） |

额外标注项：
- 滞后帧数：布料某部位相对于身体的延迟（数帧差）
- 摆幅角度：布料从自然态到极值的角度量（用量角器/估算法）
- 波浪频率：布料波浪每秒起伏次数（Hz）

#### Step 4：分类归档

把所有标注好的帧按以下维度归类：

| 分类维度 | 归档标签 |
|---|---|
| 布料类型 | 裙摆 / 披风 / 斗篷 / 头发（同属挂在身上的独立微动体） |
| 动作类型 | 走路 / 奔跑 / 转身 / 跳跃 / 静止 / 战斗 |
| 材质 | 丝绸 / 厚棉 / 帆布 / 皮革 / 纱 |
| 风速 | 无风 / 微风 / 轻风 / 强风 |

#### Step 5：对照参数表提炼

这一步是**从"观察"到"知识"的关键转化**：

```
提炼公式 = 实际测得参数 → 对照标准参数表 → 填入 KB 条目

示例：
- 测得：鬼灭披风在奔跑时滞后 2 帧，摆幅 55°
- 对照标准表（443 披风）：厚棉 + 奔跑 = 滞后 1.5-2 帧，摆幅 45-60°
- 提炼：鬼灭披风属于标准"厚棉披风"范畴，无特殊处理
- 若测得值偏离标准：如某斗篷滞后 4 帧 → 标注为"夸张处理"，进入经验/争议库
```

#### Step 6：提示词产出

把提炼好的参数翻译成 AI 视频可直接使用的提示词：

```
# 拆解参数 → 提示词的翻译模板

输入参数：
材质 = 厚棉披风，内衬红色
动作 = 奔跑 3.5 m/s
滞后 = 2 帧
摆幅 = 55°
波浪 = S 曲线，频率 2 Hz

输出提示词：
thick cotton cloak with red inner lining, flapping backward 
at 55° angle while running, 2-frame lag behind body movement, 
S-curve wave pattern at 2 Hz frequency, wind billowing edges

负向词：
no rigid fabric, no flat hanging, no synchronous movement with body
```

### 确定性标注规范

| 等级 | 含义 | 标注方式 |
|---|---|---|
| **公认** | 业界一致认可的物理原理/动画经验 | 无标注或 `(公认)` |
| **经验** | 多数案例中观察到但缺乏系统论文 | `(经验)` |
| **争议** | 存在反例或不同解释 | `(争议：原因说明)` |
| **夸张** | 为视觉效果刻意偏离物理现实 | `(夸张：偏离参数说明)` |

## 备注

- 本条是**方法论**，产出的参数填充到 442（裙摆）、443（披风）、444（头发）、445（配饰）中形成完整的知识体系
- 呼应眼神戏 426 的六步拆解流程：元数据→抽帧→标注→分类→提炼→产出（不同领域共享同一研究范式）
- 拆解时注意区分**物理真实**和**动画夸张**——动画业界常用"为视觉效果夸张物理幅度"，提炼时要标注出来
- 60fps 高帧率素材的滞后帧数会比 24fps 素材多 2.5 倍（同一物理延迟在不同帧率下的帧计数不同），需换算成**时间毫秒数**再对比（公认）
- 3D 渲染的布料物理比手绘动画更接近真实物理但缺乏手绘的"弹性夸张"——拆解时分开归档
- 完成拆解后统一运行 build_index.py 更新索引（不在各轮中运行）
- 本方法论与 406（场景生机）的环境微动观察形成互补：406 讲环境，本条讲角色身上的物理体
