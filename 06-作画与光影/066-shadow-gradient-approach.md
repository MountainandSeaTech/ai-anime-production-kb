# 阴影渐变逼近

## 核心要点
- 阴影渐变=**暗区逐渐扩大逼近主体**=潜伏威胁的可视化
- 与 061 长影不同：长影是影子拉长，渐变是暗区蔓延覆盖
- 暗区覆盖主体=临界=将被动=揪心顶
- 是 044 恐怖/049 围困的光影版——用暗"合围"

## 阴影渐变的张力来源

### 1. 暗区=潜伏威胁
- 暗区里"可能藏着什么"=044 的"间"
- 暗区扩大=威胁蔓延=加压

### 2. 渐变=延迟可视
- 暗区逐渐扩大=威胁"将至"被画出来
- 渐变=时间轴的视觉化（013）
- 比"突然全暗"更揪心——慢慢吞没

### 3. 覆盖=临界
- 暗区覆盖主体=临界=将被动
- 覆盖瞬间=峰值=威胁到

## 阴影渐变的用法

### 1. 暗区蔓延
```
主体在亮区（1s）→ 暗区从边缘渐扩（1s，逼近）→ 暗区覆盖主体（0.5s，临界）→ 威胁现身/出手（0.3s）→ 定格（1s）
```

### 2. 多向合暗（围困光影版）
```
主体居中亮（1s）→ 暗从四面合拢（1s，049 光影版）→ 主体被暗包围（0.5s）→ 临界（0.3s）→ 定格（1s）
```

### 3. 暗区吞没
```
主体半明（0.5s）→ 暗区从脚下渐上吞（1s，将没）→ 全暗（0.3s，峰）→ 静默定格（1s）
```

## 阴影渐变的常见坑
- **暗区不扩大**：静态暗=无逼近=无张力
- **覆盖太快**：一下全暗=无渐变=无延迟
- **暗区无威胁**：只是暗=无"可能藏着"=无揪心
- **无临界**：暗了无反应=悬空

## 阴影渐变与其他工具配合
- 渐变+静默（033）=潜伏+留白顶配
- 渐变+负空间（020）=孤立+潜伏
- 渐变+低频BGM（034）=听觉渐强配合
- 渐变是 044 恐怖"间"的光影化

## 经典阴影渐变张力场景

### 暗区逼近
```
主体亮区近景（1s）→ 暗区从画面边渐扩（1s）→ 覆盖主体（0.5s，临界）→ 威胁现身（0.3s）→ 定格（1s）
```

### 多向合暗
```
主体居中亮全景（1s）→ 暗从四面合拢（1s）→ 被暗包围（0.5s）→ 临界出手（0.3s）→ 定格（1s）
```

### 脚下吞没
```
主体半明（0.5s）→ 暗从脚下渐上（1s）→ 全暗（0.3s）→ 静默定格（1s）
```

## AI 提示词

- 多向合暗：`darkness closing in from all sides, shadows surrounding, engulfing`
- 脚下吞没：`darkness rising from ground, swallowing from below, shadow consuming`
- 覆盖临界：`shadow covering subject, engulfed in darkness,临界`
