# 灰度渐变与分步渲染法

## 核心要点
- **不透明度渐变法**：笔刷固定不透明度（如70%），同一区域**涂抹次数**决定深浅（涂1遍=灰度A，2遍更深……）；用吸管取上一格灰再涂=获得更浅的连续序列——"每重新涂抹一次，最浅的灰色只出现在最新一层"
- **图层工作流**：线稿层"INK"设正片叠底（亮色自动透明）；其下建"TONAL"灰度层处理色调；渐变图层不透明度降到65%让下层笔触若隐若现=匹配手绘感
- **分步渲染四步**（逆光风景示范）：①灰中间调打底+简笔线稿定主要地标光影区（只关注动态方向，**千万别陷进枝叶细节**）②眯眼快速排布主要明暗区与重点形状 ③第二遍强调暗部区+特效形状（树枝等）增加复杂性与纵深 ④渲染抽象树叶与中间调
- 收尾：调暗远处建筑上部（灰白渐变+正片叠底）强化纵深；图像/调整/色阶微调整体对比

## 详细内容

### 不透明度渐变的数学
| 操作 | 结果 |
|---|---|
| 70%黑涂1遍 | 灰度A |
| 吸管取A再涂新区域1遍 | 灰度B（更浅） |
| 取A再涂A区域一遍 | A区域加深一档 |
| 循环链式取色 | 完整渐变序列 |

- 软件自带渐变工具只配辅助；真正的渐变要靠手绘叠加
- 100%不透明度=边缘清晰的色块（远看也平滑、近看断裂）——要光滑融合就降不透明度

### 几何体分步示范（图4.8-4.15）
线稿定几何轮廓与阴影边界 → 主要阴影区 → 阴影中反射光 → 桌面中间调+高斯/动态模糊 → 亮部与中间调 → 渐变层65%收尾

### 纵深收尾组合拳
- 前景暗 vs 远处亮高楼形成对比分离
- 白色填充层降不透明度让细节可见但整体变亮
- 车轮等视觉中心最后清晰化

## 对 AI 分镜的落地要点
- 明度分层渲染流程：`atmospheric backlit base tone` → `main value zones blocked in` → `dark accents and detail shapes` → `midtone rendering`
- 灰度方案先行：黑白/灰度概念稿确认后再上色
- 负向词：`flat gradient banding`（渐变断层）、`oversaturated midtones`
- 与 Wan/H3 生成衔接：场景概念图按"打底→大块明暗→暗部强调→中间调"四步出四版，选最优再进角色合成
