# 色彩情节与调色板先行

## 核心要点
- **调色板先行**：开机前必须建立统一色彩系统，再进入拍摄。调色板不是后期调出来的，而是前期锁死的创作决策。
- **禁用色清单比主色更重要**：明确"不拍什么"比"拍什么"更能锁定风格。
- **滤镜参数可量化角色弧光**：《丹尼尔》用85号琥珀滤镜的增减曲线，把情感变化翻译成技术参数。
- **色彩承担叙事功能**：帮观众区分时间线、阵营、心理距离。
- **选景铁律**：两个候选地都好时，选加灯光后色彩变化最少的那个。
- **一致性>真实感**：色彩主观，但全片自洽，观众下意识就会读懂。
- **美术减法叙事**：《城市王子》背景从满到空，与灯光三段式同步外化孤立。
- **AI迁移**：为每角色/每幕定主色+禁用色；分幕色调关键词写入prompt；建色彩圣经用数值而非感觉；先主题后色彩。

## 详细内容

### 一、调色板先行：先建系统，再开机

吕美特强调：主题确定后，第二个关键问题是"如何讲好它"，而色彩系统是第一块基石。调色板先行意味着：
- 剧本围读阶段，导演、摄影、美术、服装共同确定全片色彩边界；
- 所有部门在同一调色板内工作，色彩方案与滤镜、灯光联动设计。

AI动漫短剧同构：生成第一张概念图前，就必须写死色彩prompt框架，否则会在无数"看起来还行"的随机结果中失焦。

### 二、《大审判》：秋色盘与禁用色清单

- **主色**：棕、黄褐、深黄、焦橙、酒红——全套秋色；
- **禁用色**：蓝、粉、淡绿——系统性排除，任何场景、服装、道具零出现。

禁用色清单比主色清单更有执行力：美术组选领带、窗帘、海报时，有一票否决的标准。AI生成时，负面prompt中的色彩排除与正面指定同等重要。

### 三、《丹尼尔》：85滤镜递减法

技术背景：日光直拍胶片偏蓝，标准做法是加琥珀色"85"滤镜校正。吕美特反其道而行：

| 叙事段落 | 滤镜方案 | 功能 |
|---|---|---|
| 父母回忆戏 | 双倍85→单倍→1/2→1/4递减 | 记忆温度随时间冷却 |
| 丹尼尔成年戏 | 不用85→1/4渐增→全85 | 丹尼尔逐步理解父母、进入父母世界 |
| 结尾探监戏 | 色彩归一 | 两代人和解 |

精髓：**滤镜不是装饰，是可量化的角色弧光**。每一场用几分之几的85，写在拍摄计划里。

AI迁移：为每幕写"色调关键词+数值锚点"：第一幕冷蓝、滤镜强度0；第三幕中段滤镜强度50%；结尾统一暖调、滤镜强度100%。

### 四、"选颜色对的那个"

卡洛·迪·帕尔马原则：两个候选地都好时，选**加灯光后色彩变化最少**的那个。灯光会改变一切——暖墙在钨丝灯下变脏橘，绿植在荧光灯下发灰。选"颜色对"的景，意味着后期修正成本最低。

AI迁移：确定场景参考图时，不看"好看"，看它在目标光效下的色彩稳定性。参考图在"黄昏暖光"和"正午冷光"下差异巨大的，不是好锚点。

### 五、色彩只需全片自洽

观众不会拿色卡比对银幕。你可以让"回忆=暖琥珀、现实=冷蓝"，只要全片用法一致，观众下意识就会读懂。关键是**不中途换规则**——第三幕突然让反派穿青绿，观众会潜意识混乱却说不出原因。

AI迁移：第一集建立的色彩语法，后续集数必须严格继承。色彩圣经用具体色值（HEX/RGB），不用"暖一点""冷一点"。

### 六、美术减法叙事：《城市王子》

背景密度与灯光三段式同步：
- 第一阶段：背景亮于前景，霓虹、公告牌、人群满——主角还活在喧嚣世界；
- 第二阶段：前后景平衡，色彩收束；
- 第三阶段：只有前景亮，空墙、空街、空法庭——主角被彻底孤立。

背景递减与色彩收束同步，外化"试图把控一切，却被一切控制"的主题。AI迁移：分幕场景密度表与分幕色彩表必须同步写入制作文档。

### 七、AI迁移清单

1. **先主题后色彩**：写色彩prompt前，先用一句话回答"这一集是讲什么的"；
2. **每角色/每幕定主色+禁用色**：写进角色设定文档；
3. **分幕色调关键词写入prompt与后期**：每幕生成prompt必须包含色温、滤镜强度、主色占比、禁用色；
4. **色彩圣经用数值**：色温4300K±200K、主色#8B4513占比≥40%、禁用色#0000FF-#00FFFF区间；
5. **顺序铁律**：先锁主题，再定色彩，不可颠倒。

## 关键参数 / 模板 / 清单

### 色彩圣经模板

| 字段 | 示例 | 说明 |
|---|---|---|
| 主题一句话 | "异类比我们想象的更孤独" | 色彩系统最高过滤器 |
| 全片主色 | #8B4513、#A0522D、#800000 | HEX值，禁止模糊词 |
| 全片禁用色 | #0000FF-#00FFFF、#FFC0CB | 负面prompt必写 |
| 角色A主色 | #D2691E | 服装、道具锚定 |
| 角色A禁用色 | #0000FF | 阴影部也不允许偏蓝 |
| 分幕滤镜强度 | 0 / 0.5 / 1.0 / 2.0 | 与叙事段落绑定 |

### AI生成prompt色彩片段

```
[色彩系统] 主色：深棕#8B4513、焦橙#D2691E、酒红#800000；禁用色：蓝#0000FF、粉#FFC0CB；
[滤镜参数] 琥珀滤镜强度：{0/0.25/0.5/1.0/2.0}；色温：{5600K/4300K/3200K}；
[场景密度] 背景元素：{满/中/空}；饱和度：{高/中/低}。
```

## 备注

- **踩坑**：不要先生成"好看"画面再回头找色彩逻辑。色彩系统必须在第一批测试图前锁定。
- **限制**：一致性>真实感，但不等于可违背基本物理直觉（如"血是绿的"需极强叙事 justification）。
- **适用范围**：适用于需跨场景、跨集数保持一致性的AI视频，尤其适合有时间线跳跃或阵营对立的叙事。
