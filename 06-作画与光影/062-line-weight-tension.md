# 线条粗细与张力

## 核心要点
- 线条粗细（line weight）在动漫里编码**重量与锐利**——粗线=重/压迫，细线=锐/精致
- 线粗骤变=张力信号——从细转粗=力量爆发，从粗转细=锐利聚焦
- 线条是 2D 动漫的"重量语言"，3D/AI 视频里靠边缘/描边模拟
- 线条与 016 景别、058 集中线配合强化焦点

## 线粗与张力对照

| 线粗 | 感受 | 张力用途 |
|---|---|---|
| 极粗 | 重、压迫、蛮力 | Boss、重击、压迫逼近 |
| 粗 | 有重量、稳定 | 强者、稳重站姿 |
| 中 | 平衡 | 日常、过渡 |
| 细 | 锐利、精致、快 | 居合、刺击、精锐 |
| 极细 | 脆、即将断 | 弱者、临界、将崩 |

## 线粗的张力来源

### 1. 重量编码
- 粗线=重=力量可视化
- 重击/Boss 用粗线=压迫
- 与 060 形变同理——重量视觉化

### 2. 锐利编码
- 细线=锐=快=精
- 居合/刺击用细线=锐利
- 细=精准=致命

### 3. 线粗骤变=信号
- 细转粗=从锐转重=力量爆发
- 粗转细=从重转锐=聚焦精锐
- 骤变=张力转折

## 线粗的用法

### 1. 角色线粗=权力（017 视觉版）
- Boss 用粗线描=压迫；弱者细线=脆弱
- 角色线粗变化=权力反转
```
弱者细线近景（1s）→ 觉醒转粗线特写（0.5s，反转）→ 粗线反击（0.3s）→ 定格（1s）
```

### 2. 动作线粗=力量
- 重击粗线，刺击细线
- 出招瞬间线粗骤变=力量信号
```
蓄势细线（0.5s）→ 重斩粗线+冲击帧（0.15s）→ 恢复（0.3s）→ 定格（1s）
```

### 3. 临界细线=将崩
- 弱者/临界用极细线=脆=即将断
- 线越细越揪心（要断了）
```
弱者极细线近景（1s，将崩）→ 线骤粗（0.5s，爆发/断）→ 定格（1s）
```

## 线粗的常见坑
- **全程一样粗**：无对比=无张力
- **线粗无骤变**：渐变无冲击=无信号
- **线粗与场景不符**：Boss 细线=无压迫
- **3D/AI 不模拟**：3D 无线=失重量语言

## 线粗与景别/集中线配合
- 粗线+大特写=压迫双钉
- 细线+大特写=锐利聚焦
- 线粗+集中线（058）=焦点+重量双加压

## 经典线粗张力场景

### 居合锐转重
```
居合细线站姿（1s，锐）→ 出刀细线（0.3s）→ 重斩粗线+冲击帧（0.15s）→ 恢复细线（0.3s）→ 定格（1s）
```
锐→重的骤变=力量爆发。

### 弱者觉醒
```
弱者极细线被打（1s，将断）→ 线骤粗觉醒特写（0.5s）→ 粗线反击（0.3s）→ 定格（1s）
```

## AI/3D 的线粗模拟
- 3D/AI 视频无线条，靠**边缘描边/toon shader** 模拟
- prompt：`cel shaded, bold outlines, thick contour lines` / `thin sharp linework`
- 后期可叠加描边（AE/剪映边缘检测）
- 线粗骤变靠分镜切换（细线镜→粗线镜）

## 备注
- 线条粗细是 2D 动漫的重量语言——粗=重，细=锐
- 线粗骤变=张力信号（锐转重/弱转强）
- 3D/AI 视频靠 toon shader/描边模拟，prompt 用 cel shaded+粗细词
- 与 017 角度权力、060 形变同属"重量视觉化"家族
