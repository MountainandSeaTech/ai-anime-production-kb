# 街舞影像美学：灯光 / 场景 / 色彩

## 核心要点

- 街舞影像的视觉公式：**暗环境 + 轮廓光分离主体 + 彩色光源塑形 + 雾让光束实体化 + 反光/有纹理的地面**；整体欠曝半档让舞者身体成为画面中最亮结构
- 六大经典场景：**地下俱乐部、工业仓库、街头 cypher（涂鸦/沥青）、练功房（镜墙地胶）、天台/停车场、霓虹街区**——选场景先选它决定的地面与光位
- 布光优先序：①逆光/侧逆光勾轮廓（舞者从黑里"切"出来）②顶光网格保 360° 一镜到底 ③正面弱补光保脸 ④彩色洗墙/霓虹给色彩 ⑤频闪只跟重拍
- 色彩即阵营：battle 双方用**互补色光各打一侧**（青/橙、品红/青、红/蓝），与本库既有战斗色彩法（063/302）一致，零台词分清敌我
- 地面是"第二演员"：地胶反光、水泥扬尘、方格线、镜面倒影都在给动作作证（高度、滑动、旋转）；地面资产必须与舞种匹配

## 详细内容

### 一、六大场景资产卡

#### 1. 地下俱乐部（Underground Club）
- **空间**：低顶、黑墙、小舞台或空地，音箱堆、DJ 台在圈边
- **光**：暗底 + RGB 摇头灯/洗墙灯 + 频闪 + 激光束；**雾机必备**（没有雾，光束不存在）
- **地面**：光滑水泥或薄地胶，反光映彩光
- **适配**：cypher、battle、house/waacking；氛围关键词 `haze, volumetric light beams, deep shadows, neon rim`

#### 2. 工业仓库（Warehouse / Hangar）
- **空间**：超高顶、裸露钢架、混凝柱、大面积空场、大窗
- **光**：窗外硬日光（窗光切割）或夜间顶光排灯；冷调工业光 + 少量暖色实用光反差
- **地面**：粗糙水泥、扬尘——stomp/power move 落地有尘
- **适配**：krump、breaking 大招、决战；关键词 `raw concrete, steel beams, hard window light, dust`

#### 3. 街头 Cypher（Street / Block Party）
- **空间**：沥青空地、涂鸦墙（合法墙）、纸箱音响、折叠椅、居民楼背景
- **光**：日光/黄昏黄金时刻或夜晚路灯+车头灯+便携灯
- **地面**：沥青颗粒（脚步可见）、雨后湿地面反光是升级款
- **适配**：old school、locking、派对群舞；关键词 `graffiti wall, asphalt, boombox, golden hour / sodium streetlamp`

#### 4. 练功房（Dance Studio）
- **空间**：**整墙镜**（可拍镜像双人/无限反射）、把杆、地胶、白炽灯/日光灯
- **光**：均匀顶光+大窗柔光，明亮干净
- **地面**：专业地胶（木色/灰），脚下质感统一
- **适配**：编舞排练、镜面构图（对接110镜像镜语）、训练蒙太奇、情绪对照戏
- **注意**：镜中反射会暴露机位与灯，AI 生成镜墙极易穿模——只取"局部镜面反射"不拍整墙

#### 5. 天台/停车场（Rooftop / Parking Lot）
- **空间**：城市天际线/楼层标识、排气管、黄色车位线
- **光**：城市光污染背景 + 单盏强轮廓光（夜）；天台黄昏逆光剪影（日）
- **地面**：硬水泥、车位线（天然图形参照，俯拍阵型极佳）
- **适配**：齐舞、urban、热血登场；关键词 `city skyline, rim light, parking lines, dusk silhouette`

#### 6. 霓虹街区（Neo Street / Cyber Alley）
- **空间**：窄巷、中文/日文招牌、雨湿地、便利店光、蒸汽
- **光**：多色招牌做实用光源（practical），人脸被彩光分区照亮
- **地面**：湿沥青反射霓虹（赛博标配）
- **适配**：urban/k-pop 风、tutting（全息界面）、变身戏；关键词 `wet asphalt reflections, neon signs, practical lights, steam, cyberpunk alley`

### 二、布光架构（实拍与 AI 通用）

**标准三点的街舞改写**：
```
① Key 主光：不作正面平打！改侧 45-90° 硬光或顶侧光，塑形身体线条
② Rim/Backlight 轮廓光（最重要）：舞者身后逆位 1-2 盏，勾头肩腿轮廓，
   power move 时逆光把腾空的人与地面分开
③ Fill 补光：仅留 10-20% 强度保脸，或干脆不要（剪影选择）
④ Color wash：背景洗墙色（深蓝/品红/青），与轮廓光形成色温差
⑤ Effect：频闪（跟 kick）、摇头光束（跟走位）、灯管（实用）
⑥ Haze：薄雾使所有硬光变成可见光柱
```
- **频闪规则**：频闪只跟重拍（1/5），频率不高于音乐 BPM；连续频闪不超 1–2 小节，否则廉价且有光敏风险
- **白衣服警告**：白色服装在强逆/频闪下易过曝成一片，舞者服装若白，轮廓光降档、正面留补光
- **LED 屏/灯 banding**：实拍快门与 LED 刷新不同步会滚条纹，快门调到 1/100 或 1/50 匹配；AI 无此问题但描述中避免"细密 LED 墙占满背景"

### 三、色彩阵营与情绪配色

| 配色 | 气质 | 典型用途 |
|---|---|---|
| 青 vs 橙（teal/orange） | 经典对峙 | battle 双方分区、主角 vs 对手 |
| 品红 vs 青（magenta/cyan） | 俱乐部、赛博 | cypher、霓虹街区 |
| 红 vs 蓝 | 阵营直白 | 团舞对团舞、变身前后 |
| 单色蓝洗 + 一束暖光 | 孤独/专注 | 练功房独舞、备战 |
| 金色暖光（黄金时刻） | 怀旧/和解/热爱 | 街头日戏、结尾大合舞 |
| 高对比黑白+一点红 | 决战/致敬 | final battle、冲击帧色彩（对接302） |

- 同一场 battle 全片色彩口径锁定，不中途换阵营色（对应用户龙形口径统一类规则）
- 灯光变色要给动机：随音乐 drop 换色、随攻守交接换主色，不无意义乱闪

### 四、地面选择（按舞种）

| 舞种 | 最佳地面 | 视觉收益 |
|---|---|---|
| Breaking（footwork/power） | 专业地胶/光滑木地板/平整水泥 | 旋转顺滑、影子清晰、扬尘可控 |
| Hip-hop/Locking | 沥青/木地板 | 踏步质感、时代感 |
| Glide/Moonwalk | 光滑反光地面（瓷砖/湿地/镜面地板） | 滑动错觉、倒影 |
| House | 俱乐部木地/光滑水泥 | 快速脚步与光斑流动 |
| Krump | 粗糙水泥/土地 | 重跺扬尘、重量感 |
| 齐舞 urban | 有图形线的地面（车位线/方格/水波纹） | 俯拍阵型、队形几何 |

### 五、服装与光的配合（资产联动）

- **宽松面料是动作放大器**：卫衣、阔腿裤、外套袖摆在旋转/抡臂时延迟 2–4 帧甩动，逆光下轮廓清晰——breaking/krump/house 优先
- **亮片/金属/PVC**：waacking/vogue 夜店戏，在点光源下出闪烁星点
- **帽子**：帽檐下阴影＝眼神悬念；头转类动作帽子是文化道具也是视觉焦点
- **头发**：长辫/脏辫在甩头/kill-off 时是独立运动部件，提示词写明头发动态
- 服装色彩避免与洗墙光同色（红衣服进红光＝消失），角色与背景必须有色相差或明度差

## 关键参数 / 模板 / 清单

### 灯光提示词块（直接拼接）

```
[俱乐部] dim underground venue, strong colored rim light from behind, 
haze with volumetric beams, deep blue/magenta wash, faint reflections on smooth floor
[仓库] raw warehouse, hard window shafts cutting darkness, dust particles, 
cold industrial top light with warm practical accent
[街头] graffiti wall at golden hour, warm backlight, asphalt texture, 
long shadows / night: sodium lamps and headlights, wet ground reflections
[练功房] bright studio, mirrored wall (partial reflection only), 
soft window light, wood-sprung floor, neutral tones
[天台] rooftop dusk, city lights bokeh, strong rim light, 
silhouette option, painted parking lines visible from above
[霓虹巷] narrow alley, neon sign practicals in magenta and cyan, 
steam, rain-wet asphalt mirroring signs
```

### 场景资产提示词（建场用，中性无人版）

```
empty [场景类型], no people, wide establishing view, 
[光位/光色/雾], [地面材质与反光], deep depth of field, 
consistent architecture for multi-shot reuse
负向：crowd, dancers, text artifacts, distorted signage, 
flicker banding, extra doors/windows changing between shots
```

### 灯光场景验收清单

- [ ] 舞者轮廓与背景分离（逆光/明度差/色相差三选一成立）
- [ ] 硬光光束有雾才成立；无雾时改用柔光/洗墙
- [ ] 暗部有细节但整体不过亮，脸部至少可辨识（剪影段落除外）
- [ ] battle 双方阵营色全片一致，换色有音乐/攻守动机
- [ ] 地面与舞种匹配：旋转地不涩、滑步地反光、重跺地有尘
- [ ] 服装与光不同色消失，白装测试过曝
- [ ] 频闪只跟重拍、时长受控
- [ ] 镜墙只做局部反射，无整墙镜像穿帮
- [ ] 同场景多镜头光源位置一致（窗/灯/招牌不瞬移）
