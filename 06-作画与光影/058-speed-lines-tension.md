# 速度线/集中线

## 核心要点
- 速度线/集中线是**背景的强制聚焦工具**——把视线钉到一点=注意力压缩=张力
- 速度线=运动方向感；集中线=指向焦点（常指向威胁源/爆发点）
- 两者是 020 构图张力的"线条版"——用背景线强化焦点
- 慎用：每镜都线=无对比=失效

## 两种线

### 速度线（speed lines / motion lines）
- 背景放射状线条，方向=运动方向
- 表现主体高速移动=速度感
- 张力：速度=威胁（057）

### 集中线（focus lines / impact lines）
- 从画面边缘向一点汇聚的线条
- 指向焦点（出刀点/中招点/眼神）
- 张力：把视线强制钉到焦点=注意力压缩

## 线条的张力来源

### 1. 强制聚焦
- 集中线把所有线引向一点=观众视线被强制带到焦点
- 等效景别收紧（016）+负空间（020），但用线条
- 焦点=即将爆发处=揪心点

### 2. 速度=威胁
- 速度线密度=速度=威胁程度
- 线越密越快越险

### 3. 方向暗示
- 集中线指向=威胁来自/去往哪
- 指向主体=主体将受击；从主体发散=主体将爆发

## 张力曲线
```
蓄势无线（1.5s，干净）→ 集中线渐现指向焦点（0.5s，加压）→ 爆发+线最密（0.3s，峰）→ 线消散定格（1s，释）
```

## 线条的三种用法

### 1. 集中指向威胁
```
对峙干净（1.5s）→ 集中线从边缘指向主体胸口（0.5s，将受击）→ 中招+线爆（0.3s）→ 定格（1s）
```

### 2. 速度线逼近
```
追兵远景无线（0.5s）→ 速度线渐现（0.5s，加速）→ 线最密抵近（0.3s）→ 抓到/出招（0.3s）→ 定格（1s）
```

### 3. 爆发散线
```
蓄势（1s）→ 主体周围集中线汇聚（0.5s，蓄到顶）→ 爆发+线向外散（0.3s）→ 定格（1s）
```

## 线条的常见坑
- **每镜都线**：无对比=失效=视觉疲劳
- **线方向乱**：不指向焦点=无聚焦=乱
- **线太密**：盖住主体=看不清=信息过载
- **无渐现**：突然线爆=无蓄势=突兀

## 线条与景别/构图配合
- 集中线+大特写=注意力双钉死（最强蓄势）
- 速度线+全景=速度威胁可视化
- 线+负空间=孤立+聚焦双加压
- 线条是 020 构图的强化工具，不能单独救命

## AI 提示词
- 集中线：`focus lines converging on point, radial lines pointing to target, dramatic emphasis`
- 速度线：`speed lines, motion lines radiating, high speed background streaks`
- 爆发散线：`impact lines bursting outward from character, energy radiating`
- 渐现：`lines gradually appearing, building tension, focusing`
