# 高对比光影张力

## 核心要点
- 高对比光影（chiaroscuro）= **强明暗差**，制造压迫+隐藏+揭示
- 阴影藏威胁（潜伏），强光揭示瞬间=张力开关
- 与 019 景深同属"注意力分配"——光分配清晰区=注意力钉死
- 高对比是 044 恐怖、046 悲剧、049 围困的共同光影底

## 高对比的张力来源

### 1. 阴影藏威胁
- 大片阴影=可能藏着什么=潜伏（044 的"间"）
- 观众盯阴影找威胁=注意力被钉
- 比全亮更揪心——半隐半现（044 核心）

### 2. 强光揭示
- 强光打在某处=强制聚焦=揭示
- 揭示瞬间=信息差释放=峰
- rack light（光转移）=视觉化信息差

### 3. 明暗差=压迫
- 极亮极暗并存=视觉压迫=情绪重
- 角色半明半暗=内心分裂/双重

## 高对比的用法

### 1. 阴影潜伏
```
主体半明近景+大片阴影（1.5s，潜伏）→ 阴影里有东西动（0.5s）→ 强光揭示威胁（0.3s）→ 定格（1s）
```

### 2. 强光揭示
```
低光对峙（1s）→ 强光骤打在某处（0.3s，揭示）→ 揭露真相（0.5s）→ 定格（1s）
```

### 3. 半明半暗角色
```
角色面半明半暗近景（1s，双重）→ 转脸全暗/全明（0.5s，立场）→ 出手（0.3s）→ 定格（1s）
```

## 高对比的常见坑
- **全亮无影**：无藏身处=无潜伏=无张力
- **全暗无光**：看不清=信息过少=无聊
- **对比无变化**：一直一样=无揭示=平
- **光乱打**：光方向不一致=违和

## 光源方向与张力

| 光源 | 效果 | 用途 |
|---|---|---|
| 顶光 | 面部上下分明 | 审判、内心分裂 |
| 侧光 | 半明半暗 | 双重、对峙 |
| 逆光 | 剪影/轮廓（068） | 神秘、压迫 |
| 底光 | 面部诡异向上 | 恐怖、异常 |
| 强聚光 | 一处极亮 | 揭示、聚焦 |

## 高对比与其他工具配合
- 高对比+负空间（020）=潜伏+孤立
- 高对比+静默（033）=恐怖"间"顶配
- 高对比+逆光（068）=剪影压迫
- 高对比+浅景深（019）=注意力双钉

## 经典高对比张力场景

### 阴影潜伏威胁
```
主体半明+大片阴影（1.5s）→ 阴影动（0.5s）→ 强光揭示（0.3s）→ 定格（1s）
```

### 半明半暗双重
```
角色半明半暗近景（1s）→ 转脸全暗（0.5s，立场反转）→ 出手（0.3s）→ 定格（1s）
```

## AI 提示词
- 高对比：`high contrast lighting, chiaroscuro, strong light and dark, dramatic shadows`
- 阴影潜伏：`deep shadows, threat hidden in darkness, partial illumination`
- 强光揭示：`sudden spotlight, harsh light revealing, dramatic illumination shift`
- 半明半暗：`half-lit face, split lighting, dual nature, side light`

## 备注
- 高对比是 044 恐怖/046 悲剧/049 围困的共同光影底
- 核心：阴影藏威胁+强光揭示=光作张力开关
- AI 视频光影靠 prompt（high contrast/spotlight）+后期调光
- 半明半暗角色=内心双重/立场反转的视觉信号
