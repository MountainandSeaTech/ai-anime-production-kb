# 色块冲击与张力

## 核心要点
- 色块（color block）= 用**大面纯色**制造视觉冲击——色面=情绪瞬间
- 色块对比=张力骤变（红转黑=暴怒转死亡）
- 单色压满画面=情绪瞬间（全红暴走、全黑断灭）
- 色块是 036 闪白的"面版"——不是一瞬光，是大面色

## 色块的张力来源

### 1. 色面=情绪瞬间
- 全画面一色=情绪被填满=瞬间凝固
- 全红=暴怒/血，全黑=断灭，全白=超载，全蓝=悲冷
- 色面比渐变更"瞬时"=情绪峰值

### 2. 色块对比=骤变
- 色块切换=情绪骤变=张力转折
- 红转黑=暴怒转死亡；暖转冷=情绪反转
- 骤变=不可逆信号

### 3. 单色压满=压迫
- 大面纯色压满=无处可逃的色=情绪压迫
- 配静默（033）=最强情绪瞬间

## 色块的用法

### 1. 情绪瞬间（单色压满）
- 情绪转折瞬间用单色压满画面
```
正常画面（0.5s）→ 全红压满+暴走特写（0.3s，暴怒峰）→ 恢复/定格（1s）
```

### 2. 色块对比骤变
- 两色块切换=情绪骤变
```
暖色对峙（1s）→ 骤切冷色+背叛揭露（0.3s，反转）→ 定格冷色（1s）
```

### 3. 色块冲击帧
- 冲击帧（059）用色块替换——红/黑/白单色冲击帧
```
挥击（0.5s）→ 红色块冲击帧（0.15s，血/力）→ 恢复（0.3s）→ 定格（1s）
```

## 色块与颜色的情绪编码

| 色 | 情绪 | 张力用途 |
|---|---|---|
| 红 | 暴怒、血、危险 | 暴走、杀戮、致命 |
| 黑 | 断灭、死亡、虚无 | 死亡、剧变（054） |
| 白 | 超载、纯净、爆 | 超能力爆发、闪白（036） |
| 蓝 | 冷、悲、死寂 | 悲剧、决别（046） |
| 黄 | 警示、临界 | 倒计时、将爆 |
| 紫 | 异常、腐败 | 异变、诅咒 |

## 色块的常见坑
- **色块太多**：每镜都色块=无对比=疲劳
- **色块太久**：压满 1s+=拖=变静止画
- **色与情不符**：死亡用红=错码=违和
- **无静默配合**：色块+音乐满=信息过载

## 色块与其他工具配合
- 色块+静默（033）=情绪瞬间顶配
- 色块+冲击帧（059）=色面凝固
- 色块+闪白（036）=色与光双爆
- 色块与 065 单色张力同源

## 经典色块张力场景

### 暴走全红
```
被压（1s）→ 全红压满+暴走特写（0.3s）→ 红消散变身（0.5s）→ 反击（0.3s）→ 定格（1s）
```

### 死亡全黑
```
致命（0.5s）→ 全黑压满0.2s（断灭）→ 静默（0.8s）→ 拉远定格（1.5s）
```

### 色块骤变反转
```
暖色信任（1s）→ 骤切冷蓝+背刺（0.3s，反转）→ 冷蓝定格（1s）
```

## 备注
- 色块是 036 闪白的面版——大面纯色=情绪瞬间
- 色面=情绪凝固，色块对比=骤变转折
- 色块压满时长 0.2-0.3s，长了变拖
- 必配静默——色+声双留白=情绪顶配
- 与 065 单色张力同源，本条聚焦"瞬间冲击"，065 聚焦"持续氛围"
