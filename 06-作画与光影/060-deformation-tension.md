# 形变夸张张力

## 核心要点
- 形变（deformation/squash-stretch）= 用**夸张变形视觉化力量**=重量感
- 受击部位瞬间形变（脸压扁/拳陷进）=打击的视觉证据=重量
- 出招方向拉伸（squash-stretch）=速度+力量
- 形变必须快速恢复（0.1s）——不恢复=滑稽=出戏

## 形变的张力来源

### 1. 重量视觉化
- 受击部位形变=力量被画出来=重量感
- 没形变=轻飘飘=无重量=无张力（042 徒手戏命脉）
- 形变程度=力量程度

### 2. 速度视觉化
- 出招方向拉伸=速度感（squash-stretch）
- 拉伸越长=速度越快=威胁

### 3. 冲击放大
- 形变常配冲击帧（059）——形变是冲击帧的内容
- 形变+集中线+闪白=冲击帧三件套

## 两种形变

### 受击形变（压扁/凹陷）
- 受击部位被压扁/凹陷=打击证据
- 经典：脸被打压扁、胸被拳陷进、地面被踩裂
```
挥击（0.5s）→ 受击部位压扁形变+冲击帧（0.15s）→ 恢复+飞出（0.3s）→ 定格（1s）
```

### 出招形变（拉伸）
- 出招方向身体拉伸=速度+力量
- 经典：挥拳手臂拉长、冲刺身体拉长、跳跃腿拉长
```
蓄势（0.5s）→ 出招身体拉伸形变（0.3s）→ 击中+受击形变（0.15s）→ 恢复（0.3s）→ 定格（1s）
```

## 形变的张力曲线
```
出招拉伸形变（0.3s，速度力量）→ 击中受击形变+冲击帧（0.15s，峰）→ 快速恢复（0.1s）→ 飞出/定格（0.5s）→ 定格（1s）
```

## 形变的常见坑
- **不恢复**：形变不回弹=滑稽=出戏
- **形变过度**：变形太大=失真=违和
- **无冲击帧配合**：单形变无定格=看不出重量
- **静态形变**：形变但不动=死的=无力量
- **每击都形变**：无对比=失效

## 形变的恢复原则
- 形变必须 0.1-0.2s 内恢复=弹性=力量感
- 不恢复=橡皮泥=滑稽
- 恢复的"弹回"=力量的余韵

## 形变 vs 残影 vs 冲击帧

| 工具 | 表现 | 时长 |
|---|---|---|
| 残影（057） | 速度拖影 | 持续 |
| 形变 | 力量变形 | 0.15s+恢复 |
| 冲击帧（059） | 瞬间凝固 | 0.1-0.2s |

> 三者常叠加用：出招残影+击中冲击帧（含形变）=峰值顶配。

## 经典形变张力场景

### 一拳重量
```
蓄拳拉伸形变（0.5s）→ 击中面部压扁形变+冲击帧（0.15s）→ 弹回恢复（0.1s）→ 飞出（0.3s）→ 定格（1s）
```

### 重击地面
```
高举武器拉伸（0.5s）→ 砸地+地面裂纹形变+冲击帧（0.15s）→ 弹回（0.1s）→ 震波扩散（0.3s）→ 定格（1s）
```

## AI 提示词
- 受击形变：`impact deformation, face squashing, compressed on hit, exaggerated distortion`
- 出招拉伸：`stretch deformation, arm elongated mid-strike, squash and stretch, speed`
- 地面形变：`ground cracking on impact, debris, crater forming, deformation`
- 恢复：`snapping back to shape, elastic recovery, rebound`

## 备注
- 形变是 042 徒手戏重量的命脉——没形变=轻飘=无张力
- 必须快速恢复（0.1-0.2s），不恢复=滑稽
- 形变是冲击帧（059）的内容，常与残影（057）叠加
- AI 视频形变靠 prompt（squash and stretch/deformation）+后期，易过度需控
