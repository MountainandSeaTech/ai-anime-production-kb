# 影分离与影张力

## 核心要点
- 影子在动漫里可**独立成威胁源**（影分离）或把主体剪影化
- 影分离=影子脱离主体独立动=潜伏威胁/异常
- 剪影=主体化为影=压迫感/神秘
- 影是 044 恐怖"间"的视觉工具——黑暗里的影=潜伏威胁

## 影的三种用法

### 1. 影分离（影子独立动）
- 影子脱离主体，自己动=异常/潜伏威胁
- 经典：影先于主体动、影做主体没做的事、影独立成怪
- 张力：影=不可控的另一重存在=异常=揪心
```
主体近景（0.5s）→ 影子在地独立抬头特写（0.8s，异常）→ 主体察觉回头（0.3s）→ 影扑来（0.3s）→ 定格（1s）
```

### 2. 主体剪影化
- 主体化为黑影/逆光剪影=压迫感+神秘
- 剪影看不到表情=不可读=威胁
- 经典：Boss 登场逆光剪影、主角化影暴走
```
逆光剪影全景（1.5s，压迫）→ 剪影缓步逼近（1s）→ 出剪影露脸特写（0.5s）→ 出手（0.3s）→ 定格（1s）
```

### 3. 影长逼近
- 影子被拉长，从远处逼近主体=威胁将至
- 影长=时间将到=延迟可视
- 经典：夕阳长影逼近、怪物影覆盖主角
```
主体近景（0.5s）→ 地上长影逼近特写（1s，将至）→ 影覆盖主体（0.5s）→ 主体察觉（0.3s）→ 威胁现身（0.3s）→ 定格（1s）
```

## 影张力的来源

### 影=潜伏威胁
- 影子里"可能藏着什么"=044 的"间"
- 影比本体更恐——半隐半现（044 核心）

### 影=不可读=神秘
- 剪影无表情=观众读不出意图=不可预测=揪心
- 剪影化让任何角色都变威胁

### 影=延迟可视
- 影长=时间将到=延迟被画出来
- 影先于本体到=预告

## 影的常见坑
- **影不独立**：只是普通影子=无异常=无张力
- **剪影太久**：全程剪影=无揭示=拖
- **影方向乱**：影子方向不一致=违和
- **影太明显**：影一出来就明是怪=无悬念

## 影与其他工具配合
- 影+负空间（020）=潜伏威胁双加压
- 影+静默（033）=恐怖"间"的视听双留白
- 剪影+逆光（068）=压迫感顶配
- 影+黑白（069）=极致影张力

## 经典影张力场景

### 影分离扑击
```
主体走（0.5s）→ 地上影独立抬头（0.8s，异常）→ 主体察觉（0.3s）→ 影扑来（0.3s）→ 定格（1s）
```

### Boss 剪影登场
```
逆光剪影全景（1.5s）→ 剪影逼近（1s）→ 露脸特写（0.5s）→ 压迫（0.3s）→ 定格（1s）
```

### 长影逼近
```
主体近景（0.5s）→ 长影覆盖（1s）→ 主体回头（0.3s）→ 威胁现身（0.3s）→ 定格（1s）
```
