# 蒙太奇（Montage）

## 核心要点
- 镜头**并置**产生新义=1+1>2
- 库里肖夫效应：两镜相加=生第三义（不在任一镜中）
- 蒙太奇=剪辑的最高形态——不是连而是"造义"
- 苏联学派标志：爱森斯坦《战舰波将金号》

## 张力来源

### 1. 联想=观众参与
- 蒙太奇=两镜并置=观众脑补第三义
- 观众"参与造义"=比被动看更投入=张力
- 不说破=留白=让观众想（见 094 负空间）

### 2. 冲撞=张力
- 爱森斯坦：两镜"冲撞"=产生新概念=张力
- 不是平滑连而是冲撞=矛盾=张力
- 越冲撞=越张力

### 3. 主题升华
- 蒙太奇=用画面"写论点"=视觉论证
- 多镜并置=主题渐显=升华
- 比台词说教更高级——纯视觉

### 4. 压缩/加速
- 蒙太奇=压缩时间/空间=加速=紧迫
- 训练/成长/备战蒙太奇=时间压缩=节奏

## 蒙太奇的类型
| 类型 | 特点 | 用途 |
|---|---|---|
| 叙事蒙太奇 | 时空连=推进叙事 | 转场/时间跳 |
| 表现蒙太奇 | 并置造义=主题 | 联想/隐喻 |
| 节奏蒙太奇 | 节拍驱动=韵律 | 训练/加速 |
| 冲撞蒙太奇 | 矛盾冲撞=新义 | 爱森斯坦式张力 |
| 知性蒙太奇 | 概念并置=论证 | 主题升华 |

## 库里肖夫效应（关键）
```
同一张无表情脸 + 汤 = "饥饿"
同一张无表情脸 + 棺材 = "悲伤"
同一张无表情脸 + 玩具 = "渴望"
→ 镜头并置改变意义=1+1>2
```
- 脸没变=变的是并置=观众脑补=造义
- 这是蒙太奇的核心原理

## 《教父》受洗+暗杀（经典）
- A线：教父受洗（神圣）+ B线：暗杀执行（血腥）
- 并置=反讽=神圣与暴力=主题：罪与赎
- 不用台词=纯视觉论证=顶配

## AI 实现（关键）
- 蒙太奇是**剪辑层**——多镜并置+后期（090）编排
- 工作流：
  1. 确定主题/对比
  2. 生成多镜（A线/B线）
  3. 并置剪辑=造义
- 提示词不涉及蒙太奇——靠镜序编排

## 常见坑
- **无主题**：并置无义=散；要服务主题
- **太直白**：说破=无联想=失蒙太奇；要留白
- **节奏拖**：蒙太奇节奏慢=失冲击；快节拍才张力
- **滥用**：多用=失冲击；关键时刻用

## 进阶
- 表现蒙太奇+反讽=并置反差=顶配（《教父》受洗+暗杀）
- 节奏蒙太奇+跳切（106）=冲击递增顶配
- 库里肖夫效应=留白让观众造义=参与张力
- 冲撞蒙太奇=矛盾=张力顶配
