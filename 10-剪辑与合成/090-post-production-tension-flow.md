# 剪映/达芬奇 张力后期流程

## 核心要点
- 后期是张力的**总装线**——AI 生成的单镜在此组装成片
- 三层处理：剪辑（控节奏）+ 调色（控氛围）+ 混音（控情绪）
- 编镜比例 6:1:3（build:peak:release）= 张力曲线
- 剪映够用，达芬奇进阶

## 完整后期流程

### 1. 素材整理
```
- 按 build/peak/release 分镜分文件夹
- 标记每镜张力等级（1-5星）
- 弃用崩镜（角色崩/动作崩）
- 保留多 seed 备选
```

### 2. 粗剪（按 014 张力曲线）
```
build 段（60%）：缓推/环境/对峙镜——渐压
peak 段（10%）：慢镜/冲击/爆发——爆点
release 段（30%）：拉远/空镜/余韵——释放
```
- 按张力曲线编镜=有节奏
- build 长，peak 短，release 中

### 3. 精剪（节奏控制）
| 转场 | 用途 |
|---|---|
| 硬切 | 紧张/快节奏/冲击 |
| 叠化 | 回忆/过渡/缓 |
| 跳切 | 时间跳/紧迫 |
| J-cut（先听后看） | 悬念/预示 |
| L-cut（先看后听） | 余韵/延续 |

- build 段：缓叠化/长镜=慢节奏
- peak 段：硬切/快切=冲击
- release 段：叠化/J-cut=余韵

### 4. 调色（控氛围）
| 色调 | 氛围 |
|---|---|
| 冷蓝 | 压迫/死亡/冷峻 |
| 暖橙 | 温情/怀旧 |
| 高对比 | 肃杀/冲突 |
| 降饱和 | 写实/纪实 |
| 单色 | 抽离/记忆 |

- 剪映：滤镜+调节（快）
- 达芬奇：节点调色（精）
- 全片统一色调=不漂

### 5. 混音（控情绪，见 089）
```
TTS + SFX + BGM 三轨
- build：BGM 渐强+SFX 低频轰鸣+TTS 气声
- peak：骤停或拔顶+SFX 冲击+TTS 爆发
- release：BGM 钢琴单音+环境白噪+沉默
```
- 关键帧调音量=精准控渐强渐弱

### 6. 字幕/特效
- 字幕：打击感字（大/粗/抖）
- 速度线/冲击帧特效（剪映自带）
- 限帧/残影（见 056/057）后期可模拟

## 6:1:3 编镜实例（10秒短剧）
```
build（6s）：缓推环境+对峙特写（2-3镜）
peak（1s）：冲击帧/慢镜爆点（1镜）
release（3s）：拉远+空镜余韵（1-2镜）
```

## 剪映 vs 达芬奇
| 项 | 剪映 | 达芬奇 |
|---|---|---|
| 上手 | 快 | 陡 |
| 调色 | 滤镜级 | 节点级精 |
| 特效 | 丰富自带 | 弱 |
| 混音 | 够用 | 专业 |
| 速度 | 快 | 慢 |
| 推荐 | 短剧快出 | 精品长片 |

## 常见坑
- **镜间不统一**：色调/风格不一=廉价感；全片统一调色
- **转场太花**：叠化/特效转场堆=业余；张力片用硬切为主
- **节奏太平**：build/peak/release 无区分=散；按 6:1:3 编
- **混音太满**：三层全开=糊；该静就静（见 033）
- **调色过重**：滤镜太重=假；`--style raw` 素材+轻调=真

## 进阶
- J-cut/L-cut 是悬念/余韵利器
- 关键帧调音量=渐强渐弱精准控
- 达芬奇节点调色：先统一基础→逐镜微调
- 限帧/抽帧（剪映调速）可模拟 056 限帧张力
- 冲击帧加抖动特效=打击感
