# 闪白闪黑与瞬爆

## 核心要点
- **闪白**：白光爆闪一瞬=能量爆发、惊愕、超载
- **闪黑**：黑场一瞬=剧变、死亡、意识断灭
- 闪=比硬切（032）更极端的"瞬间切换"，用光代替切
- 闪用在峰值瞬间=瞬爆感；滥用=廉价癫痫=失效

## 闪白 vs 闪黑

| 闪法 | 视觉 | 情绪 | 适用 |
|---|---|---|---|
| 闪白 | 白光爆满 | 能量、惊愕、超载 | 出招爆发、超能力、爆炸 |
| 闪黑 | 全黑一瞬 | 断灭、死亡、失去意识 | 致命、剧变、转场到 unconscious |
| 闪红 | 红光爆 | 暴怒、血、危险 | 暴走、杀戮 |
| 闪频 | 多次快速闪 | 信息过载、混乱 | 高潮乱战、心理崩坏 |

## 闪在张力曲线的位置
闪只用在 **peak 峰值瞬间**，不能用在蓄势或释放段。

```
build-up（蓄势 2s）→ 闪白峰值（0.1s）→ release（定格/拉远 1s）
```
闪替代了硬切，把峰值做成"光爆"。

## 闪的三大用法

### 1. 出招瞬间闪白（能量爆发）
出刀/开枪/超能力瞬间一帧闪白=能量爆发的视觉化。
```
蓄势（2s）→ 出刀+闪白0.1s → 收刀定格（1s）
```
闪白比硬切更"爆"，强调"能量释放"。

### 2. 致命瞬间闪黑（断灭感）
致命一击或死亡瞬间闪黑=意识断灭的视觉。
```
中刀画面（0.3s）→ 闪黑0.15s → 倒地/定格（1s）
```
闪黑=时间断灭，比定格更"绝"。

### 3. 闪频过载（高潮乱战）
连续快速闪白/闪黑 3-5 次=信息过载=混乱紧张。
```
乱战快切（0.4s×3）→ 闪频3次（0.1s×3）→ 定格峰值（0.5s）
```
闪频=把混乱推到顶，再定格收。

## 闪 vs 硬切的选择

| 维度 | 硬切（032） | 闪 |
|---|---|---|
| 强度 | 强 | 极强 |
| 用途 | 普通爆发 | 极端爆发/剧变 |
| 频率 | 可多次 | 一段戏1-2次 |
| 风险 | 低 | 高（滥用廉价） |

> 优先硬切，闪留给"必须更爆"的瞬间。

## 闪的配合
- 闪+爆音：闪白同时炸响重音效=视听双爆（最强峰值）
- 闪+静默前置：蓄势静默→闪白爆音=延迟释放极致
- 闪后定格：闪完接定格/慢镜=凝固余韵
```
静默蓄势（1.5s）→ 闪白+爆音（0.1s）→ 升格定格（1s，余韵）
```

## 闪的常见坑
- **滥用**：每镜都闪=廉价癫痫=观众不适=失效
- **闪在非峰值**：蓄势段闪=提前泄
- **闪太长**（>0.2s）=变白场/黑场=拖
- **闪无配合**：只闪没爆音=光有视觉没听觉=半截

## 闪的时长与频率
- 单次闪：0.05-0.15s（1-3 帧）
- 闪频：3-5 次，每次 0.05-0.1s，总时长 <0.5s
- 超过这个范围=拖或滥用

## AI/剪辑实操
- AI 视频生成不直接产"闪"，需后期叠加（白/黑场帧插入）
- 工具：剪映/达芬奇，在峰值帧插入 1-3 帧纯白/纯黑
- 闪白可叠 `lens flare` / `light burst` 增强能量感
- 闪黑可叠 `vignette` 暗角增强断灭感
- 闪必须同步爆音效，否则半截

## 备注
- 闪是 014 peak 段的"极端版"，比硬切更爆
- 闪是昂贵工具，一段戏最多 1-2 次，把"贵"留给真正峰值
- 闪白=能量，闪黑=断灭，别用反
