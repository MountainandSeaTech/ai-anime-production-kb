# 硬切节奏与爆发

## 核心要点
- **硬切（hard cut）= 无过渡直接切换**——最朴素的切法，也是爆发段最强工具
- 硬切的力量在**对比**：慢切蓄势→硬切爆发=频率骤变=峰值
- 硬切本身不制造张力，**硬切的密度骤变**才制造张力
- 与软切/溶解/转场相反：软切模糊时间，硬切强调"瞬间"

## 硬切 vs 其他切法

| 切法 | 效果 | 张力用途 |
|---|---|---|
| 硬切（hard cut） | 瞬间直切，强调时间断裂 | 爆发、峰值、惊愕 |
| 软切（soft cut） | 动作连贯的切，平滑 | 连续动作推进 |
| 溶解（dissolve） | 叠化过渡，时间流逝 | 转场、回忆（杀张力） |
| 闪白/闪黑 | 强光过渡 | 极端爆发、转场（见036） |
| 跳切（jump cut） | 同主体时间跳跃 | 不安、加速（慎用） |

> 张力段优先硬切；溶解/转场用于非张力段。

## 硬切的密度骤变（核心技法）

### 慢→快骤变（蓄到爆）
```
慢切蓄势（每镜2s，3镜6s）→ 硬切爆发（每镜0.3s，3镜0.9s）→ 慢切定格（1镜2s）
```
密度从"3镜/6s"骤变到"3镜/0.9s"=频率骤变=峰值信号。这是 023 的剪辑实现。

### 快→慢骤变（爆到凝）
```
快切缠斗（每镜0.4s，4镜1.6s）→ 硬切到致命一击长镜（1镜1.5s）→ 硬切定格（1镜2s）
```
快到慢的硬切=时间凝固感。

## 硬切的爆发段编排

### 居合斩杀硬切序列
```
慢切对峙（2s×2=4s）→ 硬切出刀特写（0.3s）→ 硬切中刀特写（0.3s）→ 硬切收刀全景（1.5s）
```
4s→0.3s→0.3s→1.5s，密度骤变。

### 惊愕点硬切
```
长镜蓄势（2s）→ 硬切惊愕面特写（0.2s，极短）→ 硬切回长镜（1s）
```
0.2s 的极短硬切=惊吓点，闪现一瞬。

### 多角度爆发（硬切拼峰值）
```
出刀中景（0.3s）→ 硬切出刀特写（0.3s）→ 硬切中刀特写（0.3s）→ 硬切反应特写（0.3s）→ 硬切定格全景（1s）
```
同一爆发瞬间从多角度硬切=把 0.3s 的爆发展开成 1.5s 的多镜峰值。

## 硬切的节奏型

| 节奏型 | 模式 | 张力效果 |
|---|---|---|
| 长静短爆 | 慢切→极快硬切→慢切 | 居合型，最揪心 |
| 快停快 | 快硬切→长镜停→快硬切 | 缠斗喘息 |
| 多角度爆 | 同瞬间多硬切 | 峰值展开 |
| 渐快阶梯 | 慢→中→快硬切 | 逼近倒计时 |

## 硬切的常见坑
- **全程硬切匀速**=无密度对比=无张力（见 015）
- **爆发段用软切/溶解**=峰值被平滑=泄气
- **硬切太多**=疲劳轰炸，峰值失效
- **硬切位置错**：在无关处硬切=无意义冲击

## 硬切的音画配合
- 硬切点对齐音效（刀声、枪声、爆音）=冲击翻倍（见 035）
- 硬切点对齐 BGM 重拍=节奏感（见 034）
- 蓄势段硬切可配静默，爆发段硬切必配音效

## 自检：硬切是否服务张力
- [ ] 爆发段是不是硬切（无溶解）？
- [ ] 硬切密度有没有骤变（慢→快）？
- [ ] 硬切点有没有对齐音效/BGM 拍？
- [ ] 蓄势段慢切够不够长给硬切做反差？

## 备注
- 硬切是 023 切换频率的"爆发向"应用
- 动漫短剧剪辑优先硬切，溶解/转场只用于明确的非张力过渡
- 硬切的"密度骤变"比"硬切本身"重要——关键是慢切做足蓄势再骤变
