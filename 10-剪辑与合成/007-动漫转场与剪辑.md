# 动漫风格转场与剪辑节奏

## 核心要点
- 动漫短剧以「硬切」为主，叠化/光效转场仅用于情绪段/回忆/段落切换
- 打戏段剪辑节奏快，每镜 0.5-1.5s，靠硬切堆出爆发力
- 情绪/氛围段剪辑慢，每镜 3-5s，留呼吸感
- 转场不是炫技，是节奏调节工具

## 转场类型与适用

| 转场 | 适用场景 | 注意 |
|---|---|---|
| 硬切 | 动作段、对白来回切换 | 默认选择，干净利落 |
| 叠化（dissolve） | 回忆、时间流逝、情绪过渡 | 时长 0.5-1s，别拖 |
| 闪白 | 爆发瞬间、斩击落刃 | 1-3帧，极短 |
| 闪黑 | 段落结束、章节切换 | 0.3-0.5s |
| 光效扫过 | 镜头/魔法切换 | 慎用，易俗气 |
| 动作匹配切 | 两镜动作衔接（出刀→收刀） | 同动作不同景别切换 |

## 剪辑节奏控制

### 打戏段
- 镜长 0.5-1.5s，硬切为主
- 关键瞬间（斩击落刃）用 1-3 帧闪白强调
- 节奏：慢→快→爆→定格
  - 慢：对峙 2-3s/镜
  - 快：交锋 0.5-1s/镜
  - 爆：决胜 0.3-0.5s/镜 + 闪白
  - 定格：斩后定 0.5-1s 收尾

### 情绪段
- 镜长 3-5s，可叠化
- 留角色表情呼吸，别切太碎
- BGM 主导节奏，剪辑点踩拍

### 对白段
- 正反打切换，每句一切
- 角色说话时镜头给本人，停顿切对方反应
- 关键台词后留 0.3-0.5s 定格

## 剪辑点对齐
- 动作剪辑点对齐：A镜动作结束帧 = B镜动作开始帧（出刀→入刀）
- 音频先行：BGM 节拍点对齐剪辑点，增强节奏
- 配音尾音：剪辑点留出尾音 0.1-0.2s，别切太死

## 工具
- 剪映：快速剪辑，模板转场多，动漫项目可用
- DaVinci Resolve：专业调色 + 剪辑，长片/高质量
- Premiere：标准流程，团队协作
- FFmpeg 命令行：批量拼接/转码，脚本化处理

## FFmpeg 拼接模板
```bash
# 1. 生成文件列表
for /r %i in (*.mp4) do @echo file '%%i' >> list.txt
# 2. 无损拼接（同编码参数）
ffmpeg -f concat -safe 0 -i list.txt -c copy out.mp4
# 3. 需重编码拼接
ffmpeg -f concat -safe 0 -i list.txt -c:v libx264 -crf 18 -c:a aac out.mp4
```

## 备注
- 动漫转场忌用写实影视的「推拉摇移叠化」组合，易拖
- 硬切是动漫本体语言，多用硬切少用花式转场
- 闪白/闪黑帧数极少（1-3帧），多了刺眼

## WAN3.0 校准（2026-10-20）

- WAN3 30s 原生减少拼接点，FFmpeg 多段拼接模板定位降级为跨长段拼接备用：30s 原生一个段落内的多景别/多动作已可原生连续生成，段落内部不再需要硬切拼接；FFmpeg 拼接模板主要用于把多个独立 30s 段落接成更长集，使用频率显著下降。
