# 街舞拍摄总览：机位 / 焦段 / 鱼眼美学

## 核心要点

- 舞蹈拍摄第一铁律：**动作边界优先于构图美学**——舞者（含手、脚、甩动的肢体）任何时刻不能出画；先保证全身余量（headroom + footroom），再谈好看
- **机位高度跟着重心走**：Breaking 贴地→贴地低机位/高俯拍；站姿舞种→胸-眼平机位；高踢/托举→仰角给高度
- **舞种决定镜头性格**：Breaking 要冲击（低角+鱼眼+手持），Popping 要冷静（固定+中近景），House 要流动（steadicam 跟拍），齐舞要阵型（正面固定/缓推）
- 焦段安全区：**全身 35–50mm 等效**，广角显力量与空间但边缘变形（可利用），长焦压缩适合阵型纵深和情绪特写
- 帧率：正常跳 24/25fps 即可；大招升格用 50–100fps **只给 0.5–1 秒**；电子快门/高帧率拍快速脚步可降果冻效应
- 鱼眼（8–16mm）是 1990s breaking 录像带的文化符号，不只是镜头选择，是**风格声明**

## 详细内容

### 一、四条构图铁律

1. **全身余量律**：全景预留头顶一掌、脚下一脚的安全空间；快速 arm swing/踢腿方向额外留 20–30% 画面余量（waacking/krump 尤其）
2. **脚步不裁律**：拍脚步戏（house/footwork/glide）画面下沿必须低于脚踝，宁可多带地面——glide 错觉一旦裁脚立刻失效（320）
3. **手不出画律**：tutting/waacking/vogue hand performance 时，手部活动范围是身体外扩 1.5 倍，取景框按此放大
4. **动势留白律**：舞者朝向/甩出方向留运动空间（nose room），反方向是墙；环绕移动时留白方向跟着转

### 二、六类机位与舞种匹配

| 机位 | 高度/角度 | 视觉效果 | 最适配 |
|---|---|---|---|
| **贴地低角 floor-level** | 镜头贴地、微仰 | 人显得高大、腾空更高、"像在飞" | Breaking 全部、Krump stomp、登场（参考 Little Shao 拍法） |
| **斜 3/4 低角** | 腰高、微仰 | 兼顾力量与动作全貌 | Power move、air flare、齐舞前排 |
| **平视标准位** | 胸口到眼高 | 客观、尊重动作原貌 | Popping/Locking/Hip-Hop 展示、教学记录 |
| **斜上 3/4 高角** | 2–3m 高俯 | 圆形走位、地面图案清晰 | 6步/风车/swipe、齐舞阵型、cypher 圈 |
| **正俯视 top-down** | 垂直俯拍 | 图案化、去重量感、"轻盈" | Footwork 圆形轨迹、地面造型、Vogue floorwork |
| **正面全景/缓推** | 眼高平视固定 | 阵型、整齐度、仪式感 | 齐舞、Urban 编舞、T台/vogue 对峙 |

**角度心理学（沿用017/101/102体系）**：仰角赋权（舞者统治空间）、俯角显轻或显困（高俯让大招变轻盈是舞蹈特有用法）、正侧最读纵深（wave、body roll、前后移动）。

### 三、焦段选择

| 焦段（等效） | 特性 | 舞蹈用途 |
|---|---|---|
| **鱼眼 8–16mm** | 180°视场、中心正常边缘桶形畸变、深景深 | 1990s b-boy 录像带美学；狭小空间拍全身；低角强化腾空 |
| **广角 24–28mm** | 近大远小、空间夸张 | 低角力量感、群舞环境、手持冲击 |
| **标准 35–50mm** | 比例自然 | 专业舞蹈视频默认（50mm 拍全身约距 2.5–3.5m） |
| **中长焦 70–135mm** | 压缩纵深、浅景深 | 阵型压缩、表情/手部特写、隔人群拍摄 |
| **长焦 200mm+** | 强压缩、需要远距 | 舞台远景抓拍、剪影、隔离个体 |

注意：广角近距拍 waving/isolation 会拉伸扭曲动作精度，技术展示优先 35–50mm。

### 四、鱼眼美学（Breaking 的文化镜头）

- **来源**：1990s 纽约 b-boy 用家用 Hi8/DV 配广角附加镜在小公寓/俱乐部拍圈，鱼眼能在 2m 距离装下整个人+动作
- **视觉签名**：桶形变形让风车/flare 的圆弧更大、边缘人群微微弯成弧形（cypher 的"圈"被镜头强化）、地平线弯曲
- **使用守则**：
  - 舞者放画面中心（中心畸变小，动作可读），利用边缘变形收纳围观人群
  - 贴地仰拍时鱼眼让腾空高度夸张 20–40%
  - 同片混用时给它语义：鱼眼＝战斗/街头段落；正常镜头＝日常/情绪段落（风格切换=空间切换）
- **AI 提示词**：`fisheye lens, extreme wide angle, barrel distortion, ground-level, VHS 90s aesthetic`；不要在需要精确展示几何的 tutting 段用（直线被弯掉）

### 五、运动镜头适配（按舞种）

| 舞种 | 推荐运镜 | 忌 |
|---|---|---|
| Breaking | 固定为主+大招甩镜/快速横移跟圆弧 | 全程乱晃手持 |
| Popping | 三脚架固定、缓推到造型 | 随 pop 抖动镜头（pop 是舞者的事） |
| Locking | 中全景固定+锁拍轻推/快推 | 错过 lock 造型的移动 |
| Hip-Hop 齐舞 | 正面固定/缓推、轨道横移 | 快切碎切 |
| House | Steadicam 平行跟走/前退跟拍 | 与舞者反向乱动 |
| Krump | 手持跟拍、重拍低频震动（300） | 晃到出画 |
| Waacking/Vogue | 固定 3/4 正面带手臂余量、造型定格轻推 | 手部裁切 |

### 六、曝光/帧率/快门基础参数

```
帧率：24/25fps 基础观感；50/100fps 升格仅用于大招半秒到1秒
快门：1/(2×帧率) 标准运动模糊；快速脚步想清晰可 1/(4×帧率)
（快门过快会让转动"卡顿发假"，拍 windmill/flare 别用太高速快门）
光圈：群舞/全身收 f5.6–f8 保深景深；手部/表情特写可 f2.8 浅景深
ISO/光：街舞场景常暗，保快门优先，噪点可保留作街头质感
对焦：锁定舞者活动区域用手动/跟踪对焦；footwork 低机位用小焦距广角保全景深
```

## 关键参数 / 模板 / 清单

### 拍摄前机位选择决策表

```
这段是什么？→ 机位
├─ Breaking 站姿 toprock → 平视/微低全景
├─ Footwork → 斜上3/4或正俯（看圆）
├─ Power move → 贴地3/4低角（看高）或高俯（看圆），二选一为主
├─ Freeze → 低角微仰，hold 2拍
├─ Popping → 固定正面，中景；wave 可加正侧机位
├─ Tutting/finger tut → 中近景/特写，背景压净
├─ Glide → 固定平视全身拍到脚，地面有纹理
├─ 齐舞 → 正面高位全景+侧面纵深第二机
├─ Cypher → 圈外手持，弧线上有进有出（328）
└─ 变身/Krump → 手持低角推进+重拍震动
```

### 单镜验收清单

- [ ] 舞者极限动作位（手/脚最高点、最外点）全程不出画
- [ ] 脚踝/手部按戏的需要完整保留
- [ ] 机位高度与动作重心匹配（贴地戏不站着俯拍）
- [ ] 朝向留白正确，运动方向不撞框
- [ ] 鱼眼/广角使用有语义，技术展示段未被畸变干扰
- [ ] 运动模糊适度（大招不发"鬼畜卡顿"）
- [ ] 地面纹理/影子在画面中（高度与滑动的参照证据）
