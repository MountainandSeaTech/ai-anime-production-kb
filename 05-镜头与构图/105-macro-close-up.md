# 微距特写（Macro Close-Up）

## 核心要点
- 极近拍微小细节=**放大不可逃**=压迫/悬疑/顿悟
- 一滴汗/一双眼/一只手=微观宇宙
- 比近景更近——微距=超越日常视距=异化=张力
- 放大=时间凝固=瞬间被拉长（与 029 冲击帧同源）

## 张力来源

### 1. 放大=不可逃
- 微距=填满画面=无处可看别处=不可逃
- 细节被放大=观众被"按头看"=压迫
- 比近景更强的"聚焦暴力"

### 2. 微观=异化
- 日常视距看不到的=微距能看到=异化
- 汗珠/瞳孔/指纹=熟悉变陌生=诡异
- 异化=不安=张力

### 3. 时间凝固
- 微距=瞬间的放大=时间被"拉停"
- 一滴汗滑落=被放慢=凝固=冲击帧（029）
- 微观时间=被拉长=压迫

### 4. 细节=叙事
- 微距细节=叙事信息（手抖/汗/瞳孔缩=情绪）
- 不用台词=一个微距=情绪全传递

## 微距的拍摄对象
| 对象 | 叙事 |
|---|---|
| 眼睛/瞳孔 | 恐惧/顿悟/杀意 |
| 汗珠 | 紧张/恐惧/极限 |
| 手/指 | 抖/握拳/松=抉择 |
| 嘴唇 | 干裂/颤抖=极限 |
| 武器细节 | 刀刃/扳机=即将 |
| 物件 | 线索/证据=悬疑 |

## 与张力的配合
| 场景 | 微距效果 |
|---|---|
| 紧张/恐惧 | 汗珠/瞳孔微距=极限压迫 |
| 顿悟/发现 | 瞳孔放大微距=顿悟瞬间 |
| 抉择时刻 | 手抖/握拳微距=抉择 |
| 悬疑线索 | 证据微距=揭示=顿悟 |
| 即将爆发 | 武器细节微距=前一刻 |

## 微距 vs 近景 vs 特写
| 距离 | 主体大小 | 效果 |
|---|---|---|
| 近景 | 胸部以上 | 日常近距=情绪 |
| 特写 | 面部 | 强情绪=脸=压迫 |
| 大特写 | 眼/嘴局部 | 极限情绪=瞬间凝固 |
| 微距 | 汗/瞳/指纹 | 放大异化=不可逃=顶配 |

## AI 提示词
- 瞳孔微距：`extreme macro close-up, pupil dilating, eye detail, sweat, terror, shallow depth, cinematic`
- 汗珠微距：`macro shot, single sweat drop rolling down temple, tension, extreme detail, slow motion`
- 手部微距：`macro close-up, trembling hand, gripping fist, decision moment, extreme detail`
- 物件微距：`macro detail, blade edge catching light, evidence object, shallow depth, revelation`

## 常见坑
- **微距无叙事**：为近而近=空；微距要传递信息
- **微距太多**：多用=失冲击；用作"凝固瞬间"1-2次
- **AI 畸变**：极近 AI 易畸变（手/眼）→图生视频锁（088）
- **无景深**：微距必须浅景深=背景虚=聚焦；大景深（093）微距=糊

## 进阶
- 微距+慢镜=时间凝固顶配（029 冲击帧）
- 微距+浅景深=极致聚焦=不可逃
- 微距+高对比（064）=汗/光=极限压迫
- 微距作 build 段末=逼近凝固=接 peak 爆点

## 备注
- 微距=极近拍微小=放大不可逃=异化=凝固
- 一滴汗/一双眼=微观宇宙=叙事
- 比特写更强的"聚焦暴力"
- 用作"凝固瞬间"1-2次，不滥用
- 微距+慢镜=时间凝固顶配
- AI 极近易畸变→图生视频锁
