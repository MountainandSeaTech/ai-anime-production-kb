# 三分法则与负空间留白（Rule of Thirds & Negative Space）

## 核心要点
- 主体压在**三分线交点**+大片负空间留白=失衡=张力
- 留白不是"空"——是"会说话的空"
- 负空间传递：孤独/压迫/未知/威胁
- 与对称（092）相反——对称是秩序压迫，三分留白是失衡压迫

## 张力来源

### 1. 失衡=不安
- 主体压边/角=重心偏=视觉失衡=不安
- 人眼本能求平衡——失衡=张力

### 2. 留白=孤独
- 主体周围大片空=视觉孤独=情绪传递
- 越多留白=越孤独/越渺小/越被吞噬

### 3. 留白=未知威胁
- 空白处=看不见=未知=想象填充=威胁
- 恐怖片留白=怪物在"空白处"（不在画面=在想象）

### 4. 视线方向=留白
- 角色看向留白方向=视线引导=观众跟随=期待/不安
- 留白在视线方向=未知的"他"在那

## 三分法则的位置
```
┌─────┬─────┬─────┐
│     │     │     │
├────-●────-┼────-●────┤  ← 上1/3线，两交点是焦点位
│     │     │     │
├────-●────-┼────-●────┤  ← 下1/3线，两交点是焦点位
│     │     │     │
└─────┴─────┴─────┘
主体压在交点=动态平衡=不呆板
```

## 负空间的类型
| 留白位置 | 情绪 |
|---|---|
| 主体上方大片空（多 headroom） | 孤独/被压/渺小 |
| 主体看向的留白 | 期待/不安/未知 |
| 主体背后的留白 | 过去/追忆/被追 |
| 包围主体的留白 | 孤绝/被吞噬 |

## 经典案例
- 《Ida》(2013)：4:3 画幅+极端低位构图=头顶大片留白=压抑/孤独
- 角色压下1/3+头顶巨量留白=被压/渺小

## 与张力的配合
- **孤独张力**：主体压角+四周留白=孤绝
- **恐怖张力**（间）：留白处=未知=威胁在画外
- **期待张力**：视线方向留白=观众跟随=不安
- **悲剧张力**：角色退到画面边+留白=被世界抛弃

## AI 提示词
- 孤独留白：`character in lower third, massive negative space above, isolation, minimal, cinematic`
- 视线留白：`character looking into negative space, rule of thirds, anticipation, cinematic`
- 被吞噬：`small figure surrounded by vast emptiness, rule of thirds, insignificance, wide shot`

## 常见坑
- **主体居中**：居中=对称=呆；压三分点才动态
- **留白无目的**：为留而留=空；留白要服务情绪
- **留白太少**：填太满=无呼吸；至少留 1/3 空
- **视线方向错**：视线朝框边=堵；视线朝留白=呼吸

## 进阶
- 三分+框中框（091）=主体压交点+框=聚焦+失衡
- 三分+低角度（101）=压迫+失衡=弱势主角
- 极端留白（主体极小+空极大）=被吞噬顶配
- 打破留白（突然填满）=爆点/冲击

## 备注
- 三分法则+负空间=失衡=孤独/压迫
- 留白是"会说话的空"——不是空洞
- 主体压交点=动态平衡；居中=呆
- 视线方向留白=期待/不安
- 与对称相反：对称是秩序压迫，留白是失衡压迫
- 《Ida》极端留白=顶配孤独
