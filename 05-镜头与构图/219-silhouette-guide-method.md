# 剪影导览法——简化为剪影检验构图

## 核心要点
- **剪影 = 构图的 X 光片**：把所有元素压成背光黑色剪影，剥离细节后只看基本形状如何作为叙事方式组合在一起
- 剪影检验的是「整体场景」是否被精心设计，而非单个角色画得好不好看
- **尺寸大小 + 光线明暗**是突出视觉焦点的两大杠杆：让某个角色更大、更亮，观众视线自然落向它
- **双重结构**：整体构图趋势由一条主对角线（主结构）驱动，角色群构成次级结构与节奏
- 缩略图阶段先做剪影，简洁才是王道，细节全部忽略

## 详细内容

### 1. 为什么要看剪影
观众在看清细节之前，先识别的是轮廓。把画面里的角色、道具、环境全部简化为黑色剪影后，剩下的就是形状与形状之间的关系——这才是构图真正承载叙事的部分。如果剪影看起来混乱、没有重点，那么加上再多细节也救不回来。

剪影检验要回答的问题：
- 视线第一眼落在哪里？有没有明确的焦点？
- 元素之间是协调流动，还是单摆浮搁、毫无联系？
- 有没有故意的断点来强化戏剧张力或突变？

### 2. 用尺寸与明暗突出焦点
图例 2.7 / 2.8：三个条状剪影在轮廓光帮助下提高辨识度。画面最右的角色被刻意放大、提亮，成为视觉焦点。这样观众眼睛不会在画格内漫无目的地乱转，而是被精准引导到场景的特定点上。

操作原则：**焦点角色 = 更大的剪影 + 更强的轮廓光**，其余角色主动缩小、压暗，甘当配角。

### 3. 双重结构：主对角线 + 角色次级节奏
图例 2.9 / 2.10：场景的整体构图趋势围绕一条特殊对角线展开（主结构），在这条流动线之上，三个角色构成次级结构与节奏。每个角色自身又被描述成弧形，最终汇集于画面顶部。

这就是双重结构：
- **主结构**：一条对角线或几何形状，决定整张画面的能量走向
- **次级结构**：角色沿主结构排列，自身的弧形/直线形成节奏与呼应

图例 2.11 / 2.12 进一步说明：一个独占鳌头的角色位于画面最右；构图整体基于橙色三角形；角色流动感沿从右往左的直线展开。

### 4. 几何剪影草图
图例 2.15–2.19 展示了基于简单几何形状的剪影效果构图。豪放的草图忽略所有不必要的细节——**在这个阶段，简洁才是王道**。先确定形状骨架，再往里面填肉。

## 对 AI 短剧的落地要点

生成视频/图像时，剪影思维要写进提示词：

- **先给形状，再给细节**：提示词开头用几何描述锁定骨架，如「三个黑色人形剪影，右侧最大最亮，沿对角线排列，整体呈三角形构图」
- **轮廓光强调焦点**：对主角加 `rim light / 轮廓光 / backlight`，让它在剪影中依然跳出来
- **缩略图自检**：生成后把图调成纯黑白剪影（或在脑中想象），检查焦点是否一眼可辨、元素是否协调
- **群戏场景必做**：多角色同框时，先用剪影法分配主次（1 个主角大+亮，其余小+暗），避免 AI 平均分配注意力导致画面发闷
- **负向词**：`flat silhouette, no focal point, evenly lit crowd, cluttered outline`

## 关键参数 / 模板 / 清单

```
剪影自检清单：
[ ] 画面是否有唯一的视觉焦点（最大/最亮的剪影）？
[ ] 主结构线（对角线/三角形/弧线）是否清晰？
[ ] 角色次级结构是否沿主结构形成节奏？
[ ] 元素之间是否有流动感，而非各自孤立？
[ ] 有没有故意的断点来制造戏剧张力？
```

```
提示词模板（群戏剪影骨架）：
silhouette of [N] characters, backlit, rim light on protagonist,
largest figure on [right], diagonal composition, strong negative
space, dramatic, no facial details --ar 16:9
```

## 备注
- 剪影法适合在**缩略图/构图阶段**使用，不适合精修阶段才用——那时改成本太高
- 剪影不等于全部涂黑：轮廓光（rim light）是让剪影依然可读的关键，尤其是主角
- 群戏构图用剪影法检验最有效，能快速发现「谁是主角」这件事有没有讲清楚
- 剪影检验可与 220（形状语言）串联：先看剪影轮廓是否清晰，再看底层几何形状是否支撑叙事
- AI 生成多角色时极易出现「人人都是主角」的平均光，剪影法是最直观的排查手段
