# 画幅制式叙事法（宽高比）

## 核心要点
- **画幅（宽高比 / Aspect Ratio）= 观众还没看懂剧情时先感受到的情绪底色**：比例本身就是语法，不是技术参数
- 越窄（1:1、4:3）→ 越亲密、逼仄、压抑；越宽（2.39:1）→ 越宏大、疏离、史诗
- **同一部片内切换画幅**是最省钱的叙事手段：区分现实／梦境、过去／现在、禁锢／释放
- 传统 1.33:1 是无声片与电视标准；1.85:1 与 2.39:1 是现代宽银幕主流
- AI 生成时必须**开场就锁定画幅**，全片统一（除非有意图地切换）

## 常用制式对照

| 制式 | 别名 | 情绪／适用 |
|---|---|---|
| 1.33:1 | 4:3 | 早期标准；亲密、怀旧、压抑、孤立（《Ida》4:3 头顶留白） |
| 1.85:1 | 学院宽银幕 | 当代剧情片主流，视野与亲密的平衡 |
| 2.39:1 | 2.40:1 变形宽银幕 | 史诗、动作、大景观；广阔=人物渺小 |
| 1.90:1 | DCI 数字放映标准 | 数字影院通行规格 |
| 1:1 | 方形 | 特写、肖像、被框住的孤立感 |
| 9:16 | 竖屏 | 短剧／短视频原生画幅，贴近感强、信息密度高 |
| 1.43:1 | IMAX 70mm | 极致沉浸，巨幕专属 |

## 画幅切换做叙事（进阶）

```
现实 → 梦境／回忆：宽 → 窄（挤压），或窄 → 宽（释放）
过去 → 现在：《妈咪》1:1 → 16:9 = 视觉上的"呼出一口气"
禁锢 → 自由：竖窄框 → 全幅展开
单一角色心理 → 群像史诗：16:9 → 2.39:1
```
切换点必须落在**情绪或时空的硬转折**上，且一次只表达一件事。

## AI 生成落地

```
番剧（横屏）：16:9 ｜ 短剧（竖屏）：9:16 ｜ 史诗／大场面段落：2.39:1
AI 提示词里锁定画幅：另起一行写明画幅，并在负向词补
  letterbox bars / stretched aspect / inconsistent aspect ratio / black bars
Midjourney 用 --ar 16:9 / --ar 9:16 / --ar 2.39:1；视频模型用"宽银幕画幅"自然语言描述
```

## 备注（踩坑）
- 全片画幅必须**在资产与首帧阶段就锁死**（写进该剧的美术规范），否则续接镜会出现黑边或拉伸
- 横竖屏素材混编是发布级事故：同一项目只用一个主画幅，切换必须是**叙事意图**而非随手
- 画幅切换后，构图／景别策略要跟着改（窄画幅慎用横向多点构图）
