# 镜面反射镜头（Mirror Shot）

## 核心要点
- 镜中影=**双重/分裂/真相**——角色与倒影=两个自我
- 镜是第二画面=框中框（091）的变体
- 镜面=自我审视/双面人格/真相揭示
- 技法：替身同步/双面镜/机位角度

## 张力来源

### 1. 双重/分裂
- 角色与镜中影=两个自我=分裂
- 双面人格/精神分裂用镜=视觉化
- 哪个是真？=悬疑=张力

### 2. 自我审视
- 角色看镜=看自己=内省=内心
- 镜中影"回看"=角色面对自己=对话=张力
- 抉择/顿悟场景对镜=内心放大

### 3. 真相揭示
- 镜中映出画外=揭示=悬疑
- 角色不看镜头但镜中映凶手=偷窥=恐怖
- 镜=揭示真相的工具

### 4. 框中框变体
- 镜=第二画面=框中框（091）
- 镜框=聚焦+困局+纵深
- 比门框更"内化"——困住的是自我

## 镜面的隐喻
| 用法 | 隐喻 |
|---|---|
| 角色对镜 | 自我审视/内省/抉择 |
| 镜中双我 | 分裂/双面/真假 |
| 镜映凶手 | 偷窥/真相揭示/恐怖 |
| 碎镜 | 自我崩/厄运/破裂 |
| 无限反射镜 | 迷失/无限/深渊 |

## 技法（实拍关键）

### 1. 替身同步法
- 镜其实没镜——墙开洞=替身在对面背对镜头
- 演员和替身动作同步=假反射
- 《终结者2》用 Linda Hamilton 真孪生姐妹=镜面对戏

### 2. 双面镜法
- 半反半透镜=一侧看反射一侧穿透
- 《上海小姐》Welles 用双面镜=镜中迷宫
- 拍穿透侧=看不见摄影机=真反射感

### 3. 机位角度法
- 计算摄影机/演员/镜的几何关系
- 镜面只在特定角度反射摄影机=避开
- 调角度让摄影机不在反射区

### 4. 后期擦除法
- 拍到摄影机反射→后期擦除
- 现代多用绿幕/CG 擦除

- 碎镜=自我崩=破裂=厄运
- 碎片映多个自我=彻底分裂
- 碎镜是精神崩的视觉顶配

## 常见坑
- **穿帮摄影机**：镜中反射摄影机=穿帮；用替身/角度/后期
- **镜面无隐喻**：为镜而镜=空；要服务双重/真相
- **AI 镜面乱**：AI 画镜面易畸变→图生视频锁（088）
- **滥用**：多用=廉价=失冲击；关键时刻用
