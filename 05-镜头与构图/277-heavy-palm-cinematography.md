# 刚猛掌法的镜头语言

## 核心要点

- 刚猛系武功的力量感 70% 靠镜头与反应，30% 靠出招者动作本身
- 核心节奏型：**慢蓄-爆发-延迟-反馈** 四拍，缺"延迟"拍力量感减半

## 详细内容

### 机位规则
1. **低角度仰拍出招者**——压迫感来源；配合降龙掌下压式招（飞龙在天）必备
2. **前景遮挡出掌**——掌从镜头前掠过（虚焦前景），增加速度层次
3. **受击者反应用平视或微俯**——与出招者仰拍形成力量位差

### 节奏四拍
1. 慢蓄：蓄力 1-2 秒（密云不雨状态），镜头缓推
2. 爆发：出掌 2-4 帧快切，可抽帧
3. **延迟：击中后受击者静止一拍（0.3-0.5 秒）再飞出**——这是"力量很大"的潜台词
4. 反馈：环境破坏（地砖碎裂、木柱裂纹、尘土环爆）作力量刻度

### 力量刻度表（环境破坏递进）
| 掌力级别 | 环境反馈 |
|---|---|
| 三成力 | 衣发倒伏、落叶吹散 |
| 五成力 | 尘土环爆、桌椅掀翻 |
| 七成力 | 地砖碎裂、木柱现裂纹 |
| 十成力 | 墙塌、人嵌入墙/地 |

## 关键参数 / 模板 / 清单

**分镜提示词节奏标注法**（Wan 3.0 自然语言）
```
镜头先缓推蓄力约2秒，出掌瞬间切换为快切镜头，掌力击中后对手静止半秒，
随后整个人向后飞出撞碎身后木桌，碎片与尘土同时扬起。
```

**自检清单**：有没有延迟帧｜环境破坏级别与剧情掌力是否匹配｜仰拍/平视的位差是否拉开｜前景遮挡有没有增加速度感

## 备注

- 延迟帧时长与掌力成正比，但超过 0.8 秒会变滑稽——喜剧场景除外
- 与 186/189（动作剪辑条目）联用：刚猛招的剪辑点卡在"掌到人飞"之间，不卡出掌中段
