# 主观镜头/POV（Point-of-View Shot）

## 核心要点
- 镜头=**角色眼睛**=第一人称代入=观众变角色
- 悬疑/恐怖最强视点——观众"亲眼看见"=最恐
- 经典三段式：看（角色望）→ 看见（POV）→ 反应（角色回切）
- 从客观（第三人称）到主观（第一人称）=视角转换=张力

## 张力来源

### 1. 第一人称代入
- POV=观众=角色=亲历=不可逃代入
- 比第三人称更"参与"——不是旁观而是经历
- 恐怖 POV=观众"亲眼见鬼"=最恐

### 2. 未知=悬念
- POV=只看角色看的=有限视角=未知
- 看不见全貌=想象填充=悬念
- 希区柯克悬念=POV 逐步揭示

### 3. 认同/共情
- POV=观众认同角色=共情
- 角色所见即观众所见=情感绑定

### 4. 偷窥感
- POV=偷窥视角=观众成"窥视者"
- 不安/诡秘场景 POV=偷窥张力

## POV 经典三段式（关键）
```
A镜：角色望向某处（看）——建立"要看"
B镜：POV（看见）——观众=角色眼，看见目标
C镜：角色反应（回切）——角色情绪=观众情绪
```
- A→B→C 是 POV 的标准结构
- B 镜可以多切（多次 POV 揭示）

## POV 的类型
| 类型 | 特点 |
|---|---|
| 角色 POV | 镜头=角色眼=第一人称 |
| 受害者 POV | 受害者视角看凶手=恐怖 |
| 凶手 POV | 凶手视角逼近受害者=偷窥压迫 |
| 主观手持 | 手持晃=主观=混乱/恐惧 |
| 梦境 POV | 变形/模糊=梦境/幻觉 |

## 大师案例
| 影片 | 场景 | POV |
|---|---|---|
| 《惊魂记》Hitchcock | 淋浴谋杀 | 受害者 POV=恐怖 |
| 《大黄鲨》 | 第一人称鲨鱼 | 凶手 POV=偷窥 |
| 《闪灵》 | Danny 三轮车 | POV 走廊=诡异 |
| 《女巫布莱尔》 | 全片手持 POV | 伪纪录=沉浸恐怖 |

## 与张力的配合
| 场景 | POV 效果 |
|---|---|
| 恐怖（间） | 受害者 POV=亲眼见=最恐 |
| 悬疑 | 有限视角=逐步揭示=悬念 |
| 追逐 | 被追者 POV=逃亡代入 |
| 发现/顿悟 | POV 看真相=观众也顿悟 |

## 凶手 POV（进阶）
- 镜头=凶手眼=逼近受害者=偷窥+压迫
- 观众被迫"成凶手"=道德不安=张力
- 比受害者 POV 更诡异——你是加害者

## AI 提示词
- 角色 POV：`POV shot, first person perspective, character's eye view, looking at, subjective camera, handheld`
- 受害者 POV：`victim POV, looking up at attacker, terror, handheld, low light, horror`
- 凶手 POV：`stalker POV, approaching victim, voyeuristic, creeping, handheld, ominous`
- 梦境 POV：`dreamlike POV, distorted, blurred edges, surreal, hallucination, warped`

## 常见坑
- **全程 POV**：全片第一人称=晕=失叙事；用三段式穿插
- **无反应镜**：只有 POV 没角色反应=断裂；要 A→B→C
- **POV 太稳**：太稳=不像人眼；手持微晃=主观感
- **凶手 POV 滥用**：多用=廉价=失不安；关键时刻用

## 进阶
- POV+手持=混乱/恐惧代入
- POV+低光=恐怖顶配（064 高对比）
- 凶手 POV=道德不安=诡异顶配
- POV 切客观=视点转换=张力（见 081 POV 切换）
- **身体在场（POV 的肉体证据）**：纯第一人称易成"架空摄像机"——补角色身体线索（呼吸声、面罩/头盔边缘入画、双手入画、汗珠滑进眼角），观众才信这镜头长在角色身上

## 备注
- POV=镜头=角色眼=第一人称代入
- 经典三段式：看→看见（POV）→反应
- 悬疑/恐怖最强视点——亲眼见=最恐
- 凶手 POV=偷窥+道德不安=诡异顶配
- 用三段式穿插，不全程第一人称
- 手持微晃=主观感
