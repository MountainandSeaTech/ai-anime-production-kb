# 构图张力：负空间 / 对称 / 失衡

## 核心要点
- 构图是**张力的底座**——机位景别运动都建立在构图之上
- 三大张力构图：**负空间**（孤立/潜伏）、**对称**（仪式压迫）、**失衡**（不安）
- 角色压在画面一角 = 被环境挤压 = 弱势/被困
- 构图失衡（dutch/偏置）= 心理异常的视觉信号

## 三大张力构图

### 1. 负空间（Negative Space）
- 画面大片空无，角色压在一角/很小
- 张力来源：**空=可能藏着威胁** + 角色被孤立
- 经典：主角压在右下角，左上大片空白=观众盯空白等"什么东西会出现"
- 适用：孤独、潜伏威胁、追逃孤立、决别

> 负空间越大，"即将出现"的预期越强——这是 011 延迟释放的视觉化。

### 2. 对称构图（Symmetry）
- 左右/上下严格对称
- 张力来源：**仪式感=不可违抗** + 对称太完美=异常不安
- 经典：居中对峙、Boss大厅、神殿审判
- 适用：威压登场、对等对峙、宿命对决
- 注意：完全对称在 AI 生成里偶发畸变，可用 near-symmetry 替代

### 3. 失衡构图（Imbalance / Dutch）
- 地平线歪斜、主体偏置、重心不稳
- 张力来源：**本能的不安**——人脑倾向平衡，失衡=异常=危险
- 经典：角色心理崩坏、世界观异常、背叛揭露
- 适用：心理转折、异常事件、崩溃瞬间
- 慎用：每镜都失衡=没对比=失效

## 角色位置与权力

| 角色位置 | 感受 | 张力用途 |
|---|---|---|
| 正中居中 | 主体、掌控 | 对等对峙、主角决意 |
| 压在一角 | 被挤压、弱 | 弱方、被困、孤立 |
| 低位居中 | 被俯察 | 被审判、失败 |
| 中心但小（负空间） | 孤立渺小 | 孤独、潜伏威胁 |

## 经典张力构图组合

### 居合对峙
```
对称构图，两人分列左右（1.5s）→ 大特写刀柄居中（1s）→ 失衡倾斜出刀瞬间（0.3s）→ 对称全景定格收刀（1s）
```
对称（仪式）→居中特写（聚）→失衡（爆发）→对称（收束）。

### 潜伏威胁
```
负空间全景，主角压右下角小，左上大片空（2s）→ 焦点/rack 到左上空区，敌人浮现（0.5s）→ 负空间被填满，压迫反转（1s）
```

### 弱者困境
```
主角压左下角小，右上大片负空间（1.5s）→ 仰视特写Boss占满画面（1s）→ 俯视主角更小（1s）
```

## 构图法则速查
- **三分法**：主体放三分线交点，比居中更"活"，但张力不如居中——居中=主体掌控，三分=动态
- **引导线**：走廊/栏杆/光柱把视线引向主体或威胁，强化"逼近"
- **前景遮挡**：前景物体半遮主体=窥视感=不安临场
- **框中框**：门框/窗框/刀缝里看主体=被困/受限

## AI 提示词对照
- 负空间：`negative space, character in lower corner, vast empty space` / `minimalist composition`
- 对称：`symmetrical composition` / `centered, bilateral symmetry`
- 失衡：`dutch angle, tilted frame` / `asymmetric, off-balance composition`
- 角色压角：`character pushed to frame edge, small in corner`
- 框中框：`framed by doorway` / `viewed through window`

## 备注
- 构图是 013 空间轴的核心操作，成本最低（prompt 即可）回报最高
- AI 生成里构图词相对稳，优先用构图调张力再考虑机位运动
- 负空间 + 浅景深 + 大特写 = 注意力三重压缩，蓄势顶配
