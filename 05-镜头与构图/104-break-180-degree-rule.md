# 越轴/打破180度线（Breaking the 180° Rule）

## 核心要点
- 180度线=两角色间隐形动作线——机位应守一侧=空间连贯
- **故意越轴**=空间错位=失衡/混乱/转折信号
- 规则是工具不是法律——刻意越轴=有意的失衡
- 用于：权力反转/混乱/精神崩/转折点

## 180度线原理
```
        角色A ●——————动作线——————● 角色B
                ╲    ╱
                 ╲  ╱  ← 机位守这一侧（180度半圆）
                  ╲╱
              ▼─────▲  ← 守线：A 在画面左，B 在画面右
        （越轴到另一侧=A 右 B 右=空间翻转=错位）
```
- 守线=角色左右位置不变=空间连贯=观众不乱
- 越轴=角色左右翻转=空间错位=观众失衡

## 越轴的张力来源

### 1. 空间错位=失衡
- 角色左右翻转=大脑处理不了=失衡
- 微妙的不适=不安=张力

### 2. 权力反转信号
- 对峙中越轴=权力关系翻转的视觉信号
- 不用台词就传递"力量变了"

### 3. 混乱/精神崩
- 混战/精神崩场景越轴=混乱=失序
- 观众分不清方向=代入角色的混乱

### 4. 转折点标记
- 越轴=视觉"断"=标记转折
- 比硬切更"空间性"地标记转变

## 何时越轴（关键）
| 场景 | 越轴效果 |
|---|---|
| 权力反转 | 对峙中越轴=力量翻转信号 |
| 混乱/混战 | 越轴=失序=代入混乱 |
| 精神崩溃 | 越轴=精神失方向 |
| 转折点 | 越轴=视觉断=标记转折 |
| 惊吓/顿悟 | 越轴=世界倾覆=失衡 |

## 干净越轴法（关键）
- 不能硬越=观众懵=业余感
- 干净越轴法：
  1. **运镜越轴**：镜头移动跨线=观众看到过渡=重映射空间
  2. **中立镜过渡**：切正面/背面中立镜=重置=再越轴
  3. **动作越轴**：角色移动改变动作线=自然越
  4. **POV 越轴**：切 POV 再回=重置视角

## 与张力的配合
- **反转张力**（049）：越轴=权力翻转视觉信号
- **混乱张力**：混战越轴=失序代入
- **精神崩张力**：越轴=角色失方向
- **转折标记**：越轴=视觉断=标记剧情转折

## 常见坑
- **无意越轴**：不故意越了=业余=观众懵；要刻意
- **硬越无过渡**：直接越无运镜/中立镜=断=业余；用干净越轴法
- **越轴太频繁**：多越=失方向=乱；关键时刻1-2次
- **对白越轴**：普通对白越=无理由=懵；只张力场景越
