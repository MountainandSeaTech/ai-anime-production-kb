# 画幅转换三法——1.85:1 与 2.35:1 的微妙变化

## 核心要点
- 画幅比例改变通常意味着整个构图要重新考虑，但 1.85:1 与 2.35:1 之间往往只需微调
- **三种转换方法**：①保持高度不变调宽度（裁两边）；②保持宽度不变调高度（加/减上下）；③宽高同时折中
- **转换前必须扪心自问**：原始画幅哪一部分赋予场景最佳视觉信息？顶部、底部还是两边？
- 裁剪不是平均取中，而是根据叙事价值决定哪边多裁、哪边少裁
- 与 184（画幅制式叙事法）互补：184 讲各画幅的叙事含义，本条讲画幅间如何转换与取舍

## 详细内容

### 1. 三种转换方法

| 方法 | 操作 | 适用判断 |
|---|---|---|
| **① 保高调宽** | 高度不变，裁剪或扩展两边 | 画面上下信息是叙事核心（如角色全身、天空vs地面比例） |
| **② 保宽调高** | 宽度不变，增加或删减上下 | 画面横向信息是叙事核心（如远景关系、左右对峙） |
| **③ 宽高折中** | 宽高同时平均调整 | 中心区域是能量焦点，四周均可让步 |

### 2. 转换前的灵魂拷问
把场景从一种画幅「转换」到另一种画幅之前，先问自己：**哪些信息最有价值？原始画幅的哪一部分赋予了场景最佳视觉信息？** 是画格顶部、底部，还是左边/右边？想清楚之后再决定修改哪个维度，才能保持叙事完整性。

### 3. 案例一：海盗船（保高调宽）
三个海盗划小船从大帆船驶向远处大船。2.35:1 画幅顶部没有多余帆船与天空，底部没有多余海水，非常合适。若必须用 1.85:1：

- **保高调宽**：保留高度，裁两边。但不是平均取中——画面右边「空气」太多，可多裁画右，但不能把远处大船全部切掉（要交代海盗去哪）；画左前景帆船也可裁掉一些（对叙事无用）。
- **保宽调高**：保持宽度，调整高度。在顶部扩展帆船信息可强化大小对比的戏剧性；在底部增加海面信息可突出海盗身陷危机（危机来自大自然而非帆船压力）。上下滑动画面会产生截然不同的基调。

### 4. 案例二：攻击碉堡（保高调宽 + 保宽调高）
海军陆战队在战机掩护下冲山头进攻碉堡。

- **保高调宽**（1.85 裁两边）：碉堡处于画面右侧角落（压力点尽头），超出三分法范围。裁剪后前景士兵（画左画右都有）保留，对叙事无用的信息被裁掉，动作叙事性依然清晰，失衡感与动势几乎完整保留。
- **保宽调高**：1.85 画幅对原 2.35 底部裁剪，同时扩展顶部信息（支援战机），士兵不再孤军作战。再往下移动去掉大部分飞机，主题变成地面士兵如何在地形上艰难前进——**画幅上下移动直接改变场景基调**。

### 5. 案例三：超低空飞行（宽高折中）
飞机编队飞向远处航母。为保持叙事完整性，两种画幅构图中心位置几乎一样，左右两边平均裁剪（不同于前两个案例一边多一边少）：

- 画右裁太多 → 中心飞机机翼过分靠近边缘，构图不舒服
- 画左裁太多 → 前景飞机机翼丧失细节与趣味性
- 因此**居中构图**是最佳解

折中方法（图例 5.26–5.29）：先把两种画幅叠加，确定镜头能量的发射与聚集点（落在飞机身上的消失点），从该点向画面角落引线，放大构成全新画幅，确保 1.85 与 2.35 使用同一个动势发点。

## 对 AI 短剧的落地要点

- **先定主画幅再生成**：不要先生成 2.35 再裁成 1.85，而是在提示词里直接写目标画幅（`--ar 1.85:1` 或 `cinematic 1.85 aspect ratio`）
- **如需跨画幅复用素材**：生成时在核心信息四周留足「安全余量」（负空间），方便后期裁剪
- **提示词标明视觉核心**：如 `focal point at center, safe margins on all sides for cropping`，让 AI 不把关键信息贴边
- **裁剪决策**：后期裁画幅时，先确定叙事焦点落在哪，再决定裁哪边、裁多少，绝不平均取中
- **横竖屏转换**：竖屏短剧素材转横屏时优先用「保高调宽」（补两侧环境）；横屏转竖屏优先「保宽调高」（补上下空间）

## 关键参数 / 模板 / 清单

```
画幅转换决策树：
1. 原始画幅哪部分信息最有价值？
   → 上下有价值 → 方法①保高调宽（裁左右）
   → 左右有价值 → 方法②保宽调高（裁上下）
   → 中心有价值 → 方法③宽高折中
2. 裁剪是否平均？
   → 叙事焦点偏左 → 多裁右边
   → 叙事焦点偏右 → 多裁左边
   → 中心对称 → 平均裁
```

```
AI 生成留余量提示词：
[场景], aspect ratio 2.35:1, key subject centered,
ample negative space on all sides for safe cropping,
no critical elements near frame edges
```

## 备注
- 1.85 与 2.35 差异细微，大多数情况只需微调；但从宽银幕转竖屏（9:16）则必须彻底重新构图
- 裁剪不是「技术操作」而是「叙事决策」——每一刀都要回答「切掉的信息对故事有用吗」
- 与 184 配合阅读：184 帮你选画幅，本条帮你在画幅间迁移
