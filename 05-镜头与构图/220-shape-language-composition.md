# 形状语言——几何形状作为构图骨架

## 核心要点
- **形状语言 = 构图的底层结构**：在画任何细节之前，先用几何形状确定整张画面的骨架
- 形状定义动势与叙事基调：倒三角=主次分明有层次，垂直线=稳定固执，之字形=坚实紧凑的流动感，弧形/椭圆=压迫感或辐射感
- **整体形状语言先于细节设计**，必须在缩略图阶段确定
- 画面内可同时存在多种形状形成对比（胖瘦、高矮、圆润vs棱角），对比产生张力
- 与 218（拐点）配合：形状路径上的拐点创造戏剧，打破节奏

## 详细内容

### 1. 先定形状，再画细节
在《码头的一天》案例中，作者在绘制草图之前先深入理解镜头元素（角色、建筑、环境），因为**整体形状与体积感直接影响观众对造型轮廓的快速识别**，以及对故事中人物、地点的感知。

随手画的缩略图提炼出要素的整体形状语言，再通过元素在画面中的对比与构图创建浅显易懂的平衡、失衡与张力感。这个阶段不碰细节。

### 2. 常见形状及其叙事含义

| 形状 | 叙事含义 | 适用场景 |
|---|---|---|
| **倒三角形** | 主次分明、有视觉层次（最左角色最大最醒目） | 角色群像、需要明确主角的场面 |
| **垂直线** | 稳定、固执、节奏感 | 站立对峙、仪式感、权威感 |
| **之字形（Z 形）** | 坚实紧凑的视觉流动感，方向多变 | 混乱场景、追逐、丛林穿行 |
| **弧形 / 椭圆形** | 压迫感或辐射感（椭圆居高临下压迫下方人群） | 权力压制、被包围、辐射控制 |
| **A 形** | 强烈戏剧张力，先向上再突然下降 | 情绪爆发点、力量对决 |
| **倒 9 形** | 流动性与连贯感，断点处运动方向突变 | 连贯动作、转折点 |

### 3. 形状案例解读
- **倒三角**（图例 2.1）：女战士构图来自倒三角形，最左角色离镜头最近、个子最高最醒目，所有元素主次分明且有层次。
- **垂直线**（图例 2.2）：名人与两个保镖呈三条垂直线，传递稳定、固执的节奏感。
- **之字形**（图例 2.3）：混乱画面中之字形构图提供坚实紧凑的流动感。
- **椭圆辐射**（图例 2.13）：楼顶枪手的椭圆形对下行人群产生压迫感，赋予牛仔掌控全局的辐射感，在他与人群间形成缓冲地带。
- **A 形动势**（图例 2.14）：能量从前景岩石底部窜升至牛仔头部，再沿人群直线骤然下降，最锐角 A 形传递强烈戏剧张力。
- **倒 9 形**（图例 4.13）：倒 9 的动势给镜头带来流动性，足球位置正是倒 9 的断点，守门员动势在此被足球飞来的动势替代。

### 4. 形状对比产生张力
同一个画面内出现各种形状并形成对比——或胖或瘦、或高或矮、或圆润无比或棱角分明——可能产生完全不同的结果。纤瘦风格化的女人与粗壮的船长并置，本身就是性格冲突的视觉预告。

### 5. 与拐点（218）的配合
形状是骨架，拐点是戏剧。先确定一条形状路径（之字、弧形、9 形），再在路径的关键拐点上制造方向突变——能量流动从一种形式彻底变为另一种形式。「变化意味着戏剧张力」。创造某种节奏，然后在某个时刻通过拐点打破它，戏剧性由此而来。

## 对 AI 短剧的落地要点

- **提示词里写形状骨架**：在描述细节之前先用形状词锁结构，如 `inverted triangle composition, three figures descending in size left to right`
- **用形状词替代散点描述**：不说「三个人站着」，而说「three vertical lines composition, rigid and stable」
- **拐点提示**：在连贯动作镜头加 `Z-shaped motion path, sharp turn at [position], dramatic inflection point`
- **缩略图先行**：先用低分辨率 / 草图模型出 3–5 张形状骨架变体，选定后再上细节模型精修
- **群戏先排形状**：多角色场景先决定整体是什么形状（三角/椭圆/之字），再分配角色位置，避免 AI 乱排

## 关键参数 / 模板 / 清单

```
形状语言速查：
倒三角 → 主次分明、有层次
垂直线 → 稳定、固执、仪式
之字形 → 混乱中坚实的流动感
弧形/椭圆 → 压迫、辐射、被包围
A 形 → 戏剧张力、先升后降
倒 9 → 连贯流动、方向突变
```

```
提示词模板：
[场景描述], [形状] composition, strong [形状] structure,
inflection point at [位置], dramatic tension, sketch-like,
minimal details --ar [画幅]
```

```
形状自检：
[ ] 缩略图阶段是否已确定整体形状？
[ ] 形状是否匹配叙事基调？
[ ] 画面内是否有形状对比（胖瘦/圆润棱角）？
[ ] 拐点是否落在形状路径的关键位置？
```

## 备注
- 形状语言必须在**缩略图阶段**确定，进入精修后再改骨架成本极高
- 形状不是越多越好：一张画面通常有一个主形状 + 一两个次级形状即可
- 与 219（剪影导览法）互补：剪影看轮廓关系，形状语言看底层几何骨架，两者配合使用
