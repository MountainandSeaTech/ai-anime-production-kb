# 镜头运动与张力

## 核心要点
- 镜头运动方向编码张力：**推进=加压（蓄势），拉远=泄压（释放）**
- 跟随/横移维持张力但不加压——用于持续紧张段
- **爆发段黄金法则：固定机位 + 主体动**——镜头不动，动作爆发力最强
- 镜头运动越复杂，AI 越易畸变；张力段优先简单运动

## 运动方向与张力

| 镜头运动 | 张力效果 | 适用阶段 | 备注 |
|---|---|---|---|
| 推进（dolly in / push in） | 加压蓄势 | build-up | 慢推进=决意/压抑；快推=惊愕 |
| 拉远（dolly out / pull back） | 泄压揭示 | release / 转场 | 揭示环境或孤立 |
| 横摇（pan） | 维持/扫视 | 过渡、跟随 | 主体别动，否则拖影 |
| 竖摇（tilt） | 揭示/压迫 | 登场、仰视 | tilt up 登场，tilt down 压 |
| 横移（tracking） | 跟随维持 | 追逐侧面、打戏侧跟 | 最稳的运动镜头 |
| 跟随（follow） | 维持临场 | 背后跟随 | 稳定性好 |
| 升降（crane） | 揭示/俯仰转换 | 场景揭示 | 适合开场/收束 |
| 固定（static） | 最强爆发 | peak | 主体动镜头不动=爆发力顶 |
| 手持（handheld） | 紧张临场 | 乱战 | 动漫风格慎用，易晕 |

## 推进=加压的原理
- 推进=主体在画面里变大=注意力被强制聚焦=视觉上的"逼近"
- 等效于 013 时间轴的加压：推进越慢，蓄势越久，峰值越爽
- 配合景别收紧（近→特写）双重加压

## 爆发段为什么固定机位最强
- 镜头一动，观众注意力被镜头分走，主体爆发力被稀释
- 固定机位+主体动 = 所有视觉变化来自主体 = 爆发感最大化
- 这就是居合戏、一击戏镜头不动的根本原因

## 经典运动序列

### 居合斩杀
```
固定近景对峙（2s，static）→ 慢推进特写刀柄（1s，slow dolly in）→ 固定大特写出刀（0.3s，static）→ 慢拉远全景定格（1.5s，slow dolly out）
```
固定→慢推（蓄）→固定（峰）→慢拉（释）。运动只在蓄和释，峰不动。

### 追逐
```
横移跟随逃者（1s，tracking）→ 横移跟随追兵（1s，tracking，切镜）→ 固定特写回头（0.5s，static）→ 横移跟随距离更近（1s，tracking）
```
横移维持紧张，固定特写做峰值。

### 揭示威胁
```
慢推进主角近景（2s，slow dolly in，蓄）→ 拉远揭示背后有敌人（1s，dolly out，泄+揭示）
```
推进蓄到顶，一拉揭示反差=惊愕张力。

## AI 生成的运动稳定性排序（从稳到险）
1. static（最稳）
2. slow dolly in / out
3. pan / tilt（中等）
4. tracking
5. crane
6. handheld（最险，易崩）
> 张力段优先 1-2，复杂运动留给非张力段。

## 速度修饰与节奏
- `slow dolly in` = 慢推，蓄势/压抑（2-4s）
- `fast push in` = 快推，惊愕/转场（0.5s）
- `gradual` = 渐进，决意时刻
- `sudden` = 骤变，惊吓点

## 备注
- 本条是 003 镜头运动词库的"张力向"应用版
- 镜头运动在 AI 视频里是畸变高发区，复杂运动（推进+横摇）极易崩
- 原则：能用景别变化替代的，就不用镜头运动；能固定的，就不动
