# AI 导演风格提示词手册 · 第一期（下）：导演 06–10

## 核心要点

- 接上篇（404）：六维 = 焦段、构图、光线、色彩、运动、节奏；每位导演一段整段可复制提示词。
- 用法三步：按情绪选导演 → 整段贴提示词 → 末尾叠加画面主体（谁、在哪、做什么）。提示词管「怎么拍」，你的描述管「拍什么」。

## 详细内容

### 06 贾樟柯（Jia Zhangke）

- **关键词**：粗粝纪实 / 手持 DV 感 / 灰调 / 时代噪音
- **一句话**：县城、尘土与时代噪音

| 维度 | 参数 |
|---|---|
| 焦段 / 画幅 | 手持随机，构图不完美；DV 与数字感 |
| 构图 | 随意、偶尔切掉半个头、画框边缘不讲究 |
| 光线 | 现场光、荧光灯、尘土中的散射 |
| 色彩 | 低饱和灰绿黄，脏、旧、发闷 |
| 运动 | 随机跟随、晃动、突然停住 |
| 节奏 | 生活流，混乱中偶有静止 |

风格提示词（整段复制）：

```
手持 DV 粗粝纪实感，构图随意不讲究、偶尔切掉半个头，现场光与荧光灯、尘土中的散射，低饱和灰绿黄、脏旧发闷，随机跟随晃动后突然停住，生活流节奏，时代噪音感
```

### 07 克里斯托弗·诺兰（Christopher Nolan）

- **关键词**：IMAX 大画幅 / 冷灰蓝 / 实景实拍 / 精密结构
- **一句话**：用理性搭建的时间迷宫

| 维度 | 参数 |
|---|---|
| 焦段 / 画幅 | IMAX 65mm，广角全景与超大特写硬切 |
| 构图 | 稳定、水平、信息密度高，实景为主 |
| 光线 | 自然光与实用光，低对比灰调，不做美化 |
| 色彩 | 冷灰、钢蓝、去饱和，肤色偏冷 |
| 运动 | 稳定器、航拍、机械般精准的推进 |
| 节奏 | 沉稳、理性、结构感强 |

风格提示词（整段复制）：

```
IMAX 大画幅，广角全景与超大特写硬切，稳定水平的高信息密度构图，自然光与实用光、低对比灰调不做美化，冷灰钢蓝去饱和，稳定器与机械般精准的推进，沉稳理性结构感强
```

### 08 韦斯·安德森（Wes Anderson）

- **关键词**：绝对对称 / 粉彩 / 居中构图 / 平面化横移
- **一句话**：装进糖果盒的强迫症

| 维度 | 参数 |
|---|---|
| 焦段 / 画幅 | 中焦正对，严格居中；1.85:1 或 2.35:1 |
| 构图 | 绝对左右对称，人物永远在正中，平面化 |
| 光线 | 柔和均匀，几乎没有硬阴影 |
| 色彩 | 粉红、芥末黄、薄荷绿、天蓝；高明度低对比 |
| 运动 | 机械横移、90 度转场、俯拍平铺（flat lay） |
| 节奏 | 轻快、俏皮、卡片式 |

风格提示词（整段复制）：

```
绝对左右对称、人物严格居中，中焦正对，平面化构图，柔和均匀光线几乎无硬阴影，粉红／芥末黄／薄荷绿／天蓝的高明度低对比粉彩配色，机械横移与俯拍平铺，轻快俏皮卡片式节奏
```

### 09 昆汀·塔伦蒂诺（Quentin Tarantino）

- **关键词**：低机位广角 / 复古饱和 / 章回结构 / 暴力美学
- **一句话**：话痨、爽感与暴力芭蕾

| 维度 | 参数 |
|---|---|
| 焦段 / 画幅 | 超低机位仰拍广角；对话用长焦 |
| 构图 | 极端视角（车内、后备箱、地板向上） |
| 光线 | 硬光、70 年代胶片感、暖 |
| 色彩 | 暖黄、正红、高饱和复古 |
| 运动 | 突然推镜（crash zoom）、快速摇镜 |
| 节奏 | 话痨式对白 + 瞬间爆发 |

风格提示词（整段复制）：

```
超低机位仰拍广角、对话用长焦压缩，极端视角构图（车内、后备箱、地板向上），硬光、70 年代胶片质感，暖黄正红高饱和复古色，突然推镜与快速摇镜，话痨式节奏里瞬间爆发
```

### 10 大卫·芬奇（David Fincher）

- **关键词**：低照度 / 青绿阴影 / 精密运镜 / 冷峻疏离
- **一句话**：毫米级控制的冷峻黑暗

| 维度 | 参数 |
|---|---|
| 焦段 / 画幅 | 中焦为主，运镜精确到毫米 |
| 构图 | 稳定、几何、监控视角感 |
| 光线 | 低照度、单一光源、暗部极大 |
| 色彩 | 青绿阴影 + 微暖肤色，整体去饱和 |
| 运动 | 缓慢、精确、机械；几乎无手持 |
| 节奏 | 冷静、压迫、克制 |

风格提示词（整段复制）：

```
中焦为主，稳定几何的监控视角构图，低照度单一光源、暗部极大，青绿阴影配微暖肤色、整体去饱和，缓慢精确到毫米的机械运镜、几乎无手持，冷峻克制压迫
```

## AI 漫剧落地提示

- **贾樟柯**：适合现实题材、年代戏、底层/小镇叙事、纪录片式过场；"构图不讲究、切半个头"这类反精致提示词反而能降低 AI 的塑料感，做出伪纪录片质感的回忆段或新闻段。
- **诺兰**：适合科幻/悬疑大场面、多线叙事的高潮段落、需要"史诗感+信息量"的镜头；广角全景与超大特写硬切的节奏可直接当分镜模板用，冷灰蓝去饱和调色对科幻番统一影调非常省事。
- **韦斯·安德森**：适合喜剧、萌系/日常番、片头片尾卡片、角色介绍定格；绝对对称+粉彩是 AI 最容易稳定复现的风格之一，适合做整集的视觉锤（如每集开场俯拍平铺道具）。
- **昆汀**：适合动作爽剧、黑帮/西部桥段、话痨式对峙后的瞬间爆发；超低机位仰拍广角是立"狠角色"登场的一招鲜，crash zoom 可作为图生视频的运镜指令直接写入。
- **芬奇**：适合悬疑、犯罪、心理惊悚夜戏；"监控视角构图+低照度单一光源"是压迫感的公式化写法，几乎无手持的机械运镜对图生视频极友好（运动小、崩坏少），适合整季保持冷峻基调的悬疑番。
- **六维参数化 vs 只写"电影感"**：只写"电影感"时模型每次自由发挥，焦段色彩随机漂移、镜头间风格断裂；六维参数化后每一维都有确定值，同一导演段落可在整集复用，保证影调统一——再叠加主体描述（谁、在哪、做什么）即可实现"怎么拍"与"拍什么"的分离管理（提示词工程思路参见 396）。
