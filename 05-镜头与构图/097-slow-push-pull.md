# 慢推与缓拉（Slow Push In / Pull Out）

## 核心要点
- 慢推=**逼近**=压迫递增=最简最强张力运镜
- 缓拉=**抽离**=孤独/余韵/释然
- 推=拉入；拉=送走——一进一退=情绪两端
- 《教父》餐厅慢推 Michael=决定时刻=经典

## 张力来源

### 慢推（Push In）
- 摄影机缓向主体推近=逼近=压迫
- 主体不变大但距离缩=观众"被拉向"主体=不可逃
- 缓慢=递增=越推越紧
- 信号："这很重要"——告诉观众"注意"

#### 慢推的情绪
| 场景 | 慢推效果 |
|---|---|
| 决定时刻 | 逼近内心=抉择压迫（《教父》） |
| 恐惧发现 | 逼近真相=压迫递增 |
| 对峙 | 逼近脸=压迫=冲突前 |
| 觉醒/顿悟 | 逼近意识=内心放大 |

### 缓拉（Pull Out）
- 摄影机缓向远处退=抽离=主体变小
- 退=送走=孤独/余韵/释然
- 主体变小=与世界抽离=孤绝
- 信号："结束/释然/远去"

#### 缓拉的情绪
| 场景 | 缓拉效果 |
|---|---|
| 结尾余韵 | 主体变小=抽离=回甘（083） |
| 孤独 | 退远=孤绝=被世界抛弃 |
| 释放 | 退=释放=紧张后松 |
| 揭示 | 拉开=揭示周围环境=context |

## 慢推 vs 缓拉的节奏
```
慢推：—→—→—→—→■（逼近峰，递增压迫）
缓拉：■—→—←—←—←（抽离峰后，递减余韵）
```
- 慢推配 build 段（014）=逼近=压迫累积
- 缓拉配 release 段=抽离=余韵

## 大师案例
| 影片 | 场景 | 运镜 |
|---|---|---|
| 《教父》 | 餐厅 Michael | 慢推=决定时刻 |
| 《指环王》 | Frodo 多次 | 慢推=内心/抉择 |
| 《迷失东京》 | 多次 | 缓拉=孤独/抽离 |
| 任何结尾 | — | 缓拉=余韵回甘 |

## Z 轴运镜
- 慢推/缓拉都是 Z 轴（纵深方向）运镜
- Z 轴运镜=逼近/退远=最直接的距离张力
- 比横移（X轴）和升降（Y轴）更直接的情绪力

## AI 提示词
- 慢推：`slow push in, camera moving toward subject, building tension, approaching close-up, cinematic, 24fps`
- 缓拉：`slow pull out, camera retreating, character becoming small, isolation, melancholy ending, cinematic`
- Z 轴逼近：`z-axis dolly in, subject isolation from world, intensify, shallow depth`

## 常见坑
- **推太快**：快推=惊吓≠压迫；慢=递增才压迫
- **无目的推**：为推而推=空；要服务"这很重要"的信号
- **推拉混用**：一镜内又推又拉=混乱；一镜一方向
- **AI 漂移**：长推超5s AI 漂→拆短拼接伪一镜

## 进阶
- 慢推+定主体=逼近压迫顶配（主体不动镜头逼近）
- 慢推+对称（092）=Kubrick 走廊逼近顶配
- 缓拉+空镜（083）=结尾余韵顶配
- 推到极近+硬切爆点=逼近后爆发=极致

- 慢推信号"这很重要"，缓拉信号"结束/释然"
- 《教父》慢推 Michael=经典
- Z 轴运镜=最直接的距离张力
