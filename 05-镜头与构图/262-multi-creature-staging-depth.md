# 多动物同框层次

## 核心要点
- **三级细节分配**：主角动物给完整动作链＋微表情级细节；中景动物保留步态、砍微表情；远景动物剪影化、只留步态循环
- **全精细＝混乱**：所有动物同等精细，观众注意力被撕碎——层次是为了"让观众知道看哪只"
- **背景动物不能死**：降级≠静止，背景动物保留低频步态/移动剪影——死了的背景比降级更糟（→250 静止即死物）

## 详细内容
- **主角动物判定**：当前镜头里"承担剧情功能的动物"才是主角（要传递信息/完成动作的那只），其余一律降级
- **背景动物动作库**：吃草、慢走、卧倒、互相蹭、甩尾——低幅度、可循环、无剧情含义的通用动作
- **焦点配合**：浅景深把背景动物虚化，是物理层面的"降级"，与动作降级叠加使用（→019 景深）

## 关键参数 / 模板 / 清单
```
分级清单：
  主角动物：微动作全保留（呼吸/耳/尾/眼神）＋剧情动作链
  中景动物：保留步态与大体动作，砍耳抖/眨眼等微表情
  远景动物：剪影式步态循环，无个体特征，只保证"在动"

分镜写法示例：
  「近景闪电貂在钟灵怀中探头（主角细节全给）；中景两名弟子牵马
   立于阶下，马只是偶尔刨蹄甩尾（步态级）；远景坡下羊群如
   灰白斑点缓缓移动（剪影级）。」
英文关键词：
  foreground creature fully detailed, midground animals with basic gaits,
  background herd as moving silhouettes
```
