# 景深与焦点：隔离与揭示

## 核心要点
- **景深 = 注意力的强制分配**：浅景深只让一处清晰，其余模糊=注意力钉死=加压
- **焦点转移（rack focus）= 信息差视觉化**：前清后糊→后清前糊，揭示隐藏的威胁/真相
- 浅景深 + 特写 = 最强注意力压缩（居合刀柄特写）
- 深景深 + 全景 = 环境压迫（全景清晰=威胁无处不在）

## 景深与张力

| 景深 | 画面特征 | 张力效果 | 适用 |
|---|---|---|---|
| 浅景深（strong bokeh） | 主体清晰，背景糊 | 隔离加压，钉死注意力 | 特写蓄势、情绪峰值 |
| 中景深 | 主体+近景清晰 | 平衡 | 对峙近景 |
| 深景深（deep focus） | 全程清晰 | 环境威胁/孤立 | 全景压迫、追逃纵深 |

### 浅景深为什么加压
- 背景糊掉=排除干扰=注意力被强制聚焦到一点
- 等效于景别收紧，但是用"清晰度"而非"取景范围"压缩注意力
- 居合刀柄大特写+浅景深 = 注意力钉在"即将出鞘"的瞬间

### 深景深为什么也压迫
- 全景都清晰=威胁可能藏在任何角落=环境本身是压力源
- 追逃纵深长廊深景深=看得见追兵但够不着=距离焦虑
- 与浅景深相反，但同属空间轴加压

## 焦点转移（Rack Focus）：信息差神器
- 前清后糊→后清前糊，一次镜头里揭示"背景里有人/有刀/有危险"
- 视觉化 013 心理轴的"信息差"：观众和主角一起发现威胁
- 经典用法：主角特写清晰→焦点转到背后模糊的敌人→敌人变清晰=惊觉

### 焦点转移的张力序列
```
主角近景清晰，背景糊（1s，蓄：不知情）→ 焦点转背景，敌人变清晰（0.5s，峰：发现）→ 焦点回主角，主角表情变（0.5s，释：反应）
```
一条镜头完成"发现"张力曲线，不用切镜。

## 经典景深组合

### 居合刀柄蓄势
```
大特写刀柄，浅景深，背景全糊（1.5s）→ 焦点不变，出刀瞬间（0.3s）→ 拉远转深景深全景定格（1s）
```
浅→深，从压缩到揭示。

### 背后威胁揭示
```
主角近景浅景深清晰，背后糊（1s）→ rack focus 到背后敌人变清晰（0.5s）→ 焦点回主角惊恐表情（0.5s）
```

### 追逃纵深
```
全景深景深长廊，逃者前景清晰+追兵远景清晰（1.5s，距离可见=焦虑）→ 特写逃者回头浅景深（0.5s）→ 全景深景深距离更近（1s）
```

## AI 提示词对照
- 浅景深：`shallow depth of field, strong bokeh, blurred background` / `f/1.4 bokeh`
- 深景深：`deep focus, everything in focus, f/11`
- 焦点转移：rack focus 在 AI 生成里较难单镜完成，通常用两镜剪辑模拟（前镜背景糊→后镜背景清晰）

## 备注
- rack focus 在 AI 视频里单镜实现不稳定，建议用剪辑模拟（切到背景清晰镜）
- 浅景深是 AI 生成的强项，bokeh 词很稳，优先用
- 景深+景别组合：浅景深+大特写=注意力双压缩，最强蓄势
- 深景深+全景+低机位=环境压迫三件套
