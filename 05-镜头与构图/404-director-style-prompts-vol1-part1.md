# AI 导演风格提示词手册 · 第一期（上）：六维方法论 + 导演 01–05

## 核心要点

- 想让 AI 生成「有电影感」的画面，光写「电影感」三个字没用——真正起作用的是**焦段、构图、光线、色彩、运动、节奏**这六个维度的具体参数。
- 每位导演压成一段可直接复制的提示词，配六维拆解表：看表理解他为什么这么拍，抄段落直接出图。
- 用法三步：① 先按情绪选导演（要暧昧找王家卫，要仪式感找张艺谋，要压迫感找芬奇）；② 把「风格提示词」整段贴进文生图或图生视频工具；③ 在末尾叠加你的画面主体——谁、在哪、做什么。
- 记住一句话：**提示词管「怎么拍」，你的描述管「拍什么」**。

## 详细内容

### 01 王家卫（Wong Kar-wai）

- **关键词**：霓虹湿街 / 抽帧拖影 / 浓绿洋红 / 贴身窥视
- **一句话**：暧昧、潮湿、欲言又止的都市情绪

| 维度 | 参数 |
|---|---|
| 焦段 / 画幅 | 18mm 超广角贴身手持；2.35:1 宽银幕 |
| 构图 | 前景遮挡（门框、雨伞、玻璃、烟雾），人物偏居画面一隅 |
| 光线 | 实用光为主（霓虹、台灯、车厢顶灯），大光比，暗部不死黑 |
| 色彩 | 青绿（teal）阴影 + 洋红 / 橙红高光，整体偏暖绿 |
| 运动 | 手持轻微漂移 + 抽帧拖影（step-printing），慢门 |
| 节奏 | 跳切、碎片化、内心独白式 |

风格提示词（整段复制）：

```
2.35:1 宽银幕，18mm 超广角贴身手持，前景遮挡式构图（门框、雨伞、玻璃、烟雾），实用光源大光比，青绿阴影配洋红高光强烈对冲，慢门抽帧拖影，粗颗粒胶片质感，暗部不死黑，情绪暧昧而疏离
```

### 02 张艺谋（Zhang Yimou）

- **关键词**：大色块 / 高饱和 / 仪式感对称 / 群体阵列
- **一句话**：把色彩当主角的仪式感美学

| 维度 | 参数 |
|---|---|
| 焦段 / 画幅 | 中焦到广角；大量正对轴线的大全景 |
| 构图 | 严格中轴对称，人物居中，背景阵列化重复（人海、方阵、灯笼墙） |
| 光线 | 平光或顶光为主，色彩靠美术而非布光 |
| 色彩 | 单一主色爆满画面（正红、明黄、青蓝），大面积纯色块 |
| 运动 | 缓慢推进、仪式化横移，节奏庄重 |
| 节奏 | 古典、稳定、一板一眼 |

风格提示词（整段复制）：

```
大面积单一主色块铺满画面（正红／明黄／青蓝），严格中轴对称构图，背景阵列化重复（人海、方阵、灯笼墙），平光或顶光、色彩靠美术不靠布光，高饱和，缓慢推进或仪式化横移，古典庄重一板一眼的节奏
```

### 03 侯孝贤（Hou Hsiao-hsien）

- **关键词**：固定长镜头 / 远观 / 自然光 / 生活流
- **一句话**：退到远处，看生活的呼吸

| 维度 | 参数 |
|---|---|
| 焦段 / 画幅 | 中长焦固定机位（50–85mm）；4:3 或 1.85:1 |
| 构图 | 远景、中远景，人物进出画框，常留大片空景 |
| 光线 | 纯自然光、窗光、灯泡，不做任何修饰 |
| 色彩 | 低饱和、褪色感、绿灰调 |
| 运动 | 几乎不动；偶尔极缓慢横摇或微微呼吸 |
| 节奏 | 极慢，一个镜头撑很久 |

风格提示词（整段复制）：

```
50–85mm 中长焦固定机位，远景与中远景，人物进出画框、常留大片空景，纯自然光与窗光不做任何修饰，低饱和褪色感绿灰调，镜头几乎不动，一个镜头撑很久，生活流式留白
```

### 04 姜文（Jiang Wen）

- **关键词**：高反差黑白 / 快速手持 / 荒诞浪漫 / 强节奏剪辑
- **一句话**：烈日下的荷尔蒙与荒诞

| 维度 | 参数 |
|---|---|
| 焦段 / 画幅 | 广角略畸变（25–35mm）快速推拉 |
| 构图 | 不稳定、倾斜、突然的极近特写 |
| 光线 | 硬光、强投影，黑白时期对比拉满 |
| 色彩 | 高反差黑白；或浓烈的暖金黄（阳光灿烂感） |
| 运动 | 手持快速移动、突然甩镜、跳切 |
| 节奏 | 极快，呼吸感强 |

风格提示词（整段复制）：

```
25–35mm 广角略畸变，不稳定倾斜构图、突然切入的极近特写，硬光与强投影，高反差黑白或浓烈暖金黄，手持快速推拉与甩镜，跳切，极快的呼吸感剪辑，荒诞浪漫
```

### 05 杜琪峰（Johnnie To）

- **关键词**：冷蓝夜色 / 站位调度 / 静待爆发 / 舞台式打光
- **一句话**：静止里蓄着枪火

| 维度 | 参数 |
|---|---|
| 焦段 / 画幅 | 中远景为主，偶尔长焦压缩群像 |
| 构图 | 人物站位像舞台调度，几何关系极其精确 |
| 光线 | 顶光 / 侧光切割，暗部占比大，路灯做唯一暖源 |
| 色彩 | 冷蓝、青灰为主，点缀一点暖黄路灯 |
| 运动 | 静止为主；爆发时切极快 |
| 节奏 | 极静 → 极动，反差巨大 |

风格提示词（整段复制）：

```
中远景冷蓝夜色，舞台式人物站位调度、几何关系极其精确，顶光侧光切割画面、暗部占比大，路灯作为唯一暖源，长时间静止后接极快爆发式剪辑，静与动反差强烈
```

## AI 漫剧落地提示

- **王家卫**：适合夜戏、都市情感文戏、暧昧/错过/独白桥段——男女主擦肩而过、雨夜便利店、回忆闪回。漫剧里"抽帧拖影"可用动态模糊+降帧后期近似，霓虹湿街是 AI 出图的高稳定区。
- **张艺谋**：适合大典/仪式/战争阵列、群像登场、势力展示等大场面；单色块爆满画面对 AI 极其友好（提示词短、翻车率低），是做"名场面封面图"的首选。
- **侯孝贤**：适合慢生活流、日常治愈番、乡土/年代文戏；固定机位+空景对图生视频最稳（几乎无运动=几乎无崩坏），适合预算低、求稳的过渡场次。
- **姜文**：适合高能量对白戏、荒诞喜剧、男性荷尔蒙桥段（酒桌、烈日操场、对峙升级）；高反差黑白可直接作为单集风格化标签，"突然极近特写"是现成的包袱分镜。
- **杜琪峰**：适合悬疑、黑帮、对峙戏——"极静→极动"的节奏模型可直接套用到漫剧单集结构：长静止铺垫 + 一卡爆发，站位调度提示词对多人群像构图防崩尤其有用。
- **六维参数化 vs 只写"电影感"**：只写"电影感"时模型自由发挥，色彩焦段随机漂移、多镜头之间风格不连贯；落到六维参数后，每一维都有确定取值，同一位导演的段落可在整集内复用，保证镜头间风格统一——这正是漫剧分镜连贯性（参见 343/345）在提示词层面的实现方式。
