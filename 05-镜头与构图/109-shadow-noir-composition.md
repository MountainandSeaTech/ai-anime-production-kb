# 阴影构图与黑色电影布光（Shadow / Noir Lighting）

## 核心要点
- **阴影比光更重要**——黑色电影（Noir）哲学
- 低调布光（low-key）+高对比=半明半暗=道德灰区/未明/压迫
- 明暗对照法（chiaroscuro）=强光强影=戏剧性
- 《猎人之夜》只打眼睛=表现主义阴影顶配

## 张力来源

### 1. 半明半暗=未明
- 半张脸亮半张脸暗=看不全=未明=不安
- 比"全亮"更诡异——藏了一半=想象填充
- 悬疑/反派用半明半暗=道德灰区

### 2. 阴影=藏
- 阴影藏东西=未知=恐惧（间，033）
- 角色从阴影走出=未知变已知=张力释放/递增
- 阴影是"会说话的暗"（见 094 负空间）

### 3. 高对比=戏剧
- 强光强影=非日常=戏剧化=张力
- 平光=平=无张力；高对比=戏=张力
- 低调布光=阴影为主=压迫

### 4. 阴影=图形
- 阴影本身是构图元素=图形=视觉力
- 百叶窗影/栏栅影=困局图形
- 角色站在阴影图案中=被图案困=隐喻

## 低调布光 vs 高调布光
| 维度 | 低调（Noir） | 高调（喜剧/日常） |
|---|---|---|
| 光比 | 高（8:1+） | 低（2:1） |
| 阴影 | 深暗为主 | 浅/无 |
| 情绪 | 压迫/悬疑/恐怖 | 轻松/明亮 |
| 用途 | 黑色电影/恐怖/悲剧 | 喜剧/日常/广告 |

## 阴影的类型
| 阴影 | 隐喻 |
|---|---|
| 半脸阴影 | 道德灰区/双面/未明 |
| 百叶窗影 | 困局/囚笼/被分割 |
| 栏栅影 | 囚禁/被困 |
| 角色投射影 | 双重/暗面/未明 |
| 环境大暗 | 未知/恐惧/吞噬 |
| 只打眼影 | 表现主义/诡异顶配 |

## 大师案例
| 影片 | 场景 | 阴影 |
|---|---|---|
| 《猎人之夜》 | 牧师 | 只打眼=表现主义顶配 |
| 《马耳他之鹰》 | 多场 | 低调半脸=Noir 标志 |
| 《第三人》 | 下水道 | 大暗影=吞噬 |
| 《惊魂记》 | 多场 | 半脸阴影=不安 |

## 《猎人之夜》只打眼（顶配）
- 摄影师 Stanley Cortez 用黑绒遮光板精确控光
- 只打亮 Robert Mitchum 的眼睛=其他全黑
- 表现主义=storybook 噩梦美学
- 用物理剪影板造锐利投影（非真影）

## 与张力的配合
| 场景 | 阴影效果 |
|---|---|
| 反派（070） | 半脸阴影=双面/道德灰区 |
| 悬疑 | 半明半暗=未明=不安 |
| 恐怖（间） | 大暗影=未知=恐惧 |
| 困局 | 百叶窗/栏栅影=视觉囚笼 |

## AI 提示词
- 半脸阴影：`chiaroscuro lighting, half face in shadow, half lit, film noir, high contrast, dramatic`
- 只打眼：`only eyes lit, rest in darkness, expressionist, nightmare, extreme low-key`
- 百叶窗影：`venetian blind shadows across face, barred light, trapped, noir, cinematic`
- 环境大暗：`deep shadows, vast darkness, figure emerging from shadow, horror, unknown`

## 常见坑
- **平光**：无阴影=平=无张力；必加阴影
- **阴影太均匀**：均匀暗=糊；要有光暗对比
- **阴影无隐喻**：为暗而暗=空；阴影要服务叙事
- **AI 默认平光**：不写 low-key→AI 给平光；必强调

## 进阶
