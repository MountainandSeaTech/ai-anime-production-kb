# 屏幕震动与冲击帧的叠加公式

## 核心要点

- 震动是打击感的**空间维度**——冲击帧管画面、顿帧管时间、震动管空间，三层叠加才立体
- 现代准则：**顿帧期间角色冻结但镜头继续微震**——画面不能"死"

## 详细内容

### 震动三参数模型
| 参数 | 定义 | 量级映射 |
|---|---|---|
| 幅度 | 画面偏移像素数 | 轻击2-5px／重击10-20px／爆炸30px+ |
| 频率 | 每秒抖动次数 | 重击低频（3-5次/s，有"钝"感）／轻击高频（8-12次/s，有"脆"感） |
| 衰减 | 震动消退曲线 | 指数衰减最自然；线性衰减有机械感 |

### 与冲击帧/顿帧的时序
```
接触帧C：冲击帧（画面断裂）
C起：震动开始（幅度峰值）
C+2起：顿帧冻结角色——但镜头震动继续（关键！）
顿帧结束：震动随受力反馈衰减至零
```
**铁律：镜头永远不冻**——冻结期间镜头静止＝画面死亡；镜头低频微震＝"余震未消"

### 方向性震动
- 震动主轴应与冲击方向**一致**：水平拳击→水平主震＋垂直微噪
- 全向随机震动只用于爆炸/地震——打击用随机震动＝摄像机没安装稳，不是打击感

### AI生成与后期
- AI视频模型自带"手持晃动"倾向，需负向压（`camera shake, handheld jitter`）保持干净底片
- 打击震动一律后期加（剪辑软件的shake预设/表达式），可控可撤销

## 关键参数 / 模板 / 清单

**叠加预算**：同一次命中＝冲击帧（1-2帧）＋顿帧（2-10帧）＋震动（幅度按量级）——三层全上为重击，轻击只用震动一层即可
