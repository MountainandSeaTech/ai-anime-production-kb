# 长镜头的张力累积

## 核心要点
- 长镜头（long take）的张力来源：**不剪切=观众无处逃逸**，注意力被持续锁定
- 与快切相反，长镜头靠"持续"累积，适合逼近、潜伏威胁、长对峙
- 关键：长镜头内部必须有**起伏**（景别变/机位动/主体动），否则=无聊长拖
- 动漫短剧里长镜头=单镜 3 秒以上不切，6 秒以上要慎用

## 长镜头为什么能累积张力

### 1. 无逃逸点
- 快切每次切镜都给观众"重置注意力"的机会
- 长镜头不切=注意力被迫持续锁定主体=揪心无法打断
- 等效于 013 时间轴持续加压

### 2. 实时感=真实威胁
- 长镜头模拟"真实时间"，观众觉得"正在发生"=临场紧张
- 适合追逃、逼近、危机倒计时

### 3. 一气呵成=宿命感
- 不切的连贯性暗示"不可逆转"=决别、宿命对决的最佳载体

## 长镜头必须有内部起伏
长镜头≠固定不动一镜到底。内部至少有一种"动"：

| 内部变化手段 | 效果 | 举例 |
|---|---|---|
| 景别收紧（推近） | 蓄势加压 | 慢推从中景到大特写 |
| 机位运动 | 跟随/揭示 | 横移跟随再揭示威胁 |
| 主体运动 | 动作进展 | 角色逼近/退却 |
| 焦点转移 | 信息揭示 | rack focus 揭示背后敌人 |
| 光照变化 | 气氛转折 | 阴影逼近/光熄灭 |

> 完全静态的长镜头（机位主体都不动）超 3 秒就拖，必须有上面至少一种变化。

## 长镜头的张力曲线（单镜内）
```
起（中景，平稳，1s）→ 渐（推进/主体动，蓄势，2s）→ 峰（景别最紧/动作爆发，0.5s）→ 收（缓拉远/定格，1s）
```
一条长镜头内部完成 build-peak-release，不靠剪辑。

## 经典长镜头张力场景

### 逼近对峙（一镜）
```
中景对峙（1s）→ 慢推进近景（2s）→ 大特写刀柄（0.5s）→ 出刀瞬间（0.3s）→ 缓拉远定格（1s）
```
全程不切，靠推进+景别变完成曲线。

### 揭示背后威胁（rack focus 长镜）
```
主角近景清晰、背景糊（1s）→ 焦点转背景敌人变清晰（0.5s）→ 焦点回主角惊恐（0.5s）→ 缓拉远全景（1s）
```

### 追逃纵深（一镜跟随）
```
跟随逃者背影跑（2s）→ 镜头缓转揭示后方追兵逼近（1s）→ 特写逃者回头（0.5s）→ 全景距离更近（1s）
```

## AI 生成的长镜头限制
- 单镜超 6 秒，AI 易出现漂移/形变/主体崩
- 建议：长镜头在 AI 视频里用 3-5 秒为上限，更长用剪辑伪装（多段相似机位拼接）
- "一镜到底"在 AI 短剧里多为"伪一镜"——用连续构图剪辑模拟

## 长镜头 vs 快切的选择

| 维度 | 长镜头 | 快切 |
|---|---|---|
| 张力类型 | 持续累积揪心 | 爆发冲击 |
| 适合阶段 | build-up / release | peak |
| 观众感受 | 沉浸、无处逃 | 被冲击、过载 |
| AI 稳定性 | 较低（时长长易崩） | 较高（短镜拼接） |

## 备注
- 长镜头是 013 时间轴的极致运用，但成本高、AI 易崩
- 动漫短剧优先用"伪一镜"（构图连续的短镜拼接）模拟长镜头效果
- 长镜头必须有内部起伏，纯静态长镜=拖沓，是新手常见坑
- 023 切换频率讲的是反面——快切如何制造张力
