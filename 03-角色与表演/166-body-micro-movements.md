# 肢体微动作

## 核心要点
- 微动作≠小动作：**微动作是无意识的身体习惯**，是角色内心状态的外泄管道
- 次级动作(Secondary Action)：主线动作之外的叠加动作——喝咖啡+用勺搅三圈，搅的那三圈才是戏
- 观众对微动作的处理是**潜意识级**的：说不出哪里好，但角色"活了"
- AI视频里微动作是最容易被"单动作铁律"(146)误杀的部分——本条讲怎么合法地加
- 关联 164 复合表情、168 手部、169 姿态、146 通用铁律

## 微动作词典（按泄露的心理状态分类）

### 紧张/不安
```
摸后颈 / 玩戒指或转笔 / 整理袖口(已整齐还整理) /
抖腿 / 频繁吞咽 / 摸鼻子 / 衣角揉搓 /
手指在桌面无目的敲击
```

### 自信/支配
```
占据更多空间(张开腿/手臂搭椅背) /
缓慢的动作节奏 / 物品摆放精确对齐 /
不急着回应 / 手势少而大
```

### 防御/封闭
```
双臂交叉(经典但不等于全是防御) /
手持物品挡在身前(杯子/包/书) /
身体角度偏离对话者 / 摸自己的手腕(自我安抚)
```

### 思考/隐瞒
```
摸下巴 / 视线飘移+手指停顿 / 把物品拿起又放下 /
重复同一动作(倒糖包三次)
```

### 习惯型签名动作（角色锚点）
```
摸耳环 / 咬下唇 / 吹口哨 / 用手指绕着杯口画圈 /
某角色专属的、反复出现的、无功能的小动作
= 这是"角色指纹"，见075表情设计/088角色一致性
```

## 次级动作三层法

```
主层：核心动作（对话/走路/拿东西）
次层：微动作（搅咖啡/摸戒指/瞟窗外）
衬层：环境反应（头发被风吹/杯子里的涟漪/窗帘摆动）

三层叠加="这镜头是活的"
```
- AI视频常缺次层和衬层——画面干净得像3D渲染截图
- 加次层的提示词公式：`[主动作] + while + [微动作]`
  例：`"she drinks tea while her thumb rubs the cup rim absently"`

## 微动作的叙事密度控制

### 节奏原则
```
文戏镜头：1个微动作/2秒（密一点没关系，文戏靠这个活）
动作戏：0.5个微动作/2秒（微动作太多=分心）
情绪顶点：1个微动作/4秒（少即是多，微动作是标点不是句子）
```

### 一个场景的微动作预算
```
建议上限：3个
  - 开场1个（建立人物基调）
  - 中段1个（情绪转折标记）
  - 收尾1个（角色余韵）
超预算=角色变成多动症
```

## AI提示词中的微动作描述

### 标准句型
```
主句 + while/and + 微动作(带程度词)

坏："she plays with her ring nervously"（太直白）
好："she sits still, while her fingers trace the edge of 
    the table in slow, repetitive circles"
更好："she sits still, fingers absently tracing circles 
      on the table, gaze fixed on the rain outside"
```
- 微动作描述要**具体且带质感**（"slow, repetitive"比"nervously"好用）

### 高频微动作提示词库
```
traces circles on the table（桌面画圈）
thumb rubs the ring（拇指摩挲戒指）
adjusts cufflinks（整理袖扣）
taps finger rhythmically（有节奏敲击）
plays with hair strand（绕头发）
checks phone without unlocking（看手机不解锁）
rubs the back of neck（摸后颈）
swirls liquid in cup（摇晃杯中液体）
```

## 常见坑
- **微动作当主语**："she fidgets nervously"作为主句=画面主体变成了小动作——微动作永远在从句位置
- **全员微动作**：每个角色都在小动作=镜头像跳蚤市场——一场戏只给主角配微动作
- **无动机微动作**：紧张时给自信的小动作=观众读不懂；微动作必须和场景情绪匹配
- **微动作太大**：变成了"表演动作"=失去潜意识属性——幅度控制在"不注意就错过"的区间
- **AI生成太满**：提示词堆了3个微动作=AI全画出来=画面拥挤——一次只给一个

## 进阶
- **微动作的镜像**：对话双方做相似微动作（都转杯子/都摸下巴）=潜意识同步=关系亲密暗示
- **微动作的消失**：角色从焦虑变平静的过程=微动作逐渐减少直至消失=不靠台词的转变叙事
- **惯性设计**：紧张时摸戒指→危险时刻摸空了（戒指丢了/手被绑）=微动作变成剧情机关
- **环境共振**：角色的微动作影响环境（抖腿带动桌子共振）=身体-世界连接感
