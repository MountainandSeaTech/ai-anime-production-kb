# 活物互动总原则

## 核心要点
- **活物不是道具**：凡角色抱着、牵着、骑着、扛着的动物/宠物/灵兽，都是"配角演员"——必须有自己的合理动作＋与人物的互动动作
- **双层运动模型**：①自主运动层（呼吸/耳抖/尾摆/转头等生物本能动作）②接触反馈层（被抱时的挤压形变、被牵时的颈部跟随、被骑时的步伐承托）
- **静止即死物**：活物完全不动＝毛绒玩具/标本感，负向词压不住，必须**正向写动作**
- **互动即生命**：接触点必须有物理反馈（形变/位移/重量下沉），无反馈＝"抱着空气"
- 与 183 的分工：**183 管静物道具别消失，本条管活物道具别死机**

## 四大接触型总览

| 接触型 | 典型 | 自主运动重点 | 接触反馈重点 |
|---|---|---|---|
| 抱（怀中/臂弯） | 宠物、小兽 | 呼吸起伏、探头、耳抖 | 腹部受压形变、人体后仰代偿（→251） |
| 牵（缰绳/绳链） | 马、犬、坐骑 | 头部随张力偏移、步态 | 绳索垂弧与张力、拉锯节拍（→252） |
| 骑（骑乘） | 马、大型坐骑 | 步伐节律、耳向 | 骑手骨盆随背起伏、起止步惯性（→253） |
| 扛/负（肩上） | 猎物、大中型动物 | 垂坠肢体的随动摆动 | 负重下沉、肩颈压迫（→260） |

## 关键参数 / 模板 / 清单
```
活物互动镜头三句保底（每 Shot 必含）：
  ① 自主动作：写清活物此刻在做什么（呼吸/张望/蹭/警觉……）
  ② 接触反馈：写清接触面的物理结果（腹部压痕/绳索绷直/背脊起伏……）
  ③ 时机关系：人物动作先行 0.2–0.5 秒，动物反应跟随（惯例值）

负向词常备组：
  stuffed toy, plush toy, taxidermy, frozen statue, plastic figurine,
  lifeless pet, motionless animal
```

## 备注
- 微动作间隔 ≤3 秒：超过 3 秒无动作，观众潜意识里判定"死的"
- 时机铁律：人先动、动物后应（0.2–0.5s 延迟），同步动＝预读剧本的假
