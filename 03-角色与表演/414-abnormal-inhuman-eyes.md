# 病态与非常态眼神

## 核心要点
- **眼球震颤(nystagmus)**分两种波形：jerk型（慢相漂移+快相回跳，有方向性）与pendular型（正弦往返）——写病理角色别写成随机乱抖，波形本身就是诊断语言（公认医学）
- **疯批眼神=crazy eyes公式**：瞳孔放得比平时大+焦点微微错位+眼裂开大——日站Tag定义"yandere式焦点偏移的眼"，单独写crazy smile不出疯感，必须眼口影三件套（公认Tag用法）
- **黑化=高光五级熄灭**：L1眉口角下沉高光尚在→L2高光变小→L3高光全灭+瞳孔缩小+脸色发青→L4完全虚ろ(うつろ)+口半开=精神崩坏——黑化是渐进的，一步到位没有说服力（公认业界惯例）
- **附身/洗脑的官配=Mind Control Eyes**：平眼(flat eyes)/同心圆瞳+**焦点漂移+动作异常平滑**——库内苍月附身状态正是此配方：失焦眼神+异常平滑=人形容器感（经验+项目实证）
- **非人感靠异形瞳孔**：竖瞳(hebime蛇目)≈邪恶/捕食者、矩形瞳=山羊/恶魔、复眼=虫/异种、机械环瞳=人造物——配红/黄虹膜放大"wrongness"（公认Trope）
- 三白/四白眼（sanpaku）=虹膜小、三面露白——东洋面相学的"失衡之眼"，疯批与危险角色的常客（经验）

## 详细内容

### 1. 眼球震颤（病理向）

| 类型 | 波形 | 视觉 | 叙事用途 | 确定性 |
|---|---|---|---|---|
| jerk型 | 慢相漂移→快相回跳（以快相方向命名） | 眼睛"飘走-弹回"节律循环 | 神经损伤/中毒/眩晕状态 | 公认 |
| pendular型 | 等速正弦往返 | 钟摆式水平摆动 | 先天性/意识模糊 | 公认 |
| 方向 | 水平/垂直/旋转(torsional) | 垂直与纯旋转=中枢性，更"不对劲" | 恐怖谷调味 | 公认 |

动画化参数（经验）：每3-6帧一次往返、幅度小于虹膜直径10%、**双眼同相**——AI视频写"rhythmic involuntary eye oscillation, subtle pendular nystagmus"，比"trembling"更不容易崩成眼跳。与412瞳孔地震区分：地震=虹膜抖（情绪符号），震颤=眼球摆（病理符号）。

### 2. 疯批眼神配方（crazy eyes系）

```
基础式 = crazy eyes(放瞳+焦点错位) + wide-eyed(眼裂开大)
加强式 = + 三白眼(sanpaku) + 笑不动眼(嘴角笑/眼睛不笑=413矛盾对位)
定番组合(Danbooru系Tag，公认)：
  病娇豹変：crazy eyes, crazy smile, open mouth
  全力狂气：shaded face, empty eyes, crazy smile, open mouth
  被逼入绝境：constricted pupils, wavy mouth, trembling
单Tag失败率高：crazy smile单写≈不出疯感——眼・口・影三件套是业界共识(公认)
```
- 疯批的演技核心不是"瞪"，是**眼的情绪与全脸脱节**（162泄露失控版）：脸在笑、瞳孔在震、焦点在飘=三层各演各的（经验）

### 3. 黑化/闇堕ち五级表（高光熄灭进程）

| 等级 | 眼部状态 | 伴随 | 提示词锚点 |
|---|---|---|---|
| L1 轻度 | 高光尚在，眉/口角微沉 | 沉默寡言 | highlights dimming slightly |
| L2 中度 | 高光变小、瞳略缩 | 不笑了 | smaller eye highlights, faint frown |
| L3 重度 | **高光全灭+瞳孔缩小**+脸色发青 | 阴影覆脸 | empty eyes, no highlights, constricted pupils, shaded face |
| L4 极度 | 完全虚ろ(失焦空洞)+口半开 | 精神崩坏 | vacant unfocused eyes, mouth half open, hollow stare |
| L5 闇堕ち完成 | 重画眼型：高光换成异样光点/变色 | 新人格诞生 | dark glowing iris, slit pupils emerge |

- **对比是灵魂**：前一个镜头还是生动的眼，下一镜高光消失——"突然熄灭"的剪辑对位比渐变更绝望（公认演出手法）
- 视线配合：向下=没有希望；凝视虚空=心ここにあらず（公认漫画手法）

### 4. 附身/被操控（Mind Control Eyes）

```
视觉签名 = flat eyes(平眼/无立体感) 或 同心圆瞳
动态签名 = 焦点漂移(对不上人) + 眨眼频率异常(过多或归零) + 动作异常平滑(机器人式无顿挫)
库内实证：苍月附身状态 = 失焦眼神 + 异常平滑 —— "人形容器"感=眼睛不对焦+运动没有生命噪音(254反向应用：抽掉噪音层)
```
- 提示词：`possessed, flat lifeless eyes, gaze drifting slightly off-focus, unnaturally smooth head movement, no idle micro-motion`（经验配方）
- 解除瞬间=微动回归+高光重燃+第一次眨眼——复活三件套（经验）

### 5. 非人感瞳孔图鉴

| 瞳型 | 出处/Tag | 含义 | 确定性 |
|---|---|---|---|
| 竖瞳(蛇目/hebime) | slit pupils | 邪恶/捕食者/非人血统——"typically evil"是日网共识 | 公认Trope |
| 矩形横瞳 | rectangular pupils | 山羊→恶魔/牧场感，怪异度高于竖瞳 | 公认Trope |
| 复眼 | compound eyes | 虫/异种/量产机——剥夺个体性 | 经验 |
| 机械瞳 | mechanical/ring/crosshair pupils | 人造物/义体/被改造——虹膜里有光圈叶片或准星 | 经验 |
| 异色+红黄虹膜 | red/yellow eyes | 放大"wrongness"——Trope原话"accentuate the wrongness" | 公认Trope |

### 6. 提示词速查（中英对照）

```
失焦：unfocused eyes / glazed eyes / thousand-yard stare(创伤放空) / gaze slightly off
空洞：empty eyes, no highlights, blank stare, expressionless
疯狂：crazy eyes, wide-eyed, dilated pupils, sanpaku eyes
附身：possessed, flat eyes, concentric circle pupils, unnaturally smooth motion
非人：slit pupils, vertical pupils, glowing iris, mechanical pupils
防崩稳定词：steady head, subtle, slow（165）——疯批戏表情幅度大，微动词更不能省
```
