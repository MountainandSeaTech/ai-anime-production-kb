# 冷面与疯批角色的眼神克制——全部表演压在眼周

## 核心要点
- **面瘫≠没戏，是把表演预算全部压到眼周**（公认）：倪大红案例——"人中永远拉长、嘴角永远向下，但那双细长眼睛一眯一瞪就出了味道"（人民网）；基顿"石脸"同理——脸越死，眼睛动一下越是惊雷
- **雕像效应**（公认）：James Agee 评基顿——"当他转动眼睛，就像看见雕像的眼睛在动"。冻结的面具让每一次眼部微动获得 10 倍放大，这是面瘫角色表演的根本杠杆
- **疯批=眼神平静+行为离谱的反差**（经验·项目偏好）：疯不在眼，在"眼太稳"——用最平静的眼神做最离谱的事，反差越大越瘆人；眼睛先疯=普通反派
- **眼皮跳/单侧挑眉=毫米级泄压阀**（经验）：面瘫角色的情绪只允许从这两个阀门泄露，幅度以"观众要倒回去确认"为及格线
- **"用最稳的眼神说最疯的话"**（经验）：台词越疯，眼神越要稳——眼神晃一下=心虚，疯批从不心虚
- **空洞眼神=情绪的最高浓度**（公认）：倪大红《天盛长歌》"那股心痛从空洞的眼神中流出来"——大悲不用泪光用"空"，高光压暗+焦点涣散=灵魂的呜咽

## 详细内容

### 1. 面瘫眼神的账户模型（经验）

```
全片表演预算=100%
面瘫角色的分配：
  眉区(锁死不动) ......... 0%
  嘴区(锁死不动) ......... 0%
  眼周(眯/瞪/眨/跳) ...... 85%   ← 主战场
  其余(呼吸/喉结) ........ 15%
```
- 面瘫角色每次出场，眼周只允许动一个变量——两个以上同动="脸活了"=人设破功（经验）
- 破功点预算沿用 170：全片 1-3 次完整表情，其余全靠眼周（170 的总纲，本条是眼周专篇）

### 2. 面瘫眼周四件套（公认+经验）

| 动作 | 参数 | 语义 | 确定性 |
|---|---|---|---|
| 眯(squint) | 眼睑收 15-30%，1-2 秒缓动 | 怀疑/盘算/起杀心的前奏 | 公认（倪大红"一眯"） |
| 瞪(stare) | 眼睑开 +10-20%，不眨眼 | 威压/看穿对方 | 公认（倪大红"一瞪"） |
| 慢眨 | 10 帧+，对话中定点投放 | "你继续说，我在听笑话" | 公认（162 疯批官配） |
| 焦点切换 | 失焦 8-12 帧→重新聚焦 | 内心戏/空洞→回神 | 经验 |

```
中文分镜句：
  他没说话，只是眼皮极缓地眯下去一成，棋照下，茶照喝。
英文提示词：
  deadpan face completely still, only the eyelids narrow by a fraction, 
  slow deliberate blink, everything else frozen — statue-still face, living eyes
```

### 3. 疯批配置：平静眼神×离谱行为（经验·项目偏好）

```
疯批三原则：
  1. 行为离谱度 ↑↑↑（放火/说疯话/突然凑近）
  2. 眼神平静度 = 日常待机值（甚至比正常人更稳）
  3. 两者永不调和——观众的不适感=疯感的来源
```
- **反向踩坑**：眼睛圆睁+瞳孔地震+歪头笑=常规精神病，是"表演出来的疯"；真疯批的眼睛是"这事很正常"的眼神（经验）
- 官方吐槽位：配角看到这反差后的瞳孔地震=观众的替身（072 反应放大器，联动 163 瞳孔地震）
- 疯批眼神关键词：
```
  perfectly calm eyes, serene untroubled gaze, 
  eyes of someone discussing the weather, 
  unsettling stillness of the eyes while [行为描述]
```

### 4. 眼皮跳与单侧挑眉的分寸（经验）

面瘫角色仅有的两个"泄压阀"，分寸表：

| 阀门 | 幅度 | 时长 | 频率上限 | 语义 |
|---|---|---|---|---|
| 眼皮跳(eyelid twitch) | 单眼睑 1-2mm 一跳 | 1-2 帧，≤2 连跳 | 一场戏 1 次 | 怒意/杀意压不住了（泄露，非表达） |
| 单侧挑眉 | 眉峰上移 ≤15%，另一侧锁死 | 0.3-0.5 秒 | 一场戏 1 次 | 轻蔑/玩味/"哦？"（162：轻蔑唯一不对称） |
| 双挑眉 | 禁用 | — | — | 太活泼=破功 |
| 连续眼皮跳 | 禁用 | — | — | 变抽搐=喜剧化 |

```
提示词：
  a single involuntary twitch of the left eyelid, barely perceptible, 
  gone in a blink — the only crack in an expressionless face
  / one eyebrow lifts a few millimeters, the other doesn't move
```
- 验收线：第一遍看"好像动了？"、倒回去逐帧才确认=及格；一眼就看见=演过了（经验）

### 5. "用最稳的眼神说最疯的话"（经验）

```
分镜结构：
  特写：角色面部（眼神稳如老狗，语速均匀）
  台词：「那就把这座城烧了吧，今晚风大。」
  眼神：全程锁定对方，慢眨一次，结束。
```
- 稳=可信度：眼神越稳，疯话越不像玩笑——对方（和观众）意识到"他是认真的"的瞬间=全场最冷的一帧（经验）
- 反打配合：给听者一个 163 的"瞳孔收缩+眨眼频率上升"——疯批的稳靠听者的慌来显影（027 视线权力学：他永远不移开视线）
- 禁忌：说疯话时眼神飘/笑眼弯——飘=吹牛，笑眼=撒娇，都毁掉"认真的疯子"（经验）

### 6. 空洞眼神：疯批与大悲共用的终极武器（公认）

```
作画/生成参数：
  高光：消失或缩到针尖（163 黑化符号的病娇版）
  焦点：slightly unfocused gaze / eyes looking through you（焦点穿过对方）
  瞳孔：不放大不收缩——"无反应"本身就是反应
  眨眼：频率减半
提示词：
  vacant hollow eyes, highlights gone from the irises, 
  gaze unfocused as if looking through the person, 
  unnervingly slow blinking
```
- 疯批用=灵魂不在线（yandere 教程公认：高光消失=与现实断联"soulless eyes"）
- 大悲用=倪大红式"心痛从空洞里流出来"（公认案例）
- 同一组参数，上下文决定是疯是悲——空洞是"情绪超过表情容量"的通用解（经验）

### 7. AI 生成实操（经验）

```
双层公式（165）面瘫版：
  基底："expressionless deadpan face, perfectly still"
  眼周微动："+ only the eyes narrow slightly" / "+ a faint twitch under one eye"
负向词：expressive face, raised eyebrows, smiling, grimacing
抽卡：面瘫眼周戏 3-5 次抽卡——AI 容易"忍不住给表情"
验收：遮住画面下半脸只看眼周，戏还在=成功
```
