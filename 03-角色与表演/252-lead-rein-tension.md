# 牵引互动

## 核心要点
- **绳索是弹性系统**：张力大小直接写在绳体形态上——松弛下垂成弧、绷紧成直线；永不是不变形的钢丝
- **动物侧必跟**：被牵引时动物头部/颈部随张力方向偏移，前腿有抵抗或顺从的步态变化——"人拽绳、兽不动颈"＝断开连接
- **情绪沿绳传递**：人紧张→手收紧→绳绷直→动物头被带起→动物警觉；绳子是两人（人/兽）之间的"对话线"

## 详细内容
- **三档张力状态**：①随行（绳垂弧、轻接触）②引导（绳微绷、动物随向）③对抗（绳笔直、双方角力——即拉锯，喜剧用法见 261）
- **手部细节**：牵绳手不是死握——有绕指、换把、抖绳示意等微动作；急躁时绕绳缠手，从容时虚握垂腕
- **大型动物**：牵引更多是"礼仪性引导"（马随人），暴冲时人根本拉不住→被拖行（重量关系见 260）

## 关键参数 / 模板 / 清单
```
参数（惯例值）：
  · 静止随行：绳体下垂弧度明显，接触为克级至低牛顿级
  · 拉扯对抗：绳体绷直成线，动物颈部偏向拉力反方向（抵抗）或同方向（顺从）
  · 转向引导：绳先紧→动物头随→身体随，三段依次发生（各差约 0.2s）

中文提示词句：
  「缰绳微微绷紧传递张力」「牵引绳自然下垂成弧」
  「马匹头部随缰绳拉力方向偏转」「拉锯式角力」
英文关键词：
  elastic rein tension, rope sagging in a slack curve,
  head follows rein direction, tug-of-war rhythm
```

## 备注
- 高发翻车：绳索全程笔直如钢丝（无垂感）、动物被拽动但颈部纹丝不动
- 牵引中的"静止"也是互动：双方都不动时绳子仍要有微颤/垂弧
- 拉锯的喜剧设计见 261；骑乘时的缰绳手感见 253
