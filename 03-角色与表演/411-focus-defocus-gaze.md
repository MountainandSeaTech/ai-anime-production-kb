# 焦点与失焦

## 核心要点
- 失焦（unfocused gaze）的本质：**视线有落点但"没有看向任何东西"**——眼球停在远点，大脑切到内部频道（经验）
- 三种经典语境共用同一配方：**解离（dissociation）、崩溃前兆、回忆杀（flashback）**——靠前置事件区分（经验）
- "千码凝视"（thousand-yard stare）是真实的临床相关现象：创伤/PTSD 的固定失焦远眺，视线"穿过"人和物（公认：心理学文献）
- **重新聚焦（refocus）是失焦戏的戏眼**：回神的 2-4 帧 = 觉醒/决定/被拉回现实，全镜头最有戏的瞬间（经验）
- 镜头 rack focus 与眼神焦点可以同构对位：角色失焦时镜头跟着虚=进内心；角色回神时镜头跟着实=回世界（经验：摄影惯例）
- AI 对 `unfocused gaze` / `eyes glaze over` / `vacant stare` 识别稳定；`dissociation` 这类心理词写了白写（经验）

## 详细内容

### 失焦配方与分帧（24fps，经验）

```
进入失焦（8-16 帧渐变）：
1. 眨眼减少直至停止
2. 眼球漂移减速、锁定在远点/空处（407 drift 接管）
3. 眼睑微降半档（409 微垂）
4. 面部肌肉整体松垮 = "人不在眼里"
维持期：2-5 秒，微扫视几乎归零，只留呼吸和睫毛
```

### 三种语境的区分写法（经验）

| 语境 | 前置事件 | 失焦特征 | 收尾 |
|---|---|---|---|
| 解离/创伤 | 巨大冲击、噩耗 | 彻底放空+面肌垮+长时间（5 秒+） | 被外力拉回（喊名字/触碰） |
| 崩溃前兆 | 压力累积到顶 | 失焦+眼睑/嘴角微抽（409）+泪光上涌（410） | 重新聚焦=做决定，或崩落 |
| 回忆杀 | 触发物（旧物/气味/台词） | 失焦+视线略上扬（408 上=回忆符号） | 淡出叠化进闪回，回神=闪回结束 |

- 中文影视实证：杨紫《生命树》25 秒零台词——"瞳孔失焦+眼神震颤+茫然"→压抑→一滴泪滑落，失焦被当震惊-绝望转折的发动机用（经验案例）
- 刘青云式"双目失焦放空"演行尸走肉：长期低功耗失焦=角色已死一半（经验案例）

### 重新聚焦瞬间的表演力（经验）
```
回神配方（2-6 帧）：
1. 一次眨眼（163：眨眼当标点=频道切换的标点）
2. 眼球一次小 dart 锁定新目标（407：扫视回归）
3. 瞳孔/眼睑微调 = "系统重启完成"
```
- 回神速度=情绪走向：**快回神（2-4 帧）**=惊醒/决定/警觉；**慢回神（8-12 帧）**=不愿醒来/悲伤残留
- 回神后第一个表情决定戏义：回神+咬牙=黑化决定；回神+微笑=释然；回神+泪落=崩溃开闸（410 阶段 5）

### rack focus 与眼神焦点的配合（经验：摄影惯例）

| 镜头操作 | 眼神状态 | 叙事效果 |
|---|---|---|
| 角色清晰、背景虚 | 正常注视 | 常规内心独白位 |
| 角色由实变虚 | 进入失焦 | 镜头跟着角色"进内心"，世界离他而去 |
| 背景由虚变实（角色仍虚） | 失焦维持 | 观众替角色"看见"他没看见的东西=反讽/危机预告 |
| 双实：rack 回角色 | 重新聚焦同步 | 回神=世界重新压回他身上，最常用收法 |

- 原则：**镜头焦点平面的切换 = 角色意识频道的切换**——两者同步最有说服力，错位（角色虚、背景实）制造不安

### AI 视频提示词中英对照（可直接抄）

**失焦进入**
```
通用放空：her gaze goes distant, unfocused eyes / 视线飘远失焦
解离：vacant stare, eyes looking through him / 空洞凝视，视线穿过他
崩溃前兆：eyes glaze over, blank expression / 眼神蒙住放空
回忆杀：gaze drifts upward, lost in memory / 视线上飘陷入回忆
千码凝视：thousand-yard stare, fixed distant gaze / 创伤性远眺（军警/幸存者角色）
```

**重新聚焦**
```
快回神：her eyes snap back into focus / 眼神猛地重新聚焦
慢回神：focus slowly returns to his eyes / 焦点缓缓回到眼中
被拉回：blink, eyes refocus on the voice / 眨眼，视线重新锁定声源
```

**镜头配合**
```
rack focus from her face to the door behind / 焦点从她脸上转移到身后的门
shallow focus, background melts into bokeh as her gaze drifts / 浅焦背景化开配合失焦
```

### 稳定性与翻车（经验）
- `unfocused gaze` 稳定；但要和"死鱼眼"区分——加 `distant` `lost in thought` 类语境词防 AI 学成纯发呆
- 回神瞬间建议写在时间轴后半段（如 "4-6s: her eyes snap back into focus"），AI 对时序指令响应好于同句堆叠
- 失焦+大表情同写必崩：失焦期面肌是垮的，别同时写 frown/grimace

### 确定性标注
- 公认：千码凝视/解离的临床定义（PTSD 文献）；rack focus 的摄影技术定义
- 经验：失焦配方分帧、回神速度语义、镜头-眼神对位表
- 争议：无重大争议；"失焦=演技好"在影评语境有过誉倾向，注意滥用
