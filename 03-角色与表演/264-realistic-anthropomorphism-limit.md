# 写实系拟人化边界

## 核心要点
- **砍三件套**：人形化眉毛、嘴角大幅上扬/下撇（咧嘴笑/撇嘴）、人类式皱眉——写实动物脸上没有这些肌肉配置
- **保留五通道**：耳位、尾位、瞳孔、体姿高度、被毛状态（→255 五态表）——写实动物的情绪全部走这五条
- **行为链代替表情包**：开心＝蹭人＋尾高频摇＋耳松软（一串行为），不是"脸上笑一下"

## 详细内容
- **边界测试**：把动物镜头静音遮住身体只看脸——如果你还能读出情绪，大概率越界了（写实系应该读不出，得靠全身）
- **允许的例外**：瞳孔变化、眨眼/慢眨、嘴部微张（喘息/紧张）、舔鼻（不安）——这些是动物真实具备的面部动作
- **本剧口径**：真人写实风项目一律走写实系动物；迪士尼式表情只允许出现在明确喜剧幻想段落（本项目不用）

## 关键参数 / 模板 / 清单
```
提示词约束写法：
  「情绪通过耳朵、尾巴与身体姿态表达，面部保持动物真实状态」
  「无拟人化表情——不笑、不皱眉、不挑眉」
负向词（写实动物常备）：
  human eyebrows on animal, smiling mouth, grinning animal,
  anthropomorphic face, cartoon expression, disney-style face

对照示例：
  ✗ 「小貂开心地笑了」（咧嘴笑＝越界）
  ✓ 「小貂尾巴高频小幅度抖动，耳朵松软后贴，往她掌心里蹭了蹭」（行为链）
```
