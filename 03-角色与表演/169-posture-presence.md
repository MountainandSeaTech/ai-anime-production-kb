# 姿态与气场

## 核心要点
- 姿态(posture)=角色**唯一永不卸妆的表演**——脸可以放松，姿态一直在说话
- 脊柱对齐线：耳-肩-髋-踝一条垂线=身体效率最高=自信与控制力
- 姿态是**地位的可视化**：同一房间里，谁的脊柱更直、谁占据更多空间，谁就是上位者
- 关联 070 反派压迫感、071 弱势主角、166 微动作、168 手部

## 脊柱叙事学

### 脊柱状态谱系
```
超直(反弓)：军人/舞者/极度自律/僵化偏执
  → 控制欲的外化，也可能是脆弱在硬撑
标准垂直：自信/掌控/健康/主角态
  → 英雄站姿，但太标准=无趣
微驼(5-15°)：疲惫/谦卑/中年感/书卷气
  → 日常感与人味
深驼(15°+)：衰老/绝望/长期压迫/怪物
  → 反派的手下、被生活压垮的人
C型蜷缩：极度防御/受创/退行到胎儿位
  → 崩溃场景的终点站
```

### 重心即态度
```
重心居中：稳定/准备好/可控
重心前倾：进攻性/渴望/急迫（反派扑食前兆）
重心后仰：防御/轻蔑/放松（老板椅姿态）
重心偏移(单腿支撑)：随意/挑衅/不自信
```
- 冷幽默角色标配：重心后仰+下巴微抬="你继续表演"的身体版

## 气场=占据空间的方式

### 空间占有量
```
上位者：扩张——张开腿坐/手臂展开/物品摊一桌
下位者：收缩——并腿/手臂贴身/物品抱怀里
```
- 同一张桌子前，老板和员工的坐姿对比=权力结构的解剖图
- 镜头俯仰角(101/102)强化或反转姿态的权力读数

### 动作速度等级
```
上位者动作：慢、稳、少——每个动作都被注视所以不浪费
下位者动作：快、碎、多——永远在反应别人
```
- **疯批冷幽默核心**：天大的事发生，角色的动作速度不变=情绪稳定的物理证据
- 例外：上位者的"快"=爆发时，慢的越快越吓人（0到100的瞬时切换）

## 姿态的场景动力学

### 对峙场景
```
双方姿态镜像(同样挺直)=势均力敌
一方直一方驼=碾压局
一方逐渐塌下=心理防线崩溃的过程可视化
```
- 对峙戏的身体版轴线：谁向谁倾斜，谁就处于索取位

### 姿态的破功时刻
```
全程笔挺的角色突然垮下肩膀0.5秒
= 162微表情的身体版=全片最贵的0.5秒
```
- 姿态破功比表情破功更狠——脊柱是最后的防线

### 群体姿态合唱
```
军队：姿态完全同步=纪律与去人格化
暴民：姿态杂乱但方向一致=乌合之众的能量
一家人：姿态各异但有相似的小习惯=血缘感
```

## AI提示词实操

### 姿态词汇库
```
脊柱：upright posture / ramrod-straight spine / 
      slouched shoulders / hunched over / 
      relaxed lean against the wall
重心：weight shifted forward / leaning back casually /
      balanced stance / weight on one leg
空间：takes up space, arms spread / 
      closed-off posture, arms tucked /
      dominating the frame
速度：slow deliberate movements / unhurried /
      sudden explosive motion from stillness
```

### 公式
```
[脊柱状态] + [重心方向] + [空间占有] + [动作速度]

示例：
"he sits with a straight spine, leaning back,
 arms spread on the bench back, 
 moving with unhurried precision"
= 一个从容的上位者，不用一句台词
```

### 与镜头语言的乘法
```
低角度(101) × 挺直姿态 = 气场×2
高角度(102) × 蜷缩姿态 = 卑微×2
俯视(102) × 挺直姿态 = 困兽——环境压人但人不服=张力
```

## 常见坑
- **姿态全片不变**：角色从底层爬到巅峰姿态没变=弧光没长在身体上
- **AI姿态崩坏**：AI生成的人物脊柱常随机弯曲——用姿态词强约束+多抽卡
- **姿态与台词打架**：台词说"我不怕"，姿态缩成一团=观众信姿态不信台词（可有意用于撒谎场景）
- **全员挺直**：所有角色都是模特站姿=没有权力层级=世界扁平
- **忽视坐态**：坐姿比站姿更泄露性格（人站着会演，坐着就放松）——对话戏的姿态重点在坐姿

## 进阶
- **姿态时间轴**：给主角画一条全片姿态曲线——第1集的驼到第8集的直=不靠台词的成长叙事
- **姿态传染**：下位者无意识模仿上位者的姿态=忠诚/迷恋的身体证据
- **姿态反转喜剧**：佝偻老头一站直=绝世高手的经典桥段，喜剧版=怂包突然站直0.5秒又缩回去
- **静帧姿态测试**：随便暂停一帧，只看剪影能说出谁强谁弱=姿态设计合格
