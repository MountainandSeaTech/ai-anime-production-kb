# 阻碍——把障碍变成燃料（工具3）

## 核心要点
- **阻碍（obstacles）= 物质、情感和精神上的障碍，让你的人物达到目标变得困难**
- 核心公式：**成功的难度越大 → 达到目的时越有满足感**；**「胜利只在有着失败可能性的前提下才会令人满足。这种失败的可能就来自于阻碍。」**
- **人物越想战胜阻碍、越不能战胜 → 就越努力 → 这种努力创造出一场戏的张力**（张力随戏持续增强直至高峰）
- 三大类别：**外在（物质/身体/社会）、精神（认知/信念/心理）、情感（关系/性格/创伤）**；且**阻碍既是内在的也是外在的**
- 原书金句：「**阻碍令人不顾一切，而不顾一切就会产生喜剧。**」（克雷默的屁、约会时的笨拙）
- 阻碍要**个人化**到你自己最痛的地方；**当克服阻碍以完成分场目标的努力停止时，一场戏就结束了**

## 详细内容

### 1. 定义与作用原理

> **阻碍是物质、情感和精神上的障碍，让你的（人物）达到目标变得困难。**

- 阻碍使**任务更难完成**，从而让目标充满**力量和强度**。
- 核心逻辑：**到达目标要有风险**——物质和情感上都会相应陷入险境。
- 比喻：**攀登珠穆朗玛峰**（雪崩、空气稀薄、失足致死陷阱）vs **翻越小土丘**——同样是目标，前者阻碍大得多，也更令人兴奋。

查伯克公式（贯穿全章）：**成功的难度越大 → 达到目的时越有满足感。** 一个富有挑战性的阻碍会让奋斗更具激情。

### 2. 阻碍如何抬升张力（运用阻碍创造挑战）

- 实现总目标/分场目标越困难、越危险，对演员和观众而言这段旅程越精彩。
- 每场戏中阻碍越多，越难达到分场目标；一场戏开始，人物就面对内在阻碍并努力战胜；剧情发展又出现新的阻碍。
- **人物越想战胜阻碍、越不能战胜 → 就越努力 → 这种努力创造出一场戏的张力。**
- 阻碍让张力**持续增强**，推动这场戏的需要和意义发展，最终把它推向高峰。
- 「送到目标的困难越大，完成它和观赏它就越有满足感。」

**片例 · 惊悚感——《夺宝奇兵》（Raiders of the Lost Ark）蛇穴那场**：琼斯有严重**恐蛇症**（生理+情感阻碍）。若观众不知道他的恐蛇症，穿越就平淡无奇；加入了恐惧，情景才充满惊悚气息，也让琼斯显得**英勇无比**。

**喜剧公式**：「**阻碍令人不顾一切，而不顾一切就会产生喜剧。**」当你特别想得到什么时，常做出愚蠢、疯狂、怪异的行为。
- 例：约会想留下好印象，越想老练冷静越尴尬：绊倒、撞墙、走错门、冒出不知所云的评论、把东西撒在自己或别人身上、打碎东西……有些看似微小的情形（如放屁）也会成为强有力的阻碍。

**喜剧片例**：
- 《宋飞正传》迈克尔·理查兹饰克雷默：反复出现的分场目标是「**让你（杰里）喜欢我**」。一集里他放了个屁，为不让杰里闻到，**疯狂在屁股后面扇风**、每次杰里靠近就躲开扇空气——**这种搞笑行为来自他急切克服「臭味」阻碍以实现分场目标**。
- 《High 到哈佛》雷德曼饰从贫民区走出的哈佛学生：**上瘾（吸毒，甚至吸死人骨灰）是一种需要，成为切实存在的阻碍**；非贫民区活动（如和白人男孩划船比赛）时他觉得必须抽大麻，于是想出「划一下桨再抽一口大麻」，喊出「划啊、抽，划啊、抽……」，克服阻碍带来喜剧一幕。
- 金·凯瑞的高雅喜剧角色（《阿呆与阿瓜》劳埃德）：**每件事都是阻碍**，因为他必须克服「他是个呆瓜」这个阻碍，所以每件事都很难。

### 3. 三类障碍（定义与举例）

> **任何造成拦阻和冲突的事物都是一个阻碍**；把每个可能的阻碍都列出是徒劳且无穷尽的，但大多数阻碍符合三大类别：**外在的、精神的、情感的**（即物质/精神/情感）。且**阻碍既是内在的也是外在的**——它们可以是在你迈向目标途中的任何事物。

> **总原则**：对于实现总目标和分场目标来说，**任何能够产生障碍、冲突、限制、总之阻拦你的事情，都有可能成为阻碍**。

### 4. 案例：《毕业生》（The Graduate）——罗宾逊夫人 vs 本杰明（双视角）

琳达·格雷在伦敦西区舞台版《毕业生》扮演罗宾逊夫人获好评，归功于她深入研究角色**必须克服的阻碍**，把人物塑造得有血有肉、多面、敏感柔弱又迷人。

**罗宾逊夫人的阻碍：**
1. **本杰明可能会拒绝她**（失败的可能性、想得而得不到的可能性——**分析每个剧本都会遇到**）。
2. **她年龄比本杰明大很多** → 对身体不满意（皱纹、皮肤松弛、赘肉，对比同龄女孩的紧致挺拔）。
3. **丈夫很久没碰她** → 需要男性注意 → 对「无性别的年纪」（女人从美丽变成「端庄」）的深深恐惧。
4. **本杰明是邻居、是好朋友的儿子** → 若处理不好会被告知他人 → 失去丈夫、社会地位，成为笑柄。
5. **本杰明与女儿伊莱恩相恋** → 伊莱恩发现隐秘关系的风险 → 毁掉母女关系。
6. **旅馆偷情可能被朋友/邻居/熟人发现。**
7. **她开始对他着迷、甚至可能爱上他** → 极难放弃他，或忍受他对女儿的感情。
8. **对女儿产生嫉妒**（母女关系中的嫉妒并不鲜见）。

**本杰明的阻碍（相对罗宾逊夫人）：**
1. 可能被拒绝。
2. 比她年轻很多 → 被她丰富的性经验吓到（会不会早泄、阳痿？抚摸方式是否青涩笨拙？）。
3. 知识匮乏（聊什么？会不会显得傻和幼稚？）。
4. 她是他妈妈最好的朋友 → 性行为近乎**乱伦**。
5. 她看着他长大、太了解他 → 知道他所有难堪时刻（尿床、被看作书呆子……）。
6. 害怕被罗宾逊夫人的丈夫、他的父母、伊莱恩发现。
7. 当他爱上她女儿时，罗宾逊夫人会想尽办法对付他。

> **关键洞察**：本杰明的阻碍与罗宾逊夫人**相对应，只是视角不同**。分析剧本找阻碍时，**找得越多越好——外在、情感、精神三个方面——因为一个人物要克服的阻碍越多，表演就越复杂。**

### 5. 如何选择与「个人化」阻碍

- 先搞清剧本中人物的阻碍是什么，及其在**总目标和分场目标**中的意义。
- 再回到戏里把它们**个人化**，与你的生活发生联系。
  - 例（演勾引戏）：人物阻碍可能是**被拒绝、性功能障碍、自尊问题、身体缺乏安全感、过往恋人造成的伤害**。
  - 个人化路径：找**与你个人独特经历有关**的阻碍——被拒绝、性恐惧、身体形象（**挑你身上最讨厌的部分——胸部、腿部、手臂……选最糟糕那个**）；你是羞涩、傲慢还是软弱顺从？它怎么给你带来麻烦？
- **融入表演的阻碍，应当是难度最大、要求最高、问题最复杂和最有挑战性的。**
- 角色的阻碍**不是都必须写在剧本里**：有些白纸黑字，另一些需基于剧本事实做**猜测与想象**。**即使有的角色看似没有阻碍，你也得找出来。**「**看一场风暴令人兴奋，风平浪静就非常无聊。**」
  - 片例（乔伊·布莱恩特《三路狂奔》丽塔）：剧本没给「她为何爱上一个靠不住的男人」充足理由 → **假设她家人都去世 → 「孤独」是阻碍**；猜测她找老男人因为他像她缺席（亡故/失踪）的父亲 → 用以合理化总目标「让你爱我并和我在一起」。
  - 片例（佩姬·利普顿《双峰》诺尔玛）：角色像「风暴中的一块岩石」稀松平常 → 由剧本事实**推断阻碍**：女招待→经济困难；单身→孤独；住小镇→选择不多；周围有杀人犯→害怕下一个被杀；小镇怪人多→格格不入。这些阻碍催生角色特点，让她与观众更有联结。

### 6. 内/外障碍的关系与「永不认输」原则

- **阻碍既是内在的也是外在的**；由「替代」（工具4）来具体实现个人化——**你对替代的选择，将会决定你如何对阻碍进行个性化**。
- 一旦确定最具挑战性的阻碍，**即使看似无法战胜，也不要对实现分场目标失去信心。绝不要认输**，即使机会很小也要知道总有希望。
- 轻言放弃的人常被观众视为**失败者**；要用好胜的、凡事皆有可能的心态表演。
- **当克服阻碍以完成分场目标的努力停止时，一场戏就结束了。** 若斗争提前结束，前进动力就没有，观众也不再关心下面的戏——**到该结束时再结束**（哪怕出画后片刻导演才喊「停」）。

### 7. 实践运用（操作步骤）

1. **手里拿着铅笔研读剧本**，边读边标注；从头读一遍，之后再来一遍，把阻碍直接写在剧本上（用铅笔以便擦改）。
2. 研究阻碍时，**不要仅看自己出现的场景或台词**，因为许多阻碍是**其他角色的行动和语言**造成的。
3. 在剧本里找到阻碍，或结合人物逻辑**推断**出来。
4. 下一步让阻碍与自己的生活和联系——**个人化只能由你所选择的替代（工具4）来实现**。

> 剧本分析第一层步骤回顾：(1) 找到总目标；(2) 找到分场目标；(3) 找到符合剧本和人物逻辑的阻碍。

```
外在阻碍（物质/身体/社会）：<1 条>  例：电动车被偷 / 断肢 / 太穷 / 身份禁忌
精神阻碍（认知/信念/心理）：<1 条>  例：自卑不敢开口 / 藏着秘密 / 政治信仰
情感阻碍（关系/性格/创伤）：<1 条>  例：被前女友嫌弃穷 / 旧伤 / 嫉妒 / 被遗弃感
```
要求：**三类各至少一条**，并挑**难度最大、最有挑战性**的作为本场主阻碍。

### 阻碍有效性自检
- 它是否让「失败真的可能发生」？（无失败可能=无满足感）
- 它是否与角色的**总目标/分场目标**直接对抗？
- 它是否**可个人化**到你的真实生活？
- 它是否**越多越好**（外在+情感+精神三线并行，人物才复杂）？

## 对 AI 短剧的落地要点

> AI 生成的角色最怕「没有阻力」。阻碍就是给 AI 角色注入**摩擦**的装置，也是让画面产生喜剧与张力的开关。

- **建「阻碍三库」提示词模板**：为每个角色显式写出 1 个外在阻碍 + 1 个情感阻碍 + 1 个精神阻碍。例：外卖小哥 → 外在「**电动车被偷**」＋情感「**被前女友嫌弃穷**」＋精神「**自卑、不敢开口表白**」。
- **压迫动机而非状态**：AI 分镜指令里写「**因为 X 阻碍，所以拼命做 Y**」，而不是「表现沮丧」。阻碍 → 拼命 → 张力/喜剧。
- **喜剧放大法**：让一个「小阻碍」成为灾难（放屁/打嗝/门铃响错），角色疯狂掩盖 → 喜剧节拍。给 AI 的指令：「角色为掩盖小尴尬，做出夸张的掩饰动作（扇风/躲闪/假装看手机）」。
- **角色卡固定字段**：每条角色 prompt 里固定保留「**本场分场目标 + 本场最强阻碍**」，让 AI 在生成每个 beat 时都带「想要但受阻」。
- **冲突强度旋钮**：短剧想「燃/爽」就加大「失败的代价」（越高风险 → 达成时越有满足感）。用原书公式：**难度越大 → 达成时满足感越大**。
- **关系型阻碍最值钱**：优先选「亲密关系问题 / 背叛 / 嫉妒 / 年龄差 / 身份禁忌」等情感阻碍（参考《毕业生》双视角），比纯外在阻碍更能驱动人物关系戏。
- **双视角阻断**：同一场对手戏，为**双方各写一份阻碍清单**（视角不同、内容对应），可避免 AI 生成「一方有戏、一方工具人」的单薄对话。
- **镜头语言：阻碍可视化**——用特写（障碍物/表情）、手部小动作（扇风、攥拳）、受阻瞬间的停顿来表现；「**斗争停止=戏结束**」，所以镜头在阻碍解决前不要收（延续到出画）。
- **落点提示词示例**：`she wants to leave (objective) but the door is stuck and he keeps talking (obstacle); she grows more frantic` / `tiny obstacle blown into disaster: he tries to hide a fart from his crush, fanning behind himself`。
