# 主角的弱者张力

## 核心要点
- 弱者主角=**代价可见+差点失手+觉醒反转**=最强张力载体
- 无敌主角=代价为零=零张力（011 代价要素）
- 弱者主角的弧光：被压→临界→觉醒→反击=055 变身的人物版
- 机位：主角用俯视/小景别=弱势编码（017）

## 弱者张力的来源

### 1. 代价可见
- 主角受伤/被逼/濒败=代价被画出来=揪心
- 没代价=无威胁=无张力
- 每场必须有"主角差点输"瞬间

### 2. 差点失手=不确定性
- 主角差点死/差点败=结果不可测=揪心（011）
- 无敌=可预测=不揪心

### 3. 觉醒反转=弧光
- 被压到临界→觉醒反击=人物弧光
- 反差越大=张力峰值越高（055）

## 弱者主角的机位编码（017）

| 主角状态 | 机位 | 编码 |
|---|---|---|
| 被压/弱 | 俯视+小景别 | 弱、被动 |
| 临界/觉醒 | 平视转仰视 | 反转 |
| 反击/强 | 仰视+大景别 | 强、掌控 |

> 机位随主角弧光从俯→平→仰=视觉化强弱反转。

## 弱者主角的常见坑
- **无敌**：全程碾压=代价零=无张力
- **无差点失手**：一路顺=无悬念
- **无觉醒铺垫**：突然变强=生硬
- **机位不变**：全程平视=无强弱反转视觉

## 弱者主角的弧光节奏

### 被压段（俯视+小景别）
```
主角被压俯视近景（1.5s，弱）→ 受伤/濒败特写（0.5s，代价）→ 差点失手（0.3s，悬念）→ 临界（0.5s）
```

### 觉醒段（平视转仰视）
```
临界平视近景（0.5s）→ 眼神转变特写（0.5s）→ 转仰视（0.5s，反转）→ 反击（0.3s）→ 定格（1s）
```

## 弱者主角 vs 无敌主角

| 维度 | 弱者主角 | 无敌主角 |
|---|---|---|
| 代价 | 可见 | 零 |
| 悬念 | 差点失手 | 无 |
| 弧光 | 觉醒反转 | 无 |
| 张力 | 强 | 弱 |

> 无敌主角要救张力，必须制造"代价在别处"——保护的人会死/时间限制/道德困境。

## 经典弱者主角张力场景

### 被压觉醒反击
```
被压俯视近景（1.5s）→ 濒败受伤特写（0.5s）→ 差点失手（0.3s）→ 临界觉醒平视（0.5s）→ 转仰视反击（0.3s）→ 定格（1s）
```

### 保护代价（无敌主角的张力救法）
```
主角无敌打（1s）→ 但保护的人被威胁特写（0.5s，代价在别处）→ 主角被迫抉择（0.5s）→ 出手（0.3s）→ 定格（1s）
```

## AI 提示词

- 受伤代价：`close-up, wounded protagonist, blood, pain, desperation`
- 觉醒反转：`eyes shifting, determination rising, low to high angle transition, awakening`
- 反击强：`low angle protagonist, counterattack, empowered, rising`

## 备注
- 弱者主角是张力最强载体——代价+悬念+弧光
- 无敌主角=零代价=零张力，需把代价移到别处（保护的人/时限/道德）
- 机位随弧光俯→平→仰=强弱反转视觉化
- 觉醒反转要与 055 变身、070 反派压迫联动
