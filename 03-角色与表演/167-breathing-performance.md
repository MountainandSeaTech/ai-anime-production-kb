# 呼吸表演

## 核心要点
- 呼吸是**一切身体动作的发动机**——动画原理里叫"预备动作"，表演里叫"呼吸支持"
- 吸气=准备/蓄力/紧张上升；呼气=执行/释放/放松
- 观众**看不见呼吸但能看见呼吸的副产品**：肩膀起伏、胸口扩张、腹部运动
- AI视频最缺的表演细节：角色像塑料模特一样"无呼吸生存"——本条教你怎么补
- 关联 166 微动作、165 AI提示词、026-027 人物张力

## 呼吸的叙事语法

### 基础呼吸模式
| 呼吸模式 | 身体表现 | 心理状态 |
|---|---|---|
| 深呼吸 | 胸腹大幅起伏，肩膀微抬 | 蓄力/下决定/压制情绪 |
| 浅快呼吸 | 胸部小幅快速起伏，颈侧肌肉可见 | 恐惧/紧张/警觉 |
| 屏息 | 全身静止，只有眼睛在动 | 震惊/恐惧/专注/等待 |
| 叹气(长呼) | 肩膀垮下，身体前倾或后仰 | 疲惫/无奈/释放/失望 |
| 倒吸气 | 快速吸气，胸廓快速扩张 | 震惊/恐惧/突然意识到什么 |
| 憋笑式呼吸 | 胸部不规则小抖动 | 强忍笑意/尴尬 |

### 呼吸与动作的相位关系
```
出拳/挥剑：出招瞬间呼气（核心收紧）
跳跃：起跳前吸气（蓄力），落地时呼气（缓冲）
对话：句首吸气（准备开口），句中气息支撑（音量稳定）
受击：被击中时呼气或屏息（身体反应）
```
- 违反相位=动作看起来"没力"或"假"
- AI视频生成如果模型不支持呼吸细节——后期用**画面微抖动**或**音轨呼吸声**补（156）

## 呼吸作为表演节拍器

### 对话戏的呼吸设计
```
角色A说重话前：深吸一口气=这句话很重的预告
角色B听完后：缓缓呼出=消化信息
两人沉默对峙：各自的呼吸节奏从同步→失同步=关系破裂的听觉/视觉信号
```
- 呼吸声在157的L4层（主观抽象层）——特写镜头里呼吸声比台词更重要

### 情绪转变的呼吸标记
```
愤怒→平静：呼吸从急促→深慢（一次深呼吸=转折点）
恐惧→决心：屏息→倒吸一口气→稳定深呼（三步曲）
悲伤→爆发：浅快呼吸积累→突然屏息→嘶吼式呼气
```
- 一次呼吸模式的转变=一次情绪转变的身体证据
- 比任何台词都诚实

## AI视频的呼吸实操

### 提示词策略
```
显性呼吸："visible breathing, chest rises and falls with each breath"
隐性呼吸："subtle body movement suggesting breathing"
屏息："holding breath, body still, only eyes moving"
叹气："exhales slowly, shoulders drop with the breath"
```
- **位置**：放在动作描述之后、环境描述之前——呼吸是动作层的附属信息
- **景别匹配**：远景别写呼吸（看不到），近景/特写必须写

### 翻车与修复
| 症状 | 原因 | 修复 |
|---|---|---|
| 角色像蜡像 | 无呼吸提示 | 加"visible breathing" |
| 呼吸太夸张 | 幅度词失控 | "subtle breathing"替换 |
| 只有胸在动 | 缺乏全身联动 | "shoulders rise slightly with breath" |
| 对话戏无呼吸 | AI忽略副动作 | 单独抽"对话+呼吸"组合镜头 |

### 分层叠加
```
呼吸是"衬层"动作：
  主层：对话/核心动作
  衬层1：呼吸（本条）
  衬层2：微动作（166）
  衬层3：环境反应
```
- 每层单独可控——AI做不到就分层生成，剪辑叠加

## 特殊场景的呼吸设计

### 战斗后
```
大口喘气+胸口剧烈起伏+肩膀下垂
= 体力消耗的视觉证据（156的拟音补喘息声）
```

### 告白/亲密场景
```
两人呼吸从各自独立→逐渐同步
= 关系拉近的潜意识信号（比任何情话都高级）
```

### 死亡/濒死
```
呼吸从正常→浅快→不规律→长呼后不再吸
= 生命消逝的身体叙事（无台词的死亡场景）
```

### 觉醒/变身
```
深吸气（蓄力）→屏息（力量凝聚）→爆发式呼气（释放）
= 能量释放的呼吸相位（与动作特效同步）
```

## 常见坑
- **无呼吸场景**：所有镜头角色都像在真空里生存——每个近景都必须有呼吸意识
- **呼吸幅度过大**：正常对话配深呼吸=角色像在跑马拉松——幅度匹配场景烈度
- **呼吸与动作脱节**：出拳时吸气=动作没力——相位对齐是铁律
- **忽略呼吸声**：画面有呼吸动作但音轨没呼吸声=感知减半——157L4层同步
- **全片同呼吸**：所有角色所有场景同一呼吸模式=呼吸是变量不是常量

## 进阶
- **呼吸暂停当切点**：屏息帧=最佳剪辑点——观众也屏住呼吸，切点不疼
- **呼吸同步做转场**：角色A呼气的尾帧→角色B吸气的首帧=呼吸接力（138的呼吸版）
- **呼吸消失=非人化**：AI/机器人/尸体角色不呼吸=观众潜意识识别"不是人"
- **呼吸即节奏**：用角色的呼吸频率反推剪辑节奏——紧张时快切跟着快呼吸走
