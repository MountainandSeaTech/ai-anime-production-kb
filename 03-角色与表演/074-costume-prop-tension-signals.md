# 服装/道具张力信号

## 核心要点
- 服装道具是**张力信号源**——破损=代价，隐藏道具=伏笔，仪式服装=宿命
- 道具是 026 前摇/030 手部的延伸物，也是 051 反转的线索载体
- 服装变化=弧光可视化（破损=被虐，整新=觉醒）
- 道具/服装比表情更稳，AI 视频里优先用

## 服装的张力信号

### 1. 破损=代价
- 衣服破损/血迹=被虐代价可见（071）
- 破损程度=代价程度
- 觉醒时破损衣服=被虐后反击的视觉

### 2. 整新=觉醒
- 觉醒/变身时服装变新/变形态=弧光可视化
- 破旧→整新=弱→强的视觉

### 3. 仪式服装=宿命
- 特定仪式服装=宿命/决战信号
- 换上仪式装=将赴决战

## 道具的张力信号

### 1. 隐藏道具=伏笔（051）
- 角色身上的隐藏道具（暗器/印记/信物）=反转线索
- 提前藏=回看才发现=好反转

### 2. 道具前摇（026）
- 手搭武器/握道具=前摇物理信号
- 道具是 030 手部的延伸

### 3. 道具特写=焦点
- 道具大特写=注意力钉死=蓄势
- 刀柄/扳机/信物特写=将动信号

## 服装道具的用法

### 1. 破损代价
```
主角被压衣服破损近景（1s，代价）→ 血迹特写（0.5s）→ 觉醒反击（0.3s）→ 定格（1s）
```

### 2. 隐藏道具反转
```
盟友并肩（1s）→ 盟友身上隐藏印记特写（0.3s，线索）→ 反转揭露（0.5s）→ 定格（1s）
```

### 3. 道具前摇
```
手搭刀柄道具特写（0.5s，前摇）→ 指节白（0.3s）→ 出刀（0.3s）→ 定格（1s）
```

### 4. 仪式服装决战
```
换仪式装全景（1s，宿命）→ 赴决战（1s）→ 对峙（0.5s）→ 出手（0.3s）→ 定格（1s）
```

## 服装道具的常见坑
- **无破损**：被虐但衣服完好=代价不可信
- **隐藏道具太明显**：一出来就明是线索=无反转
- **道具无前摇**：直接用=无蓄势
- **仪式装无铺垫**：突然换=无宿命感

## 服装道具的进阶

### 道具的"角色化"
- 道具有自己的"状态"——刀有锈/锈掉/亮，枪有上膛/未上膛
- 道具状态=角色状态=张力信号

### 服装的色彩编码
- 服装色=立场/情绪（065 双色）
- 主角红衣 vs 反派蓝衣=冲突可视

## 服装道具与其他工具配合
- 道具+手部（030）=前摇延伸
- 道具+前摇（026）=蓄势物理信号
- 隐藏道具+反转（051）=反转线索
- 服装破损+弱者主角（071）=代价可见

## 经典服装道具张力场景
