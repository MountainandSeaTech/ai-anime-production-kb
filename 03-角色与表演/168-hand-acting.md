# 手部表演

## 核心要点
- Proko名言：手不是独立于身体存在的——**手是标点符号**，给身体的句子加断句和语气
- 手势的叙事权重仅次于眼睛——特写里一只手能讲完一整场戏
- 手的位置+弧度+力度=三维情绪坐标
- AI视频对手部的生成至今是地狱级难度——**手部特写是高危镜头，但也最容易出神来之笔**
- 关联 166 微动作、165 AI提示词、075 表情设计

## 手的位置叙事学

### 高度等级
```
手在头部以上：智慧/灵感/疯狂/神性（举手过头）
手在胸部：情感/真诚/恳求（手放胸口）
手在腹部：犹豫/不安/保护（护腹/交叉于前）
手在髋部：自信/对抗/掌控（叉腰）
手在背后：尊重/服从/等待/隐藏（背手）
手完全隐藏：威胁/秘密/未知（插兜/袖中）
```

### 经典手位词典
```
双臂交叉抱胸：封闭/防御/自我保护（过于常见=少用）
双手背在身后：尊重/地位低/等待指令（服务生式）
单手叉腰：放松/随意/自信
双手叉腰：对抗/挑战/不耐烦
手指塔尖（指尖对触）：自信/掌控/思考（反派标配）
手插口袋：随意/隐藏/不投入/保留
手摸下巴：思考/怀疑/评估
手托腮：无聊/沉思/疲倦
```

## 手的弧度与力度

### 弧度等级
```
完全伸展(五指张开)：开放/欢迎/投降/展示
微曲(自然弧度)：放松/日常/真实
半握(空握)：克制/潜在力量/准备
全握(拳)：决心/愤怒/力量/攻击
```
- 从张开到握拳的渐变过程=情绪升级的身体标记

### 力度等级
```
轻触：温柔/犹豫/试探
稳定接触：自信/掌控/平静
紧握/用力：决心/愤怒/恐惧(用力到指节发白)
颤抖：恐惧/愤怒到极限/身体崩溃
```

### 指尖语言
```
指尖轻敲：不耐烦/思考/倒计时
指尖划圈：无聊/诱惑/暗示
指尖捏合：精确/控制/挑剔
指尖张开如爪：疯狂/失控/怪物化
```

## 手部特写=独角戏

### 特写公式
```
手 + 物 + 微动作 = 一场微型戏

"hand slowly clenches around the sword hilt, 
 knuckles whitening, then relaxes"
= 内心挣扎→决定，全程无台词
```

### 经典手部特写场景
```
1. 握手：力量对比、关系变化、背叛预感
2. 递物：权力转移、信任测试、仪式感
3. 写字/签名：决定、身份确认、不可逆
4. 触摸伤口：疼痛、脆弱、回忆
5. 摆弄武器：危险、准备、习惯性动作
6. 空手摊开：一无所有、展示诚实、放弃
```

## AI视频手部实操

### 提示词策略
```
高危预警：手部是AI生成最容易翻车的部位（六指/融指/幽灵指）

降低风险的策略：
  1. 手部特写尽量短（1-2秒）
  2. 动作极简单一（只做一个动作）
  3. 避免复杂手指动作（握拳>张开>OK手势>比数字）
  4. 用遮挡降低手指可见度（握物/藏袖/逆光剪影）
  5. 必要时用H3的精控或参考图锁定手型
```

### 手部提示词安全词库
```
安全（成功率高）：
  clenched fist（握拳）
  open palm（张掌）
  hand resting on table（手放桌面）
  hand gripping sword hilt（握剑柄）
  hand reaching out（伸出手）

危险（成功率低）：
  interlaced fingers（手指交叉）
  counting on fingers（掰手指）
  intricate hand gesture（复杂手势）
  hand with spreading fingers（张开五指）
  holding delicate object（拿易碎品）
```

### 替代方案
```
手部翻车时的B计划：
  1. 切到手背/手腕视角（规避手指）
  2. 用剪影/逆光（手指细节不可见）
  3. 切到手部影子（影子可以表演）
  4. 用物体遮挡（手被杯子/剑柄/衣物部分遮挡）
  5. 后期修复或重抽（接受抽卡成本）
```

## 常见坑
- **手当主角**：对话戏中手比脸戏多=喧宾夺主——手是配角
- **手势无动机**：角色说话时手在乱挥=多动症——每个手势必须有心理动机
- **AI硬画手指**：明知AI画不好还非要手部特写=自虐——用遮挡/剪影/短时长规避
- **忽略手与物的关系**：手握剑柄但手里没有剑柄的接触变形=悬浮感
- **手势千篇一律**：所有角色同一种手势=手部设计也要角色化（075）

## 进阶
- **手部对比叙事**：同一角色前期手稳如磐石→后期手抖如筛糠=不用台词的崩溃过程
- **手-物关系**：角色对物品的态度=对世界的态度（珍爱地擦拭vs随意丢弃）
- **手的不在场**：角色刻意把手藏起来=有秘密的视觉暗示
- **群体手语**：群体场景中不同角色的手的位置=权力结构的可视化（169姿态联动）
