# 微表情与呼吸：张力信号源

## 核心要点
- 蓄势段角色不动，**张力靠微表情+呼吸外泄**——细节是"即将爆发"的信号弹
- 观众盯细节找"什么时候爆"——细节越精准，揪心越强（012 静态张力的燃料）
- 三大信号源：眼部微表情、嘴部微表情、呼吸节律
- AI 视频生成微表情稳定性差，必须用大特写+短时长锁定

## 三大微表情信号源

### 1. 眼部（最强信号）
| 信号 | 含义 | 张力用途 |
|---|---|---|
| 瞳孔收缩 | 警觉、决意、杀意 | 出刀前摇 |
| 眨眼骤停 | 注意力锁定 | 锁定目标的瞬间 |
| 视线偏移 | 动摇/察觉威胁 | 心理转折 |
| 眼睑微颤 | 压抑的情绪 | 强忍、将崩 |
| 凝视不动 | 锁定 | 对峙 |

> 眼是观众最盯的微表情区，大特写眼睛=蓄势顶配。

### 2. 嘴部
| 信号 | 含义 |
|---|---|
| 嘴角紧抿 | 压抑、决意 |
| 唇线微颤 | 强忍恐惧/怒 |
| 一侧嘴角上扬 | 冷笑/轻蔑 |
| 唇干张口欲言 | 犹豫、将说未说 |

### 3. 呼吸节律
| 信号 | 含义 | 张力用途 |
|---|---|---|
| 呼吸变浅变快 | 紧张、将动 | 蓄势顶点 |
| 屏息 | 决意瞬间 | 出手前 0.3s |
| 长呼气 | 释放/决断后 | release 段 |
| 呼吸骤停 | 死亡/剧变 | 峰值后 |

## 微表情如何串成张力曲线

### 居合蓄势（不动的 2-3 秒）
```
近景呼吸变浅（0.5s）→ 大特写瞳孔收缩（0.5s）→ 大特写嘴角紧抿（0.5s）→ 大特写屏息（0.3s）→ 出刀爆发（0.3s）
```
四个微表情信号叠加，把"即将动"的预期拧到顶，再爆发。

### 对峙动摇
```
特写凝视（1s）→ 视线偏移一瞬（0.3s）→ 回凝视但眼睑颤（0.5s）→ 嘴角微颤（0.3s）→ 接话/出手
```
动摇的微表情序列=心理轴加压。

## 微表情的"反差定律"
- 微表情越细微，爆发时反差越大=张力峰值越高
- 全程面无表情→最后瞳孔一收→出刀，这种"静-微-爆"序列最揪心
- 反例：全程夸张表情→出刀，反差小=普通

## AI 生成的微表情实操
- **必须大特写**：景别越紧微表情越可见，中景以上微表情会被吃掉
- **时长要短**：微表情信号 0.3-0.8s/镜，太长 AI 会漂移变形
- **关键词**：`micro-expression, subtle facial tension, eyes narrowing, breath held, lips pressed tight`
- **避坑**：AI 生成"夸张表情"远比"微表情"稳，微表情段优先用定格帧/短镜拼接

## 自检：蓄势段有没有微表情信号
- [ ] 这段有没有眼部微表情特写？
- [ ] 呼吸节律有没有被表现（胸口起伏/锁骨）？
- [ ] 微表情序列有没有递进（一个比一个紧）？
- [ ] 微表情后接的是不是爆发？

## 备注
- 微表情是 012 静态张力的核心燃料——不动但内部在"动"
- AI 视频微表情稳定性是难题，建议大特写+短镜+必要时升格放大
- 呼吸用锁骨/肩膀起伏表现比"胸口起伏"在 AI 里更稳
