# 角色一致性下的张力（动起来不崩）

## 核心要点
- **张力建立在角色不崩之上**——崩了再强的镜头也出戏
- 先定妆图锁角色 → 再图生视频动起来
- 一致性是张力的地基，不是加分项
- 角色崩=最致命的张力破坏

## 一致性破坏张力的场景
| 崩的类型 | 张力破坏 |
|---|---|
| 脸变（鼻眼嘴跑偏） | 观众出戏=张力归零 |
| 服装变色/变款 | 连续性断=专业感崩 |
| 体型漂移（胖瘦变） | 角色识别混乱 |
| 发型变 | 镜间不一致=廉价感 |
| 风格漂移（写实↔二次元） | 整片调性崩 |

## 锁角色工作流（关键）

### 1. 定妆图（MJ/即梦）
```
第一步：MJ 出角色定妆图
- 正面/侧面/背面三视图
- 标注：发色/瞳色/服装/体型/特征
- 固定这一张，全片复用
```

### 2. 图生视频（喂定妆图）
```
Gen3/Kling/即梦 → image-to-video
- 第一帧/参考帧 = 定妆图
- 提示词只写动作+镜头，不重写角色外貌
- AI 按图锁角色 → 动起来不崩
```

### 3. 多镜复用同一参考图
```
镜A：定妆图 → push-in 缓推
镜B：定妆图 → 转身动作
镜C：定妆图 → 表情特写
- 三镜同一参考=同一角色
```

## 锁角色的提示词要点
- **图生视频时**：提示词**不重写外貌**，只写"动作+镜头+情绪"
- 错误：`金发蓝眼少女穿白裙缓步走来`（重写外貌→AI 改脸）
- 正确：`character slowly walking forward, low angle, tense expression`（只动作）
- 外貌由参考图锁定，提示词只管动

## 不同工具的一致性表现
| 工具 | 一致性 | 用法 |
|---|---|---|
| Gen3 | 图生视频稳 | 定妆图→push-in/orbit |
| Kling | 图生视频稳 | 定妆图→动作链 |
| 即梦 | 图生视频最稳 | 定妆图→风格化动作 |
| MJ | 不生成视频 | 出定妆图/关键帧 |

## 多角色一致性
- 每个角色独立定妆图
- 同镜多角色：用 MJ 先出"双人构图图"再喂视频AI
- 避免视频AI"自由发挥"多角色→必崩

## 角色设计的张力加分
- 与 070 反派设计联动：反派定妆图突出压迫感
- 与 071 弱主角联动：主角定妆图突出"弱"
- 与 075 表情设计联动：定妆图含3-5个关键表情

## 常见坑
- **文生视频直接动**：没定妆图→每镜脸变→崩
- **提示词重写外貌**：图生视频还写外貌→AI 改脸
- **多角色同镜**：视频AI自由发挥→必崩
- **风格不锁**：每镜风格漂移→整片调性崩
- **定妆图太复杂**：细节太多→AI 记不住→简化特征

## 进阶
- 定妆图三视图：正/侧/背=全角度锁
- 表情集：定妆图含怒/惊/冷/笑=表情不崩
- `--sref`（MJ）锁全片风格统一
- LoRA/参考图权重调高=角色更锁

## 备注
- 一致性是张力的地基，不是加分
- 工作流：定妆图→图生视频→多镜复用
- 图生视频提示词只写动作+镜头+情绪，不重写外貌
- 即梦图生视频一致性最稳
- 多角色用 MJ 先出构图图再动
- 定妆图简化特征=AI 更易锁
