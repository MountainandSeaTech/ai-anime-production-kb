# 体型差与张力

## 核心要点
- 体型差=**视觉权力差**——大压小=压迫（070 反派），小胜大=反差爽点
- 体型是权力的肉身化，比台词/机位更直观
- 与 017 机位角度同属"权力编码"家族——机位是镜头权，体型是肉身权
- 张力来源：体型差越大，反差/压迫越强

## 体型差的张力来源

### 1. 大压小=压迫
- 大体型反派 vs 小体型主角=视觉压迫=威胁
- 大影覆盖小=049 围困的肉身版
- 不需要台词，体型即威

### 2. 小胜大=反差爽
- 小主角击败大体型反派=反差=爽点峰值
- 体型差越大，胜利越爽
- 是 071 弱者主角的视觉底

### 3. 体型渐变=弧光
- 主角觉醒时"看起来变大"（仰视+近景）=视觉化变强
- 反派败时"看起来变小"（俯视+远）=视觉化变弱
- 体型随弧光反转

## 体型差的用法

### 1. 大压小对峙
```
大反派仰视全景+小主角俯视全景对切（1.5s，体型差）→ 大逼近小（1s）→ 小临界（0.5s）→ 反击（0.3s）→ 定格（1s）
```

### 2. 小胜大反差
```
小主角被压（1s）→ 觉醒反击（0.5s）→ 击倒大反派（0.3s，反差峰）→ 大倒下+小仰视定格（1s）
```

### 3. 体型反转（弧光）
```
小主角俯视+大反派仰视（被压，1s）→ 觉醒→ 小转仰视+大转俯视（0.5s，反转）→ 小胜定格（1s）
```

## 体型差与机位/景别配合

| 主角状态 | 体型表现 | 机位景别 |
|---|---|---|
| 被压 | 小、远景 | 俯视+远/全 |
| 临界 | 同大 | 平视+中 |
| 反击 | 大、近景 | 仰视+近/特 |

> 体型+机位+景别三件同步=强弱反转完整视觉化。

## 体型差的常见坑
- **体型无差**：双方一样大=无视觉权=平
- **大反派太笨**：只会蛮力=无智=低级
- **小胜太易**：无代价=无悬念=不爽
- **体型不反转**：全程大压小=无弧光=无爽点

## 体型差的进阶

### 大而灵（高级反派）
- 大体型但灵活=智+力=最可怕
- 比笨重大反派更揪心

### 小而韧（高级主角）
- 小但不倒=韧性=反差
- 被打倒又站起=意志=爽点

## 体型差与其他工具配合
- 体型+机位（017）=肉身权+镜头权双编码
- 体型+负空间（020）=大影覆盖小=压迫
- 体型+反派设计（070）=Boss 巨影
- 体型+弱者主角（071）=小胜大弧光

## 经典体型差张力场景

### 大压小对峙
```
大仰视+小俯视对切（1.5s）→ 大逼近（1s）→ 小临界觉醒（0.5s）→ 反击（0.3s）→ 定格（1s）
```

### 小胜大反差
```
小被压（1s）→ 觉醒（0.5s）→ 击倒大（0.3s）→ 大倒小仰视定格（1s）
```
