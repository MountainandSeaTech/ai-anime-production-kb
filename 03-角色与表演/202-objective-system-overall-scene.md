# 目标体系——总目标与分场目标（工具1+2）

## 核心要点
- **总目标（overall objective）**=角色在**整个剧本**中最想得到的东西；「首要任务是什么？」**所有其他工具都必须服从和支撑总目标**
- **分场目标（scene objective）**=在**一场戏里**想要得到的东西；必须**统一于、支撑**总目标，**一场戏内绝不可中途改变**
- 关键分水岭：分场目标**不应**是「我要感受某种情绪」，而应是「**我要你（对手）怎样**」——必须**要求对方做出回应**
- 原书原话：**「目标是最重要的工具！」**「我怎么强调都不为过……目标是最重要的工具。」
- 铁律顺序：**先定总目标 → 再定分场目标 → 最后才用其他工具**去让目标更真实、更紧迫

## 详细内容

### 1. 工具1：总目标（overall objective）

#### 1.1 定义
**你的角色在全剧本中想要达到什么。「首要任务是什么？」这就是总目标。**

#### 1.2 它的三个功能
1. **提供剧本的开端、发展和结局**——为演员、也为观众定义戏剧旅程。
2. **所有其他表演工具必须服从和支撑总目标。**
3. **给行动注入紧迫感**——总目标**压缩了演员和观众的时间感**，让时光飞逝、一切更刺激，「仿佛任何事情皆有可能发生在舞台上」。

#### 1.3 为什么是「目标」而非「情感」（核心论证）
- 误区：「认为只要真实，或具有真实、深刻的感受，就是表演」（用眼泪代替塑造）。
- 真相：**「你如何运用这些情感来驱动并达到你的目标，这才是表演这门艺术让表演者和观众都兴奋的所在。」**
- 反例逻辑：没有明确目标、没有「为成功达到目标而进行的斗争」，**纯粹的情感型演员会成为剧本规定情境下的受害者**——「**没有人愿意去看一个受害者如何成为受害者。我们想要看到的是一个人如何改变命运，而不是接受命运的凌辱。**」
- 结论句：「**演员必须学会运用情感，不是把它当作结果而是当作手段，使之迸发出激情去处理剧本中的矛盾冲突。**」

#### 1.4 「情感是对一个行动产生的反应，而不是相反」
- 先找总目标，可**避免在表演开始前就迸发情感**；从不相关处硬挤情感，结果「就像是把**情感呕吐**出来」。
- 机制：**人类的生存本能让我们以目标为导向**；**情感生活只是达到或未达到目标的一种结果**（以「被爱」为例：达到就高兴，未达到就伤心和愤怒）。
- 副产品：一场戏一场戏追求总目标 → 创造**真实行为**；注意力集中在完成目标上，**就不去刻意关注自己看上去怎样**，本能行为乃至怪异之处自然显现——**正是这种真实行为产生出即时的张力**。
- 共情机制：观众看到目标一步步被实现，会**感同身受、仿佛自己在解决问题**；**人们若对他人的奋争感同身受，就会更乐于支持这个人。**

#### 1.5 总目标的性质要求
- **必须能给人物的生活带来一种转变**，一种对人物**物质或精神方面持续生存必不可少的**转变；是**全局性、普遍性的人类命题**。
- 好的总目标包含**基本人类需要**：
  - 寻找爱 / 找回旧爱 / 被无条件地爱 / 得到父亲或母亲的爱
  - 得到权力 / 拥有伟大的事业
  - 被认可
  - 生育孩子 / 结婚
  - 活下来（求生） / 保护所爱的人并让其活下来
- **总目标不是情节**：萧伯纳「没有新的情节，只有新的沟通方式并由此产生新的相互关系」；观众看的是**人类如何产生关系**。
  - 例：《限时追捕》把情节性的「侦破案件」改为**「让马特回到身边并再次爱我」**——破案因「要打动他」「要帮他洗清」而双重紧迫。
- 应「**简单、基本、积极主动**」：**最常见的错误是让总目标太过复杂**。
  - 例：《德州电锯杀人狂》重拍版：错误「让我和朋友活下来——因为杀人狂嗜杀、我还怀孕而男友不知情」；修正为**「保护我的腹中胎儿」**——最本能、最紧迫（即使最终剪辑把怀孕内容全剪掉，它仍让表演有原始的紧迫感）。
- **不要从理智上决定总目标**：先确定**三四个**，排练中都试；通常在**对话第二页结束时**，哪个最简单最有效就会明朗。

#### 1.6 如何找到与「个人化」总目标
- **多次通读剧本**很重要：找到更多人物元素，思考其他人物如何谈论你的角色（**即使你不在场时**）。
  - 例：《沉默的羔羊》汉尼拔总目标**不是「成为极具威胁的连环杀手」，而是「赢得探员克拉丽丝的友情」**——据此，结尾那句「一会儿我有一位老朋友来吃晚餐」让观众**不感到害怕而是会笑**。
- 个性化：把抽象目标换成一个**对你有个人利害**的目标。
  - 例：《拯救大兵瑞恩》剧本像是给「赢得战争」，但这对演员无个人意义；改为**「让我的婚姻顺利」**（把「战争」映射为每个人生活中类似战争的情感挣扎）。
- **给「坏人」一个有同情心的总目标**：如《海达·高布勒》把「邪恶女人」解释为**「得到我父亲的爱」**（父亲本想要儿子继承军事事业），于是她的算计有了令人同情的根源。
- **绝不评价角色或目标**：把不道德行为转译成「**夺回**」式目标。

### 2. 工具2：分场目标（scene objective）

#### 2.1 定义与总目标的关系
- **定义**：你的角色**在整场戏中想要的东西**。
- **分场目标一定要为总目标提供支撑**；每个分场目标都**不能违背**总目标（每场戏都是**情节链上的一个环节**）。
- 例：总目标是「被爱」，则每场戏都为「得到爱」铺垫；即使某场戏要**结婚**、后面某场戏要**离婚**，总目标仍不变——因为离婚由总目标激发（当前婚姻里没得到爱，情境驱使他到别处），**离婚并不违背「被爱」，而是为它服务**。
- 概括：分场目标是「**一场戏中让你的角色与其他角色联系的具体动力**」，是**达成总目标的具体方式**。
  - 例：《巴顿将军》总目标「获得权力」；动员演讲这场戏的分场目标「**鼓舞和激励（部队将士）**」——将士加倍回馈，让巴顿获得更强大的权力。

#### 2.2 分场目标必须**要求他人做出回应**（最重要区别）
- 自检问题：**「我的分场目标是否表达了对他人做出反应的要求？」**
- 必须把分场目标表达得**基础、强烈、原始**，才能落实到**身体**而非停留在头脑。
- **正确 vs 错误措辞对照表**（原书）：

| ✅ 正确的分场目标（要求回应） | ❌ 错误的分场目标（不要求回应） |
|---|---|
| 让你爱我 | 我需要爱 |
| 让你给我一份工作 | 我需要工作 |
| 让你认可我 | 我想要被认可 |
| 让你成为我的伙伴 | 我需要伙伴 |
| 让你把我的权力还给我 | 我要权力 |
| 让你和我发生性关系 | 我想要发生性关系 |
| 让你犯错，显出我的正确 | 我想要是正确的 |
| 让你给我希望 | 我要希望 |
| 让你崇拜我 | 我要被崇拜 |
| 让你帮我感觉好些 | 我要感觉好些 |

- **为什么错**：措辞的结构与意义**没有要求一个回应**——这样你就**不会影响其他演员**。
- 核心公式：「**表演是人与人之间的相互作用。**」「『我想要爱』与『我要**你**爱我』有巨大差异」——后者会**改变对方、迫使他们做出反应**。「**你必须改变对方来获得最终想要的东西。**」
- **反例：理智化、太复杂的措辞（错误）**
  - 「我想搞明白你是怎么想的，这样就能知道我们是否有一起坠入爱河的可能性。」
  - 「我需要你理解我做这些事情是因为我小时候曾被虐待……」
  - 诊断：**措辞太复杂、不清楚，不利于给出直观明确的方向**。方法：**尝试三或四个对话形式的措辞**，**若某个能在大声说出它时调动你的身体和情感，那它就是正确的**（「最有效的分场目标就像一副合适的手套」）。

#### 2.3 分场目标在一场戏中决不能中途改变
- 若中途改变、或感觉它变了，就说明**选错了分场目标**；它必须是**一个单纯的念头**，自始至终一致。
- 表演的复杂性来自**特定人物如何呈现他的需求**（角色与演员独特的背景、经历、个性）。

#### 2.4 拳击比赛比喻（当下性与即时性）
- 分场目标是一句**要求回应的话**：必须**影响另一个演员、激发他给出答复**——像一场精彩的拳击比赛（冲拳→上勾拳→迎击→回击，**所有行动都是当下和即时发生的**）。
- **你选的分场目标越有力，对方的回应也越有力，这场戏也越有力。**

#### 2.5 「目标是（最重要的）表演工具」
- 没有目标，情感只会躺在那里——**一大堆躁动却无用的感受**；**一味表达强烈情感 → 观众会认为那是自我沉醉的表演**。
- 「**让情感成为动力去达到你的分场目标，而不是以情感自身为终点。**」
  - 例：《急诊室的故事》艾瑞克·拉塞拉把剧本写成「内向、喜怒无常」的医生，却抓住分场目标**「让你活下去」**——给表演带来方向、行动、对胜利的极度渴望与失败的可能，成为**唯一抓住目标的演员**。

#### 2.6 始终让分场目标聚焦于**人物关系**，不要仅限于把情节演出来
- 「**演员的存在是要解读剧本，赋予它鲜活的人性。这种工作可以归结为创造出这样或那样的人物关系。**」
- 极端例：**即使有人把枪顶在你头上，你也要和持枪者建立一种关系**（《危情十日》——逃生唯一办法是让疯狂女粉丝相信他喜欢她）。
  - 例：《白宫风云》把白宫闲谈戏的关系驱动分场目标定为「**让你爱上我，并被我的性魅力所吸引**」，把平凡客串角色变成复杂可共鸣的人物。
- 极端反证：「哪怕你说一门外语，**只要有强有力的分场目标，别的演员和观众也会看懂**」（《阿米斯塔德号》杰曼·翰苏的「**让你喜欢我**」）。

#### 2.7 分场目标使一场戏有「开头、中间、结尾」
- 它给一场戏**存在的理由**，让每个人物的情感与想法有**动力和方向**。

#### 2.8 想清楚这场戏在整部剧本中的**位置**，并为「结尾」铺垫充分依据
- 要能准确定位某场戏（开头/中间/结尾？）——随剧情展开，**戏剧性和张力急剧增强**（以「初次约会 → 结婚」为例，张力逐场升级）。
  - 例：《黑客帝国》试镜戏在**开头**，尽管对白是招募套话与科幻术语，分场目标仍定为基本需求「**让你喜欢我**」，因初识而表现为**挑逗、性感、诱惑**。
- 为结尾铺垫：若结尾是**在一起**，每场戏都须与「获得这份爱情」有关；若**分手/死亡/杀人**，也须给出**充分依据**。
  - 例：《往日情怀》因最终成为陌生人，分手戏的分场目标从「让你爱我」**转变为「不惜一切代价让你留在我身边」**（暗示维持关系代价过高，分手成为情感存活的唯一选择）。
  - 例：《圣徒》角色死于心脏病，分场目标「**让你在我死之前爱上我**」带来时间紧迫感（观众不愿她死，制片厂甚至重拍让她活下来）。
  - 例：《埃德蒙》演连环杀手：分场目标「**让你该死**」——他设法刺激女孩暴怒，好让「杀掉她」在逻辑上成立。

#### 2.9 每一场戏都一定有一个分场目标（绝无例外）
- 「当你和某个人交流或者谈话的时候，总会有一个目的……**一定是有的**。」
- 现实反证：若真想分手且已打定主意，寄信/邮件即可；**若你需要一个投入的长谈，那肯定有更多事情需要解决**（「让你把我留下」/「让你承担罪责」/「让你尝尝我的痛苦」）。

#### 2.10 始终做出**利己**的选择；且**不要评判分场目标**
- **比起利他的事，我们总是在利己的事上花费更大力气**。
  - 对照：「让你感觉好一些」（利他，你能得到什么？） vs 「**让你感觉好一些，因此你会喜欢我**」（利己 → 带来回报，**也带来失败的可能**）。
  - 例：圣女贞德——与其演成「完全相信自己使命、高人一等」，不如演成「**极度渴望人们爱她**」的分场目标「**让你爱我**」，戏剧性才出来。
- **不要评判分场目标**：「评判像审查，而审查与艺术相冲突」；**「某种看上去糟糕的情况，若从另一个角度看则有可能是积极的。」**
  - 例：《愤怒的公牛》薇姬的分场目标是「**让你揍我，这样我们就能有很棒的性爱**」——暴力对她而言是**积极行为**。

#### 2.11 群戏（三人以上）中的分场目标
- 一场戏通常有**一个中心人物**，其余人物是**有意或无意的帮手**。
  - **无意的帮手**：聚会上你着意表现性感聪明，真正目标是房间那头的中心人物；四人约会中把朋友的对象当中心人物（你已能得到的约会对象不奏效）。
  - **有意的帮手**：Three-card Monte 纸牌游戏里的「托儿」（shill）帮你骗下注者。
- 例：《后天》山姆没和心仪女孩直接交谈，仍以「**让你选择我而不是另一个家伙**」为目标，借和朋友聊毛绒玩具熊来影射情敌，**声音大到让女孩听见**。

#### 2.12 面对导演指令，也要私下转化成分场目标
- 若导演说「你的角色只需自说自话、不需要别人」，**可私下把指示转化成分场目标**；否则表演没有前进动力、平淡无奇。
  - 例：《太空牛仔》洛伦·迪安私下坚持分场目标「**让你失败，而我是赢家**」（导演伊斯特伍德表面说不必准备，实则雇专家苦练——两人都在争胜，伊斯特伍德赢在理解「在工作中获得胜利的重要性」）。

#### 2.13 即使角色害羞、低调、似乎没有行动，也必须运用分场目标
- 例：《玻璃动物园》劳拉表面害羞、受人摆布，细读会发现她**有强烈欲望，实际上是在利用自己的害羞来获得她想要的**（用「无能」、害怕与腿疾让人们关照她、爱护她），并成功达到分场目标「让你喜欢我」。
- 结论：她的成功正是**由于成功运用了本是弱点的方面**。

### 3. 综合示例：《死囚之舞》（Monster's Ball）

- **总目标**：**「被爱和被照顾」**（莱蒂西娅最需要安全感与被帮助）。
- **分场目标（最后一场「背叛」戏）**：**「让你爱我」**。
  - 理由：这是全片最后一场戏，她必须战胜阻碍、成功达到总目标；因此分场目标**不能是「关于这个背叛」**，而应是「她如何得到她想要的东西——爱」。
  - **反面参照**：分场目标**不应**是「我要感受愤怒和绝望」（情绪正常的人会想要这样吗？）。
- **注入希望**：剧本不给快乐结局，于是由哈莉的表演注入「**感觉上的希望和可能性**」，避免角色沦为多重悲惨命运的受害者。

### 4. 误区清单（工具2）

1. **分场目标不支撑总目标 / 与总目标相矛盾。**
2. **措辞理智化、复杂或含混**（「我想搞明白…」「我需要你理解…」）。
3. **措辞不要求回应**（「我需要爱」而非「让你爱我」）——不会影响对手。
4. **在一场戏中让分场目标中途改变 / 出现多个分场目标。**
5. **把「情节」当成分场目标**（只演情节，不建立人物关系）。
6. **只表达强烈情感而目标缺位**（自我沉醉的静态表演）。
7. **只做利他目标**（没有个人利害，缺乏真正热情与失败风险）。
8. **评判分场目标**（用道德/社会价值审查角色）。
9. **群戏中试图从每个人取得反馈**（应聚焦一个中心人物）。
10. **先做内心工作再设目标**（本末倒置，分场目标无法推动戏）。
11. **忽略「这场戏在全剧中的位置/结尾走向」**，没有为结尾铺垫充分依据。
12. **以为「害羞、低调、没行动」的角色不需要分场目标。**

### 5. 工具1 误区清单（附加）

- 把「真实/深刻的情感」当表演本身；用情感作结果而非手段；总目标过于复杂情节化；从理智上决定目标；把总目标设定为情节而非基本人性需求；缺失最基本人性需求；评判角色及其目标。

```
总目标（全剧）：<一句最基本的人性需求>
  例：被爱和被照顾 / 得到父亲的爱 / 夺回我的权力 / 让我的婚姻顺利

分场目标（本场/本集）：<你—我 句式，要求对方回应>
  例：让你爱我 / 让你选择我 / 让你认输 / 让你留下 / 让你在我死之前爱上我
  ✗ 反例：我需要爱 / 我想要被认可 / 我要感受愤怒与绝望
```

### 分场目标自检三问
1. 它是否**要求对方（对手）做出回应**？
2. 它是否**支撑总目标**、且本场戏内**没有中途改变**？
3. 大声说出它时，是否**调动了你的身体与情感**（像「一副合适的手套」）？

## 对 AI 短剧的落地要点

> AI 只能生成**看得见的表演**，所以「目标」必须外化成两个东西：**角色卡里的一句目标** + **分镜里目标驱动的动作**。

- **把分场目标写成「你—我」句式**：`让你爱我 / 让你选择我 / 让你认输 / 让你留下`。**禁止**写成「我需要…」「我想要…」——这条可直接做进提示词模板的**校验规则**。
- **每集一句分场目标，单集内不得中途改变**；跨集可有不同分场目标，但都必须**服务同一个总目标**（避免 AI 生成的角色前后行为漂移）。
- **把「对手的反应」写进镜头需求**：因为分场目标要求回应，镜头最好同时给出**双方的反应回合**（正反打 / 过肩）——这是短剧「你来我往＝拳击」质感的来源。
- **关系优先于情节**：AI 剧本生成时，先写「**人物关系与欲望**」再写「事件」。台词废场（寒暄、职场闲谈）要补一个关系驱动的分场目标（参考 2.6《白宫风云》把闲谈变成情欲张力）。
- **目标外化为动作指令**：给 AI 的运镜/表演提示优先描述「**为达目标而采取的行动 + 眼前的阻碍**」（如「她一边微笑搭话一边死死盯住对方，手在桌下攥紧」），而非「她很悲伤」。
- **群戏镜头设计**：多人场景指定**中心人物**，其余角色写成「有意帮手／无意帮手」；让主角**对着帮手说话、眼睛却瞟向中心人物**，AI 分镜可显式写出这个走位。
- **结局前置**：先定结局（在一起/分手/死亡/反杀），再设计每集分场目标以铺垫依据；否则 AI 生成的短剧容易虎头蛇尾。
- **反派与灰色地带**：给冲突双方都写「**利己且自认正确**」的分场目标（如互相归罪），避免 AI 把短剧写成非黑即白。
- **弱势角色也要有目标**：给「社恐／柔弱／配角」也写一个隐性的、带操纵性的分场目标（参考 2.13 劳拉「用无能获得关照」），避免 AI 把她们生成纯背景板。
- **落点提示词示例**：`scene objective: make him stay (plead, seduce, humiliate herself if needed)` / `cut between her face and his reaction, real back-and-forth`。
