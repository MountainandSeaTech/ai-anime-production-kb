# FACS动作单元

## 核心要点
- FACS(Facial Action Coding System)=把43块面部肌肉的活动编目为**动作单元(Action Unit, AU)**——Ekman & Friesen 1978
- 表情=AU的组合公式：悲伤=AU1+4+15，真笑=AU6+12
- 对AI视频的价值：**AU给你一套精确的描述词汇**——"嘴角上扬"不如"AU12 lip corner puller"
- 关联 162 微表情、165 AI提示词、075 表情设计

## 高频AU速查表（动画/AI必备10个）

| AU | 名称 | 肌肉动作 | 表情效果 |
|---|---|---|---|
| AU1 | 内眉上扬 | 额肌内侧 | 悲伤/担忧的"八字眉" |
| AU2 | 外眉上扬 | 额肌外侧 | 惊讶/好奇 |
| AU4 | 皱眉下压 | 皱眉肌 | 愤怒/专注/困惑 |
| AU5 | 上睑提升 | 提上睑肌 | 瞪眼（恐惧/愤怒） |
| AU6 | 脸颊提升 | 眼轮匝肌 | 真笑标志（挤出的鱼尾纹） |
| AU7 | 眼睑收紧 | 眼轮匝肌睑部 | 眯眼（怀疑/用力看） |
| AU9 | 皱鼻 | 提上唇鼻翼肌 | 厌恶 |
| AU12 | 嘴角上扬 | 颧大肌 | 微笑 |
| AU15 | 嘴角下压 | 降口角肌 | 悲伤/不满 |
| AU26 | 下颌下落 | 咬肌放松 | 惊讶张嘴 |

## 关键组合公式

### 六大基本情绪的AU配方
```
快乐(真笑)：AU6+AU12（脸颊提升+嘴角上扬）
        假笑只有AU12——没有AU6的笑=职业假笑
悲伤：    AU1+AU4+AU15（内眉八字+皱眉+嘴角下压）
惊讶：    AU1+AU2+AU5+AU26（眉全抬+瞪眼+张嘴）
恐惧：    AU1+2+4+5+7+20+26（比惊讶多了紧张和嘴角拉伸）
愤怒：    AU4+AU5+AU7+AU23（皱眉+瞪眼+眯眼+嘴唇紧抿）
厌恶：    AU9+AU15+AU16（皱鼻+嘴角下压+下唇提升）
```

### 真假笑的分水岭
```
AU6(脸颊提升/眼轮匝肌收缩)是"杜兴微笑"的标志：
  有AU6 = 真笑，眼周有皱纹，眼睛微眯
  无AU6 = 假笑，只有嘴在笑，眼睛是死的
```
- AI生成"smiling"常出无AU6的假笑——提示词补"crow's feet, eyes slightly narrowed"（165）

## AU的动画/AI实战价值

### 1. 拆解参考
```
看到一段好表演→逐帧问：眉毛哪个AU？眼睛哪个AU？嘴哪个AU？
= 把"演得好"翻译成可复制的组合公式
```

### 2. 精确描述
```
模糊："他看起来有点难过"
精确："AU1内眉上扬15%，AU15嘴角微压，眼睑略垂"
= 后者能直接写进AI提示词（165五要素公式）
```

### 3. 复合情绪调配
```
苦笑 = AU12(笑) + AU15(压) 同时 = 矛盾情绪的外化
皮笑肉不笑 = AU12强 + AU6缺席 + AU7眯眼 = 威胁感
```
- 复合情绪=多AU叠加+不对称（左右脸不同AU强度=内心冲突）

## 微表情与AU的关系
- 微表情=完整AU组合的**时间压缩版**（0.5秒内）——组合不变，时长被压（162详解）
- 压制表情=AU启动到一半被反向AU截停——这个"截停痕迹"就是演技

## 常见坑
- **对称迷信**：真人表情几乎不对称——AI提示词加"asymmetric"反而更真
- **全集齐病**：把6个AU全写上=表情过载成鬼脸，微表情要的是1-2个AU的克制
- **忽视眼部**：只写嘴部AU=面瘫感，眼睛(AU5/6/7)才是情绪主战场
- **AU强度不分级**：AU4皱眉10%和90%是两种生物——描述要带幅度词（slight/full）

## 进阶
- **AU速度即情绪**：同样AU12，0.2秒拉起=真诚，0.05秒弹起=轻佻
- **延迟设计**：听到消息，AU4(皱眉)先于AU15(嘴角下压)出现=思考后难过；反过来=本能悲伤
- **冻结帧分析**：拉片时在情绪转折点冻结，标注AU组合=自建表演词典
- **跨物种映射**：动物/怪物角色的"表情"也可映射AU逻辑（眉区动作=哺乳动物通用语言）

## 备注
- 表情=AU组合公式，10个高频AU覆盖90%场景
- AU6分真假笑；不对称才真；幅度必须分级
