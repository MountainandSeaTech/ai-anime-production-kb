# 动物当配角演员

## 核心要点
- **动物是配角不是道具**：与 250 总原则互为表里——250 管"别死机"，本条管"会演戏"
- **总目标制**：给动物一个贯穿全剧/全场的总目标（守护主人／觅食／依附安全感／占据高地），它所有动作从总目标长出来
- **行动动词驱动**：每镜给动物一个主动作动词（蹭、盯、扑、挡、讨、避）——"可爱的宠物"是形容词，演不出来；动词才演得出来

## 详细内容
- **动词与主角目标对齐或对立**：动物动词与人物当前目标形成协助（人要走→犬在前带路）或对立（人要走→犬咬住裤脚不放）——戏剧关系由此产生
- **动机可辨识**：动物每个动作的动机必须在镜头前 0.5 秒内可被观众读懂（盯＝看见了什么、蹭＝讨要/亲昵）——读不懂的动机＝乱动
- **查伯克平移**：201-215 的人物表演体系可整体平移给有戏份的动物角色——总目标/阻碍/行动动词三件套即可，不必全十二步

## 关键参数 / 模板 / 清单
```
动物行动动词库（按总目标分组）：
  守护系：挡在身前、盯着来者、低吼、贴紧主人腿侧
  讨要系：蹭手心、扒拉衣角、仰头等喂、衔来物品
  依附系：跟脚、钻臂弯、听见动静先躲到主人身后
  占据系：跳上高处俯视、趴住某物不放、挡在门口

分镜写法示例（闪电貂·依附＋守护）：
  「它往钟灵臂弯深处钻了钻（依附），却从臂弯里露出头盯着左子穆
   的剑（守护）——随时准备再扑一次。」

反面写法：
  ✗「可爱的貂在她怀里很乖」——无动词、无目标、无戏
```

## 备注
- 动物训练师现场就是这么干的：不问"它该怎么演"，只设计"它要干什么"，动作靠训练/诱饵触发
- 动机可辨识与 259（动物先行）组合：先行的动作动机越清晰，预警张力越强
- 长篇项目里给常驻动物写一页"角色小传"（总目标/习惯动作/雷区），与人类角色档案同级管理
