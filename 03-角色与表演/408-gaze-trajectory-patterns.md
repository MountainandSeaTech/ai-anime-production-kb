# 视线游移轨迹

## 核心要点
- 视线轨迹分四型：**回避型=卸载/害羞/认输，扫视型=戒备/搜索，定焦型=支配/专注，游移型=紧张/说谎感/心不在焉**（经验）
- "思考时移开视线"有硬科学支撑：gaze aversion 是**认知负荷管理**机制，题目越难移开越多，移开后回答准确率上升（公认：Doherty-Sneddon / Glenberg 研究线）
- "往左看=回忆、往右看=说谎"的 NLP 眼动学说已被证伪——2012 年 PLOS ONE 三项实验、23/24 篇同行评审研究均否定（争议→**科学证伪**）
- 但方向语义作为**观众内化的视觉符号**依然有效：观众相信"眼神飘忽=心虚"，表演就可以用——科学事实与表演惯例要分开标注
- 日本剧团实证：视线稳定性直接决定角色气场——女演员零眨眼+定焦一点，瞬间逆转权力结构（经验）
- AI 提示词写"轨迹图案"比写"情绪"更稳：写 `gaze drops to the floor` 比写 `she feels ashamed` 出片稳定

## 详细内容

### 四种视线轨迹图案（经验：表演惯例+剧团实证）

| 轨迹型 | 图案特征 | 叙事含义 | 典型戏 |
|---|---|---|---|
| 回避型 | 视线从对方脸上移开，落向空处/下方 | 认知卸载（公认）/害羞/认输/隐瞒 | 被戳穿时看向旁边 |
| 扫视型 | 多次短促 dart，覆盖环境/对方全身 | 戒备、威胁评估、搜索逃跑路线 | 进陌生房间、被包围 |
| 定焦型 | 一点锁定，眨眼减少甚至归零 | 支配、专注、深情、杀意 | 对视压制、表白、宣战 |
| 游移型 | 无落点的连续漂移，"眼睛在游泳" | 紧张、心虚、撒谎感、心不在焉 | 被质问、强装镇定 |

- **游移=最廉价的"心虚"写法**：日语称「目が泳ぐ」，紧张时扫视急增是生理事实（经验）
- **定焦=权力**：叫喊的人越来越弱，静看的人越来越强——"激动=扫视级动揺，静观=平滑追踪级确信"（日本天文座剧团实证，经验）
- 变体两招（经验）：
  - **头锁眼动**（头不动只转眼）= 偷看/戒备/"你不配我转头"的强者余裕
  - **眼锁头动**（身体动视线钉死）= 执念/疯狂/恐怖感，惊悚片神器

### 视线方向语义对照表（务必看确定性列）

| 方向 | 通行说法 | 确定性 |
|---|---|---|
| 向上看 | 回忆、思考、想象 | 经验（NLP 具体对应已证伪，符号仍通用） |
| 向下看 | 羞耻、悲伤、屈服、认输 | 经验（跨文化表演惯例） |
| 向左/右看 | NLP：左=记忆右=编造 | **证伪**（Wiseman 2012，勿当测谎用） |
| 移开不看 | 思考难题、降低认知负荷 | 公认（gaze aversion 研究） |
| 过度对视 | 支配/深情；也可能=刻意伪装 | 经验；说谎者会**故意增加**眼神接触（DePaulo，公认） |
| 缓慢移开 | 悲伤、放下、结束对话 | 经验 |
| 突然移开 | 被戳中、逃避、受惊 | 经验 |

**争议标注**：NLP 眼动线索（eye accessing cues）作为测谎工具已被科学否定，但其"上=回忆、下=羞耻"等方向感已渗入全球影视语言，观众会照单全收——**当符号用，别当证据用**。

### AI 视频提示词中英对照（可直接抄）

**回避型**
```
害羞：she averts her gaze, looks down and to the side / 她移开视线低头
认知卸载：his gaze drifts upward as he thinks / 他思考时视线飘向上方
认输：gaze drops to the floor, defeated / 视线落到地面
```

**扫视型**
```
戒备：eyes scanning the room warily / 警惕地扫视房间
评估：his gaze flicks between the exits / 视线在出口之间弹跳
侧目偷看：sidelong glance, head stays still / 头不动斜眼偷看（头锁眼动）
```

**定焦型**
```
支配：unblinking stare, eyes locked on him / 不眨眼锁定
深情：gaze holds on her face, soft and steady / 稳定柔和地注视
疯狂执念：body turns but eyes stay fixed on her / 身体转动视线钉死（眼锁头动）
```

**游移型**
```
心虚：eyes wandering, unable to hold her gaze / 视线游移不敢对视
强装镇定：rapid small eye movements, forced smile / 快速小幅眼动+僵笑
```

### 轨迹的"节拍"参数（经验）
- 回避后**回不回来**是戏眼：移开→回来看一眼=还有话；移开→不回=关系结束
- 扫视频率：1 秒内 2-3 次 dart = 紧张升级；每 3-4 秒一次 = 常规环境扫描
- 定焦时长：3 秒以上开始产生压迫感/暧昧感，5 秒+进入"不是爱就是杀"
- 游移修正：想让角色"聪明地想"用**有落点的扫视**（dart 到具体物件），别用无落点漂移——漂移=心虚，有落点=思考

### 确定性汇总
- 公认：gaze aversion 认知负荷功能；说谎者反而增加对视（DePaulo）；NLP 方向测谎被证伪
- 经验：四型轨迹的表演映射、头锁/眼锁技法、定焦=权力
- 争议：一切"具体方向=具体心理"的精细对应（只能当观众符号）
