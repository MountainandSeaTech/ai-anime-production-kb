# 配角反应放大张力

## 核心要点
- 配角=**张力放大镜**——旁观惊愕/屏息/倒吸=把主角的张力放大给观众
- 观众通过配角反应"读"出主角多强/多险=信息差放大
- 配角不是摆设，是观众情绪的"代理"
- 与 031 群戏反应层同源，本条聚焦配角的功能

## 配角的放大功能

### 1. 惊愕=主角强
- 配角惊愕=主角做了不可思议的事=强被放大
- 没有配角惊愕=主角强没参照=不震撼

### 2. 屏息=临界感
- 配角屏息=临界将至=揪心放大
- 配角比主角更怕=代价感放大

### 3. 倒吸/退步=威胁感
- 配角倒吸/退步=反派/威胁多可怕
- 配角是威胁的"度量衡"

## 配角反应的类型

| 反应 | 放大什么 | 用法 |
|---|---|---|
| 惊愕瞪眼 | 主角的强 | 主角出手后 |
| 屏息 | 临界将至 | 出手前蓄势 |
| 倒吸/退步 | 反派的可怕 | 反派登场/出手 |
| 颤抖 | 真实恐惧 | 全程危险 |
| 笑（轻蔑/苦） | 态度 | 立场信号 |
| 喊"住手/别" | 代价 | 危险将发生 |

## 配角反应的用法

### 1. 蓄势期屏息（放大临界）
```
主角蓄势（1s）→ 配角屏息特写（0.3s，放大临界）→ 主角出手（0.3s）→ 定格（1s）
```

### 2. 出手后惊愕（放大强）
```
主角出手（0.3s）→ 配角惊愕瞪眼特写（0.5s，放大强）→ 定格（1s）
```

### 3. 反派登场倒吸（放大威胁）
```
反派逆光登场（1.5s）→ 配角倒吸退步特写（0.5s，放大威胁）→ 定格（1s）
```

## 配角反应的常见坑
- **无反应镜**：主角单打独斗无参照=强没放大=不震撼
- **反应太夸张**：配角大喊大叫=抢戏=廉价
- **反应太多**：每镜都反应=主线被打断=泄
- **反应无针对性**：呆滞无变化=没放大

## 配角反应的进阶

### 微反应（高级）
- 配角不喊不叫，只用微表情（024）=屏息/瞪眼/颤抖
- 微反应比大喊更"真"=更放大
- 适合疯批冷血风格（用户偏好）

### 多配角分层（031）
- 不同配角不同反应=立体放大
- 一人惊愕、一人退步、一人屏息=多维参照

## 配角反应与其他工具配合
- 反应+微表情（024）=高级放大
- 反应+群戏分层（031）=多维放大
- 反应+静默（033）=屏息放大顶配
- 反应是 070 反派/071 主角的"参照系"

## 备注
- 配角是张力放大镜——观众通过配角反应读主角强/威胁可怕
- 核心：蓄势屏息+出手惊愕+反派倒吸
- 微反应比大喊高级，适合冷血风格
- 忌反应太多太夸张——会抢戏/廉价
- 反应镜 1-2 个足矣，短（0.3-0.5s）
