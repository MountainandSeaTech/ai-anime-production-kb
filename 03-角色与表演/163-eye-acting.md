# 眼神演技

## 核心要点
- 面部表情的70%信息量在**眼周**——嘴可以演，眼睛最难撒谎
- 眼神三要素：**眨眼(blink)的节奏、眼跳(saccade)的方向、瞳孔(pupil)的状态**
- 真人眨眼3-4秒一次，3-5帧完成——AI角色要么不眨眼(蜡像)要么乱眨眼(癫痫)，中间态是演技
- 关联 162 微表情、133 视线匹配、161 AU系统

## 眨眼：思考的可视化

### 眨眼的语法
```
正常：每3-4秒一次，下落3-5帧，停留1-2帧，抬起稍快
快速连眨：紧张/撒谎/处理信息过载
慢眨(10帧+)：疲惫/悲伤/陶醉/无语（冷幽默吐槽神器）
不眨眼：专注/威胁/震惊定格/非人感
```
- **疯批角色的官配**：对话时慢眨="你继续说，我在听一个笑话"
- 眨眼是人类在**转移视线方向时的伴随动作**——转头瞬间眨眼=自然感的秘密

### 眨眼时机=表演节拍
```
听到关键信息→眨眼一次=接收处理
决定说出口→眨眼后开口=下定决心
被质问→眨眼频率上升=防线动摇
```
- AI提示词："slow deliberate blink" / "rapid blinking" / "unblinking stare"（165）

## 眼跳：内心的地图

### 眼跳方向的叙事含义
```
眼球快速跳动(darting)：紧张/搜索/恐惧/大脑高速运转
视线锁定不动：专注/杀意/入神
视线缓慢下移：悲伤/认输/回忆
视线上移：回忆/思考/翻白眼(轻蔑前奏)
视线躲开：撒谎/愧疚/屈服
```
- 眼跳先于头部动作：先看过去，头才转过去——**头随眼动**是生动感的铁律
- 违反它（头先转眼后动）=机器人感

### 对视的权力学
```
持续对视=支配/挑衅/深情（看上下文）
先移开视线=认输/服从/心虚
对视中缓慢眨眼+不移开=顶级支配（猫科动物模式）
```
- 133视线匹配是空间连续，本条是**表演权力**——正反打里谁先移开视线谁就输了

## 瞳孔：情绪的仪表盘

```
瞳孔放大：兴奋/渴望/恐惧/看到在意的人（交感神经兴奋）
瞳孔收缩：厌恶/愤怒聚焦/强光
```
- 特写镜头中瞳孔变化=潜意识级别的情绪信号
- AI提示词可用："pupils dilated" / "constricted pupils"——特写镜头有效，远景浪费
- 反光点(catchlight)：眼睛里有没有光点=角色"活没活着"的视觉底线

## AI视频眼部实操

### 生成要点
```
1. 特写镜头才配写眼部细节（中远景写了也白写）
2. 眼部描述放提示词靠前位置（优先级权重）
3. 组合描述："eyes narrow slightly, slow blink, gaze shifts to frame left"
4. 避免同时写剧烈表情+精细眼部——AI算力会被大动作吃掉
```

### 翻车对照
| 症状 | 病因 | 处方 |
|---|---|---|
| 全程瞪眼不眨 | 默认行为 | 加"natural blinking" |
| 疯狂乱眨 | 运动幅度过大 | 降幅度，加"subtle" |
| 斗鸡眼/斜视 | 双人特写视线混乱 | 单侧描述+133方位词 |
| 死鱼眼 | 无catchlight+无微动 | 加"light reflection in eyes" |
| 眼球震颤 | AI不稳定 | 抽卡重做，眼部戏缩短时长 |

## 动漫语境的眼部加成
- 动漫眼部简化为**高光/瞳孔大小/眼线张力**三变量——高光消失=黑化/绝望的经典符号
- 瞳孔地震(eye trembling)=动漫特有的震惊表演，真人影视没有
- 056-069作画张力联动：眼部是有限动画优先保的作画区域

## 常见坑
- **头动眼不动**：转头时眼球锁定原方向=恐怖谷（应头随眼动）
- **眨眼与台词脱节**：说到关键词时不眨眼=机器人，关键词配一次眨眼=重音
- **双人戏视线乱飞**：对视戏中一方视线漂移=观众无法锁定关系（133）
- **特写不给眼部时间**：眼部微动需要0.5秒以上才被读到——快剪里的眼神戏=白演
- **全片瞪眼**：怕观众看不出情绪就瞪=最低级的表演

## 进阶
- **眨眼当标点**：冷幽默台词说完后接一个慢眨=句号；不接=余韵
- **眼跳定剪辑**：角色眼跳向左→下个镜头切左边事物=视线引导剪辑（136动线联动）
- **三层眼部表演**：瞳孔(生理)+眼睑(情绪)+眉(AU1/2/4)=同向叠加或矛盾对位
- **无眼表演**：墨镜/背光/刘海遮眼=剥夺观众读眼的权利=神秘感靠"不给你看"

- 特写才写眼部细节，多抽卡，0.5秒起步
