# 表演层次与克制

## 核心要点
- 表演的能量守恒：**演员给出的越少，观众投入的越多**——观众补完的部分才是他们自己的
- 克制不是"不演"，是**把表演压缩到只有信号没有噪音**
- 面瘫演技(deadpan)的本质：把情绪外放压到10%，剩下的90%让观众从上下文推理=疯批冷幽默的表演地基
- AI生成的默认表演是"满"的——克制是AI时代的稀缺操作，也因此更显高级
- 关联 162 微表情、164 复合配方、155 静默（声音层的克制）

## 表演能量分配模型

### 100%分配原则
```
一场戏的表演总能量=100%
演员的输出 + 观众的脑补 = 100%

演100% → 观众0% → 看完就忘
演70%  → 观众30% → 合格
演50%  → 观众50% → 高级
演30%  → 观众70% → 大师级（风险：观众跟不上=闷）
```
- 短剧观众注意力短——建议常规60-70%，高光场景降到40-50%

### 层次的三明治
```
表层表演：角色想让在场者看到的（社交面具）
中层表演：角色下意识泄露的（微表情/微动作）
深层表演：只有观众看到的（独处时的真实状态）

三层齐备=角色是立体的；只有表层=纸片人
```

## 克制的四把手术刀

### 1. 减幅度
```
错误：悲伤=嚎啕大哭+捶地
克制：悲伤=眼睛红了一下，转头，继续切菜
```
- 幅度减半，真实感翻倍——真实的人在中爆发

### 2. 减频率
```
错误：每个镜头都给反应
克制：关键镜头才给反应，其余保持基底
```
- 反应镜头的稀缺性=反应的价值（072配角反应的反面：主角要少反应）

### 3. 减同步
```
错误：听到噩耗立刻变脸
克制：听到噩耗→0.5秒延迟→极轻的表情变化
```
- 延迟=消化过程=真实感；同步反应=条件反射=动物感

### 4. 减表情种类
```
错误：一场戏换8种表情
克制：一场戏1个基底表情+1次微变化
```
- 表情的变化次数和单次的含金量成反比

## 面瘫（Deadpan）表演工程学

### 面瘫不是没戏
```
面瘫三件套：
  1. 表情基底锁死（AU活动压到10%）
  2. 台词节奏稳定（无情绪波动的语速）
  3. 动作效率极高（无多余动作）
= 这三样越死，偶尔的一次破功越炸
```

### 破功点的设计
```
全片面瘫角色的破功预算：全片1-3次
位置建议：
  第一次：1/3处（证明他有心）
  第二次：高潮（证明他有人性）
  第三次（可选）：结尾（证明他变了）
```
- 破功形式梯度：微表情(162)→姿态塌0.5秒(169)→一次完整的表情=逐级加码

### 冷幽默的面瘫红利
```
面瘫角色说离谱台词=冷幽默核弹
面瘫角色做离谱的事=疯批美学
面瘫角色+周围人崩溃=气场差永动机（072反应放大器）
```

## AI生成的克制实操

### 降表演强度的提示词链
```
满级："crying hysterically, grief-stricken"
降级："eyes glistening, holding back tears"
再降："stares at the dish, a brief pause in chopping, 
      then continues"
```
- 逐级降级的词汇：restrained / understated / subdued / 
  holding back / composed / barely / a hint of

### 验收标准
```
克制表演的AI验收三问：
  1. 只看画面静音，能感到情绪吗？（能=过了）
  2. 情绪是"显示出来"的还是"泄露出来"的？（泄露=对）
  3. 如果把表情再减一半，戏还成立吗？（成立=还有压缩空间）
```

## 常见坑
- **把克制演成空洞**：克制=压缩情绪，不是删除情绪——底层要有东西可压
- **AI配合度问题**：提示词太克制=AI直接生成"无表情"——克制要描述"压着什么"，不是描述"没有"
- **全程克制**：从头到尾演50%=平——克制是为了让爆点更爆，不是取消爆点
- **观众不匹配**：短剧观众刷手机看——克制表演需要更强的上下文铺垫，否则被划走
- **破功太随意**：面瘫角色的破功镜头没用够铺垫=浪费全片最贵的一发子弹

## 进阶
- **克制的对位**：画面克制+声音满（153），或画面满+声音克制（155）——两条轨的能量互补
- **群体克制差**：同一个噩耗，主角沉默+配角崩溃=主角的深度靠配角的音量垫出来
- **克制的时长**：一场戏里克制的时间越长，最后一丝泄露越致命——憋气原理（155静默的表演版）
- **表演压强计**：给角色设定"情绪压强值"1-10，全片记录每场戏的压强=可视化的克制曲线
