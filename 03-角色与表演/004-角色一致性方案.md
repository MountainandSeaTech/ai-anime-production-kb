# 动漫短剧角色一致性方案

## 核心要点
- 一致性是分层控制的：角色卡（外观）→ 首帧锁（构图）→ seed 固定（微调）→ 镜头选择（规避弱点）
- 没有「一键搞定」的方案，必须四层叠加
- 单角色同一场景内一致性可达 90%+，跨场景/跨集需重新出卡

## 四层策略

### 1. 角色卡层（外观锁定）
- 用 SDXL/Flux 出「角色设定图」：正面/侧面/背面三视图 + 表情集 + 关键服饰细节
- 提示词固定，跑多版挑最稳的作为「母卡」
- 母卡切片为各镜头首帧输入：正面镜头用正视图切片，侧面镜头用侧视图切片
- 角色卡提示词模板：
  ```
  character sheet, [角色描述], front view + side view + back view, 
  [服饰细节], [发色发型], [瞳色], white background, reference sheet, 
  cel-shaded anime style
  ```

### 2. 首帧锁层（构图锁定）
- image-to-video 模式：用角色卡切片作为首帧
- 首帧决定构图、光照、角色姿势，视频只负责「动起来」
- 不要让模型从纯文本脑补角色，必然漂

### 3. Seed 固定层（微调复现）
- 同一镜头、同一首帧、同一提示词，固定 seed
- 改提示词时保留 seed，可做「只改动作不改外观」的对比
- 不同镜头用不同 seed，但同一镜头序列内固定

### 4. 镜头选择层（规避弱点）
- 正面镜头稳定性：正面 > 3/4 侧面 > 正侧面 > 背身转头
- 动作幅度：小幅 > 大幅，瞬发 > 持续
- 不让模型生成「背身转头回正」这种必崩镜头，改用切镜

## 角色卡管理
- 一个角色一个文件夹：`refs/角色名/母卡.png + 切片/*.png + 提示词.txt`
- 母卡版本号：`角色名_v01.png`，迭代后旧版保留
- 跨集复用：同一角色多集共用母卡，仅在剧本需求变化时迭代

## 失败信号
- 同一镜头内角色脸变形 → 换 seed 或减小动作幅度
- 跨镜头脸不像 → 检查首帧是否用了正确切片
- 服饰细节漂移 → 角色卡补一张「服饰细节特写」

## 备注
- 多人同框一致性极难，建议分角色单独生成后合成
- 跨集场景换装时，新建角色卡 v02，不要在原卡上改
- 即使用了四层策略，仍需多跑取优，一致性是概率不是保证
