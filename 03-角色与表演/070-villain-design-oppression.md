# 反派设计的压迫感

## 核心要点
- 反派压迫感来自**体型+逆光+俯视+静**——越静越强越揪心
- 最大忌：反派张牙舞爪=虚张声势=不威=不揪心
- 高级反派=面瘫冷血+极少动+一出手必杀（用户偏好的疯批冷幽默可融入）
- 反派是 011 威胁源的化身，设计即威胁

## 反派压迫感的四件

### 1. 体型大/逆光
- 体量比主角大=视觉压迫（073 体型差）
- 逆光剪影=不可读=神秘威（068）
- Boss 登场用逆光巨影

### 2. 俯视机位（017）
- 反派用仰视拍=权力编码=强
- 主角用俯视=弱
- 机位高低差=权力差=张力

### 3. 静=强
- 反派越不动越威——动则必杀
- 静止+微表情=掌控全场=揪心（012 静态张力）
- 张牙舞爪=心虚=虚

### 4. 微表情冷血
- 面瘫/冷笑/轻蔑=不把主角放眼里=代价感
- 一瞬的表情变化=出手信号（024）

## 反派设计的常见坑
- **张牙舞爪**：大喊大叫=虚张=不威
- **动太多**：一直动=无"必杀"感
- **表情夸张**：大笑大怒=脸谱=低级
- **无逆光/俯视**：平视平光=无威

## 高级反派的"疯批冷血"（用户偏好融入）
- 面瘫+语气平淡地执行离谱逻辑=寒意
- 一边聊天一边杀人=情绪稳定=反差=最恐
- 这种"情绪稳定的离谱"比暴怒反派更揪心

## 经典反派压迫场景

### Boss 逆光登场
```
逆光巨影剪影全景（1.5s）→ 仰视剪影逼近（1s）→ 露脸冷笑特写（0.5s）→ 一手挥/必杀（0.3s）→ 定格（1s）
```

### 面瘫屠杀
```
反派面瘫近景（1s，静）→ 主角冲来→ 反派一动作秒杀（0.3s）→ 回面瘫（0.5s）→ 定格（1s）
```
静→一击→回静=必杀感。

### 冷血对话杀人
```
反派面瘫聊天近景（1.5s）→ 一边说一边出手杀（0.3s）→ 回面瘫继续说（0.5s）→ 定格（1s）
```
情绪稳定地杀=最寒。

## AI 提示词
- 逆光巨影：`massive backlit villain silhouette, imposing, threatening`
- 面瘫冷血：`blank cold expression villain, emotionless, deadpan menace`
- 仰视威压：`low angle villain, looking down, power, dominance`
- 一击必杀：`single strike instant kill, effortless, minimal movement`
