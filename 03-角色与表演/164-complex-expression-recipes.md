# 复合表情配方

## 核心要点
- 单一情绪表情(纯喜/纯怒)是**儿童动画和表情包**的语言；真人表演=复合情绪
- 复合表情=**主情绪(70%)+次情绪(30%)**的AU混合——层次来自配比
- 矛盾的表情迫使观众"解码"=参与感=角色深度感
- AI生成默认出纯情绪(训练数据偏向明确标签)——复合情绪要**配方化描述**
- 关联 161 AU公式、162 微表情、075 表情设计

## 经典复合配方表

### 悲喜系
```
苦笑 = AU12(嘴角上扬) + AU15(下压) + AU1(内眉八字)
     → "我在笑，但别问开不开心"
含泪的笑 = AU6+12(真笑) + 眼眶含泪(泪腺) + AU1
     → 婚礼上的父亲/久别重逢
欣慰的悲伤 = AU12弱 + AU15弱 + 缓慢眨眼
     → 目送孩子远行
```

### 怒系复合
```
怒极反笑 = AU4(皱眉) + AU12(嘴角上扬) + AU7(眯眼)
     → 疯批角色的招牌：表情在笑，眼睛在杀
克制的愤怒 = AU4+AU23(唇紧抿) + 下颌紧绷 + 无其他动作
     → "我很生气但我在数到十"
悲悯的愤怒 = AU4 + AU1(内眉扬) → 愤怒中含同情
     → 处刑堕落者的圣职者
```

### 恐惧系复合
```
强装的镇定 = 平静基底 + AU5(眼睑微睁) + 吞咽动作
     → 162的微表情泄露+喉部动作
恐惧中的兴奋 = AU5(瞪眼) + AU12(笑) + 瞳孔放大
     → 变态反派/极限爱好者
安心与不安并存 = 眉区放松 + AU7(眼微眯) + 视线扫描
     → 哨兵的雨夜
```

### 疯批冷幽默特调
```
"情绪稳定地离谱" = 表情基底0.1(几乎无AU活动) 
     + 场景烈度9.0(背景在爆炸)
     → 反差即人设，表情越死，场面越疯
轻蔑的愉悦 = 单侧AU12(不对称笑) + AU7 + 视线下移(俯视)
     → "你认真的？"的表情版
```

## 配方化描述方法（AI提示词用）

### 主+次两段式
```
公式：[主情绪基底] + [次情绪AU细节] + [矛盾提示词]

示例：
"a calm smile, but worry visible in his slightly furrowed brows,
 conflicting emotions on his face"

"she laughs, but tears well up in her eyes, 
 bittersweet expression"
```

### 矛盾提示词库
```
but / yet / while / conflicting / mixed / bittersweet / 
fighting back(tears/anger) / barely holding / behind the smile
```
- 这些词提示AI做"两层渲染"——实测有效的复合触发器

### 不对称加成
```
"asymmetric expression" / "one corner of mouth raised" /
"left brow slightly higher"
```
- 不对称=内心冲突的视觉签名（161）

## 复合表情的时机设计

### 情绪过渡三段式
```
情绪A(纯) → 复合(A+B混合) → 情绪B(纯)
例：愤怒 → 愤怒+悲伤混合 → 崩溃痛哭
```
- 复合表情常是**两种纯情绪之间的过渡带**——过渡演好了，转变才可信
- 缺少复合过渡的情绪转变=跳切式表演=观众出戏

### 微表情嫁接
```
复合表情+162微表情泄露=三层表演：
  表层：冷静（演的）
  中层：苦笑（复合的）
  深层：0.3秒的愤怒微表情（真的）
```

## 常见坑
- **五五开配比**：两种情绪各50%=观众读不出主从=脸瘫感；主次要分明(7:3或6:4)
- **AI双情绪翻车**：写"happy and sad"=AI精神分裂式左右脸；要用配方化描述和矛盾连接词
- **复合当常态**：每场戏都复合=情绪油腻；纯情绪用于爆点，复合用于人味
- **缺生理细节**：复合表情的可信度靠泪光/吞咽/呼吸支撑（167）——纯AU组合像贴纸
- **过渡帧缺失**：AI生成情绪转变镜头时，中间帧容易鬼畜——转变镜头缩短到2-3秒，降低漂移

## 进阶
- **配比随剧情漂移**：同一角色的苦笑，第1集笑7悲3，第8集笑3悲7=无声的角色弧光
- **群体复合对照**：同一场戏，主角"怒极反笑"，配角"强装镇定"=复合表情的对位（153的声音对位在表演层的镜像）
- **观众解码测试**：给不看剧情的人看截图，他能说出"这人不对劲但说不上来"=复合成功
- **建立角色表情库**：为主角定义3-5个签名复合配方=角色一致性(004)的表演层实现
