# 动漫眼神符号体系

## 核心要点
- 动漫眼简化为三变量：**高光/瞳孔大小/眼线张力**（163）——其中高光是"生命开关"：有=活着，无=死/绝望/崩坏，一句话不用就能宣判角色状态（公认惯例）
- 高光解剖：**1个主高光（靠上）+1-2个小副高光**；高光位置决定眼睛"看向哪"；双高光=立体感——画错位置=视线错位（公认画法）
- **星星眼分单双眼**：单眼星=受击/震惊（seeing stars老符号），双眼星=憧憬/渴望/被迷住——写反了情绪就反了（公认符号学）
- **死鱼眼三要素**：无高光+无瞳孔细节+平涂无体积——扁平感是灵魂，加立体阴影反而破功（经验画法）
- 符号眼型（>_< ／ X_X ／ @_@螺旋 ／ 心形 ／ 火焰）是**喜剧语域专属**：正剧哭戏/死亡用写实眼，Q版/吐槽/夸张拍才切符号眼——语域混用=违和感来源（经验，有manga iconography文献支撑）
- 竖瞳/猫眼有**双面性**：蛇目(hebime)=邪恶捕食者（414），猫目(nekome)=俏皮/恶作剧/撒娇模式——同一张脸上是模式切换符号（公认符号学）
- **萌系大圆眼微动适配：眼越大，微动幅度越小**——同等眼跳角度，大眼虹膜移动的像素量翻倍、读感被放大；大眼角色的微动要按虹膜直径比例限幅，并多用"高光闪"替代"眼球动"（经验，254体量-幅度反相关原理的脸部应用）

### 4. 使用边界（什么时候不能用符号眼）

```
语域规则：符号眼型 = 喜剧/Q版/夸张拍 专属
  正剧的眼泪、死亡、觉醒 → 用写实眼+高光系统（414黑化五级）
  中途插一格符号眼 = 吐槽拍(comic beat)，插完必须切回
连续性规则：符号眼是故意off-model——
  AI视频里把符号帧混进写实序列 = 角色一致性崩坏
  正确做法：符号眼单独生成短插段(0.5-1秒)，硬切进出(415时长表)
比例纪律：符号拍全片占比建议<10%——符号用多了就不搞笑(经验)
```

### 5. 萌系大圆眼的微动适配

```
原理：大眼虹膜直径可能是写实眼的2-3倍
  → 同等眼跳角度，大眼移动像素量翻倍，观众读感放大(经验)
  → 库内萌系资产"大而圆的眼睛"=高分辨率画布，自带信息量，运动宁少勿多
适配参数(按虹膜直径D限幅)：
  眼跳幅度 ≤ 0.1-0.15D（写实眼可到0.25D）
  眨眼放缓：下落4-6帧、停留2-3帧（比163基准更柔）
  瞳孔缩放幅度减半(412表×0.5)——大眼瞳大，小幅度已清晰
替代技法：用"高光闪"替"眼球动"
  心动/惊喜不写眼球跳，写 highlights shimmer / light sparkles in eyes
  = 眼球稳+高光动：萌系静谧感不被破坏，情绪照样送达(经验)
关联254：体量越大微动越小=生命噪音层原理的脸部应用
```

### 6. 提示词速查

```
生动：large expressive eyes, one big highlight plus two small ones, bright highlights
死鱼眼：dead fish eyes, no highlights, flat shading, blank half-lidded stare
星星眼：sparkling eyes, star-shaped highlights, eyes filled with admiration
眩晕：spiral eyes, @_@, dizzy expression
萌系微动：minimal eye movement, tiny saccade, slow soft blink, highlights gently shimmer
竖瞳切邪恶：slit pupils（414）；猫目俏皮：cat-like eyes, upturned large round eyes, mischievous glint
```
