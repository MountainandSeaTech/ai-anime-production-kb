# 行为动作——用道具演出的真实（工具9）

## 核心要点
- **行为动作（doings）= 通过使用道具来让我们的意图具体化**——即「运用道具产生的行为」
- 生活中人们做的所有事都是行为动作：说话时整理头发、洗盘子、整理床铺、做饭、打扮和清洁
- 核心信条：**「言语可以说谎。行为总是表达真相。」** 大多数行为由**潜意识**驱动，不可能被有意识地控制
- 张力越大，人越会做点什么——**「当情境的张力很大时，我们会做很多事情。」** 「站着盯人再大喊」是**只有演员才以为有力**的假演法
- 行为动作**反映角色的精神症候、社会背景、教育背景、经济状况**及对其他角色的真实感受；道具 / 活动必须**适合角色的生活**
- 行为动作必须**对分场目标有帮助**，不是随意摆弄道具；并要**用替代与内心视像个人化**

## 定义
- **行为动作 = 通过使用道具来让我们的意图具体化**（运用道具产生行为）
- 它帮助我们**更好地知道一个角色是什么样的人**；道具的使用让行为自然表现，而**内心活动指引你如何使用它们**
- 与节奏单元/行动的关系：行动通过**语言和行为动作**共同完成；行为动作是行动落到身体上的载体（见 206）

## 核心信条：言语说谎，行为吐真
- 我们常用言辞掩饰真实情感（说谎、欺骗、用谎言保护他人）；即使自认说真话，最真实的反应也会从行为中流露
- 原因：**大多数行为是潜意识驱动的，不可能被有意识地控制**
- 所以道具是「诚实的通道」——内心活动决定了你会怎样使用它

## 为什么必须用（论证与片例）
- **真实现实**：人类面对高度戏剧化情境时，总会做些什么，而且往往是狂热的方式
  - 第一次到喜欢的人住处、单独相处、性张力强 → 你会浏览书架、吃咖啡桌上的软心糖豆、拿易碎物摆弄来缓解不自在，甚至打碎东西或看了不该看的 → **没有行为动作，这些未经刻意安排的时刻就不能发生**
  - 与所爱之人准备沙拉时争吵 → 更有效、更真实的是**继续切沙拉**：报复式地使劲切黄瓜（像在切你发怒的对象）、恶狠狠扯下一颗生菜头（当作警告）→ 温和的「做沙拉」变得带威胁气息，**无须大吼大叫**，即便语调平缓也能表达愤怒（对比：停下来只是站着吼）
- **提供一个「另外的空间」**：张力强时你不可能一直盯着对方眼睛；行为动作给你**合理理由不用面对对方**——搅动壶、卷香烟、预备饮料、穿衣服、修水槽下的水管时非常容易「撒谎」；若被迫面对面直视，不诚实或不自在就会被发现
- **学生吉姆的顿悟**：他一直「在激烈争吵中站着吼叫」，直到与疏远多年的父亲在草坪上争吵时，父亲下意识**把蒲公英拔掉、扯成两段**——吉姆因此笑出来 → 印证「当我们感到害怕、沮丧、愤怒或兴奋时，我们总会做点什么」

## 如何选择 / 叠加 / 个人化（关键）
- **道具与活动要适合角色的生活**：符合其**心理特征、经济背景、当下工作状况、历史、性倾向、所处地域、时代**等；行为动作反映角色的精神症候、社会背景、教育背景、经济状况
- **必须对分场目标有帮助**：行为不是简单随意地摆弄道具（若分场目标是「让你爱我」，向所爱之人扔尖锐东西显然无益）
- **可以改变行为动作**：剧本写的行为动作常只是**建议**；若未被对白限定，就取决于演员的想象（要考虑「角色是个什么样的人」、时间因素、分场目标）。**不要局限于剧本写明的行为动作——行为动作越多，角色表现越多**
- **用替代与内心视像把行为动作个人化**（这样才对你特殊有意义）：
  - 未来恋人家柜子上的照片 → 把照片中人想象成**在情感上对你有作用的竞争者/对手/阻碍你与「作为替代的那个人」发展关系的人**（例：尼尔·西蒙《爱情第二章》乔治捡起珍妮前夫的照片）
  - 演酒鬼、行为动作是喝酒 → 若你真酗酒，把面前的酒想象成你平时喝的某种酒；若不酗酒，可基于**自己的另一种恶习**（毒品/性/睡觉/食物/购物/电脑上瘾——任何无节制行为）
  - 放 CD / 放音乐 → 把这首音乐想成**你与这场戏的替代一起听过**的某首歌，或能唤起与剧本给定感受一致的过去事件
  - 例：《圣女魔咒》德鲁·富勒饰克里斯，角色有枚贯穿多场戏的神秘戒指 → 把它想象成德鲁本人**与女友成对、约定「谁先摘下即关系结束」的皮革手环** → 极易调用「爱与失去爱」的情感
- **叠加 / 反复使用**：同一行为动作可贯穿多场戏 / 多镜头反复使用（如十字架项链、戒指）以形成**人物标志**；行为动作越多，角色的各种表现就越多

## 行为动作如何泄露情绪与潜台词 / 避免「只演情绪」
- **手上忙着一件事、嘴上说另一件事**：温和的「做沙拉」可以承载愤怒；甜言蜜语可以伴随恶狠狠切黄瓜 → 台词与真实意图同时在画面里
- **行为揭示的往往比台词更真**：布拉德·皮特在《致敬》中，剧本未写倒酒，他自备两个高脚杯与道具红酒，开场就从厨房拿酒出来 → 制造不言自明的性张力；他下意识把酒杯拿在胸前、用手指捻动杯脚（「像在捻乳头」，他本人并未预想）→ 通过行为看出他真正在想什么，形成「第一次性经验的紧张感」
- **给角色一个「自在 / 安全的天地」**：巴里·佩珀在《拯救大兵瑞恩》饰神枪手杰克逊，战场恐怖难忍，因他有宗教信仰，让他**始终戴着十字架项链**，恐怖难忍时抚摸/看它获得勇气安宁 → 剧本未写，却让观众更深理解人物
- **用行为动作塑造「幸运 / 幽默」**：马修·佩里在《广播新闻》饰阿龙（用幽默保护自己、幽默也是获胜手段），让他带来一大箱收藏的玩具在整场戏里摆弄 → 观众据此理解他的烦恼、对简的爱、沮丧 / 缺乏安全感；行为越多，笑声越多
- **反向避免「只演情绪」**：不要用「表现愤怒 / 悲伤」这类情绪词驱动表演——那会得到夸张表情；改用**具体的身体事务**（切、扯、擦、拧、倒、点、穿、修），让情绪从行为里渗出来

## 何时用、用多少
- **张力大时必须用**：高度戏剧化情境下的人总会做事 → 行为动作不是装饰，而是避免虚假的必需品
- **随时可用**：可贯穿多场戏 / 多镜头反复使用，形成人物标志（十字架、戒指、手环、玩具）
- **不需要多，但要「有含义」**：一个行为动作只要比「站着吼」真实、且服务于分场目标即可；关键是**由内心活动与个人化想象指引**，而非数量
- **可为剧本带来幽默**：马修·佩里的玩具、布拉德·皮特的泡菜瓶盖、99 美分虾仁杯（《十一罗汉》达斯提）都用行为动作把一个类型化角色变成古怪、有缺点的独特人物

## 与道具调度 / 镜头 / 形体的关系
- **道具调度清单（按功能分类，可直接复用）**：
  - 情感锚点类：项链 / 十字架 / 戒指 / 手环 / 旧照片 / 日记（对应「替代 / 内心视像个人化」，见 202）
  - 发泄 / 攻击外化类：切菜、扯生菜、摔餐具门、用力擦银器（用物件替代高声吼叫）
  - 掩饰 / 给台阶类：倒酒、点烟、穿衣服、搅动饮料、修东西（提供「合理不看对方」的理由）
  - 幽默 / 性格类：玩具、廉价食物（书中「99 美分虾仁杯」）、零食（嚼曲奇饼干的坏蛋）
- **与镜头**：行为动作常发生在手部 / 中近景 → 手部与身体的执行细节见 168 手部表演、166 身体微动作；一个镜头配一个新 doings，并标注它所服务的 action（如「切黄瓜=警告对方别再贬损我」）
- **与形体**：行为动作会体现为言语之外的形体——好表演的判断方法之一是「即便把声音消掉，依然可以让人哭、笑和感动」，因为行动暴露并驱动角色的意图前进

## 示例 / 片例
1. **厨房争吵・借食物应对紧张**：从冰箱拿出一加仑冰淇淋、抓把勺子、把餐具门一甩关上、摆碗、一勺接一勺狼吞虎咽地塞进嘴里，旁边有人对你大吼大叫 → 简单动作对对手演员和观众都含义丰富
2. **心理治疗场景・用纸巾折纸**：病人用柔软易碎的纸巾做复杂折纸（需技巧与高度专注）→ 观众无须台词即理解角色**谨慎克制、内向、难以表露内在情感**
3. **沙拉争吵**：报复式切黄瓜 / 扯生菜头当作警告（同上）
4. **《致敬》布拉德·皮特饰杰德**（害羞、仍是处男、活在魅力父亲阴影下）：分场目标「让你喜欢我」；自备两高脚杯 + 道具红酒 → 制造性张力、捻杯脚泄露真实想法；同场戏「打开一瓶泡菜吃一块」，他死活打不开瓶盖，**淡定地把瓶子递给女孩让她开**（她毫不费力打开，观众笑他的柔弱）→ 勇于即时反应、不怕看起来蠢，创造真实可感的联结
5. **《十一罗汉》布拉德·皮特饰达斯提**：主张角色**一直享受拉斯维加斯的廉价食物**（如 99 美分虾仁杯）→ 用行为动作把典型狡猾骗子变成古怪、有缺点的独特人物
6. **《告密者》罗德·罗兰饰 FBI 特工艾弗森**：交代性场景原本平淡，让他**脱下穿了 24 小时的袜子**放松 → 抓袜子举到对手演员面前、抬脚凑到鼻子前 → 简单行为把两人联系起来、成为亲密关系建立的最初方式；编剧随后把这些行为动作**写进剧本**（观众据此了解塔尔萨邋遢、大胆，艾弗森入行久、喜欢塔尔萨、太臭需要除味）
7. **《拯救大兵瑞恩》巴里·佩珀饰杰克逊**：始终戴十字架项链、恐怖时抚摸 → 给角色一个自在/安全的天地
8. **《广播新闻》马修·佩里饰阿龙**：带一大箱收藏玩具在整场戏摆弄 → 形象立体、易共情；成为他的突破性表演（随后接《老友记》获艾美奖）
9. **神经症示例（选择行为动作要体现角色神经症）**：《疤脸大盗》托尼·蒙塔纳（极端偏执）、《奥赛罗》（过分嫉妒）、《麦克白》麦克白夫人（狂热野心）、《赌城风云》尼基·桑托罗（拿破仑情结）、《时时刻刻》弗吉尼亚·伍尔夫（自杀倾向）

## 常见错误
- 用**真酒**（或真实危险道具 / 物质）；「在表演中永远不要用真的酒」，用道具酒
- 「**站着盯人吼叫**」→ 假；张力大时总要做事
- 行为动作与**分场目标无关**、随意摆弄道具
- 道具 / 活动**不符合角色**（精神症候、经济、教育、地域、时代）
- 未**个人化**（未融入替代与内心视像）→ 无特殊意义
- 只照搬**剧本写明的**行为动作，不敢扩展 / 改变
- **害怕看起来蠢**：出错就跳出角色 / 改台词（应像布拉德·皮特开瓶盖那样即时反应）

## 对 AI 短剧的落地要点
- **把 doings 写进每个分镜的动作描述**：AI 视频不擅长表现抽象情绪，却擅长表现**具体动作**。提示词应写角色**在做什么**（梳头 / 系鞋带 / 喝水 / 切菜 / 擦餐具 / 摆弄玩具 / 绕车钥匙 / 摸项链），而不是「表现紧张」
- **行为动作=潜台词可视化**：让角色手上忙着一件事、嘴上说另一件事（如「一边甜言蜜语一边狠狠切黄瓜」），AI 画面可同时承载台词与真实意图——解决短剧「台词多、画面空」的通病
- **手部 / 道具动作提示词写法**（对应 168 手部、166 身体微动作）：
  ```
  手部动作：___（动词明确，如 shredding lettuce / drumming fingers / twisting ring）；
  物件：___（1–3 件，写明用途与情感含义）；
  幅度 / 速度：___（用力 / 缓慢 / 下意识）；视线：___（不直视对方 / 盯着手里的物件）
  ```
- **道具调度清单（可直接复用）**：给每场戏配 1–3 件**有情感含义的道具**并写明用法与含义——
  - 情感锚点类：项链 / 十字架 / 戒指 / 手环 / 旧照片 / 日记（对应「替代 / 内心视像个人化」）
  - 发泄 / 攻击外化类：切菜、扯生菜、摔餐具门、用力擦银器（用物件替代高声吼叫）
  - 掩饰 / 给台阶类：倒酒、点烟、穿衣服、搅动饮料、修东西（提供「合理不看对方」的理由）
  - 幽默 / 性格类：玩具、廉价食物（如书中「99 美分虾仁杯」）、零食（嚼曲奇饼干的坏蛋）
- **一个镜头一个新 doings，且与分场目标同向**：给每个 doings 标注它所服务的 action（如「切黄瓜=警告对方别再贬损我」），确保行为不是花哨无用
- **不要用真酒 / 危险道具**，也提醒生成时避免违禁内容
- **无台词也能讲清楚**：好表演「消掉声音仍能看懂」——AI 短剧镜头尤应遵守：写完后自问「关掉音频，观众能否从动作看懂发生了什么」
- **人物识别符**：给每个主要角色一个**标志性 doings / 道具**（贯穿多集反复使用，如十字架、戒指、手环），既强化人物一致性，也帮助 AI 在多镜头间维持角色辨识度（见 088 / 004）
- **道具错误可利用**：AI 生成偶有「穿帮」（道具拿不稳 / 打不开）；可像布拉德·皮特开瓶盖那样，把意外**写成角色的即时反应**（淡然递给别人帮忙），转化为真实时刻——在剧本层面预留「允许意外的行为动作」
