# 微表情

## 核心要点
- 微表情(micro expression)=完整情绪表情**压缩到1/25~1/2秒**的版本——Ekman定义
- 成因：有意识压制(conscious suppression)或无意识压抑(unconscious repression)——情绪先于理智漏出来
- 叙事价值：**微表情=角色的真话**，台词和表情都可以演，微表情演不了
- AI视频世代：微表情是让AI角色"像人"的最后一公里，也是翻车重灾区
- 关联 161 AU系统、163 眼神、165 AI提示词

## 七大通用情绪（Ekman七宗罪）
```
快乐 / 悲伤 / 恐惧 / 厌恶 / 愤怒 / 惊讶 / 轻蔑
```
- 跨文化通用——包括与世隔绝的部落，这七种表情全人类的脸都长得一样
- **轻蔑(contempt)是唯一不对称的基本情绪**：单侧嘴角上扬=优越感/鄙视
  - 疯批冷幽默角色的官配表情：别人暴怒他轻蔑=气场碾压

## 微表情的三种产生场景（叙事用途）

### 1. 谎言场景
```
台词："我没事。"
微表情：AU15嘴角下压闪过0.3秒
= 观众收到两层信息，角色深度+1
```
- 观众未必"看到"，但会"感觉到"角色在装——不安感就是这么来的

### 2. 危险识别场景
```
角色看到威胁→恐惧微表情(0.2秒)→立刻换上冷静面具
= 比直接瞪大眼睛演恐惧高级十倍——克制=受过训练的人设
```

### 3. 压抑爆发前的泄露
```
全程冷静的角色，愤怒微表情频率逐渐增加
= 观众潜意识拉响警报：这人快爆了
```

## 微表情 vs 宏表情

| 维度 | 宏表情 | 微表情 |
|---|---|---|
| 时长 | 0.5-4秒 | 1/25-1/2秒 |
| 控制 | 可演 | 几乎不可控 |
| 叙事功能 | 角色想让你看的 | 角色真实感受 |
| AI生成难度 | 低（默认就出） | 高（需要精确描述+运气） |

## AI视频中的微表情实操

### 提示词策略
```
错误："character hides his fear"（AI不懂"隐藏"）
正确：两层描述法
  表层："calm composed expression, steady gaze"
  微泄："+ brief flash of worry crossing the face,
         momentary brow furrow that quickly disappears"
```
- 关键句型："brief flash of X" / "momentary X that fades" / "X flickers across the face"
- 时长控制词："for a split second" / "barely perceptible"

### 生成现实
- AI对"0.5秒内的表情变化"控制力弱——成功率低，**微表情镜头多抽卡**（3-5次）
- 替代方案：**剪辑造微表情**——两段素材的硬切点=人造表情泄露（切帧处观众会脑补过渡）
- H3的[指令]语法可尝试 `[Subtle expression shift]`（141）

## 疯批冷幽默角色的微表情配置
```
面瘫基底：全片AU活动压到最低（表演克制，170）
破功点设计：全片只给2-3次微表情泄露
  → 每次泄露=观众过年
  → "情绪稳定地离谱"的人设=靠零表情+一次破功完成
```
- 用户偏好角色类型：面瘫毒舌/情绪稳定——微表情是这类角色的唯一泄压阀

## 常见坑
- **微表情太长**：超过1秒=不是微表情是普通表情变化，压缩感是灵魂
- **全程微表情**：每个镜头都泄露=等于没有面具，压制与泄露的比例建议9:1
- **AI直译翻车**："hidden anger"会被生成成"满脸怒气"——AI不理解隐藏，只理解描述
- **无视轻蔑的不对称**：对称的冷笑=假，轻蔑必须单侧嘴角
- **微表情无铺垫**：泄露前要有"压制"的上下文，否则观众读不到两层

## 进阶
- **呼吸出卖**：微表情可配一次极轻的呼吸变化（167呼吸表演）=双重泄露
- **眼部先行**：情绪泄露从眼睛开始（AU5/7微动）再到眉再到嘴=符合生理顺序
- **反向微表情**：故意让观众看到"假装的微表情"=角色在演给别人看（局中局）
- **帧级考古**：拉片时逐帧找真实演员的微表情（0.5秒内），建自己的素材词典
