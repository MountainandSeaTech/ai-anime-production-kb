# 背景事件——开拍前发生了什么（工具7）

## 核心要点
- **背景事件（moment before）**：一场戏开始之前（导演喊「开始」之前）在**身体与情感两方面**都已发生的事件，是演员的**起始点**
- 它回答第三个问题——「为什么**在此刻**我如此迫切地需要分场目标？」→ 为分场目标注入**紧迫性与即时性**（时间概念与时间带来的压力）
- 生活里一场戏不会无端发生：背景事件让剧本上的一场戏成为某个**进行中关系的延续，而非起始**
- 影视尤其重要：不按顺序拍、片段短、拍摄缓慢且常中断 → 每场戏都必须能从情感充沛处**独立**开始
- 设计核心：**一分钟规则**（用全部感官在想象中重温「它刚刚发生」）+ 只选**最近发生**或**悬而未决**的事件（见 202 / 206）
- 没有背景事件 = 表演没有起点，是最常见的「一开场就空」

## 定义
- 背景事件 = 在一场戏开始之前所发生的事件，从**外在**（身体）与**情感**（情绪）两方面为角色提供依据
- 作用：驱动你达到分场目标、唤起**强烈的需求与紧迫感**；它给你一个**起点**——为什么来、从哪里来、当下为何如此迫切
- 类比：大幕升起前、场次变换前、离台返回时，人物其实一直在「生活」；背景事件就是把这段被剧本省略的生活补出来

## 三问清单（定位背景事件）
1. **我想要什么？** → 由**分场目标**回答
2. **为什么我如此迫切地需要它？** → 由**阻碍、替代、内心视像**回答
3. **为什么在「此刻」我如此迫切地需要它？** → 由**背景事件**回答（这一问正是背景事件存在的理由）

（三问相互配合；层级为 总目标 ⊃ 分场目标 ⊃ 节奏单元与行动，见 206 / 201。）

## 为什么重要（尤其影视）
- 一场戏**并非从剧本所写的开头开始**：此前必有假设性/暗示性事件推动
- **拍摄不按顺序、各自独立**：电影最后一场戏可能是开机后最先拍的 → 每镜都要能独立进入
- **片段通常很短**（常不超过三页）：来不及从零建立强烈情感 → 每场戏必须从情感充沛处开始
- **拍摄缓慢、常搁置/中断**：背景事件让你能随时、迅速地重建角色的需要与处境

## 如何设计（操作步骤）
1. **锁定事件**：想清楚什么样的个人事件能产生最紧迫的需要（对齐分场目标）
2. **开拍前一刻给自己一分钟**：在想象中体验选定事件，**设想它刚刚发生**
3. **用全部感官重温细节**：
   - 那个特定空间（样子 / 感觉 / 气味）→ 视觉化
   - 另一个人（样子 / 感觉 / 气味）
   - 你和他说过的**确切话语**
   - 用心感受你当时的各种行动和反应
   - 目标：让重新体验把你带到**情感和身体被高度激发**的状态
4. **绝不超过一分钟**：超时=选错了事件；好事件必须**很容易、很迅速地**起作用
5. **验证**：把背景事件当作排练工具去试；**若它不能在一分钟内对你产生影响，就继续尝试别的选择**，直到找到能真正驱动分场目标的那个

## 为什么反对「长时间酝酿」
- 花几小时唤起（如「狗死去那天」）→ ①耗竭演员；②在喊「开拍」前心里积聚「蘑菇云」般情感，**爆炸快、消失也快** → 表演模糊不清
- 根因：与故事/角色需要**无关联**的情感**没有贯穿的行动线或方向**，且爆发的情感不持久

## 选择原则
- **始终用最近发生的个人事件，或过去发生但问题尚未解决（悬而未决）的事件**——「悬而未决会让你的情感在心中不断弥漫」
- **不用问题已解决的事件**：知道结果、确知如何产生 → 只产生机械重复的情感，无驱动力
- 用**当下的问题**：不需酿很久、容易调用相关情感，也不用「头脑游戏」或深挖早已不关心的地方
- 很久以前但在**心理上未完结**的经历，也算「当下事件」（心里还没解决）
- 判断情感是否真解决的唯一办法 = **把它用作背景事件去尝试**
- **不要害怕改变背景事件**：生活出现更痛的新事件（意外死亡、车祸、被甩、发现怀孕、被炒）应立即替换

## 「假使」（What If）
- 适用：生活平稳、无紧迫事件、想不出未解决往事时；**不硬挤、不用已不再关心的旧事**
- 定义：以**深层、确切的个人恐惧**为基础的**想象性事件**，想象它发生的所有细节，仿佛真的发生过
- **必须基于属于你个人的真实、可信的恐惧**：妈妈很健康就不能用她的死作「假使」（对你太不可信、过于遥不可及 → 无效）
- 「可能发生」往往比「实际发生」更可怕（不知会怎么发生，人天性习惯想象最糟）→ 背景事件要**存在各种可能性/潜在偶然性**
- 变体：用**过去真实创伤**，但**不重现过去**，而是想象「**同一事件再次发生、即刻发生**」——第二次是全新事件（你已不同、更戒备、更有经验）→ 阻碍更大、紧迫性极高

## 按分场目标的示例清单
- **「让你爱我」**：刚被分手 / 担心伴侣背着你鬼混（「假使」看到证据）/ 用「失去会改变你生活、你愿花大力气挽回」者的关系破裂「假使」
- **「让你还回属于我的权力」**：被不讲理地炒鱿鱼 / 打斗打输 / 遭遇身体暴力或凌辱 / 被欺骗并受不可挽回的伤害
- **「让你崇拜我（仰慕我）」**：刚被解雇 / 恋人抛弃 / 又搞砸试镜 / 父母为无法掌控之事严斥 / 被拒还让你觉得自己很糟
- **第一次性爱场景**：由真实的**性焦虑与性幻想**驱动（之前想象最深的性不安与最糟性经历并以「假使」再次发生；之后想象问题已赤裸发生并承受结果）
- **冲突场景**：先审视替代与内心故事 → 背景事件应是**将要触发这场冲突的那件事**（如「刚发现对方撒谎」）
- **请求和好**：回忆一件让你深感**做错了、带来深重内疚**的事（不忠、撒谎被抓、攻击、偷窃…），与替代 / 内心故事统一

## 与分场目标 / 节奏单元的衔接
- 链条：**背景事件 → 分场目标 → 节奏单元与行动**（见 206）
- 背景事件提供「在此刻迫切」的**燃料**，分场目标决定方向，节奏单元与行动是每一小步的具体走法
- 每个节奏单元的行动（「让你……」）都从这个起点出发，形成整场戏**不断上升的轨迹线**
- 它必须与**替代、内心视像、场所**协调一致（见 202 / 208）

## 片例
- **《汉娜姐妹》苏珊**：从平淡到爆笑——把**未解决的暴力劫车事件**作背景事件，并同步改内心视像与替代（喜剧要求的内心选择比正剧更绝望/黑暗）
- **《蝴蝶效应》艾米·斯马特饰凯莉**：本人无被抛弃经历 → 用「假使」（发现男友与别人在一起）→ 甜美平和的人变满口脏话、吸毒成瘾
- **《广播新闻》大卫·斯佩德**：用「**压倒骆驼的最后一根稻草**」（最近搞砸《今夜秀》机会）→ 让「心爱女孩爱上对手」具致命杀伤力
- **《私人战争》学生马特饰萨尔维奥**：用任何性挫折事件（性功能障碍 / 尺寸 / 被女人嘲笑床上功夫）→ 掩盖身心无力而过度补偿
- **《再续前缘》苏珊娜·汤普森饰卡伦**：用当下「深冬突然无家可归」的危机 → 体会精神崩溃者的震惊、沮丧、迷失
- **碧昂丝试镜**（作者用自己的死作背景事件）→ 证明「未解决」的痛苦残余仍在潜意识（「父亲从未说过爱我」泪流不止）
- **13 岁起被保姆性侵的学生**演「无良知连环强奸犯」：用保姆作所有受害者的替代、想象「今天再次发生」→ 让每场强暴戏成为有动机的行动

## 常见错误
- 运用背景事件**超过一分钟** = 选错事件
- 选用**问题已解决**的事件（只产生机械重复的情感）
- 硬挤出情感 / 勉强用早已不再关心的旧事
- 「假使」事件**不基于真实的个人恐惧**（太遥不可及 → 无效）
- 背景事件与**分场目标 / 替代不合情合理**
- **孤立酝酿情感**（与故事无关联）→ 无行动线、无方向
- 对角色行为做**道德评判**（绝对不可——角色总有自己的正当理由）
- 忘了**换事件**：出现更痛的新事件时应立即替换

## 对 AI 短剧的落地要点
- **给每个登场镜头写「起始状态 / 前情」**：AI 生成最易出问题的是「人物为什么一开始就处于某种情绪」。提示词里写 `moment before：___（就在本镜之前刚发生的具体事件）`，如「刚刚被分手」「五分钟前刚被老板羞辱」
- **镜头起始状态模板**（可直接套用）：
  ```
  角色：___；本镜前情(moment before)：___（刚发生、未解决）；
  情绪起点：___（低幅度、克制，勿写夸张情绪词）；
  身体起点：___（呼吸浅促 / 姿态紧绷 / 手上正忙的事）
  ```
- **一句话 + 一分钟原则**：背景事件要能被分镜师与模型**一句话说清、一分钟内点燃**；需要长篇铺垫的设定直接替换
- **逐镜独立给前情**：AI 短剧逐镜 / 逐段生成，天然对应「每场独立」→ **每一镜都独立标注 moment before**，不依赖上一镜延续
- **用「未解决」而非「已了结」**：给角色设定「悬而未决的痛点」（未回的债、没说出口的道歉、没证实的分手）→ 情绪张力自然渗出，AI 表演不空洞
- **把「假使」转成生成提示**：写 `what-if：假使___（基于角色真实恐惧的想象事件）`，如「假使她的爱人此刻正在别人床上」——比直接命令「悲伤」更有效
- **冲突 / 打斗镜头必写「引爆点」**：前情要写清触发冲突的事件（如「刚刚发现对方撒谎」），否则打斗显得无理由
- **合规提醒**：书中大量背景事件以性、暴力、创伤为例；转写 AI 提示时按需**抽象化为情绪触发**，避免生成违规内容

- 铁律：**只选最近或悬而未决**、**一分钟内点燃**、**绝不评判角色**
