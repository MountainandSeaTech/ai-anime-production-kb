# 冲击帧禁用清单——什么时候绝对不能闪

## 现象

- 在文戏情绪点（哭戏 / 告白 / 死亡）里闪。
- 在悬念 / 恐怖铺垫段闪。
- 在闪回 / 梦境里闪。
- 在每场打戏的第一击就闪。
- 在片头片尾字幕段闪。
- 成片里出现"不该闪的闪"，需要逐帧回头铲。

## 根因

冲击帧是"大事发生"的标记——**在没有大事的地方闪，等于训练观众忽略它**。禁用清单和预算表同等重要。五类绝对禁用的禁因：

| 场景 | 禁因 |
|---|---|
| 文戏情绪点（哭戏/告白/死亡） | 冲击帧的"炸"会撕碎情绪的"渗"——情绪戏用缓镜不用闪帧 |
| 悬念/恐怖铺垫段 | 冲击帧是"释放"，悬念需要"悬置"——一闪就把气放了 |
| 闪回/梦境 | 时态混乱——闪回自带滤镜语言，冲击帧会把观众拽回现实 |
| 每场打戏的第一击 | 第一击是"试探"，给冲击帧＝提前亮底牌（首击只配顿帧） |
| 片头片尾字幕段 | 冲击信息等级错位——字幕不需要"打击感" |

三类谨慎使用（规则）：

| 场景 | 规则 |
|---|---|
| 喜剧打击 | 可用但优先⑤文字型/夸张型——正剧冲击帧别混进来 |
| 远景命中 | 冲击帧在远景里几乎不可读——要么切近景再闪，要么不闪 |
| 慢动作中 | 慢动作本身已是"时间断裂"，再叠冲击帧＝断裂套断裂，仅必杀特写允许 |

与贬值律的联动（301）：每一次禁用场景的误用，都在**消耗合规场景的威力**——乱闪一次＝高光帧贬值一成。

## 错误 vs 正确示例

- 反面：文戏情绪点用反色闪帧 → 正面：用缓镜（情绪戏不用闪帧）。
- 反面：文戏误用冲击帧后试图硬留 → 正面：把反色帧改为"去饱和定格帧"（保留时间断裂、去掉画面炸裂）。
- 反面：每场打戏第一击给冲击帧 → 正面：首击只配顿帧。
- 反面：远景命中直接闪 → 正面：切近景再闪，或干脆不闪。

## 后果量化

- 每一次禁用场景的误用，都在**消耗合规场景的威力**——乱闪一次＝高光帧贬值一成。
- 全片冲击帧整体失去标记功能。
- 具体废片率 / 重生成次数 / 成本（待估）。

## 修法清单

剪辑审查：
- □ 问句：这处冲击帧对应的"大事"是什么？——答不上来即删

误用修复方案：
- □ 发现成片里有"不该闪的闪"：逐帧定位→移除插入帧→用相邻帧补齐时长→检查音轨是否需要重对
- □ 文戏误用冲击帧的抢救：把反色帧改为"去饱和定格帧"（保留时间断裂、去掉画面炸裂）
