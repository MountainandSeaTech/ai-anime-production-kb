# 真人写实风的冲击帧边界——本剧应用口径

## 现象

- 纯日式黑白闪直接贴到本剧画风上，会**画风崩坏**。
- 抽象型（纯几何 / 放射线）在写实画面里像贴上去的补丁。
- 文字型（拟声字）在写实正剧里无处容身。
- 冲击帧一旦露出"动画感"，就破坏真人写实底色。

## 根因

- 本剧画风＝真人写实（AI 写真级）——纯日式黑白闪直接贴上去会画风崩坏。
- 口径：**画面断裂降级为"画质突变"，色彩断裂改造为"单通道保留"**——保住冲击功能，藏起动画感。

## 错误 vs 正确示例

可用 / 改造 / 禁用表（原版动画技法 → 本剧改造方案）：

| 类型 | 本剧判定 | 改造方案 |
|---|---|---|
| ①反色型 | 改造后可用 | 不做纯反相，改"去饱和+对比拉满+保留单一主题色"（如血色红） |
| ②剪影型 | 谨慎可用 | 剪影做半透明化处理（60-70%不透明度），叠在原画面上而非替换 |
| ③抽象型 | 禁用 | 纯几何/放射线在写实画面里是补丁 |
| ④插画型 | 改造后可用 | 不画风突变，改"同一写实风格下精度暴增"（皮肤纹理/汗珠级特写静帧） |
| ⑤文字型 | 禁用 | 写实正剧无拟声字容身之处 |

## 后果量化

- 直接贴原版动画技法 → 画风崩坏，破坏全剧写实一致性。
- 改造不当 → 冲击功能与画风二选一，退回重调。
- 具体废片率 / 重生成次数 / 成本（待估）。

## 修法清单

与真气显形四级制的对齐（290）：
- □ L1 无形攻击＝**不给冲击帧**，只给顿帧+震动（无形之物没有接触面可闪）
- □ L2 微形＝可用①改造版（去饱和闪）
- □ L3 显形（特批金龙帧）＝可用②半透明剪影——且与龙形显形**同帧**出现，冲击帧即显形帧，一鱼两吃

本剧冲击帧预算（在 301 总预算上再收紧）：
- □ 单集：①改造版≤6次，②剪影≤2次（其中 1 次保留给降龙掌高光）
- □ 每集必须有**至少一场打戏完全无冲击帧**——用纯顿帧+震动+音效完成，保住写实底色

本剧冲击帧提示词（②剪影型静帧生成用）
```
高对比剪影，人物纯黑轮廓，单一深红底色，边缘有热浪扭曲纹理，
半透明叠加质感，写实人体结构，无卡通化。
负向：anime style, flat colors, speed lines, comic book, cel shading
```
