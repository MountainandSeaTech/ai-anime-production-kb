# 平台审核红线与规避写法

## 核心要点

- 合规是**准入线**不是优化项：不过审等于整片白做，成本与工期 100% 沉没——所以它必须排在验收之前，而不是"最后再看"
- 红线分三类：**政治法律类**（碰不得，无改写空间）、**生理下限类**（血腥/色情/自伤，靠手法规避）、**权利类**（名誉/肖像/著作权，靠化名改设定规避）
- 规避的第一手段是**虚构化 + 去具体化**：阵营/宗教/国家全部虚构且不对号现实；危险技术只写概念与后果、不写步骤参数；复仇走因果清算而非血腥私刑
- 三条本库长期硬约束：**全员成年**、**反赌反贷立场鲜明（不美化投机）**、**不制造性别对立**
- 交付前以**平台当日生效**的审核标准为准；本条目给通用口径与改法，不承诺"保证过审"

## 详细内容

### 一、八类平台红线（碰不得）

| # | 类别 | 常见触发表现 | 本库对策 |
|---|---|---|---|
| 1 | 违反宪法基本原则 | 制度性否定、颠覆性表述 | 世界观全部架空，不映射现实制度 |
| 2 | 危害国家安全 / 泄露国家秘密 | 影射现实机构、军事细节 | 机构名与职能全部虚构，不写真实编制与装备参数 |
| 3 | 破坏民族团结 | 民族/地域标签化丑化 | 族群虚构，冲突写成"势力立场"而非"人群属性" |
| 4 | 邪教与封建迷信 | 宣扬教义、迷信治病 | 教会/宗门全虚构；占卜类作品走"反赌内核"，不美化投机与迷信效力 |
| 5 | 淫秽色情与低俗 | 身体局部特写、性暗示台词、屎尿屁 | 擦边只留光影与氛围，不写身体局部；控制脏话与低俗段子占比 |
| 6 | 暴力血腥与教唆犯罪 | 断肢、穿身、内脏、作案教程 | 见第二节改写表；危险技术只写概念不写教程 |
| 7 | 诱导自伤自杀与危险模仿 | 自伤细节、危险挑战 | 不写方法与过程；AI/克隆类题材不做"自我否定/自毁"诱导 |
| 8 | 侵犯他人合法权益 | 影射现实人物、搬运素材、未授权音乐 | 现实人物化名+改设定、不恶意丑化；素材与音乐用可商用授权 |

### 二、十类高危题材的虚构化改写

| 题材 | 高危点 | 改写手法 |
|---|---|---|
| 打斗 / 战斗 | 血腥、断肢、兵器穿身 | **木质训练假人替代活人**；断肢→木屑/护盾碎裂；穿肩穿胸**一句带过不写过程**；战斗全程搞笑化 |
| 复仇 / 处刑 | 私刑、血腥清算 | 走**因果清算**（反派自食其果、机关反噬），不写处决过程 |
| 未成年相关 | 感情线、身体描写 | **全员成年化**：学院改 18 岁毕业舞会；无未成年人感情线、无身体描写 |
| 女性角色 | 雌竞、擦边、被物化 | **不雌竞 + 女性互助**；恋爱走双向尊重、无强制；擦边控制在光影氛围层 |
| 赌博 / 贷款 / 投机 | 美化投机、写操作步骤 | **反赌反血贷立场鲜明**（给反面结局）；只写概念与后果，不写可操作参数 |
| 现实政治 / 宗教 | 对号入座、教义传播 | 阵营/行会/教会/国家**全部虚构**且不对号现实；不涉现实政治与宗教议题 |
| 现实人物 / 时事 | 名誉权、肖像权、恶意丑化 | 化名+改设定；不恶意丑化；不调侃现实事件与新闻 |
| 技术教程类（黑客/制毒/开锁） | 可操作性 | **只写概念、后果与代价，不写步骤、参数、配方** |
| 引战梗 | 性别/地域/阶层对立 | 不做"XX 大战 XX"式对立梗；对立写成"立场差异"而非"人群标签" |
| 外链与软广 | 引流、广告、吐槽平台 | 片内与文案**不含外链、二维码、联系方式、平台吐槽**（也是常见驳回原因） |

### 三、上线前自检清单（逐项打勾，任一"否"不得交付）

```
□ 全员成年？无未成年感情线／身体描写？
□ 无血腥过程（断肢／穿身／内脏）？已改为木屑、碎裂或一句带过？
□ 无擦边（身体局部特写、性暗示台词）？低俗段子已压到安全占比？
□ 现实国家／宗教／政治已虚构化，无对号入座？
□ 赌博／贷款／投机无美化、无操作步骤，且立场为反？
□ 无现实人物影射、无恶意丑化？
□ 无性别／地域／阶层引战梗？
□ 无自伤自杀与危险行为的可模仿描写？
□ 黑客／制毒类只写概念，未写步骤与参数？
□ 片内与文案无外链、二维码、联系方式、平台吐槽？
□ 结局走因果清算，而非私刑复仇？
```
