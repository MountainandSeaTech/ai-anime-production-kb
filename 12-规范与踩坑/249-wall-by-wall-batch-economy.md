# 按墙拍摄与批次生成经济学

## 核心要点
- 按墙拍摄：同一面墙拍完所有景别（由松到紧）再换下一面墙；机位角度超15°就要重打光（约2小时），四次=一天报废。
- 外景就近：上午拍完一两小时内搬到下一处，省的就是钱。
- 通告单是圣经：场景提示、场号、角色编号、页数（以1/8计）、演员时间表、道具说明、未来数日进度预告。
- AI迁移：同场景同角度批次生成，锁定seed与灯光参数一次出全。

## 详细内容

### "按墙拍摄"原理
片场最贵的不是摄影机转动，而是**重打光**：机位角度改变超15°就要重打光，一次约2小时；一天只容得下约四次，四次=一天报废。因此：

- 先拍完对墙A的**所有景别**，由松（全景）到紧（特写），再整体转向墙B；
- 少动基本机位，灯光只微调不推翻；
- **360°环绕布光极贵**：《十二怒汉》首个8分钟镜头用13个机位点+吊臂约11个左右位+8个上下位，布光7小时、4条才过；
- 大转向**利用午餐时间换墙**——置景组早一小时开饭，演员回来时新墙已布好光。

### 外景就近原则
外景地选择标准之一是地理位置成串：上午拍完一处，一两小时内搬到下一处，当天就能开布光。搬迁=纯损耗，省的就是钱。

### 通告单：把经济原则写成文书
按墙拍摄靠前一夜发出的通告单（call sheet）落地。它是剧组的圣经，要素：

| 要素 | 说明 |
|---|---|
| 场景提示 | INT/EXT - 地点 - D/N（内/外-地点-日/夜） |
| 场号 | 剧本场次编号 |
| 角色编号 | 演员以编号调度 |
| 页数 | 以1/8页计；一天拍3页，120页剧本≈40天 |
| 演员时间表 | 车接→报到→化妆→到场分列 |
| 光替/群演调度 | 到场时间与编组 |
| 道具特殊说明 | 当日非常规道具 |
| 未来数日进度预告 | 各部门提前准备 |

配套纪律：收工前**预走次日第一个镜位**；睡前复盘三问：拍到想要的了吗？要补备用机位吗？要重拍吗？

### 一致性校验 = 场记职能
按墙拍摄把同一场戏拆在不同时段拍，接戏风险上升。场记核对：动作接戏点、视线方向、服装连续性。少了这道校验，省下的布光时间会加倍赔进剪辑室。

## 关键参数 / 模板 / 清单

### AI迁移：批次生成经济学
传统布光成本对应AI流程的**提示词与参数调定成本**——每换角度、氛围、光照描述就要重新试错。迁移规则：

1. **按墙拍摄 → 同场景同角度批次生成**：锁定seed与灯光参数，把某背景某机位的全部镜头（由松到紧）一次出全，再切下一角度。减少提示词反复重调就是省钱。
2. **360°环绕镜头在AI中成本也极高**：环绕运镜一致性压力最大，翻车率最高。尽量拆分为固定机位剪辑模拟，或利用已有素材拼接。
3. **外景就近 → 同场景多镜头在一次会话/固定seed中批量输出**：跨会话重建场景气质=跨天搬迁。
4. **通告单 → 每日生成任务单**：场景标识、镜头编号、出场角色、景别序列、所需资产、参数锁定项、次日首个镜头预告。
5. **AI场记**：动作接戏点、视线方向、服装连续性、光照方向、背景陈设，批量生成后集中验。
6. **预走次日第一个镜位 → 提前锁定次日首段提示词**：次日开工直接生成，不冷启动试错。

### 一日生成流程模板
锁定当日场景/参数 → 按墙批量生成（松→紧）→ 场记式一致性校验 → 午休时切墙 → 下午批次 → 16:30后不开新大段落 → 预锁次日首个镜头提示词 → 看样片验收 → 复盘三问。

## 备注
- 按墙拍摄与情绪接力存在张力：情绪密度高的戏优先保连续，过场戏优先保批次。
- 批次生成不是"一次跑几百张再挑"——前提是**先想清楚这面墙要哪些景别**，清单先行，无清单的批量生成只是抽签。

## WAN3.0 校准（2026-10-20）

- WAN3 30s 原生一次可覆盖更多景别，批次策略从"锁 seed 出一墙景别"变为"锁场景出完整 30s 段落所有景别"：一个场景从松到紧的全部景别可以在同一段 30s 原生输出中连续覆盖，减少跨 seed 重建场景气质的损耗。
- 本地编辑版本归档：WAN3 本地编辑产物（含 edit 版本、patch 文件、range 标注）与原始生成版本一并纳入批次归档目录，命名规范见 010 命名规范校准节，按场景/批次号整理便于回看与跨镜复用。
