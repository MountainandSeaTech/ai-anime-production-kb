# AI 视频生成常见失败与修复

## 现象

- 融指 / 多指：手部多出一根手指、手指粘连。
- 变脸 / 脸漂：镜头间或镜头内人物面部偏移、换人。
- 背景融化 / 背景漂移：背景随镜头运动糊化、错位。
- 闪烁 / 抖动：画面高频闪烁或抖动。
- 主体不动 / 动作不响应：提示词写了动作，人物却几乎不动。
- 多人面部崩坏：同框多人时面部集体失真。
- 文字 / 名牌乱码：画面中的文字、招牌、名牌生成成乱码。
- 基本判断：失败有规律，多数失败可从提示词 / 首帧 / 参数三处修。

## 根因

逐病成因：
- 融指 / 多指：手部细节高频出现 + 动作幅度大。
- 变脸 / 脸漂：侧脸 / 背身转头 / 动作幅度大。
- 背景融化 / 背景漂移：镜头运动 + 复杂背景。
- 闪烁 / 抖动：风格冲突 / 参数过高 / 时长过长。
- 主体不动 / 动作不响应：提示词动作描述弱 / 动态程度太低。
- 多人面部崩坏：多人面部模型识别困难。
- 文字 / 名牌乱码：模型对文字生成能力弱。
- 流程层：跨镜一致性问题不是单镜问题，是流程问题。

## 错误 vs 正确示例

原文给出的对照（其余条目原文未提供正反写法对照）：
- 风格混用：反面「赛璐璐+写实光影」混写 → 正面 风格关键词统一。
- 动作词：反面「拿着」 → 正面 强动词「挥斩」「突进」。
- 手部约束：反面 无负向约束 → 正面 负面词加 `no extra fingers, no morph`。
- 文字：反面 在视频生成阶段要求文字 → 正面 文字后期叠加（PS / 剪映加字幕层），招牌 / 名牌用纯色块代替、后期贴字。

## 后果量化

- 同一镜头跑 4-6 次取最优是常态，预算要预留。
- 「再跑一次说不定就好」是赌博，不修参数只重跑，成本随次数累积。
- 不修则废片率与被弃镜头数上升；具体废片率 / 重生成次数 / 成本（待估）。

## 修法清单

修复优先级（成本由低到高）：
1. □ 改提示词（成本最低）
2. □ 换首帧 / 角色卡切片
3. □ 调参数（动态程度 / 影响力）
4. □ 换 seed 多跑取优
5. □ 拆镜 / 改镜头运动
6. □ 放弃该镜改方案

逐病修法：
- □ 融指 / 多指：减小手部动作幅度、让手定格；首帧把手放在身后 / 被袖遮住；负面词 `no extra fingers, no morph`；换 seed（有些 seed 对手部友好）；实在修不了：拆镜，关键帧单独用图生图修手。
- □ 变脸 / 脸漂：用正面 / 3/4 角度首帧；减小头部转动，用切镜代替转头；首帧用角色卡正脸切片；多跑取优，挑脸不漂的一版。
- □ 背景融化 / 背景漂移：简化背景，用纯色 / 简单几何；镜头改为 static、主体动；motion brush 锁定主体运动区、背景不动；首帧背景越简单越好。
- □ 闪烁 / 抖动：时长缩短到 5s 以内；动态程度降到 0.4-0.5；风格关键词统一，别「赛璐璐+写实光影」混；后处理轻微抗闪烁。
- □ 主体不动 / 动作不响应：动作词用强动词「挥斩」「突进」而非「拿着」；提示词影响力提到 0.8+；动态程度提到 0.6-0.75；检查动作是否与镜头运动冲突。
- □ 多人面部崩坏：分角色单独生成、后期合成；减少同框人数到 ≤2；多人场景用背影 / 远景；关键正面镜头分批生成。
- □ 文字 / 名牌乱码：文字后期叠加（PS / 剪映加字幕层）；不在视频生成阶段要求文字；招牌 / 名牌用纯色块代替，后期贴字。

纪律（备注）：
- □ 修不了就拆镜或换 seed，别在一版上死磕
- □ 同一镜头跑 4-6 次取最优是常态，预算要预留
- □ 「再跑一次说不定就好」是赌博，要改参数再跑
- □ 跨镜一致性失败修单镜没用，要回到角色卡层修
- □ 留一份「失败样本」文件夹，积累到一定量后总结规律

WAN3.0 校准（2026-10-20），WAN3 特有故障五类，旧模型故障列表（1-7）仍适用：
- □ ① 原生音画不同步：WAN3 原生音画对齐精度高于旧模型，但长段（≥20s）偶发音频延迟或抢拍；验收时对比波形与口型 / 动作锚点，偏移超 0.1s 触发本地编辑重对齐。
- □ ② 本地编辑提示词残留污染：用 WAN3 本地编辑对局部修帧时，原整段生成 prompt 可能被模型残留记忆带入编辑段，导致风格或动作串味；编辑前单独写 prompt patch 文件，编辑后单独验收被修改段。
- □ ③ 多模态参考权重失衡：WAN3 支持图像 / 视频 / 音频多模态参考同时输入，权重分配不当会出现"某一参考盖过主体动作"；建议主参考权重 0.6，辅参考各 0.15-0.2。
- □ ④ 30s 长段中间漂移：WAN3 30 秒原生后段（15s 起）角色身份 / 背景偶发漂移；可在 15s 处加一个风格锁 prompt 片段，或拆为两段 15s 各加本地编辑衔接。
- □ ⑤ 音频 22-30s 处自发截断：WAN3 原生 30s 音频尾段偶发自发截断或音量骤降；验收时必听尾 8s，截断则用本地编辑补接静音或重跑音频轨。
