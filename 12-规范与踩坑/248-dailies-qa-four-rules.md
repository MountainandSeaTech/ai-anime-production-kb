# 看样片四规则与走神测试

## 核心要点
- 看样片只回答一个问题：我们想要的东西是否落实在了银幕上；接受单光号印片的粗糙，只查戏剧冲击力。
- 走神测试：监看或看样片时自己走了神=哪里出了差错，注意力分散=有问题。
- 四条规则：不信内部笑声；拍摄难度大≠镜头好；技术错误别毁掉判断；存疑时隔两三天盲评。
- 缺陷补救顺序：先重拍 → 换镜头语言 → 调色/滤镜 → 配乐兜底。AI验收迁移：盲评去参数、隔日复审、序列检验、脸崩重生成不用调色救。

## 详细内容

### 看样片的目的
样片是单光号印片（one-light）的粗略产物，接受其粗糙——看样片只为回答：**我们想要的东西是否落实在了银幕上**。评判维度只有一个：戏剧冲击力在不在。

看样片要求分裂心态：既要认可这部电影，又要对失败直言不讳。现场以为完美的镜头，样片里可能令人失望；现场觉得不行的，样片里可能很棒。警惕情绪污染判断：今天不顺别把怨气撒给昨天的样片，今天克服了困难也别过度肯定。

### 走神测试
现场监看时导演与演员"同演"——默念台词、感受动作情绪。**如果自己走了神，一定是哪里出了差错，必须重拍。** 看样片同理：注意力分散=镜头有问题。走神不是观众的错，是镜头的错——这是成本最低的质检仪器。

### 四条规则
1. **千万别相信笑声。** 内部人员的笑声是"乐队笑话"，与真实观众无关。镜头终归要在前后镜头之间接受检验。
2. **拍摄难度大≠镜头好。** 观众不知道也不在乎你花了三天布光。
3. **别让技术错误毁掉判断。** 评判标准始终是"它有生命力吗？"技术无瑕与表演更好之间，永远选后者。
4. **存疑时隔两三天再看，撕掉条数标签盲评。** 不带着"这是第几条"的现场记忆做判断。兜底心态："我可能是错的。那又怎样？拍电影就是冒险。"

### 缺陷补救顺序
演员演不出温柔，靠镜头？滤镜？音乐？吕美特"把所有的方法都试了一遍"——仍可能救不回最基本的东西。补救有优先级，越靠后越接近遮羞布：

| 顺序 | 手段 | 性质 |
|---|---|---|
| 1 | 重拍 | 从源头修复，最有效 |
| 2 | 换镜头语言 | 用摄影机粉饰缺陷 |
| 3 | 调色/滤镜 | 表层修饰 |
| 4 | 配乐兜底 | 最后手段 |

### 录像带行业的警告：均匀即乏味
技术人员会把**安静戏推响、喧闹戏压小**，动态被抹平，"均匀到乏味"——与AI音频"一键响度最大化"同病。验收须保留安静与爆发的动态差。

## 关键参数 / 模板 / 清单

AI生成镜头验收清单：
- [ ] 走神测试：完整播放一遍，注意力在哪一秒飘了？飘了=该镜头有问题
- [ ] 序列检验：放进前后镜之间播三遍，单张漂亮不算数，必须在序列中成立
- [ ] 盲评：导出时去掉生成参数信息（模型/seed/提示词/第几批），只看画面
- [ ] 隔日复审：存疑镜头搁置两三天后重看再定生死
- [ ] 规则一自查：这个"笑点"是内部语境产物，还是对陌生观众也成立？
- [ ] 规则二自查：是否因为"这条提示词调了很久"而高估了镜头？
- [ ] 规则三自查：有没有因小瑕疵否掉一条有生命力的镜头？

缺陷补救迁移：
- 表情/脸崩 → **重生成**，不要试图用调色救（调色救不了结构缺陷）
- 气质不对 → 换镜头语言重生成；色调不统一 → 调色归拢；情绪不足 → 配乐兜底

## 备注
- 走神测试须保持"同演"状态而非挑刺状态；带checklist逐帧挑错反而测不出走神点，两种模式分开。
- 盲评需流程支撑：生成时即分离"画面文件"与"参数文件"，否则无法剥离参数记忆。

## WAN3.0 校准（2026-10-20）

- WAN3 本地编辑段需单独验收被修改局部与前后段音画连贯性：本地编辑可能破坏被改点与前后段的光影/动作/音频接缝，验收除走神测试外，必加"接缝检查"——被修改点前后各 2s 拉慢逐帧看音画连续性、角色身份是否跳变、音频波形是否有断点。
