# Popping 核心技术：Hit / Wave / Isolation / Boogaloo

## 核心要点

- Popping 的原子单位是 **Pop（也称 Hit）**：在拍点上把某一肌群**瞬间收紧再立刻放松**（等长收缩），视觉上像电流/冲击波穿过身体——一拍一个、干净、回弹
- **Wave（电流/波浪）**：力量沿关节链逐节传导，**同一时刻只有一个关节在动**，像能量在体内流动；做假在"整条胳膊一起动"
- **Isolation（隔离）**：一个部位动、其余部位绝对不动（fixed point 定点练习），制造"身体分区"错觉
- **Boogaloo**：身体各部位（头-肩-胸-胯-膝）做方向各异的滚动 roll，身体像被拆散的万向节，带流动感和"软骨"错觉
- Popping 是 AI 视觉上**最容易出超能力感**的舞种：肌肉顿挫≈冲击波附体，电流≈能量传导，天生适配"被技能击中/操控/通电"的表演
- 与冲击帧/顿帧语法（292–308）天然同构：**pop 落点＝音乐重拍＝剪辑点/冲击帧候选点**

## 详细内容

### 一、Pop / Hit：一个动作的肌肉说明书

**做法**：拍点前放松 → 拍点瞬间（约 1–2 帧内）该肌群猛收紧 → 立刻松开回松弛。不是移动位置，是在原地"炸"一下。

**可 pop 的部位与视觉表现**：

| 部位 | 发力 | 画面可见 |
|---|---|---|
| 手臂 pop | 三头/前臂瞬间绷紧，臂微外弹 | 最明显，入门先练 |
| 胸部 pop | 含胸位猛挺胸扩背 | 上身"撞"一下，冲击波感最强 |
| 颈部 pop | 颈侧/后颈收紧，头微点 | 机械开关感 |
| 肩/背 pop | 肩胛后夹 | 胸 pop 的加强 |
| 腿 pop | 膝盖微屈位大腿绷紧打直 | 整个人被"顶"高一瞬 |
| 胯/核心 pop | 腹肌收紧 | 近景可见 |

**pop 的密度用法**：
- 基础：每个重拍（1、5）全身 pop 一次
- Groove：每拍都 pop（连续小电流）
- Fill：跟鼓手密集加花，一拍双 pop（"hit on the &"）
- **重拍大 pop、弱拍小 pop**——力度分层是高手与新手的区别（对比冲击帧贬值律301同理：全用大 pop 等于没有 pop）

### 二、基础练习舞步（也是镜头里的基础动作）

- **Fresno（弗雷斯诺步）**：popping 第一课。左右移动重心，当前侧手臂前伸，**每拍在伸臂侧 pop 一次**，两拍换边；节奏 1pop-2换-3pop-4换
- **Walk Out（走出去）**：从站姿开始，手先向斜前方"探"出→身体拧转跟出→脚迈出，过程分步+每步 pop，像木偶被线牵着走
- **Neck-O-Flex / Twist-O-Flex**：身体分节旋转（头先转→肩→胸→胯逐节跟随），每节到点 pop——制造"分段拧转"的诡异流畅
- **Master Flex**：更大幅度的分节波浪转身
- **Pose**：在拍点上突然摆出夸张造型并 pop，停顿 1 拍——"人形雕塑"展示

### 三、Arm Wave（手臂电流）逐关节链

标准 7 节点传导（以双臂连成一条横线为例）：

```
① 指尖翘起（手指压腕）
② 手腕下沉/上提
③ 肘尖抬起（手腕回落同时肘起——交接帧）
④ 肩耸起（肘落）
⑤ 力量过胸：对侧肩起
⑥ 对侧肘起
⑦ 对侧腕→指尖送出，波浪从另一手指尖流出
```

- **铁律**：波峰到达的关节处于高位/弯曲位时，**前后关节必须是平的**；像鞭子/多米诺，不是波浪手整体起伏
- 速度：慢波一个来回 8 拍（抒情/超能力蓄能），快波 2–4 拍（电击/中招）
- **Body Wave（身波）**：踝→膝→胯→腹→胸→颈→头依次前送再回，像能量从脚灌到头顶或反向"从头漏到脚"
- 分镜价值：**电流方向可以被镜头设计成"能量入口"**（手被抓住→波传向身体→眼瞳亮起），与特效光轨叠加即"附体/传功"

### 四、Isolation（隔离）与定点魔法

- **做法**：设定一个"固定点"（伸出的手贴在假想墙上），身体左右移动/蹲下/转身而手纹丝不动
- 常用部位隔离：头（身体动头不转）、胸（胯不动只胸绕圈）、胯（上身不动胯画圆）、手
- **视觉错觉系**：
  - **Ticking/Strobing（频闪）**：把一个连续移动切成一串被 pop 断开的极短静止，像灯光频闪下的动作
  - **Dime Stop（一毛钱急停）**：任何移动都在拍点上瞬间完全静止、零余动——机械舞质感的核心
  - **Hitting Pose**：移动→拍点定格造型→下一拍打散再成型
- AI 提示要点：`dime stops on every beat, zero drift during holds`，并明确"hold 期间身体不动，只有衣服/灰尘有余动"

### 五、Boogaloo（布加洛滚动）

- **核心动作 Roll**：头/肩/胸/胯各自画圆，且**相邻部位方向可相反**（左肩前滚时右肩后滚），再把这些圆串成全身波浪
- 标准全身 boogaloo：头 roll → 双肩反向 roll → 胸推出 → 胯带出 → 膝盖绕圆，8–16 拍一圈
- **Walk-Out + Roll**：boogaloo 风格移动的基础组合
- 质感：看似柔软无骨、动作却卡在拍上——"水做的机械"
- 与 Locking 区别：boogaloo 不停住、不表演、无笑容指令；是连续的流动+隐性 pop

## 关键参数 / 模板 / 清单

### Pop 逐拍锚点表（动画/K帧）

| 拍 | 身体 | 帧表现（30fps） |
|---|---|---|
| & of 4 | 放松预备 | 松弛 |
| 1（重） | 肌群收缩 | 第1–2帧绷紧外弹 |
| 1的第3帧起 | 立刻放松 | 回弹余动 2–3 帧 |
| 2–4 | 小 pop 或移动 | 弱处理 |
| 5（重） | 大 pop（可换部位） | 同1 |

### 提示词模板（Popping 段）

```
popping dancer, sharp muscle hits on every beat, 
[arm/chest/neck/leg] pop then instant release, staccato electric rhythm,
[选项A: continuous arm wave traveling fingertips-wrist-elbow-shoulder-chest, only one joint moving at a time]
[选项B: body isolations, [chest/hips/head] moving independently, rest of body locked]
[选项C: boogaloo rolls, body parts rolling in opposing directions, fluid yet on beat]
dime stops, slight overshoot then settle only on clothing, 
static frontal camera (见326), [场景]
负向：wavy noodle arms, constant motion without stops, soft ballet arms, 
whole arm moving together on wave, jointless limbs, slow drift during holds,
trembling shake, random convulsion
```

### Popping 段验收清单

- [ ] 每个重拍有可辨识的"收-放"顿挫，且位置不变（是震动不是位移）
- [ ] pop 有大小层级，重拍重、弱拍轻
- [ ] Wave 逐节传导，单帧截图能指出"波峰在哪个关节"
- [ ] 隔离段只有一个部位在动，其他部位零漂移
- [ ] Dime stop 真的零余动（允许衣摆/帽绳滞后 1–2 帧）
- [ ] 全程重心稳定（popping 很少大跳大移，位移靠 walk out/fresno）
- [ ] 与特效叠加时：光/电传导方向与 wave 方向一致，pop 帧与特效冲击帧对齐

- Popping 1970s 末发源于加州弗雷斯诺（Fresno），Electric Boogaloos 舞团奠基，故基础步名 Fresno
