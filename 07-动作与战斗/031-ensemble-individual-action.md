# 群戏个体动作编织

## 核心要点
- 群戏（多人同框）张力来自**个体动作的错位编织**——不是所有人一起动
- 黄金法则：**分层动**——主角做主张力动作，旁人做微反应，反派做对位动作
- 群戏最大坑：所有人一起动=糊成一团=没焦点=张力全散
- 错位=观众视线有落点=揪心有锚

## 群戏的分层动作模型

| 层 | 角色 | 动作类型 | 作用 |
|---|---|---|---|
| 主层 | 主角/交锋双方 | 主张力动作（蓄势/爆发） | 张力核心 |
| 反层 | 反派/对手 | 对位动作（锁定/逼近） | 对抗压力 |
| 反应层 | 旁观者/同伴 | 微反应（屏息/惊/退） | 情绪放大镜 |
| 环境层 | 背景/群众 | 极微动/静止 | 氛围底座 |

> 四层同时存在但动作幅度递减——主层最大，环境层几乎不动。这样视线聚焦主层，但有层次。

## 错位编织的三种节奏

### 1. 镜像对位（对峙群戏）
- 主角蓄势→切反派对位蓄势→切旁观屏息→回主角爆发
- 双方动作镜像（都搭武器、都凝视）=势均力敌
```
主角搭刀（0.5s）→ 反派搭刀（0.5s）→ 旁观屏息（0.3s）→ 主角出刀（0.3s）
```

### 2. 涟漪反应（单点爆发扩散）
- 主角一动→旁人依次反应→形成反应涟漪
- 适合：一击决胜、突发剧变
```
主角出刀（0.3s）→ 旁观惊愕（0.3s）→ 反派中刀（0.3s）→ 群众骚动（0.5s）
```

### 3. 错峰蓄势（多人但不同步）
- 多人都在蓄势但节奏错开——A 已到顶点，B 还在起步
- 错峰=不可预测谁先动=悬念
```
A 指节白（顶点，0.5s）→ B 才搭柄（起步，0.5s）→ C 屏息（中段，0.3s）→ A 爆发（0.3s）
```

## 群戏的剪辑骨架

### 正反打+反应镜（标准群戏）
```
主角近景蓄势（0.5s）→ 反打反派近景对位（0.5s）→ 反应镜旁观屏息（0.3s）→ 主角特写爆发（0.3s）→ 全景定格余韵（0.8s）
```
主线（主-反）+反应镜（旁）+全景（收），四镜完成群戏曲线。

### 主镜+穿插反应（主角主导）
```
主角长镜蓄势（1.5s，主镜）→ 穿插旁观惊愕特写（0.3s）→ 回主角爆发（0.3s）→ 全景定格（1s）
```
主镜不切维持张力，穿插反应镜加密度。

## 群戏张力杀手

### 全员一起动
- 所有人同时蓄势/爆发=没焦点=糊=观众不知看谁
- 解法：分层，主层先动或最大幅动

### 反应镜太多
- 切太多旁观反应=主线被打断=张力泄
- 解法：反应镜 1-2 个足矣，短（0.3s）

### 群众动作抢戏
- 背景群众动作太夸张=抢焦点
- 解法：群众几乎静止/极微动，把戏留给主层

### 缺反应层
- 只有主反两层没有旁观反应=情绪没有"放大镜"=揪心弱
- 解法：至少一个旁观屏息/惊愕特写

## 经典群戏张力场景

### 三方对峙（主-反-中立）
```
主角搭刀（0.5s）→ 反派搭刀（0.5s）→ 中立方屏息特写（0.3s，放大）→ 主角出刀（0.3s）→ 全景定格（0.8s）
```
三方分层，中立方做反应放大镜。

### 一击制众（涟漪）
```
主角爆发一击（0.3s）→ 反派中刀（0.3s）→ 众喽罗惊退（0.5s）→ 主角收刀定格（1s）
```
单点爆发→涟漪扩散→收束。

### 错峰围攻（多人攻一人）
```
A 逼近蓄势（0.5s）→ B 才起步（0.5s，错峰）→ 主角凝视锁定 A（0.3s）→ A 出手主角闪（0.3s）→ B 还在逼近（0.5s）
```
错峰=不可预测=悬念。

## AI 提示词
- 群戏分层：`multiple characters, one in foreground acting, others in background still, layered composition`
- 反应特写：`bystander wide-eyed reaction, gasp, held breath`
- 避坑：AI 群戏多角色易崩脸/穿模，建议：群戏镜优先静态构图（背景人不动）+主角动；反应镜单独生成单人特写拼接
- 群众镜用 `motionless crowd, frozen bystanders` 让背景稳

## 备注
- 群戏是 012 静态张力+024 微表情的多体扩展
- AI 视频群戏稳定性差，核心策略：**静态背景+动态主角+单独反应镜拼接**
- 错位编织的核心是"不同步"——同框人动作幅度必须有差
