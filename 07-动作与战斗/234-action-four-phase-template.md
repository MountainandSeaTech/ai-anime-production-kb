# 动作四阶段拆解模板（起始-发力-顶点-收势）

## 核心要点
- 任何格斗动作都可拆成四段：**起始 → 发力 → 顶点 → 收势**，一段一个提示词单元
- **起始**写架势/重心/视线；**发力**写重心转移/发力链顺序/转体；**顶点**写肢体伸展极限/肌肉状态/衣发动态；**收势**写缓冲/还原戒备/残心
- **残心是收势的灵魂**：打击后不放松架势与斗志，眼神警惕、随时可再接下一招
- 完整模板＝镜头＋角色服装＋四阶段，一段不缺，动作才不会"飘"或"断"
- 连击用节奏衔接词串段：**紧接着／无缝衔接／落地即起**

## 四阶段各写什么

| 阶段 | 必写要素 | 关键词示例 |
|---|---|---|
| ① 起始 | 架势（近/中/远距离戒备）、重心位置、视线锁定 | 中距离戒备、含胸沉肘、重心居中、视线平锁目标 |
| ② 发力 | 重心转移、发力链顺序（地→腿→腰→髋→末端）、转体方向 | 重心移至支撑腿、提膝蓄力、蹬地转腰、腰胯拧转、摆头带动转体 |
| ③ 顶点 | 肢体伸展极限、肌肉绷紧状态、衣褶/发丝随惯性扬起 | 腿完全伸展、拳峰绷紧、肌肉线条隆起、裙摆与发丝随转体扬起 |
| ④ 收势 | 缓冲方式、还原戒备、残心眼神 | 沿原路收腿、落地屈膝缓冲、迅速恢复戒备、眼神警惕保持残心 |

> 新手只写③顶点，成片必"飘"；老手四段全写，动作才有重量感和连续性。

## 残心：收势的灵魂

- **定义**（源自空手道/剑道）：打击意识的延伸——做完打击动作后**不可放松姿势与斗志**，保持随时回应对手反击的心理准备、架势与气力
- 提示词落法：收势段必加 `眼神警惕、架势不松、保持残心（alert eyes, ready stance, zanshin）`
- 防御也有残心版：格挡后立刻衔接反击意识，不是挡完就站着
- 省略残心＝动作之间出现"断裂感"，连击像 PPT 翻页

## 完整提示词模板

```
[镜头]＋[角色/服装]＋[阶段1 起始：架势、重心、视线]
＋[阶段2 发力：发力链顺序、身体转动]
＋[阶段3 顶点：肢体伸展极限、肌肉状态、衣发动态]
＋[阶段4 收势：缓冲、还原戒备、残心眼神]
```

## 横踢示例（照套模板）

```
全景镜头，穿制服的少女格斗家，
中距离戒备、重心居中、视线锁定对手中段（起始）
→ 重心移至左腿、右腿提膝翻胯、腰胯拧转发力（发力）
→ 右腿横踢完全伸展击中目标、裙摆与发丝随转体扬起（顶点）
→ 沿原路收腿落地、迅速恢复戒备、眼神警惕保持残心（收势）。
```

## 组合连击：节奏衔接词

连击＝多组四阶段串联，段与段之间用衔接词锁死节奏：

- **紧接着**：后招接前招收势，常规连击
- **无缝衔接**：前一踢收与后一踢起几乎同步（如二段踢）
- **落地即起**：落地缓冲瞬间立刻蹬地再起（如跳跃连续下劈腿）

```
示例（二段踢）：……第一踢击中收腿，落地即起，第二腿无缝衔接弹出……
```

## AI 落地注意事项

- **接缝卡在硬切处**：四阶段分给多条 clip 生成时，切点放在阶段交界处（起始末/发力末），不要砍在动作中段——阶段交界是天然剪辑点
- **避免顶点糊帧**：顶点（③）是运动速度最快的一帧，最容易糊——顶点单独给一条短 clip 或用「击中瞬间定格微帧」处理，配合 026 前摇单独成镜的思路
- **一条 clip 装不下四段就别硬塞**：爆发类动作（后回踢 12 帧级别）拆 2-3 条生成，按阶段接缝拼接
- 顶点帧提示词加 `impact frame, full extension, motion frozen at peak` 稳住姿态

## 常见坑

- **只有顶点没有发力链＝飘**：只写"踢中目标"，AI 不知道力从哪来，动作轻飘无重量。发力段必须写清"重心转移＋腰胯拧转"的传导顺序
- **收势省略＝断裂感**：没有缓冲和还原戒备，下一镜角色像瞬移回站姿，连击变幻灯片
- **起始不写视线**：转体类动作（后回踢）视线先于身体到位，漏写则转体像盲转
- **残心漏写**：收势只剩"站回去"，角色气势泄掉，打斗张力当场归零
- **四段全塞一句**：四个阶段挤在一个从句里，AI 只执行最后一段——用箭头/分号显式分段
