# 战斗中的势转换（攻守易势）

## 核心要点
- 战斗不是单方面碾压——是**势的来回**
- 势转换=攻守角色互换的瞬间=战斗的剧情转折点
- 一场好战斗至少有 2-3 次势转换
- 势转换靠"信号词"提示——观众要看懂风向变
- 关联 121 三幕式、134 弱势反转

## 势的定义
```
势 = 战斗中谁占上风的状态
  - 攻势方：主动出招、压迫、追击
  - 守势方：被动格挡、后退、受伤
```
- 势不是绝对的——可"守中有攻"（反击）
- 势是流动的——会因一招而翻转

## 势转换的视觉信号

### 势转换前（A 占优）
```
A 的信号：
  - 镜头仰拍 A（见 017 角度即权力）
  - A 表情从容/微笑/不耐烦
  - A 步伐稳健前进
  - A 攻击频率高
B 的信号：
  - 镜头俯拍 B（弱小感）
  - B 表情狰狞/咬牙/喘息
  - B 后退/踉跄/挨打
  - B 防御姿态
```

### 势转换瞬间
```
信号反转：
  - A 的从容突然凝固（表情微妙变）
  - B 的喘息突然停（呼吸凝住）
  - 镜头角度从仰 A 俯 B 切换为 仰 B 俯 A
  - 镜头从跟拍 A 切到跟拍 B
  - 灯光/色调微变（暗→亮 或 冷→暖）
  - 音乐从压迫变上扬
```

### 势转换后（B 反占优）
```
B 的信号反转：
  - 镜头仰拍 B
  - B 表情坚毅/眼神聚焦
  - B 步伐前压
  - B 出招频率提高
A 的信号反转：
  - 镜头俯拍 A
  - A 表情错愕/惊怒
  - A 后退/格挡
  - A 防御姿态
```

## 势转换的 5 种触发器

### 1. 顿悟型
```
B 在被压制时回忆起师承/顿悟新招
→ 信号：闪回帧插入+眼神聚焦+一招反击
```

### 2. 觉醒型
```
B 被打到极限触发隐藏力量
→ 信号：气息爆发+发色变化+周围环境震动
```

### 3. 反派傲慢型
```
A 占优后傲慢自大→露出破绽
→ 信号：A 表情狞笑+B 抓住破绽反击
```

### 4. 牺牲型
```
B 挨一重伤换得反击机会
→ 信号：B 挨打特写+B 抓住 A 武器反击
```

### 5. 外部介入型
```
援军到来/环境崩塌改变战局
→ 信号：画外声音+A 分心+B 反击
```

## 多次势拉锯（经典模式）
```
势 1: A 压 B（建反派威慑）
势 2: B 反击（势转 1）
势 3: A 认真起来再压 B（势转 2）
势 4: B 顿悟再反（势转 3）
势 5: A 亮真形态最终压 B（势转 4）
势 6: B 觉醒终极爆点（势转 5，决胜负）
```
- 这是长篇战斗经典节奏——5-6 次势转=张力脊柱
- 每次势转都要有视觉信号+触发器

## 模板示例（5 段势拉锯）

### 段 1：A 压 B
```
仰拍 A 进攻，俯拍 B 后退
B 表情狰狞，A 从容
镜头：A 跟拍多
```

### 段 2：B 反击（势转 1）
```
B 突然抓住破绽反击
A 表情凝固（信号反转）
镜头角度互换，色调转暖
```

### 段 3：A 认真再压
```
A 亮真本事=再压 B
B 再次退守但更稳了
镜头：A 仰拍强化
```

### 段 4：B 顿悟
```
B 闪回师承=眼神聚焦
节奏骤停 1 帧=爆点前呼吸
镜头：极近特写 B 眼
```

### 段 5：B 终极反击
```
B 一招决胜
A 错愕慢镜
色调完全反转（A 暗 B 亮）
收束：A 倒下，B 收刀
```

## 常见坑
- **势无转换**：一方碾压到底=无聊
- **势转无信号**：观众看不懂谁占优=混乱
- **势转太频繁**：每 5 秒一转=情绪被切碎
- **信号词冲突**：A 占优但镜头俯拍 A=信息矛盾
- **势转无触发器**：突然反转=突兀无说服力

## 进阶
- **势转换的"沉默帧"**：势转前插 1-2 帧静默=爆点放大
- **势转的视觉锚点**：每次势转固定一个视觉锚（如表情/角度/色调）=观众跟得上
- **假势转**：B 看似反击实则陷阱=反套路
- **群战的势**：每小场一个势状态，整体战局也有大势
