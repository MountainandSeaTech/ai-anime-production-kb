# 亢龙有悔专项——"盈不可久"的收发力学

## 核心要点

- 洪七公原话精髓："亢龙有悔，盈不可久"——打出去的力道十分，留在自身的还有二十分
- 这一招是"收"的哲学：高级刚猛不是全力输出，而是可控的余量
- 郭靖版动作锚点：左腿微屈、右臂内弯、右掌划圆圈向外推

## 详细内容

### 为什么是总纲第一招
1. 教学上：先学"收"再学"放"，杜绝弟子一味猛打
2. 力学上：留力＝保留重心与变招余地，掌力可回收可叠加
3. 叙事上：萧峰/郭靖的人格镜像——强大但克制

### 动作分解（生成用）
1. 蓄：左膝微屈沉胯，右臂内弯收于胸侧，掌心暗含
2. 转：右掌以小臂为轴划圆（圆=留力的视觉符号）
3. 推：掌缘外翻直线推出，出掌速度"缓起急落"
4. 收：掌到尽处不停滞，自然回收半寸——这"半寸回缩"是这招的灵魂帧

### 与满力掌的画面对比
- 满力掌：身体前倾、手臂完全伸直、表情狰狞——视觉上是"赌命"
- 亢龙有悔：身体中正、肘部留弯、表情平静——视觉上是"掌控"

## 关键参数 / 模板 / 清单

**AI 提示词模板**
```
武者身体中正不倾，左膝微屈，右臂内弯掌贴胸侧蓄力，随即右掌划圆向外推出，
掌势浑厚而克制，出掌后肘部仍留弯曲余量，掌心在尽处微微回收半寸，
表情平静眼神沉稳，周身气劲内敛而非爆发。
负向词：arm fully extended locked elbow, overextended lunge, screaming face,
all-out desperate attack, body falling forward
```

**自检三问**：肘留弯了吗｜表情是平静还是狰狞｜掌到尽处有没有回收帧

## 备注

- 此招是"疯批冷幽默"气质的武戏对应物：力量越大越平静，反差即张力
- 与 183 武器持久性同理：留力状态要在逐镜提示词中锚定，防止 AI 把留弯的肘画直
