# 技能魔法编写二十连③：能力命名学

## 核心要点

- **好名字干两份活**：①告诉你这招长什么样（描述职能）②被喊出口时带感（仪式职能，街霸/动漫传统）
- **名字是观众记忆的索引**：机制再复杂，一个可复述的名字就能被讨论、被期待、被玩梗——传播力是能力生命周期的一部分
- 五大命名范式：**白描复合词**（街霸：昇龍拳＝rising dragon fist）、**式-形-名三段**（鬼灭/火影：水之呼吸·壹之型·水面斩）、**解放令＋器名**（死神：散落吧，千本樱）、**文化借名**（JOJO替身全用乐队/歌名）、**中式典故意象**（易经/成语/诗词：亢龙有悔、凌波微步）
- 命名纪律：**同一体系同一句法**（观众听名字就知道归属）；名字必须与视觉一一对应；喊招是节拍器不是每招义务

## 详细内容

### 一、命名公式库

**短式（二字-四字，适合武侠/格斗）**
- 主题名词＋攻击动词：闪电击、碎岩掌
- 形容词＋主题名词＋动词：赤龙 Blast、寒霜指
- 白描复合词最耐听：动作＋部位＋意象，如"升龙拳""龙卷旋风脚"——字面即画面

**日式三段（式/形/名）**
```
[流派/属性]之[体系] · 第[序号][型/式] · [意象名]
水之呼吸·壹之型·水面斩
火遁·豪火球之术
```
体系价值：序号天然承载成长（壹之型→拾之型）与收藏感；观众一听前缀就知阵营与属性。

**解放令（言灵式）**
```
[命令动词]，[器/灵的名字]！
散落吧，千本樱／轰鸣吧，X
```
价值：把"发动瞬间"变成对白节拍，名字与器物绑定，辨识度极高；适合器灵/召唤/变身（对接376）。

**文化借名（JOJO范式）**
- 替身/能力以乐队、歌曲、塔罗、神祇命名（Killer Queen、Star Platinum）
- 名字本身不描述功能，靠**能力表**补足——好处是格调与神秘感，风险是观众需二次记忆；适合现代异能/都市奇幻（375）

**中式典故意象（本项目主口径）**
- 易经卦象（亢龙有悔、见龙在田）、成语诗词（凌波微步、斗转星移）、佛道术语（六脉神剑、生死符）
- 名字给意境与哲学，招名不可直接入提示词，须拆动作白描（271铁律，374管线）
- 命名即性格：金庸给萧峰用"亢龙有悔"（盛极而戒），给段誉用"凌波微步"（逍遥轻盈）

### 二、好名字的五条检验

1. **画面性**：没看过的人能否猜出大概景象？（纯抽象词如"寂灭第七"过不了）
2. **喊感**：大声念出来顺不顺、有没有重音落点——两到四个重音步最佳
3. **归属**：去掉专有部分还剩什么体系特征？（"水之呼吸"前缀必须保留归属信息）
4. **留白**：名字暗示效果但不说破——"有悔"不说怎么悔，"千本樱"不说刀刃是花瓣
5. **不撞车**：同剧两名在字数/音步/意象上拉开；避免同偏旁同义堆叠（炎龙斩/炎龙破/炎龙裂三连是偷懒）

### 三、命名与机制的绑定结构

```
[体系名]（门派/属性/血脉）
  └ [招式名]（具体技法）
       └ [境界/阶段名]（成长刻度，可选）
```
- 三层各管一件事：体系管归属，招式管画面，境界管成长
- 海裂可用：能力统称（频率共振/地脉共鸣）→ 具体技法命名 → 代价阶段名（如岩骨石化的"初灰/裂纹/化石"三阶）
- 境界名要稀缺：一整套从青铜到王者的十级名是数值思维（363批判），故事里真正被称呼的境界名不超过三五个

### 四、喊招（叫び）的使用纪律

- **功能**：发动节拍＋少年热血仪式＋帮观众读招＋角色表演（喊法随性格：闷哼/傲慢/嘶吼）
- **密度**：首秀必喊（365仪式感）；常规战点到为止；高手往往不喊（无名神僧式压迫感）；同一招反复喊会贬值
- **时机**：名字落在蓄力末-爆发点（配合291蓄爆延反、304声画）；解放令型名字本身就是扳机
- 真人写实风的口径：武侠可以喊招（传统戏曲/评书基因），现代写实异能慎用——对表《天龙八部》真人感：招式名可由旁白点出或对手口中称呼，少让主角自己每招必喊

### 五、命名流程（工作法）

1. 机制定稿（361五要素）后再命名——名从属于实，禁止先定帅名硬凑能力
2. 一稿出5-8个候选，按五条检验筛到2个
3. 喊感测试：大声读三回
4. 撞车检查：与本剧名表、知名IP名（尤其JOJO/火影/金庸）查重，文化借名注意商标敏感区
5. 定名即锁定进能力圣经（377）：名、别称、体系、首次出场集数、谁会用
6. 外号层：给观众/敌对阵营起**俗称**（"那个一喊就死人的琴"）——俗称与正式名的落差本身是世界观质感

### 六、反面清单

- 机械翻译腔：Absolute Annihilation Heavenly Dragon Supreme Sword——堆叠最高级等于没有
- 数字通胀：X斩→X斩改→真X斩→超真X斩（成长应在机制不在名字通胀，370）
- 名实不符：叫"千雷寂灭"结果只是个电火花（名给的期待必须兑付，357节点法）
- 体系混搭：一个门派的招式从句法到典故完全不同源
- 全员生僻字：观众不会念就不会传播——生僻字全剧限用并安排角色念出教学
