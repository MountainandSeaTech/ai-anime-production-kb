# 易经卦象动作设计法

## 核心要点

- 金庸式武学命名不是贴标签，而是"卦辞意象→身体动作"的系统转译
- 掌握此法可自行原创易经系武功招式，不限于降龙十八掌

## 详细内容

### 转译三要素
1. **方位**：卦的爻位决定动作空间——初爻（低位/蓄势）、五爻（高位/显达）、上爻（过极/转折）
   - 例：潜龙勿用（初九）＝低位收敛；飞龙在天（九五）＝凌空高击；亢龙有悔（上九）＝过极知返
2. **劲路**：卦的德性决定力道性质——乾刚（直线爆发）、坤柔（承化）、震雷（突发）、巽风（渗透）
   - 例：震惊百里（震卦）＝环形震荡波；龙战于野（坤上六）＝惨烈缠斗
3. **节奏**：卦辞的事件性决定动作节拍——"密云不雨"＝悬停蓄势；"突如其来"＝零前摇爆发

### 转译流程（四步）
1. 读卦辞爻辞，抓核心意象词（龙/雷/水/风/山）
2. 定方位（高/低/中；进/退/旋）
3. 定劲路（刚/柔/爆/绵）
4. 定节奏（蓄/爆/连/变）

### 实战验证（降龙掌案例回测）
- 见龙在田（九二，阳爻居阴位）：方位中、劲路稳、节奏后发→站桩反击招 ✓
- 羝羊触藩（大壮九三）：进退两难意象→诱敌锁困招 ✓

## 关键参数 / 模板 / 清单

**原创招式速查卡**
```
卦名+爻位 → 查卦辞 → 提意象 → 定三要素 → 白描成动作句
例：水山蹇（险在前）→ 意象"止步" → 方位守、劲路绵、节奏缓 → 防御反击招
```

## 备注

- 此法与 279 招名库配合使用：起名先用卦象校验气质是否匹配
- 不限掌法——剑法（如"风泽中孚"可做轻灵剑招）、轻功均可套用
