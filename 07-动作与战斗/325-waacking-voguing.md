# Waacking 与 Voguing：两大俱乐部造型舞种

## 核心要点

- 两者都是 1970s 俱乐部文化产物、都重手臂与造型，但来源和质感不同：**Waacking 出自洛杉矶，跳 Disco/Soul，核心是手臂快速绕圈甩动后重击定格（whip-stop）；Voguing 出自纽约 Ballroom，核心是模仿时尚杂志的模特造型（pose）与线条（lines）**
- Waacking＝**鞭子**：手臂绕环-甩出-骤停，音乐里每个镲片/弦乐 stab 都"打"一下；脚步轻快 shuffle 让位给躯干拧转
- Voguing＝**杂志封面**：一切为"摆出能被拍照的造型"服务，讲究直线条、对称、定格与造型之间的转换
- 两者都具强烈**表演性与戏剧性**（眼神、表情、与对手的姿态对峙），适合动漫里的"气场对决/T台登场/华丽变身"
- 镜头共性：中全景带手臂完整活动范围、**造型定格帧给切镜**、旋转用环绕或固定正面；忌手部出画裁切

## 详细内容

### 一、Waacking（甩舞 / Punking）

**起源**：1970s 洛杉矶西岸同性恋俱乐部，随 Disco/Soul 音乐而生；早期称 Punking（punk＝耍弄/戏仿），"waack"为甩动拟声词。

**核心技术**：
1. **Waack（甩臂）**：手臂（保持伸直或微屈）在肩后/身侧快速画整圆加速，像鞭子抽出去
   - **Waack Back**：在肩后方绕环挥出，末端重击停住
   - **Waack Forward**：在身前延展挥出，末端重停
   - **Double Waack**：双臂一前一后/同时绕甩，末端双双重击
2. **Whip-stop（鞭-停）**：每个甩动末端必有一个脆停（卡镲片/弦乐 stab），这是与"随便挥胳膊"的本质区别
3. **躯干**：拧转（twist）与展胸（open chest）配合甩臂方向，身体可微后仰"让手臂过"
4. **脚步**：轻而小，左右 shuffle、追步、小转，**服务于稳定上肢平台**，不抢戏
5. **Pose & Drama**：甩臂之间插入叉腰、托腮、展臂造型；表情外放、眼神"杀"，可戏仿明星姿态

**质感词**：uplifted（整体上扬，像随时要和观众击掌）、sharp stops、disco 华丽

### 二、Voguing（ Vogue / 折手舞）

**起源**：1970s–80s 纽约哈莱姆 Ballroom 文化，名字来自《Vogue》杂志；以摆模特造型、拼"线条"和姿态对峙为核心。

**三大派系**：
| 派系 | 特征 |
|---|---|
| **Old Way 老派** | 模仿杂志封面与古埃及壁画：对称、直线、定格清晰；两人对峙时用手臂把对方"框"住或锁住 |
| **New Way 新派** | 三关节分离（triple-joint illusion）、手臂交错成几何架（arms control）、身体在几何格中扭曲，极柔与极硬切换 |
| **Vogue Fem 女态** | 最戏剧化，五元素全开，极度女性化的夸张表演，含高速手部与地面坠落 |

**Vogue Fem 五元素（5 Elements）**：
1. **Hands / Hand Performance 手部表演**：手指、手腕连续柔软动作，像说话/变魔术，常配叙事（整头发、照镜子）
2. **Catwalk 猫步**：夸张版 T 台步，交叉腿前进、胯大幅左右送、一手前伸保持平衡线
3. **Duckwalk 鸭步**：蹲低位、脚跟抬起、膝盖开合地向前蹬行，上身保持模特造型
4. **Spins & Dips 旋转与坠落**：旋转后优雅地跌到地面（一腿折收、身体卷落，手臂保持线条）
5. **Floorwork 地面表演**：在地上用腿、胯、手臂摆造型与软度展示（劈叉、拱桥、背腰）

**Dip vs Death Drop（术语必须分清）**：
- **Dip**：可控的、优雅的旋转-卷落，腿折叠缓冲，身体保持造型线条——"艺术性摔倒"
- **Death Drop / Death Fall**：从蹲姿**猛地起跳、双腿在空中 V 字打开、身体向后直拍落地**，常被托住（手臂/肩背缓冲）——戏剧性"猝死"，全场炸点

**对峙语法（Battle/Competition）**：两人轮流走 catwalk 逼近→在对方面前摆压倒性 pose→用手臂几何"框住"对手→dip 收尾；本质是"用造型说我比你美/比你强"。

### 三、两舞种对比与选型

| 项 | Waacking | Voguing |
|---|---|---|
| 音乐 | Disco/Soul/Funk（快、亮、镲多） | House/Beats（Ballroom 场景） |
| 主角 | 手臂速度与鞭停 | 造型线条与定格 |
| 脚步 | shuffle 小步平台 | Catwalk/Duckwalk 即表演本身 |
| 情绪 | 派对、华丽、戏仿 | 气场、对决、时装感 |
| 动漫适配 | 华丽连击、指挥家型角色、搞笑明星戏仿 | T台登场、变身 pose 连摆、双姝对峙 |

### 四、8拍组合（Waacking 例）

```
[1-4] 左右 shuffle 前进，waack back 左右各一次（镲片点重停）
[5-6] double waack 双臂同甩，重击
[7-8] 展胸 pose：一手上一手侧，停满
[9-12] waack forward 连续两次+小转一周
[13-16] 叉腰三拍走步逼近镜头 → 重拍甩臂定格+眼神特写
```

## 关键参数 / 模板 / 清单

### 提示词模板

```
[Waacking]
waacking dancer, fast extended arms whipping in full circles behind/front of body, 
sharp whip-stop on every cymbal stab, chest open with torso twists,

[Voguing]
voguer performing [old way / new way / vogue femme],

[sinuous hand performance / exaggerated catwalk strut / low duckwalk / spin into elegant dip],

glamorous outfit, runway lighting
负向：soft jazz dancing, bent broken lines during poses, ordinary walking,

```

### 验收清单

- [ ] Waacking：每个甩臂末端有可见"鞭停"，卡音乐 stab
- [ ] 手臂绕的是整圆（在耳侧/身后绕满），不是半截划水
- [ ] 脚步小而轻，不与手臂抢注意力
- [ ] Voguing：每个 pose 有直线/对称几何，定格清晰可拍照
- [ ] Catwalk 有交叉步+送胯，不是普通走路
- [ ] Duckwalk 低位蹲行、上身造型不掉
- [ ] Dip 是卷落有控制；Death Drop 是 V 字起跳后拍落——两者不混
- [ ] 手臂活动全程不出画（手部表演给足画面空间）
- [ ] 眼神有对手/镜头对象，气场对峙成立
