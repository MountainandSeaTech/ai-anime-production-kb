# 顿帧Hitstop——冲击帧的时间孪生

## 核心要点

- 顿帧＝命中瞬间**攻击方与受击方同时冻结**数帧——表现的力与反作用力的**短暂对抗**，不是"打中了"的通知
- 冲击帧撕画面，顿帧停时钟——**分管视觉与时间**，叠加才是完整打击感

## 详细内容

### 本质重定义（GameRes实操结论）
- 顿帧不是表现"命中"，是表现**两股力的对抗**——轻攻击力小顿帧短甚至没有，重攻击发力强顿帧明显，破防级冲击顿帧最长
- 没有顿帧：剑像划空气一样穿过敌人；有顿帧：大脑确信"砍到了实体"

### 现代改良版（ahmadmohammadnejad "A More Realistic HitStop"）
- 传统全画面冻结会打断战斗流畅感、破坏沉浸
- 改良：**只冻结角色双方**，粒子、镜头运动、环境元素保持正常速度——既保住打击感又不卡戏

### 与冲击帧的分工
| | 顿帧 | 冲击帧 |
|---|---|---|
| 管什么 | 时间（冻结） | 画面（断裂） |
| 时长 | 2-10帧 | 1-2帧 |
| 观众感知 | "这拳很重" | "这里发生了大事" |
| 时序 | 冲击帧**之后**开始 | 接触帧C或C+1 |

### 常见误用
- 顿帧过长→战斗拖沓，像网络卡顿
- 每次命中都顿→贬值，只剩"卡"
- 顿帧期间镜头也冻→画面死寂，正确是镜头继续微震（见300）

## 关键参数 / 模板 / 清单

**联用公式**：接触帧C放冲击帧（1-2帧）→ C+2起顿帧冻结角色（帧数见298）→ 冻结结束接受力反馈
