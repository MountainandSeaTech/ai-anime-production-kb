# 降龙十八掌使用者差异——三种劲路

## 核心要点

- 同一套掌法，三个使用者三种劲路——AI 改编时"谁在用"决定动作气质，不可混用
- 掌力射程原著参照：萧峰可打出十丈之外，郭靖约三丈之内——但郭靖造诣被评价更高（刚柔合一）

## 详细内容

### 萧峰版——天赋刚猛，直出直入
- 特点：删繁就简（二十八掌→十八掌的执行者），招式最简、威力最猛、实战最强
- 气质：豪气＋悲怆同框，掌出必中、中者必伤
- 画面特征：出掌无前摇，掌风直线，受击者直接飞出/骨折
- 适用场景：聚贤庄死战、雁门关类大开大阖场面

### 洪七公版——3.0 改良，七虚七实
- 特点：融入天罡北斗阵原理，形成七虚七实的劲力网；教郭靖时强调刚柔转化
- 气质：游戏人间的宗师感，掌里藏着玩笑
- 画面特征：掌路虚实交替，对手挡到的都是虚的，实掌总在意外处
- 适用场景：教学戏、切磋戏、戏耍反派

### 郭靖版——刚柔合一，至刚化至柔
- 特点：九阴真经内力催动刚猛外功，兼空明拳与左右互搏（可双掌同时不同招）
- 气质：沉稳厚重，侠之大者的"守"
- 画面特征：掌力浑厚绵长，招式之间无断点，越战越稳
- 适用场景：守城、护卫、持久战

### 版本迭代暗线（可作剧情素材）
1.0 萧峰原版的刚猛直出 → 2.0 删繁后的精悍 → 3.0 洪七公虚实网 → 4.0 郭靖刚柔互济

## 关键参数 / 模板 / 清单

| 使用者 | 劲路关键词 | 出掌节奏 | 镜头适配 |
|---|---|---|---|
| 萧峰 | 刚猛直线 | 无前摇瞬发 | 低角度仰拍＋受击飞出 |
| 洪七公 | 虚实交替 | 快慢相间 | 中景环绕＋假动作特写 |
| 郭靖 | 刚柔绵长 | 匀速连绵 | 稳定长镜＋下盘特写 |

## 备注

- 本项目《天龙八部》主用萧峰版劲路；若后续出现回忆/对照戏，三种劲路可做跨时空对仗剪辑
- "左右互搏双掌不同招"仅郭靖版可用，萧峰/洪七公版本不得画出双手异招
