# 待机姿势张力：居合与对峙

## 核心要点
- **待机姿势 = 静态张力的容器**——角色不动，但姿势本身已编码"即将爆发"
- 好的待机姿势让 0.5 秒的静止就揪心，差的姿势站多久都松
- 三大高张力待机：居合拔刀姿、侧身对峙、低姿态蓄势
- 待机姿势要"紧"——重心压低、肌肉预紧、视线锁定

## 三大高张力待机姿势

### 1. 居合拔刀姿（最强静态张力）
- 左手握鞘，右手搭刀柄（未拔），侧身对敌
- 紧来源：刀未出鞘但手已就位=爆发前摇的物理信号
- 重心：略低，膝盖微屈=随时可弹
- 经典时长：静止 1.5-3 秒后出刀
```
居合站姿近景（1.5s）→ 大特写右手搭刀柄（0.5s）→ 屏息（0.3s）→ 出刀（0.3s）
```

### 2. 侧身对峙
- 双方侧身相对，主手在前，重心略下沉
- 紧来源：侧身=减小受击面积=专业=随时可动
- 双方镜像侧身=势均力敌的视觉信号
- 适合：剑客对峙、枪手对峙
```
对称构图双方侧身（1.5s）→ 特写一方手搭武器（0.5s）→ 反打特写另一方眼神（0.5s）→ 出手
```

### 3. 低姿态蓄势
- 重心压低、单手撑地/扶武器、像弹簧压紧
- 紧来源：身体储能=即将弹射的物理预期
- 适合：突进起手、跳跃攻击前
```
低姿态全景（1s）→ 特写撑地手指发白（0.5s）→ 爆发突进（0.5s）
```

## 待机姿势的"紧"要素

| 要素 | 紧的状态 | 松的状态（避） |
|---|---|---|
| 重心 | 压低、膝微屈 | 直立、松垮 |
| 肩膀 | 沉肩、预紧 | 耸肩或全松 |
| 手 | 搭武器/握拳/撑地 | 自然下垂 |
| 视线 | 锁定目标 | 游移 |
| 呼吸 | 浅而稳/屏息 | 大幅起伏 |
| 下颌 | 微收 | 抬头 |

> 六要素全紧=顶级待机；缺两个=普通；全松=站桩无聊。

## 待机姿势的张力序列（通用骨架）
```
全身待机全景（1s，交代姿势）→ 特写手部就位（0.5s，前摇信号）→ 大特写眼神锁定（0.3s，决意）→ 屏息（0.2s）→ 爆发（0.3-0.5s）
```
五段式，从全身到细节到爆发，注意力逐级压缩。

## 反例：松垮待机（杀张力）
- 直立垂手站桩 → 没有储能信号 → 观众不知道要爆 → 不揪心
- 重心太高 → 像聊天不像战斗
- 手不搭武器 → 没有前摇物理信号
- 视线游移 → 没有锁定目标

- 对峙：`combat ready stance, side profile, hand near weapon, tension pose`

- 关键修饰：`tense, coiled, ready to strike, low center of gravity, muscles tensed`
