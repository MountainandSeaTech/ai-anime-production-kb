# 动作戏三铁律

## 核心要点
- 三条规律全部来自**实战返工**（《竹雨·第七刀》Wan 生成后暴露的缺陷），不是纸上理论
- 铁律一：**张力靠"按住"，不靠"加动作"**——动得越多，张力越少（011）
- 铁律二：**招式靠"换维度"，不靠"加招数"**——同一维度堆十招＝匀速＝单调（123/041）
- 铁律三：**写"相交/接触/压住"必须给全几何四要素**，缺一即武器共面穿模（128）
- 三条可独立使用，也可作为动作戏的出厂自检
- 关联 011 张力五要素、041 冷兵器张力、123 武器节奏、128 武器物理

## 铁律一：张力靠"按住"

### 病灶
把戏写满动作 ≠ 张力强。011 原话：**"动得越多≠张力越强"**。张力是"将发未发"的揪心感，动作是"已经发了"的刺激感——两回事。

### 无敌流的特殊困境
主角碾压 → 代价为零 → 观众不紧张（011 反例）。冷幽默/无敌流最容易死在这里。

### 修法：把不确定性从"胜负"挪到"时机与代价"
```
不改主角强度，只加一条约束：
  "他只剩一次出手的机会"（旧伤／反噬／规矩）

一条约束同时补四个缺口：
  延迟释放 → 他为什么还不出手？（吊着观众）
  代价     → 一刀落空就没机会（代价≠0）
  不确定性 → 从"谁赢"变成"何时出、会不会被搅局"
  信息差   → 观众知道"只有一刀"，对手不知道
```

### 自检（011 五要素逐项问）
```
□ 威胁源：观众清楚危险来自谁吗？
□ 延迟释放：该爆发的事被"按住"了吗？按住多久？
□ 代价：失败后果够重吗？够不够"揪心"？
□ 不确定性：结果能预测吗？能预测＝张力减半，立刻改
□ 信息差：观众和角色知道的一样多吗？能否制造不对称？
```

## 铁律二：招式靠"换维度"

### 病灶
招式单一的真相不是"招不够多"，而是**节奏同质**（123："节奏同质＝单调"）。全片"相交→震退→再相交"＝匀速循环＝无张力（041："全程连斩＝匀速＝无张力"）。

### 修法：四个维度轮换，每 2-3 招换一个
```
维度① 斩击高度：上段 / 中段 / 下段
维度② 交战距离：远（对峙） / 中（突刺） / 贴身（短打）
维度③ 攻防角色：攻 → 防 → 反制 → 被压制 → 反压制
维度④ 节奏速度：慢（蓄） → 快（连环） → 突变 → 骤停
= 四维度轮着换，观众就永远猜不到下一招
```

### 节奏反压（123 的张力放大器）
让双方**不同节奏**：一方快（短兵连环）、一方慢（重刀/一刀）——节奏差本身就制造张力，不必比招数。

### 招式维度表（可套用）
| 序 | 招式 | 距离 | 高度 | 节奏 | 攻/防 |
|---|---|---|---|---|---|
| 1 | 环步试探 | 远 | — | 慢 | 中立 |
| 2 | 突刺 | 中→近 | 中 | 快 | 攻 |
| 3 | 上段斩 | 近 | 上 | 快 | 攻 |
| 4 | 下撩 | 近 | 下 | 快 | 攻 |
| 5 | 刀背架＋卸力 | 贴身 | — | 顿 | 防 |
| 6 | 横扫斩 | 中 | 中 | 慢→快突变 | 反 |
| 7 | 回旋/跳斩 | 中 | 斜 | 快 | 反 |
| 8 | 贴身短打（柄击/绊） | 贴身 | — | 极快 | 双 |
| 9 | 拉开喘息 | 远 | — | 静 | — |

### 041 通用骨架（5s 冷兵器戏）
```
长镜读步法(1.5s 蓄) → 兵器/手部特写(0.5s 前摇) → 呼吸/眼神特写(0.3s 决意)
 → 交锋快切(0.3s×2 峰) → 定格几何线收(1s 释)
```
- 关键补丁：连斩 barrage 后**必须接一记"屏息定格"**，否则没有峰值点

## 铁律三：相交靠"几何"

### 病灶
写"两剑相交于画面正中"→ AI 拿不到空间线索 → 默认两把剑共面 → **重叠/穿模**。
`画面正中` 还起了反作用——等于告诉 AI"让它们重合在中心"。**极近特写＋正面**更是穿模高发配置。

### 修法：四要素全部写死
```
① 视角：用侧向 3/4 或过肩，避免纯正面（避开共面景深）
② 交角：X 形，约 30°，刃对刃
③ 前后层：谁在前景、谁在中景，交点处"近刃遮远刃"
④ 接触点：中段/近护手，且明确交点"偏画面某侧"（不写正中）
+ 物理：火花从交点向四周辐射（128 冲击感）
```

### 提示词写法对照
```
✗ 两剑相交于画面正中
✓ 侧向3/4近景，两剑X形交角约30°，刃对刃，接触点在两刃中段近护手；
  裴照的长剑从右上向左下切入、在前景；言不弃的窄刀从左下向右上架出、在中景；
  交点偏画面右上方，近刃清晰遮挡远刃，两剑各自独立、互不穿插。
  火花从交点向四周辐射。
```

### 负向词必加
```
weapon clipping, merged blades, fused swords, overlapping blades,
blades passing through each other, coplanar blades, single blade from two
```
- 通用负向词里的 `weapon clipping` 不够狠，要补"blades passing through each other"这类描述性极强的词

## 模板示例（三律合一）

### 改前（张力弱 + 招式单一 + 描述含糊）
```
SEG-1：3 秒对峙后立刻开打（无延迟释放）
SEG-2：两剑相交于画面正中（几何缺失→穿模）
全片：相交→震退→再相交（单一维度循环）
```

### 改后
```
SEG-1：整段刀不出鞘，拇指微动又停，拨蜗牛的手在抖，「你出剑吧」——不出刀（张力靠按）
SEG-2：侧3/4＋X形30°＋近刃遮远刃＋交点偏右上（几何写全）
SEG-3/4：9 招按高度/距离/攻防/节奏四维轮换，匹杀后接屏息定格（招式换维）
```

## 常见坑
- **用动作量补张力**：加打斗时长/招式数量＝加刺激、减揪心（越补越平）
- **只加招数不换维度**：十招全是"横向劈"，观众三招后就盲
- **节奏同质**：双方都"快"，或全程同一速度＝匀速轰炸＝疲劳
- **无敌流摆烂**：以"反正他赢"为由不设代价＝张力归零（要用"时机/代价"替代"胜负"）
- **几何四缺一**：写了交角忘前后层，或写了接触点忘避正面——照样穿模
- **首尾帧不管**：穿模也常出现在首尾帧（接触帧首尾帧要写清"接近未接触→刃对刃"）

## 进阶
- **三律当出厂自检**：任何动作戏写完，逐条打勾——张力五要素齐否／招式维度是否轮换／相交几何是否四要素
- **维度交换可反向**：想突出压迫感→固定"高度"、放开"距离"；想突出慌乱→放开"节奏"
- **几何四要素也适用于非武器**：拳掌相交、抓握、抱摔、握手——凡"两个物体接触"都适用
- **与 165 联动**：招式打到贴身时，面部微表情要同步压（克制表演），否则眼花
- **实战返工词条化**：每次翻车的根因，按此格式沉淀成一条，库会越用越准
