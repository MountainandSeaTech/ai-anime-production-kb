# 战斗运镜手法

## 核心要点
- 战斗运镜四件套：**跟拍 + 环绕 + 甩拍 + 手持**
- 每种运镜表不同势/情绪——不是炫技
- 运镜方向=势的方向——跟优势方走
- 战斗中运镜忌讳：双方同向变向反复=观众晕
- 关联 018 运镜张力、099 跟拍、100 环绕

## 运镜四件套

### 1. 跟拍（Tracking）
```
功能：跟随一方移动=表势
方向：朝优势方移动方向跟
用例：
  - 主角压制反派时跟主角
  - 反派被追退时跟反派（后退跟拍）
  - 长镜头连击串（成龙式）
镜头：横向跟拍多，纵深跟拍少
```
- 跟优势方走=潜意识告诉观众谁占上风
- 成龙式：长跟拍让连击不切=流畅感

### 2. 环绕（Orbit/Arc）
```
功能：环绕主角=表英雄登场/势翻转
方向：以一方为圆心环绕
用例：
  - 主角觉醒时环绕+仰拍=英雄仪式
  - 双方对峙时慢环绕=建压
  - 必杀技释放时环绕+体积光=神圣感
镜头：慢环绕多，快环绕少
```
- 环绕=仪式感运镜——必杀技/觉醒专用
- 关联 100 环绕运镜

### 3. 甩拍（Whip Pan）
```
功能：极快横摇+模糊=转场/能量信号
方向：水平快速摇
用例：
  - 转场（一甩接到下一动作）
  - 能量爆发瞬间（甩+爆）
  - 焦点切换（A 场甩到 B 场）
  - 速度感强化（追逐段）
镜头：甩拍后定焦在主体
```
- 甩拍是动作戏的转场神器——见 115 镜头词汇
- 甩拍+定格=能量爆点

### 4. 手持（Handheld）
```
功能：晃动感=紧张/纪实/混乱
方向：不规则晃动
用例：
  - 主角受伤视角（醉感）
  - 群战混战段（纪实感）
  - 追逐段（紧迫感）
  - 反派压制段（不安感）
镜头：小幅晃动+快切
```
- 手持=不安感运镜——别滥用，会晕
- 受击后短暂手持=代入主角失衡

## 运镜与战斗阶段匹配

### 建压段（对峙）
```
慢推+慢环绕为主
镜头几乎不动=静默张力
偶尔极慢推近=建压力
```

### 交锋段（势来回）
```
横向跟拍优势方
势翻转时切跟拍对象
中景跟拍=清晰看招式
```

### 压制段（一方占优）
```
跟拍优势方+仰拍
被压制方手持晃动+俯拍
镜头语言强化势差
```

### 爆点段（终极一击）
```
甩拍+环绕+骤停
必杀技释放=慢环绕+仰拍
接触帧=定格+冲击波
```

### 释放段（战后）
```
缓慢拉远/上升
长镜头+环境音
收束情绪
```

## 运镜方向=势方向（核心原则）

### 跟优势方移动方向
```
A 压 B 时：跟 A 前进方向移动
B 反击时：镜头切换跟 B 方向
势翻转信号：镜头切换跟拍对象
```
- 这是潜意识的势信号——观众不察觉但感受到

### 双方对峙时
```
慢环绕（以中点为圆心）
= 表势均力敌
环绕速度增加=势即将破
```

## 运镜模板示例

### 居合斩一击
```
建压：慢推近+静默
出招：甩拍+速度线
接触：定格+冲击波环
反作用：双方交错+慢镜
释放：拉远长镜头
```

### 觉醒爆点
```
建压：俯拍主角倒地（手持晃动）
觉醒：环绕+仰拍+体积光
出招：跟拍主角前进
爆点：甩拍+冲击帧
收束：拉远+战场残局
```

### 群战混战
```
航拍战场+各方站位
手持跟拍 A 小队
甩拍切到 B 小队
焦点收束：双方头目对峙
单挑慢环绕建压
爆点定格
```

## 常见坑
- **跟拍对象错**：跟劣势方=势信号错乱
- **手持滥用**：全程晃=观众晕+无爆点
- **环绕太多**：每次势转都环绕=仪式感稀释
- **甩拍无定焦**：甩完没主体=观众找不到焦点
- **双方对峙时运镜快**：建压段运镜快=静默张力散

## 进阶
- **运镜节奏签名**：每角色给专属运镜（如反派慢推，主角快跟）
- **势转的运镜锚点**：每次势转固定一个运镜变化=观众跟得上
- **运镜+音画同步**：运镜重拍对齐音乐重拍=节奏感加倍
- **反运镜**：观众期待跟拍时给静镜=爆点放大
