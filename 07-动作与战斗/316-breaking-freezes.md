# Breaking-Freezes 定格体系

## 核心要点

- Freeze＝**突然静止在空中的造型**，功能是句读：一套 footwork/power move 结束时"钉"在重拍上，是 breaking 的标点符号和炸场单位
- 力学共性只有一条：**重心垂线必须落在支撑面内**；省力关键是用骨骼硬结构（肘顶胯/肘顶腹）把体重"挂"在支点上，而非纯臂力
- 四大基础定格：**Baby Freeze（肘顶胯悬空）、Chair Freeze（侧水平安乐椅）、Air Freeze（斜倒立）、Headstand/Handstand（倒立）**；高阶以 Hollowback（反弓倒立）为代表
- 戏剧价值＝**动→骤停的反差**：镜头要先给运动惯性，freeze 落定瞬间切短停顿（2–4拍 hold）再切，动势越足定格越炸
- AI 生成要点：freeze 是单帧造型任务，**首帧直接喂造型参考图**远比让模型从运动中"停住"可靠；手脚支撑数量要写死

## 详细内容

### 一、支点原理：肘是钩子，不是柱子

| 支点技术 | 接触点 | 受力逻辑 |
|---|---|---|
| **肘顶胯（elbow in hip/iliac）** | 肘尖卡在骨盆髂骨窝里 | 骨盆直接坐在上臂上，省力，Baby/Chair 基础 |
| **肘顶腹（elbow in abs/oblique）** | 肘顶在腰侧腹肌凹陷 | 核心收紧夹住大臂，Turtle/Elbow freeze |
| **直臂支撑（locked arm）** | 手掌全掌接地、臂伸直 | 肩在掌正上方，倒立/Air 系 |
| **头点（head tripod）** | 头顶+双手三点 | 头承重 30–40%，三角形求稳 |

铁律：**支撑臂肩部必须耸起顶开（shoulder protraction）**，缩肩会塌；非支撑部分全部绷成刚体（脚尖、膝、核心三点锁紧）。

### 二、基础定格逐个拆

#### 1. Baby Freeze（宝贝定格，入门第一个）
- **支撑**：一肘顶同侧胯窝撑地（主撑手），另一肘顶腹、另一手在侧前方也撑地（辅撑）；双脚离地
- **身体**：侧身约 45° 朝向地面，胸打开朝侧上，双腿屈膝摆出（常见：一腿弯勾、一腿伸出，或抓脚尖造型）
- **头**：抬起看镜头/前方——是它和"摔倒"的唯一区别
- **用途**：footwork 任意拍可插，教学最先学
- **镜头**：低机位平视略仰最稳，显悬空感

#### 2. Chair Freeze（安乐椅定格）
- **支撑**：单手掌撑地，**上臂后侧/三头或肘顶住侧腰胯**，身体侧向水平悬空，像躺在一张看不见的躺椅上
- **造型**：胸腹朝上微仰，腿并拢或造型伸出，自由手常扶头（"躺椅扶手"）、指观众或抓脚
- **气质**：松弛、炫耀式轻松——越像躺着越炸
- **变体**：Air Chair（肘不顶胯、纯直臂侧水平，高一难度）；Shoulder Spin 入 chair
- **镜头**：正侧面水平机位是标准位；正面会看不出悬空高度

#### 3. Air Freeze（空中定格）
- **支撑**：双手（进阶单手）直臂撑地，身体呈**倾斜倒立**而非竖直——肩在掌上方，但腰胯折出角度、双腿摆出（剪腿、屈腿、分腿）
- 与竖直 handstand 的区别：air freeze 求"造型"，handstand 求"直"
- **用途**：power move 收招最常用终点（风车/大回环最后"提"成 air freeze）
- **镜头**：微仰广角，把斜向线条和地面缝隙拍出来

#### 4. Handstand / Headstand Freeze（倒立/头立定格）
- **Handstand**：双手直臂、身体竖直一条线、脚尖绷；breaking 版常故意留腿造型
- **Headstand（头立）**：头与双手成三角形，腿自由摆造型（分腿、盘腿、剪刀），视觉怪趣
- 变体 **Elbow Freeze**：前臂撑地+肘顶腹，身体水平，比 chair 低，更贴地

### 三、进阶与高阶定格（视觉炸点排序）

| 定格 | 形态 | 难度观感 |
|---|---|---|
| **Hollowback** | 倒立后肩胸后移、腰反弓，脚向头顶方向垂落，整体成新月反弓 | 高阶标志，镜头从侧面拍弧度 |
| **One-hand Handstand / One-hand Air** | 单手倒立或单臂斜定格，另一手叉腰/伸展 | 力量炫耀，慢镜 1 拍最炸 |
| **Air Flare Freeze** | 大回环中途停在最高点的倒立分腿位 | 把动态大招"冻"在半空 |
| **Pike / Planche Freeze** | 双腿前伸与地面平行的水平支撑（团身/分腿水平） | 体操感极强 |
| **Flag（旗帜）** | 单手抓立物（杆/队友），身体横向水平展开如旗 | 需要立面道具，街头场景好用 |
| **Suicide 落地式定格** | 从站立直接拍背/拍体侧砸地并"死"在地上 | 喜剧/震撼两用，见下 |
| **L-kick / V-kick freeze** | 手撑地、双腿在空中劈成 L/V 字瞬时定格 | 短促 1 拍点，衔接用 |

### 四、Freeze 的表演语法（怎么用才炸）

1. **落点卡重拍**：动作最后一拍"锁"住，舞者常跟 DJ 鼓 fill 落
2. **Hold 拍数**：基础 hold 2–4 拍（约 1–2 秒）；高难定格 hold 4–8 拍并可加微调（tweak，换腿造型）
3. **Tweak 变化**：定格中切换腿型/换手/点头，一个 freeze 当两个炸点用
4. **动→死对比律**：进入越暴力（suicide dive 摔进 freeze、power move 急停），定格越响；慢速控制进入则显优雅（两种情绪别混）
5. **看镜头/看对手**：freeze 时眼神必须有对象——看观众＝挑衅/展示，垂眼＝冷酷，看队友＝接力信号
6. **Suicide 语义**：故意重砸在地并静止＝喜剧节拍或"拼了"的态度，动漫打斗中可直接挪用为"被轰飞后钉地定格"

## 关键参数 / 模板 / 清单

### Freeze 选型决策（按镜头需求）

```
要什么观感？
├─ 入门/插在footwork里 → Baby Freeze（侧45°低机位）
├─ 松弛炫耀 → Chair Freeze（侧面平视，手扶头）
├─ 大招收尾、有向上动势 → Air Freeze / Handstand（微仰广角）
├─ 高难高潮 → Hollowback（侧面拍反弓）/ 单手倒立
├─ 怪趣节奏 → Headstand 盘腿 / V-kick
├─ 喜剧/被击飞落点 → Suicide 砸地定格
└─ 有墙/杆/队友 → Flag 旗帜
```

### 提示词模板（定格段）

```
b-boy frozen in a [baby/chair/air/hollowback] freeze, 
[支撑方式：one elbow hooked into hip / one hand on ground], 
body held [horizontal / tilted inverted / arched back] above floor, 
legs in [造型], toes pointed, head up looking at camera, 
sharp stop on the beat, hold, low angle, [场景]
帧策略：运动段末帧→静态造型首帧（参考图），hold 2-4拍→切
负向：shaking, sagging hips, shoulder collapsed, extra hands, 
fingers merged into ground, bent support arm（air类）, floating without contact, blurred face
```

### 定格段验收清单

- [ ] 重心几何正确：支撑面在画面中能"托住"重心投影（看着不会倒）
- [ ] 肩撑起不缩、非支撑肢体绷直成造型，无"半吊子"弯腿
- [ ] 头有朝向（看镜头/对手/垂目），禁止脸埋地无视线
- [ ] 支撑点数量写死并与画面一致（单/双手、是否头点、肘数）
- [ ] 进入段有动势铺垫，落帧在重拍，hold 2 拍以上才切
- [ ] 服装在 hold 首帧有"甩到定"的余动（帽绳/衣摆 1–2 帧延迟静止）
- [ ] 影子完整落在地面，确认不是浮空

## 备注

- 术语口径：breakin 圈 "freeze" 可作动词（freeze 住）；Air Freeze 在不同地区也称 Air Chair 的手撑倒立版本，写英文造型描述可消歧
- 真实安全：suicide/head spin 类需专业场地垫；AI 生成无安全问题，但真人复刻提示需谨慎
