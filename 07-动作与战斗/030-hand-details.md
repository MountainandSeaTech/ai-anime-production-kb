# 手部细节：握刀与颤抖

## 核心要点
- **手部是张力最浓缩的细节区**——心理状态几乎都能从手读出
- 握刀松紧=决意程度，颤抖=压抑情绪，指节发白=极度用力
- 手部大特写=蓄势段注意力锚点，与 024 眼部微表情并列最强信号
- 手部细节在 AI 视频里稳定性中等，需大特写+短镜锁定

## 手部状态与心理对照

| 手部状态 | 心理 | 张力用途 |
|---|---|---|
| 搭刀柄未握 | 蓄势、随时可动 | 出手前摇起点 |
| 缓缓握紧 | 决意累积 | 蓄势递进 |
| 紧握指节发白 | 极度决意/压抑 | 蓄势顶点 |
| 微颤 | 压抑恐惧/怒 | 强忍、将崩 |
| 稳如石 | 专业/超然 | 居合高手 |
| 松开又握 | 犹豫又决意 | 心理转折 |
| 指尖轻搭 | 轻蔑/游刃 | 强者姿态 |
| 握拳又展 | 压下冲动 | 隐忍 |

## 手部细节的张力序列（标准四段）
```
手搭刀柄近景（0.5s，起点）→ 缓缓握紧特写（0.5s，递进）→ 指节发白大特写（0.3s，顶点）→ 出刀（0.3s，爆发）
```
搭→握→白→爆，四段递进，把决意从"想"拧到"必"。

## 三大手部张力信号

### 1. 握刀松紧的递进
- 搭（轻触）→ 握（合拢）→ 紧（发力）→ 白（极致）
- 每一阶都是决意加码的物理信号
- 观众读出"越来越要动"=蓄势累积

### 2. 颤抖=压抑
- 手抖=身体在对抗某种冲动（恐惧/怒/痛）
- 抖而未松=还在忍=即将崩
- 经典：强忍怒意的手抖→最终爆发
```
手抖特写（0.8s，压抑）→ 骤停变稳（0.3s，决意确立）→ 出手（0.3s）
```
抖→停→爆，从动摇到决意到爆发。

### 3. 指节发白=极致用力
- 用力到指甲失血=极度决意/压抑
- 是"已到极限"的视觉信号，后接必是爆发或崩溃
- 大特写指节发白=蓄势顶配

## 手部与其他信号的组合

### 手部+呼吸（双重蓄势）
```
手搭柄（0.5s）→ 握紧+呼吸变浅（0.5s）→ 指节白+屏息（0.3s）→ 出刀（0.3s）
```
手部递进+呼吸递进双线加压。

### 手部+眼神（双锚点）
```
手搭柄特写（0.5s）→ 眼睛瞳孔收缩特写（0.5s）→ 手指白+眼锁定（0.3s）→ 出刀（0.3s）
```
手部与眼部交替特写，注意力在两锚点间跳=密度高=揪心强。

## 经典手部张力场景

### 居合拔刀（手部主导）
```
手垂自然（0.5s）→ 搭刀柄（0.5s）→ 缓握（0.3s）→ 指节白（0.2s）→ 猛拔（0.3s）
```
全段手部特写，靠手部五段递进完成蓄势。

### 强忍怒意
```
握拳垂手（0.8s，隐忍）→ 指节白特写（0.5s）→ 手微颤（0.5s）→ 骤停稳（0.2s）→ 转身出手（0.3s）
```
颤抖→稳=决意确立的转折。

### 松握不定（犹豫）
```
握拳（0.5s）→ 松开（0.3s）→ 又握（0.5s）→ 紧握（0.3s）→ 出手（0.3s）
```
松-握反复=心理犹豫外化。

## AI 提示词
- 握刀：`hand gripping sword hilt, knuckles white, tense grip`
- 颤抖：`trembling hand, suppressed emotion, slight shake`
- 递进：`hand slowly tightening on hilt, gradual grip`
- 指节：`close-up of white knuckles, intense grip`
- 避坑：AI 手部生成易多指/畸变，大特写+短镜+多生成几条选最佳；必要时用剪影/局部遮挡降低崩坏

## 备注
- 手部是 024 微表情的"手版"——心理外化的另一锚点
- 手部+眼部双锚点特写是蓄势顶配，比单一信号密度高一倍
- AI 手部是高频崩坏区，建议：手部镜单独生成、景别紧、时长短、多备选
