# 技能魔法编写二十连⑧：首秀仪式

## 核心要点

- **能力首秀是全剧最贵的单场戏之一**：观众对一个能力的机制理解、情感态度、视觉印象全部在第一次定型，后面都是在还首秀的债。第一定律要求"用能力解题前先让观众理解"——首秀就是理解的开户窗口
- **先立人，再立世界**（MHA开篇法）：在任何奇观之前先让观众认识角色的性格、目标、障碍——能力才有被关心的主人
- **首秀五拍**：①需求（有个非解决不可的具体问题）②挣扎（常规手段失败/他不情愿）③显形（能力第一次出现，机制可读懂）④定价（代价立刻可见）⑤后果（人的反应＋世界的改变＋他自己的惊愕）
- **危险逼出 ≠ 剧情赠送**：Die-or-Fly（生死关头能力被逼出，且他控制不了、付出代价）是合法首秀；New-Powers-as-the-Plot-Demands（打不过了突然会了）是作弊——区别在失控感与代价
- 首秀生成的镜头即该能力的**视觉正典**（色板/介质/手势/声音定稿存档，对接343正典纪律、374视觉开发）

## 详细内容

### 一、首秀五拍拆解

1. **需求拍**：具体、当下、可理解——救人、自保、护住某物。不要为展示而展示，问题越具体能力越好懂
2. **挣扎拍**：先试常规办法（跑、打、喊人）失败；或他**抗拒**使用（知道有代价/身份不能暴露）——挣扎让显形有重量
3. **显形拍**：
   - 机制一次只演一个核心因果（"他一按地→石刺隆起"），复合效果留给后续
   - 给一个干净完整的"动作→现象"镜头，少切快切，让观众读懂
   - 首秀偏软处理时可以失控/不完整（段誉式），但失控本身也要可读
4. **定价拍**：第一次使用**当场**就演示代价——指尖泛灰、脱力跪倒、器物损毁、旁人受伤（362定价镜头）。没有定价拍的首秀等于印假钞
5. **后果拍**：
   - 本人反应要真实：惊奇/恐惧/困惑/狂喜——刚获得力量是大事，平淡处理最假
   - 旁人反应给能力定价（347反应镜头：强者的震惊比奇观本身更说明强度）
   - 世界留下痕迹：焦痕、坑、围观者的眼神——后果延续到下一场（138状态连续）

### 二、首秀要同时交付的四份信息

| 信息 | 交付方式 |
|---|---|
| 机制（它怎么运作） | 一个完整可读的动作→现象，不靠台词讲解 |
| 边界/代价 | 失控、疼痛、痕迹、旁人口中一句后果 |
| 人设 | 他选择保护谁、怎么使用、使用后的表情（364首战即自白） |
| 视觉口径 | 色/光/声/介质/手势全套定型，此后跨镜复用 |

一集首秀容量有限：主角首秀四样全给；配角首秀只给机制+视觉，代价延后补。

### 三、触发情境的三种合法类型

1. **Die-or-Fly 逼出型**：生死/危机中爆发，但伴随失控与代价；适合开篇觉醒
2. **水到渠成型**：训练/日常中第一次成功（"几根头发丝粗细"的微弱起点）——弱起点胜强起点：成长空间与真实感都在，之后每个节点都可对照
3. **历史回溯型**：能力早已存在，首秀是"观众第一次看见"——用一次成熟但克制的使用＋他人反应立威，闪回再补起源（萧峰式开场适用）

禁忌：**情绪触发要具体**。超级赛亚人式觉醒之所以成立，是因为具体的失去（挚友被杀）＋此前全部铺垫；空洞的"愤怒变强"是通胀（363）。情绪触发三条件：具体事件、情感铺垫已足、觉醒后仍付代价。

### 四、首秀的镜头与声音规格

- **一条干净主镜**：全身或中全景看清动作与现象的因果，机位稳、时长给够——首秀忌碎切（碎切适合后期熟练战，366）
- **反应镜配额**：本人反应1条＋关键旁观者反应1-2条（强者/将被保护者各一）
- **声音三件套**：发动音（机制音色定稿）＋环境反应音＋冲击后**半拍静默或耳鸣**（304/155）
- **光**：首秀光效按290选合适显形级，不要首秀就满配L4——起点低，上限才有空间
- **AI工艺**：首秀镜走I2V定关键帧（355），英雄镜预算（357），生成满意的整条与关键帧存档为视觉正典

### 五、首秀在集结构中的位置

- 番剧首集：先立人（非能力情境一小场）→世界信息最小投放（338）→首秀放首集后段做集尾钩子
- 不要首集开场五分钟能力世界大战：没有主人的奇观无人关心
- 多能力剧排首秀表：主角第一集；二号能力/队友能力每隔几集一个，错开仪式——两个首秀不能放同一集抢资源
- 反派能力首秀用"受害者视角"：先看后果再看到人（339未见之鲨）

### 六、首秀之后：规则的"还账"节奏

首秀只给核心因果，第二、三次使用补规则：
- 二次使用：换个情境试边界（成功或失败都教学）
- 三次内：演示一次明确的限制（触发不了/精度不够/代价催缴）
- 之后观众才具备看智斗的资格（第一定律兑付窗口）
