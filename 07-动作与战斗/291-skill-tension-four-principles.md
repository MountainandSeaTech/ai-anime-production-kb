# 技能张力四原则——招式不是放出去就完事

## 核心要点

- 平A式技能＝没有张力；张力来自**节奏**而非特效大小
- 技能是角色的**情绪外化**，不是单纯的攻击手段
- 环境不给反应的技能＝打在棉花上

## 详细内容

### 原则一：蓄-爆-延-反四拍不能少

| 拍 | 时长 | 内容 | 张力功能 |
|---|---|---|---|
| 蓄 | 0.5-2s | 蓄力姿态，能量凝聚，呼吸下沉 | 张力积蓄，观众预期建立 |
| 爆 | 0.1-0.3s | 释放瞬间，身体舒展，气劲离体 | 张力峰值，视觉焦点 |
| 延 | 0.3-0.5s | 命中后静止帧，时间凝固 | 让观众"感受"到冲击力 |
| 反 | 0.5-2s | 环境破坏/人物倒飞/气浪扩散 | 张力释放，确认威力 |

**缺一即平A**——没有蓄力＝偷袭，没有爆发＝慢动作，没有延迟＝没打实，没有反馈＝打空了

### 原则二：势大于形

- **错误**：降龙十八掌＝打出一条金龙（形）
- **正确**：降龙十八掌＝以掌引动天地刚猛之势，掌风所过之处龙形隐现（势）

- **错误**：六脉神剑＝射出一道光（形）
- **正确**：六脉神剑＝无形剑气破空，所过之处空气撕裂、落叶为齑粉（势）

形是结果，势是过程。观众记住的是"势"的压迫感，不是"形"的清晰度。

### 原则三：技能与角色情绪共振

| 情绪状态 | 技能表现 |
|---|---|
| 愤怒/爆发 | 掌风狂野不规整，气劲外溢，收势带颤 |
| 冷静/掌控 | 气劲凝练如丝，收发一体，余韵不散 |
| 悲壮/决意 | 招式大开大合，不顾防御，以命换命 |
| 戏谑/玩弄 | 招式留有余地，虚招多于实招，猫戏老鼠 |

**同一招不同人打**：萧峰打亢龙有悔是"刚猛无俦"，郭靖打是"厚重如山"，洪七公打是"虚实莫测"——劲路差异即情绪差异

### 原则四：环境必须给反应

| 打空/打实 | 环境反馈 |
|---|---|
| 打在空处 | 地面龟裂、尘土逆卷成柱、远处树木伏倒 |
| 打在实处 | 人物倒飞轨迹＋沿途破坏链（撞断柱/穿墙/砸坑） |
| 气浪波及 | 旁观者衣物猎猎、发丝飞扬、站立不稳 |
| 余波持续 | 烟尘弥漫、碎石滚落、耳鸣效果 |

环境反馈是**威力的翻译器**——观众看不懂内力深浅，但看得懂"这一掌把地面打裂了"

## 关键参数 / 模板 / 清单

**技能提示词四拍模板**
```
[蓄]武者马步下沉，双掌回收腰间，掌心相对如抱球，呼吸沉重，
    地面尘土以双足为中心缓缓向外扩散；
[爆]双掌猛然推出，身体舒展如弓，掌风离体瞬间空气扭曲，
    一道刚猛气劲破空而出；
[延]气劲命中目标，时间仿佛凝固，目标身体僵直，面部表情定格；
[反]目标倒飞而出，沿途撞断木柱、穿破墙壁，最终砸入地面，
    烟尘冲天，气浪扩散吹得旁观者站立不稳。
```

**技能张力自检四问**
1. 有蓄力过程吗？（预期建立）
2. 有爆发瞬间吗？（峰值呈现）
3. 有命中延迟吗？（冲击确认）
4. 有环境反馈吗？（威力翻译）

四问缺一，技能即平A。
