# 技能魔法编写二十连⑬：升级、觉醒与变身

## 核心要点

- **变身是"相变"不是换装**（鸟山明立的规矩）：超级赛亚人改变的是整套战斗规则——速度、输出、耐久甚至性格，旧策略全部作废，对手必须重新适应。只是发光染发色、打法不变＝廉价皮肤
- **"挣到"的公式**：远期伏笔（越早越好）＋绝境触发（具体的失去/顿悟）＋首次使用**有缺陷/失控/强副作用**＋代价记账＋后续训练才掌握——五条齐了升级才earned
- 升级改变的是**解题方式**，不是数字（363反通胀）：二阶形态让他能做以前做不到的某类事（如能精细操控），而不是同一种事打得更狠
- 觉醒给的是**可能性**不是胜利：觉醒当下可以输、可以没控制住——胜利在下一场靠理解新规则取得，避免"觉醒即翻盘"的廉价感

## 详细内容

### 一、升级的三种类型（先分清要写哪种）

| 类型 | 特征 | 例子方向 |
|---|---|---|
| 量进 | 原有机制更熟练/更大/更快 | 最常见也最危险，必须配代价与变奏 |
| 质变（相变） | 规则集切换：获得新维度或旧维度反转 | 可控火→可控热传导；地脉→不仅听脉能改脉 |
| 整合 | 两种已知能力/内外矛盾统一 | 代价与能力共存、两种劲路合一 |

高级成长多用后两种：质变更出画面、整合更出弧光。**质变设计要回答"旧打法为什么不够"以及"新规则的新盲区是什么"**——新阶段必须带来新弱点，否则单边增强。

### 二、Phase Change（阶段转换）的BOSS/主角逻辑

- 游戏boss二阶段的本质：让玩家（观众）刚学会的策略作废——叙事里同理，主角进入新形态后，**敌人的应对也必须升级**，否则形态没有重量
- 给每个形态定义：核心规则差异、视觉差异、性格/使用方式差异、维持条件（时限/媒介/情绪）、退出后反噬
- 形态不是常驻：进入条件苛刻＋退出有代价→每次变身是事件；随叫随到的变身三集后贬值
- 形态阶梯数量克制：全片主角2-3个形态足矣（初始→觉醒→终极），终极形态只在终局用一到两次

### 三、铺垫的埋设法（伏笔到触发距离越远越香）

1. **理论提及**：早期有人说过这种状态"只存在于记载/传说"，甚至断言他不可能达到
2. **失败的影子**：一次无意中擦边（情绪激动时火星变了色），本人没意识到
3. **条件拼图**：升级所需的东西分散出现（顿悟、某物、某人的话、某次失败）
4. **触发事件**：具体的失去/守护/绝境——情绪事件要实（人在场、关系已立），不是抽象愤怒
5. **兑现**：所有拼图在同一场汇流，观众能一一回想
- 检验表：升级后回看，前面积累了几条线索？少于三条＝ass pull（从屁股里掏出来的升级）

### 四、首次觉醒的五拍（与365首秀同构但更烈）

1. 旧路已绝：常规手段与现有形态确认无解（先让观众绝望）
2. 内在转折：一个具体的心理/关系时刻（不是吼得更大声）
3. 相变过程：给可见的中间态（355变身语法：从哪里开始扩散、什么材质在变）
4. 失控首秀：力量溢出、敌我不分、身体承受不住——强而不稳是规则
5. 中断与余波：时限到/被唤醒/力竭；留下代价痕迹与"那到底是什么"的余味
- 觉醒当集可以不赢：保住了人但没能击败敌人，新力量成为悬念——比当场反杀高级

### 五、掌握曲线（觉醒之后才是戏）

- **失控期**：不敢用/用了伤人/维持几秒
- **试探期**：训练中找条件与边界（教学+日常关系戏）
- **稳定期**：可主动进入但代价明确
- **代价升级**：越用越深的账（362），终极形态＝终极代价
- 敌人同步学习：第二次交手敌人已针对新形态准备——逼出再变招，循环但不重复

### 六、外形设计纪律（AI生产相关）

- 形态差异要**剪影可辨**：轮廓变化（不是只换光效颜色）——肩背姿态、发型、介质层、新增物
- 保留身份锚：再怎么变，脸/标志物/主色系要留一条线（343正典参考），否则变身=换人
- 变身过程走355首末帧插值＋中间态描述；英雄镜预算（357）；变身镜头全剧复用同一套过程镜头语法（可做模板元素）
- 形态资产入圣经（377）：每个形态独立参考图＋固定提示词串＋色板＋声音

### 七、常见翻车

| 病 | 修法 |
|---|---|
| 绝境突现新招翻盘 | 五伏笔＋觉醒不等于胜利 |
| 变身只换颜色 | 相变：规则/打法/性格至少两项改变 |
| 形态随叫随到 | 进入条件+时限+反噬三件套 |
| 升级后旧问题全消失 | 新形态配新盲区 |
| 数字通胀（二段→三段→超段） | 2-3形态封顶，靠规则外推不靠段位名 |
| 触发全靠愤怒 | 具体事件+拼图汇流 |
| 变完队友全变观众 | 形态有盲区，队友补位仍关键（367/373） |
