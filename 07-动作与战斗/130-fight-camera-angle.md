# 战斗角度选择

## 核心要点
- 角度即权力——仰拍=强势，俯拍=弱势
- 势转换时角度必反转=视觉信号
- 越肩/POV=代入感；倾斜=失衡/不安
- 角度错位=势信号矛盾=观众混乱
- 关联 017 角度即权力、124 势转换

## 战斗角度六件套

### 1. 仰拍（Low Angle）
```
功能：让被拍者显强大/威慑
用例：
  - 反派登场/必杀技释放
  - 主角觉醒/英雄时刻
  - BOSS 全貌展示
  - 优势方追击
镜头：极低角度仰拍强化分量
```
- 势优势方=仰拍（信号强化）

### 2. 俯拍（High Angle）
```
功能：让被拍者显弱小/被动
用例：
  - 倒地的主角
  - 被压制方
  - 战场残局（鸟瞰）
  - 绝望瞬间
镜头：俯拍+手持晃动=代入无力感
```
- 势劣势方=俯拍（信号强化）

### 3. 越肩（Over-the-Shoulder）
```
功能：代入一方视角看另一方
用例：
  - 对话戏（包括战斗中口头对话）
  - 双方对峙建压
  - 一方观察另一方破绽
  - 主角锁定反派瞬间
镜头：越过 A 肩拍 B
```
- 越肩=代入感+双方都在画面

### 4. POV（主观视角）
```
功能：完全代入一方视角
用例：
  - 主角视角看反派逼近（压迫感）
  - 受击后倒地视角（失衡感）
  - 必杀技瞄准视角
  - 临死前的视角
镜头：可加手持晃动+广角畸变
```
- POV 是最强代入——但别多用=晕

### 5. 倾斜构图（Dutch Angle）
```
功能：表失衡/不安/失控
用例：
  - 受击后失衡瞬间
  - 反派怪物化（世界观扭曲）
  - 绝望瞬间
  - 心理崩坏
镜头：倾斜 15-30 度
```
- 倾斜=失衡信号——战斗爆点/受击专用
- 关联 018 倾斜张力

### 6. 平视（Eye Level）
```
功能：中性客观，平等双方
用例：
  - 双方对峙建压
  - 中性叙述段
  - 对话戏
镜头：标准平视
```
- 平视是中性——快切段多，张力段少

## 角度与势转换（核心）

### 势优势方角度
```
仰拍 + 平稳运镜 + 从容表情
镜头角度强化其强大
```

### 势劣势方角度
```
俯拍 + 手持晃动 + 狰狞/咬牙表情
镜头角度强化其弱小
```

### 势转换瞬间
```
角度反转：仰 A 俯 B → 仰 B 俯 A
这是势翻转的最强视觉信号
```
- 角度反转=势翻转锚点——必加

## 战斗阶段角度分配

### 建压段（对峙）
```
平视为主，越肩为辅
偶尔慢推近（建压力）
平视+对峙=平等势
```

### 试探段
```
平视+越肩切换
双方都平等展示
招式特写穿插
```

### 压制段（势明显）
```
仰拍优势方+俯拍劣势方
角度差强化势差
势差越大=角度差越大
```

### 绝境段（主角倒地）
```
俯拍主角（无力感）
POV 主角视角（看反派逼近）
倾斜构图（失衡）
```

### 爆点段（觉醒）
```
仰拍主角（强势反转）
环绕+仰拍（仪式感）
接触帧平视（中性客观=爆点清晰）
```

### 释放段
```
鸟瞰/航拍（战场全貌）
平视收束（恢复常态）
```

## 角度模板示例

### 居合斩决斗
```
建压：平视+越肩（双方对峙）
出招：仰拍主角（强势反转）
接触：平视特写（爆点清晰）
反作用：俯拍反派倒下
释放：鸟瞰拉远
```

### 觉醒爆点
```
绝境：俯拍主角倒地+POV
顿悟：极近特写眼（平视）
觉醒：仰拍+环绕+体积光
爆点：仰拍主角出招
收束：俯拍反派败倒
```

### 群战混战
```
航拍：鸟瞰战场
小场：平视+越肩切换
爆点：仰拍统帅
收束：航拍残局
```

## 常见坑
- **角度无变化**：全程平视=势无信号
- **势转角度不反**：A 占优还俯拍 A=信号矛盾
- **POV 滥用**：>20% POV=晕
- **倾斜乱用**：每镜都倾斜=失衡感稀释
- **角度与情绪冲突**：主角强势给俯拍=违和

## 进阶
- **角度节奏签名**：每角色给固定角度倾向（反派多仰拍，主角觉醒前多俯拍）
- **角度反转锚点**：每次势转固定一个角度反转=观众跟得上
- **倾斜递增**：绝望段倾斜角度逐渐加大=心理崩坏可视化
- **POV 嵌入**：快切中插 1-2 帧 POV=代入感放大

- 角度即权力——仰优势/俯劣势
- 势转必角度反转=势翻转信号
- POV/越肩代入感强但别滥用
