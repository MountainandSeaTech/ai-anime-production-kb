# 战斗分镜节奏（快慢切与切片频率）

## 核心要点
- 战斗节奏=**每个镜头的时长组合**——不是动作多就快
- ASL（平均镜头时长）=节奏的硬指标
- 快切堆不出张力=情绪累——长切才建情绪
- 节奏需"快-慢-快"波形——单调快切=乏味
- 关联 023 切片频率张力、021 慢镜张力

## ASL 节奏档（战斗专用）

| ASL | 切/分钟 | 节奏 | 战斗阶段 |
|------|---------|------|----------|
| 0.3-0.8s | 75-100 | 极快乱 | 决胜爆点瞬间 |
| 1-2s | 30-60 | 快激烈 | 交锋连击段 |
| 2-3s | 20-30 | 中紧凑 | 试探压制段 |
| 3-5s | 12-20 | 中慢 | 建压/释放段 |
| 5-8s | 7-12 | 慢沉 | 静默对峙段 |
| 8s+ | <7 | 极慢 | 顿悟闪回段 |

- 单一节奏=乏味；要"快-慢-快"波形
- 慢段是快段的**呼吸孔**——没慢段快段就没张力

## 战斗节奏波形（经典）

### 波形 A：加速型
```
慢（建压）→ 中（试探）→ 快（升级）→ 极快（爆点）→ 慢（释放）
```
- 单场战斗最常用——情绪累积到爆

### 波形 B：锯齿型
```
中→快→慢→快→慢→极快
```
- 势来回战斗（见 124）——每次势转插入慢段

### 波形 C：突发型
```
慢（很长）→ 极快（爆点瞬间）→ 慢（释放）
```
- 居合斩/拔刀术——一击决胜模式

### 波形 D：混乱型
```
快→快→快→乱→骤停→慢→快
```
- 群战混战——加一帧骤停=张力放大

## 节奏破口技法

### 1. 骤停（最常用）
```
连续快切 5-6 帧 → 突然 1 帧静止 → 接爆点
```
- 骤停帧是爆点放大器——必加

### 2. 慢镜嵌入
```
快切中 → 1-2 个慢镜帧（极近特写）→ 回快切
```
- 慢镜帧=关键爆点的"放大镜"

### 3. 长切呼吸
```
连快切 8 帧后 → 1 个 3-5s 长切 → 回快切
```
- 长切=观众情绪呼吸孔——别让观众疲劳

### 4. POV 切入
```
客观快切 → 1-2 帧 POV（主角视角）→ 回客观
```
- POV=代入感放大器——关键时刻插入

## 节奏与战斗阶段匹配

### Phase 1 试探（见 125）
```
ASL 2-3s，中紧凑
每招完整呈现，不快切
目的：让观众看清招式+建调子
```

### Phase 2 升级/压制
```
ASL 1-2s，快激烈
多角度冲击帧，势来回时切多
目的：累积势转换+绝望
```

### Phase 3 绝境
```
ASL 5-8s，极慢
倒地闪回/呼吸停顿/同伴呼喊
目的：情绪沉淀+顿悟准备
```

### Phase 4 爆点
```
ASL 0.3-0.8s，极快乱
连击+冲击帧+慢镜嵌入
目的：终极爆点
```

### Phase 5 释放
```
ASL 5s+，极慢
战场残局+主题回响
目的：情绪落地
```

## 节奏曲线模板（4 段战斗）

```
段1（试探）：3-3-3-4-3 ASL（中稳）
段2（升级）：1.5-1-2-1.5-0.8 ASL（锯齿加速）
段3（绝境）：8-6-7 ASL（骤慢+顿悟）
段4（爆点）：0.5-0.3-慢镜-0.5-0.3（极快+慢镜嵌入）
段5（释放）：6-8 ASL（长切呼吸）
```
- 这是经典战斗节奏曲线

## 常见坑
- **全程快切**：80+ 切/分钟=观众疲劳+情绪累
- **快切无慢段**：没呼吸孔=观众累=情绪无法累积
- **慢段太长**：试探段 8s 一镜=拖
- **节奏同质**：5 段都是 ASL 2s=乏味
- **爆点无骤停**：直接快切到爆点=爆点无重量

## 进阶
- **节奏可视化**：用柱状图标注每镜时长=直观调整
- **音乐同步**：关键切点对齐音乐重拍=节奏感加倍
- **反节奏**：观众期待快时给慢镜=爆点放大
- **节奏签名**：每角色给固定节奏签名（如反派慢沉，主角快灵活）

## 备注
- ASL 是节奏硬指标
- 快-慢-快波形=战斗节奏黄金
- 骤停帧+慢镜嵌入是爆点放大器
