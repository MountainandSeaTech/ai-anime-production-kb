# Krump 狂派舞：四大元素与爆发语法

## 核心要点

- Krump 2000 年代初由 Tight Eyez 与 Big Mijo 创立于洛杉矶中南部，名字源自 **K.R.U.M.P = Kingdom Radically Uplifted Mighty Praise**；脱胎于小丑舞（Clowning）但走向"狂派"——**把情绪外化成可见的爆发**
- 四大基础动作：**Chest Pop（胸爆）、Stomp（重踏）、Arm Swing（抡臂）、Jab（快刺）**；质感词叫 **Buck（野、爆、有冲击力）**
- 与 Popping 的胸 pop 形似神不同：popping 的 pop 是"电击般干净收放"，krump 的 chest pop 是"**被音浪砸中后整个人炸开**"——含呵气、带身体位移、幅度大、有情绪叙事
- 表演单位是 **Session（情绪段落）**：攒能量（stance 对峙）→ 小爆发（jabs/stomp）→ 大爆发（连续 armswing+chest pop）→ **Kill Off（失控式终结：甩头、踉跄、砸地、倒地）**
- **动漫短剧适配度极高的舞种**：变身觉醒、怒气爆走、解除封印、野兽化——krump 的"平静→攒劲→炸开→失控"曲线直接就是变身戏的动作脚本

## 详细内容

### 一、四大基础动作

#### 1. Chest Pop（胸爆）
- **做法**：鼻吸气蓄力，嘴猛地呵气，胸肌/胸廓向某一方向**爆发推出并带回**，肩保持沉重（不是耸肩！），力量从核心炸出
- **方向**：前爆、上爆、侧爆、斜爆；连续多方向 chest pop 像被多拳连续击中
- **观感**：胸口挨了音波/重拳的反应；常配整个人退步或下沉
- **与 popping 区别对照**：

| 项 | Popping hit（319） | Krump chest pop |
|---|---|---|
| 幅度 | 原地小、只看肌肉 | 全身大、带位移 |
| 呼吸 | 不强调 | 必有可见呵气/怒吼 |
| 情绪 | 冷静控制 | 愤怒/宣泄/被击中 |
| 肩 | 稳定 | 沉重但可被带起 |

#### 2. Stomp（重踏）
- **做法**：整条腿像灌铅般**整脚重重砸地**，胯随之沉、对侧身体可被震起；声音和震动感是动作的一部分
- **变体**：前跺、侧跺、交叉跺、连续点地小跺（pounds）
- **镜头价值**：落地帧配地面扬尘/地裂特效/低频音效＝"力量型角色登场"标准镜头

#### 3. Arm Swing（抡臂）
- **做法**：整条手臂伸直像鞭子/棍棒**大幅度抡砸**——上抡、下劈、横扫，带躯干转动；Tight Eyez 比喻为"用拳头连续猛击假想敌人的上盘再打下盘"
- **要点**：臂要直、轨迹要满（画整圆或半弧），不是挥拳的短直线
- **连击**：连续 armswing 左右交替时身体随之拧转，像在人群中打一场看不见的群架

#### 4. Jab（快刺）
- **做法**：手臂短促、快速地向前/侧连续戳刺（直拳式但放松），像驱赶看不见的东西
- **用途**：session 的"小剂量高频"填充，配合脚步逼近/后退，建立紧张感

### 二、脚步与身体词汇

- **Stance（架势）**：双腿大开微蹲、重心压低、双拳架起——krump 的对峙蓄势位，可在重拍抖胸或小晃
- **Get-off / Step out**：爆发前的脚步启动，一脚猛踩切入攻击距离
- **Travel**：用大踏步/滑步快速突进或绕圈追打"空气敌人"
- **Pound / Bang**：拳或肘向下短促砸（真砸在自己大腿/胸口出声也常见）
- **Lab / Sync**：krump 中两人同步对舞的高难配合（battle 高级玩法）
- **Storytelling（叙事段）**：用动作演情境（照镜子、掐脖子、被附身、心脏被揪出）——与变身戏直接同源

### 三、Session 情绪曲线（Krump 的段落结构）

```
① Stance 对峙（2-4拍）：低重心、呼吸可见、小 chest pop 攒能量
② Jabs+小 Stomp（4-8拍）：能量外漏、脚步逼近、动作短促高频
③ 爆发段（8-16拍）：连续 arm swing + 大 chest pop，
   身体大范围位移、抡臂轨迹完整，可加怒吼/呵气声
④ Kill Off 终结（2-4拍）：动作"过载"——
   头猛烈甩动、踉跄退步、单膝或双膝砸地、身体痉挛式抖动、
   甚至倒地，最后一个重拍骤然静止（接 freeze 或瘫软）
```

- **关键对比**：前 80% 时间越克制（小 jabs、沉 stance），kill off 越炸；全程狂砸反而贬值（对应冲击帧贬值律301）
- Battle 中 kill off 是"我这段结束"的宣战信号，对手必须用更猛的一轮回应（攻防逻辑见328）

### 四、动漫场面映射表

| 剧情需求 | Krump 动作配置 | 镜头/特效配合 |
|---|---|---|
| 变身/觉醒 | stance 蓄力→chest pop 连续上爆→kill off 甩头 | pop 帧叠能量波（305），kill off 升格半秒 |
| 愤怒爆走 | armswing 连击 + stomp 追步 | 手持晃动跟拍、落地尘、快速推近 |
| 被附身/操控 | storytelling 掐喉+反向身波+不受控 jabs | 眼神失焦、关节反向顿点（混 popping 语法319） |
| 怪力登场 | 连续 stomp 入场 | 低机位，每跺配低机位震（300） |
| 野兽化 | stance 弓背 + 地面 travel + 双手砸地 | 贴地低角、慢推、剪影（068） |

## 关键参数 / 模板 / 清单

### 提示词模板（Krump 爆发段）

```
dancer krumping, [阶段：coiled stance / explosive combo / kill-off],
violent chest pops exploding forward with sharp exhales, heavy full-foot stomps, 
long straight arm swings whipping overhead and across like hitting an invisible enemy, 
rapid jabs, low aggressive stance, large full-body displacement, 
raw aggressive emotion, wild buck energy,
handheld camera low angle pushing in, dust from stomps, [场景]
收束：final kill-off — head whip, stumble, drop to knees, sudden stillness on beat
负向：clean tiny popping hits, ballet lines, relaxed smiling dancer, 
small wrist-only movement, stiff torso, floating jumps, choreographed boyband poses,
shaky cam so extreme that body leaves frame
```

### 变身戏专用节拍脚本（16拍）

```
拍1-4   近景：低头、呼吸、stance 微颤，灯光低压
拍5-8   中景：chest pop ×2（被能量顶起），脚步被逼退半步
拍9-12  全景：armswing 连击左右，stomp ×2，地面尘起，特效能量外溢
拍13-15 升级：连续三向 chest pop + 甩头，镜头手持急推
拍16   杀招：kill off 双膝砸地+仰天怒吼→骤静0.5秒→（变身完成切造型）
```

### 验收清单

- [ ] 胸爆是"推出-带回"带呵气，不是耸肩或原地小抖
- [ ] Stomp 整脚砸地、胯沉，看得清重量（不是踮脚跳）
- [ ] Arm swing 臂直、轨迹满（半圆以上），带躯干拧转
- [ ] 爆发前有明确的蓄力/克制段，对比成立
- [ ] Kill off 有"过载失控"动作并在重拍戛然静止
- [ ] 情绪写在脸上/呼吸上（皱眉、呵气、怒吼），不是空做动作
- [ ] 手持晃动有分寸：身体始终在画面安全框内

## 备注

- Krump 不是暴力舞：其文化内核是把街头暴力冲动转化为非接触的舞蹈对抗，battle 中身体接触属犯规
- 早期 clowning 有画笑脸彩绘传统，krump 保留少量 face paint 仪式但非必需；资产设计中彩绘＝小丑舞（Clowning）视觉信号，勿与 krump 混用
