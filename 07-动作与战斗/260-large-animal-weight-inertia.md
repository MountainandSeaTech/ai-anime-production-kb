# 大型动物的重量与惯性

## 核心要点
- **惯性延迟**：大型动物启动与停止都有 0.5–2 秒延迟——先见肌肉蓄力，再见位移；瞬启瞬停＝假
- **人体代偿**：人拉大型动物身体大幅前倾（15–30°）、推时后仰（10–20°）、重心下沉步幅缩短；直立不动拉动巨兽＝物理穿帮
- **肌肉语言**：拉拽时人体肌肉紧绷、颈筋暴起、脚步打滑或蹬地——力量必须"看得见"

## 详细内容
- **启动三段**：动物重心下沉蓄力 → 肌肉隆起/低吼 → 才开始位移；巨兽起步"慢而重"本身就是威严感
- **止步更难**：奔跑的大型动物不能急停——有前冲滑行/多步缓冲；撞停时带起尘土/碎屑
- **拖拽失败也是戏**：人全力拖、巨兽纹丝不动，人踉跄前扑——力量悬殊本身可喜剧可绝望
- **扛/负大型动物**：扛在肩上时人步态小而沉、膝微屈、呼吸粗重；猎物四肢随步伐摆动（重力垂坠）

## 关键参数 / 模板 / 清单
```
参数（惯例值）：
  · 动物启动/止步延迟：0.5–2s（体型越大越长）
  · 人拉：前倾 15–30°；人推：后仰 10–20°
  · 拖拽步幅：缩短至正常 1/2–2/3，脚底有滑/蹬地细节
  · 急停滑行：按体重给 0.5–2 个身长的前冲缓冲

中文提示词句：
  「全力拖拽、身体后倾、双脚蹬地」「巨兽起步缓慢沉重，肌肉先隆起才移动」
  「奔跑的巨兽急停时前冲滑行、扬起尘土」
英文关键词：
  straining lean against the weight, heels digging in, slow heavy inertia start,
  muscles bunching before movement, skidding stop with dust
```
