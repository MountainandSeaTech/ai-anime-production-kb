# 高燃武打分镜 50 式·总索引与万能公式

## 核心要点

- 50 条模板分五大类型：**近身爆发（399）/ 兵器交锋（400）/ 异能法术（401）/ 高速瞬移（402）/ 必杀终结（403）**
- 用法三步走：**先定节奏（连击/重击/必杀）→ 再挑景别机位 → 最后填满场景反馈三层（地面塌了、空气炸了、背景崩了）**
- 一条分镜写全 8 项，画面基本不会空

## 详细内容

### 一、高燃分镜万能公式（8 要素）

```
景别 + 机位 + 运镜 + 角色 + 身体动作 + 特效层 + 场景反馈 + 节奏
```

一条分镜写全这 8 项，画面基本不会空。

### 二、场景反馈三层写法

| 层 | 对象 | 写法词库 |
|----|------|----------|
| 第一层 | 地面 | 裂 / 陷 / 翻 / 犁 |
| 第二层 | 空气 | 气浪 / 尘环 / 速度线 / 空间扭曲 |
| 第三层 | 背景 | 石柱断 / 建筑崩 / 云层涡 / 山岳崩 |

### 三、高燃节奏三件套

| 节奏 | 配方 |
|------|------|
| 连击 | 降格 + 跟拍 + 速度线 |
| 重击 | 升格 + 特写 + 定格 |
| 必杀 | 环绕 + 拉镜 + 全白 |

**用法**（原文）：先定节奏（连击/重击/必杀），再挑景别机位，最后把地面、空气、背景三层反馈填满——地面塌了、空气炸了、背景崩了，画面就立起来了。

### 五、战斗宏观三段式（近身 → 交手 → 收尾）

> 打斗不是招式堆出来的，是三步走出来的。单镜节奏靠"三件套"（上文第三节），**整场打斗的骨架**靠这三段：

| 段 | 任务 | 拼什么 | 典型招式词汇 | 对应本库模板类 |
|---|---|---|---|---|
| ① 近身 | 解决"怎么冲过去"——隔太远招式再猛也是空的 | **速度**：先贴上去 | 瞬身疾袭、飞踹、滑步突进、俯冲突袭、侧闪腾挪、贴身快打 | 402 高速瞬移、399 近身爆发 |
| ② 交手 | 贴上去之后手脚怎么交换，决定戏的骨架 | **因果**：有来有回（防→接→反打） | 卸力格挡、蓄势崩拳、避击反打、贴地横扫、交叉硬抗、瞬拔斩 | 399、400 兵器交锋 |
| ③ 收尾 | 把张力推到顶、把对手打穿，最后一帧砸得狠 | **狠劲**：一击定音 | 凌空旋风斩、浮空连击、霸体冲撞、退步蓄力重击、掌风震退、坠地裂地重击 | 403 必杀终结 |

**连招组装原则**（来源同下）：
- 从三段里**各挑一两式**串起来就是一套完整连招（近身式→交手式→收尾式），不要在同一段里堆三个同类招式
- 搭配词别堆满：一招配 3-5 个搭配词足够，**留白反而更高级**
- 打斗能不能燃不在词多，在于**会不会挑那一帧**——收尾段的"最后一帧"优先级最高

**国风武侠变体词库**：气浪成圈、灵气光晕/灵气激荡、剑气环绕、衣袂翻飞、拳风波纹、地面龟裂碎石迸溅——套到五大类模板上即为武侠风味；纯体术对决按项目规则走，法术类招式才过 G6 法术门。
