# 打狗棒法八诀三十六路

## 核心要点

- 丐帮帮主嫡传，三十六路变化，以**绊、劈、缠、戳、挑、引、封、转**八诀为总纲
- 结构：挑/封/绊/戳四诀各四式，转/引/缠/劈四诀各五式，共三十六式
- 定位：金庸体系最完善的无短板全能兵刃体系——以巧破万法，越遇强手越无解

## 详细内容

### 八诀释义
| 诀 | 功能 | 意象 |
|---|---|---|
| 绊 | 攻下盘、绊倒 | 扫腿绊足 |
| 劈 | 正面劈打 | 当头棒喝 |
| 缠 | 黏住敌械不放 | 细藤缠树，休想脱缚 |
| 戳 | 点刺穴道要害 | 快准点穴 |
| 挑 | 挑飞敌械 | 棒身伸出挑甩兵器前端 |
| 引 | 引偏敌力 | 四两拨千斤 |
| 封 | 封挡门户 | 压扁狗背式防守 |
| 转 | 身法旋转反击 | 恶犬回咬 |

### 招式名库（狗意象命名体系）
- 挑字诀：棒挑癞犬、歹挑狗身、捣乱狗窝、挑拨狗爪
- 封字诀：压扁狗背、饿狗拦路、犬牙交错、母狗护雏
- 转字诀：恶犬回咬、快击狗臀、丧家之犬、黄狗追尾、幼犬戏球
- 通用名招：拨狗朝天（挑飞敌械）、横打双獒（横扫双人）

### 动作设计特征
- **缠字诀是第一杀招**：竹棒如韧藤，缠住即不可脱——表现时用"棒身微弯的弹性"可视化
- 棒走轻灵不靠蛮力：招式名虽土，打法极雅——反差是角色魅力（洪七公/黄蓉）
- 打狗棒本身＝道具锚点：绿竹棒（关联 183 武器持久性）

## 关键参数 / 模板 / 清单

**提示词模板（缠字诀）**
```
绿竹棒如活物般缠上对手长剑，棒身微弯带弹性，任对方如何横甩直拉
都无法挣脱，棒尖始终黏在剑身上，持棒者手腕轻转，对手兵器被带得失去方向。
负向词：rigid staff, heavy brute force swings, weapon released easily,
stick phasing through sword
```

**八诀速查**：下盘→绊｜正面→劈｜黏械→缠｜点穴→戳｜飞械→挑｜卸力→引｜防守→封｜旋转→转

## 备注

- 招式名入提示词必须转译（"恶犬回咬"→转身回扫），模型不认招式名
- 缠字诀连续镜头中竹棒不可离手（关联 183）
