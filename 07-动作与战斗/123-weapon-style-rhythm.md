# 武器流派与战斗节奏

## 核心要点
- 武器不只决定招式——决定**节奏与镜头分配**
- 长兵器=远距离+大开大合+中远景多
- 短兵器=近身+快速连环+特写多
- 重兵器=慢蓄重击+慢镜+冲击帧
- 双兵器/奇门=节奏多变+组合技多
- 关联 144 居合斩、143 武器设计

## 武器节奏分类

### 长兵器（枪/棍/薙刀）
```
距离：远（2-3 米）
节奏：大开大合，单招间隔长
镜头：中景/全景为主（武器扫过画面要留空间）
爆点：扫击/突刺的瞬间冲击
```
- 长兵器扫击=横扫画面对角线=视觉张力大
- 突刺=直线纵深=可做透视爆点

### 短兵器（刀/剑/匕首）
```
距离：近（1 米内）
节奏：快速连环，单招间隔短
镜头：特写/中近景为主（手部动作要清晰）
爆点：交锋瞬间的火花/刀刃特写
```
- 短兵器招多=镜头切换要快
- 刀剑交锋的"叮"声+特写=经典爆点

### 重兵器（锤/斧/大刀）
```
距离：中远
节奏：慢蓄重击，单招间隔长+一击毁灭
镜头：慢镜+冲击帧（蓄力段慢镜，命中帧定格）
爆点：地面开裂/冲击波/物体飞溅
```
- 重兵器蓄力段=张力建压黄金段
- 命中帧必加 motion blur+冲击波环

### 双手兵器/奇门（双刀/锁镰/链）
```
距离：变化多端
节奏：节奏多变（快慢交替+组合技）
镜头：跟拍+环绕多（武器轨迹复杂）
爆点：组合技的连环冲击
```
- 链/鞭类=弧线运动=镜头要跟轨迹
- 双刀=左右交错=可做对称构图

### 远程兵器（弓/枪/暗器）
```
距离：远（视线内）
节奏：蓄力-锁定的静+发射的动
镜头：极近特写（瞄准眼/手）+POV（弹道视角）
爆点：弹道慢镜+命中瞬间
```
- 远程战的张力在"锁定"段——靶心特写+呼吸
- 弹道可做 POV 慢镜追弹

### 异能/魔法（见 148）
```
距离：任意
节奏：招式风格化强（每招一仪式）
镜头：仰拍+体积光多
爆点：能量释放帧+冲击波
```

## 节奏映射到镜头

### 慢节奏武器（重兵器/长兵器）
```
- 蓄力段：慢镜+呼吸特写+肌肉紧绷
- 挥击段：motion blur + 速度线
- 命中段：定格冲击帧+冲击波环
- 余动段：地面开裂/碎片飞溅慢落
```

### 快节奏武器（短兵器/双兵器）
```
- 交锋段：快切+多角度冲击帧
- 连击段：每击 2-3 帧切换
- 防守段：刀格挡特写+火花飞溅
- 翻转段：势转换时的慢镜停顿
```

### 变节奏武器（奇门/异能）
```
- 静段：诡异静止+悬念
- 动段：突发爆点+轨迹跟拍
- 转换段：节奏突变=观众错愕
```

## 武器节奏组合（双人战）
```
快 vs 慢：短兵打长兵=快攻vs大开大合
重 vs 轻：重锤vs双刀=毁灭vs连击
远 vs 近：弓vs刀=锁定vs突进
异 vs 常：魔法vs刀剑=超常vs常识
```
- 节奏反差=张力放大器——同节奏对战=乏味
- 主角武器节奏 vs 反派武器节奏=人设对比（见 139）

## 模板示例

### 居合斩（短兵+慢节奏）
```
建压段：极远对峙+呼吸静默
交锋段：极近特写拔刀瞬间+冲击帧
释放段：双方交错+慢镜+收刀入鞘
```

### 长枪对决（长兵+大开大合）
```
建压段：中景对峙+枪尖交错
交锋段：中远景横扫+突刺纵深
爆点段：枪尖相碰的火花特写
释放段：长枪折断特写+败者倒下
```

### 重锤碾压（重兵+慢蓄重击）
```
建压段：仰拍+肌肉蓄力慢镜
爆点段：地面冲击波环+碎片飞溅
释放段：尘埃散去+反派倒地全景
```

## 常见坑
- **快武器拍太慢**：短兵慢镜太多=节奏拖
- **慢武器拍太快**：重锤快切=没重量感
- **远程武器没弹道**：弓箭只拍命中=没锁定张力
- **节奏同质**：双方都用快武器=单调
- **武器与角色不配**：力量型角色用细剑=违和

## 进阶
- **武器节奏反差战**：主角快武器 vs 反派慢武器=张力加倍
- **节奏突变**：战斗中段换武器=节奏破口
- **武器损毁**：战斗中兵器断裂=势转换关键时刻
- **节奏停顿**：快节奏中插一帧静默=爆点放大
