# 动作前摇的累积

## 核心要点
- **前摇（wind-up）= 动作爆发前的预备动作**——拔刀前的手搭柄、出拳前的沉肩、跳跃前的屈膝
- 前摇是 011 延迟释放的物理化：该爆发的事被"预备动作"拖延
- **前摇越长、越细节，张力越强**——但超过 3 秒变拖
- 前摇是 build-up 段的肌肉，014 曲线的"蓄"主要由前摇填充

## 前摇的张力原理
- 前摇让观众看到"要动了"但还没动=预期被激活但未满足=揪心
- 前摇的物理细节（手发白、肌肉绷、重心移）= 爆发能量的"可见储存"
- 前摇结束时爆发=储存能量一次释放=峰值

## 前摇的分解层次（从粗到细）

| 层次 | 内容 | 时长参考 |
|---|---|---|
| 全身前摇 | 重心下沉、姿势转换 | 0.8-1.5s |
| 局部前摇 | 手搭武器、肩沉、膝屈 | 0.5-1s |
| 微前摇 | 手指收紧、呼吸屏、瞳孔缩 | 0.3-0.5s |
| 极限前摇 | 刀柄特写、屏息特写 | 0.2-0.3s |

> 层次越多=前摇越立体=张力越满。新手只拍全身前摇，老手拍到微前摇。

## 前摇的累积序列（标准五段）
```
全身前摇（重心下沉，1s）→ 局部前摇（手搭柄，0.8s）→ 微前摇（手指收紧，0.4s）→ 极限前摇（屏息特写，0.2s）→ 爆发（0.3s）
```
从全身到极细节，注意力逐级压缩到一点，再释放。这是居合/拔枪/突进通用的前摇骨架。

## 前摇的拉长技巧（不加时长也能加压）
- **插入反应镜**：前摇中切对手的惊觉反应，前摇时长不变但揪心翻倍
- **升格微前摇**：把 0.3s 的微前摇升格到 0.6s，细节被放大
- **多角度重复**：同一前摇瞬间从不同景别拍两三镜，时间被"展开"
- **微表情叠加**：前摇同时配呼吸/眼神信号（024）

> 这些技巧让前摇不靠"拖时间"而靠"密度"加压，避免拖沓。

## 前摇的常见坑

### 前摇太短
- 直接从静止跳到爆发，没有预备=观众没预期=不揪心
- 自检：爆发前有没有至少 1 秒前摇？

### 前摇太长
- 超过 3 秒=拖，观众出戏
- 解法：用上面拉长技巧加密度而非加时长

### 前摇无细节
- 只拍全身前摇没拍局部/微前摇=层次单薄
- 解法：至少拍到微前摇层

### 前摇被打断
- 前摇中插入无关镜头=预期被浇灭
- 解法：前摇段一镜到底或只在相关主体间切

## 经典前摇案例

### 居合拔刀
```
居合站姿（1s）→ 手搭柄（0.5s）→ 手指收紧特写（0.3s）→ 屏息特写（0.2s）→ 出刀（0.3s）
```

### 狙击开枪
```
抵肩（1s）→ 手指搭扳机（0.5s）→ 屏息特写（0.3s）→ 扣动瞬间（0.2s）→ 开枪（0.2s）
```

### 突进起手
```
低姿态（1s）→ 撑地手指发白（0.5s）→ 重心前移（0.3s）→ 爆发突进（0.4s）
```

## AI 提示词
- 前摇段优先静态+微动：`winding up, hand tightening on hilt, breath held, about to draw sword`
- 升格微前摇：`slow motion, fingers tightening, micro tension before strike`
- 避坑：AI 生成"完整动作"时容易跳过前摇直接到爆发，要单独生成前摇镜再拼接

## 备注
- 前摇是 014 build-up 段的核心内容，与 025 待机姿势、024 微表情三位一体
- 前摇的"细节密度"比"时长"重要——加细节而非加秒数
- AI 视频里前摇镜要单独生成（带 about to / winding up 词），别指望一条 clip 完成前摇+爆发
