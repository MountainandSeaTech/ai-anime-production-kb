# 技能魔法编写二十连⑱：现代异能的编写与边界

## 核心要点

- **越抽象的能力越需要硬边界**：时间、空间、心智、概率、因果系一旦"按需发挥"，悬念与公平感立刻死亡。观众能容忍复杂规则，**绝不容忍移动的球门**——规则早锁、全程一致，复杂不是问题，摇摆才是
- 高抽象能力四件附加工作：①选定逻辑模型并锁定（如时间三模型）②专属边界清单（防万能化）③介质显影（抽象必须有可见现象，281/374）④日常与社会后果（能力在非战斗世界留下什么）
- **情感真实永远胜过技术黑话**：时间系的好故事不在物理自洽，在"回去也救不了"的情感必然——机制选够用的，不选最炫的
- 都市异能额外一层：**普通人社会如何容纳能力**（隐藏/收编/商业化/污名）——社会设定本身就是限制来源与故事土壤

## 详细内容

### 一、时间系：先选模型（生产级决策，不可中途换）

| 模型 | 规则 | 叙事质地 |
|---|---|---|
| 闭环/自洽（诺维科夫） | 过去不可改，你以为的改变本就是历史 | 宿命、"自己救自己"、情感闭环 |
| 分支/多世界 | 改动产生新支线，原世界不变 | 低风险但高孤独（救的不是你的人） |
| 可变/蝴蝶效应 | 过去可改且波及现在 | 戏剧张力最大、烧脑与崩盘风险最高 |

锁定后每个镜头都服从它。配套边界（至少选三）：
- 回溯时长/次数/冷却；是否携带物品/他人
- **不能重复刷**：同一时刻只能去一次/回溯有损耗（每次回去旧伤加重）
- 时间规则下的信息边界：只看不改？能停留多久？
- 时停系：停时内物体规则（空气变墙？食物？）、作用半径、维持消耗、谁能一起动
- 时间系对决：两个同系能力者的交互规则必须提前写明（参考"时删vs时停"式内战推演表）

### 二、空间系：瞬移/传送/结界/维度

瞬移专属边界：
- **瞄准规则**：必须去过/看见/有坐标的地点；盲跳有风险（穿模/掉到"别的地方"）——熟悉度决定精度，研究一个地点要时间
- 距离/质量上限与消耗（带人与带货成本不同）
- 冷却、起手动作、落点置换（空气被挤开的音爆？）
- 室内/封印/坐标被屏蔽怎么办
战术推论（368素材库）：用锚点物品反制（偷他的坐标物）、逼他盲跳、用熟悉的地形反杀。
传送门/结界：开门方向、持续维持、门框实体可否被破坏、门两侧的声音/光线规则。

### 三、心智系：读心/控心/幻觉/记忆

- **读心**：表面念头还是深层记忆？同时接收几人？嘈杂人群是否过载？对方知不知道被读？——**最强限制是社交性的**：会读心就没有"不知情的亲密"，关系戏天然成立（364缺陷内嵌）
- **控心**：语言/视线/接触触发；被控者是否有模糊记忆；抵抗机制（训练/强烈情绪/另一个心智）
- **幻觉**：五感全包还是单通道？受害者如何验证（掐自己/看镜像/数手指）？施术者能否移动
- **记忆操作**：改动会不会被缺口识破？被改者的情绪惯性怎么办
心智系铁律：**不能让它替编剧解决情报难题**——读心者必须在"想知道的真相"前受阻（目标无思维/被屏蔽/读到的是假记忆），真相仍靠剧情挣。

### 四、概率/因果/现实改写系（最危险区）

- 唯一安全写法：**把抽象重写成具体的窄机制**——不是"改变概率"，而是"让接触到的硬币连续正面/让瞄准他的下一枪卡壳（每天一次）"
- 锚定：必须接触/必须说出口/必须付出等量代价（守恒式约束，371）
- 因果系（言灵/名字/契约）：规则字面化＋漏洞即战场（JOJO式），观众要能逐字复盘
- 现实系视觉最难：用**结果倒推**表现（杯子无故碎裂、风向突变、所有人同时沉默）而非能量光——恐怖/神性向，慎用

### 五、抽象能力的介质显影（AI视频口径）

| 抽象 | 介质选择 |
|---|---|
| 时停 | 灰化冻结的尘埃/雨滴悬停＋只有他在动的色块；声画全静（352/369静默语法同源） |
| 瞬移 | 残像＋空气填充的尘环＋落点音爆；少做发光隧道 |
| 读心 | 不做脑内CG（廉价），用被读对象的微表情特写＋声音设计（低语叠化） |
| 幻觉 | 让观众也被骗的整段"正常镜头"＋一个物理穿帮点（影子方向错） |
| 概率 | 小动作链蒙太奇（一连串恰好）＋轻微画面跳帧 |
原则：抽象能力的视觉预算花在"世界如何不同"上，不花在"能力多亮"上（347/354节制）。

### 六、日常后果（让能力活在周一早上）

- 瞬移者不需要车也不敢坐飞机（安检/监控社会）
- 读心者在人群中戴耳机是为了降噪；吵架时不敢直视
- 时间系反复经历同一天的心理耗损；他的旧伤来自"根本没发生过的未来"
- 社会四态择一：隐藏（假面规则）／收编（注册制/单位编制）／商业化（代驾式APP）／污名（被追捕）
- 社会态决定题材：隐藏→身份悬疑；收编→体制戏；商业化→讽刺；污名→逃亡

### 七、边界自检（高抽象专用）

1. 用这个能力能不能两句话解决主线最终问题？能→加限制或改主线
2. 规则能否写成一页且无"视情况"？有视情况=球门可移动
3. 主角的胜利是否仍靠选择与代价而非机制万能？
4. 能力对日常关系的影响有没有被写进至少3场文戏？
5. 视觉方案是否明确（观众看什么知道它发动了）？
