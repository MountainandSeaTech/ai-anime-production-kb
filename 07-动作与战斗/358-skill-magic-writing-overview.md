# 技能魔法编写二十连①：编写总纲

## 核心要点

- **"技能编写"不是写一个大招画面，而是设计一个跨四层的系统**，任何一层缺失能力就塌：
  1. **设定层**：它是什么、规则、来源、代价、边界（世界观内自洽）
  2. **叙事层**：它制造什么冲突、选择、代价时刻、成长节点（故事能用）
  3. **视觉层**：长什么样、显形口径、介质、交互（观众记得住）
  4. **提示词层**：拆成AI可执行的动作白描/光色/交互（模型生成得出）
- 新手顺序常是4→1（先想画面再补设定），正确顺序是1→2→3→4：**先有规则，再有戏，再有画，最后拆词**
- 行业共识（Sanderson体系）：作者用魔法解决冲突的能力，与读者对该魔法的理解程度成正比；**限制比能力更有趣**（详见359/362）
- AI番剧的额外约束：能力必须"可稳定生成、跨镜一致、成本可控"——设定阶段就要预判视觉工艺（对接348-357特效十连）

## 详细内容

### 一、四层模型展开

**L1 设定层（能力卡）**：名称/来源/原理一句话/发动条件/输入与输出/作用域/代价/冷却或次数/克制与被克/成长上限。产物进"能力圣经"（377）。
**L2 叙事层（戏份账）**：这个能力将制造的——困境（条件难达成）、选择（用还是不用）、代价时刻（用了要还）、关系戏（队友依赖/敌人觊觎）、成长（规则突破）。列不出5场戏的能力不值得设计。
**L3 视觉层（美术口径）**：显形分级（290的L1-L4）、色板、介质、伴随现象、听觉、触觉反馈、环境后果。全剧统一进视觉圣经。
**L4 提示词层（生成口径）**：招名禁入提示词（271铁律），拆成动作白描＋物理描述＋交互结果＋镜头语言；英雄镜走356合成路线。

四层之间是**翻译**关系：设定层"地脉共鸣"→叙事层"每用一次身体石化一寸"→视觉层"灰褐岩纹沿皮肤攀爬+石粉尘落"→提示词层"subsurface裂纹蔓延，指尖变灰石质感，碎屑脱落……"。

### 二、好能力的七条标准（设计自检）

1. **有规则**：观众学一次就能预测"他能不能做到"——规则产生参与感
2. **有限制**：有明确不能做的事；限制是困境的来源（359/361）
3. **有代价**：使用要还，而且最好是不可完全恢复的东西（362）
4. **有个性**：换个人用不应该一样——能力是性格与身体历史的延伸（364/275劲路差异）
5. **有成长**：规则内可精进、可突破，突破必须有铺垫与代价（370）
6. **有画面**：一眼可辨的核心意象，且能稳定生成（374）
7. **有区分度**：同剧其他能力在机制/色板/节奏上拉开，不做换皮（373）

附加：**有反面**——它被克制、会失效、有代价发作时的狼狈（368/369），能力才完整。

### 三、能力的五种功能（写戏时对号入座）

| 功能 | 例子 | 注意 |
|---|---|---|
| 解决外部问题 | 战斗、破坏、抵达 | 最浅，不能只有这一种 |
| 制造内部冲突 | 力量与道德/关系冲突 | 好作品的主用法 |
| 暴露人物 | 怎么用比能用什么更说明人 | 364 |
| 建立世界规则 | 能力边界即社会结构 | 谁能用决定阶级/经济 |
| 成为主题载体 | 能力的代价＝作品主题 | 海裂：沟通而非消灭 |

### 四、AI番剧特有的三道视觉闸门（设定期就要过）

1. **可生成性**：机制是否能转化为可见现象？纯抽象（"概率操控""因果律"）必须找介质显影（281）——否则观众和模型都不知道在看什么
2. **一致性成本**：该视觉是否容易跨镜复用？优先设计可做成元素板/固定色板/固定手势的能力（356）
3. **身份兼容性**：发动时的大动态/变身会不会毁脸？高毁脸率能力配无脸拍法/分镜预案（345/355）

## 关键参数 / 模板 / 清单

**新能力立项四问（过不了就别画）**
```
1. 一句话原理是什么？规则边界用一句话说得清吗？
2. 代价是什么？使用后人物失去了什么？
3. 它能制造哪5场戏（困境/选择/代价/关系/成长）？
4. 它的核心可见意象是什么？AI如何稳定生成？
```
