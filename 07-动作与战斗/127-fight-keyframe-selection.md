# 战斗关键帧选择

## 核心要点
- 战斗分镜不是逐帧画——是**选关键帧**
- 一招四关键帧：**蓄力 + 接触 + 变形 + 反作用**
- 关键帧选错=动作糊+无冲击
- 选帧原则：选动作**最戏剧**的瞬间=戏剧峰值
- 关联 026 蓄力、059 冲击帧

## 一招四关键帧骨架

### 1. 蓄力帧（Anticipation）
```
功能：动作反向准备，预示爆发
内容：
  - 拳头后拉/身体下沉/武器扬起
  - 表情专注/眼神锁定
  - 重心转移（前脚后撤）
镜头：中近景，可见全身蓄力姿态
```
- 蓄力越大=爆点越强（动作大小决定蓄力大小）
- 没蓄力帧=突兀=无张力

### 2. 接触帧（Contact）
```
功能：动作生效的瞬间
内容：
  - 拳头贴脸/刀刃交剑/脚踩地面
  - 双方身体最近接触点
  - 表情刚要变形的瞬间
镜头：特写/极近景（接触点）
```
- 接触帧是冲击帧的核心——见 059
- 接触瞬间定格=爆点

### 3. 变形帧（Deformation）
```
功能：冲击造成的结果
内容：
  - 颧骨凹陷/衣料拉伸/地面开裂
  - 物体飞溅（火花/碎片/血滴）
  - 受击方表情扭曲
镜头：特写（变形部位）
```
- 变形=冲击的视觉证据
- 关联 060 形变张力

### 4. 反作用帧（Reaction）
```
功能：动作的余动与结果
内容：
  - 出招方手停在挥击尽头（惯性）
  - 受击方飞出/倒地
  - 武器反弹/震动
镜头：中景（双方身体余动）
```
- 反作用=动作的"尾巴"——没尾巴=动作假
- 关联 117 动作词汇库的 follow-through

## 选帧原则

### 原则 1：选戏剧峰值
```
不要选"中间"帧——选动作的高潮瞬间
拔刀：选刀出鞘那一刻，不是拔到一半
挥拳：选拳头贴脸那一刻，不是挥到中间
爆炸：选爆炸瞬间，不是火光刚起
```

### 原则 2：选张力峰值
```
张力曲线最高点=关键帧
建压段：选"最静"那帧（呼吸停顿）
爆点段：选"最动"那帧（接触瞬间）
释放段：选"最远"那帧（人变小）
```

### 原则 3：选清晰方向
```
动作方向要一眼看清
避免：身体遮挡、动作重叠、姿态模糊
关键帧应有清晰"动作线"（line of action）
```

### 原则 4：蓄力配反作用
```
有蓄力帧必有反作用帧
蓄力越大→反作用越大
无蓄力无反作用=动作假
```

## 战斗分镜板模板

### Initiation 段（首击）
```
帧1：双方对峙静默
帧2：A 蓄力（拳头后拉）
帧3：A 接触 B（拳贴脸特写）
帧4：B 变形（颧骨凹陷）
帧5：B 反作用（飞出倒地）
```
- 3-4 帧足够——别画太多

### Exchange 段（势来回）
```
帧1：A 蓄力+B 防御姿态
帧2：A 接触 B 武器（武器交剑特写）
帧3：B 反击蓄力
帧4：B 接触 A（A 挨打特写）
帧5：A 反作用（踉跄后退）
```
- 势来回的核心是双方都有接触+反作用

### Climax 段（终极爆点）
```
帧1：A 蓄力（极慢镜头+极近特写）
帧2：A 出招过程（速度线）
帧3：接触帧（定格+冲击波环）
帧4：B 变形（衣服破碎+地面开裂）
帧5：B 反作用（飞出远景）
帧6：A 余动（手停在挥击尽头）
```

## 不同战斗阶段选帧策略

### 建压段
- 选静帧为主（呼吸/目光/微调）
- 偶尔插入 1 帧动作信号

### 交锋段
- 蓄力+接触帧为主
- 变形+反作用快过

### 爆点段
- 4 帧全用+慢镜嵌套
- 接触帧定格最长

### 释放段
- 反作用帧为主
- 大远景的"人变小"

## 常见坑
- **只画接触帧**：没蓄力没反作用=动作突兀假
- **画中间帧**：选了"动作中间"=无戏剧瞬间
- **方向不清**：动作线被遮挡=观众看不懂
- **关键帧过多**：8 帧一招=拖+无爆点
- **接触帧无定格**：直接过渡=冲击感散

## 进阶
- **慢镜嵌套**：接触帧做慢镜，其他帧快过=爆点放大
- **变形夸张**：动漫允许非物理变形=冲击力加倍
- **反作用延迟**：接触后留 1-2 帧再反作用=爆点放大
- **冲击波环**：接触帧加冲击波环=视觉爆点强化

## 备注
- 一招四帧：蓄力+接触+变形+反作用
- 选戏剧峰值瞬间，不选中间帧
- 接触帧必定格——是爆点核心
