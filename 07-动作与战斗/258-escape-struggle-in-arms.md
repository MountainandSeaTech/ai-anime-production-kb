# 怀中挣扎/逃脱动作设计

## 核心要点
- **挣扎有逻辑**：对抗支点＋扭转逃脱——动物先找支点（蹬人手臂/胸口），再把身体扭成 C 型或 S 型从间隙里"拧"出去
- **头先走**：头部先转向逃脱方向，身体再跟上——头不动只扭身＝无方向的乱晃
- **挣扎分档**：轻度不满（蠕动调整）→ 明确抗拒（弓背推蹬）→ 全力逃脱（爆发式连续扭挣）——按剧情选档，别上来就爆发

## 详细内容
- **人体侧配合**：抱持者会本能收紧手臂、换手、调整抱姿压制——挣扎戏是双方的，不是动物独角戏
- **逃脱成功帧**：动物挣脱瞬间有"滑出"感（毛发从手臂间挤出），落地四肢着地缓冲，立刻拉开距离回望——回望是"它还有戏"的信号
- **喜剧变体**：挣扎中动物从臂弯"漏"下去（液体感逃脱），人抱了个空还保持抱姿半秒——捧空定格即笑点

## 关键参数 / 模板 / 清单
```
参数（惯例值）：
  · 挣扎频率：2–4 次/秒的扭动
  · 身体扭转角：30–90°（C/S 型）
  · 爆发逃脱：连续 2–3 次方向交替的扭挣后滑出
  · 人侧反应：收紧手臂（0.2s 内）、低头看、换托举点

中文提示词句：
  「弓背扭身、四肢推蹬着手臂找支点，从臂弯间隙里挣脱滑出」
  「头先朝逃脱方向转，身体跟着拧出去」
英文关键词：
  arching back twisting escape, paws pushing for leverage,
  head turning toward escape direction first, slipping out of the arms
```
