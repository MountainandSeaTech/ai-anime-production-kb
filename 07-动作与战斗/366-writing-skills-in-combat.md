# 技能魔法编写二十连⑨：战斗中写技能

## 核心要点

- **技能战的本质是棋局，不是烟花展**：每个回合完成一次"出意图→出招→应对"的问答；好打的看点是双方怎么**读对方**与**改方案**，不是谁的光更大
- **能力在战斗中只许"被使用"，不许"被讲解"**：机制靠应用瞬间让观众看懂（他用火点燃地上的油→观众学会火+环境组合）；停下来解释规则＝节奏自杀，讲解放训练戏与赛前分析
- **beat-breath-burst节律**：beat（具体小动作）→breath（半拍空间：眼神/换位/喘）→burst（抓住破绽的连击）——全程burst等于没有burst
- 漫画/分镜三段法适用于AI分镜：**蓄力（让观众预知要来了）→命中（最大格/最大冲击）→后果（伤害/位移/环境）**，与291蓄爆延反、306冲击帧管线同构

## 详细内容

### 一、回合棋模型（能力对打的基本单位）

每个回合四步：
1. **意图**：他此刻要什么（击倒/夺物/护人/拉开距离/试探）——意图让动作有方向
2. **出招**：用什么机制解这步题（首选方案体现人设，364）
3. **应对**：对方怎么读、怎么破——防住/闪避/受身/反制/将计就计
4. **更新**：局面变了（距离/伤势/地形/信息/代价账），下回合从新局面出发
- 检验：抽掉任一回合，后面的胜负是否还成立？成立＝这个回合是填充，删
- 每场战斗一张"回合表"：写下每回合的局面变化，保证局面**单调推进不重复**（不能连续三回合"又对轰一拳"）

### 二、让观众看懂：首看者测试

找一个**没读过设定**的人看分镜，问三个问题：
1. 现在谁占上风？（看不懂＝没有局面信息：距离/伤/体力/代价没被拍出来）
2. 他为什么这样打？（看不懂＝意图没拍：缺蓄力犹豫、缺目标特写）
3. 这招赢在哪/输在哪？（看不懂＝机制因果不清：动作与现象之间缺干净镜头）

AI分镜落实：
- **意图镜头**：眼神/目标物特写、起手蓄力（gootaku的buildup：拳头握紧的特写＋拉开的全景＋防守者"看见了"的反应）
- **出招镜头**：机制因果完整的一条
- **命中镜头**：冲击帧规格最大（292-311），低速/静帧/慢镜预算给这里
- **后果镜头**：伤害、碎物、位移、双方喘息

### 三、战斗中"教规则"的合法手法

- **失败教学**：他用A方式失败（踩了边界），换B方式成——观众同时学会限制和解法
- **对手之口**：老江湖一句"他离地就完了"——点破边界且不打断节奏（372）
- **赛前半秒**：接战前的眼神扫场地（水/铁/制高点）——预告他要用的环境资源
- **回忆闪用**：训练时一句话在应用瞬间闪回（≤1秒字幕式），首因359规则已前置才允许
- 严禁：战斗中角色自言自语向空气解释自己能力的说明书式台词

### 四、攻防转换的六种推进燃料

1. **机制被读**：招牌技被看穿，逼变招（成长来自应变不是蓄力）
2. **地形变化**：打进新区域（水边/窄巷/高处）换解题条件
3. **第三方插入**：人/兽/事件改变局面（慎用，不能替主角解题）
4. **代价催缴**：旧伤/石化/失声发作（362）——能力被自己的身体限制
5. **信息揭露**：发现对方能力真规则/真身/意图反转
6. **押注升级**：从"想赢"变成"必须护某人/必须在X秒内"——目标改变打法

### 五、节奏：beat-breath-burst与镜头配额

- **beat**：短句/短镜，具体动作与摩擦动词（撞、格、滑、踩）
- **breath**：半拍空间——错身时的对视、退半步的喘息、落地后的静止；breath是burst的利息
- **burst**：抓住破绽的连击/连招/大招，密度与速度最高
- 分配：长战斗按"三短一长"（多个小回合后压一个大回合）；大招只在burst顶点出现且全战≤2-3次（357/301冲击帧配额）
- AI生产：burst段才动用大动态+冲击帧+多pass预算（345）；beat/breath用稳镜省钱，反差本身强化burst

### 六、能力战对白（战斗台词的三种功能）

只允许三类：①宣告意图/嘲讽心理战（"你离地试试"）②现场教学的老手点评 ③暴露关系的人情话（师兄弟/宿敌）。每句≤一个短句，放在breath里，不放在burst上（304声画节奏）。

### 七、多人/群战中的技能调度

- 焦点只跟1-2个有名角色（347），其余技能只做色块与声势
- 每个有名角色每场只给一个"高光回合"，轮流转
- 组合技走367；大场面乐章走339

## 关键参数 / 模板 / 清单

**战斗回合表（一场一张）**
```
回合N：意图＿｜出招（机制用法）＿｜应对＿｜局面更新＿
起手局面：距离/地形/伤势/代价账
推进燃料（每回合标注哪种）：
大招配额：本场第几次（≤2-3）
节拍图：beat×N - breath - burst 位置
首看者三问复查
```
