# 动作戏视角×服装矩阵

## 核心要点

- 九种视角各有叙事功能：全景=交代动作全貌与重心；斜侧45°=纵深；近景=肌肉与表情击中瞬间；正面=对称与冲击；俯拍=拳路/持枪轴线的垂直轨迹；仰拍=腾空高度与力量感；侧景=身体侧面线条；攻击视角/被攻击视角=主客观镜头；静止姿势=pose定格。
- 同一动作的多机位分镜骨架：全景→斜侧→近景→仰拍/俯拍。
- 攻击/被攻击视角的对切用法：呈现施力者与受击者看到的画面，增强代入感。
- 服装作为动态放大器：贴身→肌肉线条可读；裙装→衣褶飘动增强动势。
- AI落地：单段内只用一个视角，视角切换靠分段；俯拍拳路、仰拍跳跃是性价比最高的风格化镜头。

## 详细内容

### 一、九种视角的叙事功能

| 视角 | 叙事功能 | 适用动作 | 视觉重点 |
|------|----------|----------|----------|
| 全景 | 交代动作全貌与重心 | 所有动作的起始与收势 | 全身构图、重心转移、距离管理 |
| 斜侧45° | 展示纵深与立体感 | 踢技、拳法的发力过程 | 身体纵深、动作层次 |
| 近景 | 捕捉肌肉与表情的击中瞬间 | 勾拳击中、防御格挡 | 肌肉紧张、表情变化、击中反馈 |
| 正面 | 对称与冲击 | 跳跃下劈腿、连续下劈腿 | 对称构图、双腿交替韵律 |
| 俯拍 | 展示拳路/持枪轴线的垂直轨迹 | 上勾拳、步枪射击 | 垂直轨迹、身体轴线 |
| 仰拍 | 突出腾空高度与力量感 | 跳跃动作、三角踢 | 腾空高度、空中姿态 |
| 侧景 | 展示身体侧面线条 | 跳跃下劈腿、侧翻 | 身体侧面轮廓、动作弧线 |
| 攻击视角 | 主观镜头：施力者看到的画面 | 斜上勾拳、突刺 | 目标逼近、攻击代入感 |
| 被攻击视角 | 主观镜头：受击者看到的画面 | 斜上勾拳、防御 | 攻击逼近、受击代入感 |
| 静止姿势 | pose定格 | 持刀戒备、背靠背 | 姿势美感、构图张力 |

### 二、同一动作的多机位分镜骨架

还原专业动作摄影的拍摄逻辑，同一动作按以下顺序排布分镜：

```
全景（交代动作全貌与重心）
  ↓
斜侧45°（展示纵深与发力过程）
  ↓
近景（击中瞬间的肌肉与表情）
  ↓
仰拍或俯拍（风格化强点：腾空高度/垂直轨迹）
```

**示例（横踢）**：
1. 全景：中距离戒备→重心移至支撑腿→提膝翻胯。
2. 斜侧45°：腰胯拧转发力，展示身体纵深。
3. 近景：踢击腿完全伸展击中目标，肌肉线条隆起。
4. 仰拍：踢击高度与力量感（可选）。

### 三、攻击/被攻击视角的对切用法

- **攻击视角**：摄影机从施力者背后/肩上拍摄，呈现施力者看到的画面——目标逼近、武器轨迹。
- **被攻击视角**：摄影机从受击者位置拍摄，呈现受击者看到的画面——攻击逼近、防御动作。
- **对切用法**：攻击视角→被攻击视角快速切换，增强紧张感与代入感。

**适用场景**：斜上勾拳、突刺、射击等有明显方向性的动作。

### 四、服装作为动态放大器

| 服装类型 | 功能 | 视觉效果 | 适用场景 |
|----------|------|----------|----------|
| 贴身（泳装/紧身衣） | 肌肉线条可读 | 发力时肌肉隆起、动作轨迹清晰 | 教学、动作分析、力量感展示 |
| 裙装（JK制服/百褶裙） | 衣褶飘动增强动势 | 踢击时裙摆扬起、转体时衣褶旋转 | 女子格斗、元气格斗、视觉美感 |

**服装选择逻辑**：
- 需要展示发力细节→贴身服装。
- 需要增强动态美感→裙装/宽松服装。
- 两者结合：上身贴身+下身裙装，兼顾肌肉可读性与动态美感。

### 五、AI落地要点

#### 单段单视角原则
- H3/Wan等AI视频模型在单段生成中难以处理视角切换。
- **单段内只用一个视角**，视角切换靠分段生成后剪辑拼接。

#### 性价比最高的风格化镜头

| 镜头 | 性价比 | 原因 |
|------|--------|------|
| 俯拍拳路 | ★★★★★ | 垂直轨迹视觉冲击强，AI生成稳定 |
| 仰拍跳跃 | ★★★★★ | 腾空高度感强，空中姿态变化丰富 |
| 斜侧45°踢技 | ★★★★☆ | 纵深展示好，适用所有踢技 |
| 近景击中 | ★★★★☆ | 表情与肌肉细节，情感冲击强 |
| 攻击/被攻击视角 | ★★★☆☆ | 代入感强，但AI生成稳定性稍差 |

#### 视角提示词词汇

- 全景：full body shot, wide angle
- 斜侧45°：45-degree side angle, three-quarter view
- 近景：close-up, medium close-up
- 正面：front view, symmetrical composition
- 俯拍：top-down view, bird's eye view
- 仰拍：low angle, worm's eye view
- 侧景：side view, profile shot
- 攻击视角：POV shot, attacker's perspective
- 被攻击视角：POV shot, defender's perspective
- 静止姿势：freeze frame, pose hold

## 关键参数 / 模板 / 清单

### 多机位分镜脚本模板

```
镜头1：全景——[角色] [起始架势]，重心[位置]，视线[方向]
镜头2：斜侧45°——[发力过程]，[身体转动/腰胯发力]
镜头3：近景——[击中瞬间]，[肌肉状态/表情/击中反馈]
镜头4：仰拍/俯拍——[风格化强点]，[腾空高度/垂直轨迹]
```

### 视角×动作适配表

| 动作类型 | 推荐视角组合 |
|----------|------------|
| 踢技 | 全景→斜侧→近景→仰拍 |
| 拳法 | 全景→斜侧→近景→俯拍 |
| 跳跃 | 全景→仰拍→侧景→近景 |
| 持枪 | 全景→俯拍→攻击视角→近景 |
| 持刀 | 全景→斜侧→近景→静止姿势 |
| 防御 | 近景→正面→被攻击视角 |
