# 擒龙功与控鹤功——隔空取物

## 核心要点

- 擒龙功/控鹤功：隔空抓取远处物体（或人）的罕世武功，乔峰曾以此震慑群雄
- 戏剧定位：**展示型武功**——不为杀人，为立威；一出全场失语
- 视觉难点：无接触、无轨迹、无受力点——"物体自己飞过来"必须给出可信的力学暗示

## 详细内容

### 三段式表现法
1. **锁定**：施术者目视目标，伸手虚抓（五指张开对准物体）——建立"手-物"连线
2. **起物**：物体先震颤（内力压住的征兆）→ 离地/离手 → 加速飞向施术者
3. **归手**：物体稳稳落入掌中，施术者面不改色——全程如探囊取物

### 力学可信度的三个细节
- 物体飞来的轨迹略带弧线（不是直线瞬移）——有"被拉过来"的阻力感
- 轻型物体（刀、酒碗）快，人/重物慢且晃动——重量分级
- 原持物者的反应：被夺者手指被带的踉跄/脱手的错愕——反证"力"的存在

### 群像反应（震慑戏的真正主体）
- 武功本身只值 2 秒，**围观者的失语值 8 秒**：鸦雀无声、面面相觑、有人下意识后退半步
- 乔峰版擒龙功的精髓：他做完像做了一件小事——举重若轻比排山倒海更吓人

## 关键参数 / 模板 / 清单

**提示词模板**
```
大汉隔了三丈对着地上的单刀遥遥伸手虚抓，五指张开，单刀先是在地上震颤，
随即猛地离地，划出一道低弧飞入他掌中，被他稳稳握住，全场死一般寂静，
有人不自觉地向后退了半步。
负向词：telekinesis glow, purple energy hand, object levitating with sparkles,
magnetic sound effect visual, object teleporting
```

**自检**：锁定帧有没有（手-物连线）｜轨迹带不带弧度｜群像失语帧给没给足
