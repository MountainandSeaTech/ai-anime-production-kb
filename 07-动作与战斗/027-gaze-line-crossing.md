# 凝视与视线交错

## 核心要点
- **凝视 = 静态张力的视线版**——视线锁定=注意力锚定在目标上=即将交锋的预期
- 视线方向编码关系：直视=对等对抗，俯视=轻蔑/压制，回避=动摇/弱势
- **视线交错**（两人视线不相遇）= 关系错位=张力裂痕=转折信号
- 正反打视线对接=对峙戏的标准剪辑骨架

## 视线方向与关系

| 视线方向 | 关系编码 | 张力用途 |
|---|---|---|
| 直视对方眼 | 对等对抗、锁定 | 对峙、决斗 |
| 俯视对方 | 压制、轻蔑 | 强者对弱者 |
| 仰视对方 | 敬畏、被动 | 弱者对强者 |
| 回避/侧视 | 动摇、心虚 | 心理转折、隐瞒 |
| 直视镜头 | 打破第四墙、直击观众 | 宣告、恐吓 |
| 闭眼 | 自信、轻蔑或决意 | 居合闭眼斩、最终一击 |

## 凝视如何制造张力

### 1. 视线锁定=注意力锚定
- 角色凝视目标=观众视线被带着锁定=注意力集中
- 凝视时长=蓄势时长，凝视越久越揪心（但不超 3s）
- 配合 024 瞳孔收缩=锁定信号

### 2. 视线对接=对峙成立
- 双方视线相遇（A 看 B，B 看 A）= 对峙关系成立
- 正反打剪辑让观众在两视线间来回=揪心累积
- 视线对接越久=蓄势越久

### 3. 视线交错=转折信号
- A 看 B，B 不看 A（看别处）= B 动摇/隐瞒/轻蔑
- 视线错位=关系裂痕=观众预感"要变"
- 这是心理轴（013）的视觉信号

## 正反打凝视序列（对峙戏骨架）
```
A 近景凝视（0.8s）→ B 近景凝视回望（0.8s）→ A 特写眼神变（0.4s）→ B 特写嘴角微动（0.4s）→ A 出手/开口（0.3s）
```
A→B→A→B 来回切，每次切视线对接更深，揪心逐级加码。

> 这就是为什么对峙戏几乎都用正反打——视线对接是静态张力的载体。

## 视线变化的张力信号

| 视线变化 | 信号 | 后接 |
|---|---|---|
| 凝视→瞳孔收缩 | 决意、将动 | 出手 |
| 凝视→闭眼 | 自信/最终一击 | 居合闭眼斩 |
| 凝视→侧视 | 动摇、察觉他物 | 转折 |
| 回避→直视 | 决意确立 | 反击 |
| 闭眼→睁眼 | 爆发瞬间 | 出刀 |

## 经典凝视场景

### 居合闭眼斩
```
A 闭眼近景（1s，自信/蓄势）→ B 诧异特写（0.5s，不知要发生什么）→ A 猛睁眼+出刀（0.3s，爆发）
```
闭眼=最大蓄势（看不见但掌控），睁眼=爆发信号。

### 视线回避的动摇
```
A 直视 B（0.8s）→ B 回避视线（0.5s，心虚）→ A 眼神收紧（0.3s，识破）→ A 出手（0.3s）
```
回避=心理裂痕，A 识破=转折。

### 直视镜头（打破第四墙）
```
角色猛转头直视镜头（0.3s）→ 定格（0.5s）→ 切走
```
直击观众=强宣告/恐吓，慎用但极狠。

## AI 提示词
- 凝视：`gazing intently at target, eyes locked, intense stare`
- 视线方向：`looking directly at opponent` / `looking away, avoiding eye contact` / `looking up at` / `looking down at`
- 闭眼：`eyes closed, calm expression` / `eyes snap open`
- 直视镜头：`looking directly into camera, breaking fourth wall`
- 避坑：AI 视线方向不稳定，视线戏优先大特写+短镜锁定眼神

## 备注
- 凝视是 012 静态张力的视线维度，配合 024 眼部微表情最强
- 视线方向在 AI 视频里是难点，建议大特写+明确方向词+必要时多生成几条选最佳
- 对峙戏正反打次数=视线对接次数=蓄势时长，3-5 个来回是常见节奏
