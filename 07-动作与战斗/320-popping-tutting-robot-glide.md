# Popping 风格族：Tutting / Robot / Glide

## 核心要点

- Popping 是一个"风格伞"，除了 319 的本体技术（hit/wave/isolation），还包含大量**制造视觉错觉的子风格**；动漫短剧最好用的三个：**Tutting（几何手）、Robot（机器人）、Glide（滑步）**
- Tutting 的灵魂＝**90°直角与几何框**：肩-肘-腕尽量保持直角，双手组成方形/三角，动作像在无形的格子里折叠
- Robot 的灵魂＝**分段运动 + 急停**：一个关节动时其他关节锁死，运动呈"启动-匀速-刹车"的伺服电机曲线，绝无惯性余动
- Glide 的灵魂＝**重心错觉**：观众看到的是"平脚在滑"，实际重心全在另一脚尖/脚跟上；平脚底面向后蹭只是表演层
- 三者都**极度依赖机位与景别**：tutting 需手部清晰入画（中近景/特写），robot 需正面或正侧面读关节，glide 必须**全身入画且拍到脚**（裁切到小腿以上则错觉失效）

## 详细内容

### 一、Tutting（埃及皇手 / 几何手）

- **得名**：模仿古埃及壁画与图坦卡蒙（King Tut）造型，1970s–80s 街头发展
- **形态法则**：
  1. 所有关节角优先取 **90°**（肘、腕、指根）
  2. 双手常**互相对称/镜像**，组成 box（盒子）、frame（框）、三角、字母
  3. 运动＝**一个关节折叠到新直角、其余保持不动**，每次变化可配轻 pop
  4. 手的路径沿"无形网格"移动：水平、垂直、90°转弯，不走弧线
- **基础造型库**：
  - Box：双手在面前围出方形，手指相接
  - Wrist wrap：手腕互绕后瞬间成框
  - Pyramid：双臂过头成三角（埃及壁画经典）
  - Frame：一手横、一手指尖相触成取景框
- **Finger Tut（手指版）**：仅用十指互相插接折叠成微缩几何体，速度快、密度高，特写镜头极惊艳；AI 生成手指穿帮率高，建议用手部参考图+短时长
- **戏剧用法**：施法/结界/操控符文——几何手+发光线条＝现成的魔法阵手势；现代戏可作"角色在用全息界面"
- **机位**：正面中近景（手在脸侧到胸口范围）、浅景深压杂背景；finger tut 用手部特写

### 二、Robot（机器人舞 / Animation 机器人质感）

- **运动三定律（写提示词直接可用）**：
  1. **Segmentation 分段**：每次只动一个部件（抬前臂时大臂不动），部件之间像铰链
  2. **Linear velocity 匀速**：运动过程速度恒定（机器人伺服电机），非人自然的加速-减速
  3. **Dime Stop 急停**：到位瞬间完全静止，零惯性、零晃动
- **质感部件**：齿轮启动延迟（motion 前有 2–3 帧"马达启动"停顿）、气压感（动作伴随轻微顿挫）、电量不足时的变慢/卡顿（可作喜剧拍）
- **经典角色化风格**：
  - Robot：直臂直腿、关节铰链
  - Puppet：被线牵引，手先被"拎"起身体再跟
  - Scarecrow：稻草人式松软关节+急停
  - Toy Man：玩具兵式小而脆的动作
  - Animation：更广义的"逐帧动画感"，含频闪 ticking（319）
- **戏剧用法**：被洗脑/被附身/傀儡操控/时间停止中行动——配合 pop 即"操控解除"瞬间
- **与 popping 本体区别**：robot 段可以不 pop，靠急停本身成立；混用时 pop 像金属撞击声的视觉化

### 三、Glide / Slide（滑步族）

**共同力学**：永远一只脚承重（脚尖/脚跟），另一只脚"平底轻蹭"，观众只见平底滑动的错觉。上半身保持稳（不上下起伏！）是错觉成立的关键。

| 招式 | 做法 | 错觉 |
|---|---|---|
| **Moonwalk / Backslide（太空步/后滑）** | 一脚尖踮起承重，另一脚**平底向后蹭**；蹭到位后换脚（原平脚变踮、原踮脚变平蹭回），交替循环 | 人在向前走，却向后飘 |
| **Side Glide（侧滑）** | 同样的跟-尖切换，重心在两脚间横移，平底向侧蹭 | 横向漂移 |
| **Circle Glide（圆滑）** | 以一脚为轴，另一脚连续蹭出，整体画圆 | 像站在转盘上 |
| **Air Walk（空中行走）** | 脚跟-脚尖连续交替点地，重心极低，配夸张摆臂 | 像在月球低重力行走 |
| **Walk it Out / Gliding 变体** | 加胯部隔离与转身的滑步组合 | 流动飘移 |

**逐拍（Moonwalk，4拍一循环）**：
1. 拍1：左脚尖踮起承重，右脚平底贴地向后蹭出
2. 拍2：右脚跟踮起承重，左脚变平底，开始后蹭
3. 拍3：左脚继续蹭回至右脚旁/后侧
4. 拍4：切换，重复
5. 全程：上半身微前倾、**无 bounce 起伏**、手臂自然摆动加大"走"的错觉

**机位铁律**：
- 必须**全身或至少到脚踝**入画，地面要有纹理（地板砖、斑马线）作滑动参照
- 最忌镜头跟移（跟拍会抵消滑动错觉）；固定机位或反向慢速推近
- 微俯 10–20° 能看到脚底切换，是教学/炫技位；平视最"魔幻"

### 四、三风格组合套路（32 拍可直接分镜）

```
[1-8]   Robot：分段行走 4 步入场，每步 dime stop（正面全景，看到脚）
[9-16]  接 Glide：moonwalk 后滑退回中心，上身稳
[17-24] Tutting：停步，双手 box → wrist wrap → pyramid（中近景，随动作推近）
[25-30] Finger Tut：镜头切手部特写快速折指 6 拍
[31-32] 拉回全身：双手造型定格 + 一个大 pop 收（pop 帧可叠特效，见319/305）
```

### 验收清单

- [ ] Tutting：每个静止造型都找得到 90°/几何关系，手指清晰无融指
- [ ] Tutting 运动路径为直线+直角转弯，无随手画弧
- [ ] Robot：逐帧检查无惯性余动、无匀速以外的速度曲线
- [ ] Robot：一个动作只有一个关节在动（其他部位锁死）
- [ ] Glide：平底脚全程不抬离地、承重脚切换清晰
- [ ] Glide：上身零起伏、固定机位、地面有参照纹理、脚在画内
- [ ] 三风格混排时景别跟着切（全身看滑步、近景看手），不用同一景别硬套
