# 技能魔法编写二十连⑥：战力曲线与天花板

## 核心要点

- **战力通胀死循环**：每弧要更强的敌人→逼主角成长→要更更强的敌人——直到数字失去意义，观众看数字就知道胜负，战斗再无悬念
- **五条出路**：①开局就定战力天花板 ②策略多样胜过蛮力数值 ③有意义的代价限制调用（362）④世界扩张换赛场换规则而非换更大数字 ⑤战斗之外的威胁（道德/关系/时限）
- **数值化是悬念的敌人**：战力值把战斗降维成比大小——"他有一万战力"出口的瞬间，所有计谋与角色成长都贬值。强度靠**参照系演出**传达，不靠读数
- **铁律：没有任何一种能力可以成为"自动胜利的叙事缩写"**——主角发光、反派"不可能！"、一拳结束，这是懒；赢必须来自规则运用、代价抉择或信息差（359/368）

## 详细内容

### 一、天花板先行（开局就要画好的图）

在能力圣经（377）开篇定三张表：
1. **天花板**：本作物理上的最强一击是什么级别（碎墙？裂城？移山？）——最高破坏力是预算尺，决定全剧奇观上限（357预算分级也靠它）
2. **主角曲线**：起点→中点→终点的机制位置（不是数值），每段成长是**多会了一种规则用法**而非"气又涨了"
3. **强者分布**：世间已有的高手站在哪几档；天花板最好已被某个人占据——主角终点是接近而非凭空超越，超越必须付出价（362底层代价）

### 二、传达强度：参照系演出（不读数）

观众通过参照物校准强度，给三级锚点：
- **物**：掌风灭烛（入门）→裂碑（高手）→城墙塌（天花板级）——同一组标志物全剧复用
- **人**：让已立威的高手当标尺——"连他都接不住"比旁白报数有效十倍；高手的表情比数据有说服力
- **后果**：战后的现场（一地碎兵、干涸的河床、改道的溪流）是延迟校准

铁律：**强度只演不报**。角色可以惊呼、可以不敢相信，但不要让体系内出现公认战力值排名表当胜负依据（排名表只能当社交压迫工具，不能当判决书）。

### 三、用"多样性"替代"更大"（反通胀主策略）

中期以后不靠更强，靠不同：
- **机制换类型**：新敌人不是更硬，是机制踩在主角盲区（368克制链）
- **赛场换规则**：水战、夜战、人群中、护人同时战、不能动用能力的场合（世界扩张重置棋盘）
- **目标换性质**：不是打倒，是护送/拖延/拆弹/救人/说服——非战斗目标让旧强度归零，智谋重新上岗
- **代价升级而非威力升级**：成长表现为"敢付更大代价/更精细地使用"，不是数字变大

### 四、强者角色的写法（天花板人物怎么不毁戏）

天花板级人物（扫地僧/巅峰BOSS）一旦常驻就没有紧张，四个处理：
1. **自然限制而非剧情护甲**：不出手是因为规则（不出山门/认不出真相/力量本身有代价），不是编剧拦着
2. **不在棋盘上**：他解决的是另一个量级的问题，主角的问题他够不着（大人打大人、孩子打孩子，339多线分级）
3. **强者的戏在内心**：他强到没有外部困境，戏全部来自代价/亏欠/抉择
4. **强者是用来落下的**：天花板角色的坠落或失败本身就是全剧最大事件之一，且失败必须可信（靠规则不靠降智）

### 五、成长的节拍设计

- 成长单位是**问题难度**不是经验条：每个新对手提出一个旧打法解不了的题
- 三种健康成长：①规则新用法（外推，359第三定律）②组合（与队友/环境，367）③代价承受力（敢用、会省、知道何时不用）
- 升级要带债：每次突破都在代价表上留痕（362），纯获利升级是通胀的开始
- 失强也是素材：中毒、受限、保护他人时无法全力——强度被暂时拿掉后怎么赢，比继续变强好看

### 六、战斗结果的四种合法来源（按好看程度排）

1. **规则智斗**：用观众已知的机制组合/反用（满足感最高，第一定律兑付）
2. **代价抉择**：押上不可逆成本换结果（情感最重）
3. **信息差/欺骗**：假装、藏招、诱导（278/368）
4. **硬实力碾压**：只在建立威慑或爽点节拍时用，连续两次以上即通胀
检查每场高潮战：来源是1-3还是4？全片比例建议7:3。

### 七、常见翻车

| 病 | 修法 |
|---|---|
| 反派排队送经验 | 新敌人换机制/赛场/目标，不换数值 |
| 战力值旁白报数 | 全删读数，改参照系演出 |
| 主角觉醒即胜利 | 觉醒给新可能性，胜利仍要靠选择与代价 |
| 前期碎山后期碎石 | 建标志物标尺，前期破坏力封顶，所有奇观对照天花板 |
| 高手降智陪练 | 强者按规则行动，主角赢在机制不在对手蠢 |
| 一招鲜吃遍天 | 给招牌技失效场次，逼出成长与变招 |
