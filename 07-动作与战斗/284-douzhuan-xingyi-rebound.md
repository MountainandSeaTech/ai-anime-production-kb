# 斗转星移——借力打力

## 核心要点

- 姑苏慕容家传绝技：不论对方何种功夫，都能转移力道反击其自身——核心在"反弹"二字
- "以彼之道还施彼身"的真相：不是会天下武功，是**了解各派精要后把招式方向转回去**，看起来像用了对方本门武功
- 叙事铁律：**出手的人武功越高，死法越巧妙**——慕容复的胜绩取决于对手强度

## 详细内容

### 力学逻辑（视觉化用）
1. 识：识别对方招式劲路（需武学知识储备——慕容复"眼永远在评估"的角色锚点在此）
2. 引：接触瞬间侧身/转体，将劲力导入圆弧轨迹
3. 转：圆弧末端加自身劲力，把攻击原路或变向送回
4. 放：脱手——对方的招式打在对方自己身上

### 局限（剧情张力来源）
- 对明显强于己者（萧峰的降龙掌）转不动——力量差过大时反弹失败
- 对无形/无招的攻击（六脉剑气）难找"转移点"
- 心理战：对手不知道会被反弹时效果最佳，知道后可用虚招反制

### 镜头表现法
- **镜像构图**：出招者与慕容复画面左右对称，招式从左来、向右去，形成视觉镜像
- **轨迹可视化**：用一个连续跟镜拍"劲力的圆弧路径"（攻来→绕身→返回），观众一眼看懂"转"
- **受击反差**：攻击者被自己的招式击中时的错愕特写是核心反应帧

## 关键参数 / 模板 / 清单

**提示词模板**
```
对手的掌力击至慕容复身前半尺，慕容复侧身一转，手臂划出一道圆弧，
那股掌力仿佛被无形之力牵引着绕体半周，随即沿原路反击回攻击者本人，
攻击者被自己的掌力震退，满脸不可置信。
负向词：energy shield blocking, attack bouncing off barrier,
magical reflection effect, two people trading identical blows
```

**自检**：有没有"圆弧轨迹"的连续镜头｜反弹的是不是对方的招（而非慕容复自己出招）｜对手错愕帧有没有

## 备注

- 慕容复的"假"是角色核心：斗转星移视觉上越华丽，越衬出他"借来的强大"——与本剧角色塑造（华而不实）直接绑定
- 与 275 萧峰刚猛劲路对位：刚猛 vs 反弹是天然的动作戏对仗
