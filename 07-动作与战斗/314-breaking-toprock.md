# Breaking-Toprock 完整基础步

## 核心要点

- Toprock 是 breaking **唯一全程站姿**的部分，作用是入场、立态度、跟音乐对话；任何一套 throw-down 都从 toprock 开始
- 底层质感：**膝盖微屈 bounce 不停 + 脚步轻快 + 手臂与腿反向摆动（像走路的自然对侧协调）+ 身体 rock 前后微摇**
- 四大基础步：**Indian Step（交叉步/灵魂步）、Salsa Step（侧步）、Crossover（前交叉）、Kick & Twist（踢转）**——学会这四个就能组合 80% 的 toprock
- 节拍走法：所有步子都是"**一步一拍或一步半拍**"，重拍换脚、锁姿态；常见 8 拍组合 `Indian×4 + Salsa×4`
- AI 生成提示：站姿段最怕"原地踏步"，必须给**行进方向（前进/侧移/转圈）+ 对侧手臂 + 膝盖弹性**三个锚点

## 详细内容

### 一、预备姿态（Toprock Stance）

- 双脚与肩同宽或略窄，一脚略前；膝盖保持弹性微屈（绝不全直锁死）
- 重心略前倾落在前脚掌，胸口放松微含；肩沉，头部稳定不乱晃
- 双手自然垂放或微架起，**像走路一样与腿对侧摆动**（右腿前→左臂前）——这是新手最容易做成"同手同脚"的点
- 全程 bounce：每拍膝盖有一次微小的"沉-起"，重拍下沉

### 二、四大基础步逐步拆解

#### 1. Indian Step（印第安步/Crossover Two-Step，最核心）

- **形态**：一脚抬起交叉迈到另一脚前方（轻交叉点地）→ 收回，换脚交叉，左右交替；配合小幅跳跃换重
- **节拍**：一拍一个交叉（1哒2哒），也可慢做成两拍一个
- **手脚**：左腿前交叉时右臂前摆，对侧协调；上身保持正对前方，仅下盘交叉
- **视觉特征**：从正面看双腿在小腿处反复"剪刀交叉"，身体随交叉左右微转 15–30°
- **要点**：交叉要过身体中线，步子小而脆；进阶版跳起换脚、加 1/4 转身（quarter turn）

#### 2. Salsa Step（萨尔萨侧步/Basic Side Step）

- **形态**：右脚向右侧点一步→左脚并回→左脚向左侧点一步→右脚并回，钟摆式左右移动
- **节拍**：右-并-左-并，一拍一个位置，共 4 拍一组
- **手脚**：侧出脚时对侧手向斜下/前带，身体随出脚侧倾 bounce
- **视觉特征**：整个人在画面中横向漂移，肩部保持水平律动——**横移镜头跟拍最好看的步子**
- **要点**：点地脚轻点即收，重心始终留在支撑腿一侧

#### 3. Crossover / Cross-Step（前交叉步）

- **形态**：与 Indian 类似但幅度更大，一脚从另一脚前方大幅交叉迈过，身体随步子转 45–90°，走出"之"字形路线
- **用途**：Indian 是原地态，Crossover 是**行进态**——用于进场、换位、走向 cypher 中心
- **视觉特征**：连续 crossover 走出斜向折线，配合肩膀反向 counter（上身留半拍）形成拧转张力

#### 4. Kick & Twist（踢腿+扭转）

- **形态**：一脚向前/向侧低位踢出（踢膝下高度，不高踢），同时支撑脚脚跟-脚掌拧转、胯部随踢送出，双手可开或架
- **节拍**：踢在重拍（1），回落并脚在 2；左右交替或连踢同一边
- **视觉特征**：踢腿瞬间全身有一个"甩-停"的脆点，是 toprock 里最适合卡剪辑点的动作
- **要点**：踢腿不要超过腰高（breaking 的 kick 低而快，区别于爵士高踢）

### 三、常用变化与装饰步

| 步子 | 形态 | 用途 |
|---|---|---|
| **Power Step / March** | 高抬膝原地踏步，手臂大开大合 | 开场立气势，重拍砸地 |
| **Side Rock / Brooklyn Rock | 重心左右摇滚，一脚点地 | 最省力的 groove 填充 |
| **Back Rock / Uprock(受其影响)** | 身体前后 rock，带模拟格斗手势 | 挑衅/对话感 |
| **Shuffle Step** | 脚掌快速前后蹭地半拍步 | 加密节奏、提速 |
| **Hop / Skip** | 单脚小跳换重 | 乐句之间的换气点 |
| **Toprock Freeze** | 突然单手指地/造型停半拍 | 重拍"钉"住，给切镜 |
| **Turn（1/4、1/2、full）** | 在任意步子后加转身 | 变换朝向、接 go-down |

### 四、8拍组合套路（可直接做分镜动作脚本）

**套路 A（入门 32 拍）**
```
[1-8]   Indian Step ×8（原地，建立节奏）
[9-16]  Salsa Step ×8（横向移动，机位跟移）
[17-24] Indian Step ×4 + Kick & Twist ×4（能量上扬）
[25-32] Crossover 前进 ×4 → 1/2 转身回正面 → 重拍造型停 → go-down 下地面
```

**套路 B（Battle 挑衅型 16 拍）**
```
[1-4]  Power Step 踏步逼近对手方向 ×4
[5-8]  Side Rock ×2 + 单手"过来"手势
[9-12] Indian + 1/4 turn ×4（绕小圈扫视）
[13-16] Kick & Twist ×2 → freeze 指地 → drop
```

### 五、质感校准：Toprock 的"四个不停"

1. 膝盖 bounce 不停（断了像走路）
2. 对侧手脚协调不停（同手同脚立刻假）
3. 头-肩稳定不碎晃（下盘花、上盘稳）
4. 重拍态度不停：每 4 拍至少一次明确的"砸拍"（踏步/踢/停/手势）

### Toprock 段生成验收清单

- [ ] 全程膝盖有可见弹性起伏，无直腿帧
- [ ] 手脚对侧摆动，连续 8 拍无同手同脚
- [ ] 至少一次空间位移（横移/前进/转身），不是纯原地
- [ ] 重拍（1/5）有清晰的"踩实"帧，脚-地接触明确无滑行
- [ ] 第 8 拍/段尾有造型或 go-down 收束，不平淡结束
- [ ] 服饰（宽松卫衣/帽衫）与帽子有随动延迟 2–4 帧

## 备注

- Uprock（Brooklyn Rock）严格说是独立舞种（模拟格斗的站姿对舞），与 toprock 同源互相影响；battle 挑衅手势可借用但不要把 uprock 整套当成 toprock
- 真实训练建议先 60–80BPM 慢歌练熟 Indian+Salsa 再加花；分镜使用时直接按套路 A/B 切片即可
