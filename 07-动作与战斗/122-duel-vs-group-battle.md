# 单挑 vs 群战结构差异

## 核心要点
- 单挑=**两个意志的对决**——靠心理战、势转换、招式细节
- 群战=**空间与节奏的调度**——靠队形、镜头分配、混乱中的清晰
- 二者镜头数、景别、节奏完全不同——不能套同一套公式
- 单挑重特写，群战重调度
- 关联 121 三幕式、147 大战场群战

## 单挑战斗特征

### 结构特征
```
- 双方对等（或反派略强）
- 心理战比重高（招式即对话）
- 势转换来回多次（见 124）
- 招式细节特写多（手/眼/脚步/刀刃）
- 篇幅可长可短，但心理弧要完整
```

### 镜头分配
```
特写/极近景 占比 40%（眼/手/汗/刀锋）
中景占比 30%（招式全貌）
远景占比 20%（建压/释放）
POV/越肩占比 10%（代入感）
```

### 节奏曲线
```
建压段：长镜头+静默（见 022 长镜头）
交锋段：快切+冲击帧（见 023 切片频率）
释放段：慢镜头+定格（见 021 慢镜）
```

### 单挑核心技巧
- **空间留白**：两人间隔大=张力大（拔刀术经典）
- **视线交错**：眼线交锋比刀早（见 027 视线越线）
- **呼吸同步**：呼吸节奏暗示势（见 136 呼吸停顿）
- **微表情**：嘴角/眉宇变化=心理转折

## 群战战斗特征

### 结构特征
```
- 多方混战（2v2/NvN/帮派战）
- 空间调度是核心（谁打谁要清晰）
- 焦点切换频繁但有节奏
- 群像角色各有专属镜头（见 142 群像战）
- 篇幅必须够长——否则塞不下
```

### 镜头分配
```
远景/大全景占比 30%（战场全貌+调度）
中景占比 40%（小队交锋+组合招）
特写占比 20%（关键时刻爆点）
航拍/俯拍占比 10%（壮观感+方位感）
```

### 节奏曲线
```
建压段：航拍战场+各方站位
混战段：快切在多个小战场间跳（每场 3-5 帧切走）
高潮段：组合技/统帅级对决=慢镜爆点
释放段：战场残局全景+幸存者特写
```

### 群战核心技巧
- **方位感优先**：观众要随时知道谁在打谁（用航拍+地标）
- **小队切分**：把 NvN 拆成几个 1v1 或 2v2=清晰
- **节奏切片**：A 场 3 帧 → B 场 3 帧 → 交叉剪辑
- **统帅镜头**：每方一个焦点角色=观众跟人

## 结构差异对比

| 维度 | 单挑 | 群战 |
|------|------|------|
| 焦点 | 心理对决 | 空间调度 |
| 景别偏重 | 特写 | 远景+中景 |
| 切片频率 | 中等（势来回时切多） | 高（多场交叉） |
| 篇幅弹性 | 可短可长 | 必须长 |
| 节奏骨架 | 锯齿上升 | 多线交织 |
| 镜头运动 | 静/慢推多 | 跟拍/环绕多 |
| 高潮形式 | 一击决胜 | 组合技/统帅决 |

## 单挑向群战的过渡技法
```
1. 单挑开场建调子（心理张力）
2. 援军介入=扩成群战（节奏破口）
3. 群战混战中切回原单挑=焦点收束
4. 群战高潮时单挑二人做终极对决
5. 单挑结果决定整体战局
```
- 这是动漫最常用桥段——"千军万马中两人的对决"
- 把单挑的心理深度+群战的壮观感两全

## 模板示例

### 单挑模板（居合斩）
```
Act1: 远景对峙+静默试探
Act2: 中景交锋+特写势转换+多招拉锯
Act3: 极近特写呼吸停顿+爆点帧+慢镜交错+收刀
```

### 群战模板（帮派街战）
```
Act1: 航拍街区+各方登场
Act2: 多小场交叉剪辑（A场3帧/B场3帧）
Act3: 双方头目单挑（焦点收束）+组合技爆点
收束: 战场残局全景+幸存者特写
```

## 常见坑
- **单挑用群战快切**：心理戏被切碎=情感断裂
- **群战只给远景**：没特写=观众无代入点
- **群战不切小场**：N人混成一团=谁打谁不知
- **单挑篇幅太短**：势没累积就爆=假爽
- **群战没统帅角色**：全是路人=观众无焦点

## 进阶
- **单挑的"沉默战"**：双方全程不说话=靠招式对话（如《浪客行》宫本武藏）
- **群战的"几何战"**：用队形变化讲故事（如《指环王》圣盔谷）
- **混合战**：单挑中插入群战围观=立体感
- **统帅镜头分配**：群战给统帅 30%镜头+小角色 70%镜头=焦点清晰

## 备注
- 单挑靠心理，群战靠调度
- 单挑重特写，群重重远景
- 篇幅：单挑可短，群战必长
