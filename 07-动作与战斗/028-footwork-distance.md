# 步法与距离控制

## 核心要点
- **步法 = 距离控制 = 013 空间轴的主要操作**
- 逼近=威胁累积（时间轴+空间轴双加压），拉开=喘息/释放
- **距离骤变**（一瞬贴脸/一瞬拉开）= 交锋/逃脱信号
- 步法节奏编码心理：碎步=紧张试探，大步=决意，滑步=专业蓄势

## 距离与张力

| 距离 | 张力状态 | 含义 |
|---|---|---|
| 远（3m+） | 观察、试探 | 还没到交锋 |
| 中（1.5-3m） | 逼近加压 | 威胁累积 |
| 近（0.5-1.5m） | 临界、随时可动 | 张力峰值区 |
| 贴脸（<0.5m） | 已交锋/对峙顶点 | 爆发或对峙极紧 |

> 距离从中到近=蓄势；从近到贴脸=峰值；骤变=信号。

## 步法类型与心理编码

| 步法 | 心理 | 张力用途 |
|---|---|---|
| 碎步试探 | 紧张、不确定 | 试探期、新手 |
| 沉稳滑步 | 专业、蓄势 | 剑客逼近、专业逼近 |
| 大步上前 | 决意、压迫 | 强者逼近、宣告 |
| 退步拉开 | 喘息、重整 | release 段 |
| 侧步横移 | 绕侧、寻找角度 | 战术机动 |
| 骤停不动 | 蓄势顶点 | 出手前 0.3s |

## 距离变化的张力曲线

### 逼近曲线（标准蓄势）
```
远全景（1s）→ 中景滑步逼近（1.5s）→ 近景大步上前（0.8s）→ 临界骤停（0.3s）→ 出手（0.3s）
```
距离从远→中→近→临界→骤停→爆，距离收紧=空间轴持续加压。

### 追逃距离反复（拉锯张力）
```
远（逃者跑，1s）→ 中（追兵逼近，1s）→ 近（差点追上，0.5s）→ 中（逃者加速，0.5s）→ 近（追上，0.3s）
```
距离反复拉近拉远=拉锯揪心，比单向往近更折磨。

### 骤变距离（爆发信号）
```
中对峙（1s）→ 一瞬贴脸特写（0.3s，骤变）→ 交锋（0.3s）
```
距离骤变=空间轴突变=峰值信号。

## 步法的"节奏即心理"
- 步法节奏变=心理变=张力转折
- 碎步→沉稳大步=从动摇到决意（转折信号）
- 大步→骤停=蓄势顶点（出手前摇）
- 沉稳→踉跄=失态/受伤（局势反转）

## 经典步法张力场景

### 剑客逼近
```
远全景对峙（1s）→ 滑步逼近中景（1.5s，专业蓄势）→ 骤停近景（0.3s）→ 出刀（0.3s）
```
滑步=专业信号，骤停=前摇顶点。

### 压迫式逼近（强者）
```
远（1s）→ 大步上前中景（0.8s，决意）→ 继续大步近景（0.8s）→ 贴脸俯视特写（0.5s）→ 出手/开口
```
大步不缩=强者压迫，距离持续收紧。

### 退步喘息
```
近交锋（0.5s）→ 跃开中景（0.5s，拉开）→ 喘息近景（1s，release）→ 重新逼近（0.8s）
```
拉开→喘息→再逼近=战斗的呼吸节奏。

## AI 提示词
- 逼近：`character stepping forward, closing distance, slow approach`
- 滑步：`gliding step, combat footwork, low stance advance`
- 骤停：`sudden stop, freezing mid-step, coiled tension`
- 拉开：`stepping back, creating distance, retreating`
- 避坑：AI 生成步法易踉跄/穿模，优先侧身滑步（最稳），慎用复杂步法

## 备注
- 步法是 013 空间轴的核心操作，比机位运动更直接控距离
- AI 视频步法稳定性差，建议：逼近用侧身滑步+短镜拼接，复杂步法用剪影/局部拍脚
- 距离骤变在 AI 里可用"切镜"模拟（远镜切贴脸特写），比真生成骤变稳
