# 徒手格斗发力链（踢/拳/防御）

## 核心要点
- 徒手动作的重量感来自**发力链**：力从地起，经腿→腰→髋→肩逐级传导，拳/脚只是链条最后一环
- **踢技链**：支撑腿稳→提膝蓄力→腰胯拧转→小腿弹出→力达踢点→原路收腿
- **拳法链**：蹬地→转腰→送肩→出拳——拳头是末端不是起点
- **防御链**：绷紧→下沉卸力→非防御手护另一区段→防后即反击
- 转体类动作**视线先于身体到位**（摆头带动转体），漏写则盲转

## 一、踢技发力链

```
支撑腿扎稳 → 提膝蓄力 → 腰胯拧转/伸展 → 小腿弹出 → 力达踢点 → 沿原路收腿回戒备
发力顺序永远是：地 → 腿 → 腰 → 髋 → 踢击腿
```

- 腰胯拧转是核心动力源（横踢尤其明显），只写"抬腿踢"＝断链＝飘
- 收腿沿原路返回才能立刻回戒备接下一招
- 转体踢中视线先到位：上段转体踢先摆头，后回踢在转体中后段才捕目标

## 二、拳法发力链

```
蹬地 → 转腰 → 送肩 → 出拳
```

- 空手道"**腰为轴**"：力道八成来自转腰，臂膀只负责传导
- 三种拳路：**直拳直线、勾拳弧线、摆拳大圆**——轨迹词写对 AI 才画对
- 另一手永远有职守：护颌或护于体侧，不写则散架

## 三、防御发力链

防御不是静止挨打，是"绷—沉—护—反"的链：

- **绷**：格挡瞬间肌肉绷紧，写出线条隆起
- **沉**：重心下沉、身体微沉卸力
- **护**：非防御手始终护住另一区段
- **反**：防后立刻衔接反击意识——残心的防御版，架势不松、伺机反打

## 四、17组对战动作速查表

### 踢技（8组）
| 动作 | 一句核心要领 |
|---|---|
| 前踢 | 重心移至支撑腿，提膝蓄力，小腿弹踢/前脚掌蹬点击中段，踢后速收 |
| 后踢 | 重心前移，后腿直线后蹬力达脚跟，上体前倾维持平衡，视线经肩后确认 |
| 横踢（回旋踢） | 支撑脚外旋，提膝翻胯，腰胯拧转发力，脚背/胫骨横扫，顺势收腿 |
| 上段转体踢 | 先转体摆头、视线先到位，腰胯带腿上摆至头部高度，收势控惯性 |
| 后回踢（后旋踢） | 转身一周蓄力，转体中后段视线捕目标，脚跟/脚掌后摆踢，大弧线 |
| 高踢腿 | 垂直上踢过头顶，髋关节充分伸展，上体正直不后仰，控制回落 |
| 低踢 | 踢膝/小腿下段，重心下沉支撑腿微屈，小幅快速弹出，近身牵制 |
| 二段踢 | 第一踢收与第二踢起无缝衔接，重心在支撑腿上快速转换 |

### 拳法（5组）
| 动作 | 一句核心要领 |
|---|---|
| 上勾拳 | 屈膝降重心，蹬地→转腰→送肩→拳锋向上勾击下颌，发力自下而上 |
| 勾拳（平勾） | 臂屈约90°横勾侧脸/肋部，转腰带肩臂，拳走水平弧线 |
| 斜上勾拳 | 上勾与平勾之间的45°斜向勾拳，可配攻击/被攻击双视角 |
| 中段拳 | 双脚站稳，腰胯拧转发力，拳走直线击躯干，另一手护体侧 |
| 摆拳 | 臂展打开以肩为轴抡摆，拳走大圆，幅度大破绽也大，收势速回撤护头 |

### 防御（4组）
| 动作 | 一句核心要领 |
|---|---|
| 上段单手防御 | 单前臂上举外格护头侧，沉肘含胸，瞬间绷紧，另一手护中段 |
| 下段单手—双手 | 先单手向下格挡，不足加另一手成双手下压封挡，重心明显下沉 |
| 上段双手防御 | 双前臂交叉/并立上举护头，双肘内收、含胸收下颌，微沉卸力 |
| 下段双手—单手 | 双手下封过渡至单手格挡，防御面积由大收小，伺机反击 |

## 五、架势体系：距离管理逻辑

一切动作从"距离"出发：

| 距离 | 特征 | 攻防逻辑 |
|---|---|---|
| 近距离 | 可攻击对方面部 | 快速进攻但自身暴露，仅用于防御上段攻击 |
| 中距离 | 拳脚皆宜，实战频率最高 | 须防御所有部位，手放上半身与下半身之间 |
| 远距离 | 对方拳头够不到 | 不做面部防御只防下半身；兼作击倒后的**残心姿势** |

架势共性：**重心居中、含胸沉肘、视线平锁目标**——起始段先套这三件套。

## 六、提示词词汇库

**发力动词**（按链条位置）：
- 下肢：蹬地、重心移至支撑腿、支撑脚外旋、提膝蓄力、翻胯
- 腰胯：转腰、腰胯拧转、以腰为轴、髋关节充分伸展
- 上肢/末端：送肩、弹踢、甩出、抡摆、小腿弹出、拳峰绷紧

**防御词**：格挡绷紧、重心下沉卸力、含胸收下颌、沉肘、双肘内收。

> 女性格斗发力观感：绝对力量较小→更依赖全身协调链→宜写"弹踢、拧转、甩出"（流畅弹性），忌"砸、撞"（刚猛男性化）。

## 常见坑

- **末端发力幻觉**：只写"出拳/踢腿"不写蹬地转腰＝力无源头＝动作飘
- **拳路词写错**：直拳写弧线、摆拳写直线，AI 画出的轨迹必错
- **防御写成木桩**：漏写"绷紧＋下沉"，格挡像手臂随意一抬，无受击重量
- **非防御手失踪**：单防时另一手没交代，姿态散架
- **防完不反**：缺"伺机反击"意识，攻防断档
