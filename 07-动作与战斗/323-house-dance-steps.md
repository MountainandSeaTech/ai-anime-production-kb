# House Dance 脚步体系

## 核心要点

- House 1980s 诞生于芝加哥/纽约的地下俱乐部，跳在 House 音乐（four-on-the-floor，鼓机"咚-咚-咚-咚"四分拍）上：**脚步又快又轻、位移流动、手臂松弛随躯干波浪甩动**
- 与 Breaking 相反：House **全程站姿、几乎不落地、重垂直轴**；与 Hip-Hop 相比：脚步切分更密（大量 & 拍）、像踩在针尖上
- 灵魂律动叫 **Jack（Jacking）**：核心收紧，躯干做 down-forward-up 的连续泵动/波浪，像被音乐从胸口往外顶——所有步子都长在 jack 上
- 脚步逻辑大量"**三步组**"（右-左-右/左-右-左），落在 8& 或 1&2 等切分位置，形成"哒哒-咚"的弹性密度
- 视觉气质：**流动（flow）大于定点（pose）**，少有 freeze；镜头适配流动跟拍（steadi 跟走/后退），忌频繁硬切

## 详细内容

### 一、Jack（Jacking）——躯干的泵

- **做法**：膝盖微屈，重拍胯向后沉、胸向前推（forward），次拍回正向上延展（up），核心保持张力；连续做像躯干画一个小的前后椭圆
- **变体方向**：Jack down（下沉为主）/ forward（前推）/ up（上拔），进阶加身波（body wave）
- **手臂**：随 jack 自然在身侧画弧，放松但有"水袖感"，不做定点造型
- **镜头意义**：jack 是"看得懂音乐 BPM"的动作，胸口起伏与底鼓同频——胸口律动与鼓点对齐是 house 段的第一验收项

### 二、核心脚步词汇

| 步子 | 形态 | 拍法 |
|---|---|---|
| **Pas de Bourrée（布瑞）** | 右-左-右（或反向）三小步一组：后点→并→前/侧出，重心连续切换 | 落在 8&1 / &1 等切分，三步两拍 |
| **Farmer（农夫步）** | 源自非洲舞：一脚重跺外开、另一脚轻收，配弹性小跳，双手像提水桶随跳摆动 | 跳跃感、欢乐，重拍跺脚 |
| **Loose Leg（松腿）** | 前脚掌为轴，脚跟-脚掌快速内外摆动，双膝开合同步，小腿像松散铰链 | 半拍一切的连续弹动 |
| **Skate（滑板步）** | 重心完全放一脚，另一脚滑出画弧，身体像压滑板弯道左右倾 | 长线条位移，配大弧线移动 |
| **Staircase（楼梯步）** | 脚尖脚跟交替点地（heel-toe），像原地踩楼梯，可前进/转圈 | 半拍密度 |
| **Crosswalk / Side Walk** | 一脚连续从另一脚前/后交叉，整体侧移（踢踏舞渊源） | 流畅横向漂移 |
| **Train（火车步）** | 一脚前点-收回、另一脚接力，像车轮连续前滚 | 行进组合 |
| **Set-Up / Heel-Toe** | 脚跟点→脚尖拧转的小旋转步，衔接换向用 | 换向"接口" |
| **Salsa Step / Hustle** | 借用萨尔萨的左右点步与俱乐部双人握持元素 | 社交舞段落 |
| **Shuffle / Trade Steps** | 两脚快速换位小跳 | 加速/转圈铺垫 |
| **Jump / Heel Step** | 双脚小跳、脚跟前踢点地 | 重拍装饰 |

### 三、House 的脚步组织法

1. **三步组原则**：绝大多数动作是"三点支撑切换"（点-并-出），数拍常带 `&`（如 `1 & 2` 里塞三步）
2. **永远在移动**：与 hip-hop 可原地跳不同，house 用步子把整个舞池走满——前进、侧滑、绕圈、突然反向
3. **轻**：全脚掌着地少，多用前脚掌弹；视觉是"飘"而不是"踩"
4. **Jack 不停、手不停**：脚步再密，躯干 jack 和手臂流动不断
5. **流动性收束**：偶尔用一个简短转身/下沉做句读，但不 freeze 定很久——立刻继续流动

### 四、镜头与剪辑适配

- **首选跟拍**：稳定器在舞者前方后退跟走（正面）或侧方平行跟移，速度跟人走，让背景流动
- **景别**：中全景（膝以上或全身）——house 的信息 70% 在脚但必须带躯干 jack，纯脚部特写只作点缀插入
- **地面**：光滑反光地面（俱乐部木地板/水泥）强化"滑"；光斑扫过脚步的效果极佳
- **剪辑**：长镜为主，切点放 8 拍整数；可在切分拍做小跳切（jump cut）呼应脚步密度，但一场不超过 2–3 次
- **慢放禁忌**：house 的美感来自密度与流动，升格会把"轻"拍成"拖"，不用

### 五、8拍组合（可直接分镜）

```
[1-4]   Pas de Bourrée 右左右 + 左右左，前进
[5-8]   Loose Leg ×4 原地加密，jack 幅度加大
[9-12]  Skate 大弧线侧滑绕 1/4 圆（镜头跟移）
[13-16] Farmer 重跺 ×4 收向中心 → 最后一拍下沉收（不freeze，顺势起下一段）
```

## 关键参数 / 模板 / 清单

### 提示词模板（House 段）

```
house dancer jacking to a four-on-the-floor beat, chest pumping forward-down-up, 
light rapid footwork on the balls of feet, syncopated three-step patterns 
(pas de bourrée, loose legs, farmer), constant flowing movement across the floor, 
arms loose and waving, effortless floating quality,
steadicam tracking alongside / retreating in front, club lights on smooth floor, [场景]
负向：heavy stomping, static posing, long freezes, hard robotic hits, 
flat-footed marching, upper body disconnected from feet, acrobatic floorwork,
jump cuts within phrases（剪辑侧）
```

### 验收清单

- [ ] 胸口 jack 与底鼓同频，全程不间断
- [ ] 脚步落点有切分（不是一拍一步的均匀走步）
- [ ] 前脚掌主导、视觉轻"飘"，无重踩砸地（farmer 等装饰跺除外）
- [ ] 段内有明显位移路径（前进/弧线/绕圈）
- [ ] 手臂松弛流动，无机械定点
- [ ] 跟拍镜头速度与人同步，背景流动感存在
- [ ] 无长 freeze、无升格拖慢

## 备注

- House 吸收了非洲舞（Farmer）、踢踏（Set-Up/Side Walk）、萨尔萨、爵士（Pas de Bourrée）与 breaking footwork，术语与其他舞种重叠时以"高站姿+jack+流动"辨认
- 场地传统：俱乐部Warehouse/Paradise Garage；服装宽松轻便是资产锚点
