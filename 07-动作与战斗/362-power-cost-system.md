# 技能魔法编写二十连⑤：代价体系

## 核心要点

- **有意义的代价＝改变角色下一步行动的支付**（a payment that changes what characters can do next）。扣蓝、累了睡一觉不算代价——付完之后他的处境、关系、选择必须不一样
- 代价的戏剧价值不在"扣了什么"，而在**负担路径（burden route）**：这笔债在故事里流向谁、怎么被追讨、角色如何应对
- **强系统用叠层代价**：表层（体力/资源，可恢复）＋中层（关系/社会，难恢复）＋底层（不可逆：寿元/记忆/身体部位/人性）。底层是全片情感杠杆
- **腐蚀滑坡（corruption slide）有固定形状**：不是好人突然变坏，而是一个正派的人出于正当理由第一次把代价转嫁给别人——从此每次都找理由继续。黑魔法的本质是"出口代价而非自付代价"

## 详细内容

### 一、代价的五个去向（类型学）

1. **身体**：疲惫、伤痛、寿元、感官、身体局部（石化/失声/视力）——最直观，AI番剧最易可视化
2. **资源**：稀有媒介、金属、药物、时间（仪式要三天）——产生稀缺与后勤戏（Sanderson金属燃烧）
3. **地方**：施法损坏一片土地/抽干水源/留下灾痕——代价外溢成公共事件
4. **秘密/自我**：暴露身份、失去记忆、侵蚀情绪（用一次忘了一张脸）
5. **转嫁**：把危险/伤害转给他人——道德代价，黑魔法的发动机
- 社会代价单列：使用者被打上"威胁"标签、被驱逐、被征召——改变的是关系结构

### 二、负担路径（Burden Route）写法

光设定"用血"没用，要沿故事追踪这笔债：
1. **定价**：第一次使用时让观众看见价格（特写手上石化的一寸，365首秀就要演示）
2. **记账**：之后每次使用，旧账被提及或累积——代价不能"归零刷新"（对接138状态连续性）
3. **催债**：在最不凑巧的时刻发作（决战前手臂石化过半／需要谈判时失声）
4. **选择**：出现"付不起但必须用"的时刻——角色怎么选定义人物
5. **结清或拖欠**：全片结尾要么偿付（牺牲/救赎），要么带着债活下去（余味）
- 检查：把代价从剧本里删掉，后面哪场戏塌？塌得越多代价写得越好；一场不塌＝代价是装饰。

### 三、三层代价结构（主角标配）

| 层 | 例子 | 恢复 | 用途 |
|---|---|---|---|
| 表层：使用成本 | 疲惫、出汗、短暂眩晕 | 睡一觉 | 战斗节拍（连发受限） |
| 中层：累积成本 | 手臂石化、嗓音嘶哑、关系裂痕 | 部分可逆 | 单集/单季弧光 |
| 底层：终极成本 | 不可逆石化全身、永失声音、自我消融 | 不可恢复 | 全片高潮的牺牲按钮 |

**不可逆项是主角的"核按钮"**：全剧最多按一次，越晚按越重；按之前要让观众清楚知道价码（357最后一次原则）。三主角各设一个：岩骨全石化、弦音永失声、白泽意识被深渊取代。

### 四、腐蚀滑坡（反派/堕落弧专用）

固定节拍：
1. 正派的人＋正当理由（救人/复仇）
2. 第一次出口代价：有更好的理由，只此一次
3. 第二次：理由开始变小，自我说服变大
4. 把"例外"重新定义成"必要"
5. 代价转嫁对象从恶人扩展到无辜者
6. 回看时他已不认识自己——但每一步在当时都"合理"
- 写作要点：**不要把第1步写成邪恶**；滑坡靠累积。观众的恐惧来自"换我可能也会"
- 对照写法：自愿牺牲 vs 强行索取（《A Venom Dark and Sweet》的主题分野）——正派力量要求自付与信任，反派力量靠掠夺

### 五、代价与主题挂钩

- 能力的代价最好是**主题的物理化**：主题是沟通→弦音的代价是失声；主题是共情→白泽的代价是被异质意识污染
- 设计顺序：主题句→主角要学的功课→能力让他能做什么→代价让他每用一次就离功课的考验更近一步
- 这样高潮的牺牲不是编剧要求，是系统内置

### 六、代价的视觉化（AI番剧口径）

每个代价都要有三档视觉：
- 轻：可隐藏的微痕（指尖泛灰、清嗓、短暂耳鸣）
- 中：藏不住（绷带、嘶哑、避开他人视线）
- 重：形态变化（半臂石壳、不能说话靠写字、眼内深渊光常驻）
三档直接成为角色状态资产（138），也是成长/危机的进度条（370）。**代价可视化优先选"他人能看见"的类型**——内在精神侵蚀也尽量给外显体征，否则戏只能靠台词说。

### 七、常见翻车

| 病 | 修法 |
|---|---|
| 蓝条代价（睡一觉全好） | 加一层不可恢复账 |
| 代价从不催缴 | 写"最不巧时刻"的催债戏 |
| 主角用一百次没事，配角用一次死 | 统一规则，差别放在知情选择与量级 |
| 代价只有疼（表演成本） | 换成改变处境/关系的支付 |
| 黑暗反噬只在结尾出现 | 第一次使用就定价，全程记账 |
| 牺牲可被复活廉价撤销 | 底层代价不可逆；撤销牺牲等于抽掉全片重量 |
