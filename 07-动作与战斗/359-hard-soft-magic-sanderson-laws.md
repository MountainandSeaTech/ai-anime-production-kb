# 技能魔法编写二十连②：硬魔法与软魔法

## 核心要点

- **桑德森第一定律**：作者用魔法解决冲突的能力，与观众对魔法的理解程度成正比——**规则越清楚，主角越可以靠能力正面破局；规则越神秘，能力越只能用来制造麻烦和奇观**
- **第二定律：限制 > 能力**。超人有趣的不是力大无穷，是道德准则＋氪石；观众记住的是"他不能做什么"
- **第三定律：深挖，不要新增（Expand, Don't Add）**。好的魔法系统不是一千种能力，而是少数能力被推到极致的推论；防"世界构建病"
- **硬软是光谱不是二选一**：硬魔法给策略满足感（看他用已知规则解题），软魔法给敬畏与未知感（霍比特人视角）；成熟做法是**分区**——主角能力硬、上古/敌方/禁忌能力软，随剧情推进再硬化

## 详细内容

### 一、硬魔法 vs 软魔法

| | 硬魔法 | 软魔法 |
|---|---|---|
| 规则 | 清晰、可预测、观众学得会 | 刻意模糊，不知边界 |
| 观感 | 解谜/策略的满足感 | 敬畏、神秘、不安 |
| 典型 | 蜘蛛侠（蜘蛛感应/力量/丝/爬墙）、《迷雾之子》 | 甘道夫、《指环王》 |
| 叙事用法 | 可以让主角用能力**解决**冲突 | 主要用来**制造**困境与奇观 |
| 风险 | 过度解释像说明书 | 用它救场=机械降神(DEM)，信任崩塌 |

**第一定律的实操红线**：
- 想用一个能力在高潮解决问题→这个能力的规则必须**此前**已向观众建立（最好付出过代价演示过）
- 软魔法可以救主角一次（侥幸/神秘力量），但不能由主角主动、精确地调用它来解题——那等于作弊
- 段誉六脉神剑是经典"软硬混合"：机制存在但本人不可控——它能制造奇观也能让他陷入绝境，从不能稳定地替他解题，直到后期成长

### 二、第二定律：限制的类型库

限制不是简单的"蓝不够"，至少六个维度：
1. **能源/资源**：消耗物（金属/寿命/记忆/特定媒介）——资源本身可成为剧情道具
2. **条件**：只在特定情境可用（夜晚/愤怒/接触/静止）
3. **范围/精度**：能移山但捏不碎杯；能治愈但要把伤转到自己身上
4. **代价**：用了就失去什么（362专讲）
5. **时间**：冷却、蓄时、窗口、倒计时
6. **道德/关系**：能用但不该用（对人读心＝失去爱人的信任）

好限制的检验：**它是否同时是困境生成器？** "用火会让施法者变暴躁"自动产出冲突；"每天限三次"只是数值。

弱点设计（氪石位）：给强者一个具体、可被敌人利用、且与其能力同源的弱点——同源弱点比天降弱点高级（能控火者自身惧寒/力场使用者怕静音）。

### 三、第三定律：深挖四法

不新增能力，把已有能力推到尽头：
1. **外推（Extrapolate）**：不断问"如果……会怎样"——能推物的人，能不能推空气？推体内的血？推行星？每个推论都是新戏
2. **交叉（Interconnect）**：让已有规则相互作用——A能力遇B能力发生什么？规则碰撞是智斗的燃料（368）
3. **收紧（Tighten）**：给现有能力加代价或限制，比加新能力更能产出故事
4. **下沉到社会**：能力对经济/战争/阶级/日常的影响——能造火者的世界没有木柴市场，能预言者的赌场不存在

**数量纪律**：一部剧核心机制建议1个，主力能力3-5个（三主角各一＋反面1-2），其余从这少数中外推。每个新能力上线前先问：现有能力推不出来吗？

### 四、剧集/番剧的"规则透明度"调度

长篇比电影更需要硬化节奏：
- **开局软**：能力初次登场保留神秘（敬畏感），只给现象不给原理
- **中段硬化**：借训练、失败、对手之口把规则一块块补齐（338五种投放通道，视觉演示优先）
- **高潮用硬**：主角用观众完全理解的规则解题/反杀——满足感来自"我也想到了"
- **始终留白**：体系最高层/源头保持软——续作与神话感的空间

### 五、AI番剧的硬软取舍

- 主角能力**必须偏硬**：硬规则=可复用的固定视觉语法（手势/色板/介质），才能稳定生成与跨镜一致（374/356）
- 软能力（神迹/上古之力）视觉上用"不可完整展示"处理：局部、逆光、剪影、只给反应不给全貌——恰好与347/357的节制、344远景语法重合
- 规则写进能力圣经（377），保证几十上百条生成不互相矛盾——AI制作里"硬"还有生产管理意义

### 六、常见翻车

| 病 | 症状 | 修法 |
|---|---|---|
| 机械降神 | 高潮新能力/新规则救场 | 第一定律：规则前置＋提前付代价 |
| 数值蓝条 | 限制只是耗蓝计数 | 换成处境/道德型限制 |
| 能力通胀 | 打不过就加新能力 | 第三定律：外推与交叉替代新增 |
| 说明书病 | 角色大段讲解规则 | 338：用失败/训练/应用演出来教 |
| 全员全能 | 谁都会、边界模糊 | 373：每人一种核心机制＋明确盲区 |
| 弱者无戏 | 规则全利于强者 | 限制与克制链给弱者杠杆（368） |

## 备注

- 海裂映射：人类方"频率共振"偏硬（规则、代价、成败条件清晰，观众能预判方案）；深渊之核偏软（活生态、意图不明、全貌留到逆转乐章）——硬软对照天然成立
- 武侠映射：金庸体系偏软中带硬（内功境界软、招式机理硬），降龙掌的"留力"（274）、凌波微步的步法（282）都是硬规则，境界突破则保留软处理
