# 技能魔法编写二十连⑫：技能失效与受限

## 核心要点

- **失能戏的本质：把角色与他的能力分开，让观众看清剩下的那个人**。Power-Loss-Makes-You-Strong母题之所以有效——英雄在无力时仍想救人且用智慧/意志/凡躯做到了，这证明"英雄是身份不是技能包"
- 失效五种来源：①条件不满足（触发要素缺失）②代价到期（362催债）③外力压制（封印物/领域/克星）④心理性失能（创伤/潜意识拒绝）⑤过载损毁（烧坏/反噬恢复期）
- **好的"戏剧保护性限制"自带两个设计**：有时限（15分钟模式/电池）与可被干预（信号可被干扰）——限制本身成为可被争夺的道具，攻防双方都能围绕它做戏
- 失能恢复不能白给：由人物的选择/关系/牺牲挣回，且恢复后人与能力的关系应改变（370成长接口）

## 详细内容

### 一、五种失能的写法

| 来源 | 例子 | 强项 |
|---|---|---|
| 条件缺失 | 离地则地脉绝、水中火不燃、夜能力白昼废 | 机制内置，不需新设定；逼赛场智斗（368） |
| 代价到期 | 半臂石化、失声、七窍流血 | 连续性强，是角色历史的账面（362） |
| 外力压制 | 封印钉、抑制镣铐、静默领域、克属性结界 | 制造"如何挣脱/在压制下作战"的目标戏 |
| 心理封印 | 创伤后能力拒绝响应、潜意识筑墙 | 最适合角色弧光：恢复＝与自己和解 |
| 过载损毁 | 经脉受损/感官烧坏，需恢复期 | 提供"降级战斗"与休整文戏 |

### 二、压制性限制的道具化设计（反派/危机专用）

参照"15分钟颈环"式经典设计，给压制物写三条：
1. **规则**：怎么生效、持续多久、能量/媒介限制（时限创造倒计时）
2. **漏洞**：可被干扰/距离限制/特定情绪突破——漏洞是主角行动的入口
3. **副作用**：戴着也有代价（勉强发动会烧坏自己）——要不要冒险启动是选择戏
静默领域（海裂）按此写：规则（领域内共振切断）＋边界与频率漏洞（主角方的破题方向）＋副作用（强行发动被反噬）——压制场不是无解墙壁，是规则明确的BOSS机制。

### 三、失能段的标准剧情结构

1. **失去**：在最需要时失效（代价/压制到来要选在最不巧时刻）
2. **否认与挣扎**：习惯性催动→失败→再试→受伤——动作习惯突然落空最能写狼狈（伸手点火，只有一缕烟）
3. **凡人时间**：用头脑、经验、人脉、凡俗工具解决问题——把非能力技能提前埋线（医术、谈判、地形知识），此时兑现
4. **关系显影**：需要被保护/保护他人——队友与主角的价值排序在此显形；失能者如何接受帮助也是戏
5. **挣回**：识破压制规则/心理突破/付代价重启——主动选择而非剧情归还
6. **改变**：恢复后用法或态度不同（更少滥用／敢用／为别人用）

### 四、心理性失能（高级但难写）

- 能力与情感同源时可用：能力从保护欲来，创伤后潜意识认为"用了会再失去"→墙
- 表现必须外显：不是皱眉说"我感觉不到了"，而是**所有动作都对、现象不来**——指尖的火星只冒一缕、弦响而波不生
- 突破点是具体的关系事件而非空喊；突破后给视觉标记（同样的手势，这次光回来了，但颜色/稳定性变了）
- 风险：被读作"编剧不让他用"——必须提前埋心理规则（能力与情绪/状态的关系在首秀后就立过）

### 五、失能戏的纪律（防滥用）

- **不做廉价Reset**：反复失去-恢复是注水；全片主失能段1次为主，短条件缺失可多次（后者是战术调料）
- **失去期间世界不停**：敌人推进、倒计时照走——失能不是暂停键
- **不要让队友变蠢来衬他**：他无力时队友应正常发挥，他靠协作找到新位置
- **长期去能力化（De-Power）**：适合把太强角色留在群像里——给他新职能（军师/训练者/带限制的短暂发动），而非写死或冷藏
- 恢复一战的胜利来源按368处理：失能期间的观察/准备成为恢复后破敌的钥匙

### 六、AI生产口径（失能态视觉）

- 失效也要有**可识别视觉**：不是什么都不拍——给"努力了但只有残效"的镜头（一缕烟/半截石刺/哑弦），残效比无效果更有戏剧性也更好生成
- 压制领域：正常世界与领域内做两套明确视觉口径（光被吃掉/尘粒悬停/声音闷掉），边界弧线清晰，进出场一镜可读（354反向光效）
- 恢复瞬间：用反应镜头＋声音回归（环境音从闷到清）完成，少靠大爆炸
- 失能段动作戏多用凡身拍法：近身格斗、奔逃、道具——正好避开高特效成本，预算留给恢复镜
