# 降龙十八掌总纲——易经卦象武学体系与版本口径

## 核心要点

- 定位：金庸体系"天下第一刚猛掌法"，丐帮镇帮绝学；代表使用者萧峰、洪七公、郭靖
- 骨架：招式名几乎全部直接取自《易经》卦爻辞（乾卦为主），是"易经武学化"的巅峰案例
- 历史流变：原著设定原为二十八掌，萧峰与虚竹删繁就简合编为十八掌——"删改"本身是剧情素材
- 美学内核：大巧不工、收发有度；第一招"亢龙有悔"的"悔"字即全门总纲（发十分留二十分）

### 版本差异（实作口径）

- 日本金学研究版名单含"尺蠖之屈"、无"震惊百里"——属连载版/三联版流变差异
- **本项目统一采用上表通行版名单**，影视剧（97TVB/03张纪中）均按此口径

## 关键参数 / 模板 / 清单

**AI 改编三问（每次用降龙掌前过一遍）**
1. 谁在用？——萧峰刚猛直出／洪七公七虚七实／郭靖刚柔互济（详见 275）
2. 哪一招？——招名决定动作意象与镜头调度（详见 271/272/273）
3. 收还是发？——亢龙有悔体系下"留力"是高级感来源，掌掌全力＝外行画法

## 备注

- 降龙掌在原著中并无"金龙气劲"描写，龙形特效是影视再创作（详见 276），出图/出片前需先定"写实掌风"还是"龙形气劲"口径
- 与 182（动作戏三铁律）联用：降龙掌的张力靠"收发对比"，不靠连打数量
