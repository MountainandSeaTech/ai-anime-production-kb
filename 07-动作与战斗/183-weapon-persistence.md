# 武器/道具持久性

## 核心要点
- **道具持久性失败**：手里的剑在变招、切镜、出画入画时**忽然消失又出现**——不是穿模，是"物件不存在了"
- 与 182／128 的分工：**128 管武器相交时的物理**、**182 管相交的几何**、**本条管武器不相交时别让它消失**
- 三条根因层：①提示词层缺武器锚 ②运镜层让剑出画再入画 ③负向词层只防穿模不防消失
- 高发位置：**变招瞬间、镜间切换、whip pan／quick whip、出画入画、首尾帧**
- 关联 128 武器物理、182 动作戏三铁律、138 多镜连续性、132 动作相位接力

## 病灶：为什么剑会消失

| 层 | 问题 | 现象 |
|---|---|---|
| 提示词层 | 每 Shot 只写了**人物锚词**（谁），没写**武器锚词**（剑在谁手里、什么状态） | 变招时模型把武器"丢"了——它没被要求一直存在 |
| 运镜层 | `whip pan` / `quick whip` / 快速横甩让剑**划出画框边缘** | 出画后模型没有义务让它回来 → 再入画时凭空重现 |
| 负向词层 | 负向词只写了 `weapon clipping`（穿模） | 模型只被告知"别重叠"，没被告知"别消失" |
| 结构层 | Shot 切换处没有武器状态接力（132） | 上一 Shot 剑在右手、下一 Shot 无交代 → 归零重绘 |

## 修法：三管齐下

### 1. 武器状态锚（每 Shot 复写，和人物锚同级）
```
必备三要素：
  ① 持握    sword gripped firmly in the right hand / 剑柄紧握在右手
  ② 位置    blade stays within frame / 剑始终在画框内
  ③ 状态    sheathed（未出鞘）/ drawn（出鞘）/ mid-swing（挥击中）——写清是哪一个
```
- **别用"his sword"**——每 Shot 给完整描述，代词＝模型丢件
- 变招 Shot 还要写**过渡**：`the same sword keeps travelling from the high line to the low line`

### 2. 运镜保剑在框（高风险镜单独处理）
```
✗ whip pan / quick whip（横甩快得只剩残影）→ 剑必然出画
✓ 改为剑不离框的连续运镜：
   - 绕剑轨道的 arc shot（环绕持剑手）
   - 贴身跟拍 handheld close follow（剑一直在画面里）
   - 剑尖为轴的 tilt／pan（镜头跟着剑尖动，不甩开剑）
   - 需要"快"时用 motion blur＋速度线，**不靠甩镜头**
```

### 3. 负向词补"消失类"（穿模词管不了这个）
```
weapon disappearing, sword flickering, prop vanishing, sword popping in and out,
inconsistent weapon presence, weapon teleporting, blade blinking, missing weapon
```

## 高风险位置清单（逐项点名检查）
```
□ 变招那一镜：招式切换处写"同一把剑"＋"继续在手中"
□ 每一处 Shot 切换：出口状态与入口状态都写武器（132 动作相位接力）
□ whip pan / quick whip 镜：换运镜或补"剑不离框"
□ 出画入画镜：宁可让剑贴边停留，也别让它整把离框
□ 首帧图／尾帧图：首尾帧里剑的位置必须画进去，别只画人
□ 长段生成（如 30s）：中继锚帧补画武器位置，防后段丢件
```

## 模板示例（逐镜补丁写法）
```
✗ PZ-011: 近景，裴照一记上段斩紧接一记下撩。（没说剑在谁手、什么状态）
✓ PZ-011: 近景，裴照一记上段斩紧接一记下撩——同一把长剑始终紧握在他右手、
  全程留在画框内，由上段线连续划到下段线；Camera: arc shot 绕着他的持剑手
  （不要 whip pan）。

✗ PZ-014: 中景，裴照回旋跳斩，速度快得只剩残影。
✓ PZ-014: 中景，裴照回旋跳斩，长剑始终在他右手中、贴着画面内缘划出弧线，
  速度快但剑不离框；Camera: tight follow on the blade。

负向词追加：sword flickering, weapon disappearing, blade popping in and out
```

## 常见坑
- **只锚人不锚物**：人物锚词写得很全，武器一句"his sword"带过＝变招必丢
- **靠甩镜头求快**：whip pan 让剑出画；出画的道具回来全看运气
- **负向词只防穿模**：`weapon clipping` 防的是"叠在一起"，防不了"不见了"——两组词都要写
- **Shot 切换无交接**：上一镜剑举过头、下一镜无任何武器状态＝模型归零重画
- **首尾帧只画人**：首帧图里没剑，模型就不知道剑原本在哪
- **长段偷懒**：30s 内 10+ 镜，中段没有锚帧，武器最先漂（人还在、剑没了）

## 进阶
- **武器当第二角色锚**：把武器当作与人物同级的"锚点对象"，每 Shot 一起复写，丢件率大幅下降
- **道具钩子同理**：蜗牛、刀鞘、酒壶等一切"有戏的道具"都按本方法锚定，别只锚主角
- **接力求稳**：变招密集段宁可拆段（每段少镜），也别让模型在一次生成里连变 5 次招
- **负向词组库化**：把"穿模组＋消失组＋变形组"三类负向词分级常备，按当次风险叠加
- **与 182/128 组合自检**：相交→查几何（182）＋物理（128）；不相交→查持久性（本条）

## 备注
