# Locking 完整基础动作体系

## 核心要点

- Locking 1969 年由 Don Campbell 在洛杉矶创立（初名 Campbellocking），是 **Funk 文化产物**：穿条纹衫、背带、护膝、礼帽/贝雷帽、长筒袜，动作大、表情多、**主动与观众互动**
- 招牌动作 Lock：动作做到一半**突然锁住**（屈肘、掌心朝上、上身微仰、膝盖沉），停顿后再"解锁"继续——动-停-动的节奏对比是舞种灵魂
- 与 Popping 的根本区别：**Locking 锁大造型、外放、带笑、跳 funk；Popping 用肌肉 pop、冷静控制、身体质感像机械**；不要混用
- 底层姿态：**膝盖保持深度 bounce 的半蹲位**，动作多用大幅度直线划臂（sharp but big），手是视觉主角
- 动漫短剧价值：**天然喜剧舞种**——Lock 的骤停、Point 的指认、Funky Guitar 的空气吉他，全是现成的反应镜头和荒诞节拍

## 详细内容

### 一、The Lock（锁姿）——一切的母动作

**完整一拍流程**：
1. 双臂从低位向斜上快速甩出（或由前向上）
2. 到位瞬间**双肘急停屈收**，前臂竖直、**双掌朝上张开**（像端着两个托盘），同时膝盖下沉、上身微后仰
3. **锁住 1–2 拍**：姿态完全静止，但脸上有表情（笑/惊讶/看手指的方向）
4. "解锁"：放松，弹回继续动作

- 变体：Up Lock（上锁，最经典）、Down Lock（下沉锁）、单手 lock
- 质感：甩臂要快且脆（像被拽住），锁住要绝对干净——本质是带造型的 dime stop
- **镜头**：锁住瞬间最适合切镜/定格；观众反应镜头常插在 lock 拍上

### 二、七大基础动作逐个拆

| 动作 | 形态 | 节拍/要点 |
|---|---|---|
| **Point（指）** | 一只手臂完全伸直、食指用力指向某方向（侧、上、下、指观众），另一只手叉腰或收于胸前 | 重拍"钉"出去，停半拍；常连续指不同方向做喜感 |
| **Wrist Twirl（绕腕）** | 食指指天，手腕连续绕小圈（像套索/转花），可双手同时 | 每拍绕1–2圈，手腕松、手臂紧 |
| **Scooby Doo** | 先双手上 lock 宣告，接一个前踢→踏步→并腿造型（unity pose） | 6–8拍组合，locking 第一个学的套路 |
| **Scoobot / Scoobot Hop** | 点地-换脚的小跳步配合手的快速 lock | 轻快半拍步 |
| **Skeeter Rabbit** | 高抬膝踢腿 + 小 shuffle 换重跳，前后左右移动 | 创作者名命名；踢膝到腰高，动作蹦跳感强 |
| **Funky Guitar** | 双手像抱电吉他（一手把位一手拨弦），向后走步，随律动点斗 | 空气吉他，喜剧/致敬乐队拍 |
| **Hitchhike（搭车客）** | 拇指朝肩后连续比"搭便车"手势，配踏步 | 叙事性手势动作 |

**其他高频词汇**：
- **Pacing**：手臂向侧快速戳出（wrist loose / arm tight）
- **Which-a-Way**：膝盖内扣外开连续切换方向的滑稽步
- **Stop and Go / Quickies**：走步中突然急停再启动
- **Uncle Sam Point**：仰头、手高指的山姆大叔式指认
- **Give Yourself a Hand / Clap**：自拍手、指观众、邀请鼓掌等互动动作
- **Knee Drop / Split**：跪滑、劈叉等炫技落地（locking 表演常用）

### 三、底层 Groove 与表演语法

1. **Funk bounce**：重拍向下，膝盖弹得深，胯随节奏前后/左右摆；所有动作"坐"在这个 bounce 上
2. **大线条、明方向**：手臂动作走明确直线和大弧线，指哪打哪，观众席后排也要看清
3. **Lock 节奏模板**：`快速动作（2拍）→ 锁住（1-2拍）→ 表情/看向某处（1拍）→ 解锁流动（剩余拍）`
4. **表演三要素**：
   - **笑容/表情**：locking 默认"笑眼"，与其他酷舞种最大差异
   - **观众互动**：指观众、递手、比"你们"、邀请鼓掌——cypher 里会直接对镜头做
   - **角色化**：即兴演小情境（敲门、照镜子、弹吉他、赶时间）
5. 音乐：Funk（James Brown 式）节奏鲜明、管乐 hit 多——**每个管乐 stab 就 lock 一次**是最正统的跳法

### 四、8拍组合套路（可直接做分镜脚本）

**套路 A（经典展示 16 拍）**
```
[1-2]  双手上甩 Lock，锁住，微笑看镜头
[3-4]  解锁，右手指向右上方 Point，眼看指尖
[5-6]  Wrist Twirl ×4（双手）
[7-8]  收回，半蹲 bounce 两次
[9-12] Scooby Doo：上lock→前踢→踏步→并腿造型
[13-14] 左 Skeeter Rabbit 踢跳
[15-16] 右 Point 重拍钉住 + 笑容定格（可切观众反应）
```

**套路 B（喜剧叙事 16 拍）**
```
[1-4]  Hitchhike 搭车手势 + 原地踏步，歪头看"来车方向"
[5-8]  Which-a-Way 滑稽内八外八换向
[9-12] Funky Guitar 空气吉他后退走
[13-16] 突然发现镜头→僵住 Lock→手指镜头→拉观众鼓掌手势
```

### 验收清单

- [ ] Lock 姿态正确：肘屈、掌朝上、身微仰、膝沉，四件同时出现
- [ ] 每个锁有真实停顿（1–2 拍），不是放慢
- [ ] Point 手臂完全打直、食指明确，与叉腰手形成对比
- [ ] 全程深 bounce 半蹲底律动，无直立站桩段
- [ ] 表情外放（笑/惊/夸张），至少一次与镜头"互动"
- [ ] 动作大线条、方向明确，远景可读
- [ ] 服装符合复古 funk 造型，护膝等道具在跪滑镜头前已存在（资产连续性）
