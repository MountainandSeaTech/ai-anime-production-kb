# 技能魔法编写二十连④：机制五要素

## 核心要点

- **"酷点子"不是机制**。一个机制只有答清五件事才能支撑剧本：①怎么触发 ②输入与输出（烧什么、产什么、量级）③代价 ④边界与克制（作用域/精度/时间）⑤失败模式（失误/过载/被打断会怎样）
- 业界方法可对照AALC：Appearance（表象）→Abilities（能力）→Limits（限制）→Cost（代价），按顺序构建、层层依赖——先定长相与能做什么，再用限制和代价收紧
- 每个要素都要能**生成至少一场戏**：触发条件产"做不到"的困境，精度边界产"差一点"的悬念，失败模式产狼狈与转折
- 五要素写在同一张能力卡上（377模板），全剧唯一正典，避免写到哪里改到哪里

## 详细内容

### 一、五要素逐项

**要素1：触发（Trigger）——他凭什么能用**
- 来源资格：血脉/学习/契约/装备/附体（谁能用本身就是世界规则）
- 发动条件：动作（手势/结印/拔剑）、语言（咒语/解放令）、媒介（符/金属/水）、状态（静止/愤怒/接触目标/看见目标）
- 戏剧化触发：把触发设计成"需要争取"的事——必须看到对方眼睛、必须让弦响够三声、必须接触地面（离地即废，天然被空战克制）
- 检查：触发条件能不能在战斗中被阻止？能，就有了打断戏（369）

**要素2：输入与输出（I/O）——烧什么、产什么、多大**
- 输入：能量从哪来（自身气/地脉/消耗物/环境热/他人寿命）
- 输出：现象是什么（力/热/位移/信息/改变材质），量级与范围（几米/几人/多久）
- 精度：能不能细操作（能移山但捏不碎杯＝高量级低精度；外科手术式＝低量级高精度）
- 写法建议：用"能力动词＋边界参数"描述——"推动接触到的物体；最大约一人重；作用时间≤3秒"，别用形容词（"极强"无法写戏）

**要素3：代价（Cost）——谁来还、还什么**
- 物理/寿命/情绪/社会/物质五类，强系统用**叠层代价**（362专讲）
- 本要素卡上只写硬规则：每次固定成本＋过载追加成本＋不可恢复项

**要素4：边界与克制（Limits）——不能做什么/被谁克**
- 作用域：距离、数量、是否区分敌我、能否作用于自己/空气/死人
- 对抗关系：被哪种机制直接克制；克制哪种机制（368）
- 硬禁止清单：3-5条"绝对做不到"——边界越具体，解题越可信（第一定律）

**要素5：失败模式（Failure）——出错时的世界**
- 失误：条件差一点时的效果（六脉神剑时灵时不灵＝神级失败设计）
- 过载：透支的症状序列（手抖→七窍流血→石化不可逆，分阶段即视觉成长线，对接370）
- 被打断：蓄力中被打断的反噬
- 被克制：遭遇克星时的具体表现（静默领域内声弦完全熄灭）
- **失败模式必须可视化**：失败也要有可拍的样子（374），不能只写"失败了"

### 二、AALC补层：表象（Appearance）

- 机制的"皮"：色、声、形、气味、介质、对环境的即时痕迹
- 顺序提醒：先定表象与能力再收紧——但视觉皮相与机制必须同源（岩骨的灰褐来自岩土原理，不能机制是地脉、视觉却是蓝火）
- 表象即识别系统：每个能力一个核心意象＋一个固定色＋一种声音（373/374）

### 三、能力卡示例（海裂·岩骨）

```
名称：地脉共鸣
来源：出生即与地壳矿脉共振的异质血脉
触发：赤脚/掌心接触裸露岩土；需感知矿脉走向（静止凝神1-2秒）
输入：自身神经与体力＋借用地脉应力
输出：使接触范围内岩土隆起/开裂/石化外物；量级随借取应力增大
精度：粗（墙、柱、碎块）；做不了细活
代价：每借一次，石化从指尖上爬一寸，睡眠可缓不可逆（不可恢复项）
边界：离地无效｜水中无效｜无法作用于活物血肉（只能石封外物）
克制：被空中/水生目标克制；深渊静默领域切断共振
失败：应力错判→反震内伤；过载→整条手臂石化
表象：灰褐岩纹沿皮肤攀爬、石粉尘落、低频闷响、地脉微光金线
```
五要素每一条都能直接点戏：离地困境、精度误事、石化倒计时、领域熄灭、反震狼狈。

### 四、从机制自动生戏（自检五问）

1. 什么情况下他想用但**触发不了**？
2. 什么情况下量级/精度**差一点**？
3. 代价让他在这场**用还是不用**？
4. 谁/什么环境正好踩在他**边界外**？
5. 他**失败**时旁边有谁看着？

五问答不出三场以上具体戏，机制就是"战斗道具"不是"戏剧引擎"——回去加限制而非加威力（359第二定律）。

### 五、常见机制病

| 病 | 修法 |
|---|---|
| 万能动词（操控/毁灭/创造） | 换成可观察动词＋量级＋条件 |
| 蓝条思维（只有能量消耗） | 加触发门槛与道德/社会代价 |
| 精度随剧情漂移（要粗就粗要细就细） | 卡上写死精度，剧情需要细活就设计"做不到" |
| 无失败态（要么成功要么没放） | 设计三档：小成/偏差/反噬 |
| 边界事后补丁 | 第一幕演示边界，第三幕才可用边界解题 |
