# 技能魔法特效与提示词模板二十连⑬：护盾/结界/屏障

## 核心要点

- **护盾第一死因：像玻璃贴纸**——只写"magic shield"得到的是半透明平面；必须写**形态+材质+符文**三选，护盾才有体积和质感
- **护盾六段式结构**：场景构图 → 形态材质 → 激活能量 → 冲击反应 → 环境氛围 → 风格画质——缺一不可，尤其"冲击反应"是护盾戏的灵魂
- **护盾反应四类型**：涟漪（rippling like water）/ 裂纹自愈（spiderweb cracks healing）/ 吸收增强（absorbing, runes glow brighter）/ 局部崩解重组（flaking away in embers reforming）——不同反应讲不同故事
- **护盾是光源**：护盾自身发光（`ethereal glow`, `long shadows`），它不只挡攻击还照亮战场——写清光照交互
- **环境效果不可省**：`distorts air like heat haze`, `kicks up dust vortex`, `ground cracks with energy`——护盾影响它所在的空间

## 详细内容

### 一、护盾形态×材质×符文三选表

| 形态 | 语义 | 适用 |
|---|---|---|
| spherical dome | 全方位防御 | 结界/大范围 |
| semi-translucent shimmering wall | 方向性防御 | 正面格挡 |
| concave energy disc | 集中防御 | 精准格挡 |
| interlocking hexagonal barrier | 科技/精密 | 未来/符文工程 |
| personal buckler-sized field | 个人机动防御 | 武者/游侠 |
| giant floating aegis | 神级防御 | 圣骑士/神术 |

| 材质 | 质感 | 语义 |
|---|---|---|
| flawless arcane crystal | 坚硬、透明、折射 | 精密/完美 |
| swirling ethereal mist | 流动、柔软、不可捉摸 | 自然/幻术 |
| hard-light energy | 几何、锐利、科技 | 未来/科技 |
| woven strands of pure light | 编织、有机、生命 | 精灵/神圣 |
| fractured glassy force | 脆弱、裂纹、危险 | 禁忌/牺牲 |
| ancient stone animated by runes | 沉重、古老、大地 | 德鲁伊/泰坦 |
| intertwined spectral roots | 有机、纠缠、自然 | 森林/生命 |

### 二、护盾反应四类型（冲击戏的灵魂）

```
TYPE 1 - 涟漪（Rippling）：
  → `rippling violently like water`
  → 语义：能量分散，柔性防御
  → 适用：对抗能量攻击（火球/闪电）

TYPE 2 - 裂纹自愈（Cracks Healing）：
  → `developing spiderweb cracks that quickly heal with shimmering light`
  → 语义：承受压力但恢复，有代价
  → 适用：持久防御/消耗战

TYPE 3 - 吸收增强（Absorbing）：
  → `absorbing the attack, causing its runes to glow brighter`
  → 语义：越打越强，吸收型
  → 适用：反击型护盾/能量吞噬

TYPE 4 - 局部崩解重组（Flaking & Reforming）：
  → `flaking away in glowing embers before reforming`
  → 语义：牺牲局部保全整体，悲壮
  → 适用：舍身防御/最后防线
```

### 三、护盾能量源与激活效果

| 能量源 | 激活效果 | 环境效果 |
|---|---|---|
| pure arcane | concentric rings expanding outward | air distorts like heat haze |
| divine holy light | runes tracing in air before solidifying | illuminates with ethereal glow |
| primal nature | particles drawn from environment | ground cracks with energy |
| chaotic fel | sudden shimmer coalescing | kicks up dust vortex |
| elemental fire/ice/storm | elemental burst outward | temperature change visible |
| necromantic soul-force | spectral energy weaving | shadows deepen around |

### 四、冲击类型与视觉对照

| 攻击类型 | 冲击视觉 | 音效参考 |

| dragon fire breath | shower of vibrant orange sparks | roaring inferno |
| shadowy arrows | dark energy explosion, smoke wisps | whispering hiss |
| demon fist | blinding flash, shockwave ring | bone-crushing thud |
| lightning bolt | ozone crackle, electric arcs | thunder crack |
| necrotic curse | decay spreading across shield | whispering death |

### 五、常见翻车与修复

| 翻车 | 原因 | 修复 |
|---|---|---|
| 像玻璃贴纸 | 无形态材质符文 | 补三选 |
| 冲击无反应 | 没写护盾反应 | 补涟漪/裂纹/吸收/崩解 |
| 护盾不发光 | 没写能量源 | 补能量源+环境光照 |
| 像游戏UI | 无物理交互 | 补`heat haze`, `dust vortex`, `shadows` |
| 太干净 | 无损伤痕迹 | 补裂纹/碎片/能量消耗 |
