# H3/Wan通用提示词铁律

## 核心要点
- 三条铁律通吃所有视频模型：**单一动作 / 幅度显式 / 动词优先**
- AI视频翻车的80%源于：动作太多+幅度模糊+形容词堆砌
- 模型能理解的单位是"一个节拍"——不是"一场戏"
- 关联 111 公式、117 动作词汇库

## 铁律1：单一动作原则

### 规则
```
一个镜头 = 一个主动作 + 最多一个伴随微动作
✓ "她缓缓抬头，发丝滑落"
✗ "她抬头，转身，拔刀，跃起，劈下"
```
- 多动作=AI摊薄算力=每个动作都做一半=全部糊
- 想拍复杂动作链？拆镜头（关联132动作匹配，多镜接力）

### 动作拆分到镜头级
```
原设想："她抬头看到敌人，拔刀冲出"
拆成：
  镜1：她抬头（特写）[Push in]
  镜2：敌人入画（反打）
  镜3：她拔刀（手部特写）
  镜4：她冲出（跟拍）
```
- 4个清晰镜头>1个混沌镜头

### 例外：复合动作连体词
```
有些动作天然一体可以合并：
  "转身拔刀"（转+拔=一个流畅动作）
  "跃起劈下"（跳+劈=空中连段）
判断标准：真人表演时是否一口气完成
```

## 铁律2：幅度显式控制

### 幅度词三档
```
微幅：slightly / gently / subtly / 微微 / 缓缓
中幅：（默认，可不写）
大幅：violently / dramatically / 猛烈 / 骤然
```
- 不写幅度=AI默认中等——该细的时候糙，该爆的时候软

### 幅度与情绪绑定
```
压抑场景：全微幅（呼吸/睫毛/指尖）
爆发场景：蓄力微幅+爆点大幅（关联026蓄力原则）
```
- 幅度曲线=情绪曲线（关联014）

### 幅度词位置
```
紧贴动词：
✓ "slowly raises her hand"
✗ "she raises her hand, in a slow manner, slowly"
（重复修饰=指令稀释）
```

## 铁律3：动词优先于形容词

### 原则
```
AI对动词的响应 > 名词 > 形容词
✗ "美丽的、震撼的、电影感的画面"
✓ "裙摆飞扬，火星四溅，镜头急速拉远"
```
- 形容词是评价，动词是指令——AI执行指令不执行评价

### 动作动词库（高响应）
```
面部：blink / gaze / squint / smirk / tremble
手部：grip / release / tremble / reach / draw
身体：lunge / stagger / collapse / brace / turn
环境：sway / ripple / shatter / billow / flicker
```
- 关联 117 动作词汇库

### 形容词的正确用法
```
形容词只用于"AI无法推断的物理属性"：
✓ "torn coat"（破损是视觉事实）
✓ "cold blue light"（色温是生成参数）
✗ "beautiful coat"（美是评价）
```

## 三律综合检查

### 提示词写完问三句
```
1. 这个镜头有几个主动作？（>1=拆）
2. 动作幅度写了吗？（没写=补）
3. 删掉所有形容词，动作还成立吗？（不成立=重写）
```

## 模板示例

### 反面→正面改造
```
改前：
"一个帅气剑客非常霸气地快速发动猛烈攻击，画面震撼，电影级"
（0个具体动词，4个评价词）

改后：
"剑客沉肩蓄力，猛然蹬地前冲，
 刀光自下而上撩起，水花随刀势炸开 [Tracking shot]"
（4个具体动词，幅度=猛然，方向=自下而上）
```

### 微表情镜头
```
"她的睫毛轻轻颤动（slightly tremble），
 视线缓缓下移（gaze slowly lowers），
 指尖无意识收紧（fingers subtly tighten）[Push in]"
```
- 3个微动作同向服务一个情绪=允许的复合（关联164微表情）

## 常见坑
- **动作贪心**：5秒镜头塞8个动作=每样都看不清
- **幅度缺失**：写"他怒吼"不写多大声=AI给你淑女式张嘴
- **副词游离**：幅度词不贴动词=权重分散
- **形容词幻觉**：以为"电影感8K杰作"有用=噪声
- **中文直译陷阱**："霸气侧漏"AI不懂——翻译成视觉事实（"下巴微抬，俯视"）

## 进阶
- **动词时态**：进行式（is drawing）比完成式（draws）更利于生成中间动态
- **否定幅度**："barely moves（几乎不动）"是静止镜头的保险丝
- **幅度对比**：同镜头内"周围风暴狂卷，他纹丝不动"=静者更强
- **动词链**：必须用多动作时，用时间词串联（"先…随后…"）=AI按序执行的提示
