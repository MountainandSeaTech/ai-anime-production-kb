# 动作词汇库

## 核心要点
- 视频 AI 听不懂复杂动作链——**一句一动词最稳**
- 动作四段链：**预备 + 主动作 + 余动 + 模糊**
- 迪士尼 12 原则中关于动作的：anticipation / follow-through / overlapping / squash & stretch
- 动作物理感=重量+惯性+冲击——AI 出图常飘，需词补足

## 动作链四段（核心）

### 1. 预备（Anticipation）
```
anticipation              预备动作（蓄力）
winding up               蓄力（投掷/挥击前）
crouching                蹲伏（起跳前）
pulling back             后拉（挥击前）
preparing to strike      准备出击
leaning forward          前倾
deep breath              深吸气
```
- 预备动作是张力的"建压"——见 017 动作张力
- 没有 anticipation 直接挥=突兀=无张力

### 2. 主动作（Main Action）
```
striking                 出击
slashing                 挥斩
punching                 出拳
kicking                  踢
drawing katana           拔刀
leaping                  跳跃
lunging                  突进
dodging                  闪避
spinning                旋转
```
- 一句只写一个主动作——多动词视频会糊

### 3. 余动 / 跟随（Follow-Through）
```
follow-through            余动（主动作后身体继续）
overlapping action        重叠动作（身体各部分不同时停）
hair trailing              头发飘动
cloth rippling            衣料飘动
momentum carrying         动量延续
body settling              身体落定
```
- 余动是真实感的关键——没有=机械僵硬
- 长发/披风/衣摆是余动的视觉载体

### 4. 运动模糊（Motion Blur）
```
motion blur              运动模糊
speed lines              速度线（动漫风）
impact frame             冲击帧（爆点那一帧）
smear frame             拉伸帧（变形拉伸）
afterimage               残影
```
- motion blur 沿运动方向→不是全向模糊
- impact frame 是动漫爆点专用——见 017

## 物理感词汇（重量/惯性/冲击）

### 重量感
```
heavy                    沉重
weighty                  有分量
massive impact           巨大冲击
ground-shaking           地面震动
crater-forming           形成弹坑
shockwave                冲击波
```

### 惯性
```
momentum                 动量
inertia                  惯性
carrying through         贯穿延续
skidding                 滑行停不住
stumbling                踉跄
```

### 冲击
```
impact                   冲击
collision                碰撞
explosive force          爆发力
recoil                   后坐力
bone-crushing            骨碎般
```

## 动漫专属动作词

### 爆点瞬间
```
impact frame             冲击帧（接触瞬间定格）
freeze frame             定格帧
burst frame              爆发帧
white flash frame        白闪帧
shockwave ring           冲击波环
```

### 动漫风格化
```
speed lines              速度线（背景放射线）
smear frame              拉伸帧（变形夸大）
squash and stretch       压扁拉伸（弹性质感）
exaggerated motion       夸张动作
dynamic pose             动态姿势
```

## 动作情绪词
```
frantic                  慌乱（快乱）
deliberate               蓄意（慢稳准）
graceful                 优雅（流畅）
brutal                   残暴（重硬）
desperate                拼命（失控感）
effortless               轻松（高手感）
```
- 情绪词给动作定调——AI 会调整速度与幅度

## 组合示例

### 拔刀居合（爆点）
```
character crouching in anticipation, drawing katana in single motion,
motion blur along blade arc, hair trailing, cloth rippling,
impact frame at sword unsheath, speed lines radiating
```

### 重击落地
```
character leaping from above, massive impact on landing,
ground-shaking, crater-forming dust, shockwave ring expanding,
hair trailing upward from momentum, body settling
```

### 高手从容闪避
```
character effortlessly dodging, minimal motion, hair slightly trailing,
deliberate movement, graceful arc, afterimage faint behind
```

### 拼命突进
```
character lunging forward desperately, motion blur streak,
cloth rippling wildly, stumbling follow-through, frantic pace
```

## 常见坑
- **写多动词**："drawing and slashing and jumping"→视频糊
- **忘了 anticipation**：直接出击=无张力
- **忘了 follow-through**：动作僵硬像机器人
- **motion blur 全向**：写 "blur" 不写 "motion blur along blade"→全图糊
- **缺重量词**：动作轻飘=没冲击力

## 进阶
- **三帧定爆点**：anticipation 帧 + impact frame + follow-through 帧
- **余动载体**：长发/披风/裙摆/衣袖——设计时主动加
- **情绪配速**：effortless=慢稳；desperate=快乱；deliberate=慢准
- **impact frame 配 speed lines**：动漫爆点双神器

## 备注
- 一句一动词最稳
- 动作链=预备+主动作+余动+模糊
- anticipation 与 follow-through 是张力与真实感的两根支柱
