# 技能魔法编写二十连⑰：技能视觉开发管线

## 核心要点

- **能力在文本层定稿后，要经过一条七步翻译才成为"可生成资产"**；跳过开发直接让每镜自由发挥＝同一能力每镜长相不同，必崩
- **签名特效(Signature Effect)规格先行**：一个能力=一个核心意象＋一组固定色＋一种伴随粒子＋一种声音＋一种环境后果，五样全剧不变（同343正典纪律应用于特效）
- **提示词模块化**：把签名特效拆成固定短语块（光核块/粒子块/交互块/收招块），每个镜头像搭积木一样装配变量块，固定块逐字复用
- 招名/术语**永不进入提示词**（271铁律）——提示词层只有物理白描；术语只活在剧本、对白与圣经层（372）

## 详细内容

### 一、七步管线

**Step1 机制冻结**：361五要素卡签字定稿（触发/I-O/代价/边界/失败），视觉开发中不得反改机制
**Step2 签名特效规格（一页纸）**：
```
核心意象：一个画面名词（弦状金线波／灰褐岩纹／深渊青紫雾）
主色+辅色：色值口径（暖金#D9B36C类描述用自然词：old-gold/stone-grey）
伴随粒子：石粉尘屑／空气涟漪微尘
介质：空气可见化方式（尘/雾/雨/热浪）
声音档：低闷鼓噪／绷紧弦鸣（交声音设计，304）
环境后果：地面裂纹／物件共振位移
显形级基线：L1微痕日常 / L4全力决战（290分级）
```
**Step3 正典关键帧**：图像模型出静帧——①静立蓄势（光初现）②全力发动（最大形态）③收招余痕（代价外显）三帧，迭代到满意后**存档永不重生**，作I2V与角色实体并列的第二参考
**Step4 提示词模块拆解**（见下）
**Step5 元素板预制**：纯黑底的粒子/光效/波纹板生成存档（356规范），全剧复用
**Step6 分镜装配**：每镜取固定块＋该镜变量（机位/景别/动作/环境），走345-355工艺选择
**Step7 QC入库**：截帧与正典三帧并排比对（色/形/粒子一致性），通过后进资产包登记

### 二、提示词模块解剖（四段固定串）

以"声弦"为例（英文块供国际模型，中文块供国产）：
```
[FX-CORE 固定] thin vibrating strings of old-gold light extending from her
fingertips, taut and luminous, brighter core with soft fading corona
[FX-PARTICLE 固定] fine dust motes caught and trembling along the lines,
ripples distorting the air around the strings
[FX-INTERACT 变量] the golden light catching her face from below / ground
pebbles lifting and rattling in rhythm / window paper splitting along
vibration lines
[FX-RELEASE 固定] strings thinning and retracting into her fingertips,
a single dying harmonic shimmer, her hand trembling
```
- 固定块（CORE/PARTICLE/RELEASE）逐字不变；交互块按镜头换
- 每个能力另配负向固定串：uniform flat glow, neon plastic, color shift, extra strings appearing, tangled wires（防廉价发光354/防多线/防电线感）
- 代价态独立模块：声音沙哑→指尖纹路→整臂……三档视觉（362）各有固定块

### 三、能力镜头的通用装配公式

```
[角色实体参考+服装状态] + [场景+机位+光位]
+ [触发动作白描（手势/身法，不含招名）]
+ [FX-CORE] + [FX-PARTICLE]
+ [FX-INTERACT 本镜变量：脸/衣/地/道具/空气，六接触面选345五355]
+ [摄影机反应：震/稳/慢镜] + [时间锚：第几秒发动]
+ [负向固定串]
```

### 四、分级显形的镜头预算（接290 L1-L4）

| 级 | 用途 | 工艺 | 配额 |
|---|---|---|---|
| L1 微痕 | 日常/教学 | 直出可成 | 不限 |
| L2 局部 | 普通战 | I2V+固定块 | 每战若干 |
| L3 完整 | 关键回合 | I2V+元素板合成预留 | 每集1-2 |
| L4 全力 | 觉醒/终局 | Hero镜全流程（356/357） | 全片个位数 |

级别影响：CORE块亮度词、粒子密度、环境破坏规模、摄影机反应幅度——四套预制，临场不调参。

### 五、跨镜一致性纪律

1. 同一能力所有镜头引用同一正典帧ID与同一模块版本号（圣经里登记版本，377）
2. 平台支持特效实体/参考的一并挂载；不支持就I2V正典帧
3. 色板不接受"差不多"：过QC时与正典帧叠色对比，偏色重抽
4. 多能力同框：各FX-CORE分图层生成再合成（356），同条直出多特效高概率串色串形
5. 变身/形态切换：每形态独立正典帧与模块（370），切换过程镜头独立模板

### 六、从剧本到工单的字段（制作本对接）

分镜表技能列扩成：
```
能力｜显形级｜触发动作｜FX模块版本｜交互面（选哪3面）
参考（角色实体/正典帧/元素板ID）｜工艺（直出/I2V/合成）
时长窗｜QC截帧比对结果
```
与六条铁律第4条（逐镜资产自检）、第6条（开箱即贴）合流——技能资产包就是本管线的产物。

### 七、常见翻车

| 病 | 修法 |
|---|---|
| 同一能力每镜颜色不同 | 正典帧+CORE固定块+叠色QC |
| 提示词写招名导致古风插画/CG感 | 一律物理白描，招名只在剧本层 |
| 能力光像电线/塑料管 | 负向串+tangled wires+核晕结构 |
| 每镜从零构思特效 | 模块装配，变量只写交互与机位 |
| 两种能力同框串味 | 分层生成合成 |
| 角色脸与特效难两全 | 保人轻特效策略（355/356），交互光后期补 |
