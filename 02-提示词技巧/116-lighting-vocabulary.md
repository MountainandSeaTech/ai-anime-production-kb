# 光影词汇库

## 核心要点
- 光影是张力第一命脉——均匀光=无张力
- 四类：**布光位置 + 色调 + 对比 + 质感**
- 一句提示词选 1 主光 + 1 色调 + 1 对比词最稳
- 详见 016 光影张力原理、094 光影大师镜头

## 布光位置（Lighting Position）

### 主光（Key Light）
```
key light                 主光（决定曝光与阴影走向）
soft key light            柔和主光
hard key light            硬光（阴影边缘锐利）
high key                  高调（亮部多，阴影少=轻松）
low key                   低调（暗部多=神秘/压抑）
```

### 位置/方向
```
front light               正面光（平淡，少用）
side lighting             侧光（半明半暗，张力首选）
45-degree Rembrandt       伦勃朗光（鼻侧三角光斑）
backlight / backlighting  逆光（轮廓发亮）
rim light                 边缘光（细亮勾边）
silhouette                剪影（全黑轮廓）
top light / overhead      顶光（审讯/压迫）
underlighting             底光（恐怖/诡异）
practical light           实用光源（台灯/手机/火把）
```

### 多光布置
```
three-point lighting      三点布光（key+fill+back）
split lighting            分裂光（半脸亮半脸暗=内心分裂）
motivated lighting        动机光源（光源有叙事理由）
```

## 色调（Color Temperature）

### 冷暖
```
warm tone                 暖调（橙黄=温馨/黄昏）
cold tone / cool tone     冷调（蓝=孤寂/科技/死亡）
warm orange tone          暖橙
cold blue tone            冷蓝
teal and orange           互补色（电影级标配）
```

### 单色调
```
monochrome                单色
desaturated               低饱和（灰=压抑）
high saturation           高饱和（鲜艳=强情绪）
sepia tone                褐褐色（怀旧/老照片）
black and white           黑白
```

### 具体色温词
```
golden hour               黄金时刻（日出日落橙光）
blue hour                 蓝调时刻（日落后深蓝）
moonlight                 月光（冷蓝银白）
candlelight               烛光（暖橙摇曳）
neon glow                 霓虹（赛博朋克）
fluorescent               荧光灯（冷绿=病态）
```

## 对比与质感（Contrast & Quality）

### 对比
```
high contrast             高对比（明暗反差大=戏剧）
low contrast              低对比（柔和=平淡）
chiaroscuro               明暗对照（伦勃朗式极端对比）
shadow play               投影戏（强光影投影）
```
- chiaroscuro 是张力之王——源自文艺复兴油画
- film noir 风格=极致 chiaroscuro

### 阴影质感
```
hard shadows              硬阴影（边缘锐利）
soft shadows              柔阴影（边缘模糊）
long shadows              长阴影（低角度光源/黄昏）
cast shadows              投射阴影
dappled shadows           斑驳阴影（树叶漏光）
```

### 光质
```
volumetric light          体积光（光束可见=神圣/压迫）
god rays / crepuscular    耶稣光（光束穿雾）
light rays                光线
glow                      辉光（柔光包围）
lens flare                镜头眩光
bloom                     泛光（高光溢出）
caustics                  焦散光（水面折射光斑）
```
- volumetric light 是压迫感神器

## 特殊氛围光（叙事用）

```
flickering light          闪烁光（不安/危险）
single overhead light     单顶光（审讯感）
floodlight                泛光灯（强光照射）
spotlight                 聚光灯（舞台/审讯）
lightning flash           雷电闪光（瞬间高光）
firelight                 火光（暖橙跳动）
```

## 组合示例

### 审讯压迫感
```
single overhead light, hard shadows, high contrast, cold blue tone,
chiaroscuro, volumetric light through mist
```

### 黄昏孤寂
```
golden hour, long shadows, warm orange tone, backlight, silhouette,
desaturated, low contrast
```

### 赛博压迫
```
neon glow, teal and orange, high contrast, lens flare,
flickering light, hard shadows, cold blue tone
```

### 神圣降临
```
volumetric light, god rays through stained glass, warm golden tone,
soft shadows, bloom, low contrast
```

### 不安预兆
```
flickering light, underlighting, hard shadows, cold green fluorescent,
high contrast, desaturated
```

## 常见坑
- **写 "good lighting"**：AI 不知指什么→给具体位置词
- **冷暖冲突**：同时写 warm orange + cold blue 不加 teal/orange→画面脏
- **全用形容词没名词**：写 "moody dramatic" 没用→写 "low key, side light, chiaroscuro"
- **堆 5 个布光词**：AI 不知听谁→出图花
- **忘了体积光词**：想要光束效果却没写 volumetric→出图没光柱

## 进阶
- **场景配光**：审讯=顶光；孤寂=逆光剪影；战斗=侧光高对比；神圣=体积光
- **色调叙事**：冷蓝=死亡/疏离；暖橙=回忆/救赎；冷绿=病态/危险
- **阴影也是主角**：写 shadow play / cast shadows=强化阴影本身
- **3 光固化模板**：每类场景存一组光影组合复用
