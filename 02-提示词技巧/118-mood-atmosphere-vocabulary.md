# 情绪氛围词汇库

## 核心要点
- 镜头光影给"形"，情绪词给"神"
- 一句提示词加 1-2 个情绪词即可——堆多=AI 抓不住
- 情绪词写法：`mood + 意境名词 + 具象细节`
- 张力片常用：eerie / ominous / tense / melancholic / haunting

## 常见坑
- **只写 mood 不写载体**："eerie" 没具象→AI 自由发挥
- **情绪词堆 5 个**：AI 抓不住主调→画面乱
- **用 "good/sad" 通用词**：识别差→用 eerie/melancholic 等精准词
- **情绪与光影冲突**：写 melancholic 又写 high key bright→矛盾
- **忘了具象细节**：没尘埃/雾/余烬→氛围落空

## 进阶
- **三词组法**：1 情绪 + 1 意境名词 + 1 具象细节
  - 例：`oppressive + cramped space + flickering light`
- **场景配情绪包**：每类场景固定 2-3 情绪词复用
- **情绪与光影协同**：eerie→冷蓝+闪烁；melancholic→暖橙+长阴影
- **叙事情绪弧**：build 用 ominous→peak 用 chaotic→release 用 somber
