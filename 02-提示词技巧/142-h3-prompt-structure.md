# H3提示词结构

## 核心要点
- H3官方推荐公式：**主体 + 动作 + 场景 + 运镜 + 光线 + 声音**
- 六要素按序组装=信息完整率最高的默认结构
- 每个要素写1-2个关键词即可——**要素齐全>单要素华丽**
- 2000字符上限，但前150字符权重最高
- 关联 111 提示词公式化结构、141 运镜指令

## 六要素详解

### 1. 主体（Who）
```
写什么：谁/什么 + 关键外观锚点
例："银发剑士，破损蓝外套"
原则：外观锚点选3个以内最强的（发色/服装/标志性道具）
```
- 主体是画面稳定性的锚——锚点越具体，AI越不漂移
- 关联 113 风格锁定（角色锚词复用）

### 2. 动作（What）
```
写什么：一个主动作 + 动作方式副词
例："缓缓拔刀，动作克制"
原则：单一动作原则——一个镜头一个主动作
```
- 动作幅度写清楚：slightly/gently/violently
- 关联 146 单一动作原则

### 3. 场景（Where）
```
写什么：环境 + 前景/背景层次
例："雨夜神社，前景鸟居虚化，背景松林"
原则：给前景层=画面深度免费+30%
```

### 4. 运镜（Camera）
```
写法：[指令]语法（见141）
例：[Push in]
原则：一个镜头一个主运镜，第二运镜标subtle
```

### 5. 光线（Light）
```
写什么：光源 + 光质 + 方向
例："月光从鸟居后方逆光，冷蓝色调"
原则：光线词同时锁定情绪（关联068/069光影）
```

### 6. 声音（Sound）
```
写什么：环境声/动作声（H3支持音频描述）
例："雨声渐强，远处雷鸣"
原则：声音描述影响画面氛围的生成倾向
```

## 组装模板

### 标准模板
```
[主体+外观] + [主动作+方式] + [场景+层次] + [运镜指令] + [光线] + [声音]
```

### 完整示例
```
"银发剑士，破损蓝外套，缓慢拔刀，动作克制，
 雨夜神社，前景鸟居虚化，背景松林 [Push in]，
 月光逆光，冷蓝色调，雨声渐强"
```

### 精简版（抽卡期快速验证）
```
"银发剑士雨夜拔刀 [Push in] 月光逆光"
```
- 要素骨架在，细节后补——先验证构图再丰富

## 要素权重与省略策略

### 必写（省略=翻车高危）
```
主体锚点、主动作、运镜指令
```

### 建议写（省略=质感降级）
```
光线、场景层次
```

### 可省（AI自动补全尚可）
```
声音、画质词（H3默认画质够用）
```

### 反面教材
```
"一个非常帅的剑士在很酷的地方做很帅的动作，电影感，8K"
= 主体无锚+动作不具体+场景空+运镜无+光线无
= 六缺五，全靠运气
```

## 节拍式长提示词（多动作镜头）

### 结构
```
主体 + 节拍1[指令] + 节拍2[指令] + 光线 + 声音
```

### 示例
```
"银发剑士站在鸟居下 [Static]，
 他抬手接住雨滴 [Push in]，
 远处传来脚步声，他猛然回头 [Pan right]，
 冷蓝月光，雨声与脚步交织"
```
- 主体光线声音只写一次（全局生效）
- 节拍间的动作有因果衔接（关联135）

## 中文vs英文提示词
```
H3对中文原生支持好（MiniMax国产模型）
中文优势：意境词/成语/武侠词汇
英文优势：电影术语更标准（tracking shot等）
策略：描述用中文，术语用中英皆可，混写不影响
```

## 常见坑
- **要素缺环**：只写画面不写运镜=AI随机运镜毁构图
- **主体锚点漂移**：多镜头时锚点词不复用=角色变脸（关联138）
- **动作超载**：一个镜头写"拔刀+挥砍+收刀+转身"=动作糊
- **光线缺位**：不写光=AI默认平光=画面平
- **形容词依赖**："很美很震撼"无信息量——写具体光源具体颜色

## 进阶
- **要素卡片库**：把常用六要素做成卡片（主体卡/光线卡/场景卡），组装式写提示词
- **权重前置**：最重要的信息放前150字符
- **反向要素**：不想要什么也写出来（"画面无其他人"）=简单负向（关联112）
- **要素检查清单**：写完数一遍六要素，缺啥补啥=3秒自检
