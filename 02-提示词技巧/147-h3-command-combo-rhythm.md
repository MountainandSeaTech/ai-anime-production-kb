# H3指令组合与镜头节奏

## 核心要点
- H3指令排列=镜头内部的"剪辑"：**同括号=并发，分括号=顺序**
- 一个5-10秒镜头内的指令编排=微缩版的张力曲线
- 指令数量与镜头时长匹配：**5秒≤2个指令，10秒≤4个指令**
- 关联 141 指令语法、023 切换频率

## 组合模式详解

### 模式1：纯顺序（A→B→C）
```
"角色走向窗边 [Push in]，望向远方 [Tilt up]"
= 推近完成后再上摇
气质：从容、叙事性、古典
```
- 每个运镜有完整执行时间=观众看得清每次运动

### 模式2：并发（A+B）
```
"气场爆发 [Orbit left, Push in]"
= 环绕同时推近
气质：炫技、高光、压缩感
```
- 并发制造"复合运动"=单镜头信息密度翻倍
- 上限3个；2个最稳

### 模式3：顺序+并发混合
```
"她低头 [Push in]，猛然抬头 [Tilt up, Shake]"
= 先推近酝酿，抬头瞬间摇+晃
气质：压抑后爆发
```
- 混合模式=指令级的"蓄力-爆发"（关联026）

## 节奏编排原则

### 指令与画面节拍对齐
```
写法：画面描述 [指令]，画面描述 [指令]
指令落在该节拍末尾=运镜发生在那一拍
```
- 指令不是全局生效——是节拍触发器

### 时长分配直觉
```
5秒镜头：
  1个指令=从容
  2个指令=标准
  3个指令=急促
10秒镜头：
  2-3个=标准
  4个=密集上限
```

### 静-动-静骨架（推荐默认）
```
"开场静 [Static]，中段动 [Push in]，收尾静 [Static]"
= 有起落=呼吸感
```
- 全程运动=观众无法消化=视觉疲劳
- 关联 030 停顿、136 呼吸

## 指令组合的情绪语义

### 经典组合表
| 组合 | 情绪 | 适用 |
|---|---|---|
| [Push in] | 逼近/专注 | 情绪收紧 |
| [Pull out] | 释然/孤独 | 收束/揭示 |
| [Orbit]+[Push in] | 高光/觉醒 | 主角时刻 |
| [Tilt up] | 敬畏/揭示 | 巨物/强者登场 |
| [Tilt down] | 坠落/衰败 | 败北/发现尸体 |
| [Truck]+人物同向 | 同行/陪伴 | 散步对话 |
| [Truck]+人物反向 | 错过/疏离 | 擦肩而过 |
| [Shake] | 混乱/临场 | 战斗/惊恐 |
| [Static] | 压抑/对峙 | 暴风雨前 |

## 模板示例（一场戏的指令编排）

### 场景：强者登场（8秒）
```
"烟尘弥漫的战场 [Static]，
 烟雾中浮现人影 [Push in]，
 人影抬头，眼神如刀 [Tilt up, Push in]，
 镜头环绕他周身气场 [Orbit left]"
```
- 静→推→推摇并发→环绕=张力四级递增
- 4节拍8秒=每拍2秒=从容的高光节奏

### 场景：日常温情（5秒）
```
"少女在窗边看书 [Static]，
 风吹动书页和她的发梢 [Slow push in]"
```
- 2指令5秒=舒缓
- 日常戏指令做减法

### 场景：战斗爆点（5秒）
```
"两人对冲 [Truck right]，
 刀剑相撞火花四溅 [Shake]，
 一人被震飞 [Pull out]"
```
- 3指令5秒=急促=战斗节奏
- Shake放在接触帧=爆点强化（关联059）

## 常见坑
- **指令通货膨胀**：10秒塞6个指令=每个都执行不充分=全程慌乱
- **并发超3**：[A,B,C,D]=指令互相打架=画面抽搐
- **节奏平**：5个指令均匀分布=无重点；应有密有疏
- **指令与描述脱节**：文字说"静静站立"指令给[Orbit]=矛盾
- **首尾无静帧**：开头就动结尾还动=镜头没有起落=切出去不自然

## 进阶
- **指令即分镜**：一个H3镜头内的指令序列=传统分镜的微缩版——写指令时想的是"这段戏的镜头内部剪辑点在哪"
- **静默帧插入**：两个动作节拍间插一个无指令节拍=呼吸停顿（关联136）
- **并发不对称**：[Push in, slight Pan left]——主运动+subtle辅助运动=层次（辅助运动用subtle修饰）
- **与剪辑接口**：镜头内部节奏要服务镜头间节奏（关联023/126）——内部密的镜头，外部给长时长

## 备注
- 同括号并发≤3，分括号顺序，指令落在节拍末
- 5秒≤2指令，10秒≤4指令
- 默认骨架：静-动-静
- 关联：141 指令语法、020 运镜情绪、023 切频、136 停顿
