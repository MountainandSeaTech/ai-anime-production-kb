# 技能魔法特效与提示词模板二十连⑱：特效合成后期管线

## 核心要点

- **AI视频特效后期六步管线**：AI主料生成 → AE/Blender补交互 → 色彩校正统一 → 颗粒统一质感 → 色差/镜头畸变统一镜头感 → 最终输出——少一步就"像AI生成的"
- **混合模式是合成的核心**：Screen（滤色）用于光效/能量/粒子叠加；Add（线性加深）用于光源/辉光；Multiply（正片叠底）用于阴影/烟雾；Overlay（叠加）用于中间调质感——选错模式=特效像贴纸
- **辉光三要素**：阈值（Threshold，多少亮度开始发光）+ 半径（Radius，发光范围）+ 强度（Intensity，发光强度）——AI生成的辉光常过曝，需后期压阈值
- **色差是镜头感的灵魂**：`chromatic aberration`模拟真实镜头色散，让AI生成的"干净画面"有"拍摄感"——与暗角/镜头畸变组合使用
- **颗粒统一质感**：AI各镜头颗粒度不一致是最大穿帮；后期统一加film grain（Film模式，暗部影响大）让全片质感统一

## 详细内容

### 一、AI视频特效后期六步管线

```
STEP 1 - AI主料生成：
  → 用378-393的提示词模板生成特效镜头
  → 输出：带特效的视频片段（但无交互、无统一色调）

STEP 2 - AE/Blender补交互：
  → 补：特效与人物的接触面（阴影/反光/位移）
  → 补：特效与环境的交互（光照/遮挡/粒子）
  → 补：跨镜头一致性（特效位置/大小/颜色）

STEP 3 - 色彩校正统一：
  → 统一色温（全片暖调/冷调）
  → 统一对比度（全片对比一致）
  → 统一饱和度（全片饱和度一致）

STEP 4 - 颗粒统一质感：
  → 加film grain（Film模式）
  → 颗粒大小：匹配目标胶片（35mm/16mm/8mm）
  → 颗粒强度：统一全片

STEP 5 - 色差/镜头畸变：
  → 加chromatic aberration（边缘色散）
  → 加vignette（暗角）
  → 加lens distortion（镜头畸变）

STEP 6 - 最终输出：
  → 统一分辨率/帧率/编码
  → 输出最终成片
```

### 二、混合模式选择表

| 混合模式 | 数学原理 | 效果 | 适用场景 |
|---|---|---|---|
| **Screen** | 1-(1-a)(1-b) | 永远更亮 | 光效、能量、粒子、光斑 |
| **Add** | a+b | 最亮，可能过曝 | 光源、辉光、爆炸核心 |
| **Multiply** | a×b | 永远更暗 | 阴影、烟雾、暗角 |
| **Overlay** | 高光Screen+阴影Multiply | 中间调全应用 | 纹理、质感、中间调 |
| **Soft Light** | 柔和Overlay | 轻微提亮/压暗 |  subtle 光影调整 |
| **Lighten** | max(a,b) | 取较亮者 | 光效、高光 |
| **Darken** | min(a,b) | 取较暗者 | 阴影、暗部 |

**记忆口诀**：光用Screen，源用Add，影用Multiply，质感用Overlay。

### 三、辉光三要素控制

```
THRESHOLD（阈值）：
  → 0% = 全图发光（廉价页游）
  → 30% = 只有高亮发光（电影感）
  → 50% = 只有极亮发光（神圣感）
  → AI生成常过曝（阈值太低），后期需压到30-50%

RADIUS（半径）：
  → 小半径 = 锐利辉光（能量束）
  → 中半径 = 柔和辉光（魔法光）
  → 大半径 = 弥漫辉光（环境光）

INTENSITY（强度）：
  → 低强度 = 微弱发光（余烬）
  → 中强度 = 明显发光（法术）
  → 高强度 = 强烈发光（爆炸）
```

### 四、色差与镜头感组合

```
chromatic aberration（色差）：
  → 边缘色散：红/青边缘偏移
  → 强度：0.5-2px（ subtle ）到 5-10px（风格化）
  → 适用：科幻、奇幻、梦境、记忆

vignette（暗角）：
  → 边缘压暗，聚焦中心
  → 强度：0.2-0.5
  → 适用：特写、情绪镜头

lens distortion（镜头畸变）：
  → 桶形畸变（广角）/ 枕形畸变（长焦）
  → 适用：匹配实拍镜头感

组合公式：
  → 电影感 = chromatic aberration(1px) + vignette(0.3) + film grain(35mm)
  → 科幻感 = chromatic aberration(3px) + vignette(0.2) + 轻微lens distortion
  → 梦境感 = chromatic aberration(5px) + vignette(0.5) + 强film grain
```

### 五、常见翻车与修复

| 翻车 | 原因 | 修复 |
|---|---|---|
| 特效像贴纸 | 混合模式错 | 光效改Screen/Add |
| 全片颗粒不一 | AI各镜头颗粒不同 | 统一加film grain |
| 画面太干净 | 无镜头感 | 补色差+暗角 |
| 辉光过曝 | 阈值太低 | 压阈值到30-50% |
| 色调不统一 | 各镜头色温不同 | 统一色彩校正 |

  □ 特效与人物接触面已补（阴影/反光）

  □ 颗粒强度全片统一

  □ chromatic aberration已添加（1-3px）
