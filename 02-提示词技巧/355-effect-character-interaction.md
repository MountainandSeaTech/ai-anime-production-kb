# AI视频特效十连⑧：特效×人物环境交互

## 核心要点

- **贴片感的终点答案：接触科学**。特效与角色同框时，逐条检查六种接触面——光面、身体、衣发、地面、道具、空气；缺一种就假一分
- **特效镜头里身份与特效是双任务**：角色实体（343体系）照挂，特效另写；I2V关键帧里把"交互结果"先画对（脸上的光、湿的衣、掀的袍），视频只负责让它动
- **手持能量三细节**：光从指缝漏出＋手指边缘透光（subsurface）＋电弧连到指尖；手臂要有受力姿态（托举感/肌肉紧绷/后退半步），能量是有重量的
- **变身/变形必须显式写中间态**：模型没有"变成"的物理模型，不写就硬切——沿哪个方向扩散、皮肤下先隆起什么、从脸开始还是从手开始
- **分区控制工具**：运动笔刷（Motion Brush）只让指定区域动——发丝、水面、火星局部运动而人稳；首末帧插值定义变身两端

## 详细内容

### 一、六接触面检查表（每个"人＋特效"镜头逐条过）

1. **光面（最重要）**
   - 特效当主光源：方向、颜色、闪烁节律写清（fire底光/闪电惨白顶光/能量蓝侧光）
   - 眼睛catchlight：瞳孔里有特效的光点——特写时可信度翻倍
   - 光包裹（light wrap）：人物轮廓边缘被特效色勾边，前后景分层
   - 耳部/手指等薄处透光（subsurface微红/橙）
2. **身体反应**：烫→眯脸缩手；冲击→衣发先动、身体滞后半拍；冷→缩肩呵手；巨响→震得偏头
3. **衣发**：冲击波方向掀袍（写明向哪掀）；火星烧小洞/边缘焦；雨湿后**变重贴形**；霜挂在毛领睫毛
4. **地面**：脚下尘环、积水涟漪、裂缝、特效投在地上的彩色反光、本人的接触阴影不能丢
5. **道具**：武器被照亮/震脱手/升温发红/覆霜——道具是交互的中继站
6. **空气**：呼吸白气、热浪、尘粒、被推开的雾（352）

### 三、手持能量/施法镜头（武侠奇幻最高发）

**手掌端写法**：
```
蓝白能量球在掌心上方旋转，光从指缝间漏出，手指与手掌边缘透出红蓝光，
细小电弧从球面跳上指尖；他整条手臂微沉像托着实物，肩背绷紧，
冷蓝光在他脸下半部明灭跳动，脚下尘粒被气流推成一圈。
```
三件套：①指缝/边缘透光 ②电弧或粒子连指 ③手臂受力（托举重量感）。
**施法全身端**：衣袍与发丝被能量场吸向手/从手向外吹（二选一固定）、脚下尘环、目光跟能量走。
**收发节拍**：蓄力（光弱、手抖、环境粒子开始向心）→释放（爆发、衣发猛甩、光爆打脸）→余韵（掌烟、踉跄、残光从指间熄）——对接291蓄-爆-延-反、274收发力学。

### 四、变身/变形（Morphing）

- **显式中间态**：镜中倒影变狼——"ripples in the reflection, fur pushing through where skin was, the transformation moving from the face outward（涟漪、毛从皮肤下顶出、从脸向外扩散）"
- 给扩散方向与顺序（手→臂→躯干／脊柱隆起→全身），给过渡材质（皮肤下的光纹/鳞片/岩甲浮现）
- 用**首末帧插值**锁两端：起始帧人形、结束帧兽形，模型补间流体morph，身份与兽形都可控
- 超过单条时长：末帧续接（348时间锚），两到三段接力慢变
- 变身后第一镜必须给"新形态＋旧标识"同框确认（眼神/饰物/伤疤），观众才认得出还是他

### 五、I2V交互工作流（首选）

1. 图像模型出关键帧：**交互结果直接在静帧里做对**——脸上的色光、打湿的衣、脚下尘、手持光的指缝透光
2. 运动笔刷分区：人（静/小动）、火焰区（闪动）、火星区（上升）、袍发区（飘）各涂各的；笔刷外保持稳定
3. 角色/脸参考照挂（多图参考可1-7张），身份与特效分轨
4. 多pass分工：pass1人稳特效弱、pass2特效好脸漂→优先保人，特效弱的版本后期加光/glow补（356）；反之不保
5. 运镜参数化：六轴[-10,10]，特效戏运镜幅度压低，把运动预算留给特效本身

### 六、用分镜设计回避交互难题

- **逆光剪影法**：人物在火/光前成剪影——交互只需轮廓光，脸的身份与光的复杂反射全部绕开，且最出气势（对接344 C级、331暗场轮廓光）
- **反应代替展示**：能量/怪物本体难画就画打在人身上的光和人的反应（347反应镜头），观众脑补更强
- **短接触**：手触火球、剑撞电光的同框≤1-2秒，前后用特写与反应镜接
- **遮挡切**：交互在柱后/烟中/镜头甩动中发生，重现时给结果（与346遮挡纪律一致）

### 七、交互镜头QC（除348三问外追加）

- 特效光在人物眼/脸/轮廓上吗？方向对吗？
- 衣发运动方向与特效力方向一致吗？
- 湿/烧/霜的"持续后果"还在吗（下场镜头不能干回来/复原，对接138状态连续性）？
- 手持物有重量感吗（手臂受力）？
- 变身给了中间态吗？变身后认得出吗？
- 人物接触阴影/脚下反应还在吗？

## 关键参数 / 模板 / 清单

**人＋特效镜头提示公式（Kling式扩展）**
```
主体(细节)：角色实体＋服装状态(干/湿/烧/霜)
特效：物理属性(粒子/色/重量)＋运动力学(gravity-affected/wind-blown)
交互六面：打脸光[方向色闪烁]/眼点光/衣发[方向]/手[受力]/地[尘影水]/道具/空气
场景与光：Tyndall体积光、雾、光比
电影语言：景别/运镜(低幅度)/慢镜
```
