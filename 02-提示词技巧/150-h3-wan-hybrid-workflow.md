# H3+Wan混合工作流

## 核心要点
- 单模型打全场=浪费；**按镜头类型分派模型**=性价比与质量双赢
- 全链路五阶段：**原型→分派→精做→缝合→QA**
- 本条是H3/Wan专题（141-149）的总装线
- 关联 145 选型、148 Shot原型、140 自检清单

## 五阶段管线

### 阶段1：剧本与分镜表
```
产出物：分镜表（含锚点列）
必填列：镜号|内容|入口状态|出口状态|运镜|情绪|镜头类型
```
- 镜头类型列决定阶段2的模型分派
- 关联 135 因果链、138 分镜表锚点

### 阶段2：Shot原型验证（Wan 3.0）
```
把整场戏写成Wan Shot格式 → 一次生成 → 验证：
  - 节奏对不对（Shot时长分配）
  - 叙事通不通（因果链）
  - 情绪曲线对不对
```
- 原型是草稿——画质不重要，**结构验证**重要
- 结构不对=改分镜表，别急着精做

### 阶段3：镜头分派与精做
```
分派规则（145）：
  人物特写/微表情戏 → H3（[指令]精确控镜）
  大场面/物理特效 → Wan
  需要首尾帧精密控制 → Wan
  精确复合运镜高光镜 → H3
```

### 精做单元规范
```
每个镜头交付：
  1. 模型语法适配后的完整提示词
  2. 首帧图/尾帧图（需要接力时）
  3. 3次抽卡的最好结果
  4. 翻车记录（149速查）
```

### 阶段4：音画缝合 + WAN3 原生音画省后期（2026-10-20 重排）
```
旧流程（保留参考）：
  1. 首尾帧接力处对齐动作相位（132）
  2. 音轨错位（J/L-cut，137）
  3. 统一调色（双模型色差校正）
  4. 补帧/调速（9帧率异常补救）

WAN3.0 原生音画后**可省掉的环节**：
  ✓ BGM 配乐——WAN3 原生生成（质量：够用/预览级）
  ✓ 音效叠加——WAN3 原生生成（质量：够用/氛围级）
  ✗ 对话配音——WAN3 原生生成（质量：尚可/嘴型有时对不上）
  ⚠ 最终精配——如果要上成片，后期精配 BGM/音效仍建议做

新流程（推荐）：
  1. 先出 WAN3 原生音画版本 → 听一遍哪些地方要精修
  2. 视频缝合：首尾帧对齐动作相位 + 统一调色 + 补帧
  3. 音频精修：只精修 WAN3 没做好的部分（替换整段 BGM / 修补关键音效时机）
  4. 节省：原生音画省掉了 60-80% 的后期音频工作量
```

### 阶段5：连贯性QA
```
跑140清单两轮：
  分镜表预检（应该已过）→ 素材画面复查
重点项：视线方向/状态延续/光线一致/音桥
```

### 阶段6：本地编辑 QA 修复（WAN3.0 独有，2026-10-20 新增）
```
发现问题 → 定位时间段 → 改提示词 → 局部替换：

典型修复场景：
□ 某 Shot 人物变脸 → 选中该 3-5s 段 → 加角色锚词 → 替换
□ 后 10s 场景漂移 → 选中漂移段 → 加场景参考图 → 替换
□ 某 Shot 动作没做出来 → 选中该段 → 简化动作（单一动作铁律）→ 替换
□ 音画时机错位 → 只改 Audio 行 → 替换（视频不变）
□ 整体没问题但某 2-3s 瑕疵 → 精准选段 → 最小改动 → 替换

本地编辑 vs 整条重生：
  重生整条 30s → 成本 ¥36、时间 5-10min、漂移风险高
  本地编辑 3-5s → 成本 ¥0.3-0.6、时间 30-60s、不影响其余部分
```

## 双模型协同的分派实例

### 场景：雨夜复仇（8镜头）
```
镜1 远景雨夜神社（氛围建立）→ Wan（场景质感）
镜2 主角面部特写（隐忍）→ H3（微表情）
镜3 拔刀手部特写 → H3（[Push in]精确控制）
镜4 雨水飞溅慢镜 → Wan（水物理）
镜5 对决全景 → Wan（大场面）
镜6 眼神对峙双特写 → H3（人物表演）
镜7 决胜一刀速度感 → H3（[Shake]手持冲击）
镜8 战后空镜雨停 → Wan（氛围收束）
```
- 人物戏4镜给H3，氛围/物理4镜给Wan
- 交替排列时靠风格词统一（113）

## 统一性保障（双模型混剪的核心风险）

### 风险：两个模型画风不一致
```
对策1：风格词逐镜复写且双模型用同一套词
对策2：统一首帧图源——同一张风格参考图喂两边
对策3：后期统一调色+统一颗粒/锐度
对策4：交替节奏设计——ABAB交替太密易穿帮，
        按"段落"分派（文戏段H3/动作段Wan）更隐蔽
```

### 风险：角色一致性问题
```
对策：角色参考图双模型通用
  - 同一套角色设定图分别喂H3/Wan
  - 关键角色做LoRA（如工作流支持）
  - 远景/背影/剪影镜头安排在模型切换处（面部不出镜=降低穿帮）
```

## 常见坑
- **原型阶段抠画质**：Shot原型是验结构的，别浪费抽卡次数
- **分派凭感觉**：不写镜头类型列=分派混乱=风格穿帮
- **跨模型接力**：H3的尾帧直接喂Wan=风格跳变；接力尽量同模型内
- **缝合才想统一**：调色/颗粒要在剪辑前有预设，不是事后补
- **QA走过场**：赶工时跳过140清单=观众替你检查

## 进阶
- **模型库扩展**：管线是模型无关的——新模型（可灵/Vidu/Sora）加进分派规则即可
- **段落级分派表**：按"幕"分派模型（一幕内同模型）=最隐蔽的混合
- **预算看板**：H3/Wan各自单价×镜头数=成本预估，文戏多就多排H3
- **管线模板化**：本条工作流存为模板，新短剧项目复制即用
