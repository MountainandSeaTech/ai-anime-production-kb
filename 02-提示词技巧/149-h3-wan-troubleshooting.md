# H3/Wan避坑速查

## 核心要点
- 翻车排查顺序：**语法层→语义层→结构层→运气层**
- 大部分"模型不行"其实是提示词有坑
- 同一提示词至少抽3次再下结论（单抽样本不可信）
- 关联 120 调试避坑、112 负向提示词

## 避坑条目标准格式（5 段式）

> 本库所有"避坑/翻车/排查"类条目统一按此 5 段式组织；本条目为范本。

1. **现象**：一句可复述的翻车描述（用户会怎么抱怨）
2. **根因**：为什么会这样（模型层／提示词层／流程层）
3. **错误 vs 正确示例**：反面写法 → 正面写法，给可直接抄的对照
4. **后果量化**：不修的代价（废片率／重生成次数／成本）
5. **修法清单**：可直接执行的检查项（□ 列表）

## 四层排查法

### 第1层：语法层（10秒查完）
```
□ 模型语法用对了吗？（H3用[指令]，Wan用自然语言）
□ 括号闭合/拼写正确？
□ 时间码格式对？（Wan Shot格式）
□ 提示词超长度上限？（H3约2000字符）
```

### 第2层：语义层（30秒查完）
```
□ 主动作超过1个？（146铁律）
□ 动作幅度写了吗？
□ 有矛盾指令吗？（"静止"配[Orbit]）
□ 形容词是物理事实还是评价？（评价=删）
```

### 第3层：结构层（1分钟查完）
```
□ 主体锚点给了吗？（发色/服装/道具3锚）
□ 运镜指令与画面描述匹配吗？
□ 多镜头时状态词复写了吗？
□ 首尾帧差异≤2种？（图生视频）
```

### 第4层：运气层
```
以上全对仍崩 = 换种子重抽（3次）
仍崩 = 简化提示词（砍一半描述）重试
仍崩 = 换等价写法/换模型（145选型）
```

## 高频翻车对症表

### 1. 脸崩/变脸
```
症状：人物面部扭曲/多镜头间换人
处方：
  - 加面部锚词（"sharp eyes, small scar on cheek"）
  - 脸占画面比例别太小（<1/8画面=必崩）
  - 特写镜头用[Static]或微运镜
  - 多镜头：每镜复写面部锚词
```

### 2. 手部崩坏
```
症状：六指/融指/手穿模
处方：
  - 手部动作写简单（"握拳"比"结印"安全）
  - 手部特写镜头给[Static]
  - 拿武器写"握住刀柄"（grip firmly）减少手指自由度
  - 终极方案：构图让手在画面边缘/被遮挡
```

### 3. 乱动（运镜失控）
```
症状：没要运镜却狂晃/乱甩
处方：
  - 显式写[Static]（H3）/ "camera locked, static shot"（Wan）
  - 删提示词里的暗示词（"环顾""追逐"会引发AI加运镜）
  - 运镜只写一个主指令
```

### 4. 主体漂移（中途变形）
```
症状：前2秒正常，后面衣服/发型变了
处方：
  - 缩短单镜时长（5秒内漂移少）
  - 减少画面内运动总量
  - 首尾帧双锚（144）
  - 长镜头拆成两段接力（138）
```

### 5. 动作做不完
```
症状：提示词写"拔刀挥砍收刀"，只做了拔刀
处方：
  - 单一动作铁律（146）——拆镜头
  - 或按时长拆：动作数量×2秒≤镜头时长
```

### 6. 场景串味
```
症状：写着神社，生成了教堂元素混入
处方：
  - 场景词加限定（"Japanese Shinto shrine, wooden, no windows"）
  - 负向词排除（Wan/SD系；H3用正面限定代替）
  - 参考图锁定场景（119）
```

### 7. 画风不统一（多镜头间）
```
症状：镜1动漫风，镜2写实风
处方：
  - 风格词放每镜开头且逐字复用（113风格锁定）
  - 种子固定（如平台支持）
  - 参考图统一风格源
```

### 8. 文字/字幕乱入
```
症状：画面出现乱码文字/水印感
处方：
  - 负向词："no text, no watermark, no subtitles"
  - 避免场景词触发（"街景招牌"容易带文字）
```

### 9. 帧率感异常
```
症状：动作卡顿/果冻感/加速鬼畜
处方：
  - 运动幅度降档（violently→swiftly）
  - 时长加长（给动作充分时间）
  - 后期补帧工具兜底（Topaz/RIFE）
```

### 10. 音画错位（有声模型）
```
症状：音效与画面对不上
处方：
  - 音频描述里写明时机（"at the moment of impact, a clang"）
  - 或静音生成+后期配音（137/151-160专题）
```

### 11. WAN3 特有：30s 长段后段漂移（2026-10-20 新增）
```
症状：前 15s 正常，后 15s 人物变脸/场景串味/道具消失
原因：模型注意力随时间衰减，长段信息过载
处方：
  - 逐 Shot 重写锚词（不要偷懒写 "he"）
  - 多模态参考堆叠：3-5 角色图 + 2-3 场景图 + 2-3 风格图
  - 分段策略：20s 以上考虑拆成两段接力（15s+15s）
  - 首选 WAN3 本地编辑：选中漂移段→改锚词→局部替换（比整条重生快 60%）
  - 实在不行：放弃 Shot 格式，逐镜独立生成
```

### 12. WAN3 特有：多模态参考冲突（2026-10-20 新增）
```
症状：喂了 10 张参考图，模型反而乱了——角色同时出现两版脸/场景混搭
原因：参考图质量差（分辨率不一致/风格差异大/混入无关内容）或优先级没设对
处方：
  - 角色图只放**同一角色**不同姿态，不能混入其他角色
  - 参考图分辨率 ≥720P，同类型风格统一
  - 参考排序：角色图 > 场景图 > 风格图 > 视频 > 音频
  - 视频参考 ≤5s/个（长了模型只取前 3s，后面无效）
  - 冲突检测：喂参考前先肉眼过一遍，删掉可能混淆的
```

### 13. WAN3 特有：原生音画对不上（2026-10-20 新增）
```
症状：WAN3 原生音画生成后，音效时机/音量/风格与画面预期不符
原因：音频描述太笼统（"sound effects" vs "sword clash at 12s mark"）
处方：
  - 音频描述写明时机和强度（"soft ambient rain, then sudden metal clash at impact moment"）
  - 每个 Shot 都写音频锚（不要只写第一个 Shot）
  - 音量/情绪词显式给（"quiet 0-5s / loud 10-12s"）
  - 如果 WAN3 原生音频实在不理想：静音生成 + 后期精配（效果更好但多一环节）
  - 本地编辑只改音频行：选中 Shot→改 Audio 描述→局部替换
```

## 抽卡纪律

### 预算分配
```
验证构图：精简提示词×2次
精修单镜：完整提示词×3-5次
仍不行：改写法而不是硬抽
```
- 硬抽超过5次=提示词有问题，不是运气问题

### 日志习惯
```
记录：提示词版本 + 种子 + 翻车类型 + 修法
= 个人翻车库（关联120）
```

## 常见坑（元层面）
- **一次改多个变量**：改提示词又换种子=不知道哪个生效
- **越改越长**：翻车就加词=提示词膨胀=权重稀释=更翻车；应该先砍
- **忽视平台差异**：同一模型在官网vs聚合站参数可能不同
- **拿单抽当结论**："这个模型不行"可能只是那一次种子差

## 进阶
- **最小复现**：翻车镜头砍到只剩主体+动作+运镜三要素测试=定位问题词
- **词敏感度测试**：逐个删词重生成=找到引发崩坏的那个词
- **建立替换词库**："奔跑"崩→试"sprints/dashes/rushes"=同义词响应差异很大
- **翻车分类统计**：自己的翻车70%集中在某类=针对性加固该类提示词

## 备注
- 排查顺序：语法→语义→结构→运气
- 单抽不可信，3抽再结论
- 翻车先砍词，不是加词
- 关联：120 调试避坑、112 负向词、146 铁律、144 首尾帧
