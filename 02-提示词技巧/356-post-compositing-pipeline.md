# AI视频特效十连⑨：后期合成路线

## 核心要点

- **何时放弃直出转合成**：时机必须精确（304帧级同步）／特效与身份难两全／同元素多镜复用／水与大体量破坏（350/353低天花板门类）——这四类不要和概率较劲
- **AI负责两件半成品**：①无特效的人物表演底板（身份锁343体系）②黑/灰底前的特效元素板；合起来在AE/Resolve Fusion完成——时机、强度、颜色全部回到人类手里
- **混合模式是合成的语法**：火/火星/能量/glow→Screen或Add；黑烟/阴影→Multiply；染色→Overlay/Soft Light；实体碎片→Normal
- **"交互"在合成里是可伪造的**：脸上的闪烁光＝一层彩色光层Overlay＋随机透明度；脚下阴影＝模糊黑形Multiply；光包裹＝边缘溢色。底板干净这些全可后期补——这是"保人轻特效"多pass策略成立的前提

## 详细内容

### 一、三条路线决策表

| 路线 | 适用 | 代价 |
|---|---|---|
| A 整条直出 | 远景、氛围、过场特效；交互光不复杂的镜 | 低，接受抽卡 |
| B AI底板+AI元素合成 | 主角英雄镜、施法、爆炸反应 | 中，主流方案 |
| C AI底板+素材库元素合成 | 火/雨/玻璃等要求精确的高频特效 | 中，元素可控度最高 |
| D 交给专业VFX | 精确流体、全CG大破坏 | 高，预算镜 |

默认80/20：八成镜头A，两成关键镜B/C。

### 二、元素板（Element Plate）生成规范

用AI单独生成特效素材时：
- **火/火星/能量/光系**：纯黑背景前生成——黑底直接走Screen/Add，黑自动透明；主体居中、留足余量
- **烟/尘/雾系**：深灰/黑底＋逆光，后期用亮度键（Luma Key）/Unmult提取；或生成在中性渐变上
- **雨雪**：暗背景板用Screen，或直接买现成素材库（速度/密度可调）
- **实体碎片**：需要alpha就用绿幕/灰底生成再Keylight；AI抠绿边缘需溢色抑制
- 元素板一律**高帧率/升格生成**（慢动作素材），后期可任意加速不可补帧
- 每元素多生成几种密度/方向备用，命名存档（同343正典资产纪律：特效也要资产库）

### 三、合成标准管线（AE为例）

1. **底板准备**：AI人物表演条定剪；分析镜头运动（手持/锁定）
2. **跟踪**：锁定机位直接放；有运镜→Track Motion（2D，贴招牌/符纸）或3D Camera Tracker（解算机位，元素落在地面/墙面）
3. **遮罩分离**：元素要在人物身后穿过→Roto Brush 2框选人物（首帧涂抹，自动传播；发丝指尖逐帧用减法笔修）
4. **放元素**：火/光Add+Deep Glow；烟Normal+亮度键调密度；实体Normal带投影
5. **交互光伪造**（最关键一步）：
   - 脸/身受光：在人物上层加调整光，固态层取特效色，Overlay/Soft Light，遮罩刷在受光区，透明度随特效闪烁打关键帧（火10-15Hz随机、雷瞬时满闪）
   - 光包裹：人物边缘窄幅溢色
   - 眼睛catchlight：极小白色/彩色点
6. **接触阴影**：Multiply模糊形，贴脚/特效与地面交接处
7. **遮挡与纵深**：前景加烟/尘/火星层（Screen，虚焦），元素瞬间有前后景
8. **统一调色**：Lumetri采样底板黑白场白平衡；Match Grain加同款颗粒（项目轻胶片颗粒口径）；匹配镜头畸变
9. **发光收尾**：Deep Glow只给最热区，阈值调高防满屏雾光（防354廉价病）
10. **渲染**：ProRes 422 HQ剪辑用；多通道（beauty/alpha/depth）便于调色返工

### 四、以假乱真七项核对

| 项 | 要点 |
|---|---|
| 光向 | 元素主光方向必须与底板一致（钟面法，354） |
| 色 | 特效色污染环境，冷暖与场景统一 |
| 闪烁同步 | 脸光/环境光的闪烁与火球脉动同帧（304帧级） |
| 影 | 特效投出的影子方向、硬度对 |
| 颗粒/画质 | 元素与底板同颗粒、同锐度、同镜头畸变 |
| 尺度运动 | 元素透视与机位运动匹配（3D tracker解算） |
| 时机 | 声画与冲击帧对齐，光爆可精确到帧 |

穿帮排行：①无交互光（元素像贴图）②无颗粒（元素过干净）③光向相反 ④边缘硬无包裹 ⑤阴影缺席。

### 五、声音与时机

- 合成时间线给了帧级时机：与304声画对位、306冲击帧四步管线（定位→静帧→插入→同步）直接合流
- 元素可以自由retime：蓄力拖长、命中压两帧、余响渐隐
- 爆点对齐剪辑重拍/鼓点（330节拍剪辑同方法）

### 六、删除与修补（AI镜头善后）

- 底板里多出来的穿帮物（浮渣、多余火星、歪武器）：Runway类inpainting/遮罩重绘去除
- 局部加特效：视频inpainting在手上加光，不必整条重roll
- 对话类对口型：平台lip-sync功能补
- 原则：**能点修不重roll，重roll一次身份成本全丢**（对接248/249批次经济学）

### 七、工具与能力分工

- AE：Roto Brush 2（AI roto）、Keylight、3D Camera Tracker、Deep Glow插件、Lumetri、Match Grain——综合最快
- Resolve Fusion：节点合成，调色一体化，Wan/H3片在Resolve里走完音画（246/247混音链）可一站
- Nuke：复杂多层英雄镜（团队预算时）
- 元素素材库：商用火焰/火花/雨雪/玻璃素材仍是命中率最高的C路线原料
- 3D文字/全息/符阵：3D tracker解算后直接AE三维层贴地，比AI直出稳十倍（354全息）
