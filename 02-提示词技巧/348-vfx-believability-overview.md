# AI视频特效十连①：特效可信度总纲

## 核心要点

- **先纠正概念**：传统VFX是合成到素材上的图层（有遮罩、可逐帧调时、烟可以单独重做）；文/图生视频模型**一次出片、特效烤进每个像素**，没有图层、没有遮罩、爆炸想晚两帧只能整条重roll——结构上它更像一条不可调的实拍take
- **特效假＝贴纸感，根源只有一个：交互缺失**。特效自身画得多细都没用，必须让周围世界"承认它存在"
- **可信度三杠杆**：①交互（光溢到最近表面、碎片服从重力、烟被运动物排开）②尺度词（模型对大小重量没有ground truth，"车门大的钢板"和"碎片"落法不同）③摄影机反应（受惊后退、曝光打爆半拍再恢复、冲击手持震动）
- **三条合法用途**：整条特效驱动镜头／廉价预演previs／生成元素素材（火星、烟板、全息）拖进剪辑软件当一层——第三条最接近传统VFX

## 详细内容

### 一、AI-VFX vs 传统VFX：能力边界

| 能做 | 不能做 |
|---|---|
| 从零生成整条以特效为核心的镜头 | 把特效"加到"已有视频上（无遮罩/跟踪/键控） |
| 出预演：方向、时机、氛围 | 生成后逐帧调特效时机（只能重roll整条） |
| 出元素素材（简单背景前的烟/火星/闪光）供合成 | 烟pass单独重来而保住演员表演 |

**决策含义**：凡"特效时机/位置/形状必须交付级精确"的镜头，走第三条路（生成元素→AE/Resolve合成）或换专业工具，不要指望把句子写得更好——详见356。

### 二、可信度公式：特效三问（每条特效镜头必答）

1. **它碰了什么？**（Interaction）
   - 火/光：光必须溢到最近的墙、脸、地面，写颜色、方向、闪烁
   - 碎：服从重力，低散射、落地、停住，不许悬在画面里
   - 烟/尘：被穿过它的人/车/气浪排开，而不是物体经过它不动
   - 水：打湿、反光、退水带走泡沫杂物（350专讲）
2. **它多大、多重？**（Scale cue）
   - 模型无尺度真值：写"boulder-sized巨石大小的碎块""车门大的钢板""拳头大的火星团"
   - 材质也要点名：石膏板块和钢梁绝不能以同样方式落（353）
3. **摄影机怎么反应？**（Camera reacts）
   - 爆炸：后退半步、whip-pan甩开、冲击手持震
   - 强光：曝光打爆半拍再恢复、短暂镜头光晕
   - 原理：一台"仿佛特效真在那里"的摄影机，比给特效本身多加三个形容词更能卖信

### 三、"描述结果，不描述源"原则

- 不写"有一团火"，写"跳动的橙光把长影子甩在砖墙和木箱上"——模型对**光照结果**的响应远好于对光源名词
- 魔法光同理：不写"能量球很亮"，写"冷蓝光在他脸和衣服上明灭跳动，空气中的微尘被照亮"
- 这条贯穿十连，是所有发光类特效（349火/351雷/354光）的统一笔法

### 四、给模型"现在"的时间锚

模型对"几秒后起火"没有内在时间感：
- 用节拍语言：ignition lands on the beat（点火落在某拍）、"在他转身的瞬间引爆"
- Seedance类支持整数秒时间戳的模型可直接指定第几秒；只认镜号的就用镜头语法重写
- 跨条慢变化（变身/融化）：用上一条末帧续接（return_last_frame / generation_id续生），不要让一条承担全程（详见355变身）

### 五、特效门类天花板排序（2026消费级模型实测口径）

- **高（prompt可修）**：烟/雾/体积感、魔法/能量光（无封闭预设，等于自由描述光色交互）、火、光效
- **中（要技巧）**：爆炸（交互全写上才不假）、闪电（必须给起止点，351）、雨雪雾天气（分层描述，352）、破碎（材质重量词，353）、粒子火星（给轨迹）
- **最低**：液体/流体——底层无流体模拟，倒一杯水可能末帧体积对不上，浪会中途增减质量；交付级精确水镜头直接换工具/实拍元素合成
- 注意平台特例：Pika Pikaffects是**封闭枚举**（62个图像特效/9个视频特效），只能选名不能描述；Grok Imagine无负向/无seed/无风格预设，一切约束只能正面陈述

### 六、与既有特效条目的分工

- 276 降龙掌特效双方案：武侠掌力"龙形气劲vs写实掌风"的风格口径
- 281 无形气刃：无形攻击靠介质显影（本连③交互原则的武侠特化）
- 290 真气显形L1-L4：全剧特效显形分级与"高级vs廉价"四特征
- 307 写实边界：冲击帧等动画感元素如何在真人写实风里改造
- 本十连348-357：**通用特效工艺**（火/水/雷/风/碎/光/交互/合成/叙事），武侠与巨兽项目共用

### 七、本项目映射

- 《天龙八部》：六脉神剑（351光束）、火焰刀（349+351）、降龙掌浪（350空气/349光）按276/281/290口径调用本条工艺
- 《海裂》：深渊之核静默领域（352气体/354光的反向用法——光被吞噬）、频率共振特效（354能量光+352空气涟漪）、巨兽攻城破坏（353破碎+349尘爆）

## 关键参数 / 模板 / 清单

**特效镜头万能提示骨架**
```
[场景与机位]，[特效源：什么/尺度多大/材质]，
[结果交互1：光溢到哪里、什么颜色、怎么闪]，
[结果交互2：碰到的物体如何反应（碎落/湿/排开/被掀）]，
[粒子/余波：火星轨迹、烟、热浪的去向]，
[摄影机反应：震/退/曝光/慢镜]，
[时间锚：在什么动作/第几秒发生]
```

**特效镜头QC三问**：缩略图看——周围有承认它吗？｜尺度重量像吗？｜摄影机活在现场吗？三个"没有"＝贴纸，重写而非重抽。
