# 风格锁定（--sref / --cref / 参考图）

## 核心要点
- AI 出图最大痛点：**张张不一样**——风格飘、角色变脸
- 解法：用参考图强制对齐——`--sref` 锁风格，`--cref` 锁角色
- 两者分工：sref 管"色/质/光"，cref 管"脸/发/衣"
- 全片统一=同 sref + 同 cref + 同风格词
- 别让一个参数干两份活——分工才稳

## --sref 风格参考（MJ）

### 用法
```
/imagine prompt: [正向词] --sref [image URL] --sw 200
```
- `--sref [url]`：引用一张图的**风格**（色/质/构图氛围/光）
- `--sw 0-1000`：风格权重，默认 100，越高越像参考
- 也可用 `--sref random` 随机抽风格

### 什么时候用 --sref
- 全片色调统一（冷蓝赛博/暖橙黄昏/水墨黑白）
- 复刻某画师画风（不直接写画师名=更稳）
- 锁定某种质感（胶片颗粒/油画/水墨）

### sref 强度档
```
--sw 0      关闭
--sw 100    默认（轻度影响）
--sw 200    推荐（明显但不过）
--sw 400    强（色彩构图都跟着参考走）
--sw 1000   极强（几乎复制参考）
```
- 全片统一推荐 200-400

## --cref 角色参考（MJ）

### 用法
```
/imagine prompt: [正向词] --cref [image URL] --cw 100
```
- `--cref [url]`：引用角色图，锁定脸/发/衣
- `--cw 0-100`：角色权重
  - `--cw 100`：脸+发+衣全锁（默认）
  - `--cw 0`：只锁脸（换装/换发型用）

### cref 最佳实践
- 参考图必须是 **MJ 自己出的图**——网图/真人照识别差
- 参考图角色占画面大、正面、光线干净
- 多角色场景：每角色各一张 cref，用 `--cref url1 url2` 串联

## sref + cref 组合（全片锁死）
```
/imagine prompt: [场景+动作] --sref [风格图] --sw 300 --cref [角色图] --cw 100 --ar 16:9
```
- 这是动漫短剧**角色+画风双一致**的标准打法
- 工作流：先 MJ 出角色定妆图 → 该图同时做 cref → 全片复用

## 非 MJ 工具的等效做法

### SD / Flux
- **ControlNet Reference**：等效 cref，锁角色
- **IP-Adapter**：等效 sref，锁风格
- **LoRA**：训练角色/画风 LoRA=最稳但需训练

### 视频 AI（Gen3/Kling/即梦）
- **图生视频**本身就是参考图锁定——关键帧喂进去=构图+角色+风格都锁
- MJ 出干净关键帧 → 图生视频 = 最一致链路（见 087）

## 参考图选择原则
1. **MJ 自出图优先**——MJ 训练分布对齐
2. **角色占画面 60%+**——细节够
3. **正面/45度侧**——别用大侧面
4. **光线干净单一**——别用逆光剪影做 cref
5. **背景简洁**——别让背景污染角色识别

## 多参考图策略
- **风格图 1 张 + 角色图 N 张**（N=角色数）
- 风格图全片只用 1 张=统一
- 角色图每角色固定 1 张，全片复用
- 别频繁换参考图=风格飘

## 常见坑
- **用网图做 cref**：识别差→角色变脸
- **sref + cref 用同一张图**：风格角色混做→都锁不牢
- **sw 给太高**：>500→变成复制参考图，失去新场景
- **cw 0 还想锁衣服**：cw 0 只锁脸——换装场景才用
- **频繁换 sref**：全片色调飘——一部片只用 1-2 张风格图

## 进阶
- **风格图库**：按情绪分类建风格图库（冷峻/温暖/水墨/赛博）
- **角色定妆集**：每角色出 5-8 张定妆图做 cref 池
- **--sref random 抽灵感**：跑 20 张 random 抽风格灵感
- **MJ v6+ 个人化**：`--p [personalize code]` 个性化风格

## 备注
- sref 管色质光，cref 管脸发衣——分工明确
- 全片统一=同 sref + 同 cref + 同风格词
- 参考图优先用 MJ 自出图
