# 提示词避坑与调试

## 核心要点
- 出图崩=诊断+对症下药，别瞎改
- 第一步：**定性失败还是随机失败**——跑 4-6 次同提示词
- 100% 失败=结构性问题→改提示词
- 30-70% 失败=欠定义→加细节词
- 0-30% 失败=随机性→换 seed
- **一次只改一个变量**——多改无法归因

## 调试闭环（核心）

### Step 1: 复现率判定
```
跑同提示词 4-6 次（不锁 seed）
→ 100% 失败：结构问题（改词）
→ 30-70% 失败：欠定义（加细节）
→ 0-30% 失败：随机性（换 seed 选好的）
```

### Step 2: 锁 seed 隔离变量
```
锁定 seed → 只改提示词一个词 → 跑
→ 看该词对画面的具体影响
→ 多词同改=无法归因
```

### Step 3: 检查七段完整度
```
场景 + 主体 + 动作 + 镜头 + 光影 + 风格 + 参数
→ 缺哪段补哪段
→ 最常缺：光影段（→均匀光无张力）
```

### Step 4: 词序调换测试
- 主体放首位=主体强
- 风格放首位=风格强
- 想要什么突出=放前面

## 常见失败模式 → 修复

### 失败 1：角色崩脸/崩手
```
原因：缺负向 + cref 不干净
修复：
- SD 加 (bad hands:1.4) (bad face:1.4)
- MJ 加 --no（简单）/ 换更干净的 cref 图
- 换 MJ v6+ 或 niji 6（手部已稳）
```

### 失败 2：风格飘
```
原因：缺 --sref 或风格词不统一
修复：
- 加 --sref [风格图] --sw 300
- 全片固定同一组风格词
- 同一 seed 池复用
```

### 失败 3：角色变脸
```
原因：cref 频繁换 / 网图做 cref
修复：
- 一角色一张 cref 全片用
- cref 图用 MJ 自出
- 提高 --cw 到 100
- 仍变→加 IP-Adapter 或训练 LoRA
```

### 失败 4：画面太"奶油"无张力
```
原因：MJ 默认美化 + 缺光影词 + chaos 0
修复：
- 加 --style raw
- 加侧光/逆光/体积光词
- --chaos 10-30
- 加 dutch angle / 留白 / 引导线词
```

### 失败 5：动作糊
```
原因：多动词 / 缺 motion blur 方向词
修复：
- 一句一动词
- 写 "motion blur along [方向]"
- 分镜出关键帧再图生视频
```

### 失败 6：构图太满无张力
```
原因：主体居中填满 / 没留白词
修复：
- 加 wide shot / negative space
- 主体压边/角
- 加引导线（走廊/柱列）
- --chaos 10-30 增加构图变化
```

### 失败 7：提示词被忽略后半部分
```
原因：词超 60（MJ）/ 超长（SD）
修复：
- 精简到 40 词内
- 最重要的放前面
- 复杂场景拆多张关键帧
```

### 失败 8：seed 复现失败
```
原因：提示词或参数有改动
修复：
- seed 只在同提示词+同参数下复现
- 想换风格=换 sref，别换 seed 期待复现
```

## 调试日志模板
```
| 日期 | 提示词摘要 | seed | 参数 | 结果 | 失败类型 | 修复 |
|------|-----------|------|-----|------|---------|------|
```
- 记录 seed 是黄金习惯
- 失败+修复=知识库=下次不踩同坑

## seed 抽选策略
```
1. 同提示词跑 4 次（自动不同 seed）
2. 选张力最强那张
3. 记下 seed
4. 后续精调用该 seed
5. 同 seed + 同提示词=可复现
```
- 注意：seed 不能跨提示词复现风格
- seed 只锁"初始噪声布局"——提示词一改就失效

## 提示词精简原则
- MJ ≤ 40 词最佳（超 60 后段被忽略）
- 视频 AI ≤ 30 词最佳
- 删冗余形容词——保留结构性词
- 风格词固化（sref）→ 提示词内可省风格段

## 常见坑
- **崩了就重投**：不诊断=永远崩
- **多词同改**：无法归因=瞎调
- **不记 seed**：好图无法复用
- **复制别人提示词不改**：不同模型/版本表现不同
- **崩溃就堆参数**：chaos+stylize 都拉满=更不可控

## 进阶
- **A/B 对比法**：同 seed 跑两版提示词→定优劣
- **词序实验**：把重点词轮流放首位测影响
- **失败库**：记录每次失败+原因+修复=个人调试知识库
- **分段隔离**：先只测镜头词、再加光影、再加风格——逐段定档

## 备注
- 定性 vs 随机失败是诊断第一步
- 一次一变量是黄金法则
- seed 是复现钥匙但跨提示词无效
