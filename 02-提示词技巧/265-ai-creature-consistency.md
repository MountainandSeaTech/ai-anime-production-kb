# AI视频动物一致性

## 核心要点
- **动物比人更易漂移**：模型对动物形态的"先验"比人脸弱，逐帧重新推导时毛色/体型/斑纹最先漂——必须三重锁定
- **三重锁定**：①固定种子 ②唯一主参考图（三视角＋姿态组）③锚词固定描述（物种＋毛色＋体型＋识别点）
- **禁链式引用**：上一镜的输出不当下一镜的参考——误差会累积放大，三镜之后"换了只动物"

## 详细内容
- **主参考图制度**：动物资产出"三视角设定图＋动作姿态组"两张（活物三件套，见批次0 §6.1 闪电貂先例），每镜引用主参考图，不引用中间结果
- **锚词写法**：每 Shot 复写完整描述（"同一只灰白小貂，红眼、身不满一尺"），不用"it/它"代词——与 183 武器锚词同规则
- **姿态对接**：姿态组里的姿态（睡/探/警/懒/玩）作为单镜参考直接引用，比纯文字描述稳定得多

## 关键参数 / 模板 / 清单
```
锁定参数：
  · 种子：同一整数种子贯穿全剧（闪电貂＝9202 先例）
  · 锚词结构：同一只 + [物种] + [毛色] + [体型] + [1个识别点]
    例：「同一只灰白色小貂，身不满一尺，红眼精光」
  · 负向词：different animal, species change, fur color shifting,
    size inconsistency between shots, creature morphing

每 Shot 自检：
  □ 锚词是否复写（非代词）  □ 引用的是否主参考图（非上镜输出）
  □ 姿态是否引用姿态组对应帧  □ 种子是否沿用
```

## 备注
- 与 004（角色一致性方案）、088（一致性张力）同源，本条是动物特化版——动物容错率更低
- 多只同类动物同框时，锚词必须加区分符（"左一右一""毛色略深的那只"），否则模型随机分配
