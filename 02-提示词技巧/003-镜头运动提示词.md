# 镜头运动提示词词库

## 核心要点
- 镜头运动词决定画面调度，与主体动作组合时先镜头后动作
- 单镜头只用一种主运动，组合运动（如「推进+横摇」）易触发畸变
- 速度修饰词影响节奏：slow / fast / gradual / sudden

## 镜头运动词库

| 中文 | 英文 prompt | 适用场景 | 注意 |
|---|---|---|---|
| 推（推进） | dolly in / push in | 强调主体、情绪收紧 | 节奏慢，适合氛围/决意镜头 |
| 拉（拉远） | dolly out / pull back | 揭示环境、收束段落 | 适合段尾、转场前 |
| 摇（横摇） | pan left / pan right | 跟随移动、扫视场景 | 主体别动，否则易拖影 |
| 摇（竖摇） | tilt up / tilt down | 从脚到头揭示角色、仰视压迫 | tilt up 适合登场 |
| 移（横移） | tracking shot / truck | 跟随并行、侧面跟随动作 | 打戏侧面跟随最稳 |
| 跟 | follow shot | 跟随主体移动 | 背后跟随稳定性最好 |
| 升降 | crane up / crane down | 揭示场景、俯仰转换 | 升降揭示环境好用 |
| 手持 | handheld | 紧张感、临场感 | 动漫风格慎用，易晃晕 |
| 斯坦尼康 | steadicam | 平滑跟随 | 长镜头调度 |
| 固定 | static / locked-off | 静观、构图为主 | 最稳，动作戏用固定机位+主体动 |

## 速度与节奏修饰
- slow / fast / gradual / sudden / smooth / jittery
- 「slow dolly in」= 慢推进，决意/压抑
- 「fast pan」= 快横摇，转场/惊愕
- 「gradual tilt up」= 缓慢上摇，登场揭示

## 动漫短剧组合建议
- 居合斩杀：static + 主体出刀（镜头不动，动作爆发力最强）
- 角色登场：gradual tilt up from feet to face
- 段落收束：slow dolly out + 主体渐远
- 双方对峙：static + 来回切换正反打（不要一个镜头横摇扫两人）

## 备注
- 镜头运动越复杂，模型越容易在运动中产生形变，优先「固定机位 + 主体动」
- 「dolly in + 主体动作」组合成功率高于「pan + 主体动作」
- 横摇扫过 2 人以上场景，扫到第二人时面部常崩
