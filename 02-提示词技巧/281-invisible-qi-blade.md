# 无形气刃表现法

## 核心要点

- 六脉神剑、火焰刀、擒龙功这类"无形攻击"的最大难题：观众看不见武器，力量感全靠间接证据
- 三锚点法则：**发招者姿态＋介质扰动＋受击反馈**，三者必须同框或快速连剪
- 铁律：宁可用环境碎裂表现，不滥用光束/光刃——光剑化是写实片第一大忌

## 详细内容

### 锚点1：发招者姿态
- 指法/掌缘必须有明确的"发射方向"——观众从姿态读弹道
- 蓄力帧给指端特写：观众记住"这根手指=这把剑"

### 锚点2：介质扰动（气刃的"显影剂"）
| 介质 | 表现 |
|---|---|
| 灰尘/烟雾 | 被切开一道直线空隙 |
| 落叶/花瓣 | 沿线齐齐断为两截 |
| 水面/酒面 | 划开一道深沟再合拢 |
| 烛火/灯笼 | 火焰被气刃压弯成线 |
| 雨幕 | 雨滴沿线被劈开（高级感最强） |

### 锚点3：受击反馈
- 衣物先裂→皮肤后现血线（延迟0.3秒渗血）
- 器物断裂（剑断/柱裂/瓦碎）作威力刻度
- 受击者"先愣后痛"的反应两拍

### 反例清单（不要这么画）
- 指端发光/光刃射出（变星战）
- 气刃全程可见带颜色（变页游）
- 受击处直接喷血无延迟（廉价）

## 关键参数 / 模板 / 清单

**通用提示词结构**
```
[发招者指法/掌缘特写] → [介质沿线扰动] → [受击处延迟反馈]
负向词：visible energy blade, laser beam, glowing projectile, magic bolt,
colored energy trail, particle effects
```

## 备注

- 雨幕＋无形剑气是武侠高级感天花板，但雨本身成本高，留作高光场景专用
- 介质选择要与场景资产绑定（无量山用落叶、聚贤庄用尘土、小镜湖用水面）
