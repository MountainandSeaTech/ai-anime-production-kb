# 降龙掌视觉表现——龙形气劲与写实掌风双方案

## 核心要点

- 原著降龙掌**无龙形描写**，金龙气劲是 97TVB 版首创的影视再创作，03 张纪中版走写实掌风
- 两条路线都可成立，但**同一部片内不得混用**——先定口径再出图

## 详细内容

### 方案A：龙形气劲（魔幻路线）
- 特征：出掌时金色/青色龙形气劲随掌而出，龙身缠绕手臂，击中有龙吟音效位
- 优势：辨识度极高、每招一龙可做"龙的姿态=招式意象"对仗（飞龙在天=升龙、神龙摆尾=回龙）
- 风险：容易低幼化/页游感

### 方案B：写实掌风（本剧口径匹配路线）
- 特征：无具象龙形，以空气扭曲、尘土环爆、衣发乱舞、地面碎裂表现掌力
- 优势：与本项目"真人写实风"画风口径一致
- 风险：力量感依赖音效与受力反应补

### 混用禁忌
- 同一场戏不得 A/B 混用；全剧建议统一 B，高光招（如神龙摆尾反杀）可特批一次 A 作为情绪爆点

## 关键参数 / 模板 / 清单

**方案A 提示词模板**
```
武者出掌瞬间，一条金色龙形气劲随掌势腾空而出，龙身缠绕其小臂，
龙首冲向对手，气劲边缘呈半透明流质，被击处尘土呈环形炸开。
负向词：cartoon dragon, chibi dragon, plastic texture, cheap VFX look,
flat 2D dragon decal, mobile game effect
```

**方案B 提示词模板**
```
武者出掌，掌心前方空气呈热浪状扭曲，地面尘土以掌路为轴呈放射状卷起，
对手衣发被无形掌风压向后方，无具象特效，纯物理扰动表现力量。
负向词：glowing dragon, energy beam, magic aura, particle sparkles,
superhero energy effect
```

## 备注

- 本项目全剧画风已锁定真人写实风，默认走方案B；方案A仅作特批备案
- 无论 A/B，受力者的"延迟一拍再飞"反应帧必须保留（关联 277）
