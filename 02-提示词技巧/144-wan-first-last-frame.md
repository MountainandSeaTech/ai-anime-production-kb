# Wan首尾帧技法

## 核心要点
- 首尾帧=给AI画一条走廊：起点和终点定死，中间路径AI补
- 首尾帧差异越大，**过渡描述越要细**——官方明确要求写清过渡过程
- 首尾帧是当前AI视频**单镜控制度的天花板**
- 关联 119 参考图技法、138 锚点接力

## 首尾帧详解

### 三种使用模式

#### 模式1：仅首帧（图生视频基础）
```
输入：1张首帧图 + 运动提示词
控制度：★★★（起点锁定，终点随机）
适用：氛围镜头/单向运动
```

#### 模式2：首帧+尾帧（走廊约束）
```
输入：首帧图 + 尾帧图 + 过渡提示词
控制度：★★★★★（两端锁定，中间补全）
适用：精确动作/构图变化/状态转换
```

#### 模式3：首尾帧+中间引导（如支持）
```
部分工作流支持参考视频/姿态序列
控制度：★★★★★+
适用：复杂动作还原（武打/舞蹈）
```

### 首尾帧的帧图设计原则

#### 原则1：同主体同场景
```
首帧：少女在神社前，刀在鞘中
尾帧：少女在神社前，刀已出鞘
→ 场景一致，状态变化=安全
```

#### 原则2：差异即剧本
```
首尾帧的差异点=这个镜头要讲的事：
  位置差=移动
  姿态差=动作
  表情差=情绪变化
  光线差=时间/氛围变化
  景别差=运镜
```
- 差异种类≤2种最稳；3种以上=AI中间过程易崩

#### 原则3：构图可推演
```
首帧角色在左，尾帧角色在右
= AI能补出从左到右的移动
首帧角色在左，尾帧角色在上且缩小
= AI要同时处理移动+缩小+透视=翻车率↑
```

## 过渡提示词写法

### 官方模板
```
"描述首帧状态。描述过渡过程（运镜/主体运动）。描述尾帧状态。"
例：
"A small black cat looks up at the sky curiously.
 The camera gradually rises from eye level
 and finally captures its curious gaze from a top-down view."
```

### 过渡词清单
```
运镜过渡：camera gradually rises / slowly pushes in
主体过渡：turns around / raises her hand / runs forward
状态过渡：the flower blooms / the wound heals / night falls
时间过渡：as the sun sets / the candle burns down
```

## 首尾帧图的生产流程

### 流程
```
1. 写分镜表，确定每镜首尾状态（关联138分镜表锚点列）
2. 生成首帧图（文生图，精细调整）
3. 基于首帧改图生成尾帧（图生图/局部重绘）
   → 保持角色/场景一致，只改差异点
4. 首尾帧+过渡提示词 → 图生视频
5. 中间崩坏 → 缩短时长/简化差异/重抽
```

### 尾帧改图技巧
```
首帧图 → 局部重绘只改：
  - 手部姿态（拔刀）
  - 表情（眼神变化）
  - 光线（色调偏移）
角色主体/背景不动=一致性最大
```

## 模板示例

### 例1：拔刀（状态差）
```
首帧：剑客对峙姿态，刀在鞘中，手扶刀柄
尾帧：同构图，刀已半出鞘，寒光映眼
提示词：
"The swordsman slowly draws his blade.
 Cold light reflects in his eyes as the katana emerges.
 Camera static, tension builds."
```

### 例2：揭示（景别差）
```
首帧：特写，冰镐凿进岩壁
尾帧：大远景，登山者独立山脊，日出金光
提示词：
"Extreme close-up of an ice axe striking rock.
 Camera dollies backward and tilts up to reveal
 a lone mountaineer on a sunrise-lit alpine ridge.
 Golden rim-light, subtle lens flare."
```

### 例3：时间差（光线差）
```
首帧：窗前人物，晨光，手臂缠绷带
尾帧：同构图，暮光，绷带拆除露出疤痕
提示词：
"Same person by the window, time passing from dawn to dusk.
 Light shifts from gold to blue. The bandage is gone,
 revealing a healed scar. Camera locked."
```

## 常见坑
- **首尾帧风格不一致**：两张图不同模型生成=中间崩坏→尾帧必须从首帧改图
- **差异过载**：首尾帧位置+姿态+景别+光线全变=AI摆烂
- **过渡提示词缺失**：差异大但不写过渡=AI自由发挥中间过程
- **时长给太长**：首尾帧约束随时间衰减——Wan 3.0 单次可到 30s，但锚定越往后越松；5-10s 最稳，20-30s 必须靠更密的过渡描述＋锚点帧兜底
- **尾帧复用不检查**：上一镜尾帧直接做下一镜首帧前，先检查尾帧质量（崩帧会传染）

## 进阶
- **首尾帧链**：镜头A尾帧=镜头B首帧=无缝接力（关联138）——长镜头连续性最强方案
- **锚点帧加密度**：复杂动作拆成3秒一段，每段首尾帧=分段走廊
- **首帧即海报**：首帧图按成图标准精修——视频质量上限由首帧决定
- **反向首尾帧**：先生成想要的结尾帧，反推首帧=高潮倒推法
