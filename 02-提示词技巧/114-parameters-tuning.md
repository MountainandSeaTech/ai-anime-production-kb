# 权重与参数调优

## 核心要点
- 提示词写好是骨架，参数是**旋钮**——精调出片
- MJ 三大核心参数：`--ar`（比例）/`--chaos`（变化）/`--stylize`（风格化）
- SD 系核心：`(term:权重)` 语法 + seed + steps
- seed 是**唯一可复现的钥匙**——好图必锁 seed
- 参数不是越多越好——叠太多=不可控

## MJ 核心参数速查

### --ar / --aspect 比例
```
--ar 1:1     方（默认，不适合影视）
--ar 16:9    横屏影视（电影感）
--ar 9:16    竖屏短剧（抖音/B站竖版）
--ar 4:5     人像特写
--ar 21:9    超宽银幕（史诗感）
```
- 横屏=环境+叙事；竖屏=主体+亲密
- 影视人像推荐 4:5 而非 16:9——更聚焦

### --chaos / --c 变化度（0-100）
```
--c 0     低（可靠，构图稳）
--c 10    张力构图起点
--c 20    推荐（构图多样但不乱）
--c 50    高（意外构图多）
--c 100   极高（几乎随机）
```
- 想要张力构图（失衡/倾斜/留白）→ chaos 10-30
- 想要稳态构图→ chaos 0-5
- 默认 0，多数人忘了加→出图太"安全"无张力

### --stylize / --s 风格化强度（0-1000）
```
--s 0       关闭风格化（最真实）
--s 100     低（默认）
--s 250     中（推荐起点）
--s 500     高（风格强）
--s 1000    极高（艺术化重）
```
- 写实风→低 s（50-100）
- 动漫/插画风→中高 s（250-500）
- 太高=风格压过内容→角色崩

### --style raw 美化抑制
```
--style raw    减MJ自动美化倾向
```
- MJ 默认会"奶油化"——加了 raw 才真实
- 张力片必加——不加=温柔光无张力

### --seed 种子
```
--seed 1234567890
```
- 唯一可复现参数——同 seed+同提示词=同图
- 范围 0-4294967295
- 用法：跑4张选最好那张的 seed→复用调整

### --no 排除（见 112）
```
--no text, watermark, blur
```

### --sref / --cref（见 113）
```
--sref [url] --sw 200
--cref [url] --cw 100
```

### --niji 动漫模型
```
--niji 6     切到二次元模型
```
- 动漫短剧专用——比默认模型更适合

## SD 系权重语法

### 通用权重
```
(term:1.4)   强调
(term:0.8)   弱化
(term)      默认权重1.0
```
- 权重>1.5 容易崩
- 正向权重 + 负向权重（见 112）= 双向控制

### 关键参数
```
steps 20-40      采样步数（低快糙，高慢细）
cfg 5-12         提示词依从度（低自由，高听话）
sampler DPM++    采样器（DPM++系列最稳）
seed -1          随机；固定=可复现
```

### 高分辨率修复
```
Hires. fix: upscale 2x, denoising 0.35-0.5
```
- 出图后放大修细节——手部/面部崩坏修复用

## 视频AI参数（Gen3/Kling/即梦/Wan3）

### 共通参数
```
duration        时长（5s/10s）
aspect ratio    比例
seed            可复现（部分工具支持）
```

### Wan 3.0 参数基线（2026-10 校准）
```
duration        4-30s（原生单段上限 30s）
分辨率           480P / 720P / 1080P（1080P 为基准档）
帧率            30fps（原生音画同步帧率）
音频            原生音画（BGM + 音效随画面同步生成，无需后配）
多模态参考      10图 + 5视频 + 5音频（见 Skill《资产包生成》多模态素材指引）
限流            300 RPM
价格            480P ¥0.3/s ｜ 720P ¥0.6/s ｜ 1080P ¥1.2/s
```

### 运动强度（部分工具）
- Kling: 运动幅度 slider
- 即梦: 动作幅度档（小/中/大）
- Gen3: 提示词里"slow/fast"控制

### 视频 AI 无负向无权重
- 靠正向提示词精炼 + MJ 关键帧锁定 = 等效
- 见 112 伪负向段

## 参数组合推荐档

### 张力关键帧（MJ）
```
--ar 16:9 --chaos 15 --stylize 300 --style raw --sref [风格图] --sw 300
```

### 动漫角色定妆（MJ）
```
--ar 4:5 --chaos 5 --stylize 250 --niji 6 --cref [角色图] --cw 100
```

### 写实影视感（MJ）
```
--ar 21:9 --chaos 10 --stylize 100 --style raw
```

### SD 高质出图
```
steps 35, cfg 7, DPM++ 2M Karras,
(masterpiece:1.2), (best quality:1.2),
[negative: 通用包+手部包]
Hires. fix 2x, denoise 0.4
```

## 常见坑
- **chaos 0 默认**：忘了加→构图太稳无张力
- **stylize 拉满**：>750→风格压角色→崩脸
- **seed 不记**：好图没记 seed→无法精修
- **参数全堆**：chaos 100 + stylize 1000 → 完全不可控
- **cfg 太高**：SD cfg>15→画面焦糊

## 进阶
- **参数扫描**：固定提示词，chaos 跑 0/10/20/30 对比出最佳档
- **seed 池**：跑 8 个 seed 选最好那张，记下复用
- **风格化分层**：基础 stylize + sref + 风格词 三层叠加=最稳
- **MJ 多 seed 抽帧**：同一提示词跑 4 次（自动不同 seed）选张力最强

## 备注
- chaos 10-30 是张力构图的甜蜜点
- stylize 250-500 是动漫出图档
- seed 是唯一复现钥匙
